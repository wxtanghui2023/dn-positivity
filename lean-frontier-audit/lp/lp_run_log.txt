§3 刚性关系：网格对齐标记律（x_i ∈ Z）
==============================================================================
若所有 x_{c,i} ∈ {0..255}，则 M_k = Σ_{i:x_i=k} m_{c,i}, Σ M_k = N, n2 = #{M_k = 2}:
  Parseval: Σ_{j=1}^{256} S(j) = (1/256)Σ_{j=0}^{255}|DFT M(j)|² = Σ_k M_k² = N + 2n2 = N(2 − p)
  S(N)=1 (sine-kernel 端值)      ⟹ p = 1.498046875
  S(N)=盒上端 211.432             ⟹ p = 0.676046839
  记录值 p0 = 0.681828687 与 2/3 = 0.6666667 均不在此二值上
  ⟹ 可硬算的结论：最优律**非网格对齐**（位置必为非整数有理数，与 docstring 逐字一致），
     故 Parseval 不适用，p 与 S 之间**没有**可硬算的刚性耦合 ⟹ 这正是缺失的 marks 几何。
