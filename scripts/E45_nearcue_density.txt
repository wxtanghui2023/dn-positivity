READING
  If the distinct count grows and the smallest gap shrinks as m grows, the achievable set densifies,
  so any prescribed edge value can be approximated arbitrarily well by an exact-ramp law.  If the
  smallest gap stalls, densification is not happening at these sizes and exact matching stays a search
  problem -- both answers are useful, and this script reports which one the data shows.
