  => every computed lower bound is POSITIVE, hence lambda_n > 0 for each n tested.

  ⚠️ VALIDITY vs INFORMATIVENESS (two different things, must not be conflated):
     VALIDITY: for on-line zeros every omitted summand has real part
       1 - cos(n theta) >= 0, so the partial sum IS ALWAYS <= lambda_n. No restriction.
     INFORMATIVENESS: for n >> gamma_max the partial sum SATURATES at the number of
       tabulated zeros (here about 2.0e6), because n*theta_gamma = n/gamma oscillates
       rapidly and each term averages to 1. The rows at n = 1e7, 1e8, 1e9 (all about
       2.0e6) show exactly this saturation, and are NOT evidence of large lambda_n.
     So the table is informative for n up to roughly gamma_max; beyond that it only
     repeats the zero count. The positive entries in the informative regime are the
     content: they prove lambda_n > 0 there.

(2) THE MARGIN S_n / n AS A FUNCTION OF n  (where the theorem would be tight)
------------------------------------------------------------------------------

  Split point T = gamma_max/2 = 5.6625e+05, giving B_T = 8.232379e-07 on the table.
  We scan only the applicable regime n <= gamma_max/10.

             n                  S_n/n            S_n/(n^2 B_T)
          1000           1.162106e+00             1.411628e+03
         10000           1.727623e+00             2.098570e+02
        100000           2.220858e+00             2.697711e+01
       1000000           1.986729e+00             2.413311e+00
      10000000           2.172562e-01             2.639045e-02
     100000000           2.008602e-02             2.439881e-04

  => READ THE NUMBERS, NOT AN EXPECTATION: the ratio DECREASES monotonically,
     1.41e3 (n=1e3) -> 2.10e2 -> 2.70e1 -> 2.41e0 -> 2.64e-2 -> 2.44e-4 (n=1e8),
     crossing 1 near n ~ 1.5e6. Hence the partial sum is informative only up to
     about the zero count itself; beyond that the tail term n^2 B_T dominates it.
     (My first draft of this sentence claimed the ratio stays above 1e10. The numbers
      printed above refute that, and the sentence was corrected to match them.)

------------------------------------------------------------------------------

  Paper A: lambda_n >= 0 for 2 <= n <= 2T - O(1). Compare with the prior claim
  n < T0^2 (Oesterle, uncirculated; reported in BPY 2001 and Voros 2020/2022).

     verified height T       our range 2T      prior claim T^2    ratio T/2
            1.1325e+06         2.2650e+06           1.2826e+12    5.662e+05

  => our linear window is a factor T/2 SMALLER than the prior quadratic claim.

==============================================================================
SUMMARY (number-driven)
==============================================================================
  (1) Direct computation of the Li coefficients from 2M zeros gives positive lower
      bounds for every n tested up to 1e9.
  (2) The margin S_n/n is O(1) up to n ~ 1e6 and then declines; the ratio to the
      tail term n^2 B_T falls below 1 near n ~ 1.5e6, which sets the end of the
      informative regime of the partial sum.
  (3) The theorem's linear range is a factor T/2 below the prior quadratic claim;
      this is now measured, and must be disclosed in the paper.
  (4) The phase expansion the paper relies on is verified to 1e-15 relative.
