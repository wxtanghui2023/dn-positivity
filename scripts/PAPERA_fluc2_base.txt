==============================================================================
SUMMARY
==============================================================================
  1. theta_gamma == theta(gamma); one phase function (max diff 1.4e-17).
  2. Fluc(n) = C0 - sum_{gamma<=T0} cos(n theta_gamma) + J(n); quadrature reproduces
     the project's |Fluc| = 10.17, 42.32, 39.38, 30.52 at n = 1e3..1e6.
  3. J(n) = Theta(N) for n << T0 and decays like T0^2 log T0/n; so for n >> T0 the
     problem IS the exponential sum sum cos(n theta_gamma).
  4. Allowance at n=T0^2 = 6.5465e+05 = 0.3272 N; sampled |sum cos| ~ sqrt(N/2).
  5. MARGIN = Theta(sqrt(N(T0))) = Theta(sqrt((T0/2pi) log T0)): the square-root
     cancellation gap.  This is the correct technique: an o(N) bound on the sum.
