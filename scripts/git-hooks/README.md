# git hooks（dn-project）

`.git/hooks/` **不受版本控制** ⟹ 本目录为**入库副本**，克隆后请执行：

```bash
cp scripts/git-hooks/pre-commit .git/hooks/pre-commit && chmod +x .git/hooks/pre-commit
```

## 四条规则
1. **已查地图**：`docs/` 下**新增** `.md` 必须首 20 行内带「已查地图：」标记（`ERRATUM*` 豁免）。
2. **NEWNESS RULE**（2026-09-17 17:47）：新档若含 `不重复|新手段|新用途|从未触及|首次|新发现` ⟹ **必须**同时含一行 `技术词…命中文件数=`（由 `scripts/tech_word_check.sh` 产出）。
3. **D0/D1 LEDGER RULE**（2026-09-18 19:13）：新档必须显式写 `D0:` 与 `D1:` 两行；连续 D1=0 ≥ 3 ⟹ 须带 `FREEZE-ACK:` 令牌。
4. **ROUTE-DEDUP GATE**（2026-09-29 19:48）：新档正文若命中 `docs/ROUTE-FINGERPRINTS.tsv` 中**已关闭路线**之指纹，**必须**在该档含一行机器可读申报：
   ```
   ROUTE-CHECK: R02=DUPLICATE R07=DUPLICATE <其余>=NEW
   ```
   且**不得**把已关闭路线申报为 `NEW`（否则视为违规拒提交）。
   起因（唐先生 19:48）：「这个结构性强制，我们在做 RH 时就已经有了，但实际上呢，只是偶尔生效。」
   ⟹ 教训：**建议性脚本（靠人主动跑、关键词由人选）会失效；只有机器在提交点强制的才有效。**
