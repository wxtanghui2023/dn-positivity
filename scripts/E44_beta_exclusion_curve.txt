(5) SLACKNESS: bound / truth   at sigma = 0.6 and 0.7, T0 = 3.0e12
------------------------------------------------------------------------------

  True N(sigma,T0) = 0 for sigma > 1/2 (RH verified to T0). The bounds give:
    sigma = 0.60:  Ingham bound = 4.951e+10   Guth-Maynard bound = 3.000e+12   truth = 0
    sigma = 0.70:  Ingham bound = 4.345e+08   Guth-Maynard bound = 4.345e+08   truth = 0
    sigma = 0.80:  Ingham bound = 1.732e+06   Guth-Maynard bound = 2.225e+05   truth = 0

  => the ratio bound/truth is INFINITE at every sigma > 1/2: the bounds are
     not merely loose, they are vacuous in exactly the region that matters.
     truth is 0 while the bound is 4.951e+10 at sigma = 0.6 (Ingham)
     and 3.000e+12 at sigma = 0.6 (Guth-Maynard): the gap is unbounded.

------------------------------------------------------------------------------
SUMMARY: THE SHAPE OF THE WALL (numbers above, not interpretation)
------------------------------------------------------------------------------

  sigma in [1 - 1/(5.573 log T), 1]      : EXCLUDED (zero-free region)
  sigma in (1/2, 1 - 1/(5.573 log T))    : NO unconditional exclusion exists
                                            from any of the four standard inputs
  sigma = 1/2                             : the RH line itself

  Width of the UNEXCLUDED band, 1/2 < sigma < sigma*(T):
    T =    1e+06: width = 0.487012
    T =    1e+12: width = 0.493506
    T =   1e+100: width = 0.499221
    T -> infinity: width -> 0.500000  (the band fills the entire strip)

  => As the verified height grows WITHOUT BOUND, the unconditionally unexcluded
     band WIDENS toward (1/2, 1). The wall does not move toward RH; the
     unconditional knowledge retreats away from it.

------------------------------------------------------------------------------
(6) THE THREE KNOWN INGREDIENTS, SIDE BY SIDE
------------------------------------------------------------------------------

  (a) numerical verification  : zeros on the line up to gamma = 1.13e+06
                               (this table) and to 3.0e12 (Platt-Trudgian)
  (b) zero-free region        : excludes sigma > 1 - 1/(5.573 log T)
  (c) de Bruijn-Newman        : Lambda >= 0, and Lambda = 0 iff RH (Rodgers-Tao)
  (d) zero-density exponents  : a(sigma) > 0 for all sigma < 1 (no exclusion)

  (a) and (b) are both of the form "verified/excluded up to some boundary";
  (b) RETREATS as T grows, (a) ADVANCES only with computation. Neither touches
  the individual real parts in (1/2, 1). (c) is a single number. (d) is vacuous.

  This is the beta-wall, stated in numbers rather than in words.
