## 挑战 1：P_γ 闭式从头独立推导 + 验证

**目标**：P_γ(δ) = δ²M₂/(2U²D₊D₋) 是恒等式还是近似？

**执行**：
- 从 w_H 直接定义计算 P_γ（2w_H(γ,0) − w_H(γ,δ) − w_H(γ,−δ)）vs 闭式
- 40 位精度：γ 大时相对差 1e-9~1e-3（✗——疑似问题！）
- **100 位精度**：全部相对差 1e-87~1e-98（✓——精确恒等式）

**结论**：✅ **P_γ 闭式是精确恒等式**（非近似）——40 位"失败"是灾难性抵消
（γ=1000 时 P~2e-23 而各项 ~5e-10——13 位抵消——40 位精度不足）——
100 位确认。M₂ 系数全正（γ≥γ₁——U≥200）——P_γ ≥ 0——=0 ⟺ δ=0。

**方法学教训**：数值验证必须考虑灾难性抵消——用足够精度或解析方法。

## 挑战 2：在线 δ=0 配对的严格定义

**目标**：w_H(γ,0) = 1/(1+γ²)² 的严格来源——K^nat_0 = −1/x² 奇异——需要有限部分吗？

**执行**：
- Parseval 定义：⟨K^nat_0(·−γ),H_0⟩ := ∫K̂^nat_0(u)Ĥ_0(u)e^{−2πiuγ}du
- 乘积 K̂^nat_0·Ĥ_0 = (π/2)e^{−2π|u|} + π²|u|e^{−2π|u|}——**u=0 处有限**（|u|·1/|u| 抵消）——L¹
- quad 振荡数值（γ=30/100）失败（✗）——但——**解析求值**（标准积分
  ∫₀^∞e^{−au}cos(bu)du = a/(a²+b²) 等）——γ=30/100/1000 相对差 1e-46~1e-48 ✓

**结论**：✅ **在线配对通过 Parseval 严格定义——不需要时域有限部分**——
值 = 标准积分的解析恒等式 1/(1+γ²)²。quad 振荡失败是数值方法问题。

## 挑战 3：w_H 的 Parseval 空间归属

**目标**：逐项配对的合法性——K^nat/H_0 在什么空间？

**执行**：
- δ≠0：K^nat_δ ∈ L²（x=0 有限——远处 1/x²——L²）✓
- δ=0：K^nat_0 ∉ L²（x=0 处 1/x⁴ 不可积）——**但配对不经由 K^nat_0 ∈ L²**
- H_0 ∉ L¹/L²（对数增长）——但 Ĥ_0 ∈ S'（1/|u| 型）
- **配对 = ∫(K̂^nat·Ĥ_0)e^{−2πiuγ}du——被积函数 ∈ L¹——良定义 Lebesgue 积分**
- **只依赖乘积 ∈ L¹——不依赖 K^nat/H_0 单独的空间归属**

**结论**：✅ 逐项配对严格定义——Parseval 是定义（u 域积分）非形式操作——
值由标准积分解析确定——无"Fourier 双边相等"跳跃。
