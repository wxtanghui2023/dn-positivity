## §1 字段语义（**固定，写入预注册**）

```text
true / false  ：已定义假设的判定值
null          ：该假设在当前实例的前置条件下【未定义】
字段缺失       ：输出不完整或违反输出格式 ⟹ 【不得】自动等同于 null
已定义字段     ：必须【存在】且为【布尔】且【值正确】
未定义字段     ：必须【显式输出 null】；未按要求 ⟹ 按冻结格式合规规则处置
```

⚠️ **关键区分**：显式 `null` 解决的是**输出歧义**，**不**自动解决判分器的**数学正确性**。
判分器仍须**分别实现每个假设的定义条件**，并验证其真值逻辑。

## §3 响应分类（五态，**先判 `finish_reason`**）

| 状态 | 触发 | 判分语义 |
|---|---|---|
| `SCOREABLE` | 可解析 ∧ `finish≠length` | 正常判分 |
| `PARTIAL_TRUNCATED` | 可解析 ∧ `finish=length` | **排除于能力判定**；单列完整性层（⛔ 既不记 SUCCESS 也不记 FAILURE） |
| `MEASUREMENT_FAILURE` | 不可解析 ∧（`finish=length` ∨ `content_filter`/`error`/缺省） | **UNDECIDABLE**（⛔ 永不记 FAILURE/SUCCESS） |
| `MODEL_NONCOMPLIANCE` | 空正文或不可解析 ∧ `finish=stop` | 计为**拒绝**（能力/合规失败） |
| **`UNCLASSIFIED_RESPONSE`** | 未知 `finish_reason` 等 | **UNDECIDABLE + 人工复核**（⛔ 不得静默映射） |

**聚合**：某能力仅由 `SCOREABLE` 尝试判定；全部被排除 ⟹ 该能力 **UNDECIDABLE**。
