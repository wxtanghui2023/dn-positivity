## Attack X1：Δ_H 正性是否覆盖整个零点谱？（不是有限 γ/数值观察）

**准备——独立 Lemma C'**：

> **Lemma C'**：对每个非平凡零点纵坐标 γ_ρ 和临界带内每个非零 δ_ρ（|δ_ρ| < ½）——Δ_H(γ_ρ,δ_ρ) > 0。

**证明结构**（完整闭式——非数值）：
1. Δ_H(γ,δ) = w_H(γ,δ) − w_H(γ,0)——精确恒等式（定义）
2. 闭式：w_H = (1/2)[a²(a+1)+|δ|γ²]/(a²+γ²)²——a = 1+|δ|
3. 分子 N(x) = (1/2)(a²(a+1)+xγ²)(1+γ²)² − (a²+γ²)²——x = |δ|——D = (a²+γ²)²(1+γ²)² > 0
4. N(0) = 0——∂N/∂x ≥ γ⁶/2+γ⁴+γ²/2−6γ²−13.5 > 0（γ ≥ 2）
5. N 严格增 ⟹ N(x) > 0（x ∈ (0,½)）⟹ Δ_H = N/D > 0
6. |γ_ρ| ≥ γ₁ = 14.1347 > 2——全部零点进入正性区
7. **覆盖整个零点谱**——每点逐项正——无有限 γ 截断——无数值依赖 ∎
