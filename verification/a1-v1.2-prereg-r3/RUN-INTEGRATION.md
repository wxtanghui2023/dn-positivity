# 如何独立复现集成测试

依赖已随包提供（`deps/`，7 模块）——**无需**作者树，**无需**网络，**零**模型调用。

```bash
unzip a1-v1.2-prereg-r2.zip -d /tmp/a1r2 && cd /tmp/a1r2
python3 l8_1_a12_integration.py          # 期望输出 ALL PASS: True
sha256sum -c SHA256SUMS.txt
```

期望检查项：I1 身份｜I2 四例端到端｜**I2c** 可解析+异常/未知终止（D-A 回归）｜I2b 全排除聚合｜
I3 与 r2 测试模块差分等价｜**I4 纯完整性 + 防重判**（D-⑤）｜I5 调用闸门｜**I6 聚合语义**（D-B）｜
**I7 合成空值规则**。

## r2b 复验（两次独立全新解压）
I4 现含**活体守卫自检**：round-1 阶段专用计数器（快照 `{0,0,0}`）+ **负控**（故意重判 ⟹ 检出 `{1,1,1}`）。
后续 I6 的评分调用计入**独立、明确标注**的计数器，不再混入 round-1 记录。

## r2c（第三轮修复）复验要点
- I4 的禁键检查现扫描**组装后的 I4 对象本体**（两次），并有**扫描正控**证明其确能检出注入键。
- 负控要求**四个评分入口全部**产生可检测增量，含此前遗漏的 `runner.SCORE_C1B`。

## r2d（第四轮修复）复验要点
- 必需依赖不可用时**整体验收必然失败**且**进程以非零码退出**；汇总**不允许**任何 `None` 被过滤。
- **I8 负控**在一次性副本中删除差分模块并子进程重跑，断言 `exit!=0 / all_pass=false / I3=false`。
