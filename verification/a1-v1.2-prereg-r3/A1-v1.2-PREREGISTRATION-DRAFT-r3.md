## §3 字段语义（r2，**固定**）

```text
true / false  ：已定义假设的判定值
null          ：该假设在当前实例的前置条件下【未定义】
字段缺失       ：输出不完整/格式违规 ⟹ 【不得】等同于 null
已定义字段     ：须【存在】且为【布尔】且【值正确】

⚠️ 关键区分：显式 null 只解决【输出歧义】，不解决【数学正确性】；
   判分器须**逐假设**实现定义条件与真值逻辑
```
