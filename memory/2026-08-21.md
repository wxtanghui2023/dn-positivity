### 发现（唐先生引导的循环论证审视）
**问题**：eq:lambda-D（λ_{n+1}−λ_n = 2D_n）只在零点于临界线（β=½）时成立，论文用它推 RH = 循环。

### 证据链
1. B-L 定理（Wikipedia 原文）：Re(ρ)=1/2 所有 ρ ⟺ λ_n≥0 所有 n（无条件）
   - λ_n = Σ_ρ[1−(1−1/ρ)^n] 含 β 的真实求和
   - B-L 定理**没有**"λ_{n+1}−λ_n = 2D_n（doc θ）"恒等式
2. 数值验证：λ差分 = 2D_n（doc θ）只在 β=½ 时成立（β=0.49 偏差 1e-4）
3. 论文 D_n 定义（proof-details.md 第15行）："ρ = ½+iγ" —— **假设 RH**
4. 论文第70行："Writing ρ=½+iγ" → ψ_γ = θ(γ)（只对 β=½）
5. 8 个文件全部声称 D_n > 0 ⟹ RH（paper-main.tex, proof-details.md, release/*, submission/*）

### 循环链
假设 β=½（RH）→ ψ_γ=θ(γ) → eq:lambda-D → D_n>0 → λ_n>0 → RH
= 重言式

### 诚实评估
- D_n > 0 的解析证明本身可能无条件成立（用零点虚部分布 + doc θ）
- 但 D_n > 0 不蕴含 RH（连接只在 β=½ 成立）
- 修复困难：真实相位 D_n 依赖未知 β
- 降级可行：论文改为"正性结果 + 望远镜恒等式 + 数值发现"（不声称证明 RH）
