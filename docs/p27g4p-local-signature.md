## ⭐ 核心结果——c₂ 精确展开

**Δ(u,ε) = c₂(u;δ,γ)ε² + O(ε³)——c₂(u;δ,γ) = [cosh(2δu) − 1]·(γ²[cosh(2δu) − 1] − δ²)**

## ⭐ 符号判别——γ-δ 定量竞争

| 条件 | c₂ 符号 | 含义 |
|---|---|---|
| γ²h₀ < δ²（u 小/γ 小） | **c₂ < 0** | **负方向——G4-A 恢复——2×2 就够** |
| γ²h₀ > δ²（u 大/γ 大） | c₂ > 0 | 局部 PSD（区域性——非全局） |
| γ²h₀ = δ² | c₂ = 0 | 临界——四阶判别 |

- **β 通道（δ²——双曲曲率）vs γ 通道（γ²h₀——相位曲率）——定量竞争**
