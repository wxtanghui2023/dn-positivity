# 第二部分：目标-L（下界：Σδ ≥ cM，c>1.34/1.52）—— 逐子项拆解

## L0 链路骨架（全部自推，不用文献）
- L-A 覆盖 ⟹ δ ≥ 0、Σδ = 11M − 1024 ✅ 已有（恒等式）
- L-B 双重计数 S = Σ_{x∈C_r} Σ_{z∈B₁(x)} δ(z) ✅ 已有
- L-C 上界 S ≤ μ|A|，μ ≤ (n+1)−(r+⌈d/2⌉) = 9 ✅ 已有（初等）
- L-D **下界 S ≥ ê|C_r|** ← 唯一缺口
- L-E |A| ≥ Σδ / max δ —— 待自推（此前漏项）
- L-F 合并 ⟹ Σδ ≥ cM

## L-D 的子项（每项：陈述／需求／方法／可行性）

- **L-D1 换序**：S = Σ_{z∈A} n_r(z)，n_r(z):=|C_r∩B₁(z)| ｜无难点 ✅
- **L-D2 逐点下界 n_r(z) ≥ ?**
  - 已知结构：z∈A、μ(z)=k≥2 ⟹ 其 k 个码字邻居 c₁..c_k 两两距离 2 ⟹ 对每对 {i,j}，点 e_{a_i}+e_{a_j} 距 C ≤1
  - 需求：由该结构导出 n_r(z)（或 |A∩B₁(x)|）的下界 —— **需要新的计数论证**
  - 可行性：**未知**（这是 16 年未被改进之处）
- **L-D3 把"覆盖要求"转成设计数下界**（不抄文献，自行推导）
  - 陈述：对 x∈C_r，A∩B₁(x) 的交数下界可由"每对 (z 的邻居)"的覆盖要求得出
  - 需求：自推"覆盖设计数"的**下界估计**（Schönheim 型自推：C(v,3,2) ≥ ⌈v/3·⌈(v−1)/2⌉⌉）
  - 方法：初等计数 + Schönheim 型递归（**可自推**）
  - 可行性：**中**（自推的下界估计可得，但强度未定）
  - 资产：我方已算的 D(v,3,2) = (1,1,2,4,7,8,12)（用于校准自推下界）
- **L-D4 更高阶（三元组）层**
  - 方法：同上，改用 C(v,4,3) 型下界
  - 可行性：中（自推可做，收益未知）
- **L-D5 整数性/取整**
  - 观察：c 的改进必落在取整处（van Wee 的 c=1 来自 ⌈11/2⌉−11/2 = ½）
  - 机制性失败：一切松弛型 c ≤ 1.268
  - 方法：**无**（需整数论证）
- **L-D6 局部构型枚举**
  - 机制性失败（naive）：Q_9 状态空间 2^256
  - 资产：小 n 缺陷递归（K(5,1)=7、K(6,1)≥12 自证）→ 已实测**不迁移**
- **L-D7 对称破坏 + 剪枝**
  - 需求：有效剪枝工具；现状：SDP 在 M=106 剪不动
