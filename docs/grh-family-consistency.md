# A6：族一致性正式陈述（GRH 判据对任意 L(s,χ)）

> 声明：对任意模 q、任意原字符 χ（模 q*），判别判据成立：
> $$Q_\chi = Q'_{\mathrm{RH},\chi} \iff \operatorname{Re}\rho = \tfrac12\ \forall \rho \text{（χ 的零点）}$$
> 论证：框架的每个对象不依赖 q/χ——判据逐 χ 独立成立——GRH = 全体之并。

---

## 1. 框架对象的不依赖性（逐项核对）

| 对象 | 定义 | 依赖 q/χ？ |
|------|------|-----------|
| 完成函数 ξ_χ(s) | L(s,χ) 的 Gamma 因子 + 函数方程 | 有（q,χ 进 Gamma 参数与根数）——但 Hadamard 结构通用 |
| S_χ = ∂²log\|ξ_χ(½+it)\| | Hadamard 展开 | 零点项 Σm_ρK^nat_ρ 通用——S_reg,χ 有（不进入 Q） |
| K^nat_ρ(t) | (δ²−x²)/(δ²+x²)² | **否**（通用形式） |
| H_0(t) | F⁻¹[ŵ_target/K̂₀] | **否**（纯 Fourier——与 ζ 版相同） |
| w_H(γ,δ) | [a²(a+1)+δγ²]/(2(a²+γ²)²) | **否**（代数恒等式——只依赖 K^nat + H_0） |
| P_γ(δ) | δ²M₂/(2U²D₊D₋) | **否**（代数——正系数） |
| Q_χ/Q'_{RH,χ} | 逐项定义（零点项） | 依赖零点集（γ_ρ,δ_ρ）——但定义机制通用 |

**关键**：w_H/P_γ 是**纯代数恒等式**（——从 K^nat 的 Fourier 与 H_0 推出——）
——不含任何 L 函数特定量（——无 χ(p)——无 q——无 Gamma——）——
因此**对任意 χ 的零点集逐项适用**。

## 2. 等号刚性的族一致性（A4）

- Q_χ − Q'_{RH,χ} = Σ_{轨道}m_ρP_{γ_ρ}(δ_ρ)（——通用——A3/A4 代数——）
- P_γ > 0 需 γ > 1/√5 ≈ 0.45（——5γ²−1>0——5U²−16U+16 判别式<0 恒正——）
- **非平凡零点 γ ≥ γ₁,χ**——第一个零点高度下界：
  - 数值：模 3: 8.04——模 4: 6.02（β——**最小已知**）——模 5: ~10.1——全部 > 6
  - 文献：L(s,χ) 的第一个非平凡零点 γ₁,χ ≥ 6.02（——最小为 β——标准）
  - ⟹ γ₁,χ > 0.45 自动成立——**P_γ > 0 对任意 χ 的零点成立**
- 等号刚性：Q_χ = Q'_{RH,χ} ⟹ Σm_ρP = 0 ⟹ 逐项 P = 0 ⟹ δ_ρ = 0（——正项和——）——通用

## 3. GRH = 全体之并

- 判据对**每个**原字符 χ 独立成立（A1-A4——不依赖 q——）
- GRH = 对**所有**模 q、**所有**原字符 χ 的判据之并：
  $$\mathrm{GRH} \iff Q_\chi = Q'_{\mathrm{RH},\chi}\ \forall q\ \forall \chi \bmod q$$
- **无"族交互"**（——每个 χ 的 L 函数独立——判据独立——）——
  GRH 的困难不在"交互"而在"每个判据的验证"（——A1-A5 的概念证明——）
