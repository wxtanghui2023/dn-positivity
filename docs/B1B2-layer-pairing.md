## §3 B2：从已有 ω 出发的自然配对（**不是人为新定义**）
**选择**：局部域中与辛形式同类的自然对象 = **Hilbert 符号**（等价地 cup product $H^1(G_{\mathbb Q_2},\mathbb Z/2)\times H^1(G_{\mathbb Q_2},\mathbb Z/2)\to H^2=\mathbb Z/2$）
**层可见的 Kummer 类**：
```
i=1 <-> [-1]（Q_2(i)）｜i=3 <-> [2]（Q_2(√2)）｜i=3 <-> [-2] = [-1]·[2]（Q_2(√−2)）
i=7 <-> 无类（中心层落在 H^1 之外）
⟹ 层空间 = span{[-1], [2]} ⊂ Q_2*/(Q_2*)^2，维数 2
```
**逐项核验**（$+1$ 用**显式范数**；$-1$ 用 mod 8 障碍）：
```
(2,-1) = +1   证据：2 = 1² + 1²        （2 是 Q_2(i) 的范数 ✓）
(2, 2) = +1   证据：2 = 2² − 2·1²      （2 是 Q_2(√2) 的范数 ✓）
(2,-2) = +1   证据：−2 = 0² − 2·1²     （−2 是 Q_2(√2) 的范数 ✓）
(−1,−1) = −1  证据：穷举 |x|,|y| ≤ 40 解 x²+y² ≡ −1 (mod 8) 得 0 个；
              且 mod 8：单位平方 ≡ 1，故 x²+y² ∈ {1,2,5} mod 8，而 −1 ≡ 7 mod 8 ⟹ 无 2-adic 解
              ⟹ −1 不是 Q_2(i) 的范数 ✓
```
**诱导配对矩阵（基 $\{[-1],[2]\}$，取值写入 $\mathbb F_2$，1 表示符号为 $-1$）**：
$$\begin{pmatrix}1&0\\0&0\end{pmatrix}\qquad\text{rank}\ =\ 1\ (\text{空间维数 2})$$
$$\boxed{\text{该配对在层空间上【退化】，radical} = \mathrm{span}\{[2]\}\ (\text{即 }\mathbb Q_2(\sqrt2)\ \text{的类})}$$
