# 独立 γ–β 耦合机制搜索——候选载体审计（2026-09-08 20:00）

> 唐先生新指示——搜索策略改变：
> 不是"构造对象→发现属旧框架→NO-GO"
> 而是先问：什么信息载体同时携带纵向 γ 和横向 β，但不以零点本身作为输入？

## 七硬筛选条件（候选进入计算前必须全过——）
1. β-sensitive：区分 ρ=½+δ+iγ 与 ρ^♯=½−δ+iγ
2. γ-uniform：γ→∞ 不把 β 信息压到不可见
3. 非显式公式读出：不是 Σ_ρ F(ρ) 的包装
4. 非 Li/Prony 型：不变 |1−1/ρ|=1 等价
5. 非谱实现：不要求 Hilbert-Pólya 对象
6. 非一般正性：不依赖全平正核
7. 独立刚性来源：存在其他数学结构的约束使 γ-structure + rigidity ⟹ β=½

## 核心问题的重新表述
"信息载体同时携带纵向 γ 和横向 β，但不以零点本身作为输入"
= 一个对象 O，其"自然变量"含复结构（σ 和 t——），
  O 的可计算量（不输入零点）在 σ 方向有 β 信息（横向——）
  且不因 t 大（γ 方向——）丢失

## 候选载体类别（系统盘点——）

### 类别 A：ζ 的"表面"结构（级数/欧拉积在收敛域——）
- ζ(s) = Σn^{-s}——只在 σ>1 收敛——零点在 σ≤1——够不到
- log ζ(s) = Σ p^{-ks}/k——σ>1——同上
- **A1：σ→1⁺ 的极限行为**（ζ 在 1 的极点展开——）
  ——系数含素数——不含零点显式——但素数与零点经显式公式连（循环——？）
- 状态：算术断裂（8/26——）——收敛域够不到零点区

### 类别 B：ζ 的"临界"量（在 σ=½ 或 σ=1 的——）
- B1：ζ(½+it) 的模——含 β（log|ζ| 实部——）但经 Hadamard（sum over ρ——）
- B2：|ζ(σ+it)| 的 σ 方向行为（横向扫描——）——β 墙（8/24——）
- B3：ζ(1+it)（σ=1 边界——）——已知界（ζ(1+it)=O(log t)——）——含零点？
- 状态：显式公式读出（条件 3 失败——）或 β 墙

### 类别 C：素数侧复结构（不含 ζ 显式——）
- C1：素 zeta P(s)=Σ_p p^{-s}——奇点在 ρ/k（零点编码——）
- C2：素数向量 v_p(s)=p^{-s} 的构型（σ 控大小——t 控方向——）
  ——Σ_p v_p 的平衡（素 zeta——）还是零点
- C3：素数的"复相位场"（θ(p)=t log p 的——）
- 状态：历史尝试（AXD/ACPC/ASC/affine——）全死——或零点编码

### 类别 D：独立复结构（非 ζ——）
- D1：模形式/自守 L——它们有自己的"零点"（自己的 RH——）
- D2：代数几何（Frobenius——）——char 0 无
- D3：Γ 函数/archimedean——FE 给对称不给位置
- 状态：全审计过——无独立刚性来源给 ζ 的 β

## 关键诊断（历史全失败的模式——）
1. "含 σ 和 t"的对象（ζ 表面——）→ 零点信息在延拓里（算术断裂——）
2. "含 β"的对象（|ζ|——Hadamard——）→ sum over ρ（显式公式——）
3. "独立"的对象（算术/几何——）→ 不连 ζ 的零点（无桥——）
4. 物理/谱/正性 → 不给横向位置（γ 层或循环——）

## 真正的问题（比候选更根本——）
**为什么"σ=½"需要出现？**——任何自然载体若含 σ 结构——
它的"特殊 σ"来自哪？
- FE 给 ½（对称线——）但只给对称不成对
- 算术临界（ζ(2σ)——Σp^{-2σ}——）给 ½（统计——）非逐点
- 函数域给 √q（Frobenius 模——）char 0 无对应
**独立的"½ 来源" + "与零点的强制连接"——两者都缺**
