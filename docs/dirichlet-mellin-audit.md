# Dirichlet → Mellin → FE 链审计：信息在哪里被 quotient 掉？（2026-09-02 23:25）

## 层 1：Dirichlet 卷积代数 D
D = {f: N → C}（卷积乘法）——**D ≅ C[[x_p]]（无穷多素变量的形式幂级数环）**——已知（f(n) ↔ 素因子编码的系数——n = Πp^a ↔ x^a）。
- D 编码 factorization（卷积 = 因子求和）✓
- **D 是纯乘法代数（不含 n 的加法序/大小）**

## 层 2：ζ 在 D 中的位置
f ≡ 1（常函数）↔ Ω = Π_p (1−x_p)^{−1} ∈ D
**ζ(s) = χ_s(Ω)**——其中 χ_s 是 D 的 character（x_p ↦ p^{−s}）
- ζ 是"固定代数元素 Ω 沿一维 character 族 {χ_s: s ∈ C} 的取值"
- **ζ 零点 = χ_s(Ω) = 0 的 s**

## 层 3：Mellin 压掉什么？
- Mellin（f → Σf(n)n^{−s}）对 f 是**单射**（无损——Perron 恢复）
- 但——Mellin 只用 Spec(D) 的**一维族**（χ_s）——Spec(D) = 所有 character（x_p ↦ 任意 a_p——多维）——**压掉多维**
- Mellin 引入"n 的大小"（n^{−s}——加法的）——D 本身无加法结构——**加法（大小）是 Mellin 层引入的**

## 层 4：FE 的代数根源
s → 1−s ↔ x_p → p^{−1}/x_p（反演 + 缩放）
- **反演（1/x_p——负幂）不在 D = C[[x_p]]（形式幂级数——非负幂）——需 Laurent 扩张**
- FE 的"1"（s → 1−s 的反射中心 ½）——需要"1"（尺度——）——在 D 中无对应（纯形式——无尺度）
- FE 完整形式（ξ——Gamma——Archimedean）在代数层无对应（Γ 不在 C[[x_p]]）
