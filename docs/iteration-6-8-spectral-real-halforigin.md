# 迭代推导第 6-8 轮：谱实机制普查 + "½"的来源（2026-09-02 21:15）

## 第 6 轮：谱实有没有非自伴机制？——普查
已知"谱实"实例普查：自伴算子（C*）、正交多项式（Jacobi 三对角——正测度——自伴）、随机矩阵（厄米）、量子化（自伴）、PT 对称（伪自伴——需额外条件）。
**结论：谱实 ⟹ 自伴（类）——没有非自伴的谱实机制**。
**⟹ 如果零点要"在线"（谱实现）——必须自伴——HP 循环本质**（不是"没找到自伴证明"——是"谱实本身要求自伴——而自伴是 RH 等价"）——**除非零点不是"谱"（特征值）——是别的参数**。

## 第 7 轮：函数域的"在线"其实是代数 norm 约束（不是谱实）
函数域零点（Frobenius 特征值 α）——|α| = q^{w/2}——**不是"谱实"（α 在圆上——非实轴）——是"代数大小约束"**（α 代数整数 + 共轭积 norm 整数）。
char 0 对应：ρ 在线（Re = ½）——若 ρ = log α 类（α = q^ρ）——|α| = q^{Re ρ}——需 ρ 的代数 norm——**但 ρ 超越——无**。
**"½"的一个来源线索**：θ 的模权重 ½ = 格点维数 d/2（d=1）——Re ρ = ½ 的"½"可能来自 theta/格点结构——但 Eisenstein 反例（E₈ theta 的 L 零点在 Re=½ 和 3.5——非 d/2=4）——不清晰。

## 第 8 轮："½"的更可能来源 = L² 临界指数
"½"在算术中的出现：FE 轴（平凡）、theta 模权重（格点——Eisenstein 反例）、Γ(s/2)（尺度）、**L² 临界**（ψ−x 的 RH 余项 O(x^{½+ε})——x^{½} = L² 临界增长）。
**候选**：½ = "误差的 L² 临界"——ψ−x 的"自然尺度"——但——无条件上界（零自由区域——xe^{−c√logx}）允许更大误差（x^{0.6}）——无原理强制 L² 临界——死（重复墙）。
