## 五、唯一剩下的问题（明确 ✓）

```
**证明**：`|Osc(n)| < N(T₀) − n·B_{T₀}` 对 **所有 n ≲ 2T₀²** 成立 ✓

【候选手段 ✓】
· **两区制论证** ✓：共振区（余量巨大 ⟹ 只需粗界 ✓）+ 平均区（需精细相消 ✓）
· **算术化** ✓：`Osc(n) = Re Σ_ρ(1−1/ρ)^n = Re Σ_{j=1}^n C(n,j)(−1)^j Z_j` ✓✓ ——
  其中 `Z_j = Σ_ρρ^{−j}` **由 Stieltjes 常数显式给出** ✓
  ⟹ **振荡被【精确地】化归为算术量** ✓✓（**不再有"振荡"要界** ✓）
  ⟹ 定量问题变成**二项式变换的误差控制** ✓（Voros 用鞍点法给渐近 ✓；我们要**定量** ✓）
· **van der Corput 二阶导估计** ✓：相位 `φ(T) = 2n·arctan(1/(2T))` ✓，`φ'' = 32nT/(4T²+1)² ≠ 0` ✓
【数值支持 ✓】n = T₀² 处实测偏差 **1.09×10⁻⁴** ✓；余量 **1.69 > 1** ✓✓
```
