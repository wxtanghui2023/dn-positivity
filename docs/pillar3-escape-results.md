## 测试结果

### 逃逸口 1：放大器（γA_ρ——）
- 显式公式 Σx^ρ/ρ 的 1/ρ 是**结构性的**（对数导数展开——）
- 去掉 1/ρ = 改显式公式 = 改 ζ（循环——）
- 对所有零点放大（Σγ·x^ρ/ρ——）：发散/由密度控制——无法 zero-blind 选单 γ
- **初步：zero-blind 放大器不可构造**（需知道 γ——）

### 逃逸口 2：非局部泛函（sup/limsup/积分——）
- sup_x |ψ−x|/x^{1/2}：特征 x 处贡献 ~ x^δ/γ——仍 ~1/γ（γ=14: 0.194 → 1000: 0.0027——）
- ∫W(x)(ψ−x)dx：W 宽谱（x^{−1/2}——）贡献仍 ~1/γ
- **原因**：W 无法匹配未知 β（x^β 的指数——）——宽谱核给 x^{β−1/2} 加权——特征 x 处 e·(1/γ)——衰减
- **初步：非局部泛函仍衰减**（除非核精确匹配 β——读出——）

### 逃逸口 3：集体效应（Σ 零点——）
- 有限/稀疏离轴：Σx^β_j/γ_j——每项 ~1/γ_j——衰减
- 正密度离轴：密度定理（Ingham——）限制（弱 RH 类——）
- **初步：集体累积需要离轴密度——稀疏有限衰减**
