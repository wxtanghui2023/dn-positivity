# ASC（加法-乘法尺度曲率）D_k 符号测试：系统性反例（2026-09-03 11:15）

## 对象
D_k(q,n) = det(A(q^{i+j}n))_{0≤i,j≤k}——A(n)=Σ_{a+b=n}Λ(a)Λ(b)（FFT——X=2-3×10⁵）
D1 = A(n)A(q²n)−A(qn)²（2×2 Hankel）——D2 = 3×3 Hankel

## 数值（X=200000）
**D1**（q≤√X=447——107,960 样本）：
- 正 24.8%——**负 75.2%——系统性反例**
- 负例：q=2 n=4: D1=−7.43（A(4)A(16)−A(8)² = 0.48×18.11−4.02²）

**D2**（3×3——q≤X^{1/4}=21——15,969 样本）：
- 正 32.3%——**负 67.7%——也系统性反例**

q=3,5,7 类似（~74-90% 负——全层稳定）

## 判断：ASC 第一关死（系统性反例）
- **D_k(q,n) ≥ 0 不成立**——从素数算术推不出 Hankel 正定
- **结构观察**：A 沿乘法尺度（n→qn→q²n）**log-凹（平均——）**（A(qn)² > A(n)A(q²n) 经常——）——非 log-凸——**moment 表示（正测度——D_k≥0——）不存在**
- 深层负结果：**加性卷积 A(n) 不是乘法尺度的矩序列**（q 缩放下无 Hankel 正定）
- 按唐先生判死（第一阶系统性反例——封 ASC）——**ASC 死**
