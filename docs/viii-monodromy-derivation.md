## 对象
P(s) = Σ_p p^{−s}（prime zeta——prime-only 离散对象——）
= Σ_{k≥1} μ(k)/k · log ζ(ks)（Möbius 反演——Re s > 1——）

## 推导 1：P 的奇点结构（精确——）
log ζ(ks) 在 ks = ρ（ζ 零点——）有对数支点
⟹ P 的奇点 = **{ρ/k: ζ(ρ)=0, k≥1} ∪ {1}**（缩放奇点轨道——）
- 每个零点 ρ 生成轨道 {ρ/k: k≥1}——实部 β/k——虚部 γ/k
- 缩放不改变角度：arg(ρ/k) = arg(ρ)

## 推导 2：monodromy 跳跃（精确——）
绕简单零点 ρ/k 一圈：log ζ(ks) 增加 2πi
⟹ P 的局部 monodromy = 乘以 exp(2πi·μ(k)/k)
- 跳跃系数 = μ(k)/k·2πi（k=1: +6.28i——k=2: −3.14i——k=4: 0（μ=0——）——）
- **系数完全由 k 决定（Möbius——）——与零点位置无关**

## 推导 3：碰撞分析（缩放轨道——）
ρ_i/k = ρ_j/ℓ ⟺ kρ_i = ℓρ_j
- **on-line（β=½ 全部——）**：实部 ½/k = ½/ℓ ⟹ k=ℓ——虚部 γ_i = γ_j ⟹ i=j——**零碰撞**（除平凡——）
- **off-line 单零点（δ≠0——其他 ½——）**：(½+δ)/k = ½/ℓ ⟹ ℓ+2ℓδ = k——δ 无理——无解——**也不碰撞**
- 碰撞依赖 β 的【比值】——不区分 β=½ vs β≠½

## 推导 4：延拓唯一性（关键——）
P 从素数级数（Re>1——系数 0/1——）**唯一解析延拓**——接受任何零点配置
- 奇点位置（on/off——）不影响"能否延拓"（奇点外解析——）
- monodromy 群代数结构 = Z^{∞} 类——on/off 相同（只位置标记不同——）
- 自然边界 Re=0——无条件（Hadamard β>0——）——不依赖 β=½

## 可证局部定理（诚实——真但平凡——）
**定理（P 的奇点刻画）**：P(s) 的奇点集 = {ρ/k: ζ(ρ)=0, k≥1} ∪ {1}——绕简单零点 ρ/k 的 monodromy = exp(2πi·μ(k)/k)
- 证明：Möbius 反演 + log 支点分析（直接——）
- **但这个定理不约束零点**——只是刻画 P 的解析结构（由零点决定——）
