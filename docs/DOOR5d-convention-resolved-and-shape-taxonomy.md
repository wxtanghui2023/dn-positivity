## §1 ⭐⭐ **张力解开**（用单调性 + DFMR 的圆盘公式判定方向）
```
【事实 A（Báez-Duarte (1.2)）】‖F − χ‖_H ≥ C/√(log N)，N = max a_k ⟹ **d_N ≥ C/√(log N)**（**递减** ✓）
【事实 B（Darses–Hillion 转述）】猜想 "d_n² ~ C log n"，C = 2+γ_E−log(4π) ≈ 0.0462 ✓
【单调性】d_n 是 χ 到【递增】子空间 H_n 的距离 ⟹ **d_n 非增** ✓✓
⟹ 事实 B 若字面成立（d_n² 递增 ⟹ d_n 递增）**与单调性矛盾** ✗
⟹ **判定：B 的【字面形式】不可成立**；正确形式必为 **d_n² ≍ C / log n**（**递减** ✓✓）
   （C ≈ 0.0462 是【小】常数，正符合 d_n² 递减 ✓；n = 10⁶ 时 d² ≈ 0.0462/13.8 ≈ 3.3e−3 ⟹ d ≈ 0.058 ✓ 合理）
【一致性核对】A 的 d_N ≥ C'/√(log N) 是 **B 的弱形式** ✓（因 C'/√(log N) ≪ √(C/log n) 对同量级常数 ✓）
   ⟹ **A 与 B 相容** ✓✓ ⟹ "张力"实为我上一轮对抽取短语的**误读** ⚠️
```

## §2 ⭐⭐⭐ **门的形状被定出来**（NB 的配对不是 T²，是**对数型**）
```
【DFMR 圆盘】半径项 √(1 − 2(Re λ − σ₀)d²) ⟹ 余量 **margin ~ d²** ✓
【d² ≍ C/log n】⟹ **margin ~ C/log n**
【经典无零点区域】margin ~ c/log T（de la Vallée Poussin ✓）
⟹ **log n ~ (C/c)·log T**  ⟹  **n ↔ T（对数—线性配对）** ✓✓
```
$$\boxed{\text{NB 的配对：}\ \log N \sim \log T\quad\text{（远弱于 }T^2\text{）}}$$
