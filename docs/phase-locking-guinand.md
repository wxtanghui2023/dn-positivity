## 3. 机制：Guinand 显式公式（Guinand 1947, Proc. LMS 50, 107-119）

**Guinand 公式**（MathOverflow 82635——假设 RH 版本）：
```
½(N(T+0)+N(T−0)) = T/2π·log(T/2π) − T/2π
  − (1/π)lim_{N→∞}[Σ_{n≤N}Λ(n)sin(T log n)/(√n log n)
  − ∫_1^N sin(T log t)/(√t log t)dt − sin(T log N)/log N·(Σ_{n≤N}Λ(n)/√n − 2√N)]
```

**对测试函数 sin(T·log p)·1_{T≤X} 积分**（零点脉冲 = N' 的分布）：
```
Σ_{γ_k≤X} sin(γ_k log p) = (1/2π)∫_2^X sin(Tx)log(T/2π)dT   [主项——O(log X/x)]
                          + (1/π)Σ_n Λ(n)/√n·∫_2^X sin(Tx)cos(T log n)dT   [素数项]
                          + 边界项
```

**关键积分**：∫_2^X sin(Tx)cos(T log n)dT = ½∫[sin(T(x+log n)) + sin(T(x−log n))]dT
- **x ≠ log n**：O(1/|x−log n|)——有界（不随 X）
- **x = log n（精确共振）**：½∫sin(2Tx)dT = O(1/x)——**有界**（sin(0) = 0 消失！）

**相位锁定机制**：x = log p 时——n = p 项精确共振但 sin(T·0) = 0 → O(1/x)；n ≠ p 项不共振 → O(1/|x−log n|) → **素数项 = O_p(1)**！
**x ≠ log p 时**——n ≈ e^x 的素数（如 47）|x−log n| 小 → 素数项 ~ √n·log n/|x−log n| → **爆炸**（x = 3.85 vs log 47 = 3.8501：1/0.0001 ~ 10000 量级——解释 max 1214-33147）。

**数值验证**（guinand_decomp.py——X = 1.13e6）：
- 主项 (1/2π)∫ = O(1)（±1.8）✓
- 素数项 (1/π)Σ = O(1)（±7）✓（截断 nmax=1e5——未完全收敛——数量级正确）
- Σsin = O(1)（±1.6）✓

## 4. 诚实评估：Σsin = O(1) 是"真 O(1)"还是"O_p(log X)"？

**无条件界**：主项 = −log(X/2π)cos(Xx)/(2πx) + O(1/x)——**O(log X/x)**——对固定 p 慢增长。
- x = log 2 = 0.69：log(1.13e6)·(1/(2π·0.69)) ≈ 14·0.23 ≈ 3.2——数值 max 3.3 ✓ 一致
- **数值上"看似 O(1)"是因为 log X 到 1e6 只有 14**——严格说是 O_p(log X)

**RH 连接（关键）**：Weil 显式公式（无条件版本——零点全复平面）中：
- h(t) = sin(t log p) 的全纯延拓 h(s) = sin(s log p)
- 在 ρ = β+iγ：|sin((β+iγ)log p)| ~ cosh(γ log p) ~ p^γ/2——**指数增长**
- **离轴零点（β≠½）贡献 e^{(β−½)γ log p} 类因子**——与正则化竞争
- **Σsin = O(1)（真 O(1）⟺ 零点在临界线（RH 深度）**——不是无条件可证

**结论**：Σ_k sin(γ_k log p) = O_p(log X) 无条件可证（Guinand——主项）；真 O(1) = RH 等价。

## 5. 对 r(n) = O(1) 的意义

- 8/23 交接把 Σsin(γ log p) = O(1) 作为相位均匀性的目标——**现在明确了**：
  - 它**不是**零点统计均匀性——是**算术恒等式**（Guinand——素数离散性）
  - 它**不直接给 r(n) = O(1)**（r(n) 的振荡是 Σε = −∫S·f̃'——S 的积分——不同对象）
  - 但机制链确认：Σε ≈ −(1/π)Σ_k S(γ_k)·(权重)——S = N−N₀——**S 的振荡控制仍是核心**
- **新认知**：Σsin(γ log p) = O_p(log X)（无条件——Guinand）是有价值的**独立小定理**（比随机游走 √X 强 100 倍）——可作为 r(n) 路径的一个组件（每素数项有界——但需加权求和收敛——仍需振荡控制）

## 7. 补充发现（17:10——逐项贡献 + 顺序 A/B 区别）

### max|Σsin(γ_k log p)| ~ c·√p（数值）

| p | max\|Σsin\| | max/√p |
|---|---|---|
| 2 | 3.30 | 2.33 |
| 47 | 6.03 | 0.88 |
| 283 | 28.1 | 1.67 |
| 1229 | 58.0 | 1.65 |
| 4241 | 123.9 | 1.90 |

**max|Σsin| ~ c·√p（c ~ 1-2）**——部分和的瞬时最大值随 p 增长（中间偏移），但**最终值**（K=2e6）通常 O(1)（相位锁定）或 O(√p)（p=283: −14）。

### 顺序 A vs 顺序 B（关键区别）

- **顺序 A**（全矩阵交换）：Σ_p A_p·Σ_k sin(γ_k log p) = **+1.35**（数值收敛——p≤100 就饱和）
- **顺序 B**（Titchmarsh 截断 p≤γ_k）：Σ_k Σ_{p≤γ_k} A_p sin(γ_k log p) ≈ −π·Σ_k S(γ_k) ≈ **−πK/2（巨大）**

**顺序 A ≠ 顺序 B**——A 包含 p > γ_k 的"非法"项（Titchmarsh 截断外）——这些项与 p ≤ γ_k 项大量抵消 → A 收敛。
**所以 +1.35 与 Σε = O(1) 的"同量级"是巧合**（都 O(1)）——不是因果连接。r(n) 的 Σε = −∫S·f̃'dφ（S 的积分）——与 Σ_k S(γ_k) 不同对象。

### 诚实结论（补充）

1. Σ_k sin(γ_k log p) 最终值 O_p(1)（相位锁定——Guinand——x=log p 精确）——**无条件界 O_p(log X)**
2. max|Σsin| ~ √p（数值——中间偏移）——Guinand 主项 O(log X/x) 不能解释——需更细分析
3. Σ_p A_p·Σ_k sin = O(1)（数值——顺序 A——全矩阵抵消）——**无直接 r(n) 连接**
4. 真 O(1)（对固定 p 一致于 K）= RH 深度（Weil 公式离轴指数因子）
