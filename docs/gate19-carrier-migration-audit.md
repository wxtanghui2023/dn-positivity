## 3. 缺口被精确定位（本轮核心结论）

$$\boxed{\text{锁管的是【离散谱】（自伴 ⟹ 真实 ⟹ RH 自动）；}\\
\text{而 ζ 的零点 = 散射行列式 }\varphi(s)\text{ 的零点/极点 ⟹ 【散射/共振侧】，}\\
\text{自伴性在那里【不给任何夹逼】}}$$

即：
```
离散部分（cuspidal spectrum） : 自伴 Laplacian ⟹ 谱真实 ⟹ 无条件 RH 型 ✓
连续/散射部分（ζ 所在）      : φ(s)=ξ(2s−1)/ξ(2s)，ζ 的零点在此
                               ⟹ 无自伴、无正性夹逼 ⟹ 锁【失效处】
```
这与本项目早先的 Connes 审计结论**独立一致**：零点以**吸收谱**出现，而非 Laplacian 谱 ✓
