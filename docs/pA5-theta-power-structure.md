# A5：θ(x)^w 的算术结构审计（2026-09-10）

## 结果一句话
θ^w 的系数有 **Euler product ⟺ w ∈ {1,2,4,8}**；一般 w（含所有非整数 w）**没有** Euler product。
特殊参数集 {0,1,2,4,8} 由此被**推导出来**（不再依赖经验观察）。

## 1. 系数公式（已验证）
θ(x) = 1 + u，u = 2Σ_{n≥1}e^{−πn²x}，(1+u)^w = Σ_k C(w,k)u^k

$$a_m(w)=\sum_{k=1}^{m}\binom{w}{k}2^kR_k(m),\qquad
R_k(m)=\#\{(n_1..n_k)\in\mathbb{Z}_{>0}^k:\textstyle\sum n_i^2=m\}$$

数值验证：Σ_{m≤60}a_m(w)e^{−πmx} = θ(x)^w − 1，差 ~1e−16
（w = 0.01, 0.5, 1, 2, 4；x = 1, 1.5）✓

⟹ **"无限阶 theta 卷积"**（唐先生预判正确）：非整数 w 时 k 求和无穷展开，
   不是有限个 ζ 因子。

## 2. 归一化乘法性（Euler product 判据）
b_m := a_m/a_1，a_1 = 2w。检验 b_{mn} = b_m b_n（互素，mn ≤ 60，99 组）：

| w | 失败数 | 结论 |
|---|---|---|
| 1, 2, 4, 8 | 0/99 | **Euler product ✓** |
| 0.01, 0.5, 0.75 | 40/99 | 无 |
| 3, 5, 6, 7, 10, 12 | 21–40/99 | 无 |

## 3. 结构性解释（为什么恰好是 1,2,4,8）
- θ^w 是权 w/2、level 4 的模形式；Γ_0(4) 上 S_{w/2} 无尖点形式的那些 w
  ⟹ θ^w 是 Eisenstein 级数 ⟹ 系数为 divisor 和 ⟹ 乘法 ⟹ Euler product
- w ∈ {1,2,4,8} 正是这个 Eisenstein 区间（w=1: ζ(2s)；w=2: ζ(s)L(s,χ_4)；
  w=4: ζ(s)ζ(s−1)；w=8: ζ(s)ζ(s−3)）
- w=6 已失败（21/99）⟹ 区间上界确实是 8
- **w=0**：不是 Euler product，而是**精确平方**（Jacobi product 边界）

## 4. 三个正性机制的参数集是【不相交】的 ⭐
```
w < 0        : Bochner / 正定概率测度     （Lagarias–Rains 已证）
w = 0        : 精确平方，处处正            （Jacobi product 极限）
w ∈{1,2,4,8} : Euler product（算术结构）   （Eisenstein/格点）
一般 w > 0   : 【两者皆无】——既无 Euler product，也无已知正性
w = 1        : ζ 本身（RH）；线上零点无穷多（即经典 γ_n）
```
**⟹ w-形变【不传输】正性**：w<0 的正性不是 w=1 结构的延拓，
   "anti-RH 区间"与"RH 点"之间没有连通的机制通道。
   这一条直接削弱 C6-C′ 的"延拓/对接"设想。

## 5. 对精度墙的最终判决
- "找 Ξ_w 的显式乘积公式以剥离 Γ"——**对一般 w 已死**（无 Euler product）
- **但 AFE（近似函数方程 / Riemann–Siegel 型）路线【不依赖】Euler product**：
  只需 ① 系数 a_m(w)（✓ 已验证可算）② 函数方程（✓ 双变量 zeta 的 FE）
  ③ 显式 Γ 因子
  ⟹ 仍可把 O(e^{−πt/4}) 精度墙换成 O(√t) 项的计算
