## §1 定理层级（**逐字**✓✓，arXiv:2412.17199）

- **Theorem 1.2**（Assume GRH）：存在**可有效计算**的 N_0，使若 N ≥ N_0 为偶数，则可找到 `1 <= a,b < N` 满足 `a+b=N` 且 `lambda(a)=lambda(b)=-1` ✓
- **Theorem 1.3**（Assume GRH）：设 N 为正整数，则存在**可有效计算**的 `p_0 >= 2`，使下列二者之一成立 ✓：
  (1) N 是 `p_0`-**friable**（y-smooth：全部素因子 ≤ y ✓）；
  (2) 对每个 `(eta_1,eta_2) in {-1,+1}^2`，存在 `1 <= a < N` 使 `(lambda(a), lambda(N-a)) = (eta_1,eta_2)` ✓
  —— 并且：**情形 (2) 对所有充分大的 squarefree N 成立** ✓
- **Proposition 1.4**（Assume GRH）：存在 C > 0，使对**任意素数 N**：
  `|L_lambda(N)| <= N - N e^{-C (log log N)^6}` ✓，其中 `L_lambda(N) := sum_{n<N} lambda(n) lambda(N-n)` ✓
- **对照**：此前（IMRN 2024）的结果是 `|L_lambda(N)| < N - 1` ✓ ⟹ 本论文的增量是**把间隙定量化**为 `N e^{-C(log log N)^6}` ✓

## §2 依赖链（**四级**✓✓，§6.1 逐字）

- **第 1 级（目标归约）**：要证 Theorem 1.3 的 (2)，只需证**素数 N** 时的**定量 sign-pattern 下界** ✓
- **第 2 级（反证设置）**：设 `|L_lambda(N)| > N - N e^{-C(log log N)^6}` 对无穷多 N 成立 ⟹ 存在 `eta in {-1,+1}` 使
  `|E(N)| := |{n<N : lambda(n) = eta lambda(N-n)}| = (1/2)(N-1+eta L_lambda(N)) < N e^{-C(log log N)^6}` ✓
  —— 即**某个符号模式变得极稀有** ✓
- **第 3 级（关键参数）**：取 `q := (C/10)(log log N)^6`，`P := e^{(1/40) q^{1/5}}` ✓
  ⟹ 当 N 充分大时 `P >= (log N)^{100}` ✓，且实际量级 `P = exp(c (log log N)^{6/5})` ✓✓
  —— 随后对 `P/2 < p <= P` 的素数使用 **Proposition 2.1** ✓
- **第 4 级（GRH 进入点）**：**Prop 2.1 型素数平均估计**由 **Lemma 3.3** 支撑；而 Lemma 3.3 假设
  `prod_{chi mod N, chi != chi_0} L(s,chi)` 在 `{alpha < Re(s) <= 1, |Im(s)| <= (log N)^3}` 内**无零点** ✓✓
  ⟹ **这就是 GRH 的落点：为「短素数区间上的特征和」提供一致抵消** ✓✓
