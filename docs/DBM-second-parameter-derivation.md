## §1 推导一：**Gaussian 核是被迫的** ⟹ 第二参数必须来自【流之外】
```
设变形族 H_{t,K}(x)=∫ K(t,u) Φ(u) e^{iux} du。要求该族为"正性半群型"正则化：
 (i) t=0 时为恒等；(ii) t>0 时抹平（零点向实轴靠拢）；(iii) 半群性 H_{s+t}=H_s∘H_t
 (iv) 对实系数/finite-order 性质保持
⟹ 满足这些的最简且 canonical 解 = 热半群，核 e^{t u²}（Gaussian）✓
⟹ 其他指数 e^{t|u|^α}（α≠2）要么破坏半群的有限性/正性，要么不满足 (ii) 的定向 ✗
```
$$\boxed{\text{DBM 流在"解析侧"没有第二个参数：Gaussian 是 canonical 的、实质唯一的}}\Longrightarrow\ \text{第二参数必须来自【算术侧】}$$
**顺带排除**：把 $t$ 取复、或加一次项 $e^{cu}$，都只是平移/重标定 ⟹ 不产生新自由度 ✗

```
此前我把"大 conductor/族"一律归入 β-盲 ⟹ 不准确：

⟹ 族轴不是立刻判死；它失败在【一致性/转移】上，而非在保留个体信息上 ✗
```
$$\boxed{\text{族轴的失败模式 = 缺少【uniform-in-}q\text{ 的转移】，而不是 β-盲（更正我上轮的说法）}}$$
