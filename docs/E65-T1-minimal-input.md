## 1. 算术（✓ 可复核 ✓）

```
【判据 ✓】Markov：#{n : |S_n| > t} ≤ |I|·M_{2k}/t^{2k} ✓
   ⟹ **零例外** ⟺ t > (|I|·M_{2k})^{1/(2k)} ✓；取 M_{2k} = C_k N^k（C_k = (2k−1)!! ✓ 高斯 ✓）
   ⟹ 保证 **|S_n| ≤ c_k·N** ✓，其中 c_k = (C_k·|I|/N^k)^{1/(2k)} ✓
【尺度 ✓（1e5 表 ✓）】N = 1e5 ✓，T = 74920.8 ✓，X = T² = 5.613e9 ✓，|I| = X/2 = 2.807e9 ✓
   ⟹ c₁ = 167.5 ✗｜c₂ = 0.958 ✗｜c₃ = **0.1865** ✓｜c₄ = 0.0858 ✓
【所需 ✓】A1 需要 **(1−c)N 且 c ≥ 0.2** ✓ ⟹ 即 |S_n| ≤ **0.8N** ✓
   ⟹ **k = 3 首次满足** ✓（0.1865 < 0.8 ✓）；k = 2 差一点 ✗（0.958 / 真实尺度 0.832 ✓ 均 > 0.8 ✗）
```
