## §1 **证明骨架（四条引理，全初等 ✓）**

**设定**：k ≥ 2 整数，1 ≤ τ < 2，H > e，r_H := r_H(τ) = (1+τ/H²)^{1/2}，x_ρ := 1 + τ/γ_ρ²。

> **引理 1（非负性/平方形式）**：`x^{k/2} + x^{−k/2} − 2 = (x^{k/4} − x^{−k/4})² ≥ 0` ✓
> —— **恒等式**，逐项可验 ✓（**这就是"不展开"的关键** ✓）

> **引理 2（单调性）**：`F(x) := x^{k/2} + x^{−k/2} − 2` 在 **x > 1** 上严格递增 ✓
> **证明**：F′(x) = (k/2)(x^{k/2−1} − x^{−k/2−1}) > 0 ⟺ x^k > 1 ⟺ x > 1（k > 0）✓
> ⭐ 注：**Brown 错误 1 正是把此断言写成"对一切 x>0"** ✗；而**我们的求和只在 x>1 上** ✓
> —— 与 Droll 的判断一致（该错误在经典情形**无关紧要** ✓✓）

> **引理 3（逐项界）**：`F(1+u) ≤ (k²/4)·r_H^{k−1}·u²`（0 ≤ u ≤ τ/H²）✓
> **证明**：令 y := (1+u)^{1/4} > 1。则 `F = (y^k − y^{−k})²`，
> `y^k − y^{−k} = (y − y^{−1})·(y^{k−1} + y^{k−3} + … + y^{−(k−1)}) ≤ (y − y^{−1})·k·y^{k−1}` ✓
> 且 `y − y^{−1} = ((1+u)^{1/2} − 1)/(1+u)^{1/4} ≤ u/2`（u ≥ 0 时；等价于 √(1+u) − 1 ≤ (u/2)(1+u)^{1/4} ✓ 逐项可验 ✓）
> ⟹ `F ≤ k²y^{2(k−1)}u²/4 = (k²/4)(1+u)^{(k−1)/2}u² ≤ (k²/4)r_H^{k−1}u²` ✓（u ≤ τ/H² ✓）

> **引理 4（求和界）**：取 u = τ/γ_ρ²（|γ_ρ| > H ✓）得
> **LHS ≤ (k² r_H^{k−1} τ²/4) · S₄(H)**，其中 **S₄(H) := Σ_{|γ_ρ|>H} γ_ρ^{−4}** ✓
> S₄(H) 由 t > H 上零点计数 N(t) 的**显式界**给出 ✓（**这一步正是常数 a,b,c,d 进入之处** ✓）
