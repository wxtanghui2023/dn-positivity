## §2 ζ 世界里已知的**两条精确恒等式**及其失败方式
| 恒等式 | exact? | canonical? | 无自由常数? | 失败点 |
|---|---|---|---|---|
| **函数方程** $\Lambda(s)=\varepsilon\Lambda(1-s)$ | ✓ | ✓ | ✓ | **只对称**：把 $\sigma\leftrightarrow1-\sigma$ 对应起来，**不搬运信息**（不改变到临界线的距离）✗ |
| **显式公式** $\sum_\rho h(\rho)=\text{素数侧}$ | ✓ | ✓ | ✓ | **循环**：两侧在临界深度内**都不可证**（零点侧只是【可算】而非【可证】）✗ |
$$\boxed{\text{函数方程 = 精确但只有对称；显式公式 = 精确且不对称，但两侧皆未知}}$$

## §3 ⭐⭐⭐ 由此得到缺口的**第六种（最锋利）表述**
$$\boxed{\text{需要一个【精确、canonical、无自由常数、非平均、且两侧一侧可证】的跨 } \sigma=1 \text{ 恒等式}}$$
```
逐条理由（全部由前几轮推出）：
 · 精确（非估计）  ⟸ 无负余量（Λ≥0，§1）
 · canonical/无自由常数 ⟸ 自由常数会造出余量 ⟹ 必在极限消失（上轮 §3）
 · 非平均          ⟸ 平均在极限丢个体信息（上轮 §2 更正后的精确表述）
 · 一侧可证        ⟸ 否则与显式公式同型（两侧皆未知 ⟹ 循环）
```
**与显式公式的唯一区别**：显式公式的**素数侧是"可算"**，而要求的是**可证** ✓✓
$$\boxed{\text{换言之：需要的是显式公式的【非循环化】—— 让其中一侧在临界 regime 内【可证】}}$$
