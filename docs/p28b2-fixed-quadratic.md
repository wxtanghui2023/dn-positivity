| N | λmax(Q₁) | λmax(Q₃) | λmax(Q₆) |

## ⭐ 综合判定
- **B2-A（固定指数）失败**——但——这是"这个构造"（增长的参考指数——不合理的负空间候选）——**需要"更好的 φ_j"**（如——低块局域函数（u 小）——或——匹配低块 quartets 的）
- **低块压缩谱 μ_j 保持正（persistent core——低块负质量稳定）**——支持"**persistent core + escaping edge**"（第三种结构）
- **⚠️ 但——μ_j 缓慢下降（μ₃ 1.0→0.41）——N 更大——可能继续降——core 的"持久性"未定**

## ⚠️ 诚实边界
- "固定指数"（λ 实部 0.8——增长）——不是合理的负空间候选——B2-A 需改进构造
- μ_j（欧氏近似——低块压缩）——定性——需更精确（H 内积）
- "persistent core"（μ_j > 0——N≤8）——但——趋势下降——N 更大需确认
