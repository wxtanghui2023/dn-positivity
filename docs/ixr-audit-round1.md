# IX-R 结构审计——算术族 → 退化 locus（第一轮——Eisenstein/θ 检查）

> 2026-09-07 21:30 · 唐先生 IX-R：独立算术族 → 内禀退化 locus → 零点——不偷引 ζ/ξ/谱/det

## IX-R 审计问题
哪些 unit/Euler-system/regulator 族有真复参数空间——退化 locus 能 = ζ 零点？

## 候选检查

### Eisenstein E(z,s)（复参数 ✓——算术系数 ✓——）
- **常数项** φ(s) = √πΓ(s−½)ζ(2s−1)/(Γ(s)ζ(2s))——**ζ 在常数项**（读出风险——）
- 完整化 E*(z,s) = ζ*(2s)E(z,s)——极点在 s = ρ/2（ζ 零点缩放——读出——）
- **数值**：E 常数项零点在 t = 7.0, 29.5, 33.5...（y=1——）——**≠ ζ 零点**（14.13, 21.02——）
- 判断：Eisenstein 零点 ≠ ζ 零点——不共享——不提供实现

### θ 级数（复参数 z——）
- ζ 从 Mellin(θ) 来——读出（已知——）

### Stark/分圆/椭圆单位（——）
- 参数离散（字符——层——）——无复参数空间
- 特殊值 → 单位（成熟——）——非零点 → 单位（无机器——）

### Euler system（——）
- 参数离散——无复参数空间

### 自守 L/Maass（复参数——）
- 同类 L 函数——零点不同（GRH——）——不共享 ζ 零点

## 审计结论（第一轮——）
**"独立算术族共享 ζ 零点"在经典对象中不出现**：
1. 带复参数的经典族（Eisenstein/θ——）——继承 ζ（常数项/Mellin——读出——）或零点不同
2. 离散族（Stark/单位/Euler system——）——无退化 locus
3. **共享零点需要"深层定理"**（如函数域：ζ(X) 与 Frobenius 特征值——Weil 猜想证明——）
   char 0 无此深层定理——"独立共享"= 读出或巧合

## 结构性观察（Hadamard——）
两个独立整函数 F 与 ζ 同零点（同增长——）⟹ F = e^g·ζ——几乎必然 F 隐含 ζ
除非有深层理由（函数域——）——否则共享 = 编码

## 判断
IX-R 经典候选空间坍缩（初步——）：
- 不继承 ζ 的族——零点不同（不共享——）
- 继承 ζ 的族——读出（无新——）
- 需要"深层共享定理"——char 0 无已知候选
