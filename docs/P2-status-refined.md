## §1 **本轮的实质进展（结构性事实 ✓）**
```
【事实 1 ✓】被积函数 **g(s) = s^{−3/2}e^s**（由替换 s = k/(2t²) 得到 ✓）的**最大值在 s = 3/2** ✓
   且在 **s < 3/2 时递减、s > 3/2 时递增** ✓（g′ = s^{−3/2}e^s(1 − 3/(2s)) ✓）
【事实 2 ✓】本问题中 s ∈ [λ/8, λ/2] ✓ ⟹ **对 λ ∈ (3,12)，3/2 落在区间内部** ✓
   ⟹ **积分被两个端点贡献主导**（而非内部极大 ✗）—— 这是此前的误判 ✗
【事实 3 ✓】精确恒等式给出 near 的**干净因子**：
   **F(1+1/t²) = (1−e^{−v(t)})²e^{v(t)}** ✓（v(t) = (k/2)log(1+1/t²) ✓）
   且 **v(t) ≤ v_H := v(H)** ⟹ **(1−e^{−v})² ≤ (1−e^{−v_H})²** ✓✓
   ⟹ **near ≤ (log2H/π)(1−e^{−v_H})²·∫_H^{2H}e^{v(t)}dt** ✓
【⭐ 关键观察】而 **e^{v_H}·(1−e^{−v_H})² = e^{v_H} − 2 + e^{−v_H} = r_H^k + r_H^{−k} − 2** ✓✓
   —— **与 RHS 的因子【完全相同】** ✓ ⟹ 比较可化为
   **(log2H/π)·(1−e^{−v_H})²·I  ≤  2·(1−e^{−v_H})²·e^{v_H}·T** ✓
   ⟹ **约去公共因子（!!）**：(log2H/π)·I ≤ 2e^{v_H}T ✓ —— **即只需控制 I := ∫_H^{2H}e^{v(t)}dt** ✓✓
```

## §3 **但 §1 的"公共因子约去"是实质简化 ✓✓**
```
【⭐ 简化后的目标】只需证明 **(log2H/π)·∫_H^{2H}e^{v(t)}dt ≤ 2e^{v_H}T(H)** ✓
   而 T(H) ≥ (a/3)H log H ✓ ⟹ 只需 **(log2H/π)·I ≤ (2a/3)H log H·e^{v_H}** ✓
【等价形式】令 I = ∫_H^{2H}e^{v(t)}dt ✓ —— 而 **e^{v(t)} = (1+1/t²)^{k/2}** ✓✓（**定义式 ✓**）
   ⟹ 目标变为：**(1/π)∫_H^{2H}(1+1/t²)^{k/2}log(2H)dt ≤ (2a/3)H log H·(1+1/H²)^{k/2}** ✓
【⚠️ 注意】此处 (1+1/H²)^{k/2} 与 (1+1/t²)^{k/2} 的比值随 t 增大而**急剧下降** ✓
   —— 这正是"集中窗口"的解析表述 ✓ ⟹ **闭式化的自然路线**：令 y = (1+1/t²)^{k/2}/(1+1/H²)^{k/2} ✓
   并利用 log y = (k/2)log[(1+1/t²)/(1+1/H²)] ≈ −(k/2)(t²−H²)/(H²t²) ≤ −(k/2H²)(t²−H²)/t² ✓
   ⟹ **y ≤ e^{−λ(t−H)(t+H)/(2t²)} ≤ e^{−λ(t−H)/(2H)}**（因 (t+H)/t² ≥ 1/H 当 t ≤ 2H ✓✓）
   ⟹ **∫_H^{2H}y dt ≤ ∫_H^∞e^{−λ(t−H)/(2H)}dt = 2H/λ** ✓✓✓
⟹ ⭐⭐⭐ **闭合！** **I ≤ (2H/λ)(1+1/H²)^{k/2}** ✓ ⟹
   (log2H/π)·I ≤ (2H/λ)(log2H/π)e^{v_H} ✓ 与 (2a/3)H log H e^{v_H} 比较 ⟹
   **ratio ≤ (2H/λ)(log2H/π)/[(2a/3)H log H] = [2/(λπ)]·[log2H/log H]/(2a/3)** ✓
   而 2a/3 = 1/(3π) ✓ ⟹ **ratio ≤ 6·log(2H)/(λ·log H)** ✓✓
   ⟹ **< 1 ⟺ λ > 6log(2H)/logH ≈ 6.6** ✓✓ —— **给了大 λ 的闭式界（λ ≳ 6.6 ✓）** ✓✓
```
