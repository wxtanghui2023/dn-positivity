## §1 奇层能量恒等式：推导（逐行，初等 ✓✓）

```
设 φ_j ∈ (0, π/2)，σ_j ∈ {±1}，F_{2r+1} := Σ_j σ_j cos((2r+1)φ_j)（r = 0..12）✓

(1) 望远镜求和（用 2 sin A cos B = sin(A+B) - sin(A-B)，A = ψ，B = (2r+1)ψ）:
    2 sin ψ · cos((2r+1)ψ) = sin((2r+2)ψ) - sin(2rψ)
    ==> Σ_{r=0}^{12} 2 sin ψ cos((2r+1)ψ) = sin(26ψ) - sin 0 = sin(26ψ)
    ==> K(ψ) := Σ_{r=0}^{12} cos((2r+1)ψ) = sin(26ψ)/(2 sin ψ)      （ψ ≠ 0；K(0) = lim = 13 ✓）

(2) 乘积展开（cos A cos B = ½[cos(A-B) + cos(A+B)]）:
    Σ_r cos((2r+1)φ_j) cos((2r+1)φ_{j'}) = ½[ K(φ_j - φ_{j'}) + K(φ_j + φ_{j'}) ] ✓

(3) 求和:
    Σ_{r=0}^{12} |F_{2r+1}|^2 = Σ_{r} (Σ_j σ_j cos((2r+1)φ_j)) (Σ_{j'} σ_{j'} cos((2r+1)φ_{j'}))
                              = Σ_{j,j'} σ_j σ_{j'} · ½[ K(φ_j - φ_{j'}) + K(φ_j + φ_{j'}) ]   ✓
==> 恒等式成立（对一切 φ, σ；仅用初等三角恒等式）✓✓

(4) 充分性：若 max_r |F_{2r+1}| <= 1/2，则 13 项每项 <= 1/4，故 Σ <= 13/4 ⟹ 逆向即靶 ✓
```
