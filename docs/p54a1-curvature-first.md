## ⚠️ 结构分析
1. **b₂/|ξ|² = L'' + 2(L')²**——2(L')² ≥ 0 恒——**但 L'' 可负**
2. **Γ part 的 L'' ~ −1/(2t) < 0（Stirling）——Γ 不提供正曲率（coercivity 不在 Γ）**
3. 正性来自 2(L')²——L' 大在零点附近（|Ξ| 极小——log 陡）——**b₂ 在 |Ξ| 极小（零点附近）正——在极大（零点间）负——振荡**
4. **"判别"实际是零点处**：b₂(γ_k) = Ξ'(γ_k)² > 0（在线——Ξ(γ_k)=0）——离轴移动后原位置 b₂ 可负（8/31 的负谷）——**局部检测（依赖零点位置 γ_k——循环风险）**

## 判定
- **b₂ > 0 全体 t 不是 RH 判据（在线变号——数值否定）**
- 若判别是"零点处 b₂(γ_k) > 0"——依赖零点位置（循环——需先知道 γ_k）
- **Γ part 无 coercivity（L'' < 0）——正曲率的来源是零点结构本身（L' 的振荡——经零点）——非独立**
- ⚠️ 需澄清 8/31 的 b₂ 定义（当时说"在线全正"——与现在矛盾——可能用了不同对象/归一化/区间）
