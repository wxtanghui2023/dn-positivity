# 算术运输曲率 v2 审计（2026-09-10）

## C0：精确素数分解 ✓
Ω(S) = Σ_p ω_p(S) log p，ω_p ∈ ℤ（±1 指示函数之和）
验证：max|Σ ω_p log p − Ω| = 2.665e−15（机器精度）

## C1：局部可积性（弱判据）
(p, ω_p(S)) 决定 ω_p(T_A S)：多值键 30/154 ⟹ 非单值 ⟹ 非平凡
（弱迹象，非充分）

## C2：跨素数耦合 —— 【不通过】
键 (p, a mod p, b mod p) 共 3468，取值不唯一的键 = 0
⟹ ω_p 只依赖 (a,b) mod p（完全 p-局部）
⟹ Ω = Σ_p（独立 p-局部分量）= Euler 化局部量

### 结构性原因（比现象更重要）
任何由整除性/rad/gcd 数据构成的权，其 ω_p 自动 p-局部
（"p|n" 本身是 mod p 条件）
⟹ radical 类权【永远】产生不了跨素数耦合 ⟹ v1/v2 这一类在 C2 上不可能通过

## ⭐ 结构性结论：唯一出路 = 阿基米德通道
跨素数耦合要求权含【非 p-局部】数据；唯一非 p-局部算术量是

  2¹⁰ + 1 = 1025 = 5²·41   ← 加法创造新素数 5, 41
⟹ 进位是跨素数耦合的唯一来源
⟹ v3 必须把 log-尺度/大小放进权，而非仅 rad
