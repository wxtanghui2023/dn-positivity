## 任务 1 — 构造与**容许性检验**

**构造（赋值书中的路线 (i)，带限）**：令 `ĝ` 为 `g` 在实轴上的 Fourier 变换，
```
g_Δ(t) := ∫_{|x| ≤ Δ} ĝ(x) e^{2πi x t} dx          （把 ĝ 截断到带宽 Δ；Δ = 平滑参数）
```
**容许性（两项都通过 ✓ —— 失败不在容许性，而在定量）**
```
① 条带：g_Δ 是指数型 2πΔ 的整函数（Paley–Wiener）⟹ 在 |Im z| ≤ 1/2 + ε 内解析，**任意 ε > 0** ✓
② 衰减：g(t) = 1 − cos(nθ(t)) ≍ n²/(8t²)（θ(t) ~ 1/t）⟹ |g_Δ(t)| ≪ (1+|t|)^{−2}，取 δ = 1 ✓
⟹ **对每个 Δ，g_Δ 都属容许类**；差异只在逼近误差的大小（任务 2）。
```
**为什么必须逼近**：`g` 本身在 `|Im z| < 1/2` 解析，但**首奇点恰在边界 `|Im z| = 1/2` 上**；标准引理要求 `ε > 0`，
在 `ε = 0` 处素数侧 `Σ Λ(m)/√m·ĝ(log m/2π) ≈ Σ Λ(m)/m` **对数发散**（综述 §0(ii)）。

## 任务 2 — 误差估计（显式，关于 n、T₀、平滑参数 Δ）

**奇点结构（本文件核验）**：`w = z − i/2`，`θ(z) ≈ i log w + C` ⟹ `e^{inθ} ≈ e^{inC} w^{−n}` ⟹ `g ~ −½e^{inC} w^{−n}`
（**n 阶支点**，|c| = ½）。`w^{−n}` 的 Fourier 变换**精确**为（脚本 [0] 段数值核验，n = 1…5，ratio = 1.0000）
```
|ĝ(x)|_单侧 = π (2π|x|)^{n−1} e^{−π|x|} / (n−1)!        （e^{−π|x|} 的**速率**由“到边界距离 ½”决定；
                                                        (2π|x|)^{n−1} 的**多项式因子**由支点**阶数 n** 决定）
```
**上界的显式形式**（把两侧奇点与 |c| = ½ 合起来，常数正好抵消）：
```
ε(Δ,n) := sup_{t∈R} |g(t) − g_Δ(t)| ≤ ½ ∫_{|x|>Δ} |ĝ(x)|dx = 2^n Γ(n, πΔ)/(n−1)!
        = 2^n · P( Poisson(πΔ) ≤ n−1 )        （用 Γ(n,x) = (n−1)! e^{−x} Σ_{k<n} x^k/k! ）
```
**预算**（正确形式）：`|Fluc_g − Fluc_{g_Δ}| ≤ ε·( #{γ≤T₀} + main(T₀) ) ≈ 2ε N(T₀) ≤ 0.41 N(T₀)`
```
⟹ 需  ε < 0.205   （综述的 0.41 漏掉了这个因子 2；下文一切比较都用 0.205）
```
**素数侧长度**：`g_Δ` 的指数型为 `2πΔ` ⟹ `ĝ_Δ` 在 `log m/2π > Δ` 处**恒为 0** ⟹ 显式公式素数侧只到 `m ≤ e^{2πΔ}`。

**关于 n! 的追问（赋值书要求）——本构造【不】避开它**：
```
ε(Δ,n) = 2^n Σ_{k<n} (πΔ)^k e^{−πΔ}/k!     中的 **1/k!** 就是“丢掉的 n!”：
  自然带宽 πΔ = n/2 时，主项为 (n/2)^{n−1}/(n−1)!，被 1/(n−1)! 严重压低；
  要补偿它必须把 πΔ 抬到 n 以上。精确阈值：
        ε(Δ,n) < 0.205   ⟺   πΔ ≥ c·n,     c = 2.678347  （c 是 1 + log(2c) = c 的根）
【独立交叉检验（条带强制 / Achieser）】g 在 |Im z| ≤ 1/2 − η 内解析且 |g| ≤ C η^{−n}；
  经典上界 E ≤ C η^{−n} e^{−2πΔ(1/2−η)} 对 η 极小化 ⟹ E ≤ C e^{−πΔ} (2πeΔ/n)^n；
  在 πΔ = c n 处化为 C (2ec·e^{−c})^n，而 **2ec = e^c 恰等价于 1 + log(2c) = c** ⟹ 两法给出**同一个** c ✓
⟹ **换构造也救不了**：这是带限类本身的定量极限，不是 Fourier 截断的人为产物。
```

## 任务 4 — 诚实判定

## 对本项目的意义

1. 候选 A（带限逼近 + 宽松预算）**已被排除**，而且是**定量排除**：失败不是 `ε·log` 量级的小差，而是 `2^n` 量级的鸿沟；
   `n = T₀²` 处差 `10^{3.8e11}`（情形 1）/ `10^{2.7e24}`（情形 2）个数量级 —— 任何“调常数”都不可能挽回。
2. “0.41 的预算很宽松”这一侦察判断**被证伪**：宽松的前提（目标在更宽条带内有界）恰好不成立。今后不要再用它做乐观估计。
3. 失败定位到**两个等价的说法**：θ 在 `±i/2` 的 **n 阶支点**；或 `cos(nθ)` 复合导致的 **n 倍带宽/型放大**。
   与此前“共振（δN）”结论**互相独立、结论一致**：`n ≤ T₀²` 在本框架内确实是一条真障碍。
4. 论文 A 应保留**线性范围**为已证结果；本文件可作为 Remark/附录的一段**负面结果**（“为何带限路线不能推到二次范围”，带显式阈值 `πΔ ≥ 2.678n`）。
5. 若仍要攻二次范围，出路不在“逼近”，而在**换对象/换机制**（候选 B 的 ε = 0 正则化显式公式，或候选 C 的一致啁啾–素数音估计）——
