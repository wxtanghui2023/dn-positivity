## §1 论文 descent chain 的最小五组件（拆解自源码 ✓✓）

```
C1 **压缩**（compression）：每个非空可容许谓词有短见证 n，使 **ν(n)·q < T** ✓
     ［源码：`short_representative_of_invariance`］
C2 **失败保持**（failure preservation）：failure 在"乘子 j<q"与"取负"下**保持** ✓
     ［源码：`P(j*x) ↔ P(x)`、`P(-x) ↔ P(x)`］
C3 **严格下降**（strict descent）：由失败 (q,n) 得失败 (j,r) 且 **j<q、r<n** ✓
     ［源码：`extension_descent_certificate_symmetric`／`uniform_even_descent`］
C4 **外层闭包**：**∀j<q：j ∈ H**（使 C2 的 j-乘子可用）✓
     ［源码：`Nat.strong_induction_on` 给出 `hprev`］
C5 **良基性**：C3 的下降落在 ℕ 上 ⟹ 无无限下降 ⟹ 矛盾 ✓
     ［源码：`Nat.find` 的最小性 `hminimal`］
【判据】 缺 C1／C2／C3 中任一 ⟹ 桥**不成立**；且 **C1 必须严格弱于目标**（新增，见 §0③）✓✓
```
