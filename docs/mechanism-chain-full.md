## 2. 各环节状态

### 2.1 M(T) = O(1)（P1——确认）
- **M_Smid（S_mid·gaps）不可靠**（中点离散化——假趋势 +0.017——假象）
- **M_direct（分析抵消）可靠**：Σ(T−γ_k) − ∫(θ/π+1)dt——θ 的 Stirling 解析积分
  - ∫θ/π dt = T²/4π·log(T/2π) − 3T²/8π − T/8 + (1/48π)log T + 1/(11520πT²)
  - 主项精确抵消——残余 O(1)
- **结果**：采样 +0.78, +0.34, +0.55, +0.49, +0.57, +0.59, +0.72——振荡——前后半差 −0.0058 ≈ 0——**无趋势——O(1) 确认**
- **纠正**：8/22 晚"M(T) = O(log T)"判断是 M_Smid 假象——今天恢复 O(1)

### 2.2 窗口和定理（严格——无条件）
**定理**：对任意 m, L = O(log m)——Σ_{k=m}^{m+L} δ_k = O(1)
**证明**：
- 恒等式（部分求和）：Σ_{k=1}^n δ_k = −(S_{n+1} − S_1)/N'_n + ∫_2^{γ_n} S·g dt + O(1)
- 窗口差（常数偏移消去）：Σ_{m}^{m+L} = −S_{m+L+1}/N'_{m+L} + S_m/N'_{m−1} + ∫_{γ_{m−1}}^{γ_{m+L}} S·g dt
- S/N' = O(1)（Littlewood——|S| = O(log)——N' ~ log——无条件）
- ∫S·g（窗口）= O(1/m)（g = 2π/(t·log²(t/2π))——缓变——S = O(log t)）
- **结论**：窗口和 = O(1)——无条件 ✓

### 2.3 ∫S·g = O(1)（数值确认）
- ∫S·g dt = +0.1313（常数——T=7.5e4 到 5.5e5 不变）
- 虽然 |∫S·g| ≤ ∫|S|·g ~ log log T（发散——绝对）——但带符号振荡抵消——O(1)
- 部分求和差 ~−5.4（S 的跳跃项——常数偏移——不影响 O(1)）

### 2.4 ε_m 连接（δ 的加权和——框架）
- ΔS_k = −δ_k·N'_k（精确——corr 0.996）
- ε_m ≈ −Σ_{k in block} f̃(φ_k)·δ_k·N'_k（δ 的加权和）
- 权重 f̃(φ)·N' 在块上符号固定（0 次变化）——m 大时缓变（变化率 0.28）
- **Abel + 窗口和 O(1) → ε_m = O(1)（m 大）**——m 小（有限个——O(1) 常数）

### 2.5 Σε_m（最后一段——研究级）
- Σε_m = ∫f̃ dS（全范围）= −∫S·f̃' dφ（部分积分）
- f̃'(φ) = 2[cos φ·sin(φ/2c) + sin φ·cos(φ/2c)/(2c)]——∫f̃' = 0
- 数值：Σ|ε_m| = 0.48-0.74（n=5000-20000）——有界
- **技术**：Σε_m = (1/π)Σ_p ∫ sin(t(φ)log p)·f̃'(φ)/(p^{1/2}log p) dφ（素数项逐项）
  - van der Corput（t(φ)log p 的振荡——与定理 1 同类）——研究级
- **最后一段**：Σε_m 的振荡控制（van der Corput 常数——专门工作）

### 2.6 r(n) = O(1)（数值——弱 RH）
- r(n) = λ_n − ½n·log n − cn（λ_n 余项——数值 n≤3000——max 0.24）
- **弱 RH**：r(n) = O(1) 排除"无穷多 β>½ 离轴"（λ_n → ∞）——允许有限离轴（贡献 O(1)——不可检测）
- **不是** r(n) = O(1) ⟺ RH（有限离轴 OK）——但排除无穷多离轴——有价值
