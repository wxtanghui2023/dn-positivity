## Maier-Rassias 论文核心方法（arXiv:1705.09918——Canadian Math Bulletin 2018——）

### 定理 1.1（签名——）
若 ζ 有恰好 4 个离轴零点（σ₀±iγ₀, 1−σ₀±iγ₀——FE 四重奏——）——则 BNBD 距离：
```
d_N² = (1/2π)∫|1−ζV_N(½+it)|² dt/(¼+t²)
     = (A·N^{2σ₀−1}·cos(2γ₀ log N) + B·N^{2σ₀−1})/log²N · (1+O(N^{½−σ₀+ε}))
```
（A, B 常数——依赖 σ₀, γ₀——）

### 推导方法（可借鉴的——）
1. **V_N 分解（Lemma 2.3——Bettin-Conrey-Farmer——）**：
   V_N(s) = (1/ζ(s))(1 − (1/log N)ζ'/ζ(s)) + (1/log N)Σ_ρ R_N(ρ,s) + (1/log N)F_s(1/N)
   - **每个零点一个显式贡献 R_N(ρ,s) = Res_{z=ρ} N^{z−s}/(ζ(z)(z−s)²)**——逐点零点追踪（非集体量——）
2. **离轴/在线分离（Def 2.6——）**：Σ^(1)（在线——）+ Σ^(2)（离轴 {σ₀±iγ₀}——单独追踪——）
3. **签名机制**：R_N 含 N^{ρ−s}——离轴零点给 N^{σ₀±iγ₀}——Σ^(2)·Σ^(2) 交叉给 N^{2σ₀−1}（实部——）+ cos(2γ₀ log N)（虚部 2γ₀——）——**离轴实部 σ₀ 直接进指数（比在线 N^{½} 大——）**
4. **R_N 显式（单零点——）**：R_N(ρ,s) = N^{ρ−s}/(ζ'(ρ)(ρ−s)²)——**ζ'(ρ)（离轴零点导数——）进入 A, B**
5. 技术：修改版 Lindelöf（Lemma 2.1——离轴假设下 ζ ≪ t^ε——）+ 留数 + 积分线移动 + Σ 1/|ζ'(ρ)|² ≪ T^{3/2−δ}（假设——）

## 任务 1-4 结果（全部负面——）

### 任务 3：A, B 分析（数值拟合——离轴主导项积分——）
- **ζ'(ρ) 完全消去**（相位无关——大小 ~1/m²——A·m², B·m² 恒定——）

- A/B 的 γ₀ 依赖是数值伪影（γ₀ 接近 ζ 零点处异常——如 γ₀=50 ≈ γ=49.77——）
- **结构判断**：|A| ≤ B 自动（A, B 来自同一正量 d² ≥ 0 的傅里叶型分解——|cos|≤1——）——无约束潜力
- ⚠️ 数值注意：积分线 (½−ε) 经过 ζ 零点附近时数值污染（γ₀ ≈ 零点高度——）

### 任务 4：有限 vs 无限离轴
- 有限（固定 σ₀——）：单频增长签名（N^{2σ₀−1}——改变 d_N² 渐近——）
- 无限（σ_j → ½——）：签名 ~ Σ 1/γ_j²·osc/log²N ~ 1/log²N——**藏在在线（1/log N——）下——不可区分**
- **无限离轴 ψ 收敛性**（数值诊断——）：正密度零点型分布 → 收敛（cos 抵消——~0.1——）——只有共振分布（γ_j ~ 2πk/log x——）发散——但——**共振不能对所有 x 同时成立**（一个 γ_j 只对一个 x 共振——）——ψ 显式公式对所有 x 成立——所以不矛盾
- **结论：无限近线离轴与 ψ 已知界相容——不矛盾**
