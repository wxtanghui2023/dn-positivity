# M(T)=O(1) 攻坚——层次结构与数值基础（2026-09-08 18:30）

## 一、数值基础（强——）

- max M = +0.58——min M = −0.77——max|M| = 0.77

- 实际 ~ ±0.3——**强局部自抵消**——S 的净面积在每 ~10^4 零点尺度内平衡

## 二、层次结构（清晰——）

定义：
- δ_k = Δγ_k − 1/N₀'(γ_k)（间距偏离——）
- e_k = γ_k − G_k（位置偏离——G_k = Gram 点——）
- **e_{k+1} − e_k = δ_k**（位置偏离 = 间距偏离累积——）
- M(γ_k) ~ Σ_{j≤k} e_j 类（位置偏离的累积——）

层次：
```
① Σδ_j = O(1)——【已证】（8/23——无条件——）
② e_k = Σ_{j<k}δ_j + e_0 = O(1)——位置偏离有界（推论——）
③ M = Σe_j = O(1)——【目标】——位置偏离的累积有界
   ——需要 e_j 的"零均值回归"（不只是有界——）
```

**③ 比 ② 强**——e_k 有界不足够（若 e_k → c≠0——Σe ~ ck 发散——）——需要 e 回到 0 附近（净面积——）。

## 三、文献连接（难度确认——）
- S₁ = O(log T)（Titchmarsh 9.9A——）
- S₁ = o(log) ⟹ Lindelöf（13.8——）
- ⟹ M(T)=O(1) 证明 = Lindelöf 级（100 年未证——）

## 四、证明核心（精确表述——）
**M(T)=O(1) ⟺ 位置偏离 e_k 的累积 Σe_k = O(1)**
⟺ e_k 序列"零均值强回归"（Gram 点回归——）

这比 δ 补偿（Σδ=O(1)——已证——）强一层：
- Σδ=O(1)：间距偏离的净累积有界（"间距回归"——）
- Σe=O(1)：位置偏离的净累积有界（"位置回归"——更强的结构——）
