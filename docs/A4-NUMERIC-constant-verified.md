## §1 **目标**：核验 **C = Σ_{Reρ=½} m(ρ)²/|ρ|² = 2 + γ − log(4π)**
```
【前沿（BBLS / Burnol ✓）】d_N² ~ C/log N（猜想 ✓）；**下界 d_N² ≥ (C+o(1))/log N 已证 ✓✓**

【经典恒等式】在线时 1/|ρ|² = 1/(ρ(1−ρ)) ✓，而 **Σ_ρ 1/(ρ(1−ρ)) = 2 + γ − log 4π** ✓（经典 ✓）

```
