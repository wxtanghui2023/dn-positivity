## 0. 定理（✓ 本轮成果 ✓）

```
**定理 ✓**：设 φ(u) = nθ(u) ✓，θ(u) = 2arctan(1/(2u)) ✓；零点计数 A(u) = M(u) + S(u) ✓（M = 光滑律 ✓，S = 经典误差 ✓）。
则在**慢相位区** Y := √n ≤ u ≤ T ✓ 有

   | Σ_{γ∈[Y,T]} e^{iφ(γ)} | ≤ 3·sup|ρ/φ′| + 2·(c₁logT + c₂loglogT + c₃) + ‖S‖_{L²}·√(T−Y) ✓

**推论 ✓（把 Selberg 第二矩代入 ✓）**：对**每一个** n ∈ [0.3T², T²] ✓
   左端 ≤ **2.4×10⁵** ✓ ≪ **0.8N = 1.6×10⁶** ✓ ⟹ **余量 6.7 ~ 9.9 倍** ✓✓
**一致性来源 ✓**：**S 与 n 无关** ✓，n 只进入权重 φ′ ✓ ⟹ 界对 n **一致** ✓✓（**无需逐点刚性输入** ✓）
```

## 1. 链条（✓ 三步，每步都可核 ✓）

```
【Abel / Stieltjes 分解 ✓】
   Σ_{γ∈[Y,T]}e^{iφ(γ)} = ∫_Y^T e^{iφ}ρ du ＋ [e^{iφ}S]_Y^T − ∫_Y^T S·iφ′·e^{iφ}du ✓
【(1) 光滑部分 ✓】**初等** ✓：φ′ 单调（|φ′| 递减 ✓）⟹ 分部积分 ＋ 第二中值定理 ✓
   |∫ρe^{iφ}| ≤ 2sup|ρ/φ′| + ∫|(ρ/φ′)′| ✓ —— 且 ρ/|φ′| 单调递增 ✓ ⟹ 两者都 = 端点值 ρ(T)/|φ′(T)| ✓
   实测 ✓：**8.07 ~ 13.12** ✓
【(2) 边界 ✓】显式经典界 ✓ |S(u)| ≤ c₁log u + c₂loglog u + c₃（c = 0.110, 0.290, 2.290 ✓）
   ⟹ ≤ 2·4.5875 = **9.175** ✓
【(3) 偏差项 ✓】Cauchy–Schwarz ✓：|∫Sφ′e^{iφ}| ≤ ‖S‖_{L²(Y,T)}·‖φ′‖_{L²(Y,T)} ✓
   慢区 |φ′| ≤ 1 ✓ ⟹ ‖φ′‖₂ ≤ √(T−Y) ✓；‖S‖₂ 由 **Selberg 无条件第二矩** ∫₀^T S² ~ T·loglogT/(2π²) ✓
⟹ 三项合计（**Selberg 版 ✓，不含表数据 ✓**）：**1.62×10⁵ ~ 2.40×10⁵** ✓ vs 0.8N = 1.601×10⁶ ✓
   ⟹ **余量 6.67 ~ 9.86 倍** ✓✓
```

## 3. 剩下的部分（✓ 精确定位 ✓）

```
【快相位区 ✓ γ < √n】**仍未闭合** ✗ —— 且**原因已精确写出** ✓：
   · 该区 |φ′| ≥ 1 ✓，但**每个零点的相位增量 ≤ ~1** ✓（**临界密度** ✓）⟹ 驻相/vdC **皆无效** ✗
   · 粗糙界给 ~n/γ₁ ≈ 10¹⁰ ✗（与真值 ~10³ 差 10⁷ ✗）
   · 即：**该区需要临界密度处的指数和界** ✗ —— 与其余各路的墙同源 ✓
【⭐ 但得到一个【新的定量靶子 ✓】**：慢区点态界 2.4e5 ✓ vs 要求 1.6e6 ✓
   ⟹ 只需 **快区 ≤ 1.36e6（点态 ✓）** ✓；而快区的 $L^2$ 均值有**严格界** ✓（E55 块二阶矩 ✓）

```
