## 1. 准入问题（必须逐条作答）

```
Q1 框架结构：正性位于哪一层？
   选项：(a) reproducing kernel 层 (b) 测试函数层 (c) 系数/Hermite–Biehler 结构函数 E 层
Q2 N39 分类：该正性 **β-盲** 还是 **β-敏感**？
   β-盲（不感知零点位置）⟹ 须无条件可证，或可被反例击穿
   β-敏感 ⟹ 先天条件性，必须申报条件来源
Q3 β-盲情形：文献中是否已有**反例**？（重点核实 Conrey–Li 一类工作，
   据报道该类正性条件在相关情形下失败——须检索核实，不得凭记忆断言）
Q4 β-敏感情形：条件来源是否为 Weil 判据 / RH 本身 / 零点位置？（N2 / META-3 hidden oracle）
Q5 作用对象（E 条）：正性作用于
   (i) 测试函数变量 还是 (ii) 待定位的零点/谱参数位置？
   仅 (i) ⟹ N29（位置盲，pinning 通道关闭）
Q6 结构函数 E 的选取：是否已内含零点信息？（hidden oracle 检查）
```
