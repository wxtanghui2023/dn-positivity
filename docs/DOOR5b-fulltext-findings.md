## §1 【全文】**判据的精确形式与算术内核**
```
【NB 判据】RH ⟺ χ ∈ span_H{ρ_θ : 0 < θ ≤ 1} ✓（χ = (0,1] 的特征函数；ρ_θ(t) 由**分式部分**给出 ✓）
【BD（Báez-Duarte）判据】χ_n := χ 在 H_n ⊂ H 上的正交投影（H_n 由 (ρ_k)_{1≤k≤n} 张成），
   **d_n := ‖χ − χ_n‖_H** ⟹ **RH ⟺ lim d_n = 0** ✓；且等价于 χ_n 系数的特定渐近行为 ✓
【⭐⭐ 算术内核（Mellin 恒等式）】**ρ̂_θ(s) = ∫₀^∞ ρ_θ(t)t^{s−1}dt = −θ^s ζ(s)/s**（0 < σ < 1）✓✓
【⭐⭐ Möbius 构造（Báez-Duarte 原文）】f_s(x) := Σ_{a≥1} μ(a)a^{−s}ρ_a(x) 满足
   **f_s(x) = (1/x)ζ(s+1) − Σ_{a ≤ 1/x}(μ(a)/a^s)[1/(ax)]** ✓✓
   ⟹ **Möbius 加权的分式部分组合【显式给出 1/ζ(s+1)】** ✓✓
   原文："**在 RH 假设下，对小的正 ε，f_ε ∈ B_nat**" ✓（这就是判据的机制 ✓）
⟹ 门⑤的实质：**"1/ζ（的适当实现）是否落在膨胀分式部分的闭包中"** ✓
```

## §3 【全文·定量现状】+ ⚠️ **一处约定张力（必须解）**
```
（i）Báez-Duarte 原文 (1.2)：**‖F − χ‖_H ≥ C/√(log N)**（F 为膨胀组合、N = max a_k ✓）
     并注："**该常数近期由 J. F. Burnol 改进**" ✓ ⟹ 下界形式 **d_N ≳ 1/√(log N)**
（ii）Darses–Hillion：**猜想 d²_n ~ C log n，C = 2 + γ_E − log(4π) ≈ 0.0462** ✓；
     并称 **Burnol 已证下界 d²_n ≥ (C + o(1)) log n，同一常数 C** ✓
     （出处：J.F. Burnol, Adv. Math. 170(1) (2002) 56–70 ✓）
⚠️ **张力**：(i) 给出 d_N **递减**（→0 ✓ 与判据一致 ✓），(ii) 给出 d_n **递增**（√(C log n) → ∞ ✗）
   ⟹ 两者**不可能同时**是关于同一个 d_n ✗ ⟹ **必有一处约定不同**（索引/范数/归一化/或题中之量不同 ✗）
⟹ **必须从一手文献（Burnol 2002 / DFMR 2013）解决** ⚠️（否则无法确定配对方向 ✓）
```
