## §1 【原文】**定理（= Connes 2026 的 Theorem 6.1）**
```
"For a real distribution 𝒟 on [0,L] with 𝒟̃ its even extension on [−L,L], if the quadratic form with
 Schwartz kernel 𝒟̃(x−y) defines a **lower-bounded selfadjoint operator on L²([−L/2,L/2])** whose
 **lowest spectral value λ is a simple, isolated eigenvalue with even eigenfunction ξ**,
 then **all the zeros of ξ̂(z) lie on the real line**." ✓✓
```

## §2 ⭐⭐⭐ 【原文】**证明核心 = 纯 *-代数命题（Proposition 2.1）**（这是机制！）
```
"Let T = (c_k) be a **positive (n+1)-dimensional real Toeplitz matrix of RANK n**
 and let (a_j)_{j=0}^n be a real vector in **ker T**.
 (1) The ideal J of A = ℂ[X, X^{−1}] generated by P = Σ a_j X^j is **stable under the canonical involution**
     (aX^n)* := aX^{−n};
 (2) the monomials X^j (j=0…n−1) form a basis of A/J;
 (3) there exists a **unique linear form φ on A/J** with φ(X^j) = c_j;
 (4) **φ is POSITIVE on the *-algebra A/J**." ✓✓✓
```
$$\boxed{\text{Toeplitz【正】+【秩亏 n】+ 核向量}\ \Longrightarrow\ \text{商代数上的【正】线性形式}\ \Longrightarrow\ \hat\xi\ \text{零点全实}}$$
```
⟹ **机制 = "Toeplitz 正性 + 秩亏 ⟹ 正性"，而【秩亏】是内容所在** ✓✓✓
   ⚠️ 对照：我们在 TP/PF 线上发现"**以零点实例化 ⟹ 条件自动坍缩（空洞）**" ✗ ——
      **差别正在于：他的对象【有秩亏】**（我们当时测的对象没有 ✓✓）
```

## §3 ⭐⭐ 【原文】**矩阵的来源 = 谱作用的二阶 Gâteaux 导数**
```
"the quadratic form given by the **second Gâteaux derivative of the spectral action**：
 ½ d²/dt²(tr f(D+tA))|_{t=0} = Σ_{i,j} A_ij A_ji q_ij ，
 其中 **q_ij 如 (11)**：**q_ij = (b_i − b_j)/(λ_i − λ_j)（i≠j）**，**a_i（i=j）**；
 b_i = f′(λ_i)，a_i = f″(λ_i)，**λ_i = i（圆上的 Dirac 算子 D_{S¹} 的谱）**" ✓✓
⟹ **矩阵是【分差/Loewner 型】：q_ij = (f′(λ_i)−f′(λ_j))/(λ_i−λ_j)** ✓✓✓
   —— 而 **Loewner 矩阵的正性 ⟺ f′ 单调 ⟺ f 凸**（经典 Loewner 定理 ✓），
      且 **Loewner 矩阵属【全正性（TP）】家族** ✓✓
【有限维偶情形】Q=(q_ij), i,j ∈ {−N,…,N} 实对称正 ✓；并给出**三条显式正性条件**（含 a₁,a₂,a₃,β,y 的三角式 ✓）
```
