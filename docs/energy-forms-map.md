# 能量泛函形式图谱：所有可能的"能量"候选系统盘点

> 2026-09-01 · 唐先生问"能量有其它的泛函形式么" · 系统盘点

## 五大类别（完整图谱）
| 类别 | 形式 | 结果 |
|------|------|------|
| 1. penalty（不排除） | D / E(ε) / S_proj / 刚性 / 相位 / 高阶D / 联合 / 轨道大小 | 离轴"贵"但"允许"——不排除 |
| 2. 守恒（不区分） | Weil Q[f] / trace | 固定——在线/离轴都 = W[f]——不区分 |
| 3. 匹配（唯一但循环） | 显式公式匹配 / 素数数据读出 | ψ↔零点一一对应——唯一平凡——循环 |
| 4. 循环（定义域限制） | 合法=在线 | = RH 本身 |
| 5. 未构造 | 特征多项式（Θ）/ 动力学吸引子 | 若存在可能提供排除——未构造 |

## 数值验证（新候选）
- **S_proj 能量**：在线极小（变分定理——无条件）——但离轴 S 更小（−6e-7——数值：γ 偏移使 S 减）——penalty——不排除
- **轨道大小能量**：E=Σ(轨道大小−2)——penalty——不排除
- **显式公式匹配**：唯一但循环（ψ↔零点一一对应）

## ⭐ 结论：没有"排除型"的能量形式
**所有能量形式落在五类——没有"排除型"**：
- penalty（不排除）——守恒（不区分）——循环（匹配/定义域）——未构造
- **"排除"（离轴不可达）在能量框架内不存在**——因为——离轴配置 Hadamard 可实现——任何自然能量对它有限

## 唯一可能提供"排除"的（未构造）
1. **特征多项式（Θ）**——若构造（谱=零点——系数代数结构——重数强制）——可能排除——但 Θ 未构造（Hilbert-Pólya——循环风险）
2. **动力学吸引子**——若构造（在线稳定平衡/离轴不稳定——演化排除离轴）——可能排除——但动力学未构造

## 与完整图景的收敛
- 能量泛函框架：没有排除型（离轴可实现——任何能量有限）
- 轨道退化诊断：排除需要"重数强制"（Spec Z 无）
- 变分局限：penalty vs 定义域限制（循环）
- **三者一致**：Spec Z 的"排除"需要"未构造的结构"（Θ/动力学/重数强制）——F_q 有（Fr/Poincaré）——Spec Z 无
