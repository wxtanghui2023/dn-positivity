## 关键结构
1. **所有瞬态族从 β<½（甚至 <0——）"出生"——穿过 ½——逃向 σ=1**——"穿过 ½"是瞬态族的普适特征

4. **主族 vs 瞬态的本质**：主族被 ζ 的零点（½——）锁定——瞬态被 ζ 的极点（1——）吸引
5. X→0：ζ_X → e^{-1/X}（无零点——）——零点在有限 X "出生"
