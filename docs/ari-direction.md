## 核心构造
E(X) = (Ψ(X)−X)/X^{1/2}——归一化素数误差
尺度变换 X → X^a——模态 e^{(ρ−1/2)t}（t=logX——）→ e^{a(ρ−1/2)t}
尺度半群 T_a（T_aT_b = T_ab——）——组合律——非单显式公式

关键：第二独立条件 |F(ρ)|=1 联合 FE 配对锁 β=½
