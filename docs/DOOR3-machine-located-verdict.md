## §1 **机器**（三台，文献级 —— 这就是 Jensen 路线到 10¹⁷ 的引擎）
```
【Hermite–Poulain】若 f(x)=a₀+a₁x+…+aₙxⁿ **实根**、g 实根，则
     f(d/dx)g = a₀g + a₁g' + … + aₙg⁽ⁿ⁾  **实根** ✓    [Levin 1964; Obreschkoff 1963; Schur 1914; Brändén 2004 Thm 11]
     推论：**保持交错性**（f ⋈ g ⟹ φ(f) ⋈ φ(g)）✓；另有 M. Riesz 的"网格不减"结果 ✓
【Obreschkoff–Dedieu】f,g 首项正 ⟹ **实铅笔 {αf+βg} 全实根 ⟺ f,g 实根且互相交错** ✓    [Obreschkoff 1963; Dedieu 1992]
【Hermite–Kakeya–Obreschkoff】三者等价：①交错 ②∀a,b: ap+bq 实根 ③p+iq 为 H⁺/H⁻-稳定 ✓    [经典]
【Borcea–Brändén 分类】T 保持**实稳定** ⟺ ①Symb T 实稳定 ②Symb Tˣᶻ 实稳定 ③im T 是二维实稳定空间 ✓
     超越型：**T 保持实稳定 ⟺ 其超越符号 Ḡ_T(x,w)=T(e^{−z·w}) ∈ LP 类**（或取 −w）✓✓    [BB09]
     ⭐ 即：**"保持实根性" ⟺ "符号落在 Laguerre–Pólya 类"** —— 把"对所有输入检验"化为"检验一个通用对象" ✓
```

## §2 ⭐⭐ **应用到我们的对象**（推导）
```
我们的对象：Ξ(t) = 2∫₀^∞ Φ(u)cos(ut)du  =  核 𝒢(u):=Φ(|u|) 的余弦/Fourier 变换 ✓
把机器用于**平移不变算子** T_𝒢：其超越符号 = ∫𝒢(u)e^{−zu}du = ℒ[𝒢](z) **就是 Ξ 本身**（代入 z=it）✓✓
```
$$\boxed{\;T_{\mathcal G}\text{ 保持实根性}\iff \Xi\in\mathrm{LP}\iff \text{RH}\;}$$
```
（order ≤ 2 的整函数：零点全实 ⟺ 属 LP 类 ✓ ⟹ 该等价即 RH ✓）
⟹ **判决：机器天真应用 = 把 RH 换成"某算子保持实根性"，而该判据的"符号"就是 Ξ 本身 ✗**
   ⟹ **自我指涉，零增益** ✗✗（与"HP 算子存在⟺RH"同型 ✓）
```

## §3 ⭐ 但**生产性用法**在哪（门的位置！）
```
机器之所以对 **Jensen 多项式**有效，是因为那里是**多项式**：乘积/分解天然可用 ✓
关键是 LP 类与"保持"性质对**乘积封闭** ✓ ⟹ 惯用技术 = **把对象分解成若干"已知落在 LP"的因子，
再用 Asano 收缩/乘积封闭性合并** ✓✓（Lee–Yang 机器的标准手法）
⟹ 用于我们这里就要求：**核 𝒢 的变换能写成"乘积"** ✓
   而 Ξ = (初等因子) × ζ(s)，且 **ζ = ∏_p(1−p^{−s})^{−1}** ✓✓ —— 乘积结构【在算术侧】 ✓
   但 **Euler 积在 σ ≤ 1 发散** ✗ ⟹ 无法把"ζ 的欧拉乘积"翻译成"核侧 LP 因子的乘积" ✓
⟹✓ **门 ③ 的精确位置 = "核侧的乘法分解"** —— 而这就是我们登记过的
   **char 0「算术窗口 vs 临界带」断裂 / 元素化缺口** ✓✓（同一堵墙的另一面 ✓）
```
