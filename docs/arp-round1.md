# ARP 首轮测试——gcd/lcm/整除/互素 关系矩阵（判死倾向——）

> 2026-09-07 17:30 · 唐先生"算术关系正性"框架首代测试

## 对象（唐先生原型——最简——）
G_s(m,n) = Σ_{d|gcd(m,n)} w(d)·(d/√(mn))^{s−1/2}

## 预分析发现（关键——对角化——）
设 m=da, n=db——(d/√(mn))^{s−½} = (ab)^{−(s−½)/2}——**与 d 无关**（消去——）
⟹ G_s(m,n) = (mn)^{−α}·F(gcd(m,n))——α = (s−½)/2——F = f*1——f(d) = w(d)d^{2α}
**Möbius 对角化**：c*G_s c = Σ_d w(d)d^{2α}·|Σ_{dk≤N}c_{dk}(dk)^{−α}|²（数值验证——差 7e-15——）

## 测试结果
### gcd 版（w=1——）
- s 实（t=0）：**正性对所有 σ ∈ [0.3, 1.2] 成立**（λ_min > 0——）——σ 无关
- s 复（t≠0）：二次型复值（非 Hermitian——）——Hermitian 化后负

### 整除矩阵 D(m,n) = 1[m|n]
- 对角全 1——三角——特征值全 1——正定**平凡**（无信息——）

### 互素矩阵 C(m,n) = 1[gcd=1]
- 特征值 min −6.7（负——）——非正定——且与 s 无关

### lcm 版
- 与 gcd 版同构（d|gcd 结构——）

## 判死判定：❌ 首代 ARP（最简关系——）触发线 8
**gcd 版对角化后 = 正系数型**：正性完全来自 w(d) ≥ 0（=1——）——与 σ 无关
- 无 σ = ½ 刚性边界
- **= IV-D 失败（正系数管不到 σ——）的矩阵版**
- "因子化成普通 Dirichlet 正性"——判死线 8 触发

## 结构观察
- 整除矩阵：平凡正定（对角占优——）
- 互素矩阵：非正定（负特征值——）
- **最简算术关系（gcd/lcm/整除/互素——）的矩阵正性——要么平凡要么与 σ 无关——要么不成立**

## 未测（唐先生的一般原型——）
G_s(m,n) = Σ_{d|(m,n)} w_d·χ_s(m/d, n/d)——χ_s **二元角色**（非因子化 (d/√mn)^{s−½}——）
- 若 χ_s 因子化——退回 gcd 版（死——）
- 若 χ_s 不因子化——可能不同——但有 Hecke/自守伪装风险
