## §1 A2 字典 · 四槽逐行核验（✓✓）

```
【设定（乙-2）】 Target := "1 ∈ M"（即 p = a²+b²）；X := {(a,b,m) : m ≥ 1, a²+b² = mp}；
   P((a,b,m)) := [m > 1]；μ := m；h : ¬Target ✓
```
| 槽 ✓ | 逐行内容 ✓ | 标注 ✓ |
|---|---|---|
| **C** ✓ | ① p ≡ 1 (4) ⟹ ∃x: x² ≡ −1 (mod p)（**Wilson/Euler 判别法**，由**假设**推得，LOCAL）✓；② 鸽笼：对 {(a,b) : 0 ≤ a,b ≤ ⌊√p⌋} 得两对不同余 ⟹ 差 (α,β) ≠ 0、**\|α\|,\|β\| ≤ ⌊√p⌋**、α + βx ≡ 0 ⟹ **p \| α²+β²**；③ 故 α²+β² = mp 且 **m ≤ 2**（因 α²+β² ≤ 2p）✓；④ h 下 m ≠ 1（**m = 1 ⟹ a²+b² = p ⟹ Target**，与 h 矛盾 —— 此步仅用**Target 的定义**，**未假设** Target ✓✓）⟹ **B := 2** ✓ | **LOCAL** ✓（＋对 h 的**定义级**使用，非循环）✓✓ |
| **R** ✓ | raw((a,b,m)) := 带余除法 (a′,b′)，**\|a′\|,\|b′\| ≤ m/2**，a′ ≡ a、b′ ≡ b (mod m)（LOCAL 整数运算）✓；Q((a′,b′)) := [**m \| a′²+b′²** ∧ (a′,b′) ≠ (0,0)]：<br>· 整除：a′²+b′² ≡ a²+b² ≡ 0 (mod m) ✓ LOCAL<br>· 非零：若 a′ = b′ = 0 ⟹ m \| a, m \| b ⟹ **m² \| a²+b² = mp** ⟹ **m \| p** ⟹ m ∈ {1,p}；而由 ③ **m ≤ 2 < p**（p > 3 ✓）⟹ m = 1 ⟹ **a²+b² = p ⟹ Target** ⟹ 与 h 矛盾 ✓（**用 h 排除 m = 1 分支** ✓，未假设 Target ✓✓） | **LOCAL / TARGET-DEPENDENT** ✓✓ |
| **D** ✓ | m′ := (a′²+b′²)/m ⟹ **m′ ≤ (m²/2)/m = m/2 < m** ✓（纯算术，m ≥ 1 ⟹ m > 1 在 P 情形 ✓） | **LOCAL** ✓✓ |
| **K** ✓ | reenter := **Brahmagupta 组合**：A := (aa′+bb′)/m、B := (ab′−a′b)/m ✓<br>· 良定义：**m \| (aa′+bb′)**、**m \| (ab′−a′b)**（由 a≡a′, b≡b′ ✓）LOCAL ✓<br>· **A² + B² = p·m′**：展开 Brahmagupta 恒等式 (a²+b²)(a′²+b′²) = (aa′+bb′)² + (ab′−a′b)² ＝ m²·p·m′ ✓ ⟹ 除以 m² ✓ LOCAL ✓✓<br>· `reenter_P`：**m′ > 1**，即 **m′ ≠ 1**；**`derive_Target`（分离）**：**m′ = 1 ⟹ A²+B² = p·1 = p**（**A2 恒等式** ✓）⟹ **p 为两平方和 ⟹ Target**（**Target 的定义** ✓）—— ⭐ **全程未假设 Target** ✓✓ | **LOCAL / TARGET-DEPENDENT** ✓✓ |

```
【⭐ 重点一之结论（照录要求）】
   `derive_Target`：**m′ = 1 ⟹ Target** 的证明链 = **① A2 恒等式 A²+B² = p·m′（LOCAL）**
```
