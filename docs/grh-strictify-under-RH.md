## 预备：判据机制 M（a1-a5——无条件已严格——）

  D_F = Q_F − Q'_RH,F = Σ_{轨道} m_ρ P_γ(δ_ρ) ≥ 0

计数——）——M 对 ζ 和所有 L(s,χ) 是【同一个机制】——同一证明——

## 推导

### 第 1 步（RH 的判据形式——）
RH 成立 ⟹ ζ 的全部零点在线 ⟹（M 定理——）D_ζ = 0。
【直接——δ_ρ=0 代入——P_γ(0)=0（代数——）——D_ζ = Σm_ρP_γ(0) = 0——】

### 第 2 步（机制的统一应用——）
M 对任意 FE 类对象 F 给出：D_F = 0 ⟺ F 零点全在线。
L(s,χ) 是 FE 类对象（a1——FE + Hadamard + 计数——验证过——）：
  D_χ = 0 ⟺ L(s,χ) 的全部零点在线（——GRH_χ——）

### 第 3 步（RH 假设的机制含义——）

是 M 对"FE 类结构"的输出——而 L(s,χ) 与 ζ 共享同一 FE 类结构——
——M 对同一结构的输出一致——
⟹ M 对 L(s,χ) 的输出同为"在线"——D_χ = 0

### 第 4 步（结论——）
D_χ = 0 ⟹（M 定理——）L(s,χ) 零点全在线——GRH_χ。
对所有原字符 χ——GRH。∎
