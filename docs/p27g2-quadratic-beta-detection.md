# P27-G2：Quadratic β-Detection——纯解析三计算

> 2026-09-01 · 唐先生 P27-G2 指令 · 纯解析（无数值）· 三计算

## 计算 (1)：D_δ 的二阶展开——L_f(γ) 精确表达
**D_δ(f;γ) = δ²·L_f(γ) + O(δ⁴)**——**L_f(γ) = 2∫e^{u/2}u²cos(γu)dμ(u)**
- cosh(δu)−1 = δ²u²/2 + δ⁴u⁴/24 + ...
- L_f 符号不定（cos(γu) 振荡——u²e^{u/2} 权重——"对所有 γ 正"不可能）
- 单零点二阶系数不自动正

## 计算 (2)：⭐⭐ 双线性版本——变量分离（核心发现）
**D_δ(f,ḡ;γ) = 4∫∫e^{(u+v)/2}cos(γ(u−v))[cosh(δ(u+v))−1]dμ_f(u)dμ_ḡ(v)̄**
（配对 O_δ(f,ḡ;γ) = Σ_orbit f(ρ')·conj(ḡ(ρ'))——指数表示——轨道配对）

**⭐⭐ 关键结构——变量分离**：
- **δ 只出现在"和"（u+v）**——cosh(δ(u+v))−1
- **γ 只出现在"差"（u−v）**——cos(γ(u−v))
- **"β 信息"（δ——u+v 通道）与"γ 相位"（u−v 通道）分离**——δ 不被 γ 振荡"洗掉"

## 计算 (3)：缺陷 Gram——δ 的可判别信息
- 纯 Gram（排除——唐先生红线）：G_jk = Σf̂_j(ρ)f̂_k(ρ)̄——自动 ⪰ 0——无判别力
- **缺陷 Gram**：G_jk = Σ_ρ D_{δ_ρ}(f_j, f̄_k;γ_ρ)——含 δ（u+v）——含 γ（u−v）
  - **G = 0 ⟺ 全部在线**（在线 D_δ=0——离轴 D_δ≠0）——G 检测离轴
  - 但 G 符号不定（cos(γ(u−v)) 振荡）——"G ⪰ 0 ⟺ RH"未定

## ⭐ G2 第一轮判定（纯解析）
- **G2.1（非退化）**——D_δ ≠ 0（δ≠0——一般 f）——大概率 ✓
- **G2.2（可分离）**——**变量分离——δ 在 u+v 通道——可识别——✓ 希望**（δ 不被 γ 洗掉——不同变量）
- **G2.3（RH 检测）**——G 的负方向（离轴 ⟹ G ⋡ 0）——**开放**——cos(γ(u−v)) 振荡——需要"相位消除"（phase averaging——唐先生方向）或"Gram 负方向"分析

## 核心发现
- **变量分离**（δ 在 u+v——γ 在 u−v）——是"β 可判别性"的关键结构——δ 信息不被 γ 相位洗掉
- 缺陷 Gram（G=0 ⟺ 全部在线）——离轴检测的候选——但符号/正半定性未定
