## 1. 主项引理（严格可证——无条件）

**引理 1**: 设 γ₁ 为第一零点虚部（14.1347），则 k→∞ 时

$$\sum_\rho \frac{1}{(\rho-\tfrac12)^k} = \frac{2(-1)^{k/2}}{\gamma_1^k}\left(1+o(1)\right)$$

*证明框架*:
1. 对所有零点 |ρ−½| ≥ γ₁（γ≥γ₁——零点虚部排序——N(γ₁)=1）
2. 第一零点共轭对: 1/(ρ₁−½)^k + 1/(ρ̄₁−½)^k = 2(−1)^{k/2}γ₁^{−k}（若 β₁=½——见引理 2）
3. 高阶零点: Σ_{ρ≠ρ₁,ρ̄₁} 1/(ρ−½)^k = O(γ₂^{1−k}·log γ₂)（零点密度 N(T) ~ (T/2π)log T——积分估计）——与 γ₁^{−k} 之比 = O(γ₂·(γ₁/γ₂)^k·log) → 0（γ₁/γ₂ = 0.672——指数压制）
4. 数值确认: 比例 k=20 时 0.0004 ✓

**注**: 若 β₁≠½——主项相位漂移（arg((β₁−½)+iγ₁)^k）——交替性破坏。数值: β₁=0.6 时主项模几乎不变（|ρ₁−½|≈γ₁）但相位偏移。

## 2. 交替性引理（锚点——第一零点）

**引理 2**: a_k 的交替性（符号 = (−1)^{k/2}——数据确认到 2e-56 精度）⟺ 第一零点实部 β₁ = ½

*证明*: 引理 1 的主项 = (1/k)·[1/(ρ₁−½)^k + 1/(ρ̄₁−½)^k]——纯实交替 ⟺ ρ₁−½ 纯虚 ⟺ β₁=½ ∎

**状态**: β₁=½ 是数值已知（Riemann 原始计算——第一零点 14.134725 在临界线——高精度验证）。"第一零点在临界线"本身是数学事实（可数值验证——但不是解析证明）。

## 3. 桥接（λ_n 重构——已验证）

**公式**: λ_n = (1/(n−1)!)·d^n/dz^n[(½+z)^{n−1}·Σ_k a_k z^k]|_{z=½}

莱布尼茨展开（数值实现——n≤50 验证——r(n)=O(1)）:
$$\lambda_n = \sum_k a_k \sum_{j=\max(0,n-k)}^{\min(n-1,k)} \binom{n}{j}\frac{(n-1)!}{(n-1-j)!}\frac{k!}{(k-n+j)!}\left(\tfrac12\right)^{k-n+j}\frac{1}{(n-1)!}$$

收敛: log ξ(½+z) 的收敛半径 = γ₁ ≈ 14.13 > ½——z=½ 在收敛域内——级数收敛（a_k 指数衰减）。

## 4. 完整渐近缺口（诚实——RH 深度）

**已严格**:
- 主项（引理 1——第一零点共轭对——交替性——无条件）
- λ_n 级数收敛（z=½ < γ₁）
- r(n)=O(1) 数值（n≤50——无消解——数据外）

**未严格（缺口）**:
- r(n)=O(1) 需要 λ_n 级数的**完整**渐近——不只是 a_k 的主项——还有 a_k 的**完整**渐近（所有 k——含振荡）
- rn-final-structure: r(n) = 常数部分（无条件 O(1)）+ 振荡剩余（= RH 深度——A_k 的反持久——相位均匀性）
- **振荡剩余在对称矩语言里** = Σ_k (a_k − a_k^{主项})·L(n,k)——a_k 的高阶修正（第二零点、第三零点……的贡献——非主项部分）
- 控制它 ⟺ 相位均匀性（所有零点 ρ−½ 纯虚——不是只有第一零点）⟺ RH
