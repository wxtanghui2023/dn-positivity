# PAPERA-EXPSUM:指数和 `|Σ_{γ≤T0} e^{i n θ(γ)}| ≤ (1-δ)(N(T0) - n B_{T0})` 的攻防(2026-09-12)

**对象** `S_n := Σ_{γ≤T0} e^{i n θ(γ)}`,`θ(t) = 2 arctan(1/(2t))`(与 `θ_γ = arg(1-1/ρ)` 逐位相同,见 round-2 §0)。
目标:存在 δ>0 使 `|S_n| ≤ (1-δ)(N - n B_{T0})` 对所有 `n ≤ T02` 成立;`N` = 实际零点数 2001052,`B_{T0} = (logT0+1)/(4πT0) = 1.049794e-6`,`allowance(T02) = 6.546544e5 = 0.3272 N`,`T0 = 1132490.658714`。
**脚本**(provenance 头 · 读 `data/` · 输出 `scripts/*.txt` · 未提交、未改他文件):
`scripts/PAPERA_expsum_nearfar.py → .txt`(硬产出 #1)、`scripts/PAPERA_expsum_routes.py → .txt`(路线甲/乙的显式数字)。

## 1. 硬产出 #1:近邻 vs 远距离的**数值判定**(结论:等分布,不是对相关)

恒等式 `|S_n|2 = N + 2Σ_{k<l} cos(n(θ_l-θ_k))`;按间距 `j = l-k` 分组,`A_j(n) := 2Σ_k cos(n(θ_{k+j}-θ_k))`,`P_tot := |S_n|2 - N = Σ_{j≥1} A_j`。`A_j` 直接求和,**远距离部分 = `P_tot - Σ_{j≤J}A_j` 为精确余项**(无近似)。`n = T02` 处实测:

| 量 | 值 | /N |
|---|---|---|
| `A_1`(近邻对) | **+7.0811e5** | **+0.354** |
| `Σ_{2≤j≤8} A_j` | -2.290e6 | -1.144 |
| `Σ_{j≤64} A_j` | -1.0976e6 | -0.549 |
| `Σ_{j≤2048} A_j` | -1.1007e6 | -0.550 |
| 远距离(`j>2048`) | -7.799e5 | -0.390 |
| `P_tot` | **-1.8806e6** | **-0.940** |

**判定:任务给的张力预设 (a) 在本 regime 不成立。** "近邻对每对贡献 +1、共 ~N 对"只在 `n·gap/γ2 ≪ 1`(即 `γ ≳ √(2πn/log) = 8.16e5`,**仅顶部 30% 零点**)时对;其余 70% 的近邻对相位已绕圈。实测**只有 `j=1` 是正的**(`+0.354N`,全部来自顶部 30% 的相干区,见 `.txt` 的按 γ 八度分箱表),而 `j≥2` 全部为负,**所需的大负质量散布在所有间距上**,不是"远距离专属"。=> **近邻(局部)结构给出的是 +0.35N 的正项,方向相反、量级也不够;真正给出 -0.94N 的是相位绕圈后的集体相消。**

**控制实验(同 N、同 n)**:iid 均匀相位模型 `P_tot = -9.04e5 ± 9.90e5`;打乱零点间距 `-9.73e5 ± 1.25e6`;**实际 -1.88e6**。三者在 `O(1)` 内同分布 ⟹ 该双和**统计上与"相位独立均匀"不可区分**,即相消来源是**相位序列的等分布(全局)**。
**结论(对任务提问的直接回答):正确的输入是 `{n θ(γ_k) mod 2π}` 的等分布(等价于 `S_n = o(N)` 的显式不一致性界);对相关(局部间距律)只控制 `A_1` 这一个(且是错误符号的)分离类,`|S_n|` 的值不依赖它。**
附注:`|S_n|2 ≈ N` 只是 Rayleigh 分布的**均值**量级(`|S|2/N` 实测散布 ±1);任务预设 (c) 中"配对和必须 ≈ -N/2"应读作 `O(N)` 的随机量,`n=T02` 恰好取到 -0.94N 属正常涨落。

## 2. 命题的精确形式:δ 的真值不是 O(1),约束点在 **n=1**,不在端点

按定义 `δ(n) := [(N - nB) - |S_n|]/(N - nB)` 直接扫描 549 个 n:

| n | 1 | 10 | 100 | 1e3 | 1e6 | 1e9 | 1e12 | T02 |
|---|---|---|---|---|---|---|---|---|
| `|S_n|/N` | 1.000000 | 0.999999 | 0.999971 | 0.999432 | 0.5717 | 0.001251 | 0.000383 | 0.000173 |
| `δ(n)` | **5.75e-9** | 5.68e-7 | 2.95e-5 | 5.68e-4 | 0.4283 | 0.99875 | 0.99920 | 0.99947 |

`min_n δ(n) = 5.7530e-9` **在 n=1**。⟹ 命题**为真**,但"绝对常数 δ"实际是 ≈6e-9,而非 `O(1)`;任务的"√N 余量"只在 `n ≫ 1` 成立(`n ≳ 1e6` 后 `δ ≈ 1`,端点余量 460×`√N`)。
**分裂**:(i) `n ≤ γ1 ≈ 14` 是**小相位 regime**(`nθ_γ ≤ 1`,用 `1-cos x ≥ x2/3` 得 `Σ(1-cos nθ_γ) ≥ n2Σθ_γ2/3 ≈ n2·0.0077 ≥ nB`,即 `n ≥ 1.4e-4`)--**可初等证明**(δ ~ 1e-9 量级);(ii) `14 < n ≤ T02` 才需要常数因子节省 `|S_n| ≤ cN`,数值上 `|S_n| ~ √N`。**任务真正未证的是 (ii)**(其中 `14 < n ≲ 300` 的 δ 仍只有 ~1e-4-1e-5,但比大 `n` 侧弱得多)。

## 3. 路线甲(等分布):唯一"可证/不可证"分割点被精确隔离

**分解**:`S_n = S_n^smooth + D_n`,`ĝ(k) := N̄^{-1}(k+1⁄2)`(`N̄(t)=(t/2π)log(t/2πe)+7/8`)。

**(甲-1) 光滑部分可证。** `max|γ_k - ĝ(k)| = 0.994`,`rms 0.188`(`O(1)`,即经典 `S(t)` 误差量级)。对光滑单调序列 `φ(k)=nθ(ĝ(k))` 用 **van der Corput 二阶导检验**(定理,常数待核):
`φ'(k) = -2πn/(γ2log(γ/2π))`,`φ''(k) = (2π/(γ log))(2-1/log)(2π/log)`;
共振点 `λ(γ_res)=1 ⟹ γ_res = 8.2683e5`,`M_B = 581491 (29.1%)`,`φ'' = 6.58e-7`,`√φ'' = 8.11e-4`:
`|S^smooth| ≤ M_B√φ'' + (φ'')^{-1/2} = 471.7 + 1232.7 = **1704** ≪ 6.55e5`(快区 `|φ'|≥1` 用一阶导检验,`Σ` 按 `λ` 二进壳求和 `= O(1)`)。
⟹ **光滑(平均密度)模型已经把 √N 相消证出来了**;`|S_n^smooth|` 实测 1.14e6/2373/1531/832,与 `|S_n|` 同量级。

**(甲-2) 唯一缺口 = 刚性误差 `D_n`,其显式恒等式(本文件新导出)**:
`D_n ≈ Σ_k (e^{i λ_k S_k} - 1) e^{i φ_k}`,其中 `λ_k := 2πn/(γ_k2log(γ_k/2π))`,`S_k := k - N̄(γ_k)`(零点计数函数的经典误差项)。
数值核对(`n=T02`):`|D_n| = 944`;模型 `|Σ(e^{iλ_k(S_k+a)}-1)e^{iφ_k}| = 816 (a=0) / 749 (a=1⁄2)` ✓ 同阶。
`S(t)` 的已知无条件信息只有 `S(t)=O(log t)`,代入得
`|D_n| ≤ 2N_A + (sup|S|)·Σ_B λ_k = 2.8391e6 + 14.0×4.1866e5 = **8.7e6**`,**超出额度 13.3 倍**(另:Erdős-Turán 的 k=1 项就是目标本身,循环,round-2 §4 已证)。
**缺的定理(一句话)**:需要对**所有 `n ≤ T02` 一致**的、定量"频域 Selberg 型"定理--即 `{λ(γ_k)S(γ_k)/2π}` 的等分布(等价 `Σ_k e^{iλ_k S_k}` 的显式上界),强度只需 `|D_n| = o(N)`(实测 ~√N)。
**更强输入**:文献现有三条都不够--`S(t)=O(log t)`(给 `O(N_A)`,差 13×)、Selberg CLT(测度式、**对 n 不一致**)、Montgomery/BGSTB 对相关(作用于**线性相位** `Σe^{iλγ}`,转成非线性相位代价 `e^{Θ(n)}`,round-2 §3)。**需要的不是更强,而是"更均匀"**:把 CLT 的 `n→∞` 换成 `n ≤ T02` 一致。

## 4. 路线乙(刚性):显式关系式 + 数字代入(**区域 B 差 1.5 倍,区域 A 无覆盖**)

离散 van der Corput 二阶差分检验(对**实际**序列 `φ(k)=nθ(γ_k)`):右端 `Λ := max_k |n(θ_{k+2} - 2θ_{k+1} + θ_k)|`,则
`|S_n^B| ≤ M_B √Λ + Λ^{-1/2}`,要求 `M_B√Λ ≤ (1-δ)(N-nB)`,即
`Λ ≤ ((1-δ)(N-nB)/M_B)2`;又 `Λ ≈ n·max|gap_{k+1}-gap_k| / γ2`。代入 `n=T02`:

- 阈值 `Λ ≤ 1.2663` ⟺ **`max|gap_{k+1}-gap_k| ≤ 0.675`(区域 B)**。
- 实测区域 B:`max|nΔ2θ| = 2.8442`(99.9% 分位 1.7644,中位 0.3226),`max|gap jump| = 1.6628`(rms 0.353)。
- `Λ = 2.8442 > 1.2663` ⟹ 界 `9.81e5 > 6.55e5`,**差 1.5 倍**(若用中位 `Λ = 0.32` 则 `3.30e5 < 6.55e5` ✓,但 max 才是合法输入)。
- **区域 A**(`γ < γ_res`,1.42e6 项):`max|nΔ2θ| = 1.9976e10`,二阶差分检验彻底失效(`M_A√Λ = 2.0e11`);一阶导检验要求 `f'` 单调,而实际增量 `= n·gap_k/γ_k2` 有 ~40% 间距噪声,**假设不成立**。

**结论**:路线乙只能覆盖区域 B,且需要一条**现有无条件文献没有**的刚性输入:间距跳变的上界 `|gap_{k+1}-gap_k| ≤ 0.675`(区域 B;等价 `Λ ≤ 1.27`)。区域 A 必须另想办法--而区域 A 的实测和只有 `|S_n^A| = 259`(`√M_A = 1191`),区域 B 只有 127(`√M_B = 763`),**两区都在 `√(计数)` 之下**,说明真实相消比任何现有工具都强。

## 对本项目的意义

1. **障碍被定位到一个可命名的算术对象**:大 `n` 侧唯一缺口是 `D_n = Σ_k(e^{iλ_k S_k}-1)e^{iφ_k}`,`S_k = k-N̄(γ_k)` 是零点计数的经典误差项。于是"二次范围 `n ≤ T02`"不再模糊,而是"**`S(t)` 的增量在频率 `λ=2πn/(γ2log)` 下的等分布**"这一条命题。
2. **对相关不是入口**:实测只有 `j=1` 的近邻项为正(+0.354N),方向与所需相反;`-0.94N` 的负质量散布在所有间距上,且与 iid 相位模型不可区分。若继续投对相关(BGSTB),救的是 `A_1`,救不了 `|S_n|`。**应改投 Selberg CLT 的"定量 + 一致"版本。**
3. **命题的 δ 不是常数级**:`δ_min = 5.75e-9`(在 `n=1`),端点处 δ≈0.9995。项目文档若写"余量 3000 倍"须注明这只在 `n ≳ 1e6` 成立;小 `n` 侧是初等的(`n ≤ γ1 ≈ 14` 可证),**不要把它当成 sqrt 缺口**。
4. **可直接写进论文的两个正面结果**：(i) 光滑模型 `|S^smooth| ≤ 1704`（vdC，显式，常数待核）；(ii) 小 `n` 区间（`n ≤ γ₁ ≈ 14`）`Σ(1−cos nθ_γ) ≥ nB` 初等可证。二者合起来把命题的“不可证部分”压缩到 `14 < n ≤ T₀²` 上的常数因子界。
5. **负面结果留档**:路线乙在区域 B 只差 1.5 倍(阈值 `max|gap jump| ≤ 0.675` vs 实测 1.663),且区域 A 完全无覆盖--**刚性路线的天花板就在这里**,除非另有一阶导检验的"非单调"版本。
6. **下一步最省力的入口**:把 `D_n` 的恒等式当作出发点,去找针对 `S(t)` 的**一致**(同时对所有频率 `λ ∈ [1, λ_max]`)显式界;文献里最接近的是 Selberg 1946 的 CLT 与零点计数误差 `S(t)` 的显式上界（如 Tsang 型结果，**出处未核验**），但都缺"一致于频率"。这是一条窄而明确的缝。
