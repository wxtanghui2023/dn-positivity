## 二、核心洞察：对称性给"谱对称"——从不给"零点在中心"

**QCD 的教训（物理通则——）**：
```
手征对称 {γ₅, D} = 0 ⟹ 谱 ±λ 对称——但——λ=0 可以没有本征值！
（对称相：无凝聚——ρ(0) = 0——谱 ±λ 成对但零点不在 0——）
零点(λ=0)在中心需要额外机制：
  (a) 拓扑：Atiyah-Singer 指标 ≠ 0（瞬子背景——）⟹ 必有零模
  (b) 凝聚：Banks-Casher——ρ(0) > 0（手征破缺相——谱密度在 0 堆积）
```

**ζ 的精确对应**：
```
FE（反射对称——）⟹ 零点 ρ ↔ 1−ρ̄ 成对——但——β=½ 可以没有零点！
（离轴配置：ρ=β+iγ 与 1−β+iγ 成对——跨 ½——但都不在 ½——完全合法——）
零点在 σ=½（RH——）需要额外机制——FE 本身不够！
```

**⟹ QCD 与 ζ 的困难同构**：物理中"对称性从不直接给中心零点"——QCD 需要拓扑荷或凝聚——ζ 需要"算术拓扑荷或算术凝聚"——**这是物理通则**（不是 ζ 特有——）。

## 三、为什么 QCD 成功而 ζ 失败（机制迁移的障碍）

QCD 的"中心零点"（零模——）机制：
1. **拓扑（Atiyah-Singer）**：背景有瞬子（拓扑荷——）→ 指标定理 → 零模存在
   - 迁移障碍：ζ 无"背景场"——素数结构不是"外部背景"——没有指标定理的输入
2. **凝聚（Banks-Casher）**：强耦合 → 有效势最小在破缺相 → ρ(0) > 0
   - 迁移障碍：需要"有效势"（可算——NJL/格点——）——ζ 无有效势（Euler 积 σ≤1 发散——）

**QCD 成功的根本原因**：有"耦合常数"（α_s——）——强耦合是"可调参数"——破缺发生在临界耦合
**ζ 的困境**：没有"可调参数"——ζ 是"唯一"的（没有家族/耦合——）——"独生子"（前一轮结论——）

## 四、最有价值的教训（如果 QCD 深挖要留下什么）

**"谱被迫在中心"在物理中总是需要二选一**：
1. **拓扑机制**（指标定理——）——零模存在性——来自"背景的拓扑荷"
2. **凝聚机制**（有效势——）——谱密度堆积——来自"相互作用的能量选择"

**ζ 需要对应物**：
1. ζ 的"背景拓扑荷"？（= L4 桥——算术体-边对应——未找到——）
2. ζ 的"有效势"？（= 我们的 P_γ/变分（D=ΣP_γ——）——但缺"可算性"——）

**我们的框架位置**：P_γ 缺陷能量（D=ΣP_γ ≥ 0——）已经是"凝聚/有效势"的尝试——它给出"离轴增加能量"（D≥0——）——像 QCD 的"破缺相能量不利"——但缺"为什么最小在 ½"（反向——）——像 QCD 缺"有效势完整计算"。
