## 2. Guth–Maynard 机制（✓ 精读所得 ✓）

```
【对象 ✓】D_N(t) = Σ_{N<n≤2N} b_n n^{it} ✓；W = [0,T] 中 1-分离点集 ✓，|D_N(t)| ≥ V ✓；问 |W| 上界 ✓
【GM 定理 ✓（Thm 7.4 ✓）】R ≤ T^{o(1)}( N²V^{−2} + **N^{18/5}V^{−4}** + T·N^{12/5}V^{−4} ) ✓
   对比 MHM（Thm 7.3 ✓）：R ≤ T^{o(1)}(N²V^{−2} + T·min{NV^{−2}, N⁴V^{−6}}) ✓
【适用区间 ✓】取 T^{5/(3+5σ)} ≤ N² ≤ T^{75(1−σ)/(54+30σ−100σ²)} ✓；
   在临界带 **7/10 ≤ σ ≤ 8/10** ✓ 中 N^{18/5}V^{−4} 主导 ⟹ **R₁ ≪ T^{15(1−σ)/(3+5σ)}** ✓
   区间外 ✓ 用经典估计 ✓ ⟹ 总 ⟹ **N(σ,T) ≪ T^{15(1−σ)/(3+5σ)+o(1)}** ✓
【统一形状 ✓】A(σ) = min{ 3/(2−σ) ✓, 15/(3+5σ) ✓ } ⟹ 在 σ = 7/10 相交 ⟹ **统一 A < 30/13 ≈ 2.308** ✓
   核对 ✓：σ = 1/2 ⟹ 2 ✓（Ingham 更优 ✓）；σ = 0.7 ⟹ 2.3077 ✓；σ = 0.8 ⟹ 2.143 ✓；σ → 1 ⟹ 15/8 = 1.875 ✓
【新意 ✓（两处）】(i) **TT\* 方法** ✓（估计 MM\* 的主特征值 ✓，用 W 与频率集的 Fourier 系数 ✓）；
   (ii) **加性能量** ✓ E(W) := #{w₁+w₂−w₃−w₄ ∈ (−1,1)} ✓ ⟹ 对大值集**结构**敏感 ✓（新维度 ✓）
【注意 ✓】全程 T^{o(1)} 型损失 ✓ ⟹ **按设计即非显式** ✗（这正是我们要评估的对象 ✓）
```

## 3. ⭐ 显式化 GM 的可行性评估（✓ 逐项 ✓）

```
【A ✓ 目标形状（明确 ✓）】
   N(σ,T) ≤ C·T^{15(1−σ)/(3+5σ)}·(log T)^{K} ✓ —— 对 **显式** C、K ✓ 与**显式**适用范围 ✓
   ＋ 分 σ 段（7/10 ≤ σ ≤ 8/10 ✓、σ ≤ 7/10 用 Thm 4.1 ✓、σ ≥ 8/10 ✓）
   ＋ 小 T 段（T < T₀ ✓）需**单独**显式处理 ✓（显式文献惯例 ✓：计算机核验 ✓）
【B ⚠️ 需要显式化的步骤（按难度分级 ✓）】
   ⭐ 易 ✓：(1) 离散均值定理（Gallagher ✓ Thm 7.1）—— 已有显式版 ✓（[IK04] Thm 9.4 型 ✓）可借
          (2) Littlewood 引理 / 截断显式公式 ✓ —— 显式文献已做 ✓（Kadiri ✓ 等）
          (3) Σ d(n)² ≪ x(log x)³ ✓（(31) ✓）—— 初等且可显式 ✓
   ⚠️ 中 ✓：(4) Type I/II 划分与计数 ✓（Montgomery 框架 ✓）—— 显式化可行但**繁琐** ✓
          (5) TT\* 的谱范数估计 ✓ —— **有限维线性代数** ✓ 原则上显式 ✓，
             但常数随**分解层数与维数**累积 ⚠️（可能很大 ✓ ⟹ 需跟踪 ✓）
   ✗ 难 ⚠️：(6) **几何/多项式划分与"蜂巢"型分解** ✓（GM 承自 Guth 的多项式方法 ✓）
             —— 这类分解**本质上产出未指定常数** ✗（依赖 ε-损失与覆盖论证 ✓）
             ⟹ 显式化需要**重做该几何步骤** ⚠️（最高风险项 ✓）
          (7) **加性能量分解** ✓（§7.3.2 ✓）—— 同上 ✓，且属**最新**技术 ✓ ⟹ 无先例可借 ✗
          (8) T^{o(1)} → (log T)^K ✓ —— 需查明 o(1) 的**每一处来源** ✓ 并给显式替代 ⚠️（工作量大 ✓）
【C ✓ 先例（判可行性用 ✓）】
   显式零密度已有 ✓：**Kadiri–Lumley–Ng** ✓（JMAA 465 (2018) 22–46 ✓："Ingham 1937 的 T^{(8/3)(1−σ)}(log T)^5
     的显式版并改进常数" ✓）；**Ramaré** ✓（Ramaré 的显式 Ingham 版 ✓）；**Simonič** ✓（σ 近 1 的显式改进 ✓）
   ⟹ ⭐ **可行性的关键证据 ✓**：既有显式结果**全部**基于**经典框架**（Littlewood + Gallagher + Halász ✓）
     ⟹ 它们是"**常数工程**" ✓ 而非"几何新法" ✗ ⟹ 因此**不能**直接借鉴来判定 GM 的 (6)(7) 两步 ⚠️
【D ⭐ 评估结论 ✓】
   · **可行性 ✓**：在"给足够人力与时间"的意义上**可行** ✓（形状清楚 ✓、多数步骤有先例 ✓）
   · **规模 ⚠️**：**月量级**投入 ✓；最大风险在 (6)(7)（几何/加性能量 ✗）—— 若这两步不可显式化，
     则只能得到"**弱化版**" ✓（例如只显式化 σ ≥ 3/4 段 ✓，或在**假定几何步常数**为小量的前提下 ✓）
   · **收益 ⚠️**：改进**显式**零密度 ✓ ⟹ 改进显式短区间素数结果 ✓；**但**：
     ⚠️ **不直接改进**我们论文 A ✗（其离轴项用**逐点**界 c_ρ ≤ 1/(2γ²) ✓，**不用零密度** ✓ —— 已核 ✗）
     ⚠️ **不直接改进** E46 ✗（素数侧二矩不用零密度 ✓）
     ⟹ 若要做 ✓，须**另设计一个"零密度为瓶颈"的场景** ⚠️（尚未设计 ✗）
   · **风险 ⚠️**：属"**已知缺口 × 高工作量 × 中等外部价值**" ✓ —— 唐先生的显式常数风格**对口** ✓，
     但**回报不确定** ⚠️（取决于是否有下游消费者 ✓）
```

## 4. ⭐ gap→RH 支线可否重开（✓ 判定 ✓）

```
【判定 ✗ **不建议现在重开** ✓（三条独立理由 ✓，均非"感觉" ✓）】
【理由 1 ✓ 方向】前沿工具**全部**是"零点 ⟹ 素数" ✓（零自由区 + 零密度 ⟹ 短区间 PNT ✓）；
   反向机器**不存在** ✓ ⟹ E47 的封口获**结构性确认** ✓✓
【理由 2 ⭐ 定量：平均/逐点价位差】✓
   GM 的 Corollary 4.1 ✓：逐点版 17/30 ✓ vs 平均版 **2/15 ≈ 0.133** ✓ —— 差 4 倍以上 ✓
   ⟹ 该技术的力量**结构性集中在平均层面** ✗；而 RH 的反例检测需要**逐点**（每个区间 ✓）
   ⟹ 想让 gap 命题排除离线零 ✓，必须付**逐点**价 ✓ —— 而 SOTA 的逐点指数**离 1/2 尚差 0.067** ✗
     （且 1/2 = 我们的临界尺度 ✓）
【理由 3 ✓ 我方独立结论】E47 §2 ✓：有限 M ⟹ 离线零对 √x 尺度贡献 = **o(√x)** ✓（数值 4.2e−3 → 6.3e−20 ✓）
   ⟹ **任何**"区间非空"型 gap 命题**无法区分**"有有限离线零"与"没有" ✓✓
   ＋ E47 §4 的铰链 ✓："一个离线零是否迫使离线谱**稠密增长**" ✗ —— **公开难题** ✓（现有工具全为上界型 ✗）
【⭐ 但留下一个【有依据】的开口 ✓（若将来重开，从此入手 ✓）】
   综述 §7.3.2 ✓ **作者自述** ✓：GM 方法对**大值集的结构**（加性能量 ✓）敏感 ✓，
     并明示"若 W 有结构（如等差 ✓）应可再改进" ✓
   ⟹ 类比到我们的场景 ✓：要检测离线零，需要的是**零集自身的加性能量** ✓（= 高阶对相关 ✓）
      —— 而我们的既有结论（E46/项目旧档 ✓）正是：**二阶可用、高阶缺** ✗ ⟹ 又回到同一堵墙 ✓
   ⟹ 故：**重开的必要条件 = 离线零密度的下界增长** ✓（铰链 ✗）或 **零集加性能量的无条件控制** ✗（高阶对相关 ✓）
      两者**目前都无门** ✓ ⟹ 结论 ✗ 现在不重开 ✓
```
