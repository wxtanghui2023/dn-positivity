## 1. 排除 1：函数型被迫等于 $\zeta$（✓ 初等、严格 ✓）

```
设极限程序输出 $F$，满足：(a) $F$ 在 $\sigma>1$ 上与 $\prod_p(1-p^{-s})^{-1}$ 一致 ✓；(b) $F$ 是解析的 ✓
⟹ **解析延拓唯一性**：$F=\zeta$ **恒等** ✓（在 $F$ 的解析域上 ✓）
⟹ $F$ 的零点集 ＝ $\zeta$ 的零点集 ✓ ⟹ **无新信息** ✗
⟹ ⭐ **故"换一个求和法"（Abel／Borel／Cesàro／Euler ✓）不会给出新载体** ✗ —— 它们都落在同一函数上 ✓
```

## 2. 排除 2：算子的**迹**就是 T1 的数据（✓ 强、可证 ✓）

$$\text{设 }T\ \text{canonical（由素数数据构造 ✓）且}\ \operatorname{Spec}(T)=\{\alpha_\rho\}\ \checkmark$$
$$\Longrightarrow\ \operatorname{Tr}(T^{n})=\sum_\rho\alpha_\rho^{n}\qquad\text{（幂和 ✓）}$$
$$\text{而零点的幂和恰由【Weil 显式公式】给出}\ \checkmark\ \Longrightarrow\ \boxed{\textbf{T 的痕量泛函 ＝ T1 的数据}}$$

```
⭐ **含义 ✓**：任何"谱＝零点"的 canonical 算子，其**可从外部读出的数据**（迹／矩／行列式 ✓）**就是显式公式** ✓
   ⟹ **它【不能】从这条路线获得新信息** ✗
⟹ ⭐ **故逃逸口唯一化** ✓：**算子必须由【直接构造】（不经迹／矩／行列式）给出，且其谱 provably ＝ \{\alpha_\rho\}** ✗
   —— **这就是 T5 的精确形式** ✓✓
⚠️ **注意 ✓**：此处**不是**说"算子不存在" ✗ —— 而是说"**经迹路线的算子不带来新信息**" ✓
   （经典类比 ✓：Hilbert–Pólya 若成功，其算子也该由直接构造给出 ✓，而非由迹反推 ✓）
```

## 3. 排除 3：稳定性（⚠️ 有前提，诚实标注 ✓）

$$C3\ \text{要求}\ |\alpha_{1/2+i\gamma}|=1\ \textbf{恰好}\ \checkmark\ \Longrightarrow\ \operatorname{Spec}(T)\subset S^{1}\ \text{（单位圆 ✓）}$$
```

⟹ 正规 ⟹ **谱定理** ⟹ 谱由**正测度**承载 ✓ ⟹ **落在 C4（非 HP/正性）之外** ✗
   或：该测度即**统计型数据** ✓ ⟹ 已被 **Lagarias–Rodgers** 排除 ✗（非零统计量与离轴相容 ✓）
⟹ ⭐ **故"恰好 $|\alpha|=1$"与"canonical"联合，把算子逼向正测度／统计型，两条路皆已排除** ✗✓
⚠️ **前提 ✓**：本条的"稳定"步是**原则**（canonical ⟹ 对扰动不敏感 ✓），**不是定理** ✗
```
