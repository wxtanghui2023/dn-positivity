```

    奇层：F_{2r+1}(σ,φ) := Σ_{j=1}^5 σ_j cos((2r+1)φ_j),   r = 0,...,12     （13 个频率）

    ∀ (φ, σ) with k >= 4 :   max_{0<=r<=12} |F_{2r+1}|  >  1/2                ✓
```
