## 1. 细节（✓）

```
【(1) Lipschitz ✓】dS_n/dn = Σ_γ iθ_γ e^{inθ_γ} ✓ ⟹ |dS/dn| ≤ Σθ_γ = **11.6377** ✓
   （θ_γ ≤ θ(14) = 0.0714 ✓ —— **压缩效应**的又一表现 ✓）
   数值验证 ✓：|S(n+h)−S(n)|/h = 0.000001 ~ 0.0590 ✓（≪ L ✓，界宽松但成立 ✓）
【(2) 为何不能界定最大值 ✓】若 |S| ≥ M ✓ 则 |S| ≥ M/2 在长 ≥ M/L 的区间上 ✓
   ⟹ 结合 Markov ⟹ M³ ≤ 4L·|I|·B ✓ ⟹ 数值 9.48e6 ✗（差 5.9 倍 ✗）
   ⭐ **根本原因 ✓**：这是"**测度 vs 高度**"的结构性差别 ✗ —— 与今日反复出现的"平均 vs 逐点"同源 ✓
【(4) 中间带为何可闭合 ✓】该带内 |φ′| ∈ [1, 11.1] ✓（每间隙推进 1~2π ✓）⟹ ∫|φ′|² ≈ 7.5e6~1.36e7 ✓
   ⟹ C–S = √(Selberg)·√(∫|φ′|²) = **1.06e6 ~ 1.43e6** ✓ < 1.6e6 ✓
【深快区为何不行 ✓】|φ′| ≥ 11 ✓（每间隙推进 ≫ 2π ✓）⟹ ∫|φ′|² 爆增 ✗（逐二进带 C–S 到最深带达 **1.1×10¹³** ✗）
   ⟹ C–S 无望 ✗；KL 需增量分数部远离整数 ✗（小块论证因"分数部之和 mod 1"失效 ✗）；vdC 见 ③ ✗
```
