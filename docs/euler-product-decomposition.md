## 1. 分解

$$\log \xi(s) = \underbrace{\left[\log\tfrac12 + \log(s-1) - \tfrac{s}{2}\log\pi + \log(s\cdot\Gamma(s/2))\right]}_{\Gamma\text{ 部分 } h(s)} + \underbrace{\log\zeta(s)}_{\zeta\text{ 部分}}$$

（log s 与 Γ 极点抵消，h(s) 在 s=0 解析）

系数：c_k = h_k + z_k（h_k = Γ 部分，z_k = log ζ 部分）

**验证**（围道积分，r=0.6）：h_k + z_k = c_k 已知（log ξ 系数），一致到 6 位 ✓

## 2. 核心结构（可靠确认，n=1..30）

$$\lambda_n = \lambda_n^\Gamma + \lambda_n^\zeta$$

| n | λ_n | λ_Γ | λ_ζ（ζ 部分）|
|---|---|---|---|
| 1 | +0.0231 | −1.47 | **+1.50** |
| 5 | +0.5755 | −123.7 | **+124.3** |
| 10 | +2.279 | −18118 | **+18121** |
| 20 | +8.769 | −3.31e8 | **+3.31e8** |
| 30 | +18.55 | −6.03e12 | **+6.03e12** |

**λ_ζ > 0 对所有 n=1..30 ✓，λ_Γ < 0 所有 n**——精确相消后 λ_n > 0。

## 3. 意义

1. **ζ 部分（Euler 积）恒正**——ζ 独有的输入（log ζ 解析延拓）确实是 λ_n 正性的来源
2. **DH 函数没有 Euler 积**——其 λ_n 失败（n=480 爆炸）与此一致
3. **方向正确**：Euler 积路径利用了 ζ 独有信息

## 4. 证明困难（诚实）

**灾难性抵消**：
- n=30: λ_ζ ~ 6.03e12, |λ_Γ| ~ 6.03e12, 差 = 18.55
- 证明 λ_ζ > |λ_Γ| 需要超高精度控制（相对精度 ~1e-12）
- **不比直接证明 λ_n > 0 容易**——Coffey (2005) 卡在类似困难
