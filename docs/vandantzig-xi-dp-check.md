# ξ ∈ D_P 数值检查——van Dantzig 路径堵死

> 2026-09-07 · 检查 Konstantopoulos-Patie-Sarkar (AIF 2024/arXiv:2211.16680) 的"ξ 属于 D_P 类吗？"问题
> 方法：数值计算 (4.16)-(4.18) 的 φ 序列——检查 Bernstein 型约束

## 背景
KPS 论文：RH ⟺ ξ ∈ D_L（LP 类——实零点——）——已知等价。他们构造 D_P ⊂ D（新解类——）——并问"ξ ∈ D_P 是否可能"（4.1 节——）——如果可能——给研究零点的新工具（Theorem 23——）。作者判断："not straightforward"——未定论。

## 我们的数值检查

### 公式（PDF 原文确认——）
```
F(n) = ∫₁^∞ (log x)ⁿ x^{−3/4} θ₀(x) dx——θ₀(x) = Σ_{n≥1} e^{−πn²x}
γ(n) = n!/(2n)!·(3/2)^{2n}·[F(2n−2) − F(2n)/2^{2n−1}]        (4.16)
ξ ∈ D_P ⟺ ∃φ ∈ BD: 1/W_φ(n+1) = (4.17) 右边
⟺ φ(n+1) = −G(2n)/(8(n+1)G(2n+2))——G(2n) = 64n(2n−1)F(2n−2)/F(2n) − 1   (4.18)
```

### 数值结果（mpmath 高精度——）
**F(n) > 0**（正确版——θ₀ 正——）：F(0)=0.0115——F(8)=1.5e-4（最小——）——F(40)=75.6（n 大时增长——）

**G(2n) > 0 且增长**：n=1: 744——n=18: 12310

**φ(n+1) 全负（n=1..18——一致——）**：
```
n=1:  −0.0392      n=7:  −0.0134     n=13: −0.00814
n=2:  −0.0296      n=8:  −0.0121     n=14: −0.00764
n=3:  −0.0239      n=9:  −0.0110     n=15: −0.00720
...                ...               n=18: −0.00613
```
比值 φ(n+1)/φ(n) ~ 0.93（趋 1——）——负值系统性（非数值误差——）

## 结论

### ξ ∉ D_P（数值强排除——）
- BD ⊂ Bernstein 函数（φ ≥ 0 在 [0,∞)——）
- (4.18) 在整数点给 φ(n+1) < 0（n=1..18——远离 0——）
- ⟹ 不存在 Bernstein φ 匹配 (4.17)——ξ ∉ D_P

### 稳健性
- G(2n) 只依赖 F 的**比值** F(2n−2)/F(2n)——归一化/整体符号不敏感
- 用 θ₀（正确——）与 θ₀'（OCR 误读——）都得到 φ < 0
- 负值深度（−0.04 到 −0.006——）远超数值误差

### 意义
1. **van Dantzig 的 D_P 路径对 RH 堵死**（ξ 不属于 D_P——Theorem 23 的工具用不上——）
2. **作者未注意到**（他们只说 "not straightforward"——未做数值检查——）
3. RH 仍等价于 ξ ∈ D_L（LP 类——）——D_P 是旁路——不通

## 边界
- 数值排除（n=1..18——）非无限证明——但负值系统性——极可能正确
- (4.18) 的推导（"easy algebra"）未逐行验证——假设其正确
- 即使 ξ ∉ D_P——D_P 类本身（Bessel/超几何——）仍是真实数学贡献
