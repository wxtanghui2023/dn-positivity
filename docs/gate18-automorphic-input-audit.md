## 1. 唯一的"ζ 作为因子"机制：诱导（非尖点）表示

$$\zeta=L(s,\pi_0),\quad \pi_0=\text{GL}(1)\ \text{平凡特征};\qquad
L(s,\operatorname{Ind}(\text{triv}))=\prod_i L(s,\chi_i)\ \ni\ \zeta$$

**关键分类**：
```
(1) π 是【尖点】(cuspidal, n≥2)：
    L(s,π) 整函数（无 ζ 因子）⟹ 零点集与 ζ 的零点【不相交】⟹ 【无传递】
(2) π 是【诱导/非尖点】：
    ζ 作为因子出现 ✓，但其余因子是 Hecke/Dedekind L 函数
    ⟹ 它们与 ζ 属【同一分析深度】（其 RH 即 GRH，地位等价）⟹ 非独立
```
$$\boxed{\text{⟹ 要么 ζ 不出现（尖点情形），要么出现的伴随因子与 ζ 同深度（诱导情形）}}$$

## 2. ⭐ 无增益原理（本关核心）

$$\boxed{\text{GRH（全部 Hecke 特征）【包含】ζ 的 RH 作为特例} \Longrightarrow \text{证明 GRH 不比证明 RH 更容易}}$$
即：高阶陈述是**包含**关系，不是**外部约束**关系。
$$\boxed{\text{高阶自守陈述}\ \supseteq\ \text{GL(1) 情形}\ \not\Rightarrow\ \text{对 GL(1) 的外部约束}}$$
