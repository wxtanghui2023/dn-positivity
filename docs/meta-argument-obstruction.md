## 目标
论证：任何"离轴零点 ⟹ 独立矛盾"（zero-blind——非循环——）必然落入三个已知障碍之一

## 支柱 1：P51-T4 逃逸 NO-GO（9/2——有限观测——）
**任何有限算术观测允许高零点离轴**（非紧致性——）
- 可观测带是紧的（x ≤ X——t ≤ logX——）
- 高频率零点（γ ≫ logX——）在窗口内平均掉——~ 1/γ 不可见
- ⟹ 有限观测不能排除高离轴——需要全局观测

## 支柱 2：反证法边界（8/23——全局观测——）
**全局观测（λ_n 全 n——）的离轴矛盾在 n ~ 2γ²/(1−2β)**
- 单离轴（有限——）需要 λ_n ≥ 0 到巨大 n——= Li = RH（循环——）
- 无穷多离轴：无条件排除 ✓（指数 vs 多项式——）
- ⟹ 全局观测的矛盾要么循环（单——）要么已排除（无穷多——）

## 支柱 3：尺寸无关性缺失（9/7——新——）
**离轴零点的效应随高度衰减**：
- 显式公式项 x^ρ/ρ：模 x^β/|ρ| ~ x^β/γ——γ 衰减
- λ_n：(1−1/ρ)^n——ε ~ (1−2β)/2γ²——~1/γ² 衰减——n ~ γ²/δ
- 矩 Σ1/ρ^k：~1/γ^k——衰减
- **FLT 类比要求"尺寸无关"矛盾**（Frey 曲线非法性不依赖反例大小——）
- 离轴零点无此性质（连续参数——效应随 γ 衰减——）
- ⟹ FLT 式固定层级矛盾不存在

## 三支柱合流
```
① 有限观测：高离轴不可见（逃逸——）
② 全局观测：单离轴矛盾循环（Li——）——无穷多已排除
③ 尺寸无关：FLT 式固定层级矛盾不存在（效应 ~ 1/γ 衰减——）
⟹ 任何"离轴 ⟹ 矛盾"：
   有限层级 → ①杀（不可见——）或 ③杀（无尺寸无关——）
   全局 → ②杀（循环——）或已排除（无穷多——）
```
