# 延拓刚性（Continuation Rigidity）第一关：纸面审计

**日期**：2026-09-10 ｜ 唐先生指定方向 ｜ 结果：congruence 类约束被 CRT 杀死；唯一逃生口 = size/product 约束

---

## 0. 方向设定（唐先生）

不寻找"产生相位的对象"，而寻找**禁止相位跨尺度自由漂移的延拓刚性**：
$$\mathscr A_X=\{\text{满足局部算术约束的全局延拓}\},\qquad \mathscr A_X\to\mathscr A_Y\ \text{的延拓关系}$$
与**保持全部局部边缘分布的 null 延拓树**比较；要求延拓数差**乘性累积**。

第一关（生死门）：
$$\boxed{\text{同一局部数据的多尺度延拓数}\ \ll\ \text{null 延拓数}\quad\text{且差异乘性累积？}}$$

---

## 1. 审计结论一：延拓树的分支二分（两档都死）

```
(a) 若约束系统包含完整算术（含"n 无小于 √n 的因子"）
    ⟹ 延拓被逐点确定 ⟹ 树只有【一条路径】⟹ 没有分支可供约束 ⟹ 命题退化

(b) 若约束仅为【有界描述】的局部数据（整除/同余类）
    ⟹ 树高度分支；而"保持同一局部边缘分布"的 null 模型
      按其构造【复现同样的分支数】⟹ 无乘性差 ⟹ 死
```
⟹ 第一关在两档下均不通过；需要一个**第三档**才可能成立。

## 2. 审计结论二：信息墙重现

有界局部数据只携带 $\log\log x$ 比特（Mertens，见 FPCA）；
而未来配置携带 $(x/\log x)\log\log x$ 比特。
⟹ 想得到**乘性累积的延拓压缩**，所需信息远超局部数据所能提供 ⟹ 对 congruence 类系统【不可能】。

## 3. 审计结论三（本轮关键）：frustration / 障碍路线被 CRT 杀死

延拓刚性若想非平凡，必须来自**过定**（frustration）：局部可行但全局不相容。
$$\boxed{\text{整除型局部约束满足【局部–全局原理】：CRT 使局部配置总能拼成全局}}$$
⟹ 解空间是局部解空间之**积** ⟹ 延拓数**可分解** ⟹ 无乘性差。

$$\boxed{\text{⟹ 一切基于同余/整除的"跨尺度兼容"系统【结构性无刚性】}}$$

## 4. 唯一逃生口：非同余约束 = size / product 约束

要让局部–全局原理失效，约束必须**不是同余型**。$(\mathbb Z,+,\times)$ 中唯一的非同一类约束是
$$\boxed{\text{乘法与大小的交互}：\ n=ab\ \text{同时锁定了 }a,b\ \text{的大小}}$$
而这类约束的**典范自对偶结构正是除子的 $\sqrt n$ 配对**（$d\leftrightarrow n/d$，双曲方法）。
$$\boxed{\sqrt{\ }\text{-障碍、以及自然的 }1/2\text{，住在这里}}$$

**注意**：这**不是**人为放入 $1/2$——它是"乘积=大小"这一约束的必然自对偶，属结构性来源。

## 5. 第一关的裁决

```
congruence / 整除 / CRT 类约束系统  : 【立即 NO-GO】（局部–全局原理 ⟹ 无 frustration）
size / product 交互类约束           : 【唯一未被关闭的约束类】——需单独审计
```

⟹ 你提的"延拓刚性"方向，**作为一个约束类是可存活的，但必须换基底**：
从同余基底换到 **size/product 基底**。

## 6. 下一关（纸面，仍不写程序）

$$\boxed{\text{以乘积–大小约束（除子 }\sqrt n\text{ 自对偶）为基底的局部约束系统，
其跨尺度延拓是否出现【乘性】压缩？}}$$
需先回答：该约束类的"局部–全局原理"是否失效（即是否存在 frustration）。
若仍满足局部–全局 ⟹ 同样死；若不满足 ⟹ 第一次有了真正的候选约束类。
