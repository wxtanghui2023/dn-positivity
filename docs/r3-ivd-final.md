# R3-IV-D 终审——正系数 Dirichlet/Mellin（最后保留方向——）

> 2026-09-07 17:20 · 唐先生：IV-A/B/C 关闭——IV-D 终审一次——失败则 IV 整类封口

## IV-D 对象
F(s) = Σa_n n^{−s}——a_n ≥ 0——算术原生（整数/素数定义——）——正性 + 天然复变量

## 终审问题（唐先生第一死亡测试——）
**a_n ≥ 0（正系数）本身能否对零点实部产生约束？**

## 分析——正系数给什么？

### 1. Landau 定理（经典——）
a_n ≥ 0 ⟹ F 在收敛轴 σ = σ₀ 有奇点
- 约束的是**收敛轴**（奇点位置——）
- ζ：收敛轴 σ=1——奇点（极点——）✓——但零点在 σ=½（延拓区——）

### 2. 关键结构事实：正系数管不到延拓零点
- 正系数级数 Σa_n n^{−s} 只在收敛半平面 Re s > σ₀ 定义
- **零点在带内（延拓区——σ₀−c < Re < σ₀——）——正系数看不到**
- ζ 实例：系数全 1（正——）——RH 未证——正系数与任意零点位置相容
- **正系数给收敛域行为——不给延拓零点——除非 FE 把带内映回收敛区——**

### 3. 正系数 + 函数方程（自对偶——）
- 自对偶正系数 L 函数（ζ——模 L——）= GRH 对象本身
- 问"正系数自对偶 L 的零点是否在线" = 问 GRH——循环
- 正系数没加新约束（ζ 就是反例——正系数 + RH 开放——）

### 4. 已知反例/边界（文献——）
- 1/ζ(s) = Σμ(n)/n^s——系数变号——极点 = ζ 零点——无正系数版本
- η(s) = Σ(−1)^{n+1}/n^s——交替——(1−2^{1−s})ζ——非正——零点同 ζ（带内——）
- **正系数的"零点自由区"定理只给收敛轴附近——非临界线**

## 终审判定：❌ IV-D 失败——IV 整类封口
**正系数不给 Re ρ = ½ 约束**：
- 正系数约束收敛半平面（σ > σ₀——Landau——）
- 零点在延拓区（带内——）——正系数结构性看不到
- 正系数 + FE = 自对偶 L = GRH 本身（循环——）
- **"算术原生正系数"是强的收敛性工具——不是零点定位工具**

## 阶段结论（唐先生框架——）
```
实矩（IV-A）→ 无复桥——关闭
零点矩（IV-B）→ 读出——关闭
显式公式矩（IV-C）→ C/III 重包装——关闭
正系数 Dirichlet（IV-D）→ 无 support rigidity——关闭
⟹ R3 剩余：某种尚未发现的算术刚性机制（非矩类——）
```

## 元观察（诚实——）
IV-D 的失败与 V（de Branges——）同构：
- V：解析正性（ζ 的连续值——）自由度太大（log ζ 稠密——）
- IV-D：算术正性（系数——）约束太弱（管不到延拓零点——）
- **两极之间缺"带算术刚性的复结构"**——正性要么太自由（解析——）要么太弱（算术——）——R3 需要的是第三种
