## §2 ⭐ **五条具体原因（按影响力排序）**

### 原因 1（决定性）⭐ **我们把主项扔掉了，用了比它弱得多的窗口** ✗
```
他们：主项 ½n log n **主动压过**误差 ⟹ 范围只受【输入】限制（T=√n ⟹ T²）✓✓
我们：把在线项只当"≥0"用 ✗ ⟹ **等于把主项归零** ⟹ 剩下的正性只来自窗口的一小段 ✗
   ⟹ 窗口必须落在 [0,T] 内 ⟹ **n ≤ T** ⟹ 这就是"线性"的全部来源 ✗✗
【量级】**我们主动放弃了 ~T 倍的因子**（T² vs T ✓）
```
### 原因 2 ⚠️ **我们手里有对的引擎，却没有用它** ✗
```
我方文件 `docs/READSUM-Li-line-structures.md` ✓ **已经记录了 B–L 的显式公式**：
   λ_n = −Σ_{j=1}^n C(n,j)η_{j−1} + 1 − (γ₀+log4π)(n/2) − Σ C(n,j)(−1)^{j−1}(1−2^{−j})ζ(j) ✓
   且 **2λ_n = W(g_n ∗ x^{−1} \overline{g_n(x^{−1})})**（W = Weil 分布 ✓）
⟹ **这正是"算术分解"那台引擎** ✓✓ —— 我们**读到了、记录了、然后没用来做范围** ✗✗
   （而是另起了一套相位+窗口的论证 ✗ —— 这就是"重造一个更弱的轮子" ✓）
```
### 原因 3 ⚠️ **我们识别了正确的标度，却没把论证建在它上面** ✗
```
我方 DOOR1 已测出 **检测阈值 n* ≈ 6.6γ²/|2δ|** ✓（**这正是 T² 的机制** ✓）
⟹ 我们**知道**标度是 γ²（⟹ T² ✓），却用窗口论证推出**线性**范围 ✗
   —— 即：**知道钥匙，没用钥匙** ✓
```
### 原因 4 ⚠️ **我们自我设限了目标**（"初等/干净"）✗
```
我们的目标措辞："**初等**四引理证明" ✗ —— 而真实结果需要：
```
