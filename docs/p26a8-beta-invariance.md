# P26-A8：β 的变形不变性——Re δ_ρ = 0（严格——无条件）

> 2026-09-01 · 继续 Level III · 变形-零点耦合深化

## P26-A8 结果

### ① 核心推导——FE + 实系数 ⟹ c_ρ 纯虚
- M_b = Σ b_p/(p^s−1)——b_p 实——M_b 实系数（M_b(s̄) = conj(M_b(s))）——留数 c_ρ̄ = conj(c_ρ)
- FE（M_b(s) = M_b(1−s)）：留数反号 c_ρ̄ = −c_ρ
- **conj(c_ρ) = −c_ρ ⟹ c_ρ 纯虚 ⟹ δ_ρ = −c_ρ 纯虚——Re δ_ρ = 0——β（零点实部）一阶不变**

### ② 二阶归纳——β 完全不变
- F_t 零点（二阶）：ρ + tδ_ρ + t²ε_ρ——FE（ρ̄−tδ_ρ−t²ε_ρ）+ 共轭（ρ̄−tδ_ρ+t²conj(ε_ρ)）——同一零点——**Re ε_ρ = 0**
- 归纳（所有阶）——**β 完全不变（变形下）——β 是变形不变量（实 b_p——FE——无条件——不需要 RH）**

### ③ 数值验证
- M_b(0.6+14.1i) = −3.0956−0.3697i = conj(M_b(0.6−14.1i))——实系数 ✓

### ④⑤ ⚠️ 诚实判断
- **"β 不变"≠"β = ½"（RH）**——离轴 β ≠ ½ 也可以是变形不动点（β 不动——但不等于 ½）——不是唯一
- **"β 规范"（唐先生最初的直觉——β 规范自由度——物理量 γ 可变形——β 规范不变量）**——严格化——但——"规范固定"（β = ½）需要额外机制——未找到
- **复 b_p**：共轭不适用（复系数）——只有 FE（c_ρ̄ = −c_ρ）——c_ρ 任意复——δ_ρ 任意——β 可移动（复 b_p）——区分（唐先生的分叉）

## ⭐ P26-A8 判定
- **β 的变形不变性（实 b_p——FE——严格——无条件——所有阶）**——变形-零点耦合的精确形态
- **但——β 不变 ≠ β = ½**——"β 规范"未固定——离轴 β 也是不动点
- **复 b_p**：β 可移动——FE 约束（c_ρ̄ = −c_ρ——复）——未探索
