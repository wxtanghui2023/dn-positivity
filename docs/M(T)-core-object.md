# M(T)=O(1) 核心对象——精确化（2026-09-08 18:45）

## 关键澄清（修正之前的层次错误——）

**e_k（零点处 S——）不是 M 的来源**：
- S(γ_k) 右极限 mean = +½（理论——）——左极限 mean = −½
- 零点处的 S 有 ±½ 的跳跃偏差——Σe_k 发散（非 M——）

**正确的对象：区间平均 S**：
- S̄_k = 区间 (γ_k, γ_{k+1}) 内 S 的平均 ≈ (S(γ_k^右)+S(γ_{k+1}^左))/2
- **mean(S̄_k) = +0.000007 ≈ 0**（零均值！——）
- M 增量 = ∫_{γ_k}^{γ_{k+1}}S = S̄_k·Δγ_k（近似——）

## 核心命题（精确——）

$$
M(T) = O(1) \iff \sum_k \bar{S}_k \cdot \Delta\gamma_k = O(1)
$$
- S̄_k = 区间平均 S——零均值
- 数值验证：M 增量累积 max = 0.767——与精确 M 完美匹配 ✓

## S̄_k 的结构（数值——）
- mean ≈ 0——std = 0.24
- 自相关：ρ(1) = +0.54（正相邻——平滑——）——ρ(3) = −0.27——ρ(5) = −0.34
- **波包振荡**（不是白噪声——不是简单反持久——）
- 随机游走预期 max|M| ~ 50（0.16·√10^5——）——实际 0.77——**强相消 65 倍**

## 为什么强相消？（开放——）
- S̄ 的波包结构（正相邻 + 长程交替——）→ 累积有界？
- 机制未明——这是 M(T)=O(1) 的核心（= Lindelöf 级——）
