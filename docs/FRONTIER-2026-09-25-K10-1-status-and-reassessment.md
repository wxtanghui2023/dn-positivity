# FRONTIER-2026-09-25 · K(10,1) 前沿现状 ＋ 本线得失复盘

## §1 前沿现状（权威快照）

```
a(10) = K(10,1) = γ(Q₁₀) ∈ [107, 120]        （OEIS A000983，Zabolotskiy 2016；下界 107 出自 Bertolo–Östergård–Weakley 2004）
```

- **上界 120**：Kamenetsky 构造（非线性 120 词码），长期未被改进。
- **下界 107**：出自 *mixed binary/ternary covering codes* 表（2004）⟹ 属**混合码/球覆盖型**方法，非邻域枚举。
- **权威表**：Kerri 覆盖码界表（`old.sztaki.hu/~keri/codes/`，n ≤ 33, R ≤ 10）——领域内标准引用源。
- **该格状态**：**停滞约 13 年**（下界 2004、上界约 2010 后未动），是典型的"硬而停滞"格。

## §2 前沿在攻什么（本轮检索结论）

1. **上界（构造）**：主活跃线。
   - arXiv:2409.14621（2024-09）"New Upper Bounds on the Minimal Domination Numbers of High-Dimensional Hypercubes"：方法 = 利用 $\mathbb F_2$-线性映射 + "domination wedge" 递归 ⟹ 面向**高维**（n 大）整体改进；自评"离证明 Conjecture 还远"。
   - 小 n（≤9）的历史记录来自**穷举/局部搜索**（Honkala–Östergård《Code design》章）。
2. **下界（解析/LP）**：改进球覆盖界（Chen–Honkala 型），以及混合码表（2004）。
3. **关键观察**：**没有任何人把它当"不可能性定理"来攻** —— 领域标准是**界**（bound），不是结构定理。
   ⟹ 我们今日攻的"证明不存在 119"（**全局不可能性**）**不是**该领域的问题形态 ✗。

## §3 一个重要结构事实（解释该格为何停滞）

```
线性码大小必为 2^k：n=10 时 2⁶=64 < 107（违反下界，不可能覆盖）⟹ 下一档 2⁷=128
```
⟹ **任何 ≤127 的改进（含 119）必然是\*\*非线性\*\*的** ✓
⟹ 纯线性构造路线在 107–127 区间**本质不可达** ⟹ 这正是该格长期停滞的结构原因 ✓
（注：2⁷=128 是否为可用线性码，需查 Kerri 表的"best known linear covering codes"分表核验——**待核**，本档不假设。）
