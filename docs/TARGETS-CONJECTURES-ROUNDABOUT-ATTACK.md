```

迂回路线（先例已走过）：
  ① 矩路线：  Σ_{n≤T}|ζ(1/2+it)|^{2k} ≪ T^{1+ε} （对所有 k）⟹ LH  —— Keating–Snaith 猜想；Conrey–Gonek 长 Dirichlet 多项式法

  ③ 谐振法（Soundararajan）：给【下界】——反向杠杆
  ④ 大值/密度法：与 T2 联合
我方对应工具：
  · 幂和极值分析（(RP_M) 即 "Re Σ z_j^n" 型）—— 与"长 Dirichlet 多项式"同构 ✓
  · 区间算术证书 ✓ —— 可把显式常数严格化
  · 计数＋整数性框架（`C-127`）
难度：长线（但**子目标可入门**：固定 k 的显式矩界；某个 t-区间的指数改进）
交付物：某区间/某 k 的显式界；或"数值断言 → 严格证书"
```
