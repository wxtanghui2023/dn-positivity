## §1 【外部·原文】**定义的精确形式**（这解决了我的困惑）
```
【PF 序列】"sequences a = (a_n)_{n∈ℤ}，使得对任意 l₁<…<l_n、m₁<…<m_n，det(a_{l_j−m_k}) ≥ 0。
   换言之，这是**双无限 Toeplitz 矩阵**，且总非负（TN）" ✓✓
   ⟹ **序列是双无限的（n ∈ ℤ）** ⟹ Toeplitz 阵**不是三角阵** ⟹ **TN 条件非平凡** ✓✓
【PF 函数】Λ: ℝ→ℝ 为 PF ⟺ (a) 可积 (b) 至少在两点非零 (c) **关联的 Toeplitz 核 T_Λ: (x,y)↦Λ(x−y) 为 TN** ✓
【TN_p / TP_p】只要求阶 ≤ p 时称 TN_p / TP_p ✓
【变差递减】TN 矩阵/核有变差递减性（Schoenberg 1930/1951）：A TN ⟹ S⁻(Ax) ≤ S⁻(x) ✓
【Pólya–Schur】Γ 是 k 类乘子序列 ⟺ 其生成函数 Ψ_Γ(t)=Σγ_j t^j/j! ∈ LP ⟺ **1/Ψ_Γ 是某个 PF 函数的 Laplace 变换** ✓
```

```

   · 我们的核公式 Ξ(t) = 2∫₀^∞Φ(u)cos(ut)du **复现了零点（7 位精确 ✓）**——零点对**整体标度不敏感** ✓
```
