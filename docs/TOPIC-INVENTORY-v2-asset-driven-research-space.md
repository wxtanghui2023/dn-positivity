## §3 类型层（`P1`–`P8`）

```
**【P1 认证/审计】** `D+H`（接 `A/C/G`）—— 照旧 ✓
**【P2 有限表/配置缺口】** `A+D` —— 照旧 ✓
**【P3 谱/惯性障碍】** `E+D` —— 照旧 ✓
**【P4 形式化/泛算法】** **REJECT** ✓
**【P5 混合约束/容量刚性】** $$B+C+D+G$$ ✓
　**形式**：`X\subseteq G` 同时满足 $$\mathcal A(X)\le A,\qquad \mathcal M(X)\le M$$ 研究 $$|X|\le F(A,M)$$ 或**容量阈值/刚性** ✓
　**要求**：**不是单纯 additive、也不是单纯 multiplicative，而是\textbf{两种结构同时作用产生新刚性}** ✓✓
　**候选域**：additive–multiplicative combinatorics；sum-product 型结构；multiplicative Sidon／additive Sidon 混合；zero-sum ＋ 乘法限制；incidence ＋ multiplicative energy；有限域混合约束极值；图/超图中同时含加法与乘法禁配条件 ✓
**【P6 最小反例/机制失效】** $$C+G+D+H$$ ✓
　**形式**：机制声称 $$P\Rightarrow Q$$，问它**在最小规模 `n_{\min}`／`X_{\min}` 处成立还是失效** ✓
　**要求（与普通 counterexample hunting 的区别）**：必须输出 $$\boxed{\text{failure mechanism}}\ \text{而非仅}\ \boxed{\text{counterexample}}$$ ✓✓
**【P7 结构定理的"失效边界"】** $$C+G+B+D+H$$（**用户判为最有潜力**）✓✓
　**形式**：已有 $$\mathcal C_k\Rightarrow P$$，问 $$\boxed{k\ \text{从哪里开始失效}}$$ ✓
　**要求**：$$\begin{cases}k<k_0\Rightarrow P\ \text{成立}\\ k=k_0\Rightarrow\textbf{新的 obstruction}\\ k\ge k_0\Rightarrow\textbf{系统性 failure}\end{cases}$$ ✓✓ —— **比"找一个未解决的整数值"更接近"发现数学机制"** ✓✓
**【P8 算术数据驱动的独立问题】** $$F+C+D+G$$ ✓
　**硬性禁止**：$$\boxed{P8\neq\text{RH 变体}}$$ ✓✓（问题本身**不能是 RH 的弱化版**；可为零点统计量的严格界／素数分布的新型相关量／additive-multiplicative prime structures／零点统计与其它算术对象的可证关系）✓
```
