## C 链：AP ⟹ 强哥德巴赫渐近（标准——Hardy-Littlewood）

### C1-C4. 圆法 ✅
- r(n) = ∫₀¹S(α)²e^{−2πinα}dα——major arcs（主项——奇异级数）+ minor arcs（GRH 控制）
- GRH 下 minor arcs |S(α)| ≤ N/log^A N——误差可控

### C5. 强哥德巴赫渐近 ✅
- GRH ⟹ R(n) = (S(n)/2)·n/log²n·(1+o(1))——充分大偶数（Hardy-Littlewood 1923）
- S(n) = 2C₂·Π_{p|n,p>2}(p−1)/(p−2)——奇异级数
- **数值实证**：R(n) vs (S/2)n/log²n——比值 1.13-1.15 → 1（c≈2.2 低阶修正）✓
