# **`DC` 归约为一条引理**

## §1 已严格得到的（照录您的三条）

```
**(1)** `q\mid B_n\iff r_q\mid n`：由 EDS 强整除 `\gcd(B_{r_q},B_n)=B_{\gcd(r_q,n)}` ＋ `r_q` 最小性 ✓
**(2)** `r_q=n\iff q` 在 `n` 处 primitive ✓
**(3)** `|P_N(S)|\le|S|` ✓
【⟹ 分解】 `T_N(S)=P_N(S)\sqcup X_N(S)` ⟹ $$|T_N(S)|\le|S|+|X_N(S)|$$ ✓（这是**无争议的**上界）
```

## §2 ⭐ injection 的真相（本档关键判定）

```
【看似要证的 (15)】 `X_N(S)\hookrightarrow\{(q,\text{非根节点})\}` ⟹ 若成立则 `|X_N(S)|\le\sum_q(\ell_q-1)` ✓
【但**按"节点＝`n` 本身"读法，injection 平凡成立**：取 `q(n):=\min\{q\mid B_n\}`，映射 `n\mapsto(q(n),n)`，由第二分量即可还原 `n` ✓✓
【⟹ 关键问题不在 injection，而在**计数**】 若只用 (15) 的平凡读法，得到的是 $$|X_N(S)|\ \le\ \#\{(q,n):q\mid B_n,\ n\in X_N(S)\}$$ 而右侧**不是** `\sum_q(\ell_q-1)` ⟹ **`DC` 不由此推出** ✗✓
```

## §3 ⭐ ⭐ 正确的缺失引理（本档归约）

```
【观测】 对固定 `q`，其"例外节点集"为 `E_q(N):=\{n\le N:\ n\in X_N(S),\ q\mid B_n\}`；由 (1) 有 `r_q\mid n` ✓
【问题】**`E_q(N)` 是否在整除偏序下构成一条链**（即 `n,n'\in E_q(N)\Rightarrow n\mid n'` 或 `n'\mid n`）？ ✓✓
【⟹ 判定】 **(a)** 若**成链** ⟹ `\#E_q(N)=\ell_q(N)-1` ⟹ **`DC` 成立** ✓✓；**(b)** 若**不成链**（出现互不整除的两个例外节点）⟹ `\ell_q-1` **严重低估** `\#E_q`（`\ell_q-1=1` 而节点数可任意大）⟹ **`DC` 为假，正确量应为"节点数"（＝偏序宽度的计数）而非链长** ✗✓✓
【⟹ 归约结论】 $$\boxed{DC\ \text{的真核心}\ =\ \text{单条引理：固定 }q\text{ 的例外节点在整除下成链}}$$ —— 而非 injection，也非容量语句本身 ✓✓
【⟹ 数据支持度（诚实）】 `q=2`：`r_2=5`，`n\le28` 上 `E_2=\{10\}` ⟹ **平凡成链**；**无信息量**（样本仅 1 个节点）⟹ **该引理目前既未被证、也未被反例否定** ✓
```
