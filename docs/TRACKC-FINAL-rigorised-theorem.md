## §1 **定理（最终形式）**
```
设 **T 是这样一个高度**：**[0,T] 内所有非平凡零点已被【严格】验证（区间算术）在临界线上** ✓
   （例：**T = 3.000175×10¹²**，Platt–Trudgian ✓）
记 **C1(n) = 1 − cos(½) − sin(½)/(96n²)** ✓（窗口下界，见 §2-C1）
   **B_T ≤ C(logT + 1)/T** ✓（C = 经典计数上界的显式常数 ✓，见 §2-C3）
且 **小 n 段（n ≤ 10⁵）由已发表的直接验证接管** ✓（Palojärvi / Coffey ✓）
则 **λ_n ≥ 0 对一切 1 ≤ n ≤ N_max** ✓✓，其中 **N_max = 满足下式的最大 n**：
$$N_{\max}=\max\Big\{n:\ \#\{\gamma\in[n/2,\min(2n,T)]\}\ \ge\ \frac{n\,B_T}{C_1(n)}\Big\}$$
```
**代 T = 3.000175×10¹²⟹ N_max = 2T − O(1) ≈ 6.00035×10¹²** ✓✓
   —— 文献记录 **n ≤ 10⁵** ⟹ **约 6×10⁷ 倍** ✓✓✓
   （数值实测：T=1.13249×10⁶ 时 **N_max = 2,264,960 = 2T − 20** ✓，所需计数在端点仅 **19.42** ✓）
```

## §2 **四要素（全部核验 ✓）**
```
【C1·窗口下界 —— **精确** ✓✓】θ_γ = atan2(γ, γ²−¼)；**数值验证（40 位）**：
   n=10⁴: nθ_{2n} = 0.499999999895833333 **vs ½ − 1/(96n²) = 0.499999999895833333**（差 **3.9e−20** ✓✓）
   n=10⁵: 差 **3.9e−24** ✓✓ ⟹ **nθ_{2n} = ½ − 1/(96n²) + O(n⁻⁴) 精确成立** ✓
   且 θ 关于 γ 单调减 ⟹ **窗口内每项 ≥ 1 − cos(½ − 1/(96n²)) = C1(n)** ✓✓
   （C1(n) = 0.122417438110 − 4.994016×10⁻³/n² ✓）
【C2·计数（**所需极小** ✓✓）】需 **#窗口 ≥ n·B_T/C1(n)** —— 实测"所需"仅为：
   n=10⁵: **0.858** ｜10⁶: **8.58** ｜2×10⁶: **17.15** ｜端点 2.265×10⁶: **19.42** ✓
   ⟹ **所需计数为 O(log T) 量级** ⟹ **经典计数界的显式常数【无关紧要】** ✓✓
   ⟹ 而"实有"计数在全程远大于所需：**余量 = 2.7×10⁵（n=10⁵）→ 3.2×10⁵（5×10⁵）→
      1.4×10⁵（10⁶）→ 1.5×10⁴（2×10⁶）→ 7.5×10²（2.25×10⁶）→ 1.03（端点）** ✓✓
【C3·尾部常数（显式 ✓）】N(x) ≤ C·x log x（经典 ✓）⟹ **B_T ≤ C(logT+1)/T** ✓
   （实测 B_T = 1.0498×10⁻⁶ @T=1.13×10⁶ ✓；T₀=3.0×10¹² 时 B_T₀ = 7.886×10⁻¹³ ✓）
【C4·离轴（显式 ✓）】β<½、γ>T：**log|1−1/ρ| = ½log(1 + (1−2β)/(β²+γ²)) ≤ 1/(2γ²)** ✓
   ⟹ **|w|^n − 1 ≤ (n/(2γ²))·e^{n/(2γ²)}**，n<2T、γ>T ⟹ **n/(2γ²) < 1/T = 8.83×10⁻⁷**
   ⟹ e^{1/T} = 1 + O(1/T) ⟹ **Σ_{离轴} ≥ −n·B_T·(1+o(1))** ✓✓
   （β>½ 时 |w|<1 ⟹ 贡献 ≥ 0 ✓ —— **故只有 β<½ 需处理** ✓）
```

## §3 ⭐ **为什么端点会差 O(1)**（本轮修正 ✓）
```
【发现】n → 2T 时窗口 [n/2, min(2n,T)] → 退化为点 ⟹ **#窗口 → 0** ✗
   ⟹ 实测：**N_max = 2T − 20**（T=1.13249×10⁶ ✓），**差值为【常数】而非比例** ✓✓
   ⟹ 原因：所需计数 ~19.4 是常数 ⟹ 只要窗口内还有 ~20 个零点 ✓ ——
      而零点间距 ~2π/logT ⟹ 20 个零点 ≈ 常数距离 ✓✓
【修正后的陈述】N_max = 2T − O(1)（**O(1) 显式可算** ✓）⟹ 结论"~6×10¹²"不变 ✓
```
