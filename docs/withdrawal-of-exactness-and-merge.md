## §1 ⚠️ **撤回**：上一弧的类级别结论过强
```
我在 `45b7514` 写过："Λ≥0 ⟹ 误差项必须在端点恰为零 ⟹ 任何'正则化→转移'范式的核心
                     必须是【精确恒等式】而非估计"
```
**复核后判定：该推理不成立** ✗
```
理由：Λ ≥ 0 说的是"不能把零点实性证到 t<0"。
     但 t<0 的结论【本身是假的】（RH ⟺ Λ=0 且 Λ≥0 ⟹ 不存在 t<0 的实性）
     ⟹ 排除它，只等于说"不能证明假命题" ⟹ 对【方法】没有额外的限制 ✗
     ⟹ 因此原推理把"不能过冲"误读为"必须精确" —— 两者不是一回事 ✗
```
$$\boxed{\text{撤回：}\Lambda\ge0\ \text{【不】蕴含"核心必须是恒等式"；估计型方法未被此论据排除}}$$
**保留的（较弱但正确）内容**：Λ ≥ 0 ⟹ 转移【不能靠"过冲/余量"】，必须【端点特异】✓

## §2 本弧**真正站得住**的两条（清点）
```
① ⭐ 【一致性对应】（YM ⟷ RH）：两问题的已证部分都靠【小参数】，未证部分都缺【无小参数的一致界】

   ⟹ 站得住（这是对已知结果【形状】的观察，不依赖任何撤回的内容）✓
② ⭐ 【恒等式族的排除】：一切已知"算术⟷零点"精确恒等式都是显式公式型（含 Selberg 迹公式）
   ⟹ "再找一个漂亮恒等式"整类无用；缺的是【新对偶】✓
```
