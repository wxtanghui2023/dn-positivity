## 2. ⭐ Hooley 模板为何**不能**推翻 Gate 0（本轮关键结论）

```
Hooley/Motohashi 在 AP / 加法除数问题中的无条件成功，其 cancellation 发生在
    【modulus 平均】坐标（离散），并（在 Motohashi 一线）经由【谱机器（Kuznetsov/Kloosterman）】
⟹ 其成功依赖的坐标 = R8 的 fixed-X 短区间问题【不具备】的
⟹ R8 唯一可用的平均坐标 = 移位 h（即 h-平均），而 h-平均的 S2-c 正是缺失者
```
$$\boxed{\text{结论：Hooley 模板【不可移植】——原因不是技术缺口，而是【平均坐标不匹配】}}$$
**⟹ 这反而为 R8-C 提供了第一块结构性论证材料**（仍非必然性定理）。

**⭐ 新增筛查项（登记）**：
$$\boxed{\text{averaging-coordinate mismatch（平均坐标错配）}}$$
任何以"某平均问题已无条件成功"为依据的路线，须先证明其**平均坐标**（modulus 平均／频率平均／移位平均）与目标问题的平均坐标一致；不一致者预淘汰。
