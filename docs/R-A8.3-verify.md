## 0. 中心判别器（逐族对齐）

$$\boxed{\text{主项是否携带【连续尺度自由度】}H/X\ (1-\eta)\text{，还是只含【离散/另一坐标】参数？}}$$

| 结果族 | 变量空间 | 权函数 | 非对角展开 | 主项含 $H/X$？ | 关键结构 |
|---|---|---|---|---|---|
| **Lavrik 型（频率平均）** | 频率 $\theta$（区间 $[\alpha,\beta]$） | 截断 Parseval | 频率积分 | **✗** | 主项正比于**频率区间长度**（$\beta-\alpha$）与 $N$，不含短区间比 |
| **Motohashi（除数族 AP / 加法除数问题平均）** | modulus $q$ | 特征/Fourier | 谱方法（Kuznetsov） | **✗**（含 $Q/N$ 而非 $H/X$） | 成功来自**乘法/Dirichlet 级数结构 + 谱机器** |
| **Hooley（素数 AP variance）** | modulus $q$ | 特征分解 | **prime-specific off-diagonal** | **✗**（含 $q/N$） | cancellation 沿 **modulus 平均**发生 |
| **R8 目标（S2-c）** | **fixed $X$、短区间 $H=X^\eta$** | $w_H(h)$ | **prime-pair** | **必须含 $1-\eta$** | 唯一合法平均坐标 = **移位 $h$** |

$$\boxed{\text{⟹ 三族的"连续比率"都是【modulus/频率坐标】，而非 R8 的【短区间比 }H/X\text{】}}$$

## 1. V1–V3 判定

```
V1 是否真含 H=X^η(η>0) 的 prime-pair 二阶主项？   ⟹ **失败**（三族对象均非此对象：
    Lavrik=频率平均量；Motohashi=除数族 AP；Hooley=素数 AP）——但 Lavrik 型是"成分"而非主项
V2 其主项是否真出现 1−η？                        ⟹ **失败**（出现的是 q/N、β−α 等**另一坐标**的函数）
V3 能否在不调用 RH/pair correlation 下转译 F(α)(α>1)？⟹ **不适用**（V1/V2 已失败）
```
**⚠️ 但 V1 的一个重要作用**：Lavrik 型频率平均量与方差的关系表明——
$$\boxed{\text{短区间尺度通过【频率截断 }\sim 1/H\text{】进入 ⟹ }(1-\eta)\text{ 是一个【频率积分的端点/边界项】}}$$
即 $H\log X-H\log H=H\log(X/H)=H(1-\eta)\log X$ 中的 $-\log H$ 来自**截断端点**。

## 2. ⭐ Hooley 模板为何**不能**推翻 Gate 0（本轮关键结论）

```
Hooley/Motohashi 在 AP / 加法除数问题中的无条件成功，其 cancellation 发生在
    【modulus 平均】坐标（离散），并（在 Motohashi 一线）经由【谱机器（Kuznetsov/Kloosterman）】
⟹ 其成功依赖的坐标 = R8 的 fixed-X 短区间问题【不具备】的
⟹ R8 唯一可用的平均坐标 = 移位 h（即 h-平均），而 h-平均的 S2-c 正是缺失者
```
$$\boxed{\text{结论：Hooley 模板【不可移植】——原因不是技术缺口，而是【平均坐标不匹配】}}$$
**⟹ 这反而为 R8-C 提供了第一块结构性论证材料**（仍非必然性定理）。

**⭐ 新增筛查项（登记）**：
$$\boxed{\text{averaging-coordinate mismatch（平均坐标错配）}}$$
任何以"某平均问题已无条件成功"为依据的路线，须先证明其**平均坐标**（modulus 平均／频率平均／移位平均）与目标问题的平均坐标一致；不一致者预淘汰。
