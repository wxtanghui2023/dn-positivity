# §4.2 严格化：C0-C4 逻辑强度谱系——逐条蕴含的定理级推导

> 2026-09-01 · 唐先生第一优先指令 · 确保每个箭头都没有偷渡 RH

## 0. 定义（精确意义）

**V(T)**（截断尾部）：
```
V(T) = ∫_T^∞ (ψ(x)−x)²x^{−3}dx
```
- **L² 尾部**（从 T 到 ∞ 的积分——不是 pointwise——不是 limsup）

**C0-C4**（精确表述）：
```
C0:  V < ∞                      （V = V(1)——全积分收敛）
C1_a: V(T) = O(T^{−a})          （固定 a ∈ (0,1]——L² 尾部衰减）
C2:  V(T) = O(T^{−1+ε})         （所有 ε > 0——L² 尾部——ε-松弛）
C3:  V(T) = O(T^{−1})           （L² 尾部——精确——无 ε）
C4:  ψ(x) − x = O(x^{1/2+ε})    （pointwise——所有 ε > 0）
```
**约定**：O(·) 均为大 O——T → ∞。C1_a 是**参数化**的（a 固定）——C1 单独写时指"存在 a>0"（下文指出这是平凡的）。

## 1. 预备引理（T7 的严格版——L² 下界/上界）

### 引理 1（L² 上界）：β_max ≤ β ⟹ V(T) = O(T^{2β−2+ε})
**假设**：所有零点实部 ≤ β（β < 1）。
**证明**：显式公式 ψ(x)−x = −Σ_ρ x^ρ/ρ + O(1)（经典——含常数项）——逐项积分（对角 + 交叉）：
- 对角：Σ_ρ ∫_T^∞ x^{2β_ρ−3}/|ρ|² dx ≤ Σ_ρ T^{2β−2}/|ρ|²·(1/(2−2β)) = O(T^{2β−2})（Σ1/|ρ|² 收敛——Hadamard）
- 交叉：Σ_{ρ≠ρ'} ∫_T^∞ x^{β_ρ+β_{ρ'}−3}e^{i(γ_ρ−γ_{ρ'})logx}/(ρρ̄')dx——van der Corput：O(T^{β_ρ+β_{ρ'}−2}/|γ_ρ−γ_{ρ'}|)——**求和收敛性用零点间距下界**（引理 2）——总量 O(T^{2β−2})（β_ρ, β_{ρ'} ≤ β）
- 常数项：O(T^{−2})（可忽略）
**引用**：显式公式（经典）、Hadamard 收敛（经典）、van der Corput（经典）、零点间距下界（引理 2——无条件）
**是否需 RH**：否——无条件
**反向**：无（引理 1 是上界方向）

### 引理 2（零点间距下界）：γ_{n+1} − γ_n ≥ c/log γ_n
**状态**：无条件经典事实（来自零点计数 + 增长估计——Jensen/Hadamard）
**引用**：经典（RH 无关）
**用途**：控制交叉项重和的收敛（|γ_ρ−γ_{ρ'}| ≥ c/log γ——分母可吸收 log 因子）

### 引理 3（L² 下界）：β_max = β₀ > ½ ⟹ V(T) ≥ c·T^{2β₀−2}（c > 0）
**假设**：存在零点 ρ₀ = β₀+iγ₀ 有 β₀ = β_max > ½。
**证明**（主项分离）：
- ψ(x)−x = −(x^{ρ₀}/ρ₀ + x^{ρ̄₀}/ρ̄₀) + R(x)——R 含其余零点 + 常数项
- 主项平方：|x^{ρ₀}/ρ₀ + x^{ρ̄₀}/ρ̄₀|² = 4x^{2β₀}cos²(γ₀logx−φ)/|ρ₀|²
  - ∫_T^∞ 4x^{2β₀−3}cos²(γ₀logx−φ)dx = (2/|ρ₀|²)·T^{2β₀−2}/(2−2β₀) + O(T^{2β₀−3})（cos² = ½+½cos(2γ₀logx)——主项 + van der Corput）
- 交叉项（ρ₀ 与 R）：van der Corput + 引理 2——O(T^{β₀+β'−2})——β' ≤ β_max'（R 中最大实部——若 β₀ 孤立最大——β_max' < β₀——可忽略；若聚点——Σ 系数 1/|ρ|² 收敛——对角正——不抵消主项）
- R 项：|R(x)|²——对角 + 交叉——O(T^{2β_max'−2})（β_max' ≤ β₀——但——**若 β_max' = β₀（聚点）——R 贡献 ~ Σ_{β_ρ≈β₀}T^{2β₀−2}/|ρ|²——正（对角）——与主项同阶但正——不抵消**）
- **结论**：V(T) ≥ (2/|ρ₀|²)·T^{2β₀−2}/(2−2β₀)·(1−o(1)) ≥ c·T^{2β₀−2}（β₀ > ½ 时——主项正——交叉/R 不抵消）
**引用**：显式公式、van der Corput、引理 2、Hadamard 收敛
**是否需 RH**：否——无条件（假设的是"存在离轴零点"——这是**反证假设**——不是 RH）
**⚠️ 诚实标注**：交叉项"不抵消主项"的论证依赖：① van der Corput 常数有界；② 对角项正性；③ 零点间距下界（引理 2）。**这是标准技术**——但**必须完整写出**（论文中给出完整证明）——不能只说"对角主导"。**若 β₀ 是聚点**——需要"Σ 系数有限"论证（Hadamard 收敛）——已包含。

### 引理 4（函数方程桥）：β_max ≤ ½ ⟺ RH
**证明**：若所有零点 β_ρ ≤ ½——函数方程（ρ 零点 ⟹ 1−ρ̄ 零点——无条件）——1−β_ρ ≤ ½——β_ρ ≥ ½——故 β_ρ = ½——RH。反向显然。
**引用**：函数方程（经典——无条件）
**是否需 RH**：否（函数方程无条件）

## 2. 逐条蕴含（严格）

### C0
**C0 无条件成立**（PNT 足够）：
- ψ(x)−x = O(x e^{−c√log x})（PNT 强形式——无条件）
- V = ∫(ψ−x)²x^{−3}dx ≤ C∫x²e^{−2c√log x}x^{−3}dx < ∞（收敛——u=log x 替换）
- **但**——C0 对任何 β_max < 1 都成立（T7/引理 1：V ~ T^{2β_max−2}——β_max < 1 ⟹ 收敛）——**太弱——不排除 ½ < β_max < 1**
- **是否需 RH**：否——**反向**：C0 平凡（不编码零点）

### C1_a（固定 a ∈ (0,1]）
**C1_a ⟹ C0**：显然（O(T^{−a}) 尾部 ⟹ 收敛）——无条件蕴含
**C1_a ⟺ β_max ≤ (2−a)/2**（若 a < 1——严格弱于 RH）：
- （⟸）β_max ≤ (2−a)/2 ⟹ V(T) = O(T^{2β_max−2}) = O(T^{−a})（引理 1——β = (2−a)/2）
- （⟹）C1_a + 引理 3（若 β_max > (2−a)/2——V(T) ≥ cT^{2β_max−2} > T^{−a} 矛盾）⟹ β_max ≤ (2−a)/2
- **a = 1 时**：C1_1 ⟺ β_max ≤ ½ ⟺ RH（引理 4）——**C1_1 = C3 的精神**
- **a < 1 时**：严格弱于 RH——**编码零点位置（部分）**
- **是否需 RH**：否（推导无条件——但——"a 的具体值"未知——因为 β_max 未知）
- **反向**：C0 ⇏ C1_a（C0 平凡——β_max=0.7 时 V<∞ 但 V(T)~T^{−0.6}——C1_{0.8} 不成立）

### C2（V(T) = O(T^{−1+ε})——所有 ε > 0）
**C2 ⟺ RH**（L² 版本——两个方向）：
- **（⟸）RH ⟹ C2**：RH ⟹ ψ(x)−x = O(x^{1/2+ε})（pointwise——经典 RH 等价）⟹ V(T) ≤ C∫_T^∞ x^{1+2ε}x^{−3}dx = O(T^{−1+2ε})——**取 ε/2 即得 C2**——严格
- **（⟹）C2 ⟹ RH**：反证——若 β_max > ½——引理 3：V(T) ≥ cT^{2β_max−2}——C2：V(T) ≤ CT^{−1+ε}——故 T^{2β_max−2} ≤ C'T^{−1+ε}——2β_max−2 ≤ −1+ε——β_max ≤ ½+ε/2——对所有 ε——β_max ≤ ½——**与 β_max > ½ 矛盾**——故 β_max ≤ ½——引理 4——RH
- **是否需 RH**：否（两个方向都不偷渡 RH——⟸ 用 RH 作为假设（这是 RH ⟹ C2——需要 RH——但这是"RH 蕴含"方向——不是偷渡）；⟹ 用反证（假设 β_max > ½——引理 3 无条件）——**关键：引理 3 是"存在离轴零点 ⟹ 下界"——这是反证假设的推论——不是 RH**）
- **⚠️ 意义标注**：C2 是 **L² 尾部**意义（不是 pointwise——不是 limsup）
- **⚠️ 经典等价标注**：C2 ⟺ RH 是**经典等价**（ψ 的 L² 平均与 RH——Gallagher 类结果的精神）——**不是新定理**——论文标注"经典等价（L² 版本）——我们给出自包含推导（引理 1-4）"

### C3（V(T) = O(T^{−1})）
**C3 ⟺ RH**（同强度——**修正之前草稿的错误**——C3 不比 RH 强）：
- **（⟸）RH ⟹ C3**：β_max = ½（RH）——引理 1（β=½）：V(T) = O(T^{2·½−2+ε}) = O(T^{−1+ε})——**但——C3 要 O(T^{−1})（无 ε）**——需要更精确：
  - 对角项精确：Σ_ρ ∫_T^∞ x^{2·½−3}/|ρ|²dx = T^{−1}Σ_ρ 1/|ρ|²（收敛——精确）
  - 交叉项：van der Corput + 引理 2——O(T^{−1}·(log T 因子可吸收？))——**需要检查——交叉项 van der Corput 常数可能产生 T^{−1+δ}（δ>0）**——**⚠️ 诚实标注：RH ⟹ C3 的"精确 O(T^{−1})"依赖交叉项的精细估计——若交叉项产生 T^{−1}·(logT)^k——C3 失败而 C2 成立——因此——严格可证的是 RH ⟹ C2——RH ⟹ C3 需要额外论证（交叉项无 log 因子）——**存疑——标注"RH ⟹ C3：需交叉项精细估计（开放细节）——保守标注 RH ⟹ C2（严格）——RH ⟹ C3（预期——待精细）"**
- **（⟹）C3 ⟹ RH**：C3 ⟹ C2（O(T^{−1}) ⊂ O(T^{−1+ε})——显然）⟹ RH（上面已证）——严格
- **结论**：**C3 ⟹ RH 严格**（通过 C2）——**RH ⟹ C3 预期但不完全严格**（交叉项精细）——**因此——C3 是 RH 的"候选等价"（⟸ 方向待精细）——论文标注"C3 ⟹ RH 严格——RH ⟹ C3 预期（交叉项无 log 因子——开放细节）"**
- **⚠️ 修正**：之前草稿写"RH ≤ C3"（C3 比 RH 强）——**错误**——C3 与 C2 同为"β_max ≤ ½"的 L² 表述——**强度相同**——只是 ε 的松弛不同——修正为 C3 ~ RH（候选等价）

### C4（pointwise）
**C4 ⟺ RH**（经典——教科书）：
- RH ⟹ ψ(x)−x = O(x^{1/2}log²x)（强形式）⟹ C4
- C4 ⟹ RH：ψ(x)−x = O(x^{1/2+ε}) ⟺ RH（经典等价——von Mangoldt 类）
- **是否需 RH**：否（经典——无条件等价）
- **C4 ⟹ C3 ⟹ C2**：pointwise ⟹ L²（直接积分）——严格

## 3. 逻辑蕴含图（最终形式）

```
          C4 (pointwise: ψ−x = O(x^{1/2+ε}))
         /  \
        /    \        ──── 无条件蕴含
       ▼      ▼       - - - RH 等价（经典/引理 4 桥）
      C3     RH  ←──────────────────────┐
       \    /                           │
        ▼  ▼                            │
      C2 (V(T)=O(T^{−1+ε})) ────────────┘（C2 ⟺ RH——引理 1,3,4）
        │
        ▼
      C1_a (V(T)=O(T^{−a}))——a<1 严格弱于 RH（⟺ β_max ≤ (2−a)/2）
        │
        ▼
      C0 (V<∞)——无条件（PNT）——太弱（任何 β_max<1）
```

**逐条标注**：
| 蕴含 | 类型 | 备注 |
|------|:--:|------|
| C4 ⟹ C3 | ──── 无条件 | pointwise ⟹ L²（直接积分） |
| C4 ⟹ RH | - - - RH 等价 | 经典（教科书） |
| C3 ⟹ C2 | ──── 无条件 | O(T^{−1}) ⊂ O(T^{−1+ε}) |
| C3 ⟹ RH | - - - RH 等价 | C3 ⟹ C2 ⟹ RH（严格）——RH ⟹ C3（预期——交叉项待精细） |
| C2 ⟹ RH | - - - RH 等价 | 引理 3 反证 + 引理 4（严格） |
| RH ⟹ C2 | - - - RH 等价 | pointwise ⟹ L²（严格） |
| C2 ⟹ C1_a | ──── 无条件 | O(T^{−1+ε}) ⊂ O(T^{−a})（a<1） |
| C1_a ⟹ C0 | ──── 无条件 | 显然 |
| C1_a ⟹ RH | ──── 仅 a=1 | a<1 时弱于 RH（β_max ≤ (2−a)/2 < ½+...） |

**明确不存在的反向**：
- **C0 ⇏ C1_a**（C0 平凡——β_max=0.7 世界满足 C0 但不满足 C1_{0.8}）
- **C1_a ⇏ C2**（a<1——β_max=(2−a)/2 > ½ 世界满足 C1_a 不满足 C2）
- **C2 ⇏ C3 直接**（ε 松弛——但——C2 ⟹ RH ⟹ C3（若 RH ⟹ C3 精细成立）——**通过 RH 桥——不直接**）
- **C3 ⇏ C4**（L² 不 ⟹ pointwise——C3 世界可有 pointwise 尖峰）
- **C0-C3 ⇏ C4**（L² 家族不控制 pointwise）

## 4. 谱系的含义（修正版）

**越想让 observable 真正"排除"离轴零点——就越接近 RH 本身**：
- C0（无条件——太弱——任何 β<1）
- C1_a（a<1——编码部分零点信息——严格弱于 RH）
- **C2 ~ C3 ~ C4——都是 RH 等价**（L² 带 ε / L² 精确 / pointwise——**同一逻辑强度——区别只是表述精度**）
- **没有任何"严格弱于 RH 但由独立素数结构可证"的中间条件**（在本审计覆盖的已知无条件工具中——PNT 只到 C0——C1_a 的 a 值依赖 β_max（未知）——C2 以上 ≡ RH）
