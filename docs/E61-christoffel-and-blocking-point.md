## 1. Christoffel 机制（✓ 原文 (d) 的精确内容 ✓）

```
【原文 (d) ✓】Lemma 3.2 在 c = 1 时 = **单边 Chebyshev–Markov–Stieltjes** 界的 m = 1 情形 ✓：
   若归一化矩 d^{−1}tr G̃^k（k ≤ 2m ✓）已知 ✓，则 **n₊(G̃)/d 的锐下界 = 1 − Λ_m(0)** ✓
   Λ_m = 矩序列在 0 处的 Christoffel 函数 ✓
【已核数值 ✓（项目 ✓）】
   m = 1（知 k ≤ 2 ✓：tr ✓ ＋ HS ✓）⟹ 1 − Λ₁(0) = **3/4** ✓（= m₁²/m₂ = 1/(4/3) ✓）✓
   m = 2（知 k ≤ 4 ✓）      ⟹ 1 − Λ₂(0) = **31/36** ✓（原文：Λ₂(0;1) = **5/36** ✓ 一致 ✓）
   ⭐ 而 **anchor 13/18 = 0.7222** ✓（HL*(4) 下 ✓，见 §2 ✓）
【读法 ✓】矩越多 ⟹ Λ_m 越小 ⟹ 下界越高 ✓：0.75（m=1 ✓）→ 0.8611（m=2 ✓）→ … → 1 ✓（全 k ✓）
```

## 3. ⭐ (a) 的阻塞点（本轮定位 ✓）

```
【阻塞 ✓】对角法在 X^k ≤ T^{2−ε} 处给出 tr G̃^k ✓ —— 但那个 G̃ 是**较短窗口**造的 ✓
   ⟹ 其矩序列 **≠ 正弦核极限矩** ✗（1, 4/3, 2, 13/4 是 X ≍ T 处的极限 ✓）
   ⟹ 要算 1 − Λ_m(0) ✓，必须先有**该长度下的矩的显式表达式** ✗
【为何这不是死路 ✓】M–V（Montgomery–Vaughan ✓）＋ k 个素数幂乘法关系 ✓ 给出**对角项** ✓
   ＋ 非对角项按 RS 范围可控 ✓ ⟹ **矩是可写的** ✓（只是要动手 ✓）
【⭐ 且这引出**一个尖锐的结构问题** ✓】
   · X ≍ T 的矩 → 正弦核矩 ✓（条件 ✓）⟹ 下界 0.75（m=1 ✓）/ 0.8611（m=2 ✓）
   · X = T^{2/k} 的矩 → **另一组数** ✓ ⟹ 其 Christoffel 下界**可能更好也可能更差** ✗
   · 而"0.682 天花板"是**带宽 1 类别**的天花板 ✓（§7.2 ✓）
   ⟹ ⭐ **要问的问题** ✓：**短长度（X ≪ T）的证书，能否逃出带宽一的天花板？** ✓
      —— 这是一个**没被问过**、且**完全无条件**的问题 ✓✓
```
