## §2 A2（Fermat 两平方）：逐项审计 ⟹ **PASS** ✓✓

```
【设定】 p ≡ 1 (mod 4) 素；M := { m ≥ 1 : m·p 是两平方和 } ✓；**μ(m) := m**（显式 → ℕ ✓）
【C1 压缩（鸽笼／Thue 短向量）】 由 x² ≡ −1 (mod p)（Euler 判别法／Wilson ✓）与鸽笼：
   在 {(a,b) : 0 ≤ a,b ≤ ⌊√p⌋} 中取两对同余 ⟹ 得 (a,b) ≠ (0,0)、|a|,|b| ≤ √p、a + bx ≡ 0 (mod p) ⟹
   p | a² + b² ⟹ **a² + b² = m p 且 1 ≤ m ≤ 2** ⟹ **M ≠ ∅** ✓✓
   ⭐ **严格弱于目标**：C1 只断言"M 非空 ＋ 存在 m ≤ 2"，**不**断言 m₀ = 1 ⟹ **D-1 PASS** ✓✓
【μ 与良序】 m₀ := min M 存在（ℕ 良序 ✓ ＝ C5 ✓）
【C3 严格下降（含恒等式链）】 设 m₀ > 1 且 m₀p = a² + b²。取 a = q₁m₀ + a′、b = q₂m₀ + b′（|a′|,|b′| ≤ m₀/2 ✓）⟹
   a′² + b′² ≡ 0 (mod m₀) ⟹ **a′² + b′² = m′·m₀**，且 **m′ ≤ m₀/2 < m₀** ✓✓；
   再由 Brahmagupta 恒等式 (a²+b²)(a′²+b′²) = (aa′+bb′)² + (ab′−a′b)² 并用 a ≡ a′、b ≡ b′ (mod m₀) 得
   **m₀ | (aa′+bb′)**、**m₀ | (ab′−a′b)** ⟹ 令 A := (aa′+bb′)/m₀、B := (ab′−a′b)/m₀ ⟹
   **A² + B² = p·m′** ⟹ ⭐ **m′ ∈ M 且 m′ < m₀** ✓✓✓
【C2 失败保持】 ⭐ **P 保持**：新对象 **m′ ∈ M**（即 m′p 仍是两平方和）✓✓ —— 恰是唐先生所指最危险处：

【C5】 由 m₀ 最小性 ⟹ **m₀ = 1** ⟹ **p = A² + B²** ∎ ✓✓
【C4 外层闭包】 对应物 = **两平方和的乘性**（Brahmagupta–Fibonacci 恒等式 ✓）＋ p = 2 与 p ≡ 3 (4) 的素情形处理 ✓
   ＝ "小尺度结构已可用"的类比 ✓
【D-1 循环门】 PASS ✓（见 C1 的"严格弱于目标"）✓✓
【判定】 ⭐⭐ **A2 = PASS** ⟹ **verified second instance**（本档已给出**显式链**：
   鸽笼 → M 非空 → m₀ → 模 m₀ 归约 → 恒等式 → m′ ∈ M 且 m′ < m₀ → m₀ = 1 ✓✓）
```
