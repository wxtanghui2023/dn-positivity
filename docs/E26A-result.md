## §3 唯一最有价值的发现：NB3 的核缺 (mn)^{−1/2}（核验）
```
【字面定义 = 约定 A】d_N² = inf_A (1/2π)∫|1−ζA_N(1/2+it)|²dt/(1/4+t²)，A_N(s)=Σa_n n^{−s}
   ⟹ 展开后 **K(m,n) = (mn)^{−1/2} g(log(n/m))**、l_n = n^{−1/2}L_n ✓（推导）
【独立验证】在同一网格上**不经核装配**直接数值积分该定义式：与约定 A 的核装配吻合到 **1e-13 相对** ✓✓
   而约定 B（NB3 实作，K = g）**不重现**该积分（N=160 时 I(V_N)：B 给 2.1016，直接积分给 0.18127）✓
【⟹ 结论】NB3 记录的 d_N² = 0.6803（N=160）是**约定 B** 的值，**不是** BCF/BD 定义的 d_N²；
   字面值（T=400）为 **d_160² = 0.0482194** ✓。`A4-1`/`A4-3` 中"高于渐近值 75 倍"的 75 主要来自该核差异 ✓
   差异的本质是核的**逐项权重 (mn)^{−1/2}**（非单一标量 k_N）：约定 B 的二次型**不是** ‖1−ζΣa_n n^{−s}‖² ✓
【兼容性】两约定下 Möbius 符号校验都仍然通过（见 §4）⟹ 符号校验**不能**发现该因子（此前未被发现的原因）✓
```
