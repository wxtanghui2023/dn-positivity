## P26-A9 结果

### ① 候选证明链（尝试——合法变形 ⟹ b=0）
- 合法变形（FE）⟹ M_b(s) = M_b(1−s)（一阶反射）
- 边界值：M_b^∂(t) = M_b^∂_left(−t)（S'——反射）
- M_b^∂(t) − M_b^∂(−t) = −跳跃(−t) = 2π Σ c_ρ δ(t−γ_ρ)（在线 δ）
- 但——M_b^∂ 的展开：级数极限（频率）+ 在线极点（PV+δ）+ **离线极点（光滑——c_ρ/(½−β+i(t−γ))——β≠½）**

### ② ⚠️ 离线极点的光滑贡献——破坏证明
- 离线零点（β≠½）——临界线边界值贡献 c_ρ/(½−β+i(t−γ))（光滑——含 β）
- 差 = 频率差 + 在线极点差（PV 抵消——δ 2πcδ）+ 离线极点差（光滑——含 β）
- 恒等式（= 跳跃）：**频率差 + 离线光滑差 = 0**
- 单频率测试：⟨频率差, φ⟩ = b_{p₀}p₀^{−k₀/2}φ̂(k₀ log p₀)/(2i)——⟨离线光滑差, φ⟩ ≠ 0（傅里叶 e^{−γμ}e^{−(½−β)|μ|} 类）
- **⟹ b_{p₀} 由离线光滑差决定（含 β——离轴零点）——不是 b=0**

### ③ 数值
- 离线光滑差的傅里叶在 k log p：非零（β=0.4: 0.93/0.90/0.87——β=0.3: 0.87/0.80/0.76——β=0.55: 0.97/0.95/0.93——破坏单频率测试）

### ④ ⭐ 判定
- **"b = 0"需要"无离线零点"（RH）——循环**
- **"离线光滑差"（含 β——离轴零点的 β 信息）是"β 墙"在边界值层的再现**
- **b ↔ 离线零点（变形系数 ↔ 离轴零点的 β）——循环确认**

- A7（在线）：b ↔ δ_ρ（在线零点移动——留数——δ 跳跃）
- A9（离线）：b ↔ 离线光滑差（离轴零点 β——光滑贡献）
- **都是"变形-零点耦合"（b ↔ 零点信息——循环）**
- 反射刚性（b=0——无极点类）严格——但——合法变形（含极点——在线或离线）——b ↔ 零点——不强制 0
- **T_ζA_arith = {0}——未闭合（b ↔ 零点——循环）**
