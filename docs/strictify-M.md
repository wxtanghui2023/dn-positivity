# M(T) = S₁(T) 有界性的严格化（2026-09-09 开始——）

## 目标
证明 M(T) = ∫₀^T S(t)dt = O(1)（数值支持：2M 零点平稳——max ~1.4-2.2——）
机制：S̄（区间平均 S——）= 几乎周期展开（R² 0.997——）——积分有界——

## 第一性原理推导

### 1. M 的精确表达式（零点——）
S(t) = N(t) − N₀(t)——N = 零点计数——N₀ = (t/2π)log(t/2πe) + 7/8
M(T) = ∫₀^T S(t)dt = Σ_{γ_k≤T}(T − γ_k) − ∫₀^T N₀(t)dt
     （N 是阶梯——∫N dt = Σ(T−γ_k)——）

### 2. M 的素数侧表达式（log ζ——）
S(t) = (1/π)Im log ζ(½+it)（约定——）
M(T) = (1/π)Im ∫₀^T log ζ(½+it)dt

对 σ>1：∫₀^T log ζ(σ+it)dt
  = Σ_{p,k} p^{−kσ} ∫₀^T e^{−ikt log p}dt / k
  = Σ_{p,k} p^{−kσ}(1 − e^{−ikT log p})/(ik² log p)
虚部：Im = −Σ_{p,k} p^{−kσ}(1 − cos(kT log p))/(k² log p)

⚠️ σ→½+ 时 k=1 项 Σ_p (1−cos(T log p))/(√p log p) 发散
   ——（Σ1/(√p log p) 发散——σ∈(½,1] 的 Σ1/(p^σ log p) 也发散——）
   ——需要【平滑/截断】正则化（σ 的 Abel 或 p 的截断——）

### 3. 平滑正则化（关键——）
S̄（区间平均——）= S 与区间平均核的卷积——核宽 Δγ(t) ~ 2π/log t
平滑的 log ζ(½+it)（卷积——）= 收敛（w = sinc 修正——数值——）
——w_p(t) = sinc(π log p/log t)（区间平均核的 Fourier——）
——大 p（log p ≳ log t——）被 w 压——正则化发散——

### 4. 平滑展开的积分（M 模型——）
M(T) ≈ −(1/π)Σ_{p,k} w_{p,k}(T)(1 − cos(kT log p))/(k² log p · p^{k/2})
——每项 ≤ 2/(k² log p · p^{k/2})——Σ 收敛（k=1: Σ1/(√p log p) 发散——
  但 w 压大 p——有效截断 p ≲ T——Σ_{p≤T}1/(√p log p) ~ √(T/log)？
  ——嗯——需要 w 的精确估计——）

## 待严格化的核心
A. 平滑（区间平均——）的 contour 推导：M(T) = (1/π)Im∫₀^T log ζ(½+it)dt

B. w_{p,k}(T)（平滑核——）的精确形式与估计
C. Σ 收敛 + M(T) 的界（从 B——）
