## 2. $u$-代入（✓ 恒等形式 ✓）

$$\gamma=\lambda u,\quad\lambda=\sqrt n,\quad u\in[1/\sqrt{11},\,1]\quad(\text{中间带 ✓})$$
$$\frac{n}{\gamma}=\frac{\lambda}{u}\qquad(\text{若 }\theta_\gamma=1/\gamma\ \text{则精确 ✓})$$
$$\boxed{\ \Delta_j\Phi=\lambda^2\Bigl(\frac1{\gamma_j}-\frac1{\gamma_{j+1}}\Bigr)=\frac{u_{j+1}-u_j}{u_ju_{j+1}}=\frac{g_j}{\lambda\,u_ju_{j+1}}\ }\quad(\textbf{恒等 ✓})$$

```
【差分 ✓】Δu_j = g_j/λ ≈ 2π/(λ logγ) → 0 ✓
   一阶 ΔΦ ≈ Δu/u² → 0 ✓
   二阶 Δ²Φ ≈ 2λ(Δu)²/u³ = 8π²/(λ u³ log²γ) → 0 ✓
⭐ 【一阶与二阶同时 →0 ✓】⟹ **相位序列渐近光滑** ✓（与 E74 的"二阶被间隙涨落压死"✗【不同】✓：
   那里是 $n$ 固定、对 $\gamma$ 求导 ✗；这里是 $u=\gamma/\sqrt n$ 下的**指标差分** ✓ ⟹ 间隙涨落被 $1/\lambda$ 压掉 ✓✓）
```

## 3. 首个 uniform-in-$n$ 不等式（✓ Abel 分解 ✓）

$$S_{\rm mid}(n)=\underbrace{\int_{\rm band}\rho(\gamma)e^{in\theta_\gamma}\,d\gamma}_{\text{(1) 光滑}}+\underbrace{\Bigl[e^{in\theta_\gamma}S\Bigr]}_{\text{(2) 边界}}-\underbrace{\int_{\rm band}S\cdot i\varphi'e^{i\varphi}\,d\gamma}_{\text{(3) 偏差}}$$

| 项 | 界 | 数值 |
|:--|:--|:--|
| (1) 光滑 | $2\sup\lvert\rho/\varphi'\rvert+\int\lvert(\rho/\varphi')'\rvert$ ✓（$\lvert\varphi'\rvert\in[1,11]$ ✓） | **≈ 8** ✓ |
| (2) 边界 | $2\sup\lvert S\rvert$ ✓（显式经典界 ✓） | **≈ 6.1** ✓ |
| (3) 偏差 | $\lVert S\rVert_{L^2}\cdot\lVert\varphi'\rVert_{L^2}$ ✓（C–S ✓） | **1.428×10⁶** ✗ |

$$\lVert S\rVert_2\le\sqrt{T\log\log T/(2\pi^2)}=\mathbf{389}\ \checkmark\quad(\textbf{Selberg 无条件 ✓})$$
$$\lVert\varphi'\rVert_2=\sqrt{\int_{\rm band}(n/\gamma^2)^2d\gamma}=3.44\,n^{1/4}=\mathbf{3.67\times10^3}\ \checkmark$$

$$\boxed{\ |S_{\rm mid}|\le 8+6.1+1.428\times10^6=\mathbf{1.428\times10^6}\ \text{vs 允许 }1.0628\times10^6\ \Longrightarrow\ \textbf{差 26\%}\ }\ ⚠️$$
