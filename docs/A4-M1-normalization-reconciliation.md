## §0 一句话结论（先给答案）

**归一化没有错。** 在每个 (N, T) 上，`I(V_N)` 的**直接按定义求积**与**核组装**一致到 **≤ 6×10⁻¹³**（相对），这同时锁死了测度、2π 因子、常数项 c=1、目标函数"1"、(mn)⁻¹ᐟ² 权重五个候选来源。**不存在归一化因子 k_N。** 任务背景里"比值 ~5.5 倍且单调升"与"I(V_N)·logN 单调降"的**行为相反**是**真实的有限-N 现象**，不是尺子没对齐——因为 `d_N²`（全体 a_n 的下确界）与 `I(V_N)`（显式次优多项式 V_N 的值）是**两个不同对象**，二者都合法地位于 C/logN 之上。

## §1 任务与判据（引用 E26 §6(A) + §2 L1/L2）

```
(A) 量 I(V_N) := (1/2π)∫_{-∞}^{∞} |1 − ζ(1/2+it)·V_N(1/2+it)|² dt/(1/4+t²)，
    V_N(s) = Σ_{n≤N}(1 − log n/log N)·μ(n)·n^{−s}（BCF 显式多项式）
    报 R(N) := I(V_N)/d_N²(N)，N = 20,40,80,160,320，T = 400/1200/2400。
    判据：R(N) 是否稳定/收敛？若漂移 ⟹ 暴露 k_N 并解析定位来源。
(B) 若定位到 k_N ⟹ 重做 L2：d_N²·logN 是否单调降入 [C, 3C] = [0.0462, 0.1386]？
(C) 若 R(N) 反而稳定 ~1 ⟹ 给出"归一化已对齐"证据并解释残余 ~5.5×。
```

实际结果落在 **(B) 与 (C) 之间**：R(N) 漂移（**下降**，7.89→3.14），但漂移方向与"存在标量 k_N"的预期**不符**——它不是无规律漂移，而是**单调、缓慢地趋向 1**，这正是 `V_N 在有限 N 尚非最优` 的签名（d_N² ≤ I(V_N) 恒成立，二者在 N→∞ 才共同趋近 C/logN ⟹ R(N)→1）。

## §2 方法（复用 NB3，零新求积）

```
【核（引用 NB3/E26A，已核验）】d_N² 化归单次傅里叶扫描：
   g(x) = (1/π)∫_0^T |ζ(1/2+it)|² cos(tx) dt/(1/4+t²)
   K(m,n) = (mn)^{−1/2}·g(log(n/m))   ← 2026-09-12 已修的权重（convention A = BCF 原文形）
   l_n = n^{−1/2}(1/π)∫_0^T Re[ζ e^{−it log n}] dt/(1/4+t²)
   d_N² = 1 − lᵀK⁻¹l  ；  I(V_N) = 1 − 2 lᵀV + VᵀKV ，V_n = (1−log n/log N)μ(n)
【关键】V_N 只是核里 a_n 的一个具体选择 ⟹ I(V_N) 无需新求积，直接复用同一 K、l。
【交叉验证（决定性）】I(V_N) 另用"直接按定义积分"（不组装核）在同一网格上算 ⟹ 两条独立路线。
【缓存】data/nb3_grid_H0.050_T{400,1200,2400}.npz（8001/24001/48001 点，h=0.05）✓
【精度】核条目**精确**（按 |log(n/m)| 去重后逐一 trapz，非插值）✓ —— 比 NB4 的 0.0005 三次样条更准。
```

## §4 R(N) 稳定性判定（核验 + 推导）

```
R(N) = I(V_N)/d_N² 随 N 的走势（T=2400）：7.702 → 5.759 → 4.474 → 3.690 → 3.140
【判定】R(N) 不"稳定"，也不在 ~1；它**单调下降、向 1 缓慢逼近**。
【为何这不是 k_N（推导）】
   · 若存在标量 k_N 使 d_N²(项目) = k_N·d_N²(文献)，则 R(N) 应无规律漂移或随 N 振荡；
     实测 R(N) 是**单调、有界、向下**的 ⟹ 它是"V_N 有限-N 次优性"的签名，非归一化。
   · 恒有 d_N² ≤ I(V_N)（下确界 ≤ 显式值）⟹ R(N) ≥ 1 恒成立 ✓（实测 3.14~7.70，✓）
   · BCF Thm 1（引用）：I(V_N) ~ C/logN 且 V_N 渐近最优 ⟹ d_N² ~ I(V_N) ~ C/logN ⟹ R(N)→1。
     实测 R(N) 从 7.9 降向 3.1，方向正确但 N≤320 远未到 1 —— 与"V_N 在 N→∞ 才最优"一致 ✓
【R(N) 对 T 的依赖（核验）】固定 N，R(N) 随 T 微降（如 N=160：3.759→3.704→3.690）；
   这与 d_N² 随 T **上升**（0.04822→0.04914→0.04938）而 I(V_N) 随 T 微升（0.18127→0.18202→0.18223）
   同时发生 ⟹ T 截断只移小数点后几位，**不是** 5.5× 量级分歧的来源 ✓
```

## §7 结论：为何"行为相反"与"~5.5×"都不是归一化错

```
【核心事实（推导 + 核验）】d_N² 与 I(V_N) 是**两个不同对象**：
   d_N²  = inf 全体 a_n 的平方距离（下确界，随 N 单调**不增**，实测 0.0558→0.0477 ✓）
   I(V_N) = 固定 V_N=(1−log n/logN)μ(n) 的平方距离（显式值，恒 ≥ d_N²，实测 0.44→0.15 ✓）
【为何 d_N²·logN 升、I(V_N)·logN 降（推导）】
   · V_N 的 (1−log n/logN) 软化对"逼近 1/ζ 的 μ 系数"是为渐近最优**调过的**，故 I(V_N) 已呈 1/logN
     形状（乘积降），只是常数 ~20C 尚未收敛到 C。
   · d_N² 是下确界，在小 N 下用全部 N 个系数把 1 逼近得比软化 μ 更好（0.048 << 0.181），故它的
     N 依赖**更平坦**：d_N² 下降慢于 1/logN ⟹ 乘积 d_N²·logN **暂时上升**（"驼峰"前段）。
   · 二者都合法地位于 Burnol 下界 C/logN **之上**（Burnol 只证 liminf d_N²·logN ≥ C，引用）✓
【"5.5×" 的本质（引用 + 推导）】
   · d_N² ~ C/logN 是**猜想**（BS04 猜想；BCF 在 RH+矩假设下才给出上界 C/logN，引用），**不是已证定理**。
   · 数值在 N=160–320 看到 d_N²·logN/C ≈ 5.4–6.0，是**有限-N 慢收敛**（对数对数量级修正 +
     远离渐近区），与"下界很松、上界条件性、两端只在 RH+矩假设下相遇"的已知图景一致 ✓
   · 因此"比值 ~5.5 倍且单调升"**不是**我们算错了尺子，而是**这个量在小 N 本就该远离渐近常数**。
【判据归属】任务 (C)"R(N) 稳定 ~1"不成立；任务 (B)"定位 k_N"经查证**无 k_N 可定位**；
   最终落在 (A)→(B)→(C) 之外的诚实分支：**归一化已对齐，L2 失败，5.5× 为真实有限-N 现象** ✓
```
