## 1. 最弱充分命题 + 紧度数值

### 1.1 最弱形式（两次弱化）

目标命题（强）：`∀n≤T0²，|S_n| ≤ (1−δ)(N − nB_T0)`。

**最弱充分命题 (P_weak)**（够用且最省）：
```
∀ 整数 n, 1 ≤ n ≤ T0² :
    Re S_n ≤ N − n·B_T0   ⟺   Σ_{γ≤T0} (1 − cos nθ_γ) ≥ n·B_T0.
```
两次弱化：**(i)** 只用实部 `Re S_n ≤ |S_n|`；**(ii)** 只要求**精确阈值**（不加 δ 缓冲）。
等价写法 `Σ(1−cos nθ_γ) ≥ nB` 是最干净的：左边是"相位绕圈的亏损"，右边是额度。

### 1.2 瓶颈定位（`PAPERA_uni_weakest.txt`）

扫 559 个 n（[1,300] 稠密 + 对数采样到 T0²）：

| n | 1 | 14 | 100 | 1e6 | 1e9 | 1e12 | T0² |
|---|---|---|---|---|---|---|---|
| `Re S_n` | 2.001052e6 | 2.001050e6 | 2.000993e6 | 1.43e4 | 524.5 | 726.2 | **−217.2** |
| `|S_n|` | 2.001052e6 | 2.001050e6 | 2.000993e6 | 1.14e6 | 2503 | 765.5 | **347.1** |
| `δ_Re(n)` | **5.77e-9** | 1.10e-6 | 2.96e-5 | 0.993 | 1.00 | 0.999 | 1.00 |
| `δ(n)`（\|S_n\|） | **5.75e-9** | 1.10e-6 | 2.95e-5 | 0.428 | 0.999 | 0.999 | 0.999 |

`min_n δ(n) = 5.7530e-9` **在 n=1**（Re-form 5.7699e-9，同一处）。δ 定义 `δ(n) := [(N−nB) − |S_n|]/(N−nB)`。
**注意 δ 的"最小"≠ 最难**：n=1 处 `s(1) = Σ(1−cos θ) − B = 0.011546`，其相对 nB 的余量是 **10998 倍**——这是**小相位 regime，初等可证**（下节），不是 √N 缺口。

### 1.3 两个 regime 的精确分割

**(i) 初等 regime `n ≤ 14`（真证明）**。`θ(γ₁) = 0.07072`，`1/θ(γ₁) = 14.14`，故 `n ≤ 14 ⟹ nθ_γ ≤ 1 ∀γ`。
用 `1 − cos x ≥ x²/3`（|x|≤1，初等）：
```
Σ(1−cos nθ_γ) ≥ (n²/3)·Σθ_γ² = n² · 0.007699   （Σθ_γ² = 0.023097 实测）
需要 ≥ nB_T0  ⟺  n ≥ 3B/Σθ² = 1.36e-4  ⟹  所有整数 n ≥ 1 均满足，余量 7334 倍。
```
**⇒ n ≤ 14 全部初等可证**（与 `PAPERA-expsum.md` §2 一致）。

**(ii) 常数因子 regime `n ≳ 0.3 T0²`（唯一未证部分）**。命题要求 `|S_n| ≤ (1−c)N`，`c = nB/N = (n/T0²)·0.6728`：

| 所需节省 c | n / T0² | allowance/N |
|---|---|---|
| 0.05 | 0.074 | 0.95 |
| 0.10 | 0.149 | 0.90 |
| **0.20** | **0.297** | **0.80** |
| 0.6728（端点） | 1.0 | **0.327** |

**"n ≳ 0.3T0² 才需常数因子节省" = 需要 ≥20% 节省**（`|S_n| ≤ 0.8N`）。
端点 `n=T0²`：需证 `|S_n| ≤ 0.3272N`；**真值 `|S_n| = 347.1 = 1.73e-4·N`，比需证的还低 1900 倍**；而平凡界 N 只比需证的高 3 倍。

**紧度陈述**：形式瓶颈在 n=1（δ=5.75e-9，初等）；实质瓶颈在 `n ∈ [14, T0²]`（需证常数因子节省，真值 1900× 富余，平凡界仅 3× 富余）。**P_weak 为真（数值），唯一未证内容是"常数因子节省 `|S_n| ≤ (1−c)N`"**。

## 2. 路线甲 · 均匀性直接（Weyl / Erdős–Turán / large sieve）

### 2.1 Weyl 判据 → 循环

`{nθ_γ/2π mod 1}` 等分布 `⟺ (1/N)Σ_γ e^{2πi m·nθ_γ/2π} → 0 ∀m≥1 ⟺ S_{mn}/N → 0 ∀m≥1`。
**m=1 条件就是 `S_n/N = 目标本身`** ⟹ Weyl 把要证的东西写成了自己的前提之一。

### 2.2 Erdős–Turán → 循环

`D_N ≤ C(1/M + Σ_{k≤M} (1/k)|S_{kn}|/N)`（C=2）；Koksma：`|Σcos(nθ_γ)| ≤ 4N·D_N`。
**k=1 项 = |S_n|/N = 目标**。上一轮实测（`PAPERA-fluc-round2` §4）：n=T0² 处 ET 界 5.67e5 勉强 < 额度 6.55e5，但 **94% 是 1/M 地板**；同 M 下 n=1e6 处失效 9.5×。要求 `|S_k| ≤ 0.0058N` 对**所有** k≤~30 成立——比原题更难。**循环 + 量级无用**。

### 2.3 large sieve → 结构性不可能

Montgomery–Vaughan large sieve（点集 `x_j = θ(γ_j)/2π`，系数 `a_j≡1`）：
```
Σ_{m=M+1}^{M+Q} |Σ_j e^{2πi m x_j}|² ≤ (Q + 1/δ)·N ,   δ = min_{j≠k}‖x_j−x_k‖.
```
实测（`PAPERA_uni_largesieve.txt`）：`min|θ_{k+1}−θ_k| = 5.67e-15 ⟹ δ = 9.02e-16 ⟹ 1/δ = 1.11e15`。
单频界：`|S_n| ≤ (N + 1/δ)^{1/2}√N = 4.71e10`，**比平凡界 N 坏 23538 倍**。

**根因**：`θ = 1/γ` 把区间顶端压缩——`γ∈[T0/2,T0]` 映到 `θ∈[1/T0,2/T0]`（长 ~1/T0，含 ~N/2 点），故 `min 间距 ~1/(T0²log)` 而 `N ~ T0 log T0`，即 **`1/δ ~ T0² ≫ N`**。

**定理级障碍（结构性，非数值运气）**：large sieve 是 **L²（二阶矩）** 界。对常数系数 `a_j≡1` 它给 `|S_n| ≤ √((Q+1/δ)N)`。要得到 `|S_n| < N`（任何常数因子节省）需 `Q + 1/δ < N`，即 `1/δ < N`。此处 `1/δ = 1.11e15 > N = 2.00e6`，**连 `|S_n| ≤ N` 都达不到**。常数因子节省需要 L¹/L^∞（相消/等分布）结构——而那正是 Weyl/ET 用 `S_n=o(N)` 重新表述的东西。**"避开 ET 循环"不可能**：所有均匀性工具都把目标写成自己的一个条件。

**判定：不成（循环 + 结构性不可能）**。均匀性作为"输入"方向错了——它**改写**目标，从不**界定**目标。

## 3. 路线乙 · 矩量替换点态输入（Selberg / Tsang）

### 3.1 设置（`PAPERA-expsum.md` §3）

`S_n = S_n^smooth + D_n`，`D_n ≈ Σ_k (e^{iλ_k S_k} − 1) e^{iφ_k}`，`λ_k = 2πn/(γ_k² log(γ_k/2π))`，`S_k = k − N̄(γ_k)`。
共振分裂 `λ(γ_res)=1`，`γ_res = 8.2683e5`：**A**（λ>1 快）`|e^{iλS}−1| ≤ 2`，`N_A = 1,419,561`；**B**（λ≤1 慢）`|e^{iλS}−1| ≤ λ_k|S_k|`，`N_B = 581,491`。
```
|D_n| ≤ 2N_A + Σ_{k∈B} λ_k |S_k|.
```
上一轮用 `sup|S| = 1.0·log T0 = 13.94`，得 `2N_A + 13.94·Σ_Bλ_k = 8.70e6`（**13.3× 超额度**）。

### 3.2 显式关系式 + 数字

**点态（更锐常数）**：`Σ_{k∈B} λ_k |S_k| ≤ sup_B|S_k|·Σ_Bλ_k`。
- 锐常数 `|S(t)| ≤ 0.110 log t + 0.290 log log t + 2.290 = 4.587`（Platt–Trudgian 2021，**出处未核验**）；实测 `sup_k|S_k| = 1.799`（**不可入证明，否则循环**）。
- `Σ_Bλ_k = 4.1866e5` ⟹ 点态项：粗糙 5.84e6 / 锐 1.92e6。

**L²（Selberg 1946 二阶矩，[出处：Selberg 1946]）**：
`∫_0^T S(t)²dt = (T/(2π²)) log log T (1+o(1))` ⟹ `∫_0^{T0}S² ~ 1.51e5`（S 的 RMS ≈ 0.365）。
Cauchy–Schwarz：
```
Σ_{k∈B} λ_k |S_k| ≤ (Σ_{k∈B} λ_k²)^{1/2} · (Σ_{k∈B} S_k²)^{1/2}.
```
- `Σ_Bλ_k² = 3.1233e5 ⟹ √ = 558.86`；`Σ_BS_k² = 2.1154e5 ⟹ √ = 459.93`（实测；Selberg 预测 `2·∫S²·(T0−γres)/T0 ≈ 3e5` 同阶，**采样转换需谨慎，标注**）。
- **CS 区域 B 项 = 2.5704e5**（比锐点态 1.92e6 改进 **7.5×**，比粗糙点态 5.84e6 改进 23×）。

### 3.3 总账与"区域 A 墙"

| 界 | 值 | ×额度 |
|---|---|---|
| 粗糙点态（上轮） | 8.6753e6 | 13.25 |
| 锐点态（Platt–Trudgian） | 4.7597e6 | 7.27 |
| **L²（Selberg）** | **3.0962e6** | **4.73** |
| **区域 A 单独 `2N_A`** | **2.8391e6** | **4.34** |

**判定：不成（区域 A 墙，4.3×）**。L² 把区域 B 从 1.92e6 压到 2.57e5（7.5×），但 **`2N_A = 2.84e6` 已恒超额度 6.55e5**——即使区域 B 完美归零（`Σ_B→0`），仍 `|D_n| ≤ 2.84e6` 差 4.3×。

**为何区域 B 的矩量救不了区域 A**：区域 A 里 `λ_k > 1`（γ₁ 处达 `λ_max = 4.97e10`），`e^{iλS}` 是快速相位，唯一点态界是 `|e^{iλS}−1| ≤ 2`，**S(t) 的矩完全不进入**。区域 A 是相位增量（vdC）问题，不是刚性矩量问题（交给路线丙）。**13.3× → 7.3× → 4.7× 的压缩全在区域 B，但区域 A 的 4.3× 墙不可逾越。**

## 4. 路线丙 · 刚性 → 相位增量（分位数/截断/矩版）

### 4.1 设置（`PAPERA-expsum.md` §4 复现）

离散 vdC 二阶差分检验（**定理：Graham–Kolesnik《van der Corput's Method》二阶导检验，常数待核**）：
```
|Σ e^{iφ_k}| ≤ M√Λ + Λ^{-1/2},   Λ = max_k |n·Δ²θ_k|,  Δ²θ_k = θ_{k+2}−2θ_{k+1}+θ_k.
```
区域 B（γ>γ_res 慢）：`Λ ≈ n·max|gap跳变|/γ²`。**sup-form：`Λ_B = 2.844 ⟹ 9.81e5`，超额度 1.50×**（上轮）。`max|gap跳变| = 1.663`（rms 0.353），需 ≤0.675。

### 4.2 截断版（把 max 换成"少数坏点单独处理"）

gap 跳变尾部分布（区域 B）：中位 0.242、0.99 分位 0.893、0.9999 分位 1.333；`max = 1.663` 仅 **~2 个点**。
阈值 τ = 0.675（≈所需 Λ 阈值）：**坏点 31500（5.4%）**，好点 549989，`Λ_good = 1.262`，`M_good√Λ = 6.179e5`。

| 版本 | 界 | ×额度 | 判定 |
|---|---|---|---|
| sup-form（标准定理） | 9.81e5 | 1.50 | 差 50% |
| 截断（朴素，单块） | 6.494e5 | 0.992 | **数值过线，非严格** |
| **截断（严格 run-split）** | **6.702e5** | **1.024** | **差 2.4%** |
| Σ-form（矩版，启发） | 3.622e5 | 0.553 | 1.81× 低于额度（**引理未核验**） |

**严格 run-split**（把好点按 γ 顺序切成极大连续段，每段套 sup-form vdC，坏点逐点 ≤1）：
`#good-runs = 23396`（≤ #bad+1=31501），每段付 `1/√Λ = 0.890`：
```
bound = M_good√Λ + runs/√Λ + #bad = 6.179e5 + 2.08e4 + 3.15e4 = 6.702e5  (1.024× 超).
```
**朴素截断的 0.992× 是假象**（把好点当一整块，非连续）；严格版本是 **1.024×，差 2.4%**。

**Σ-form（矩版，候选引理未核验）**：`|Σe^{iφ_k}| ≤ √(M·L) + √(M/L)`，`L = Σ_k|Δ²φ_k|`（用总二阶差质量替代 sup）。
`L_B = 2.2563e5 ⟹ √(M_B L_B) + √(M_B/L_B) = 3.622e5`，**1.81× 低于额度**。**若此引理在 Graham–Kolesnik 中成立（未核验），区域 B 即闭合。**

### 4.3 区域 A 覆盖方案 → 无解

区域 A（γ<γ_res，1,419,561 项），`max n·Δ²θ = 2.0e10`（γ₁=14 处）。八度分箱：

| 八度 | M | max nΔ²θ | min(M√Λ, M) |
|---|---|---|---|
| [10,100] | 28 | 2.0e10 | 28 |
| [100,1e3] | 620 | 3.3e8 | 620 |
| [1e3,1e4] | 9494 | 2.4e6 | 9494 |
| [1e4,1e5] | 127926 | 2.2e4 | 127926 |
| [1e5,3e5] | 328590 | 198 | 328590 |
| [3e5,8.27e5] | 952903 | 20.2 | 952903 |

sup-form 八度和 = **1.420e6 = 平凡界 N_A**（每箱 `M√Λ > M` 都被截断到 M ⟹ vdC **不优于平凡界**）。
Σ-form：`L_A = 4.72e10 ⟹ √(M·L)+√(M/L) = 2.587e8`，仍 ≫ 额度（`1/γ²` 在 γ₁=14 发散是致命伤）。

**判定：区域 B sup-form 差 1.50×；截断（严格）差 2.4%；Σ-form（若引理成立）1.81× 低于额度；区域 A 无任何刚性输入可覆盖（sup=平凡界、Σ=2.6e8、一阶导假设失败）。**

| 丙·朴素截断 0.992× | **数值，非严格**（好点集非连续） |

**区分**：真正"证明"的只有 (a) n≤14 初等、(b) 甲的三条定理级否定、(c) 乙的 CS 界与区域 A 墙、(d) 丙的 sup-form/run-split 界；其余（δ 值、Σ-form、截断朴素版、刚性输入）是**数值或启发**。

## 6. 对本项目的意义

1. **命题被压到最小可证对象**：P_weak 的不可证部分严格等于"常数因子节省 `|S_n| ≤ (1−c)N`"，且只需 `c ≥ 0.2`（n ≥ 0.3T0²）起，端点 c = 0.6728；真值比需证的富余 **1900×**，平凡界只富余 **3×**。
2. **三条均匀性路线全部定量判死**：甲（large sieve）是 **L² 结构性不可能**（`1/δ~T0²≫N`）；乙被**区域 A 墙**挡住（`2N_A=2.84e6`，矩量救不了快速相位）；丙在区域 B 逼近到 **2.4%**（截断）甚至 **1.81× 富余**（若 Σ-form 引理成立），但区域 A 的 `1/γ²` 发散**无解**。
3. **障碍收窄到一个可命名的算术对象（与上轮一致）**：区域 A = `D_n^A = Σ_{γ<γ_res}(e^{iλ_kS_k}−1)e^{iφ_k}`，相位 `nθ(γ)` 导数 `n/γ²` 在 γ₁=14 发散；这是"**S(t) 的增量在频率 λ=2πn/(γ²log) 下的等分布**"命题——现有 `S(t)=O(log t)`、Selberg CLT（对 n 不一致）、Montgomery 对相关（线性相位，转换代价 `e^{Θ(n)}`）三条都**不提供**。
4. **下一步最省力入口（两条缝）**：(i) 验证丙的 **Σ-form vdC 引理**（若成立，区域 B 闭合，问题纯化为区域 A）；(ii) 找 **Selberg CLT 的"定量 + 对频率一致"版本**（把 `n→∞` 换成 `n≤T0²` 一致）——这仍是 `PAPERA-expsum.md` §5 定位的那条窄缝。
5. **负面结果留档**：甲（均匀性输入是循环/结构性无望）、乙（矩量救不了快速相位区）、丙（刚性在区域 B 差 2.4%、区域 A 无覆盖）——三者防止后人重走。
