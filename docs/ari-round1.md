## 数值基础（素数到 10^8——）
- E(X) = (Ψ(X)−X)/X^{1/2}——在 X ∈ [1e4,1e8]：E ∈ [−0.46, +0.16]——振荡 ✓
- 尺度关系 E(X²) vs E(X)：无简单比（−0.22~14.2——）——符合模态相位差预期
- ⚠️ X ≤ 10^8（t ≤ 18.4——）只能看到低 γ 零点（P51-T4——）——数值受限

## T_a 的定义选项（核心——）
R_a(X) = E(X^a) − T_aE(X)——T_a 需要"纯算术定义"（不含 δ——）

### 选项 A：时间缩放（T_af)(t) = f(at)
- 平凡（R_a = 0——因为 E(X^a) 在 t 坐标 = E(at)——）
- 死（无信息——）

### 选项 B：模态匹配
- T_a 把 e^{λt} 变 e^{aλt}（保持"指数"——）
- 但——需"λ 缩放"的算子——在 t 坐标 = f(at)——同上平凡——或——需知道 λ（循环——）

### 选项 C：差分算子族
- T_a = 某种固定差分（E(X) − E(X^{1/a})——）
- R_a = E(X^a) − E(X^{a/2}) − [E(X) − E(X^{1/2})] 类——"二阶尺度差"——
- 模态：e^{λt} → e^{λat}(1−e^{−λat/2}...)—含 λ——分析中——
