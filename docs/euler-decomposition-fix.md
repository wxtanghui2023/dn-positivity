## 1. 围道法的错误

围道积分（r=0.6）计算的 log ζ 系数 z_k 有**系统误差**：
- 围道给 z_1 = −3.16，正确值 = **+1.84**（= ζ'(0)/ζ(0) = −0.919/(−0.5)）
- 高阶 z_k 误差累积 → λ_ζ 指数假象（2.668^n）

**验证方法**：z_1 = ζ'(0)/ζ(0)（解析可算）——围道不符 → 围道不可靠。

## 2. 真实结构（可靠，n≤15）

| n | λ_n | λ^{logζ}（log ζ 部分）| λ^h（Γ 部分）|
|---|---|---|---|
| 1 | +0.023 | **−1.84** | +1.86 |
| 5 | +0.576 | **−10.7** | +11.3 |
| 10 | +2.28 | **−70.7** | +73.0 |
| 15 | +5.05 | **−479** | +484 |

**λ^{logζ} < 0（超线性负），λ^h > 0（主导正）**，λ_n = λ^h + λ^{logζ} > 0。

## 3. 结论反转

- ❌ 之前的"Euler 积（log ζ）部分是正性来源"——**错误**（围道假象）
- ✅ **log ζ 部分（素数相关）是负贡献**
- ✅ **Γ 部分（Stieltjes）是正贡献（主导）**
- λ_n > 0 = Γ 部分（+73）超过 log ζ 部分（−70.7）——仍是精细平衡

## 4. 教训（重要）

1. **围道积分对 log ζ 在 s=0 的系数不可靠**（分支/奇点结构，r 选择敏感）
2. **验证不可少**：z_1 = ζ'(0)/ζ(0) 解析值是对照基准（围道不符即废弃）
3. **数值微分（ζ 在 0 无极点）是可靠方法**（z_1 = +1.84 ✓）
4. **Knessl-Coffey 的"亚线性"声明正确**（围道的指数发现是假象）
