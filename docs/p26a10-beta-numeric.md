# P26-A10：β 不变的数值验证——在线 vs 离轴（重要修正）

> 2026-09-01 · 唐先生问"β 不变支持多少数值" · 数值验证 + 严格修正

## 严格检查——重要修正
- **c_ρ 纯虚的推导依赖"1−ρ = ρ̄"（在线）**
  - 实系数：c_ρ̄ = conj(c_ρ)（在 ρ̄）——反射：c_{1−ρ} = −c_ρ（在 1−ρ）
  - **在线（β=½）：1−ρ = ρ̄——同一位置——conj(c_ρ) = −c_ρ——c_ρ 纯虚——✓**
  - **离轴（β≠½）：1−ρ ≠ ρ̄——不同位置——约束不合并——c_ρ 不必纯虚——⚠️**

## 数值验证（反射对称实函数构造）
M_b(s) = a/(s−ρ₀) + ā/(s−ρ̄₀) − a/(s−(1−ρ₀)) − ā/(s−(1−ρ̄₀))——反射对称 ✓ 实 ✓（任意 a）

| 位置 | 留数 | 结果 |
|---|---|---|
| **在线**（ρ₀ = ½+14.13i——a = 1+2i） | c_{ρ₀} = **0+4i**（a−ā = 2i·Im(a)） | **纯虚 ✓**（自动——a 任意复） |
| **离轴**（ρ₀ = 0.4+14.13i——a = 1+2i） | c_{ρ₀} = **1+2i**（= a） | **任意（β 可移动）** |

## ⭐ 修正——β 不变的支持范围
- **在线零点（β=½）：β 不变（Re δ_ρ = 0）——严格——数值强支持**（c_ρ = 2i·Im(a)——自动纯虚——机制稳健）
- **离轴零点（β≠½）：β 可移动（Re δ_ρ ≠ 0 可能）——数值确认**（c_ρ = a——任意）
- **A8 的"β 不变"应限定"在线零点"**——"离轴零点——β 可移动"——新认识

## 对 RH 的含义（诚实）
- "在线零点的 β 不变"（变形保持在线）——严格——但不排除离轴零点
- "离轴零点的 β 可移动"——如果 RH 假（有离轴）——合法变形（超分布类——如果存在）可移动离轴 β——方向/约束未探索
- "在线不变 + 离轴可动"——不对称——但——不 ⟹ 在线唯一——离轴 β 动力学未建立

## ⭐ 数值支持总结（回答唐先生）
- **"β 不变"数值支持：在线零点——强（自动——结构）——离轴零点——β 可动（无约束）**
