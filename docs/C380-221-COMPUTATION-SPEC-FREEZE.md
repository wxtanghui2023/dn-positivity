## §15 执行协议（唐先生 2026-09-22 16:42 令；**追加节，不改上文架构** ✓✓）

```
【定性】"有限实验" = **预先锁死输入、算法、预算、证书格式、停止条件的有限"认证"实验**
         （**不是**普通数值实验）✓✓

15.1 数学对象固定
     Θ = { (θ_a, θ_b, θ_c) : 0 <= θ_b <= θ_a <= π } ✓
     F_q(θ) = 2cos(qθ_a) + 2cos(qθ_b) + cos(qθ_c),   q = 1..12 ✓
     目标： ∀θ ∈ Θ,  max_{1<=q<=12} F_q(θ) > 1/2 ✓
     ⚠️ 逻辑：**不是**寻找 min_q max_q 的最小值；**而是**把 Θ 切成有限箱、每箱找一个 q 证实 F_q > 1/2 ✓✓

15.2 连续域 → 有限箱
     B = [a1,a2] × [b1,b2] × [c1,c2]，且须满足对称约束（如 b2 <= a2）✓
     第一原则：箱必须覆盖**整个** Θ（**不能**只覆盖采样点）⟹ 最终须有 Θ ⊆ ∪_{B∈B} B
     且该覆盖必须**由程序自动检查**（不得靠"网格看起来覆盖了"）✓✓

15.3 每箱只找一个见证频率
     for q = 1..12 : 若 inf_B F_q > 1/2 ⟹ 认证该箱并停止处理 ✓
     禁止 ： inf max 与 max inf 混用（ **inf_B max_q F_q  ≠  max_q inf_B F_q** ）✓✗

15.4 严格计算 inf_B F_q（变量分离 ⟹ 不需要通用三维区间算术 ✓✓）
     inf_B F_q = 2·CosMin(q,I_a) + 2·CosMin(q,I_b) + CosMin(q,I_c) ✓
     CosMin(q,[u,v])：① 看 qu, qv；② 看区间内是否有 (2k+1)π 型极小点；③ 有 ⟹ 最小值 = −1；
                      ④ 无 ⟹ 取两**端点精确包络** ✓（做成一极小、易独立复核的函数）✓

15.5 保守性要求（**必须**）
     禁止"float_min > 0.5 ⟹ 证明" ✗
     程序须产生**向外包络后的下界**： L_q^certified(B) <= inf_B F_q ✓
     只有 **L_q^certified(B) > 1/2** 才算证书 ✓
     每箱记录至少含： box | witness q | raw lower bound | certified lower bound | status(CERT/REFINE) ✓✓

15.6 B1：粗筛 ＋ 自适应二分

     · 全部 q 失败 ⟹ 标 **UNRESOLVED**（**不得**判"箱不可行"）✓
     ```
