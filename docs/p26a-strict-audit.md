# P26-A 严格审计：M(s) 解析延拓 / 极点抵消 / FE 一阶域

> 2026-09-01 · 唐先生要求的数学审计 · 结论：原极点论证有漏洞，T_ζA={0} 尚未严格证明

## 审计动机（唐先生）
"M(s) 在 Re s=0 有极点，而 M(1−s) 在该点有限"这一论证，需确认：
1. M 的解析延拓
2. 极点是否可能发生抵消
3. FE 的一阶线性化究竟在哪个函数域成立

## 审计结果——原论证有漏洞

### (a) 原"极点在 Re=0"论证不成立
**2πik/log p 是逐单项（termwise）极点，求和可以抵消。**

关键反例——平移方向 **b_p = c·log p**：
- 一阶变形 Ḟ/ζ = M(s) = Σ_p log p/(p^s−1)
- 解析上 **M(s) = −c·ζ'(s)/ζ(s)**（meromorphic 全平面）
- −ζ'/ζ 的极点在 **ζ 的零点 ρ（Re≈1/2）和 s=1**——**不在** 2πik/log p（Re=0）
- **说明：逐单项的 Re=0 极点在无穷求和中被抵消了**

数值验证（σ>1）：
| s | M_trunc | −ζ'/ζ |
|---|---|---|
| 2.0 | 0.551 | 0.570 |
| 3.0 | 0.165 | 0.165 |
| 1.5 | 1.237 | 1.505（截断尾部差大） |

→ M 与 −ζ'/ζ 只差截断尾部，解析上相等。

### (b) 平移方向仍被排除，但理由是别的
M = −c·ζ'/ζ 是 meromorphic 的（能延拓到 Re<0），但**不满足固定 Gamma 的 FE 一阶对称性**：
- M(s)=M(1−s) 需要对称
- 数值：M(2.5)=0.289 vs M(1−2.5=−1.5)=−2.994 → **不相等**
- 平移方向移动了 Gamma 因子，违反固定 Gamma
- **平移被排除，靠的是 FE 对称性，不是"Re=0 极点"**

### (c) FE 一阶关系的函数域
M(s)=M(1−s) 需要 M 在 **Re<0 有定义**（解析延拓）。
不能只在 σ>1 的级数层面谈——级数在 Re<0 不收敛。

### (d) 严格证明 T_ζA={0} 尚缺的一步
需证：**不存在非零 {b_p}，使 M=Σ b_p/(p^s−1) 能解析延拓到 Re<0 且满足 M(s)=M(1−s)**。
这一步**尚未完成**——原简单极点论证不足以支撑。

## 诚实结论
- **原 P26-A 的极点论证有漏洞**（逐单项极点可被求和抵消）
- **T_ζA_arith = {0} 目前未被严格证明**——应降级为"待严格验证的候选命题"
- 平移方向（b_p = c log p）确实被排除——但理由是 FE 对称性，且只是单个方向
- **一般情形（任意 {b_p}）的切空间平凡性——未证明**

## 下一步（严格化所需）

2. 关键工具候选：

   - 平移方向恰好是"无自然边界"的特殊情形（−ζ'/ζ 整的除极点）
   - 一般方向是否都有自然边界？——需要分析 {b_p} 的算术结构
