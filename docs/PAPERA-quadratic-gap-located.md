## 一、Oesterlé 论证的完整链条（逐字原文 ✓）

```
①  λ_n = 2∫_0^∞ [1 − cos nθ(T)] dN(T)        θ(T) = 2·arctan(1/(2T))
②  分部积分 ⟹ n⁻¹λ_n = 2∫_0^π sin(nθ)·N(½·cot(θ/2)) dθ
③  "Now replace N(T) by its large-T form (16) **neglecting δN(T)** and other O(θ^{−α}) terms:
    **the error is o(1) by the Riemann–Lebesgue lemma**, mainly because (16) makes
    δN(½·cot(θ/2)) **integrable over the closed interval [0,π]**"
④  ⟹ n⁻¹λ_n = ∫_0^π sin(nθ)·(1/θ)[8R₋₂(log(1/θ)−1) + 4R₋₁]dθ + o(1)
⑤  换元 nθ = t ⟹ λ_n = n∫_0^∞ (sin t/t)[8R₋₂(log(n/t)−1) + 4R₋₁]dt (mod o(n)) ⟹ 闭式 (15)
```

## 二、⭐⭐ **缺口在哪（精确表述）** ✓✓

```
【Oesterlé 的做法 ✓】误差项 2∫_0^π sin(nθ)·δN(½cot(θ/2))dθ → 0 **由 Riemann–Lebesgue 引理** ✓
   —— 因为 δN(½cot(θ/2)) ∈ L¹[0,π] ✓
   ⚠️ 但 **Riemann–Lebesgue 是【n → ∞ 的渐近命题】** ✗ ——
      它说"对每个固定函数，系数 → 0" ✓，**不说**"对给定 n，系数有多小" ✗✓

【二次范围需要的 ✓】把那个 o(1) **变成定量的** ✓✓：
      需要：|2∫_0^π sin(nθ)·δN(½cot(θ/2))dθ|  ≪ 主项（量级 2N(T₀)）✓
      且同时 n·B_{T₀} < 2N(T₀) ✓（这一条我方已有 ✓ —— N/B ≈ 2T₀² ✓ 数值已确认 ✓）

⟹ ⭐ **缺口 = "Riemann–Lebesgue 的有限 n 定量版"** ✓✓ ——
   即：**对 n ≲ T₀² 一致成立的振荡积分小性** ✓
```
