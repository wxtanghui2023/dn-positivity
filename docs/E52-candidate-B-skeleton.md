## 1. 骨架（✓ 本轮把它写成**可执行**形式 ✓）

```
【记号 ✓】E_n := Re S_n − (N − nB) ✓；要求 ✓：E_n ≤ 0 对所有 n ≤ X ✓
【步骤 ① 恒等式 ✓（已数值验证 ✓）】
   Σ_{n≤X} Re S_n = Σ_γ D_X(θ_γ) ✓，D_X(t) = Σ_{n=1}^X cos nt = sin((X+½)t)/(2sin(t/2)) − ½ ✓
【步骤 ② 一阶矩 ✓（已算 ✓）】均值 ≈ −7.5e−5 ✓ ≪ 许可均值 1.33e6 ✓ ⟹ 给不出结论（但确认无系统性障碍 ✓）
【步骤 ③ 二阶矩 ✓（结构已定 ✓）】
   Σ_{n≤X}(Re S_n)² = **XN/2** ✓（对角 ✓）+ (1/2)Σ_{γ≠γ′}[D_X(θ_γ−θ_{γ′}) + D_X(θ_γ+θ_{γ′})] ✓（非对角 ✓）
   ⭐ 而非对角核**只覆盖 ≤ 7 个间隙** ✓ ⟹ 是**局部配对和** ✓
【步骤 ④ ⭐ **Chebyshev ⟹ 例外密度【显式】** ✓✓（本轮的关键算术 ✓）】
   注意 ✓：E_n > 0 ⟺ Re S_n > N − nB ✓，而 N − nB ≥ (1 − BX/N) = **(1 − 0.6728)N = 0.3272N** ✓（端点最紧 ✓）
   ⟹ {E_n > 0} ⊆ {Re S_n > 0.3272N} ✓ ⟹ 由 Markov（用对角二阶矩 XN/2 ✓）：
      #{n ≤ X : E_n > 0} ≤ (X·N/2)/(0.3272N)² = X·(1/(2·0.1071·N)) = **X·4.67/N** ✓
      = X · **2.33×10⁻⁶** ✓✓
   ⟹ ⭐ **例外占比 ≤ 2.33×10⁻⁶** ✓（即 99.9998% 以上的 n ✓）
   ＋ 与数据一致 ✓：实测大 n 段 |Re S_n|/N ≈ 6.8e−4 ✓（远低于 0.327 ✓，余量 **483×** ✓）
【步骤 ⑤ 诚实边界 ✓（不变 ✓）】
   · 该骨架给出的是 **density-1 定理** ✓（"除 ≤ 2.33e−6 比例的 n 外" ✓），**不是** A1 的完整闭合 ✗
   · **真正待证的**是步骤 ③ 的**非对角界** ✓（局部配对和 ✓）—— 这才是本路线的**全部内容** ✓
   · 而"**所有 n**"仍需**逐点**输入 ✗（= 项目反复测到的 L∞/L² 价位差 ✓，前沿 4 倍 ✓）
```

## 2. 由骨架得到的**定理形状**（✓ 可写下来 ✓）

```
【候选定理 ✓】设 X = T₀² ✓。若局部配对和满足
   |Σ_{γ≠γ′, |γ−γ′| ≲ 7 间隙} D_X(θ_γ − θ_{γ′})| = o(XN) ✓
   则 **#{n ≤ X : Re S_n > N − nB} ≤ 4.67 X/N = 2.33×10⁻⁶ X** ✓
   ⟹ 即 **λ_n ≥ 0 对除至多 0.00023% 个 n ≤ T₀² 之外的所有 n** ✓
【价值 ✓】这是**新定理** ✓（虽弱于"所有 n" ✗）：把 A1 从"未证"变为"**除可量化的极小例外集外成立**" ✓
【代价 ✓】需要把步骤 ③ 的非对角界**证出来** ✓（局部配对和 ✓）—— 有界但**非平凡** ⚠️
【风险 ⚠️】局部配对和的**符号混合** ✓（D_X 可正可负 ✓，幅值可达 X ✓）⟹ 需**实质抵消** ✓；
   若抵消不足（如最坏情形累积 ✓），则上界可能退化 ✗ —— 这是**唯一的技术风险** ✓
```
