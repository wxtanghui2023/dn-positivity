## §1 双闭包迭代**一步退化 ✗**（✓ 分析 ＋ 数值 ✓）⟹ 它是"退化解探测器 ✓"，不是构造工具 ✗

$$\mathcal A(\{1\})=\{a\ge0:\ a+1\in S\}=S-1\ ✓\qquad \mathcal B(S-1)=\{b:\ b+(S-1)\subseteq S\}=\boxed{\{1\}}\ ✓$$
$$\qquad\Longrightarrow\ \boxed{(S-1,\ \{1\})\ \text{是闭包对的不动点}}\ ✓\ \text{且}= \textbf{退化解②}\ ✓（A+B=(S-1)+1=S\ ✓\ \text{全覆盖 ✓}）$$
$$\mathcal A(S)=\{0\}\ ✓（a>0\ \text{时取 }b\in S,\ b\equiv-a\bmod p^2\ ✓）,\qquad \mathcal B(\{0\})=S\ ✓\ \Longrightarrow\ \boxed{(\{0\},S)}\ ✓＝\textbf{退化解①}\ ✓$$
$$\textbf{数值 ✓（}X=4000\text{）}：\text{从 }A_0=\{0\},B_0=\{1\}\ \text{出发，\underline{第 1 轮}即得}\ |A|=2434,\ |B|=1,\ B=\{1\}\ ✓,\ \text{覆盖}\ 2433/2433=100\%\ ✓\ \text{以后不变 ✓}$$
$$\Longrightarrow\ \boxed{\textbf{结论 ✗}：\text{两个闭包都取【最大】✓ ⟹ 互相夹到极小 ✓ ⟹ 双闭包迭代只能收敛到两个退化解 ✗}\ ✓\ \text{（作为【覆盖监控】实验它对非退化解不可达 ✗）}$$
