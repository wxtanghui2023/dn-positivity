### 基本量
- 加法尺度损耗：α(x,y) = gcd(ad+bc, bd)（x=a/b, y=c/d 既约——未约分和 (ad+bc)/bd）
- 乘法尺度损耗：μ(x,y) = gcd(ac, bd)
- **路径曲率**（分配律的两种路径）：
  K(x,y;z) = [α(x,y)·μ(x+y,z)] / [μ(x,z)·μ(y,z)·α(xz,yz)]

### 性质
- K(x,y;z) = K(y,x;z)（加/乘交换）
- 四变量闭合曲率关系：K₁₂K₂₃K₃₁ = K₁₃K₃₂K₂₁（分配律立方路径的三维闭合）
