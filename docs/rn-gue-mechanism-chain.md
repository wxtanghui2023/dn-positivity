# r(n)=O(1) 的 GUE 机制链 — 文献定位与价值（2026-08-22 14:31）

## 核心机制链（我们的新发现）

```
δ_k = Δγ_k − 1/N'(γ_k)（间距偏差）
  ↓ lag-1 ≈ −0.39（2M 零点，普适：γ∈[10⁴,10⁶] 稳定）
f(γ_k) 平滑（相邻相关 0.995）
  ↓
d_k ≈ f·N'·δ 继承负相关（lag-1 ≈ −0.4）
  ↓ 方差压缩（3-间距和 std 0.47 < 独立 0.69）
r(n) = Σd_k = O(1)（λ_n 余项有界）
```

## 文献定位（唐先生搜索确认）

- Montgomery 对关联（1973）：任意零点对，非相邻自相关

- Gordon-Chavez（2021）：长程差分排斥，非相邻间距
- Bogomolny-Keating：对关联振荡，非相邻自相关

**定位**：相邻间距 lag-1 自相关的精确数值（−0.39）**可能是文献未精确记录的新数据**；Li 余项（λ_n）与间距统计的机制链**未被文献研究**（新发现）。

## 深化 (2026-08-22 14:50) — S 连接与无条件化尝试

### 重大发现: δ_k = -ΔS_k/N'(γ_k) 精确 (corr 0.9998)
- S(γ_k) = k-1-θ_RS(γ_k)/π (N(T) 无条件余项)
- δ_k 完全由 S 的差分决定 → 机制链来源从 GUE(猜想) → S(T)(无条件定义)
- ΔS_k 自相关: lag-1 = -0.36, lag-2 = -0.08 (负相关)

### ΔS 负相关机制
- 符号变化 0.619 (略高于随机), 大小补偿: 大正 ΔS 后平均 -0.136, 大负后 +0.148
- 模拟: 纯有界不足 (lag-1 ≈ -0.02), 需强均值回归 (OU κ≥0.7 才到 -0.36)
- S(γ_k) 本身 lag-1 = +0.19 (平滑漂移), ΔS 负相关来自跳跃+相位结构

### 无条件界尝试 (Abel 求和)
- |r(n)| = |Σf_kΔS_k| ≤ max|S|·Σ|Δf_k| + 边界
- Σ|Δf_k| 增长 (n=100: 7.4 → n=1000: 35.8, ~n^0.4) → 界太松 (~n^0.4·logT)
- 真实 ΔS 负相关 → |r(500)|=0.21, |r(1000)|=0.13, |r(2000)|=0.19 (很小!)
- 混合噪声 (ρ≈-0.17): |r|=3-78 (负相关确实压缩加权和)

### 卡点 (诚实)
- ΔS 负相关的无条件推导卡在 S 精细结构 (跳跃/相位 = RH 核心对象, 研究级)
- ρ → |r| 定量关系未建立 (模拟控制失败)
