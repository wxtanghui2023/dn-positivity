# Rédei R2——A 型三阶检验结果（判死——）

> 2026-09-07 · 唐先生 R2 设计（A 型 triangle-of-triangles——8 状态——max-ent pairwise null——）

## 设计
X₁ = R(a₁,b,c₁)——X₂ = R(a₂,b,c₁)——X₃ = R(a₁,b,c₂)——X₄ = R(a₂,b,c₂)
- 8 状态表（X₁X₂X₃——）
- pairwise max-ent null（Ising——保 marginal+pairwise——禁三阶——）
- Δ₃ = T_real − T_pair——D_KL——矩形 I□

## 结果（400 A 型样本——）
```
T_real = E[X₁X₂X₃] = 0.0400
T_pair = 0.0015
Δ₃ = 0.0385
D_KL = 0.00075（很小——）
bootstrap std = 0.0528——z = 0.73（< 3σ——）
矩形 parity 非零率 = 0.470（≈ 随机——）
```

## 判定：❌ R2 判死（按预定判死线——）
- 三阶残差 Δ₃ = 0.0385 但噪声 0.0528——**z = 0.73 不显著**
- D_KL 极小（0.00075——）——联合分布几乎完全被 pairwise 解释
- 矩形 parity 0.47 ≈ 随机

## 解读
- **单个 Rédei 符号的三体不可约性（R1——）没有产生跨三角形的高阶关联（R2——）**
- R1（单个 [a,b,c] 不可 pairwise 化——）与 R2（不同 [a,b,c] 间无超出 pairwise 的高阶关联——）可共存：
  - Rédei 每个符号是真三体（代数性质——）
  - 但符号之间统计上独立（无"高阶动力学"——）
- 这符合 Rédei 的数学性质：它是**确定性的代数函数**（类域论——）——不是"统计场"——单个符号的不可约性不意味着符号间的统计关联

## 结论（诚实——）
- R2 判死：Rédei 符号间无跨三角形高阶统计关联
- R1 的"单符号三体性"是代数事实（真三线性——）但**不产生统计可检测的"三体场"**
- Rédei 作为"统计三体机制"的候选——R2 不通过
- 作为"代数三体对象"——仍真实存在（R1——）——但它的"动力学/统计"层面为空
