## 1. Q_n(t) 的结构

$$Q_n(t) = -n\sum_{k=0}^{n-1} \binom{n-1}{k}\frac{(-1)^k t^k}{(k+1)!}$$

**关键性质**（已验证）：
- Q_n(0) = −n ✓
- 主导项（t 大）：Q_n(t) ~ (−1)^n·t^{n−1}/(n−1)! ✓
- 多项式增长（t^{n−1}）——但 log p 增长慢

## 2. S₂(n) 的 Euler 积表示（无条件——不预设零点位置）

$$S_2(n) = \lim_{N\to\infty}\left[\sum_{m\le N}\frac{\Lambda(m)}{m}Q_n(\log m) - \sum_{j=1}^{n}\binom{n}{j}\frac{(-1)^j(\log N)^j}{j!}\right]$$

**正规化**：减去 Σ C(n,j)(−1)^j (log N)^j / j!（发散抵消——raw 项 ~ ±200@N=1e6——reg 抵消——差 O(1)）

## 4. 等价链（唐先生——所有路径汇聚）

```
η_j 交替超衰减（严格）→ S₂(n) = Σ Λ(m)/m·Q_n(log m)（Euler 积）
 ↓
Q_n(t) = n∫_0^1 L_{n-1}(tu)du（Laguerre 表示）
 ↓
S₂(n) = Σ_ρ (1/ρ)[1−(ρ/(ρ−1))^n]（零点相位和）
 ↓
|ρ/(ρ−1)| = 1 ⟺ β = ½
 ↓
S₂(n) = O(1) ⟺ 相位均匀性 ⟺ RH
```

**核心方程（不循环）**：
$$\sum_p \frac{\Lambda(p)}{p}Q_n(\log p) - (\text{正规化}) = O(1)$$

- 从 Euler 积端：Σ_{m≤N} Λ(m)/m·Q_n(log m) = n·log N + O(1) ⟺ ψ(x) = x + O(√x) ⟺ RH
- 从零点端：Σ_ρ (1/ρ)[1−(ρ/(ρ−1))^n] = O(1) ⟺ 所有零点 β = ½ ⟺ RH

**这个等式的证明 = RH 本身——没有捷径。**
