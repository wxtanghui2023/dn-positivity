## 类别盘点

### 一、谱-几何对偶
- **Selberg 迹公式**：双曲曲面 Laplacian 谱 ↔ 闭测地线长——素数与零点类比的已实现版本——但类比 superficial（无 Dirichlet 级数——）
- **函数域 RH**（Weil/Deligne——）：Frobenius 特征值 = 零点——唯一成功"零点离散化"——char 0 缺 Frobenius

### 二、模性/自守桥（FLT 路线——已证——）
- 模性定理（Wiles/BCDT/Serre——）：离散↔解析桥——方向"对象→L 函数"——缺反构造
- 几何朗兰兹（Gaitsgory 2024——）：太远——影响间接

### 三、"L 信息→算术"方向（⭐ 未注意——）
- **Gross-Zagier/Kolyvagin/Euler 系统**：L 特殊值/导数 → 椭圆曲线算术（高度/秩——）——"解析→算术"已实现工具链——但连 L 值非零点位置——椭圆曲线 L 非 ζ

### 四、p-adic 族
- 完美oid/tilting——Fargues-Fontaine——岩泽主猜想——方向 p-adic——够不到复 Archimedean

### 五、已审计死（不重复）
谱/算子——正性——矩——显式公式——随机矩阵——物理类比——单值性——VIII

## 三大洞察
1. **方向性规律**：50 年成功桥都是"离散→解析"或"解析值→离散"——从无"零点位置→离散"
2. **Gross-Zagier = 最近方向模板**——L 值=算术量公式——50 年无人找到 ζ 零点实部的类似
3. **所有成功桥绕开 Archimedean 复零点位置**——证实 β 墙是数学空白非方法问题
