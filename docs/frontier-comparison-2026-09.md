## 一、Matomäki-Merikoski-Teräväinen："无 L 函数"筛法

### 技术核心
- 开发**新型筛法**——在"乘性结构集合"中检测素数
- 用**分布水平**（level of distribution θ + dimension k + density h）替代 L 函数零点信息
- 应用：Linnik 定理（最小素数 p ≤ q³⁵⁰——）无 L 函数新证明
  - Hoheisel（短区间素数——α=39/40——）无 L 函数证明
- 前置：Granville-Harper-Soundararajan 用 pretentious 数论给过无 L 证明（但指数很大）
- 优势：数值好——方法初等

### ⚠️ 关键理解（对我们——）
**他们绕开的到底是什么？**
- 绕开的是：**Dirichlet L 函数的零点信息**（零点的位置/零区域——）
- 没有绕开的是：素数的**统计分布本身**（γ 层信息——）

**为什么能绕开？**
- Linnik/短区间素数——本质是问"素数在模 q 的类里是否出现"——这是**γ 层问题**（零点虚部——）
- 可以用"分布水平"假设（Bombieri-Vinogradov 型——）替代——分布水平是"平均意义"的统计——不需要逐零点信息

### 对我们的意义（三层——）
1. **确认 γ/β 分工**：他们的成功再次证明——**γ 层量（素数分布——）可以完全绕开 L 函数**——因为素数的"统计出现"只依赖零点虚部的集体行为
2. **不触及 β**：β（零点实部——RH——）是"为什么统计恰好如此"的深层原因——分布水平假设（如 EH——）是**假设**而非证明——绕开 L 函数 ≠ 证明 L 函数相关猜想
3. **深层教训**：如果"素数分布的很多东西不需要零点"——那"零点位置（β）需要什么才能确定"的问题更尖锐——**β 是素数的"精确相位"信息——不是"统计出现"**——统计出现可以平均掉 β 的影响——但精确相位不能

## 二、Guth-Maynard：矩阵谱工具打破 Ingham 界

### 技术核心
**问题**：Dirichlet 多项式 D(t) = Σ_{n~N} b_n n^{it} 在 t∈W 上取大值 V≈N^{3/4}——|W| 多大？

**矩阵化**：构造 |W|×N 矩阵 M_{t,n} = n^{it}
- D(t) = (Mb)_t
- Σ_t|D(t)|² = ||Mb||² ≤ ||M||²·||b||² ≤ N||M||²
- ⟹ |W| ≤ N^{-1/2}·s₁(M)²（s₁ = 最大奇异值）

**谱工具**：s₁(M) ≤ tr((M*M)^r)^{1/2r}（迹控制最大特征值——）
- r=1：经典均值定理（Ingham 界——）
- r=2：Montgomery-Halász-Huxley
- **r=3（关键创新）**：三线性形式
  - s₁(M)⁶ ≲ Σ_{t₁t₂t₃} Σ_{n₁n₂n₃} n₁^{i(t₁−t₂)}n₂^{i(t₂−t₃)}n₃^{i(t₃−t₁)}
  - 目标：证明它比 T³ 小一点
- **难点**：c_{t_i−t_j} 系数耦合 t₁t₂t₃——难以消去
- **突破**：用 decoupling/几何方法处理（避免逐项近似函数方程——）

**结果**：N(σ,T) ≤ T^{30(1−σ)/13}——Ingham 12/5 → 30/13 ≈ 2.308
- 短区间素数渐近：x^{17/30+o(1)}

## 三、与我们 dn-project 框架的对照（重点——）

### 对照 1：Guth-Maynard 的"迹"vs 我们的"负惯性"
| | Guth-Maynard | 我们（P27——）|
|---|---|---|
| 对象 | Dirichlet 多项式大值 | Weil 二次型/缺陷核 |
| 工具 | s₁ ≤ tr((M*M)^r)^{1/2r} | n₋(K_N) = N（Sylvester——）|
| 本质 | 谱范数控制 | 负惯性（符号差——）|
| 层级 | **γ 层**（零点虚部统计——）| β 层（零点实部——）|

**洞察**：两者都是"线性代数控制解析对象"——但 G-M 的矩阵来自 **n^{it}（γ 层频率——）**——我们的核来自 **β 缺陷（实部位移——）**——工具同族——对象不同层

### 对照 2：为什么 G-M 能突破而我们不能？
- G-M 的 r=3 迹：**t₁t₂t₃ 三体耦合**——他们用 decoupling 处理
- 我们的 P28-P33：**n₋=N 有限惯性 → 不传递到无限维**（moving-edge——）
- **深层相似**：G-M 的三体耦合消去困难 ↔ 我们的"交叉项消除需分辨"（放大↔分辨——）
  - G-M 在**有限维矩阵**里处理耦合——成功（因为 W 有限——）
  - 我们在**无限维**里处理耦合——失败（因为"所有零点"——）
  - **这正是 P28-P33 的核心：有限→无限的跳跃是障碍**

### 对照 3：零密度估计的天花板
- G-M 的密度界 N(σ,T) ≤ T^{30(1−σ)/13}——指数 2.308
- 它限制的是**离轴零点的数量**（σ>1/2 的——）
- **但**：在 σ→1/2 时——界 → T^{o(1)}？——不——(1−σ)→0——界 → T^0 = 多项式——**接近临界线时密度定理失效**
- **与我们反证法的对照**：
  - 我们（8/23——）：反证法排除"无穷多离轴"（多项式 vs 指数——）
  - 密度定理：给"任意高度离轴数量的上界"——但在 σ=1/2+ε 附近很弱
  - **共同边界**：近线离轴（σ 极接近 1/2——）是密度定理和反证法的共同盲区——需要"排除有限个/近线"——即 RH 的核心

## 四、结论（对 RH 研究的意义——）

1. **Matomäki 证明"γ 层无需零点"**——但 β 层（RH——）恰恰是 γ 层统计的"为什么"——不能反推
2. **Guth-Maynard 的谱方法值得吸收**：他们的 r=3 迹/decoupling 处理"三体耦合"——与我们的"交叉项"问题是同一数学困难——**他们在有限维成功——我们在无限维撞墙——这精确验证了 P28-P33**
3. **新工具方向**：如果他们的 decoupling 方法能推广到"无限维迹"——可能有新路——但他们的 W 有限（|W| 个点——）——无限维的 decoupling 是开放问题
4. **Guth-Maynard 密度界 + 我们的反证法 = 互补**——都指向"近线/有限离轴"是 RH 的最终障碍——**这与我们 9/4 澄清的"有限离轴缺口"完全一致**
