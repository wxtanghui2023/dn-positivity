## 本轮进展

### ⭐ 有限支撑的干净证明（Bohr 系数匹配——比 Dirichlet 唯一性更直接）
**两侧表示**：
- Re s = σ>1（Euler 级数）：M_b(σ+it) = Σ b_p p^{−kσ} e^{−ikt log p}——频率 e^{−ikt log p} 系数 = **b_p p^{−kσ}**
- Re w = α<0：|p^w|<1——1/(p^w−1) = −Σ_k p^{kw}——M_b(w) = −Σ b_p p^{kw}——频率 e^{ikt log p} 系数 = **−b_p p^{kα}**

**反射匹配**：M_b(σ+it) = M_b(1−σ−it)——右侧（1−σ<0——t→−t）= −Σ b_p p^{k(1−σ)} e^{−ikt log p}
- 反射 ⟹ b_p p^{−kσ} = −b_p p^{k(1−σ)} ⟹ **b_p[p^{−kσ} + p^{k(1−σ)}] = 0**
- **p^{−kσ} + p^{k(1−σ)} > 0（σ>1——两项正——数值确认 0.75/0.31/0.44/0.12）⟹ b_p = 0**

**数值验证**：有限支撑左侧系数（p=2: −0.7072 vs 理论 −0.7071——匹配 ✓）

### ⚠️ 修正——反射能量不相容（Parseval）有循环问题
- F(σ) = F(1−σ) 在反射下**自动**（M_b(1−σ+it) = M_b(σ−it)——同函数）——不是矛盾
- **真正的矛盾来自"系数匹配"**（−b_p p^{kα} vs b_p p^{−kσ}）——而非能量
- 之前的"反射能量不相容"（数值 0.067 vs 1360）——是"形式反射级数"的——不是真实延拓值——需撤回为"循环"

### 无限支撑的缺口（精确化）
- 左侧表示 M_b(w) = −Σ b_p p^{kw}（Re w<0）——**对无限支撑不收敛**（每项 ~ −b_p——Σ b_p 发散一般）
- 延拓值（Re<0）**不是** Σ b_p/(p^w−1)（不收敛）
- **核心缺口：延拓值（Re<0）的频率系数——未知道**
- 若"自然性"（延拓在 Re<0 的频率系数 = −b_p p^{kα}）成立——匹配 ⟹ b=0——**但"自然性"未证**
- Phragmén-Lindelöf 型（Re>1 有界 + Re<0 有界（反射）+ 有限阶）——可能强制结构——但极点（Re=0）未解决
