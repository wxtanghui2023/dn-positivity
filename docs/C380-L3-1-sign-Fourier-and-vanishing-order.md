```
【设置】 碰撞对 `(i,j)`：`x_i − x_j = δ → 0`（记共同值 `x`）；记 `g(x) := √x · R_r(x)` ⟹ `w_{r,j} = g(x_j)` ✓

【反号（`ε_i = −ε_j`）】 `N = ε_i[g(x_i) − g(x_j)] + … = δ·g′(x) + O(δ²)` ⟹ **`ν_N = 1`**（系数 `g′(x)` ✓）
【例外】 `R_r(x) = 0`（`R_r` 在 `(0,1)` 内的根 ⟹ 低阶表已给 ✓）⟹ **同号亦降阶至 `ν_N ≥ 1`** ✓

　　⭐ **正是令 L3-1D 明令禁止的"路径依赖伪稳定"** ✗✗ ⟹ **反号字符一律出局** ✓✓
