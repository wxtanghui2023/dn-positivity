## 1. 干涉测量设计

```
γ → γ + ε·sin(ωγ)（同频双扰动）
χ₁₂(ω) = ∂²λ/∂ε² = 4n²Σcos(2nθ₁)·θ₁'²·sin²(ωγ)（交叉项——光谱）
选择频率 ω——提取 cos(2nθ₁) 的分量——光谱学
```

## 2. 结果

```
χ₁₂(ω) 峰：0.55, 0.75, 1.00, 1.25, 1.45（间隔 0.20-0.25）
【不随 T 变】（N=100k/300k/500k 完全一致——普适外观！）
但 π/γ₁ = 3.14/14.13 = 0.222——【匹配间隔】——γ₁ 主导！
θ₁' ~ 1/(4γ⁴)——γ 小（γ₁）主导——sin²(ωγ₁) 振荡——周期 π/γ₁
→ 平凡（与 r(n) 频谱的单零点主导一致）
```
