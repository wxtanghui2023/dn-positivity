## Lemma 1（Kernel Lemma——核无频率盲区）

**陈述**：固定 η > 0。K_η ∈ S′(ℝ)（缓增分布——Hadamard 有限部分意义），其分布傅里叶为：
$$\widehat K_\eta(\omega) = \frac{\pi|\omega|}{\eta^2}(1-e^{-\eta|\omega|}) > 0 \quad (\omega \neq 0)$$

**证明骨架**：
1. 部分分式分解：
   $$K_\eta(d) = -\frac{1}{\eta^2 d^2} + \frac{1}{\eta^2(\eta^2+d^2)} - \frac{2}{(\eta^2+d^2)^2}$$
2. 标准分布傅里叶：
   - F[PV(1/d²)] = −π|ω|
   - F[1/(η²+d²)] = (π/η)e^{−η|ω|}
   - F[1/(η²+d²)²] = (π/(2η³))(1+η|ω|)e^{−η|ω|}
3. 代入组合：
   $$\widehat K_\eta(\omega) = \frac{\pi|\omega|}{\eta^2} - \frac{\pi|\omega|}{\eta^2}e^{-\eta|\omega|} = \frac{\pi|\omega|}{\eta^2}(1-e^{-\eta|\omega|})$$
4. 正性：|ω| > 0 且 η|ω| > 0 ⟹ 1−e^{−η|ω|} > 0——故 K̂_η(ω) > 0（ω ≠ 0）∎

**闭合点**：部分分式每一项的分布意义（PV 1/d² 的严格性——标准）。

**数值验证**：闭式 vs 数值（FFT 卷积 K∗H = w 误差 1e-15——间接确认）。

## Lemma 2（Exchange Lemma——二阶极限与零点求和交换）

**陈述**：
$$\lim_{\eta\to0} \sum_\rho \frac{D_\eta^{(\rho)}(T) - D_\eta^{(0)}(\rho,T)}{\eta^2} = \sum_\rho \eta_\rho^2 K(T-\gamma_\rho)$$
其中 D_η^(ρ) 是单零点 ρ 的中心差贡献。即 lim 与 Σ 可交换。

**证明骨架**（支配收敛）：
1. 逐项极限（固定 ρ）：
   $$\lim_{\eta\to0} \frac{D_\eta^{(\rho)} - D_\eta^{(0)}}{\eta^2} = \eta_\rho^2\left[-\Re\frac{1}{(\eta_\rho - i(T-\gamma_\rho))^2} - \frac{1}{(T-\gamma_\rho)^2}\right] = \eta_\rho^2 K(T-\gamma_\rho)$$
   （η 展开：log|±η−η_ρ+id| 的一阶 η 抵消——二阶 −η²Re[1/(η_ρ−id)²]——减在线投影 η²/d²）
2. 支配函数（关键——分远场/近场）：
   - **远场**（|T−γ_ρ| ≥ δ > 0）：数值验证 |K(T−γ_ρ)| ≤ C(1+|T−γ_ρ|)^{−4}——结合 N(T) ~ (T/2π)log(T/2π)：
     $$\sum_{\rho: |T-\gamma_\rho|\ge\delta} \eta_\rho^2 |K(T-\gamma_\rho)| \le \frac{C}{4} \sum_\rho (1+\gamma_\rho)^{-4} < \infty$$
   - **近场**（|T−γ_ρ| < δ——有限个零点——因零点间距 ~ 1/log γ）：需要局部估计
     $$|R_\eta(\rho)| \le C \frac{\eta_\rho^2}{\eta_\rho^2 + (T-\gamma_\rho)^2} \text{（型）}$$
     有限和——有界——交换合法
3. 支配收敛定理（Lebesgue）应用——lim 入 Σ ∎

**闭合点**（⚠️ 最硬）：
- 近场局部估计的严格形式——η_ρ 与 d = T−γ_ρ 同阶时的控制
- 零点间距下界（γ_{n+1}−γ_n ≥ c/log γ_n——已知——用于近场零点有限性）
- η_ρ 的界（|η_ρ| < ½——临界带）保证 η_ρ² 系数有界

**数值验证**：远场支配（|K|/(1+d)^{−4} ≤ 20——Σ(1+γ)^{−4} 收敛——n=100000 累积 1e-14）；逐项极限（η_ρ=0 精确抵消——η_ρ≠0 η²级）。

## Lemma 3（Positive Weight Lemma——正权测试函数存在）

**陈述**：存在 H ∈ S′(ℝ)/ℂ（缓增分布模常数）——Weil 显式公式合法——使：
$$K_\eta \ast H = w > 0, \qquad w(\gamma) \sim (1+\gamma^2)^{-s} \ (s > 1/2)$$

**证明骨架**：
1. 构造（频域除法）：Ĥ(ω) = ŵ(ω)/K̂_η(ω)——K̂_η(ω) > 0（ω ≠ 0——Lemma 1）⟹ 逆存在（ω ≠ 0）
2. ω=0 处处理：K̂_η(ω) ~ πω²（ω→0）——Ĥ ~ ŵ(0)/(πω²) 奇异——但：
   - Ŝ(0) = 0（S 零频为零——数值 1e-17）——Parseval 配对 ⟨S,H⟩ = ∫ŜĤ 在 ω=0 处乘积 Ŝ·Ĥ ~ ηŵ(0) 有限
   - 或去常数 w−c（∫(w−c) = 0——ŵ(0) = 0——Ĥ 零频有限）
3. Weil 合法性：H 的构造经 Poisson 核正则化（见下）——属于 Weil 允许空间
4. 正性：w(γ) = (1+γ²)^{−s} > 0——K∗H = w——数值 FFT 误差 1.36e-15 ∎

**Weil 合法性的正则化**（墙 A 的解决）：
- 直接测试函数 log(1+η²/(T−γ)²)——傅里叶 O(1/ω)——素数项发散——不合法
- **Poisson 核积分表示**：
  $$\log\left(1+\frac{\eta^2}{(T-\gamma)^2}\right) = \int_0^\eta 2u \cdot \frac{1}{u^2+(T-\gamma)^2}\,du$$
- 内部 P_u(t) = 1/(u²+t²)——傅里叶 (π/u)e^{−u|ω|}——**指数衰减**——素数项 Σ_p (log p/p^{m/2})·(π/u)e^{−um log p} 收敛 ✓
- 外部 u ∈ [0,η] 有限积分——收敛
- ⟹ D_η^(0) 的 Σ_ρ 部分 Weil 无条件可算

**闭合点**：
- H 的 S′/ℂ 严格配对（⟨S,H⟩ 而非 ∫SH——分布意义）
- ŵ(0) = 0 的构造（去常数——或——Ŝ(0) = 0 自动抵消）的选择
- Weil 显式公式对 H（模常数）的适用性——需引用/推广标准形式

**数值验证**：K∗H = w 误差 1.36e-15（机器精度）——Ŝ(0) = 0（1e-17）——配对有限。
