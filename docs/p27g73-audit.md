# P27-G7.3 审计：Universal Jet——(u+v)² 的 PSD 修正 + 真实负 jet（四阶）

> 2026-09-01 · 唐先生 G7.3-A 指令 · 诚实审计（数学修正）

## ① 审计——(u+v)² 是 PSD（唐先生矩阵错误）
- **(u+v)² = u² + 2uv + v²——对称矩阵 [[1,1],[1,1]]——特征值 [0, 2]——PSD（半正定——无负特征值）**
- 唐先生的 M = [[0,1],[1,2]]（特征值 1±√2 = −0.414, 2.414——有负）——**不对应 (u+v)²**（对应 2uv+2v²）
- **⭐ leading jet 2C(u+v)² 是 PSD——不给出负方向——"universal negative jet"（基于 (u+v)² 的负特征值）——数学错误**

## ② 真实负 jet——四阶（γ 依赖——collective）
**K ≈ 2δ²(u+v)² − δ²γ²(u+v)²(u−v)² + ...**
- **二阶 jet：2δ²(u+v)²——PSD**
- **四阶 jet：−δ²γ²(u+v)²(u−v)²——NEGATIVE**（(u+v)²(u−v)² ≥ 0——系数负）
- **K_off 四阶：−(Σδ²γ²)(u+v)²(u−v)²——collective（所有零点同号——负——Σδ²γ² > 0 当 Z_off ≠ ∅）**

## ③ 数值验证
- 点 (0.5, 0.1)：K = −0.102——jet2 = +0.180——**四阶负主导**（负方向）
- 点 (1.0, 0.5)：K = −2.00——jet2 = +1.125——**四阶负主导**
- 点 (0.1, 0.1)（共同极限）：K = +0.022——二阶主导（PSD）
- **近邻 2×2 det（u=0.05-0.1——ε=0.02-0.05）：NEGATIVE（负方向——四阶机制）**——u=0.2：PSD（二阶主导）

## ⭐ 审计结论——G7.3-A 的修正
- **"leading term 无 γ"——对——但——(u+v)² PSD——不给出负方向**
- **负方向的真实机制：四阶负 jet（−δ²γ²(u+v)²(u−v)²——collective——所有零点同号）**——**依赖 γ（γ² 系数）**——需要"中等尺度"（u,v 分离——近邻）——**不是"共同极限"（u,v→0——二阶 PSD 主导）**
- **"γ 无关的 universal negative direction"——不存在**（负方向依赖 γ²）
- **但——"collective 四阶负 jet"可能给 n₋ ≥ 1**（数值支持——G7.1/7.2）——"Z_off ≠ ∅ ⟹ n₋ ≥ 1"目标仍可能——**但证明需要"四阶 jet 机制"（非 (u+v)²）**
