## §1 推导：可证非负性的 canonical 机制 = **平方完成**
```
经典实例（上轮已核验）：3+4cos t+cos 2t = 2(1+cos t)²  —— 一个【完全平方】✓
其来源：系数 (3,4,1) 恰好使三角多项式成为平方 ⟹ 非负性【可证】✓
⟹ 一般原理：算术中"可证的非负性"来自【平方完成 / 平方和】
```
$$\boxed{\text{可证非负 }\Longleftarrow\text{ 平方完成（sum of squares）；这是经典 PNT 正性的全部机制}}$$

## §2 ⭐⭐ 阶数二分（本轮核心，且是【定理级】的）
```
事实（解析）：非零三角多项式是解析函数 ⟹ 其零点集【离散】
  ⟹ 任何【非零且非负】的三角多项式在每周期内只有【有限】个零点 ✓
推广：任何【有限阶】正性结构（有限个固定平方之线性组合）的消失集是【thin】(零测)
```
$$\boxed{\text{有限阶正性 ⟹ 只能"钉住"有限多个配置 ⟹ 【结构上不足】以控制全体零点（无穷多高度）}}$$
$$\boxed{\Longrightarrow\ \text{要控制全体零点，正性必须是【无穷阶】（依赖高度）}}$$
**而这正是经典方法卡住的原因**：$(3,4,1)$ 平方只在一个配置处消失；任何有限阶都只能管有限处 ✓
```
而【无穷阶】且可证正性的已知结构 = Weil / Li / de Branges 型 ⟹ 其正性【等价于 RH】✗（不是方法）
```

## §3 ⭐⭐ 于是得到正性范式的**类级别封口**（本轮结果）
$$\boxed{\text{可证的非负性 }\Longrightarrow\text{ 不足（有限阶/rigid）};\qquad \text{充分的非负性 }\Longrightarrow\text{ 等价于 RH（无穷阶）}}$$
```
两端之间【没有中间地带】：
 · 想要"provable"，平方完成必须是 rigid（固定有限系数）⟹ 消失集 thin ⟹ 不足 ✗
 · 想要"sufficient"，平方必须 adaptive（随高度调整）⟹ 失去 rigidity ⟹ 可证性丧失 ✗
⟹ adaptive 与 provable 不可兼得 —— 这就是正性范式无法成功的原因 ✓✓
   （且它【就是】YM 的"uniform bound"缺口在正性语言中的形态 ✓）
```
