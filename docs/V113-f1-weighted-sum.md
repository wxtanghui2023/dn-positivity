## ④ ⭐⭐ 主推导：**能界住**（含显式界、常数、机制）

### ④-1 命题 F1-A 的答案
$$\boxed{\textbf{F1-A 答案 ＝ 能界住（收敛）}\ ✓✓\qquad\text{而且：所用输入 $\sum_\gamma\gamma^{-2}$ 收敛【比零密度更弱】 ⟹ 零密度【不被消费】}}$$

### ④-2 ⭐ 关键机制：**收敛的全部来源 ＝ 那个被漏写的 $-1$**
```
【若按 `CONV2` 行 25 的字面形式（$-e^{n|\delta|/\gamma^2}$，**无 $-1$**）】：
   因 $\log|w|=|\delta|/\gamma^2\longrightarrow0$（$\gamma\to\infty$）⟹ $e^{n|\delta|/\gamma^2}\longrightarrow e^0=\mathbf 1$ ✗
   ⟹ 每项 $\to1$，而**离轴零点（若存在）有无穷多个** ⟹ $\sum_{\gamma>T}1=\infty$ ⟹ **发散** ✗
   ⟹ **按此字面形式，悬点会判"不能界住"** —— 这正是"**计数够而加权和不够**"的发散机制本身 ✓
【按精确形式（$|w|^n-1$，**含 $-1$** ✓；`CONV3` §2 逐字用的就是 $-(e^{n|\delta|/\gamma^2}-1)$ ✓）】：
   $$1-|w_\rho|^n=-(e^{x_\rho}-1),\qquad x_\rho:=\log\tfrac{1}{|w_\rho|^n}=n|\delta_\rho|/\gamma_\rho^2\,(1+O(\gamma^{-2}))$$
   $$x_\rho\longrightarrow0\ (\gamma\to\infty)\ \Longrightarrow\ e^{x_\rho}-1\sim x_\rho\sim \frac{n|\delta_\rho|}{\gamma_\rho^2}\ \ \textbf{（随 $\gamma^{-2}$ 衰减，非常数 ✓）}$$
```
$$\boxed{\text{第②项负部}\ \ge\ -\sum_{\gamma_\rho>T}\bigl(e^{x_\rho}-1\bigr)\ \ge\ -\,e^{x_{\max}}\cdot n\cdot\underbrace{\tfrac12\sum_{\gamma_\rho>T}\gamma_\rho^{-2}}_{=:\,B_T}\qquad x_{\max}:=\frac{n\max|\delta|}{T^{2}}\le\frac{n}{2T^{2}}}$$
```
⟹ 收敛性 ＝ **【权随 γ 衰减】**（每项 $\sim\gamma^{-2}$），**不是**"零点稀疏计数" ✓✓
   —— **§④ 的第一个结构性发现**：`CONV2 §1` 的"零密度控制计数"是**不必要的**（甚至**不充分**：计数给不出 $\gamma^{-2}$ 衰减 ✗）。
```
