## §1 ⭐ **本轮的实质修正：Abel 形式此前漏了【从 H 起的累积】** ✓✓
```
【我此前的写法（有误 ✗）】near ≤ F(2H)M(2H) − F(H)M(H) + ∫_H^{2H}|F′|M dt
【⚠️ 问题】M(H) 计入 H 以下的**全部**零点 ✓，而 near 只求 (H,2H] 内 ✓ ⟹ 边界项被**严重高估** ✗

【✅ 正确形式】对 d(M − M(H)) 分部积分（在该区间 dM(H) = 0 ✓）：
   **near = F(2H)·(M(2H) − M(H)) + ∫_H^{2H}|F′(t)|·(M(t) − M(H))dt** ✓✓（**两项皆正 ✓**）
```

## §2 **显式界（推导 ✓）**
```
【F 的导数（t 变元 ✓）】F(t) = e^{v} − 2 + e^{−v}，v(t) = (k/2)log(1+1/t²) ✓
   F′ = 2 sinh(v)·v′ ✓，v′ = −k/(t³+t) ✓ ⟹ **|F′| = 2k sinh(v)/(t³+t) ≤ k e^{v}/(t³+t)** ✓
【M − M(H) 的界】≤ 2[(t−H)(a(log2H+1)+|b|) + c log2] ✓
【两条初等积分】∫_H^{2H}(t−H)t^{−3}dt = **1/(8H)** ✓；∫_H^{2H}t^{−3}dt = **(3/8)/H²** ✓
⟹ **near ≤ F(2H)(M(2H)−M(H)) + k e^{v_H}[a(log2H+1)+|b|]/(4H) + (3/4)k e^{v_H}c log2/H²** ✓✓
   —— **完全显式、初等 ✓**（只用 a,b,c,d 与 F,H ✓）
```
