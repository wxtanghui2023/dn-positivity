# ACPC 最小模型骨架测试（2026-09-03 10:55）

## 目标
唐先生 ACPC（加乘连通配分曲率）最小模型测试：a+b=n, n=qm incidence——构造最小配分——检查 log Z 留下什么——退化（log ζ/差谱/已知 criterion）则封死范式。

## 实现（加权计数版——非配分版）
C(X) = Σ_{a+b=qm≤X} Λ(a)Λ(b)Λ(q)Λ(m) = Σ_{n≤X} A(n)·M(n)
- A(n) = 加性卷积 Σ_{a+b=n}Λ(a)Λ(b)（素数幂对）
- M(n) = 乘性卷积 (Λ*Λ)(n)（数论卷积）
- X = 60000

## 数值结构
- **A(n)**：稠密（非零密度 0.97）——高度振荡（A/n 样本：1.79, 0.02, 0.49, 0.01——Goldbach 型——依赖 n 的素数幂分解数）——ΣA log-log 斜率 ~1.02——ΣA ~ X·log^α（α∈(1,2)）
- **M(n)**：稀疏（非零密度 12.3%——只在素数幂乘积 n=qm）——值小（1 量级）——ΣM 小（X=60k: 41532）
- **C(X)**：log-log 斜率 ~1.007——ΣC ~ X·log^~2.5（ΣC/(X log³X) 0.66-0.97 缓慢降）——主项平滑——振荡来自 A×M

## 解析骨架
- A 的 DS：ΣA(n)n^{−s} 无 Euler 积（加性卷积——a+b=n 约束不可因子化）
- M 的 DS：= (ζ'/ζ)²（乘性卷积——二次谱 ρ₁+ρ₂）
- C 的 DS：ΣA(n)M(n)n^{−s}——逐点积（Hadamard 积）——无简单 ζ 表达——谱非显然

## 判断
1. 加权计数版结构非显然（不完全等于 log ζ/差谱）——但**不是配分函数**（无 exp/块结构）——log 连通化无法在此版本测试
2. **"log Z → 一次谱"的机制无先例**：log 非线性破坏 Mellin 简单性——log Z 的谱由 Z 的解析形状（零点/极点）决定——若 Z ~ ζ 类 → log ζ（死 A）——若 Z 有零点 → log 分支（谱复杂）
3. 连通化（log）在组合层去"可分解配置"（指数公式——已知）——但不改变 Λ 权重的谱（ζ'/ζ——ρ）——Mellin 极点来自 Z 的解析形状
4. **真正测试需要配分版定义**（块的集合/权重有歧义——）——下一步：请唐先生确认最小配分 Z 的精确构造——或实现具体配分版（块=加法对——配置=共享和的集合——）测 log
