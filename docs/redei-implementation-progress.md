## 关键修正（沿路发现）
1. **norm 方程必须是 x²−py²=qz²**（三变量圆锥曲线——）不是 z=1 特例：
   - x²−py²=q（z=1——）成功率 ~27%（错误——）
   - x²−py²=qz² 成功率 **100%**（50/50——正确——）
   - 数学：β = x+y√p——N(β) = qz²——范数类 = q（mod 平方——）
2. β' = β/z 有范数恰 q（可算局部符号——）

## 不一致模式（关键诊断信息——）
例 (5113,4049,149)：
```
[a,b,c] 用 a 做 norm 方向：
第一参数 5113 → +1（(5113,4049,149) 和 (5113,149,4049)——）
第一参数 4049 → −1（(4049,5113,149) 等——）
第一参数 149 → +1
```
**符号依赖"哪个参数做 norm 方向"——[a,b,c] ≠ [b,a,c]——违反 Rédei 对称性定理——实现有系统错误**
