## §1 **记号（经典）**
```
λ_n = Σ_ρ[1 − (1−1/ρ)^n]（Li ✓，ρ 取遍非平凡零点，含共轭对 ✓；λ_n ∈ ℝ ✓）
ρ = ½+iγ（在线）⟹ **(1−1/ρ)** = (γ²−¼+iγ)/(γ²+¼) ⟹ **|1−1/ρ| = 1** ✓
   ⟹ **1 − (1−1/ρ)^n = 1 − e^{inθ_γ}**，**θ_γ := arg(1−1/ρ) = arctan(γ/(γ²−¼))** ✓
   ⟹ Re = **1 − cos(nθ_γ) ∈ [0,2]** ✓
ρ 离轴（β ≠ ½）：**|1−1/ρ| = e^{c_ρ}**，**c_ρ = ½log(1 + (1−2β)/(β²+γ²))** ✓
N(T) = #{ρ: 0<γ≤T} ✓；**F(T) = (T/2π)log(T/2πe) + 7/8** ✓
```

## §2 **三个引理**
```
【引理 1（窗口下界）】θ_γ = **1/γ − 1/(12γ³) + O(γ⁻⁵)** ✓（tan 展开 ✓）
   θ 关于 γ ∈ (½,∞) **单调递减** ✓ ⟹ 对 **γ ∈ [n/2, min(2n,T)]**：
      **nθ_γ ≥ nθ_{2n} = ½ − 1/(96n²) + O(n⁻⁴)** ✓（**40 位核验：差 3.9e−20 @n=10⁴** ✓✓）
      **nθ_γ ≤ nθ_{n/2} = 2 − 2/(3n²) < 2 < π** ✓
   ⟹ **1 − cos(nθ_γ) ≥ 1 − cos(½ − 1/(96n²)) =: C₁(n) = 0.1224174381… − 4.994×10⁻³/n²** ✓✓
【引理 2（计数）】**Trudgian（引 ✓）**：∀T ≥ e，**|N(T) − F(T)| ≤ R(T) := 0.112logT + 0.278loglogT + 2.510 + 0.2/T** ✓
   ⟹ 对 n ≥ 2e（n/2 ≥ e ✓）：**N(T) − N(n/2) ≥ [F(T) − R(T)] − [F(n/2) + R(n/2)]** ✓
【引理 3（离轴下界）】β<½、γ>T：**c_ρ ≤ 1/(2γ²)** ✓ ⟹ |w|^n − 1 ≤ (n/(2γ²))e^{n/(2γ²)} ✓
   而 n < 2T、γ > T ⟹ **n/(2γ²) < 1/T** ⟹ e^{1/T} = 1 + O(1/T) ✓
   ⟹ **Σ_{离轴} ≥ −n·B_T·(1+O(1/T))**，**B_T := ½Σ_{γ>T}γ^{−2}**（由 Trudgian 上界可算 ✓）
   （β>½ ⟹ |w|<1 ⟹ 贡献 ≥ 0 ✓ ⟹ **只有 β<½ 需处理** ✓）
```

## §3 **定理（证明骨架）**
```
λ_n = Σ_{在线 γ≤T}(1−cos nθ_γ) + Σ_{在线 γ>T}(1−cos nθ_γ) + Σ_{离轴}
    ≥ A_T(n) + 0 − n·B_T(1+O(1/T))                       （引理 3 ✓；在线 γ>T 项 ≥ 0 ✓）
    ≥ C₁(n)·#{γ ∈ [n/2, min(2n,T)]} − n·B_T(1+O(1/T))    （引理 1 ✓，窗口项 ✓）
⟹ **λ_n ≥ 0 只要 #{窗口} ≥ n·B_T/(C₁(n))·(1+O(1/T))** ✓✓  （引理 2 供计数 ✓）
⟹ **N_max := 满足该式的最大 n** ✓ —— 且小 n（n ≤ 10⁵）由已发表直接验证接管 ✓（引 ✓）
```
