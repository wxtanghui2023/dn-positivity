## 二、两道反模式筛（先过筛，再谈其它）

### 筛 1：线性性筛
$$\text{若恒等式/对象对算术系数【线性】，且核与系数无关}
\;\Longrightarrow\; \text{那只是"表示"，不是"约束"}$$

判据：是否存在形如 $F=\sum_m a_m K_m+P$，其中 $K_m$ 不含算术信息。
- 例（已判死）：AFE 恒等式（B-S1/S2/S3）

### 筛 2：形变/插值筛
$$\text{若参数依赖是【显式代数/解析变形】}\;\Longrightarrow\;
\text{是形变，不是新算术对象}$$

判据：参数是否只在显式权重/代换中出现，而所有对象都是固定经典族。
- 例（已判死）：Lagarias–Rains 的 $w$（A-N1：$w$ = 格点维数插值参数）

## 三、数值卫生协议（大 $t$ / 高精度计算必用）

```
1. 中间量（系数等）必须【按工作精度缓存/重算】
   —— 跨 dps 复用低精度缓存会制造"稳定但错误"的伪值（本项目实际发生）
2. 每个报出的数必须附【dps 稳定性证书】（更高 dps 下必须复现）
3. 值接近工作精度误差底噪时【不是证据】
4. 报数必须区分："数值建立" ≠ "无限维定理"；"区间内有零点" ≠ "第一个零点"
```

## 五、正面结论（保留，不是否定）

### 5.1 参数相图：三个正性机制参数集【不相交】
```
w < 0              : Bochner / 正定概率测度（Lagarias–Rains 已证）
w = 0              : 精确平方（Jacobi product 极限），处处正
w ∈ {1,2,4,8}      : Euler product（Eisenstein/格点算术结构）
w > 0 且 ∉{1,2,4,8} : 两种机制均不存在
⟹ w-插值【不能】把正性从离散特殊点传播到一般参数
⟹ C6-C′（靠连续延拓把特殊点正性拖到一般 w）【永久关闭】
```
