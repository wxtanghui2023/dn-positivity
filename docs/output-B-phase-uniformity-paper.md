# 成果 B：零点相位均匀性——RH 的一个新等价形式（论文草稿 2026-08-22 21:25）

> 投稿目标：Experimental Mathematics
> 诚实定位：强数值发现 + 无条件定理 + 等价链框架——严格证明为开放问题

## 摘要

设 S(t) = (1/π)arg ζ(½+it)，γ_k 为非平凡零点虚部。我们提出并数值验证（2,001,052 个零点）：

$$\sum_{k \le K} \left(S(\gamma_k) - \frac12\right) = O(1)$$

即**零点相位均匀性**（零点在 Gram 区间内均匀分布——超低差异）。我们证明：
1. 它与 M(T) = ∫_0^T S(u)du = O(1) 等价（恒等式链——无条件）
2. mean(S(γ_k)) = ½ + o(1)（无条件定理——Littlewood + 分部积分）
3. 机制链：能级排斥 → ΔS = −δ·N'（精确）→ S 锯齿 → Σε = O(1)

**如果相位均匀性成立——M(T) = O(1)——⟹ Lindelöf 假设**（确定推论）。
严格证明为开放问题——数值证据极强（2M 零点——多方法交叉验证）。

## 1. 引言与等价链

**定理 1（等价链——全部恒等式）**：以下陈述等价：
(i) M(T) = ∫_0^T S(u)du = O(1)
(ii) ∫_0^T S(t)N'(t)dt = O(1)（N' = 零点密度）
(iii) Σ_{k≤K}[S(γ_k) − ½] = O(1)（相位均匀性）
(iv) Σθ_RS(γ_k)/π = K²/2 − K + O(1)（θ 离散和）

证明：恒等式 Σθ_RS(γ_k)/π = K(K−1)/2 − ΣS_k（精确）；分部积分 Σθ = θ(T)²/2π + θ(T)S(T) − π∫SN'dt + O(1)（S_T 线性项抵消）；锯齿中点 dM_k = S(mid_k)·Δγ_k + O(Δγ³)。∎

## 2. 无条件定理

**定理 2（mean(S(γ_k)) = ½ + o(1)）**：Σ_{k≤K}S(γ_k) = K/2 + o(K)。

证明：① Littlewood M(T) = ∫S du = O(log T)（无条件）；② ∫S·N₀'dt = [N₀'M] − ∫M·N₀''dt = O(log²T)；③ 恒等式 ∫S·N₀'dt = −N/2 + ΣS_j + O(1)；④ mean(S) = ½ + O(log²T/N) = ½ + o(1)。∎

**定理 3（Selberg 均方）**：∫_0^T |M(t)|²dt ~ 0.41·T（Selberg 1946——无条件——均方根 O(1)）。

**定理 4（δ 结构）**：ΔS_k = −δ_k·N'(γ_k)（精确恒等式——corr −1.0）；Σδ_k = O(log log T)。

## 3. 数值发现（2M 零点——多方法交叉验证）

### 3.1 相位均匀性（核心）
```
Σ[S(γ_k)−½]：max|Σε| = 1.67（K = 2M——不是 √K）
子区间（每 10 万）全部 O(1)：+0.70, −0.85, +0.33, −0.58, ...
局部平衡（超低差异——所有子区间）
```

### 3.2 分布对称性
```
S_k 分布对称于 ½：中心偏差 0.054%（2M 零点）
尾部（S<0: 6.50%, S>1: 6.51%）——数量匹配——偏移镜像
skewness ≈ −0.000019（统计显著对称）
```

### 3.3 机制链（数值）
```
能级排斥：δ_k lag-1 = −0.35（间距偏差负相关）
→ ΔS = −δ·N'（corr −1.0000——精确）
→ ΔS 负相关：lag-1 = −0.35，相关和 → −0.497
→ S 锯齿：mean = ½（定理 2）+ 回归 α = 0.77
→ Σε = O(1)（相位均匀性）
```

### 3.4 S₁ 的强有界性
```
M(t) = S₁(t)：max|M| = 1.33（2M 零点）
M/log t → 0（0.040 → 0.027——o(log t)）
RH 下已知界：O(log t/(log log t)²)——我们的 O(1) 数值更强
```

## 4. Lindelöf 推论（确定）

**命题**：若相位均匀性（等价地 M(T) = O(1)）无条件成立，则 Lindelöf 假设成立（ζ(½+it) = O(t^ε)）。

证明：M(T) = O(1) ⟹ S₁(t) = o(log t) ⟺ LH（Ghosh-Goldston——Titchmarsh p.335）。∎

## 5. 与 RH 的关系（诚实）

- **相位均匀性是"RH 真"时的精细结构**——比 RH 的 S₁ 推论（O(log t/(loglog)²)）更强
- **不声称相位均匀性 ⟹ RH**（等价链到 M = O(1)——M = O(1) ⟹ LH 确定——⟹ RH 需要更多）
- **λ_n ≥ 0 ⟺ RH（B-L）**——λ_n 的无条件路径面临灾难性抵消（见成果 C）
- 相位均匀性作为**新 RH 等价形式**（若 RH 真——它必然成立——数值强支持）

## 6. 开放问题
