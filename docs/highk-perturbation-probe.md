# 高阶 A_k 扰动探测：低处盲区压缩（2026-09-04）

## 状态
唐先生"低近离轴区扰动找相变"问题——高阶 A_k 扰动测试——成功压缩盲区（1e-6 → 1e-12——）。

## 方法
在 s₀ = ½+iγ₀+ε 展开 log ξ——高阶系数 A_k（数值微分——mpmath——）：
- 在线预测：A_k·ε^k = (−1)^{k+1}/k（无翻转——对一切 ε>0——）
- 离轴（δ——）：A_k ~ −(1/k)(−1)^k/(δ−ε)^k——翻转点在 ε=δ（所有 k 一致——）
- **扰动放大**：偏离 ~(1−δ/ε)^{−k}——k 大——δ 效应指数放大
- **高阶 = 干净探针**：干扰 ~(ε/Δ)^k——k 大衰减快——k=5 几乎无干扰

## 结果（前 5 个低零点——ε 扫描到 2e-5——）
- k=3: dev 6e-12 → 1e-10——无翻转
- k=5: dev 3e-15 → 5e-10——无翻转（ε=1e-2 时机器精度——）
- **所有低零点在线——δ 约束 ~1e-12 级**

## 意义
1. "低近"（低处——）离轴排除到极深（~1e-12——）——盲区从 1e-6 压缩到 1e-12
2. 多零点 + 多 k 一致性——强证据
3. 相变点（翻转——）不在可达区——如果存在 δ < ~1e-12（效应 ≈ 在线——）
