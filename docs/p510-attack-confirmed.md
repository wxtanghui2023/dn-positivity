## 结论
**在"全局 RvM 密度 + 最小间距"约束内——所有恶意结构都不能破坏 arithmetic-direction coercivity（min/bohr 稳定 ≥ 0.02）——恶意序列构造不出来**。

**破坏 coercivity 的唯一构造（规则排列/局部密度偏移）违反 RvM 密度**——支持唐先生的判断：
> **真正控制 coercivity 的是"局部密度/局部 regularity"——不是全局 N(T)**——但——在 RvM（正确局部密度）内——coercivity 是稳定的。

## 按唐先生框架——进入 BM/Ingham/de Branges 路线
恶意序列构造不出来 ⟹ 全力研究纯调和分析定理：

**纯调和分析定理候选**：
> **定理（候选）**：设 Λ = {λ_n} ⊆ ℝ 满足：
> - **分离**：λ_{n+1} − λ_n ≍ 1/log λ_n（RvM 型局部间距）
> - **局部计数**：#(Λ ∩ [x, x+L]) ≍ L·log x（在适当尺度 L）
> - **固定系数**：w_n = 1/λ_n（或 1/(β+iλ_n)）
> 则 inf_θ F_Λ(θ) > 0——其中 F_Λ(θ) = ∫_0^∞ e^{−cv}|Σ_n w_n e^{i(λ_n−λ_0)v}e^{iθ}|²dv

**验证路径**（唐先生的逻辑顺序）：
```
纯调和分析定理（RvM 密度 + 分离 + 固定系数 ⟹ F ≥ c·bohr）
→ 验证 ζ 零点满足假设（RvM 局部密度 + 间距下界——无条件）
→ C_arith（liminf V(T)/T^{2β_max−2} > 0）

```

## 需要严格化的点（BM/Ingham 路线）
1. **RvM 是"超采样"（D⁻ = ∞）**——标准 frame 理论（有限密度）不覆盖——需要"增长密度 + 加权半无限"的版本
2. **固定系数 1/λ_n**（不是任意系数）——比 frame 下界更弱——有希望
3. **Ingham/large sieve**：通常给上界——需要的是固定方向的 uniform lower bound——**正是应该攻击的地方**
4. **Beurling-Malliavin**：lower BM density 与 gap 的对应——可能提供正确的 density notion
