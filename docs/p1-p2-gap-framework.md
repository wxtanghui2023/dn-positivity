# P1-P2 元论证框架——响应衰减 + 分辨率-支撑权衡（2026-09-08 21:40）

## 设定
观测 F_f = ∫f(x)(ψ(x)−x)dx——f 测试函数（zero-blind——不含零点输入——）
插入离轴零点 ρ* = β+iγ*（δ=β−½——）——显式公式给响应：
  δF_f ≈ M[f](ρ*)/ρ*——M[f](s) = ∫f(x)x^{s−1}dx（Mellin——）

## P1 引理（响应衰减——数值 ✓——严格可证——）
设 f ∈ C^k 紧支撑（k≥1——）：
  |δF_f| ≤ C(f,k)·γ*^{−k−1}（Riemann-Lebesgue——分部积分 k+1 次——）
数值：紧支撑 C²——γ=14: 4.0e-5 → γ=500: 3.1e-10（~γ^{−3.5}——✓）
      log-高斯 C^∞——响应 < 1e-17（数值 0——超快衰减——）

推论：对每个固定 zero-blind f——存在 γ₀(f)——F_f 对 γ*>γ₀
的离轴零点响应可忽略——【每个 zero-blind 观测有高度限制】

## P2 引理（分辨率-支撑权衡——数值 ✓——）
要响应 ≥ ε（不衰减——）——f 的谱必须含 γ*（尖锐峰——）：
  数值：f_{γ*}(x)=e^{−log²x}cos(γ* log x)——M[f] 在 γ* 处 0.97
       在 γ*±10 处 1.3e-11——峰宽 ~1/支撑——【编码 γ* 才有效应】
f 的 log-支撑 ~1/峰宽——分辨 γ* 的精度 ~1/支撑——时频不确定性

## Gap 定理（P1+P2 的合并——候选陈述——）
对任何 zero-blind 观测 F_f（有限光滑度 + 有限支撑——）：
  (i) F_f 对高离轴（γ* > γ₀(f)——）响应可忽略（P1——）
  (ii) F_f 对低离轴（γ* ≤ γ₀(f)——）的响应非零（如果存在——）
       ——但低离轴已被数值排除（验算到 10^13 零点——）
  (iii) 要覆盖所有高度——需要 f 族 {f_γ}——每个 f_γ 编码 γ（不 zero-blind——）

⟹ 【Rigidity Gap 的精确形式】：
  zero-blind ⟹ 有限高度覆盖——排除任意高离轴需无穷/依赖高度的观测
  ——"检测≠排除"从软观察升级为有引理支撑的结构
