## §2 ⚠️ 两处"非字面同型"的**正确处理**（本档核心判断 ✓✓）

```
【差异一：μ 的层数】
   Liouville = **双层**（外层强归纳于 q ＋ 内层最小性 n）；A2 = **单层**（m-下降）＋ 闭包步 ✗
   ⭐ **正确处理**：**层数不是 TLDC 的本体**，而是**实例手段**——
     外层强归纳的存在原因 = **实例版压缩引理要求 q 素**（Phase V-0 已判为实例偶然 ✓）；
     它的**功能** = 使下降产出的 j **可用**（j<q ⟹ j ∈ H）✓
     ⟹ 功能的**抽象槽位 = K**；**层数不入定义** ✓✓
【差异二：K 的两个实现】
   Liouville：**归纳闭包**（外层强归纳使小乘子已精确 ⟹ 下降输出可用）✓
   A2：**乘性闭包**（Brahmagupta 恒等式组合两表示 ⟹ 下降输出仍属同类且 μ 下降）✓
   ⭐ **正确抽象（照录唐先生）**：**`K = 把下降所得的局部对象重新送回同一类问题的闭包机制`** ✓✓
     即：**K 不规定为 strong induction**，只要求它**把 D 的输出映射回 𝒳**（使其重新满足 P 且 μ 可比）✓✓
   ⟹ 这解释了"为什么 induction closure 与 multiplicative closure 属**同一更高层结构**" ✓✓
```
