# 零曲线拓扑发现（2026-09-08 20:00）

## u=0/v=0 曲线结构（数值——）
- v=0（Im ζ=0）：近竖直（微斜——）——14.184(σ=.2)→14.135(.5)→14.089(.8)
- u=0（Re ζ=0）：**成对出现**——每对包围零点——随 σ 快速移动
- σ<½：u=0 多（27 个 t 位置——）——σ>½：骤减（5→1——）
- **u=0 在 σ=½ 处分叉/消失**（σ=.52 时 14 附近的 u=0 对消失——）

## 拓扑图像
- u=0 = ζ^{-1}(虚轴)——v=0 = ζ^{-1}(实轴)——零点 = 两者交点（ζ=0——）
- u=0 曲线在 σ-t 平面经过所有零点——σ<½ 成对（零点+额外——）——σ>½ 消失
- 额外 u=0（非零点的——）只在 σ≤½ 存在——σ=½ 处并入零点
