# II 考古第一轮——乘性 dilation 算子 B_f

> 2026-09-07 18:10 · 缺陷指数考古——候选 1：B_f（乘性 dilation——）

## 对象
B_f: (B_f h)(k) = Σ_d f(d)h(dk)——ℓ²(ℕ) 上的乘性 dilation
A_f = B_f*：Dirichlet 卷积（(A_f g)(n) = Σ_{d|n}f(d)g(n/d)——）

## 发现
1. **有限截断平凡**：B_f 上三角（dk ≥ k——）——特征值 = f(1)——有限矩阵无谱信息
2. **缺陷来自无界域**（N→∞ 定义域——）——非有限矩阵结构
3. **形式特征函数**：h_s(k) = k^{−s}——(B_f h_s)(k) = F(s)·k^{−s}——F(s) = Σf(d)d^{−s}
   - f = 1：F = ζ——h_s ∈ ℓ²(ℕ) ⟺ **Re s > ½**（谱边界——）
4. **缺陷方程**：B_f h = ±i h——形式解 k^{−s}——**ζ(s) = ±i**
   - 数值：ζ(s) = ±i 有根在 Re s > ½（σ=0.55-0.65——t=33.6 处 |ζ−i|=0.06——）
   - **ζ(s) = i 与 ζ(s) = −i 的根不成 FE 对**（χ 因子破坏——）

## 诚实评估
**结构亮点**：
- zero-blind ✓（整除——f=1——纯算术——）
- k^{−s} 特征函数 + Re s > ½ 的 ℓ² 边界——自然复结构

**连接缺失**：
- 缺陷空间 {k^{−s}: ζ(s) = ±i, Re s > ½}——**ζ(s) = ±i ≠ 0（非零点——）**——与 RH 连接不明
- ζ(s) = ±i 的根 = ζ 解析结构（仍依赖 ζ 延拓值——）——可能只是"ζ 编码"的又一形式
- n₊ vs n₋（i vs −i 根——）无自然配对（FE 不保持 =±i——）

## 判定（初步——）
- dilation 算子族**不是显然死**——有零盲结构 + 复边界
- 但"缺陷空间 ⟹ RH"的连接完全未建立（ζ(s)=±i 非零点——）
- 风险：可能又是 ζ 解析结构的编码（非新约束——）
