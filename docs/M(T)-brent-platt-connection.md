# M(T) 攻坚——Brent-Platt 连接（2026-09-08 19:40）

## Brent-Platt 结果（发现——）
- Σ_{0<γ≤T} 1/γ − (1/4π)log²(T/2π) → H ≈ −0.0171594（极限——）
- 误差 O((log T)/T²)——无条件——解析方法
- 零点**倒数一阶矩**有精确极限——"主项扣除 + 极限"结构

## 与 M(T) 的类比
- M(T) = Σ_{γ≤T}(T−γ) − ∫N0——同样的"零点和 − 光滑扣除"结构
- Brent-Platt 证 Σ1/γ 的极限——M(T) 数值 O(1)（不收敛——振荡——）
- 但 Brent-Platt 的方法（围道积分——主项扣除——）可能迁移

## 关键认识（反复确认——）
- M(T) ≠ M_main（无限素数级数发散——"先 p"死——）
- M(T) = "先 k"（零点求和——S̄ 累积——）——需要零点全局规则性
- 完整证明 = 零点局部分布规则性（Gram 型）无条件——Lindelöf 级
