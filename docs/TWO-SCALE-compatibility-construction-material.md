## §1 材料 A（最具体）：**不变因子双尺度**（格 / 理想类 / 整数矩阵）

**对象**：$\mathbb Z^2$ 中的指数为 $N$ 的子格 $\Lambda$（等价地：$2\times2$ 整矩阵、二次型、$N$ 阶理想类结构）
**两个天然尺度**：**Smith 标准形的不变因子** $d_1\mid d_2$（**唯一**，无选择）
**已存在的定理（不是输入）**：
$$d_1d_2=N\qquad(\text{指数}=\text{不变因子之积})$$
**自然的交换操作 $P$**：**对偶**（$\Lambda\mapsto\Lambda^*$）／不变因子的对换（$d_1\leftrightarrow d_2$）
**不对称性（唐先生要求的"增长律不同"）**：$d_1\mid d_2$ ⟹ 交换会**反转整除方向** ⟹ $P\circ Q\neq Q\circ P$ 在整除指标上必然不同
**固定尺度**：
$$\boxed{\text{交换不变的配置只可能是 }d_1=d_2\ \Longrightarrow\ \text{固定尺度}=\sqrt N=N^{1/2}}$$
（对非平方 $N$：交换不变的**尺度**仍是 $\sqrt{d_1d_2}=\sqrt N$）
**为何"不是自由参数"**：给定格，$d_1,d_2$ 被 $N$ 与其结构**唯一确定**（Smith 标准形唯一）⟹ 固定尺度不是可调参数 ✓
**为何"1/2 不是写进去的"**：$1/2=1/\text{rank}$，rank $=2$ 来自**对象是二维格**（$\mathbb Z^2$／二次型）——即 $\sqrt{N}=N^{1/\text{rank}}$，与 ABD-0 的"$1/2=1/\text{arity}$"同型：**由对象的维数/元数给出，而非由人为指数给出** ✓
**与排除列表的关系**：不是规定 $H=\sqrt X$（乘积律是**定理**）｜不是 AM-GM（没有用不等式，是**精确代数**）｜不是 $d\leftrightarrow n/d$（那是 $\mathbb N$ 上的除子配对；这里是**格的不变因子**，对象不同）｜不是 FE、不是 HP ✓

## §2 材料 B（更硬、与解析侧天然接壤）：**数域的两尺度：余体积 $\sqrt{|D|}$ 与类数 $h$**

**对象**：数域 $K$（$\mathbb Z^2$ 的类比是二次域）
**两个天然尺度**：
```
尺 度 1（几何）：余体积 $\sqrt{|D_K|}$ —— Minkowski 嵌入的协体积；指数恰为 1/2
尺 度 2（算术）：类数 $h_K$（理想类群的阶）
```
**已存在的定理（不是输入）**：**解析类数公式**把两者与 $L$ 函数联系起来：
$$h_KR_K=\frac{w_K\sqrt{|D_K|}}{2^{r_1}(2\pi)^{r_2}}\cdot\operatorname*{Res}_{s=1}\zeta_K(s)$$
**自然的交换操作**：数域的对偶结构（$K\leftrightarrow$ 其对偶/二次扭曲、$L\leftrightarrow\overline L$），以及**Minkowski 嵌入与理想分解之间的桥**
**为何可能给出"非自由"的固定尺度**：$\sqrt{|D|}$ 与 $h$ 的量级竞争就是 **Brauer–Siegel** 现象所在——
即"两尺度兼容/稳定"的自然表述在数论中**已有定理与猜想**（这部分**尚未审计**）
**为何这比材料 A 更值得看**：它**天然与 $L$ 函数接壤** ⟹ 唐先生的最后一步（$\to\zeta$ 零点定位）在这里**至少有现成的接口**（类数公式／Brauer–Siegel／Dedekind $\zeta_K$）

## §3 设计约束（构造阶段必须自带，否则 1/2 会变成可调）
```
C1 两个操作 P、Q 都必须【天然】（如对偶、Smith 标准形、Minkowski 嵌入），
   不得是"为了让固定点为 √ 而选"的
C2 乘积/守恒律必须是【定理】（如 d1d2=N、指数=协体积²），不得是设定
C3 固定点必须【无自由参数】（尺度被对象唯一确定）
C4 1/2 必须由【对象的内禀整数】（rank／arity／维数）给出，而非由人为指数给出
C5（最后一步，暂不处理）必须存在通往 ζ 零点定位的接口
```
**⚠️ 结构性提醒（属构造要求，不是死亡审计）**：本形状（守恒律 + 交换 ⟹ 固定点）与 **E3 的重整化不动点形状同型**；
E3 当时的审计结论是"仿射/可调 ⟹ $1/2$ 可自由插入"。因此本路线的**成败系于 C1/C2**：
**只要两个操作与守恒律都是"定理级天然"的，固定点就不是自由参数**；否则会退化为 E3 的可插入情形。
