## 0. 草案要证的东西（✓ 一句话 ✓）

```
【目标 ✓】在块 I := [X/2, X]（X = T₀² ✓）上：
   Σ_{n∈I}(Re S_n)² ≤ C·|I|·N ✓，**C = O(1)** ✓（不需要抵消 ✗，只需【不放大】✓）
⟹ 配合 Markov ✓（阈值 0.3272N ✓）⟹ 例外密度 ≤ C·4.67/N ≈ **2.3×10⁻⁶** ✓✓
【⭐ 为什么 C = O(1) 就够 ✓】因为对角项本身 = |I|·N/2 ✓ ⟹ 只要**非对角不超过对角的常数倍** ✓ 即可 ✓
   —— 这比"配对和要小"弱得多 ✓，是**关键的可达性** ✓
```

## 1. 证明草案（✓ 六步 ✓）

```
【步骤 1 ✓ 精确恒等式（E52 已数值验证 ✓✓）】
   Σ_{n≤X}(Re S_n)² = (1/2)Σ_{γ,γ′}[D_X(θ_γ−θ_γ′) + D_X(θ_γ+θ_γ′)] ✓，D_X(t) = Σ_{n≤X}cos nt ✓
   块版 ✓：把 D_X 换成块核 K_I(t) = Σ_{n∈I}cos nt = [sin((X+½)t) − sin((n₁−½)t)]/(2sin(t/2)) ✓（闭式 ✓）
【步骤 2 ✓ 分离对角与非对角 ✓】
   Σ_{n∈I}(Re S_n)² = (1/2)[ N·K_I(0) + 2Σ_{γ≠γ′}K_I(θ_γ−θ_γ′) ] + (1/2)Σ_{γ,γ′}K_I(θ_γ+θ_γ′) ✓
   对角 ✓：N·|I|/2 ✓（K_I(0) = |I| ✓）
   ⚠️ 注意 **K_I(θ_γ+θ_γ′) 项** ✓：因 θ_γ+θ_γ′ ≥ 2θ_{T₀} ≈ 2/T₀ ✓ ⟹ 该核在 0 附近**无共振** ✓
     ⟹ 该项按**相位平均**处理 ✓（无奇性 ✓）
【步骤 3 ✓ 核的宽度 ⟹ 局部化 ✓（E52/E54 已算 ✓）】
   核首零点 t = 2πk/|I| ✓ ⟹ Δθ ≈ 2π/|I| ✓ ⟹ 由 |θ′| ≈ 1/γ² 得 **Δγ ≈ (2π/|I|)γ²** ✓
   |I| = X/2 时 ✓（E54 实测 ✓）：Δγ = 0.126 / 3.14 / 10.18 / **12.57**（γ/T₀ = 0.1/0.5/0.9/1.0 ✓）
     折合**间隙数** = 0.23 / 6.6 / 22.4 / **27.9** ✓ ⟹ **有界（≤ 28 ✓）** ✓✓
   ⟹ 配对和**截断到 ≤ M 个邻居**（M ≈ 30 ✓）后，尾部可忽略 ✓（核的 1/t 衰减 ✓ + 间隙有下界 ✓）
   ⚠️ 注 ✓：M 需随 γ 分段（低 γ 只需 ≤ 1 ✓、顶段需 ≈ 28 ✓）—— 用 **γ 分段 + 每段各自核宽** ✓ 处理 ✓
【步骤 4 ⭐ **主项 = 光滑密度** ✓（本草案的实质假设，已有数值支撑 ✓）】
   把非对角写成对**零点测度**的积分 ✓：Σ_{γ≠γ′}K_I(θ_γ−θ_γ′) = ∬_{u≠v}K_I(θ(u)−θ(v))dN(u)dN(v) ✓
   拆成 ✓：**光滑主项**（dN → ρ(v)dv ✓，ρ = log(v/2π)/2π ✓）＋ **涨落项** ✓
   ⭐ 支撑证据 ✓：
     · E53 ✓：**光滑序列复现真二阶矩到 7 位有效数字** ✓✓（8.008405e13 vs 8.008407e13 ✓，X = 20/50/100/200 ✓）
     · E54 ✓：真零点截断配对和 ≈ **9.856×10⁵** ✓ vs 对角 **1.0005×10⁶** ✓ ⟹ **同量级（不放大 ✓）** ✓✓
   ⟹ 草案假设 ✓：**|非对角| ≤ C₀·|I|·N** ✓（C₀ = O(1) ✓）—— **这是唯一未证的一步** ✗
      （其"应为真"的理由 ✓：核宽度有界 ⟹ 参与者 ≤ O(N·28) 对 ✓；每对贡献的**平均**因相位分散而为 O(|I|/M) ✓ 量级 ✓）
【步骤 5 ✓ 涨落项（输入侧 ✓）】
   涨落 = 短程计数涨落 ✓ ⟹ 用 **Selberg 型短区间方差界**（无条件 ✓，如 ∫|ψ(t+h)−ψ(t)−h|² ≪ xh ✓ 的零点版 ✓）
   ⟹ 涨落 ≤ (主项)·(小因子) ✓ ⟹ 可并入 C ✓
【步骤 6 ✓ 组装 ✓】
   Σ_{n∈I}(Re S_n)² ≤ C·|I|·N ✓（C = 1/2 + C₀/2 + C₁ ✓ 常数 ✓）
   ⟹ Markov ✓（阈值 0.3272N ✓）⟹ #{n∈I : E_n>0} ≤ C·|I|·4.67/N = |I|·C·2.33×10⁻⁶ ✓
   ⟹ 加上小 n 段**自动满足** ✓ ⟹ **定理** ✓：`λ_n ≥ 0 对除 ≈ 2.3×10⁻⁶ 比例的 n ≤ T₀² 成立` ✓
```
