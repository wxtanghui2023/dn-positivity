## 2. ⭐ 完整代数展开（✓ 已做并数值复核 ✓）

```
【恒等式 ✓】Φ(z) = z^ρ ✓ 时：
   Φ(x+h) + Φ(x−h) − 2Φ(x) = x^ρ·[ (1+u)^ρ + (1−u)^ρ − 2 ] ✓，u := h/x = m^{−1} ✓
【展开 ✓】偶次幂（奇次幂**精确相消** ✓）：
   (1+u)^ρ + (1−u)^ρ − 2 = **ρ(ρ−1)u²** + [ρ(ρ−1)(ρ−2)(ρ−3)/12]u⁴ + O(u⁶) ✓
   ⟹ 首项 ✓：Φ-difference = x^ρ·ρ(ρ−1)·u²·(1 + O(u²)) ✓
【数值复核 ✓】S/(x^ρ u²) → ρ(ρ−1) ✓：β = 0.5/0.6/0.75 ✓ 比值 **0.999992 → 1.000000** ✓✓
【径向部分 ✓】x = m² ⟹ x^ρ u² = m^{2ρ}·m^{−2} = **m^{2ρ−2} = m^{2(β−1)}·e^{2iγ log m}** ✓
   ⟹ 相对**在线**情形（β = ½ ⟹ m^{−1} ✓）：**放大因子 = m^{2β−1} = m^{2δ}** ✓✓
【⟹ 回答您的问题 ✓】**因子确实自然出现** ✓，且出现方式是"**整体径向幂 × ρ-多项式系数**" ✓
   ⚠️ 但注意 ✓：**系数 ρ(ρ−1) 对 β 无选择性** ✗（所有零点共用同一核 ✓）⟹ 泛函是**线性叠加** ✓，
     **不产生 β-筛选机制** ✗ —— 唯一的 β-信息就是那个整体幂 ✓
```
