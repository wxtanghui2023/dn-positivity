## 1. 核心定义

**D_η(T)**（中心差——从 log|ξ| 无条件可算）：
$$D_\eta(T) = \log|\xi(\tfrac12+\eta+iT)| + \log|\xi(\tfrac12-\eta+iT)| - 2\log|\xi(\tfrac12+iT)|$$

**D_η^(0)(T)**（在线投影参考——无条件——无循环）：
$$D_\eta^{(0)}(T) = \text{显式项} + \sum_\rho \log\left(1+\frac{\eta^2}{(T-\gamma_\rho)^2}\right)$$
- 只依赖零点高度 γ_ρ——不依赖实部 β_ρ
- Σ_ρ h(γ_ρ)（h(t) = log(1+η²/(T−t)²)）——Weil 显式公式可算——**不含 RH 信息**
- 投影 ρ ↦ ½+iγ_ρ——谱投影——非 RH 假设

**S(T)**（二阶极限）：
$$S(T) = \lim_{\eta\to0} \frac{D_\eta(T) - D_\eta^{(0)}(T)}{\eta^2} = \sum_\rho (\beta_\rho-\tfrac12)^2 K(T-\gamma_\rho) = (K\ast\mu)(T)$$

**正谱测度**：
$$\mu(t) = \sum_\rho (\beta_\rho-\tfrac12)^2 \delta_{\gamma_\rho}(t) \geq 0$$

**核**（固定 η）：
$$K_\eta(d) = -\frac{\eta^2+3d^2}{(\eta^2+d^2)^2d^2}$$

## 2. 已建立的命题

### 命题 1（核无零点）
固定 η > 0：
$$\widehat K_\eta(\omega) = \frac{\pi|\omega|}{\eta^2}(1-e^{-\eta|\omega|}) > 0 \quad (\omega \neq 0)$$
- 无 Fourier 零点——无盲频——截断伪零已排除（零点随 dmax 漂移——Gibbs 型）

### 命题 2（配对自动消一阶）

### 命题 3（正权二次型）
存在显式测试函数 H（Ĥ = ŵ/K̂——K∗H = w）使：
$$Q_H = \int S(T)H(T)dT = \sum_\rho (\beta_\rho-\tfrac12)^2 w(\gamma_\rho)$$
其中 w(γ) = (1+γ²)^{−s} > 0（数值：K∗H = w——误差 2.2e-16——机器精度）

### 命题 4（支配估计——交换控制）
$$|K(T-\gamma_\rho)| \le C_\eta (1+|T-\gamma_\rho|)^{-4}$$
结合 N(T) ~ (T/2π)log(T/2π) ⟹ Σ_ρ(1+γ_ρ)^{−4} < ∞——lim 与 Σ 交换可行（控制收敛）——大 d 渐近 |K| ~ 3η_ρ²/d⁴（数值比 3.000）

## 3. 主定理（候选）

> **定理候选**：Q_H = 0 ⟺ RH（所有零点 β_ρ = ½）

**证明链**：
1. Q_H = 0 ⟹ S ≡ 0（H 与核的完备性——需严格化）
2. S ≡ 0 ⟹ Ŝ ≡ 0 ⟹ K̂μ̂ = 0——K̂(ω) ≠ 0（ω≠0）⟹ μ̂(ω) = 0（ω≠0）
3. μ ≥ 0 且加权有限（∫(1+t²)^{−s}dμ < ∞）⟹ μ̂ 解析（指数和）——ω≠0 处零 + 解析延拓 ⟹ μ̂ ≡ 0
4. μ̂ ≡ 0 ⟹ μ = 0（正测度 Fourier 唯一性）⟹ 每项 (β_ρ−½)² = 0 ⟹ β_ρ = ½——RH ∎
