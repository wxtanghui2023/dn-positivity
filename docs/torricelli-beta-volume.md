# 托里拆利视角：β 体积 V_β = ∫(ψ−x)²x^{−3}dx——尾部衰减探针

> 2026-09-01 · 唐先生想法 2 的深挖 · 无限变有限的具体化

## 核心构造
**β 体积**：V_β = ∫_2^∞ (ψ(x)−x)²x^{−3}dx
- **有限**（收敛——ψ−x 的振荡 ~ x^{β_max}——(ψ−x)² ~ x^{2β}——∫x^{2β−3}dx 收敛（β<1））——**托里拆利类比：零点无限（表面）但体积有限**
- **从素数数据可计算**（ψ(x) 已知——Level 2——独立于零点）

## 尾部衰减指数（β 探针）
- 尾段贡献：c(T) = ∫_T^{2T}(ψ−x)²x^{−3}dx ~ T^{2β−2}·ln2
- **在线（β=½）**：c(T)·T ~ 常数（c ~ 1/T）
- **离轴（β>½）**：c(T)·T ~ T^{2β−1}（增长——β>½ 时正指数）

## 结论
**托里拆利视角的"无限变有限"具体化**：
- ✓ **β 体积 V_β 有限**（收敛——托里拆利类比成立）

- ✓ **尾部衰减指数含 β**——新的 β 探针——数值支持 β≈½
- ⚠ **但——"在线期望"（判别基准）需要零点（循环）**——数值检测（β 可测）——不是独立约束
