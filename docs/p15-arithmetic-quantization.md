## 概念证明搜索结果
### ① 整数不变量（绕数/计数）
- N(T)（Backlund——整数——零点计数）——单轨道离轴（轨道分裂 +1）——**变化是整数——不提供非整数障碍**

### ② sgn 和（Σsgn(β_j−½)）
- 在线：0——离轴轨道 {½±δ}：+1−1 = 0（**轨道对称抵消**）——不区分

### ③ 碰撞数（de Bruijn-Newman 流）
- 离轴对产生 = 碰撞事件（整数 ±1）——**整数跳跃——允许**——"禁止碰撞"等价 Λ ≤ 0（RH——循环）

### ④ Arithmetic Uncertainty Principle（唐先生最看重）——最有希望
- **"复不确定性"**：f 在复零点 ρ = ½+β+iγ 集中（**几何定位——β 进入——非 Mellin 自适应**）vs f 的算术定位（log n 格）
- U_arith(f)·U_zero(f) ≥ C（如果无条件——复分析定理）——离轴 ⟹ 乘积 < C——矛盾——RH
- **⚠️ 两难**：
  - "无条件 ≥ C"（不涉及 ζ）——离轴 f_ρ 也满足——无矛盾
  - "离轴 < C"——需要含 ζ 的定理（循环）
  - **"复不确定性定理"（连接复定位和 Mellin 算术定位）——不存在现成——需发明**

### ⑤ Adelic/Two-Sided（三空间——散射相容）
- det(I−T₁T₁*) = det(I−T₂T₂*)——**"散射相容"可能又是显式公式（自适应）**——P3 封口（ζ 零点 = 散射极点——连续谱）

## ⭐ P15 判定（初步）
