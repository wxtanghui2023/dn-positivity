# AXD（算术交换缺陷）测试结果：倾向判死（τ = min(p,q)——平凡）（2026-09-03 10:25）

## 实现
σ = 素因子中 p↔q 互换（乘法同态——非加法同态）——加法关系 a+b=c 在交换后保持 ⟺ σ(a)+σ(b) = σ(c)——AXD_N(p,q) = 冲突数。

## 结果 1：τ(p,q)（第一个被破坏的加法关系的最小和）
- τ(2,3)=2, τ(2,5)=2, τ(2,7)=2（含 2——τ=2——1+1=2 被 σ 破坏）
- τ(3,5)=3, τ(3,7)=3（最小 3——1+2=3 类）
- **τ(p,q) = min(p,q)——完全由 p,q 的普通大小显式决定——直接命中唐先生判死（死）**

## 判断
按唐先生判死条件（τ 由 p,q 大小显式决定——死）：
1. **τ(p,q) = min(p,q)——死**（纯大小）
2. 保持比例 ~ f(min(p,q)) + 单调饱和——**倾向平凡**（大小/valuation 类——σ 移动小素数破坏更多加法——）——**不是真正的加法-乘法全局依赖**
3. 严格判死需理解保持比例的精确渐近（是否 = 某显式函数——）——但初步数据强烈倾向平凡

## 诚实结论
AXD（此版本——σ = p↔q 素因子互换——保持 = σ(a)+σ(b)=σ(c)）——**τ 死（min(p,q)——）——保持比例倾向平凡（较小素数主导）**——按唐先生判死纪律——**倾向判死**（除非保持集本身有非平凡的加乘结构——需更细检查——但初步数据不支持）。
