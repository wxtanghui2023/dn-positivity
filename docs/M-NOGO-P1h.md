# 第一部分：P1h 方向登记（唐先生）

## 0. 要防的错误
$$\boxed{\text{不要把 }C\text{ 做成"禁止出现 }1/2\text{"的语法规则}}\quad(\text{会立即退回已被反复击穿的 normal-form/representation 问题})$$
**正确方向**：把 $C$ 从"推导过程中没有出现 $1/2$"提升为**证明论中的"非目标依赖性"**

## 1. 证明论形式
设 primitive 公理/生成规则为 $\Gamma_{\rm arith}$，候选机制的证明为 $\Gamma_{\rm arith}\vdash\mathsf{Rigidity}(\alpha)$；真正需要的是
$$\boxed{\Gamma_{\rm arith}\vdash\exists!\alpha\,\mathsf{Rigidity}(\alpha)\quad\text{且}\quad\alpha=\tfrac12\ \text{是该证明的【结论】}}$$
而非定义、参数、边界条件或选择规则中的输入

## 2. 替换／参数独立测试（核心）
> 把目标指数暂时换成自由符号 $a$，检查整个机制在**不改变 primitive 内容**的情况下是否仍成立
```
若机制实际要求 T_a^∞ ⇒ α=a ⟹ a=1/2 是【外加】的，未被 arithmetic structure 强制
真机制应满足：Γ_arith ⊢ ∃!α Rigidity(α) 且 α=1/2
```
$$\boxed{\text{测试形式：能否把 }1/2\text{ 换成任意 }a\text{ 而机制仍成立？}}\qquad(\text{远强于"推导中有没有写 }1/2\text{"})$$
**关键例子**：$s_{n+1}=\sqrt2\,s_n$ 可改为 $s_{n+1}=\sqrt c\,s_n$ ⟹ $\alpha=\tfrac12$ 非结构唯一选择 ⟹ **C-fail**
**且唯一性本身不够**：若 $P(\alpha)=0$ 有解 $\alpha=0,1$，亦非"产生 $1/2$"；须
$$\boxed{P(\alpha)=0\ \text{且 admissible domain 内}\ \operatorname{Sol}P=\{\tfrac12\}}$$
（= G3 与 C 的联合效果）

## 3. C_NI 定义（Non-Insertability）
给定 primitive 系统 $\Gamma$：若存在一个目标参数 $a$，使机制可在 $a\mapsto a'$ 后**保持全部结构/公理/生成律不变**而最终指数随 $a'$ 改变，则原 $1/2$ 是**参数携带的**，非 arithmetic-generated
$$\boxed{\text{要求：不存在这样的目标参数族}}\qquad(\text{仍属【推导层】——与 P1g 核心结论一致})$$

## 4. 第三轴：暂不增加
```
原因不是"已证不存在"，而是目前所有攻击自然分成：
  A：答案是否已存在于局部/有限/独立尺度对象中？
  C：答案是否被生成规则/定义/参数预先携带？
合法区域 = 局部不知道 + 规则不知道 ⟹ 全尺度耦合产生 1/2
⟹ 第三轴最多作为【待证不存在的残余分类】，不能人为宣布不存在
```

## 5. P1h 建议的冻结形态
$$\boxed{\mathrm{ISRG}=A_{\rm cross-scale}+C_{\rm provenance}}$$
**A（对象层）**：$\forall W\Subset\mathbb X,\ \exists m_1,m_2:\rho_W(m_1)=\rho_W(m_2),\ \alpha(m_1)\neq\alpha(m_2)$；且 $\Sigma_\infty\subsetneq\Sigma_{\rm dec}$；且只有完整耦合后 $\alpha=\tfrac12$ 才唯一
**C（推导层）**：$\Gamma_{\rm arith}\vdash\exists!\alpha\,\mathsf{Rigidity}(\alpha)$，且 $\tfrac12$ 不能通过自由目标参数/边界条件/归一化/坐标选择/等价外部选择替换
