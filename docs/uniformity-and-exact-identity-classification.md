## §1 ⚠️ 更正：margin 型技术**不是类型不匹配**，而是卡在**一致性（uniformity）**上
```
上一轮我暗示"回避型/估计型结果不可能给出等式" ⟹ 过强 ✗
精确情形：
 · 经典无零点区域：σ > 1 − c/(log t)^{2/3}(log log t)^{1/3}（Vinogradov–Korobov）✓【引用】
   ⟹ 余量 c/(log t)^{2/3}... → 0，但**不是一致地**趋于 0
 · RH ⟺ 无零点区域抵达 σ > 1/2（配函数方程）⟺ 余量**一致**消失 ✓
   （等价：liminf 零点实部 = 1/2，limsup = 1 ✓【引用：Littlewood 振荡】）
```
$$\boxed{\text{margin 型技术【类型正确】（到达 1/2 即 RH），但必须做到【余量一致消失】—— 而这正是缺口}}$$

## §3 ⭐ 推导：**精确恒等式族（几乎）只有显式公式型** ⟹"再找一个漂亮恒等式"这条希望被排除
```
所有已知的"算术侧 ⟷ 零点侧"精确恒等式都是同一机制的变体：
 · 显式公式（素数侧 ⟷ 零点侧 + archimedean 项）✓
 · Selberg 迹公式（谱侧 ⟷ 几何侧）—— 同型，只是换到局部对称空间 ✓
 · 各类 L-函数的显式公式 —— 特例 ✓
⟹ 它们共享同一机制：把【一个分布的两种描述】等同起来（Weil 分布的两面）✓
```
$$\boxed{\text{因此："新的精确恒等式"若是显式公式的【重述/特例】⟹ 无用（循环不变）✗}}$$
$$\boxed{\Longrightarrow\ \text{缺少的不是一个新【恒等式】，而是一个新【对偶】（duality）}}$$
（这与 AOB2 的"周期↔谱"缺口、AOB4 的"新上同调"缺口**同址** ✓）
