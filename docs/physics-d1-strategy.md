# 物理 D1 战略：从"正性"转向"谱约束"（P1–P5 框架）

> 2026-09-01 · 唐先生战略转向 · D7 之后不再继续 D8/D9 换核

## 核心判断（唐先生）
C1–D7 扫过的区域（函数方程→Euler→Weil→Hadamard→trace→变分→局部可实现性→σ=1）几乎都有同一结构：
```
零点配置 → 某个恒等式/正性 → 离轴代价（D≥0）
```
而缺失的是：
```
独立物理/数学原则 → 谱必须实 → β=½
```
继续在纯数学框架内增加 D8, D9... 意义很低。

## 物理模型的新角色（不是证明语言）
提供**零点信息之外的结构**：
- 稳定性 / 自伴性 / 因果性 / 单位性 / 守恒
- 例：H = H† ⟹ 谱实——若 E_ρ = γ_ρ − i(β_ρ−½)——E_ρ ∈ ℝ ⟹ β_ρ = ½
- 这与 Weil 路线本质不同：正性→零点约束 vs 物理原则→自伴/单位演化→实谱→RH

## 特别强调：开放量子系统（δ ↔ Γ）
- δ≠0 表现为极点展宽——物理上 E = E_0 − iΓ/2（共振宽度）
- 建立 δ ↔ Γ——δ=0 ⟺ Γ=0（无衰减/无开放通道）
- RH 变成："为什么这个系统是封闭的/单位的？"——非常不同的问题

## 时间反演/PT 对称
- 配对 ρ ↔ 1−ρ̄（函数方程）——已知不够
- 需要第二个独立结构：unitarity/self-adjointness ⟹ 谱⊂ℝ
- 镜像对称 + 实谱 ⟹ 固定轴（几何结构——过去只有第一条）

## P1–P5 审计框架（第一阶段不碰数值 RH——只做结构审计）
- **P1 谱变量设计**：找自然 H 或 S——ρ=½+δ+iγ ↔ E_ρ=γ−iδ（或 Möbius 变换）
- **P2 独立性审计（最重要的反循环条件）**：H = H(素数/算术数据)——**不是** H = H({ρ})
- **P3 物理原则审计**：寻找独立来源的 H=H† 或 S†S=I——不能把 RH 等价假设进去
- **P4 函数方程接合**：已有 ρ↔1−ρ̄——再问物理结构是否给 E_ρ∈ℝ——两者结合
- **P5 失败判据**：若变成 "Weil positivity ⟺ RH" 或 "H 自伴 ⟺ RH" 而无独立证明——立即判失败

## 优先级（唐先生排序）
散射/共振 > transfer operator > unitary/self-adjoint realization > 开放量子系统 > 随机矩阵
理由：最有机会提供"来自零点信息之外的谱约束"

## 最终判断（唐先生）
- D7 是转折点：纯在零点/Weil/Euler 信息内部重组——难以制造缺失的反向箭头
- 真正要找：外部结构 → 谱约束
- 若"谱实性/单位性/共振宽度"路线也失败——得到干净结论：连这条完全不同的路线也不能提供独立反向——暂停 RH 非常合理
