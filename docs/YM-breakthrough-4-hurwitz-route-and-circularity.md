## §1 ⭐ **一条有效的路线**（上一轮我只说"需要稳定性类"，这里给出为什么它有效）
```
Hurwitz 定理（经典）：若 f_n → f【局部一致】且 f ≢ 0，则 f 的每个零点都是 f_n 零点的极限 ✓
⟹ 若每个 f_n 的零点【全为实】，则 f 的零点【全为实】（实轴是闭集）✓✓
```
$$\boxed{\text{路线：构造"零点全实"的逼近序列 }f_n\to\Xi\ \text{（局部一致）}\ \Longrightarrow\ \text{RH}}$$
$$\boxed{\text{即：}\text{RH}\iff\Xi\ \text{是"全实零点函数"的局部一致极限}}$$
**这是本轮第一个实质结果**：把"突破"变成了一条**判据明确、工具已知**的路线 ✓

## §2 ⚠️ 但同时得到一个**陷阱警告**（必须记录）
```
系数收敛 ⟹ 局部一致收敛（整函数、Taylor 系数逐项收敛的标准事实 ✓）
⟹ 若存在"系数收敛到 Ξ 的系数、且零点全实"的多项式/函数序列 ⟹ 立即得 RH ✗
⟹ **因此这样的序列【不可能存在】**（否则 RH 早被证明）
⟹ 推论：经典所谓"Pólya 赝品"【不可能】是"全实零点 + 系数收敛到 Ξ"的序列 ✗
   其确切构造（改换变量？复系数？弱收敛？）我【未核验】⚠️ —— 必须查清，否则会重复踩坑
```

## §3 ⭐⭐ 已知族的**循环性**（为什么现成工具用不上）
```
平滑型族（热流/DBM、Euler 截断、光滑化）的共同结构：
   族参数 t 存在一个【阈值 Λ】：零点全实当且仅当 t ≥ Λ ✓
   而 Ξ = lim_{t→0+} H_t（局部一致 ✓）
⟹ 用这条族去证 RH，需要取 t_n → 0 且每个 t_n 都在实性区 ⟹ 需要 t_n ≥ Λ 且 → 0 ⟹ **Λ = 0**
⟹ 而 Λ = 0 ⟺ RH（Rodgers–Tao：Λ ≥ 0）✗✗
```
$$\boxed{\text{平滑型族证明 RH 需要【已经知道 }\Lambda=0\text{】}\Longrightarrow \text{循环}}$$
**这就是上一轮"极限不保性"的真正机制**：不是"极限不保实性"（Hurwitz 说保 ✓），
而是**族的实性区是一条尾巴 $[\Lambda,\infty)$，而要用它就必须让尾巴触到 0 —— 那正是结论本身** ✓✓
（我上一轮把原因说成"极限不保实性"，不准确 —— 本轮更正）

## §4 于是工作项被**精确化且收窄**为唯一形式
$$\boxed{\text{需要：一个【在目标参数处直接可证全实零点】的逼近族（非平滑型、非阈值型）}}$$
```
· 不能靠"平滑到足够远再回推"（= §3 循环 ✗）
· 不能靠"系数收敛 + 全实"（= §2 不可能 ✗）
· 只能靠：在【Ξ 本身的参数处】直接构造出全实零点的结构（例如某种显式因子分解）✓
  —— 而由 LP 类的经典刻画，"Ξ 本身全实零点"⟺ Ξ 属于 LP 类 ⟹ 这又回到等价陈述 ✗
⟹ **结论：这条路线（Hurwitz + 逼近）在【已知族】上是循环的；其非循环版本需要
   "在目标处直接可证"的构造 —— 而那等价于 LP 类成员资格 ⟹ 等价于 RH** ✓✓
```
