# P5.10 BM/Ingham 路线：固定方向证明路径——诚实评估

> 2026-09-01 · 恶意序列构造不出来 ⟹ 进入定理尝试 · 核心障碍定位

## 证明路径（尝试）
**F(θ) ≥ 对角 − |交叉| ≥ c·bohr**——w=1/ρ 的平滑性抑制交叉项：
- 对角：bohr/c_w（固定——正）
- 交叉：Σ_{j≠k} w_j w̄_k e^{i(γ_j−γ_k)θ}/(c_w−i(γ_j−γ_k))

## 数值验证结果
### 1. 加权 Gram 的 λ_min（最坏方向）
- RvM：λ_min·c_w = 0.024（J=100）→ 0.015（J=1200）——**缓慢下降（可能 → 0——对数退化）**
- 规则排列：0（完全退化）
- **⚠️ λ_min（谱 gap）与固定方向不同——再次确认唐先生 P5.9-S 洞察**

### 2. 固定方向（F(θ)——数值稳定）
- min/bohr ~ 0.03-0.045（J 到 4000——不 → 0）——**固定方向比 λ_min 稳定**

### 3. 交叉/对角（证明的关键）
| 量 | 值 | 判定 |
|------|:--:|:--:|
| **三角不等式上界** | 8.1 → 11.5（J 增） | **> 1——太粗**——最坏相位对齐 |
| **实际交叉（θ 扫描）** | 抵消 97%——min/对角 = 0.03 | **留下 3% 正余量——数值稳定** |

## ⭐ 核心障碍精确定位
**固定方向的证明需要"相位抵消"的定量论证**（实际交叉 << 三角上界——97% 抵消）：
1. **w 平滑（1/γ）**——必要但不够（三角上界 8-11× 对角——> 1）
2. **相位抵消**（γ_j 无共振——准随机相位 e^{i(γ_j−γ_k)θ}）——**实际交叉远小于三角上界——关键**
3. **"无共振"的来源**：规则排列（几何级数——共振）——相位不抵消（F → 0）；RvM（准随机）——相位抵消（F 稳定）
4. **"无共振"是算术不规则性**（ζ 的零点结构）——**不是纯几何（间距/密度）**——可能依赖 ζ 的具体结构（无条件？——或——RH 相关？——未知）

## 诚实结论
- **固定方向下界（F ≥ 0.03·bohr）数值稳定**（J 到 4000——恶意序列攻击失败）
- **但——严格证明需要"相位抵消"（无共振）**——超出纯几何（间距/密度/平滑性）
- **"相位抵消"的定量论证**——是 P5.10 的核心开放点：
  - 需要：γ_j（RvM 密度）⟹ 交叉项实际 < 对角（对 θ uniform）
  - 候选工具：Bohr 平均（θ 平均——交叉消失）——但——需要"θ uniform"（不是平均）
  - 或——"无共振"的定量（γ_j 的频率独立——间距的无理性）
  - 或——Ingham/large sieve 的"下界版本"（固定方向）
