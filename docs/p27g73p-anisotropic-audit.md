# P27-G7.3-A′ 审计：各向异性测试函数的可行性（门 2 障碍）

> 2026-09-01 · 唐先生 G7.3-A′ 指令 · 严格证明 Q_off(f) < 0 · 门 2 审计

## ① 关键问题——"s 小——t 中等"在乘积测度下的可行性
- D_ρ(f,f̄) = ∫∫K_off(u,v)dμ_f(u)dμ_f(v)̄——**乘积测度**——u, v 独立
- "各向异性"需要 f 多峰（u≈a 和 u≈−a——远距两峰）——但——对角项 vs 交叉项竞争

## ② 数值验证（零点集合：Σδ²=0.5——Σδ²γ²=45.5——t*=0.148）
**远距两峰（a₀=t*/2——u≈a₀——v≈−a₀——t≈2a₀=t*）：Q_off > 0（全部 σ——0.045-0.055——对角压倒）**
**近邻两峰（G5-B 型——τ=0.1——ε=0.05——等权）：Q_off > 0（0.27）**

## ③ ⭐ 关键发现
- **等权两峰（α=β=1）——Q > 0（对角项压倒）**——负方向需要"负特征向量"（αβ<0——精细抵消——G5-B——微小 −2e-4 类）
- **"各向异性"（s 小——t 中等）在乘积测度下不可行**（s² 因子使交叉项 ≈ 0——对角正压倒）

## ④ ⭐ 四阶 jet 展开失效
- t₀ ~ t* = √(2A₂/A₂₂)——**γt₀ ~ √2·γ/√⟨γ²⟩ ~ O(1)**——cos(γt₀) ≈ cos(√2) ≈ 0.155——不是 1——高阶项重要——**四阶截断失效**
- 精确形式：K ≈ 2s²F(t)——**F(t) = Σδ²cos(γt) < 0 需要"相位选择"（cos 负主导——相位问题回归！）**

## ⭐ 审计结论——G7.3-A′ 的门 2 障碍
- **"四阶 collective jet"证明路线撞墙**：
  - 乘积限制（s, t 不能独立控制——各向异性需相关测度——非乘积）
  - 对角压倒（远距两峰——Q > 0）
  - 展开失效（t~t*——γt~O(1)——cos 高阶重要）
  - 相位回归（精确 F(t) = Σδ²cos(γt) < 0 需相位选择）
- **但——"n₋ ≥ 1"（目标——G7.1/7.2 数值支持——N₋ ≥ N）仍可能**
  - 证明需要其他机制（有限秩惯性——或——近邻负特征向量严格化 + 惯性稳定）
