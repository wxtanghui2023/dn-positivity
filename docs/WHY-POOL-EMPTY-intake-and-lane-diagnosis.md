## §1 三层诊断（为何池会空）

```
$$\textbf{(1) 生成端选择偏差}:\ \text{候选由“资产对口”筛出}\Longrightarrow\ \text{天然排除“与现有资产无关但极重要”的问题};$$
$$\qquad \text{HUNT-R1 的既有结论已明说}:\ \text{我方资产只系统性地产生三类产物（等号/锐性分类、重述换壳、有法无题）}\Longrightarrow\ \text{池贫是}\textbf{生成器}问题}$$
$$\textbf{(2) 判据 ≠ 生成器（E-40 §8 已登记）}:\ \text{我们持有的是}\textbf{过滤器};\ \text{“为新机制生成候选”是被禁止的一步};$$
$$\qquad \Longrightarrow\ \text{过滤越严，池越空；而过滤本身不产生供给}$$
$$\textbf{(3) \textsc{amend-22} 的结构性锁死（须诚实指出）}:\ \text{“候选只能取自已登记余项”}\ \text{有效防止重复投资，}\textbf{但同时把入口锁在“生成器本身有问题的那个池”里};$$
$$\qquad \text{其 (d) 款（独立新来源直进四闸）是唯一逃生口} \Longrightarrow\ \boxed{\text{关键不在闸门，在“新来源从哪来”}}$$ ✓✓
```
