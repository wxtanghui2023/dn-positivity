## 0. 本次审计的四处修正（审计发现，非录入）

### 修正 1：证据等级必须附【作用域】，否则 S 级也会变成过度声明
```
N45 的腿(ii)（路径依赖 ⟹ null 可复现）【是条件性的】：
     只有当 null 模型确实能复现该轨迹统计量时才成立
     ⟹ 腿(i)（coboundary ⟹ holonomy≡0）无条件是 S 级
     ⟹ 腿(ii) 应降为 A 级（依赖 Arithmetic Null Separation 的逐例成立）
同类作用域限制：
· N10 仅对"固定 A₁ 的 prime-label 自同构"（一般仿射半群自同构不在内）
· N42 仅对"整除/同余型局部约束"（非同余局部系统不在内）
· N20-A 仅否定"物理轴幺正性 ⟹ 内部共振排除"这一推理
· N26 仅对"任意半环中可证的事实"
· N36 为记录级（引用前须回查原 doc）
⟹ 规则：**S 级条目必须携带作用域；脱离作用域引用视为 T2 违规**
```

### 修正 2：META 必须分两类（否则会把启发式当硬规则）
```
META-硬（逻辑性，无例外）：
  META-3  no hidden oracle（RH 所需信息不得偷放进 state）
  META-4  正性必须有作用对象（只约束 test function ⟹ position-blind）
META-启发（有正当例外，须举证）：
  META-1  命名升级 ≠ 新机制（例外：底层结构确实不同）
  META-2  阶数增加 ≠ 信息增加
          （例外须证 Info(K_{k+1}) > closure(K_1,…,K_k)）
```

### 修正 3：⭐ L0–L4 阶梯的现状定位（本轮最重要的审计结论）
```
L0 形式合法 : ✓ 已定义（四种形态 L1–L4）
L1 存在性   : ✓ 【已达成】char 0 载体确实存在
              （Patterson–Sullivan / Selberg / Ramanujan；模曲面 + 测地流）
L2 耦合     : ✓ 【已达成】门 ⑲：模曲面上 计数↔流↔权重 三者锁定（非并列事实）
L3 定位     : ✗ 【从未达成】——非自伴共振的位置刚性
L4 选择     : ✗ 【从未达成】
⟹ 阶梯与残差【重合】：L3 ≡ L2-残差（non-self-adjoint positional rigidity）
   ⟹ 这是自检通过的一致性好：两条独立路径指向同一个未达成的台阶
```

### 修正 4：决策树第 [0] 步只能是【语义检查】，不能是关键词查表
```
失败模式：新想法关键词不同但实质同源 ⟹ 关键词表出现【假阴性】
第 [0] 步的正确操作形式 = 三问：
  ① 其刚性是否【仅由形式公理/半环公理】可证？      ⟹ N26
  ② 其刚性是否【仅由局部(同余/整除/p-adic)数据】可算？⟹ N5/N42
  ③ 其现象是否可被【保持局部统计的 null 模型】复现？  ⟹ N46
  三问全"否"才进入第 [1] 步；否则按对应条目归类
```

## 4. L0–L4 阶梯（活路的等级，替代先前"四种形态即活路"的模糊说法）

$$\boxed{\text{L0 形式合法}\to\text{L1 存在性}\to\text{L2 耦合}\to\text{L3 定位}\to\text{L4 选择}}$$
```
L0：过 A–H（尚无数学对象）
L1：找到真实 𝒳，且它确实具有 C, M, W
L2：证明 C↔M↔W 是【同一结构】的三面，而非三个并列事实
L3：出现 𝒫(ρ) ≥ 0 且对 Re ρ 有实质约束
L4：得到 Re ρ = 1/2
现状（修正 3）：L0 ✓｜L1 ✓｜L2 ✓｜L3 ✗｜L4 ✗
```

## 5. 四种合法形态的**退出条件**

```
形态 L1（三重锁载体）
  退出：scale coincidence —— Φ(C,M,W)=0 只是人为尺度选择
形态 L2（非自伴谱刚性）
  退出：numerical-range description only —— 只给数值域/奇异值/增长率界
形态 L3（边界—内部锁）
  退出：trace-formula coupling —— 离散↔散射只是共享迹公式/显式公式
形态 L4（非标准几何载体）
  退出：geometric repackaging —— 实为已知 RH 判据的换壳
附加（本轮）：
形态 L0 新增退出：no carrier —— 只有泛函 Q(f) 而无法给出 𝒳
```
