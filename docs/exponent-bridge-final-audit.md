## 1. 先把 1/4 的来源钉死

除数问题的 1/4 来自 **Voronoi 公式**：
$$\Delta(x)=-\frac{2}{\pi}x^{1/4}\sum_{n\ge1}\frac{d(n)}{n^{3/4}}\cos\big(4\pi\sqrt{nx}-\tfrac\pi4\big)+O(\cdot)$$
⟹ $x^{1/4}$ 是**振荡的振幅前缀**，频率是 $4\pi\sqrt n$。
且经典地 $\int_0^X\Delta^2\sim CX^{3/2}$ ⟹ $\Delta$ 的 **L² / 典型尺度 = $x^{1/2}$**，而点式猜想尺度 = $x^{1/4}$。

## 2. ⭐ 关键澄清：1/4 族与 1/2 族不是"不同类型的命题"

对比两个猜想：
```
除数问题 : 典型(L²)尺度 x^{1/2}   点式猜想 x^{1/4+ε}  ⟹ 点式 = 典型的【半指数】
RH       : 典型(L²)尺度 x^{1/2}   点式猜想 x^{1/2+ε}  ⟹ 点式 = 典型【无损失】
```
$$\boxed{\text{两者的猜想都是"点式 = 典型"（无 L²→L∞ 损失）}}$$
差别在于**对象的典型尺度**（$x^{1/4}$ vs $x^{1/2}$），不在命题类型。

⟹ "把 1/4 提升到 1/2"**不是指数运算技巧**，而是换对象 + 换自对偶结构。

$$\boxed{\text{家族阶梯 = 矩阶；"全阶"不可能由有限阶改进获得}}$$

**不可能作为"加强约束"的副产品得到。**

## 4. √ 的唯一已知来源

$\sqrt{\ }$ 尺度出现的地方是**泛函方程** $s\leftrightarrow1-s$（经 Perron/Mellin 给出 $x^{1/2}$ 尺度）。
其余所有自对偶配对（$n\leftrightarrow x/n$、除子配对 $d\leftrightarrow n/d$）只给 **1/4 族**（双曲/几何平方根）。

$$\boxed{\text{要得到新的 1/2 家族刚性 ⟹ 必须有一个新的【泛函方程型自对偶】}}$$
而这已经属于"新的 L 函数/自守对象"，是**数学发现**，不是机制构造。
