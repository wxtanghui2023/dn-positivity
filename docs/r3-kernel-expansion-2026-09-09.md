# R₃ 等价核 K(n,m) 的展开审计（2026-09-09 19:33 唐先生修正后）

## R₃ 的精确定义（无歧义版本——唐先生修正）
```
ρ_k(x) = #{r: r|k, r prime, r ≤ x}（k 的素因子秩函数——对所有素数 p 有定义——）
R₃(n,m) = Σ_{p|n}Σ_{q|m} (1{p<q} − 1{ρ_{n+m}(p) < ρ_{n+m}(q)})
```

## 等价改写（唐先生——关键——）
```
1{ρ_k(p) < ρ_k(q)}（p<q——）= 1{∃ r|k: p < r ≤ q}（区间内 k 的素因子——）
⟹ R₃ = 区间-因子交叉核：
K(n,m) = Σ_{p|n}Σ_{q|m} sgn(q−p)·1{∃ r|(n+m): min(p,q)<r≤max(p,q)}
——三素数核：p|n ∧ r|(n+m) ∧ q|m——p → r → q 跨加法边界的序桥——
```

## μ 展开（本轮新工作——）
```
1{∃ r|k: p<r≤q} = 1 − 1{gcd(k, P(p,q)) = 1}（P(p,q) = ∏_{p<r≤q}r——）
= 1 − Σ_{d|P(p,q), d|k} μ(d)（互素的 Möbius 指示——）
——d: squarefree——素因子都在 (p,q]——P^−(d) > p 且 P^+(d) ≤ q——

K(n,m) = T₁(n,m) − T₂(n,m)
T₁ = Σ_{p|n}Σ_{q|m} sgn(q−p)（纯序项——无 n+m——）
T₂ = Σ_{p|n}Σ_{q|m} sgn(q−p)·Σ_{d|P(p,q), d|n+m} μ(d)
```

## T₁ 的结构（纯序项——）
```
T₁ = Σ_{p|n}[#{q|m:q>p} − #{q|m:q<p}] = Σ_p A_p(n)·B_p(m)
  A_p(n) = 1{p|n}——B_p(m) = #{q|m:q>p}−#{q|m:q<p}
——秩-∞ 双线性（Σ_p——每项 rank-1——p 无限——）
——非有限秩（过 C——）——但积分核/谱分解型（可对角化——）
——双体（过 B——）——无 n+m（纯 n、m 函数——）
```

## T₂ 的结构（含 n+m——关键——）
```
按 d 重排（d 素因子 ∈ (p,q] ⟺ p < P^−(d) 且 P^+(d) ≤ q——）：
T₂ = Σ_d μ(d)·Σ_{p|n, p<P^−(d)}Σ_{q|m, q≥P^+(d)} sgn(q−p)·1{d|n+m}
   = Σ_d μ(d)·C_d(n,m)·1{d|(n+m)}
  C_d(n,m) = A_d(n)·B_d(m)（对固定 d 可分离——A_d = n 的截断
    素因子序统计（p<P^−(d)——）——B_d = m 的（q≥P^+(d)——）——）

全局和（T₂ 的——）：
Σ_{n,m} T₂ n^{−s}m^{−w} = Σ_d μ(d)·Σ_{n,m} A_d(n)B_d(m)·1{n+m≡0 mod d}·n^{−s}m^{−w}
  ——按同余类（n ≡ c, m ≡ −c mod d——）：
  = Σ_d μ(d)·Σ_{c mod d} F_d(c)·G_d(−c)
  F_d(c) = Σ_{n≡c mod d} A_d(n)n^{−s}（A_d 的模 d 加权类——）
```

## 初步判定（本轮——）
```
T₂：每 d 的项 = 【模 d 对角和】（character 型——可展开——）
——但 A_d、B_d 的 P^−(d) 截断（依赖 d——）产生跨 d 耦合——
  ——Σ_d 不能完全解耦（不同 d 的 A_d 共享 n 的素因子 p——）
——F_d(c) 含"素因子截断计数 + 模 d 同余"（friable + CRT 混合——）
⟹ K(n,m) 展开后【不完全坍缩】（T₂ 的跨 d 耦合——）
  ——R₃ 未被第五/六关杀掉（确认——唐先生修正成立——）
  ——但也没活——T₂ 的完整判断（F_d(c) 的解析——跨 d 耦合
    是否产生非已知结构——）需要深挖——
```
