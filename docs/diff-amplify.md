# 差分放大（高通滤波）结果（2026-08-23 23:00）

> 唐先生：找物理中放大差值的工具
> 工具：差分放大（高通——去背景——放大高频差额）
> 结果：❌ 差额是低频（不可分离）——但新发现 r(n) 超平滑

## 1. 差分放大结果

```
r(n) std = 3.03 → Δr = 0.116 → Δ²r = 0.0075 → Δ³r = 0.0005
【差分衰减 6000 倍——r(n) 超平滑——无高频差额】
Δ²r 主峰 f=0.0107 ≈ θ₁(γ₁)/π = 0.0113（γ₁ 主导——平凡）
```

## 2. ⭐ 新定量事实：r(n) 超平滑

- **r'(n) = O(1）**（Δr std = 0.116——数值——r 的导数有界）
- **Δ³r ~ 0.0005**（比 O(1）小 2000 倍——r 极其平滑）
- **差额全部低频**（慢变相位 θ₁~1/γ——r(n) 的核心机制确认）
- **高通滤波无法分离**（差额本身就是低频——不是高频隐藏）

## 3. 物理意义

1. **r(n) 的 O(1）振荡几乎全部是低频（平滑）**——不是高频隐藏结构
2. **r'(n) = O(1）可能是可证的**（Δr = λ_{n+1}−λ_n − 主项差——∫θ₁·sin(2nθ₁)N₀'——van der Corput——O(1）？）——**但 r 本身需要累积（交替）——循环**
3. **"刚性"的又一量化**（r 平滑——不仅 O(1）——导数也 O(1））
