# 反证法（候选 E）精确边界——矛盾形态攻击的关键资产

## 反证法的精确状态（8/23-9/4 澄清——）
- **无条件真**：存在离轴 ρ（β<½——）⟹ (1−1/ρ)^n 指数增长（|1−1/ρ| = 1+ε——ε~(1−2β)/2γ²——）
- **无穷多离轴 ⟹ 矛盾（无条件——）**：指数 vs 多项式（λ_n 已知增长——）——排除无穷多 ✓
- **单离轴（有限——）**：λ_n 破坏在 n ~ 1/ε ~ 2γ²/(1−2β)——**需证明 λ_n ≥ 0 到那个 n**
- **但 λ_n ≥ 0 对所有 n = Li 准则 = RH——循环——**

## 边界（精确——）
```
无穷多离轴：无条件排除 ✓（实质性——超越 67%——）
单离轴：矛盾在 n ~ 2γ²/(1−2β)——依赖 γ！
  - 高零点（γ 大——）→ n 巨大（零密度限 δ < ½−c/log^{2/3}γ——δ 小——n 更大——）
  - n 无界（处理所有 γ——）→ 不是"固定有限层级"
  - λ_n ≥ 0 到任意 n = RH（循环——）
```

## 为什么不是"有限层级矛盾"
- FLT 式矛盾：在**固定有限层级**爆炸（Frey 曲线——Mazur 有界——）
- 反证法：爆炸在 n ~ 2γ²/δ——**依赖零点高度**——γ 任意大——n 任意大——无固定层级

## 关键障碍（所有"离轴矛盾"形态的——）
**"矛盾发生的尺度"依赖 γ（零点高度）**——因为离轴效应 ~ (1−2β)/γ²（相对 γ 衰减——）——高零点效应弱——需要更大 n 才能看到——而"所有零点"包含任意高的——n 无界——非有限

**对比 FLT**：Frey 曲线的非法性（Mazur 扭点界——）**不依赖反例的大小**（任何费马解——无论多大——都产生非法 Frey 曲线——）——固定有界矛盾——**RH 的离轴零点没有这样的"大小无关矛盾"**——因为零点没有"离散大小"（连续——）

## 深层认识
- FLT 反例 = 离散对象（整数解——）——有"尺寸"但非法性尺寸无关（Mazur——）
- RH 离轴零点 = 连续参数（β——γ——）——矛盾尺度依赖 γ（无固定）
- **"离轴零点的矛盾必须尺寸无关"——这是 FLT 类比真正要求的——而零点没有这个性质（除非有隐藏的离散结构——）**
