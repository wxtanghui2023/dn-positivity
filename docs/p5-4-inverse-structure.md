# P5.4 逆问题深化：admissible class C 的结构刻画

> 2026-09-01 · 唐先生战略核心 · Characterize the admissible spectral measures

## 假想离轴谱的参数化
Z(δ)：前 N 个零点离轴——轨道配对（ρ=½+δ+iγ, 1−ρ̄=½−δ+iγ）——**虚部 γ 不变**（轨道配对）——实部偏移 δ

## 各统计律对 δ 的"满足度"（扫描）
| 统计律 | 离轴满足？ | 类型 |
|--------|:--:|------|
| 1. 素数定理（π~x/logx） | ✓（任何 β<1） | 不排除 |
| 2. 相位锁定（S(p)=O(1)） | ✓（虚部不变——S 不变） | 不排除 |
| 3. 成对正性（D=ΣP_γ≥0） | ✓（δ=0 最小——penalty） | penalty |
| 4. 变分定理（S_proj 在线最小） | ✓（允许——penalty） | penalty |
| 5. ψ 匹配（显式公式——ψ_actual 固定） | ✗（ψ'≠ψ_actual——但循环） | 排除但循环 |

## ψ 匹配的数值（x=1e5）
| δ | ψ'−ψ_actual | 相对差 |
|------|------|------|
| 0.00 | −5.2 | 0.0052% |
| 0.05 | −14.8 | 0.0148% |
| 0.10 | −46.8 | 0.0468% |
| 0.20 | −233.0 | 0.2328% |

δ=0 匹配（差小）——δ>0 不匹配（增大）——**但——"匹配"是精确约束（ψ 固定⟹零点唯一）——循环**

## β 体积（实部敏感 variance）对 δ
| δ | β体积 | 比值 |
|------|------|------|
| 0.00 | 4.23e-10 | 1.00 |
| 0.05 | 5.33e-10 | 1.26 |
| 0.10 | 9.83e-10 | 2.33 |
| 0.20 | 5.75e-09 | 13.62 |

**离轴 β 体积更大（数量级变化——δ=0.2 → 13.6×）**——但——"更大"不是"排除"（无独立上界）

## C 的结构刻画结论
**admissible class C（统计律级别）= {在线谱} ∪ {离轴谱（满足统计律 1-4——penalty 更贵——不满足精确匹配 5——但循环）}**

- **½ 是"统计律的最优点"**（变分——无条件——D=0/S_proj 最小/ψ 匹配）
- **但——"最优"不 ⟹ "唯一"**（penalty 不排除）——**"边界唯一"（RH）未证**
- **"可实现性排除"（β≠½ 不可实现）**——需要"匹配级别"约束（循环）——或——**"统计 → 约束"升级**（variance inequality——开放）

## 关键洞察（对应唐先生第七/八点）
- **"½ 作为临界稳定边界"——变分图景成立（无条件）**——"为什么 ½ 特殊"的数值图景：δ=0 是统计律最优点
- **"统计 → 约束"升级的缺口**：目前统计律只给"代价"（penalty）不给"排除"——需要"实部敏感的 variance inequality"（如 Var(ψ) 的独立上界）——**这是"检测 → 约束"的具体化方向**
