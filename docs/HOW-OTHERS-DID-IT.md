## §1 **八项进展的方法内核**

### ① Chasse（RH 至 T ⟹ J_{d,0} 全实，d < T²）【原文级 ✓】
```
【怎么做的】用 Jensen 多项式与"零点对称幂和"的**精确关系** ✓ + **Borcea–Brändén 保稳定算子** + Obreschkoff ✓
【内核】**转换/放大**：把**数值输入**（RH 到 T ✓）经**定量机制**放大成**符号结论**（d < T² ✓）
【为什么是平方】**判据对高度 γ 处零点的敏感度 ∝ γ²** ⟹ 指数由**敏感度标度**决定 ✓
```

### ② Oesterlé 2000 / Palojärvi / D-037（RH 至 T₀ ⟹ λ_n ≥ 0，n ≤ T₀²）【二手 ⚠️】
```
【怎么做的】**Lagarias/Bombieri–Lagarias 算术分解**：λ_n = **S_∞(n) − S_f(n) + δ** ✓
   其中 **S_∞(n) = ½n log n + C₁n + O(1)**（显式 ✓），S_f 用**零自由区/已验证高度**界定 ✓
【内核】**显式分解 + 误差预算**：主项（显式、可算 ✓）vs 误差（经典估计 ✓）⟹ **比大小** ✓
【⭐关键】主项 ~ n log n ｜ 误差 ~ √n log n ⟹ 对**大 n 误差无害** ✓✓
   ⟹ **范围由【输入的适用范围】决定（T = √n ⟹ n ≤ T₀²），而不是由误差决定** ✓✓✓
```

### ③ 2/3 论文（≥2/3 简单零点在线上；0.6725）【原文级 ✓】

```
【⭐关键】**改变问题**（从"证明 X"改为"给 X 的计数一个界"）⟹ 工具立刻够用 ✓✓
```

## §2 ⭐⭐⭐ **抽取出的模式（这就是答案）**
```
【P1】**全部是"转换/放大"**：已知输入 →（定量机制）→ 新符号结论。
      **没有一项**是"发明新对象"或"发现新机制" ✓✓
【P2】**输入只有两类**：(a) **严格验证的数值事实**（RH 到 T ✓、零点统计 ✓）
      (b) **已知的精确恒等式**（B–L 分解 ✓、Weil 型 ✓、CR/Jensen 关系 ✓）
【P3】**功夫在【量】上**：常数显式化、误差项控制、**标度识别**（γ²/√n/T² ✓）
      —— 而不是在【构造】上 ✓✓
【P4】⭐ **范围由【输入的适用范围】决定，不由误差决定**（主项压过误差后，误差无害 ✓）
      ⟹ 想扩范围 ⟹ **必须扩输入**（更高验证高度 ✓）或**改判据**（敏感度标度更好 ✓）
【P5】**进展只有四种形态**：
      (i) **新输入**（更高 T ✓——靠计算 ✓）
      (ii) **更好的转换**（更优常数/新判据 ✓）
      (iii) **改变目标**（证明 ⟹ 比例/计数 ✓——2/3 论文 ✓）
      (iv) **显式化 + 机器验证**（D-037 ✓）
```

## §3 ⭐⭐ **这对"找突破点"意味着什么（针对我们）**
```
【对照】**我们的项目一直在找"新对象/新机制"**（K₃、关系、动力系统、上同调…）✗
   ⟹ 而 **P1 说明：没有人**是这样取得进展的 ✓✓✓
【因此】突破点的正确形态是 **P5 四形态之一**，而不是"发明" ✓✓

【逐条评估我们的四形态机会】
 (i) **新输入** ⚠️ **对我方基本关闭**：
     要提高 T 需超算级计算 ✗；要用**零密度替代完整验证**？⟹ **逻辑上不可行** ✓
     因为：**单个离轴零点**的贡献 ~ −e^{nδ/γ²} **随 n 指数增长** ✗，
     而在线项每项 ≤ 2 ✓ ⟹ **一个离轴零点就毁掉大 n 的正性** ✗
     ⟹ **必须【逐个控制零点】⟹ 只能靠"验证高度"这类输入** ✓（**此路已封** ✓）
 (ii) **更好的转换** ⭐ **唯一明确开放的窄口**：
     现有：n ≤ T²（常数 c=1 或 1/(4log²T)）✓
     我方线索：**阈值律 n* ≈ 6.6γ²/|2δ|** ⟹ **期望 c ≈ 6.6**（γ 略高于 T₀ ✓）⚠️**需严格化** ✗
     + **log 因子**的改进 ✓
 (iii) **改变目标** ⭐ **很可能可行且被忽视**：
     例：**"λ_n ≥ 0 对 n ≤ N 中的【几乎所有】n"**（而非每个 n）✓；
         或 **Σ_{n≤N} λ_n 的显式下界** ✓；**λ_n ≥ −(显式小量) 对一切 n** ✓（定量下界而非正性 ✓）
     ⟹ 属 2/3 论文式**目标降级** ✓✓
 (iv) **显式化 + 机器验证** ⭐ **可行但需超越已有**：
     D-037 已做到 (T₀−1)² ✓；我们能做的只有**改进 (ii) 后重新显式化** ✓
【结论】**真正未被占据的窄口 = (ii) 常数/log 因子 + (iii) 目标降级** ✓✓
```
