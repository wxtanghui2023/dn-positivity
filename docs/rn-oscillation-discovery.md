## 1. 背景

RH 论文降级（发现循环论证）后，转向 λ_n（Li 系数）的精细结构研究。
核心对象：`r(n) = λ_n − ½n·log n − c·n`，其中 `c = ½(γ_E − 1 − log 2π) = −1.1303307`。

**动机**：λ_n ≥ 0 ⟺ RH（Li 1997 准则，Bombieri-Lagarias 等价形式）。r(n) 是 λ_n 渐近的余项。

## 2. 工具链

### 2.1 sin² 公式（唯一可靠工具，n>300）

$$\lambda_n = 4\sum_{\gamma>0}\sin^2(n\theta_\gamma), \quad \theta_\gamma = \arctan\frac{1}{2\gamma}$$

- 推导：ρ/(ρ−1) = e^{−2i·arctan(1/(2γ))}（临界线上精确），λ_n = 4Σsin²(nθ)
- **数值稳定**（sin² ∈ [0,1]，无相消），支持大 n
- **截断误差**：需要 γ_max 足够大，尾部 ~ n²·coef

### 2.2 Stieltjes 方法（n≤300 可靠，n>300 崩溃）

- log ξ Taylor 系数 c_m + b_m 递推 + 二项式求和
- **dps=100 在 n>300 数值爆炸**（n=350: r=−1403, n=500: r=−1.7e45）
- 原因：b_m 递推的 O(KMAX²) 高精度相消，精度不足
- dps=200 到 n=800 需要 ~1-2 小时（实测 11 分钟还在 b_m 递推，已终止）
- **结论：sin² 公式 + 零点表是唯一可靠路径**

### 4.2 关键结构特征（v2 修正后）

1. **r(n) = O(1) 有界振荡**：范围 [−10.3, +11.5]（n=50-3000 采样 296 点）
2. **无增长趋势**：r(50-500)均值 1.86 ≈ r(2500-3000)均值 2.09
3. **均值 +1.8**（λ_n 略大于主项），std 3.4，**r<0 仅 24%**
4. **对称振荡**（非系统性负偏）
5. **子结构**：n=750-850 宽波谷（深度 −6.2，宽度 ~100）；n=2000 局部峰 +11.5
6. 与 8/21 深夜 Stieltjes dps=80 的 O(1) 结论**一致**（n≤250 尾部极小，无 bug 影响）

### 4.3 数值验证（v2 修正后重新确认）

1. **截断估计精确**：多级子集验证实际尾部 vs 估计差 0.0000
2. **S(T) 振荡项误差 ~1e-5**：可忽略
3. **1M vs 2M 交叉验证（含真实尾部）**：r(2000/2600/3000) 差 ~1e-5（完全一致）
4. **符号修正验证**：r_true = λ_2M + tail − main（tail>0 应加）

**结论：n≤3000 的 r(n) 数值完全可信（误差 < 1e-4）**

| Arias de Reyna (2011) | n·y_n, y_n∈ℓ² | 无具体形式 |
