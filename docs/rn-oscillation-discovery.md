## 1. 背景

RH 论文降级（发现循环论证）后，转向 λ_n（Li 系数）的精细结构研究。
核心对象：`r(n) = λ_n − ½n·log n − c·n`，其中 `c = ½(γ_E − 1 − log 2π) = −1.1303307`。

**动机**：λ_n ≥ 0 ⟺ RH（Li 1997 准则，Bombieri-Lagarias 等价形式）。r(n) 是 λ_n 渐近的余项。

## 2. 工具链

### 2.1 sin² 公式（唯一可靠工具，n>300）

$$\lambda_n = 4\sum_{\gamma>0}\sin^2(n\theta_\gamma), \quad \theta_\gamma = \arctan\frac{1}{2\gamma}$$

- 推导：ρ/(ρ−1) = e^{−2i·arctan(1/(2γ))}（临界线上精确），λ_n = 4Σsin²(nθ)
- **数值稳定**（sin² ∈ [0,1]，无相消），支持大 n
- **截断误差**：需要 γ_max 足够大，尾部 ~ n²·coef

### 2.2 Stieltjes 方法（n≤300 可靠，n>300 崩溃）

- log ξ Taylor 系数 c_m + b_m 递推 + 二项式求和
- **dps=100 在 n>300 数值爆炸**（n=350: r=−1403, n=500: r=−1.7e45）
- 原因：b_m 递推的 O(KMAX²) 高精度相消，精度不足
- dps=200 到 n=800 需要 ~1-2 小时（实测 11 分钟还在 b_m 递推，已终止）
- **结论：sin² 公式 + 零点表是唯一可靠路径**

## 4. 核心发现：r(n) 的振荡结构

### 4.1 r(n) 不是 O(1)！（修正 8/21 深夜的结论）

之前（n≤250，Stieltjes dps=80）观察到 r(n) ~ O(1) → **误判**（视野不足）。
真实行为（2M 零点 + 精确截断修正）：

| n | r(n) | 截断 | r/√n | 说明 |
|---|------|------|------|------|
| 50 | +2.25 | ~0 | +0.32 | 起始 |
| 250 | +0.10 | ~0 | +0.01 | 接近零 |
| 500 | +2.95 | 0.18 | +0.13 | 回升 |
| 793 | **−8.51** | 1.16 | −0.30 | **深谷（宽波谷）** |
| 1000 | −1.20 | 1.84 | −0.04 | 回升 |
| 1600 | **−12.6** | 4.71 | −0.32 | 下降 |
| 2000 | **−3.2** | 7.37 | −0.07 | **局部波峰（子结构回升）** |
| 2400 | −19.2 | 10.6 | −0.39 | 再次下降 |
| 3000 | **−34.5** | 16.6 | −0.63 | **深谷** |

### 4.2 关键结构特征

1. **r(n) 不是 O(1)**：n=3000 达 −34.5，远超 n≤250 的 ±3
2. **r(n) 不是幂律**：n=2000 回升到 −3.2 打破单调增长（α 拟合无稳定值：−2.7 到 +3.5）
3. **大周期振荡假设**：n=2000 回升 + n=3000 再降 = 振荡模式
   - FFT 主频周期 ~1950 ≈ 观测窗口 → 可能是主周期（T~4000-6000）的谐波/混叠
   - 可能只看到半个大振荡
4. **系统性负偏**：n>1000 后 r(n) 几乎全负（非对称随机游走）
5. **子结构**：n=750-850 宽波谷（深度 −8.5，宽度 ~100），FFT 检测到周期 ~80-190 成分

### 4.3 数值验证（三重确认）

1. **截断估计精确**：多级子集验证（γ>600559, γ>870030, γ>1028190）实际尾部 vs 估计**差 0.0000**
2. **S(T) 振荡项误差 ~1e-5**：可忽略
3. **1M vs 2M 交叉验证**：r(3000) 完全一致（−17.912 = −17.912，差 0.0000）

**结论：n≤3000 的 r(n) 数值完全可信（误差 < 0.01）**
