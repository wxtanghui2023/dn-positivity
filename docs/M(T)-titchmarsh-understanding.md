# M(T) 攻坚补充：Titchmarsh 9.9A/13.8 理解（2026-09-08 19:30）

## S1 = O(log T)（9.9A）的来源
- S1(T) ~ 近 T 零点（|γ−T|≤1——~log T 个——）每零点贡献 O(1)
- **O(log) 墙 = 近零点数（~log T）× 每零点 O(1)**

## 13.8 证明线索（S1 = o(log) ⟹ Lindelöf）
- 用 log ζ 的围道积分——S1 控制幅角累积 → ζ 增长
- S1 = o(log) ⟹ Im log ζ 增长可控 ⟹ μ(½)=0

## Backlund 等价（Lindelöf）
- Lindelöf ⟺ 对每个 ε>0：Re β ≥ ½+ε 的零点在 (T,T+1) 内 o(log T) 个
- M(T)=O(1)（如果真——）⟹ Lindelöf ⟹ 离轴零点密度 o(log T)
- 注意：Lindelöf 允许稀疏离轴（o(log T) 每单位——）——比 RH 弱得多

## 中间目标不存在（全有或全无）
- S1 的任何 o(log) 界（逐点——）⟹ Lindelöf（13.8——）
- 文献 O(log T) 是"精确的墙"——没有中间地带
- 要么 O(log) 改进（=Lindelöf——）要么证明 O(1)（=Lindelöf——）

## 攻坚结论
- M(T)=O(1) 等价 Lindelöf 核心（近零点抵消——零点局部分布规则性）
- 数值证据极强（到 2.5M——max 1.3-1.7 稳定——）
- 完整证明需要零点局部分布规则性（Gram 型——）的无条件证明
- 这是比 RH 弱的目标（Lindelöf——）但仍是深层猜想
