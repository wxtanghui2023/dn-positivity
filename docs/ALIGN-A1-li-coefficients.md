## §1 ⭐⭐⭐ **前沿的【框架】—— 一个我们此前没有抓住的关键事实**
```
【Lagarias 2007 原文 ✓】"λ_n = S_∞(n) − S_f(n) + 1，其中 S_∞(n) 与 S_f(n) 分别对应
   **archimedean place** 与 **finite places** 的贡献；末项是 ξ(s)/s(s−1) 在 s=0 的极点贡献" ✓
【⚠️ 第三条观察（原文 ✓）】"**each positivity condition λ_n ⩾ 0 encodes 'Weil positivity' of
   Weil's quadratic functional for a particular test function g_n(x)**" ✓✓✓
⟹ ⭐⭐⭐ **"λ_n ≥ 0" 等于"对某个【显式测试函数 g_n】的 Weil 正性"** ✓✓✓
   —— 即 **Li 判据 = 一族 Weil 正性命题，每个 n 一个 g_n** ✓✓
   —— 且原文另有："the dominant contribution … comes from the **archimedean terms**, which correspond
      to the **'trivial zeros'** of L(s,π)" ✓ ⟹ **主项来自平凡零点/阿基米德位** ✓✓
⟹ **这把 A1 直接接到 Weil 正性线（A3/A7）** —— **而这是我们此前没有做的连接** ✓✓
```

## §2 **前沿已证的与未证的（精确）**
```
【已证 ✓】① **Li ⟹ 零自由**：Brown 2005 Thm 3 ✓；Palojärvi 的 τ 版对应定理 ✓
         ② **探测方向**：Palojärvi **Thm 2.3**："若存在某 n 使该项为负 ⟹ 存在零点满足 |ρ/(ρ−τ)| ≥ R" ✓
         ③ ⭐ **单离轴零点情形**：Palojärvi **Thm 4.1**："设 F 至多有一个零点满足 |ρ₁/(ρ₁−τ)| > 1 …" ✓✓✓
【未证 ✗】**零自由 ⟹ Li 非负**：Brown **Thm 2** 的 Lemma 5 **两处错误、只修一处、至今未证** ✗✓
【τ 版的关键参数】Thm 2.1：n ≥ max{e, T₀/(eτ)}，**T(n) := n·e·τ** ✓，并需一条**显式不等式**：
   **(1+τ²/N²)^{(N²/τ²)(5τ²/2)(A_F log N + M_F)} < e^{5τ²M_F/2} · N^{5τ²A_F/2}** ✓
   ⟹ **n 与实际高度/零自由参数的关系由【这条不等式】决定** —— **不是简单的线性关系** ⚠️（我此前的"线性"判断过粗 ⚠️）
```
