## P26-A20 结果

### ① 重数强制的机制分解（F_q——合并）
- 特征多项式 P(t) = det(1−t·Fr)——有限维——特征值 α——两种对称性：
  - Galois 共轭：α ↔ ᾱ（P(t) 系数在有限域）
  - Poincaré 对偶：α ↔ q^w/α（特征值倒数）
- **"合并"：q^w/α 与 ᾱ 是同一特征值（当 |α|² = q^w）——两种对称性在同一特征值上对齐——重数强制**
- **本质：两种对称性（共轭 + 对偶）的"对齐"（在谱对象中）**

### ② Spec Z 的对应
- 共轭（ρ↔ρ̄）+ FE（ρ↔1−ρ）——"对齐"（1−ρ = ρ̄——在线——β=½）——"合并"（对齐）本身是 RH
- 离轴（1−ρ ≠ ρ̄——不对齐——4 元素轨道）

### ③ ⭐ 关键——F_q 的合并发生在"特征多项式"（谱对象）中
- F_q：P(t) 的根（α, ᾱ, q^w/α, q^w/ᾱ）——当 |α|²=q^w——α 与 q^w/ᾱ 重合——重数 2
- **Spec Z：需要"谱对象"（Θ）——合并（1−ρ 与 ρ̄）发生的地方——但 Θ 未构造（Deninger——elusive）——无合并发生的地方——无重数强制**

### ⑤ ⭐ 诚实评估
- **"重数强制"的本质（F_q）：两种对称性在"特征多项式"（谱对象）中对齐——合并**
- **Spec Z 需要"谱对象"（Θ）——未构造——无合并的地方——无重数强制**
- **核心障碍：谱对象（Θ）未构造——与 THH/特征零无 Fr 一致——对齐本身是 RH——循环**

### ⑥ ⭐ 深层——"对齐"的物理含义
- F_q 的"对齐"（两种对称性的相容——表示论）——特征多项式的结构强制
- Spec Z 的"对齐"（共轭与 FE 的相容）——在线（相容——合并）——离轴（不相容）
- **"为什么必须相容"——F_q（特征多项式强制）——Spec Z（无谱对象——无强制——除非 Θ）**
