## 0. ⭐ Gate 0（我加，**首位强制**）：字典自洽性检验
```
先决事实：Montgomery 的【无条件】范围是 λ<1 ⟺ η<0 ⟺ H=X^{o(1)}
⟹ 字典 λ=1/(1−η) 必须与该事实自洽
⟹ 任何"看似无条件的 λ≥2 结果"必须先假设【字典误用】，而不是突破

核验三项（对每条候选结果）：
  ① 归一化：variance 还是 second moment？L² over x 还是 almost-all？
  ② 是【主项】还是仅【上界】？（S2-b vs S2-c）
  ③ GM 对应在【该 η 区间】是否有效？（对角主导条件是否成立）
```
$$\boxed{\text{内部自洽检查：若"无条件高 λ"与"无条件 λ<1"同时成立 ⟹ 必有一方是坐标/归一化错误}}$$

## 1. 候选机制类枚举 + 预筛
| 类 | 是否可提供 S2 主项 | 预筛依据 |
|---|---|---|
| 圆法 / Vaughan / Type I–II 和 | 待审 | 可给**平均**型渐近；须查 η 范围 |
| **纯筛法** | **预淘汰** | **奇偶性障碍（parity problem）**：二元素数关联的主项不能由纯筛法给出 |
| 大筛 / 谱方法 | 待审 | 若只给上界 ⟹ S2-b，不达 S2-c |
| 族平均 / 迹公式 | **排除**（唐先生） | 族结构不匹配 ζ（R6 已确立） |
| zero statistics | **排除** | 命中循环（N1） |
| Hardy–Littlewood | **排除** | HL 本身即强未解决输入 |
| 其他 char-0 结构 | **开放（本协议要找的）** | 须过 V1 四条件（非编码/非局部/非 coboundary/char-0） |

## 2. ⭐ 个体 h vs 平均 h（结构性要点，须写死）
```
· 个体 h 的主项 C(h;X) ~ 𝔖(h)X（如 h=2）⟹ **twin-prime 强度**（HL）⟹ 【不可得】
· R8 只需要【按 h 加权平均后】的主项 ⟹ 这允许"平均型"机制
⟹ **S2 的合法目标形式 = 平均（加权）主项，而非逐 h 主项**
⟹ 任何试图从个体 h 出发的路线，按第二行直接判为 HL 强度
```

## 3. 三问（沿用 R8）
```
Q1 独立性：该机制是否不接触 RH/zero statistics/HL？
Q2 跨越性：能否覆盖 η>0 乃至 η=1/2？
Q3 非等价性：其所需信息是否不与 F(α)（α∈(1,2)）互相定义？
```
