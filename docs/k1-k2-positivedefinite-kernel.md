# K1–K2：正定核 / reproducing-kernel 路线审计

> 2026-09-01 · 唐先生指示选 ② · K1（候选正定对象审计）→ K2（单点离轴破坏正定性）

## K1：候选正定对象审计

### 审计对象与判定
| 候选 | 正定性来源 | RH 前独立？ | 判定 |
|------|-----------|:--:|------|
| de Branges 核 K(w,z) | B(E) Hilbert 空间内积 | ❌ | 循环（E 的 HB 前提 = 零点在线） |
| Hermite-Biehler 核 \|E\|²−\|E*\|² | HB 条件 | ❌ | 循环（正定 ⟺ 零点实） |
| Weil 双线性型 | 显式公式 | ❌ | 循环（D1 已审计） |
| Li 判据 λ_n ≥ 0 | ξ 导数 | ❌ | 循环（等价刻画） |
| Mellin/Fourier 核 | 积分算子 | ✅ 但 | 正定但无 β 信息（不含零点——离轴不破坏） |

### de Branges 的循环深度（数值发现——比预期更深）
E 与 ξ 的关系：ξ(½+iz) = E(z)·E(z̄)̄（RH 下）——E 的构造需要：
1. **零点位置**（把零点分成上下两半——Level 0/1）
2. **相位因子 e^{−iaz}**（使 E* ≠ E——匹配 ξ 的实性/增长/归一化）
- 数值验证：若忽略相位（E 实系数）——E* = E——de Branges 核恒为零（非 HB 类）
- **E 的构造完全依赖 ξ 的结构（零点 + 相位 + 归一化）——深度循环**

## K2：单点离轴破坏正定性的机制——验证

### 数值验证（de Branges 核——E 从零点构造）
- 采样点实轴——核矩阵特征值：
  - δ=0.1：有负特征值（−9.3e-4）——**离轴破坏真实**
  - δ=0.3：负方向增大（−2.8e-3）——破坏随 δ 增强
- **"离轴 ⟹ 负 principal minor"机制真实存在**（当 E 允许构造时）
- **但——E 的构造需要零点（+相位）——循环**——破坏只对"构造的 E"成立

### K2 核心逻辑障碍（两难）
```
① K 含零点（β敏感）——离轴破坏 ✓——但——正定性依赖位置（循环）
② K 不含零点（β盲）——正定性独立 ✓——但——离轴不破坏 ✗
```
**"独立正定 + 离轴破坏"在"K 由 ξ 定义"的框架内互斥**：
- K ⪰ 0 对合法 ξ（独立定理）+ 离轴 ⟹ det K_n < 0（独立定理）——合起来 ⟹ RH——但——
- "K ⪰ 0 对所有合法 ξ"若真——覆盖离轴 ξ（若 RH 假——离轴 ξ 合法）——矛盾定理 2
- 除非"合法"定义独立于 RH——即可实现性判据——D5/P2′ 已审计——循环

## K1–K2 判定
- **de Branges/HB/Weil/Li：全部循环**（正定性 ⟺ RH 或依赖零点构造）
- **K2 两难：结构性障碍**——"独立正定"与"离轴破坏"互斥（在 ξ 定义框架内）
- 打破两难需要：**全新的独立核构造**（不依赖零点——且 β 敏感）——现有框架无此对象
- **K 路线（现有框架）：封口**——除非出现全新独立核（非 de Branges/Weil/Li/HB）

## 与 D7 结论的一致性
- D7："恒等/自适应通道只给代价不给排除"
- K1-K2："正定核要么不含 β（不给排除）——要么依赖零点（循环）"
- **同一堵墙的两种表述**：任何"由 ξ 定义"的正定结构——要么自适应（循环）——要么 β 盲（不破坏）

## 战略意义
- K 路线（现有正定核框架）——结构性封口
- 唐先生排序中的"变分稳定性"——同样有 D 型风险（penalty ≠ inadmissibility）
- **真正的出路**：要么全新独立核（非现有框架）——要么新的算术—几何对象（同时有算术输入和几何刚性）
