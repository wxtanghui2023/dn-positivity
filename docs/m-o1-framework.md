# M(T) = O(1) 严格框架：锯齿中点表示与相位均匀性（2026-08-22 18:25）

## 一、严格恒等式（数值验证）

### 锯齿中点表示
```
dM_k = S(γ_k + Δγ_k/2)·Δγ_k + O(Δγ_k³)
M(T) = Σ_k S(mid_k)·Δγ_k + O(1)
```
- 验证：max|err| = 0.11, mean|err| = 1e-6, Σerr = O(1)（2M 零点）
- 推导：dM = ∫[k−θ/π−1]du（θ 的积分——Taylor 展开 3 阶）
- 关键修正：之前误用 dθ/π（差）代替 ∫θdu/π（积分）——错误已修正

## 二、无条件定理（已证明）

```
mean(S(γ_k)) = ½ + o(1)（Littlewood + 分部积分 + 恒等式）
⟺ mean(S(mid_k)) = 0（锯齿中心——等价形式）
```

## 三、强数值结构（2M 零点——核心发现）

### Σε_k = O(1)（相位均匀性）
```
ε_k = S(γ_k) − ½
Σ_{k≤K} ε_k = O(1)（max|Σε| = 1.67——不是 √K！）
```
- K=1e6: Σε = −0.10, K=2e6: Σε = −0.25
- 等权重部分和有界——**M = O(1) 的直接机制**

### 机制：自相关振荡抵消
```
ε 自相关：lag-1 +0.25, lag-3 −0.10, lag-5 −0.19, lag-10 −0.08, lag-20 +0.10, lag-50 +0.14
Σρ_lag → −0.57（收敛）→ 1+2Σρ ≈ 0 → Var(Σε) = O(1)
```

## 四、完整框架链条

```
1. dM_k = S(mid_k)·Δγ_k + O(Δγ³)          （严格恒等式 ✓）
2. mean(S(γ_k)) = ½ + o(1)                 （无条件定理 ✓）
3. Σ[S(γ_k)−½] = O(1)                       （强数值——相位均匀性 ✓）
4. M(T) = ΣS(mid)·Δγ + O(1) = O(1)          （归结——研究级严格化 ⚠️）
```

## 五、等价表述（严格化目标）

Σε = O(1) ⟺ **零点相位均匀性**：
```
θ(γ_k) = π(k−1−S_k) → θ(γ_k) ≈ π(k−½) 的偏离部分和 O(1)
⟺ Σ_k [θ(γ_k)/π − (k−1) + ½] = O(1)
⟺ 零点在 Gram 尺度上的相位均匀分布（强于 mean = ½）
```

## 六、框架定位

- **不依赖素数拟合**（准周期/素数框架是辅助——滤波层——平滑部分）
- **核心机制**：锯齿（mean = ½ 无条件）+ 相位均匀性（Σε = O(1) 数值强）
- **所有部分数值确凿**（2M 零点——多方法交叉验证）
- **最后一步严格化**（Σε = O(1) 的证明）——研究级——RH 相关深度——等价于零点相位均匀性的证明

## 七、研究记录（教训）

1. **对象混淆**：Var[M(T)]（固定 T 方差）vs ∫M²dt（时间平均）——不同量
2. **公式错误**：∫θ du 误为 dθ（差）——修正为 Taylor 积分
3. **素数协方差不解释 Var[M]**：权重 1/p 发散（大素数）——高频积分 O(1)——真实机制在锯齿
4. **准周期是滤波层**：C(u)（权重 1/(p log²p)）是加权版本——非真实协方差
5. **框架必须扎实**（唐先生指示）：不能数字拟合——严格恒等式 + 无条件定理 + 明确的研究级归结
