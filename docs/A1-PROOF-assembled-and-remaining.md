## §1 **定理（组装后的陈述）**
```
设 τ = 1、k ≥ 2 整数、H > e。则
  Σ_{|I(ρ)|>H} [ (1+1/γ_ρ²)^{k/2} + (1+1/γ_ρ²)^{−k/2} − 2 ]
     ≤ 2 (r_H^k + r_H^{−k} − 2) [ (a/3)H log H + (4a/9)H + 2c log H + 2d + c/4 ]
其中 **a = 1/(2π)**、**b = −(1+log2π)/(2π)**（**b⁺ = 0** ✓）、**3a+b > 0** ✓，c,d 为 S(T) 的显式常数 ✓
```

## §2 **证明链（六条引理，全部就位 ✓）**
```
【引理 1】x^{k/2}+x^{−k/2}−2 = (x^{k/4}−x^{−k/4})² ≥ 0 ✓
【引理 2】F(x) 在 **x > 1 严格递增** ✓（F′>0 ⟺ x>1 ✓）—— 恰是 Brown 错误 1 误判的区间 ✓
【引理 3】F(1+u) ≤ (k²/4)u²(1+u)^{(k−4)/2} ✓（且 k=2 时等号 ✓）
【引理 4】⟹ LHS ≤ (k²/4)·r_H^{(k−4)⁺}·S₄(H) ✓
【引理 5（E2 救回 ✓✓）】S₄(H) ≤ (2a/3)H^{−3}log H + (8a/9+2b/3)H^{−3} + (4c log H + c/2 + 4d)H^{−4}
   —— **Abel 恒等式【含边界项】** + 计数假设 ✓；**首项系数 2a/3 = 1/(3π) 恰好尖锐** ✓✓
【引理 6（新 ✓）】精确因子：**(r^k + r^{−k} − 2)/(k²/4) = fac** ✓，且 fac = u²(1−u)(1+O(u)) ✓
```
