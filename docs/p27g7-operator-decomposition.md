# P27-G7.1：Off-Line Zero Operator Decomposition——有限秩 + 负谱

## ⭐⭐ 结构定理（严格）
**K_N(u,v) = Σ_{j=1}^N e^{(u+v)/2}[cosh(δ_j(u+v))−1]cos(γ_j(u−v)) 是有限秩算子（秩 ≤ 6N）**
- cosh(δ(u+v)) = cosh(δu)cosh(δv) + sinh(δu)sinh(δv)（秩 2）——cos(γ(u−v)) = cos(γu)cos(γv) + sin(γu)sin(γv)（秩 2）——e^{(u+v)/2}（秩 1）
- 乘积展开 = 4 项 + 2 项（−1·cos 项）——**每零点秩 ≤ 6**
- **谱 = ≤6N 个非零特征值 + 0（有限秩——无条件）**
