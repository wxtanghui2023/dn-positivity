# 轨道退化诊断：RH ⟺ 零点轨道退化（重数强制的缺失）

> 2026-09-01 · 搭接相探索 (a) 的深挖 · 修正并深化配对类型诊断

## 修正：纯倒数配对（ρ ↔ 1−ρ）其实存在
**ξ(s) = ξ(1−s)——若 ξ(ρ)=0——ξ(1−ρ)=0——1−ρ 是零点（无条件）**
- 纯倒数配对（ρ ↔ 1−ρ）存在（函数方程直接给）
- 配对模：|e^{−ρ}|·|e^{−(1−ρ)}| = e^{−1}（乘积固定——模互补）
- （之前的配对类型诊断说"缺纯倒数配对"——不准确——修正）

## 零点轨道（无条件——4 元素）
```
共轭：ρ → ρ̄（ζ 实值）
函数方程：ρ → 1−ρ（ξ 对称）
组合：ρ → 1−ρ̄
轨道 {ρ, 1−ρ, ρ̄, 1−ρ̄}——一般 4 个元素
```

## ⭐ RH ⟺ 轨道退化（4 → 2）
- 若 β=½：1−ρ = ½−iγ = ρ̄——重合——轨道 {ρ, ρ̄}（2 元素）
- **RH ⟺ 轨道退化（1−ρ 与 ρ̄ 重合——对每个零点）**
- 数值：δ=0（退化——2 元素）——δ=0.1/0.2（4 元素——不退化）

## 为什么退化需要"重数强制"——F_q vs Spec Z
**F_q**：特征值 α（有限——重数固定）——Poincaré 对偶 q^w/α + 共轭 ᾱ——**重数强制**：q^w/α 和 ᾱ 是"同一个"特征值（有限——无多余位置）⟹ |α|² = q^w——**Weil 证明**

**Spec Z**：零点 ρ（无限）——1−ρ（函数方程）和 ρ̄（共轭）都是零点——但——**无限集合——它们可以"并存"为不同零点**——无"重数强制"（无有限维多项式结构）——轨道不退化——离轴可能

## 最精确诊断（修正后）
> **Spec Z 缺的不是"纯倒数配对"（它存在——函数方程给 ρ↔1−ρ）——而是"重数强制"（有限维代数结构——F_q 的特征值多项式）——使配对与共轭重合（1−ρ = ρ̄——轨道退化——β=½）——"无限性"破坏"重数强制"——这是 Weil 证明与 RH 难度的最精确差异。**

## 与"共线"洞察一致
- 共线（唐先生 8/31）：所有零点在一条直线 = 轨道退化 = RH
- 但——"为什么退化"（重数强制）——Spec Z 无机制
- **"共线 ⟹ β=½"（函数方程配对）成立——但——"共线"的证明需要"重数强制"——Spec Z 无**

## 战略意义
- 这解释了 150 年的根本困难：函数方程的配对（ρ↔1−ρ 和 ρ↔ρ̄）**无条件存在**——但——**"重合"（轨道退化——β=½）需要"重数强制"**——有限域的 Weil 有（有限维）——Spec Z 无（无限）
- **要找的"搭接相"**：本质上是找"重数强制"（有限维化——使 1−ρ 与 ρ̄ 重合）——Spec Z 无已知来源
