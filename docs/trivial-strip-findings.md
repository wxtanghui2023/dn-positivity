## 新发现（剥离的深层结构——）

**平凡层的二项式变换形式发散**：
```
λ~_n^triv = Σ_m [1−(2m/(2m+1))^n]——m 大时 ~ n/(2m)——尾对数发散
但 λ~_n（全——）= O(1)（干净——）
⟹ λ~_n 的 O(1) = 平凡层(发散) + 非平凡层(反号发散)——灾难性抵消？
或——Maślanka 构造含正则化（趋势吸收——）
```

**λ~_n 的"平凡/非平凡分离"不直接可做**：
- 数值分离：λ~_n^triv(M=100) ~ +1.3n（增长——）——净非平凡 ~ −1.3n
- 但 λ~_n = O(1)——分离是人为的（λ 本不含平凡——）

## 认识收敛（重要——）

1. η_j 的 −1/3 = **平凡背景**（无条件——非 RH——）——无 β 价值
2. λ~_n = O(1) 的**非平凡部分**才是 β 相关的——需要相位均匀性（配对——）
3. **没有"平凡来源"的捷径**——λ~_n 的核心挑战不变
4. 但——η 层研究给了**精确的"背景分离工具"**（−1/3——剥离——）
   ——可用来区分"哪些 O(1) 是平凡的（背景——）哪些是深刻的（非平凡——）"
