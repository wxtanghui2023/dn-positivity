## P22 框架（唐先生）

- 若 D 的性质（解析/对称/协变）强迫 T = T*（或 normal/self-adjoint dilation）——independent bridge ⟹ HP-type spectral structure——"HP 唯一出路"从经验归纳变成 necessity theorem
- Gate S1-S4：S1 不预设谱 / S2 强迫对称性 / S3 检查谱参数 / S4 最关键（Bridge ⟹ Spectrality）

## Gate S1-S4 结构分析
### S1（不预设谱）——可设
假设 F1/F2 合格 object——不预设 T 自伴——框架可设

### S2（强迫对称性）——可实现
D 是"轨道量"（D(ρ) = D(1−ρ̄)——轨道不变）——但——"零集 = 在线轨道"是桥的假设性质（非 RH——桥存在 ⟹ RH——假设）

### S3（谱参数）——三路径全堵
- 路径 1："λ 成为谱参数"需要 T（HP——**循环——S3 是 HP 的另一种表述**）
- 路径 2："零集离散"（在线零点——已知）——**不强迫算子（任何离散集无算子）**
- 路径 3："标度协变"（D(aρ) = a^k D(ρ)）——**零集标度不变（锥形）vs ζ 零点不标度不变——矛盾（除非 D 零集 ≠ ζ 零点——循环）**

### S4（最关键——Bridge ⟹ Spectrality）——一般不成立
- **反例：任何零集离散的解析函数（解析/对称）——不强迫存在自伴算子**
- "一般 quotient defect"（解析/对称/零集离散）——**不强迫谱**
- "特殊协变"（Mellin）——与零集矛盾（循环——S3 路径 3）

## ⭐ P22 判定（初步）
