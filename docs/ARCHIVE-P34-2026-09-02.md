## 二、关键结果（可证明/数值证据分层）

### 2.1 可证明的（PNT 级）

**a_k(X) 端点主导（C1 封口——唐先生公式数值验证）**：
```
a_k(X) = (1/π(X))Σ_{p≤X}cos(k log p)
       = (cos(k log X) + k sin(k log X))/(1+k²) + o(1)
```
- 固定 k≠0：**无普通 X→∞ 极限**（端点振荡——振幅 ~(1+k²)^(−1/2)）
- |a_k(X)| = O(1/k) 但不趋零——"amplitude ≍ k⁻¹，固定 k 无极限"
- **推论：w=1 naive Cesàro prime-average construction 无 canonical cutoff limit**（对含非零低阶 Mellin mode 的测试类）
- 逻辑边界守住：不推出"所有 renormalized prime operator 不存在"

**feature norm 发散（D2 确认）**：
```
M_k(X) = ||φ_k^(X)||²_ℓ2 = Σ_{p≤X}w(p)² = Σ 1/p ~ log log X + B₁ → ∞
```
- w=e^(−x/2) 下 ||φ_k||² ≍ ½log log X → ∞（极慢发散）
- **"fixed-mode trivialization ⇏ operator trivialization"——核心技术事实**（非警告）
- D2 排除"快速 feature compensation"攻击——但未建立无限维 ℓ² 极限

### 2.2 数值证据（强）

**operator-level cancellation（D1**）**：
```
ρ_K(X) = T_K(X)/U_K(X) ≈ 0.05-0.09（稳定——不随 K 变——不 →0）
```
- 实际算子尾是粗界的 5-9%——cancellation 真实存在但不完全
- "absolute-summability route to R1 is excluded"（B_k* 不衰减）——但条件收敛/正交性仍可能

**Gram 几何（D2″(I)）**：
```
max|R_X(k,ℓ)| ≈ 0.16-0.53（K=5→20——中等相关）
```
- 非近似正交（高 k 不能当独立方向）——非完全低秩/高度相关（<0.7）
- **tail cancellation = coefficient oscillation + nontrivial Gram geometry**（混合机制）
- K↑ ⟹ max|R|↑（高 k 模态更相关——不能套 Parseval）

**三极限分离（D2″(III)）**：
```
L_A(K) = limsup_{X→∞}T_K(X)：K=10..80 → 0.0140 → 0.0133 → 0.0073 → 0.0028（下降）
```
- **"inf_{K≥K₀}limsup_X T_K > 0"不成立——R3 封口（limsup_K limsup_X T_K > 0）无证据**
- "lim_K limsup_X T_K = 0"（D3 方向）成为较有希望候选——但未严格证明
- K(X) 路径（log log X / √log X / log X / X^0.3）全下降——无平台——"X-dependent tail crossover"未观察到
- ⚠️ 截断偏差：T_80 尾部项（k>80..150）比 T_10 少——L_A(K) 比较偏小

**D3.1 低模态 diagnostic（4-column）**：
```
X=10⁶, K=10：||a^ren||₂=0.0368  λ_max(G_K)=3.640  ||A||=0.0316  Q=0.451
X=10⁶, K=40：||a^ren||₂=0.0405  λ_max(G_K)=10.743  ||A||=0.0318  Q=0.240
```
- **情形 A 近似成立**：系数趋零（||a^ren||₂ 减半）+ λ_max≈O(1)（O(log log X) 慢升）
- **"D3.1 未趋零 = 有限 X 残余"**（非 Gram 放大——非真障碍——R1 继续候选）
- Q ≤ 1 验证 ✓（理论上界成立）

**D3.2 高模态拟合**：
```
T_K ~ 0.236·K^(−0.273)——α≈0.27 > 0
```
- **power-law candidate, not yet an estimate**（有限 X 的 log-log slope——uniformity gap 未闭合）

## 六、元层面结论

**"检测 ≠ 排除"的跨路线确认**：
- β 墙形态：表示层面（P_γ 闭式绕开）→ 投影层面（Σq(γ) 不可算）→ 算子层面（feature 发散 + uniform tail）
- 所有排除机制（正性/变分/谱/散射/THH/算术几何/算子论）都只给"离轴代价"不给"离轴排除"
- P34 的具体贡献：**"canonicalization obstruction precedes the spectral-gap question"强候选**——素数侧在进入无限维谱隙问题之前就可能无法获得 cutoff-independent canonical operator
- 候选负面机制（若 joint limit 不存活）：
  "Endpoint renormalization removes the noncanonical low-mode oscillation, but the remaining high-mode arithmetic content fails uniform operator control. Hence canonicalization breaks before any spectral-gap mechanism can be invoked."

**P34 不是 R1 封口**——是"负空间地图"的一块：naive 素数侧构造 → endpoint 振荡（可证明）→ renormalization → 有限秩/平凡化倾向（R1 候选）+ uniform tail 未决（D3.2）。
