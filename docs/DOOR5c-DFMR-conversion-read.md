## §1 【全文】**转换的精确形式**（这就是门⑤的"转换定理"）
```
【DFMR 续篇 Theorem 2.1】λ ∈ Π_{σ₀} ⟹ **L 在 r − σ₀ + D♯_r(λ) 上无零点**，其中
   **D♯_r(λ) := { μ ∈ ℂ : |(μ−λ)/(μ+λ−2σ₀)| < √( 1 − 2(Re λ − σ₀)·d♯_r(λ)² ) }** ✓✓
   ⟹ **"距离量的界 ⟹ 显式的无零点圆盘"** ✓✓（转换 = 定量的、显式的 ✓）
【DFMR 续篇 Theorem 2.2】在 φ̂ 于 Π_r 无零点、limsup log|φ̂(x+r−σ₀)|/x = 0、a₁ ≠ 0 之下，**四者等价**：
   (1) L 在 Π_r 上无零点  (2) ∃λ: d♯_r(λ) = 0  (3) ∀λ: d♯_r(λ) = 0
   (4) **K♯_r = L²_*((0,1), dt/t^{1−2σ₀})** ✓✓（完整的 Beurling–Nyman 型判据 ✓）
【距离泛函·显式】（DFMR I §7）
   **d²_r = min_{c_j,α_j} ∫₀¹ | t^{1−r} − t^r Σ_j c_j Σ_{n<α_j/t} χ(n) |² dt/t** ✓✓
   Prop 7.5：**d²_r < 1/(2−2r)**（严格 ✓，且平凡上界即 1/(2−2r) ✓）
【机制·Mellin 分解】(4.15)：**f̂_{A,r}(s) = −L(s+r−σ₀)φ̂(s+r−σ₀)g_A(s+r−σ₀)** ✓
   ⟹ 逼近函数的 Mellin 变换**因子化穿过 L** ✓（这就是"距离如何感知零点"的机制 ✓）
【应用】原文摘要：DFMR 得到 **Siegel 零点问题的 Beurling–Nyman 型判据** ✓（并改进 Nikolski、de Roton ✓）
```
