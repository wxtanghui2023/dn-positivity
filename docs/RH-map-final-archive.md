## 二、核心障碍的精确形态（8 个月的最终认识——）

1. **β 墙**：集体量对有限离轴 O(1/N) 不可检测——虚部数据不含 β——
   有限离轴与所有已知定理相容（数值不可见——）
2. **检测 ≠ 排除**（Rigidity Gap——）：能"检测"β 的（显式公式——）自适应；
   能"约束"的（集体量——）β 盲——无工具同时检测 + 约束
3. **算术断裂**：算术窗口（Euler 积 σ>1——η 级数 σ>0——）到不了 σ≤½——
   零点在延拓区——唯一桥 = 显式公式（含零点——循环——）
4. **ζ 各层穷尽**：逐项/加性/乘性/统计/素数/Archimedean/层间恒等式——
   没有一层含"位置 ½ 的强制"——½ 在解析延拓 + FE 里——
   不在任何可算术化的结构层里
5. **函数域 vs 特征零**：函数域的 |α|=q^{w/2} 来自 Frobenius 的模（几何——）
   特征零缺 Frobenius 类比——RH 需要目前不存在的特征零 purity 机制

## 三、方法论（保留成果——可复用于其他问题——）

### 审计框架五步（候选生成 → 退化测试——）
1. **候选生成**：明确对象 + 声称的机制（不预设 ½/零点/对偶——）
2. **独立性测试**：定义不含 ζ/Mellin/零点/显式公式——B ∉ ⟨A⟩
3. **信息通道测试**：对象如何携带 β（或目标量）——不经显式公式读出？
4. **刚性来源测试**：约束/正性/刚性从哪来——不依赖零点位置？
5. **退化测试**：是否还原为 Euler/Mellin/character/谱/指数和/显式公式——
   退化即封存——不换名续命

### 纪律（唐先生——）
- "局部无条件 ≠ 整体可行"——先验证整体路径再攻细节
- 数值 ≠ 定理——有限高度 O(1) 外观 ≠ O(1)（不能区分 O(1)/log——）
- "无条件"声明必须逐项验证——"构造不出" ≠ "不存在"——分开表述
- 不把"文献负面"当"不存在"——不把"有限验证"当"穷尽"
- INVALID-first：请专家主动找错误——区分"内部一致"与"外部验证"
