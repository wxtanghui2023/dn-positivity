## 第二部分 · 可行性分析 ①：**显式化 Guth–Maynard**

### 目标形状（明确 ✓）

```
`N(σ,T) ≤ C · T^{15(1−σ)/(3+5σ)} · (log T)^K` ✓ —— C、K、适用范围**均显式** ✓

```

### 逐步难度分级（评估核心 ✓）

```
【⭐ 易——可借用现成显式版 ✓】
   ① Gallagher 离散均值定理（Thm 7.1 ✓）⟹ 已有显式版 ✓（[IK04] Thm 9.4 型 ✓）
   ② Littlewood 引理 + 截断显式公式 ✓ ⟹ 显式文献已做 ✓（Kadiri–Lumley–Ng ✓）
   ③ Σ d(n)² ≪ x(log x)³ ✓ ⟹ 初等，可显式 ✓
【⚠️ 中——可行但繁琐 ✓】
   ④ Type I/II 划分与计数（Montgomery 框架 ✓）
   ⑤ TT\* 的谱范数估计 ✓ ⟹ **有限维线性代数** ✓ 原则显式，但常数**随分解层数与维数累积** ⚠️（可能很大）
【✗ 难——最高风险项 ⚠️】
   ⑥ **几何 / 多项式划分与"蜂巢"型分解** ✓（承自 Guth 的多项式方法 ✓）

   ⑧ T^{o(1)} → (log T)^K ✓ ⟹ 需查明 o(1) 的**每一处来源** ✓ 并给显式替代 ✓

## 第三部分 · 可行性分析 ②：**gap→RH 支线可否重开**

### 判定 ✗ **不建议现在重开**（四理由，均非"感觉" ✓）

```
① **方向** ✓：前沿工具**全部**是"零点 ⟹ 素数" ✓（零自由区 + 零密度 ⟹ 短区间 PNT ✓）
   ⟹ **反向机器不存在** ✗ ⟹ E47 封口获**结构性确认** ✓
② ⭐ **价位差（定量）** ✓：平均版 **2/15 ≈ 0.133** ✓ vs 逐点版 **17/30 ≈ 0.567** ✓（差 **4 倍以上** ✓）
   ⟹ 该技术力量**结构性集中在平均层面** ✗；而检测 RH 反例需要**逐点** ✓
③ **不可见性** ✓（E47 ✓）：有限 M ⟹ 离线零对 √x 尺度贡献 = **o(√x)** ✓
   （数值 ✓：δ = 0.1 时比值 **4.2e−3 → 6.3e−20** ✓）
④ **松弛量** ✓（E49 ✓）：若 Oppermann 成立 ⟹ 窗口和**单边下界** ✓
   `ψ(m²+m) − ψ(m²−m) ≥ 2log(m²−m)` ✓ ⟺ **Δ ≥ −2m + O(log m)** ✓ ⟹ **松弛 = Θ(m) = Θ(x^{1/2})** ✓
   而离线零贡献 = **x^δ** ✓（δ < ½ ⟹ 远小于松弛 ✓）⟹ **任何"区间非空"型命题永远盖不住** ✗
```

### 重开条件（精确 ✓）

```
【唯一形态 ✓】需**比主项更精**（误差项级 ✓）的短区间下界 ✓：
   `ψ(x+x^{1/2}) − ψ(x) > x^{1/2} − o(x^{1/2})` ✓ —— 把松弛从 Θ(x^{1/2}) 压到 o(x^{1/2}) ✓
   ⟹ 强度 **≥ RH** ✗（RH 自身只给 Δ = O(x^{1/2}log²x) ✓ **大于**主项 ✗）⟹ **循环** ✓
【或】**离线零密度的下界增长** ✗（"一个离线零是否迫使离线谱稠密增长" ✓ —— **公开难题** ✓；
   现有工具全为**上界型** ✓：已验证高度 ✓、Selberg o(N) ✓）
【或】**零集加性能量的无条件控制** ✗（= 高阶对相关 ✓ —— 与教训 4 的开口同位 ✓，同堵墙 ✓）
```

### 保留的开口（✓ 作者自述 ✓）

```
综述 §7.3.2 ✓：GM 法对**大值集加性能量**敏感 ✓ ⟹ 若将来重开，应由此入手 ✓
