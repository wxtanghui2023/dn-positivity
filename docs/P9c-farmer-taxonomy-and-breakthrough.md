## §1 【原文】**Farmer 的核心论证**（为什么 Jensen 路线无用）
```
【背景结果】Kim 定理：若 f 级 <2、实轴取实值、零点在带 |Im z|<A 内，则对任意固定 R>0，
   当 n 足够大时 **f^{(n)} 在 |z|<R 内只有实零点** ✓（"微商足够多次 ⟹ 局部零点全实" ✓）
   推论：**对每个 d，n 足够大时 J^{d,n}_{f,cl} 只有实零点** ✓
【Berry 的"余弦万有吸引子"】多次微商 ⟹ 收敛到 cos ✓；**Ki 定理（对 Ξ 已证）**：
   ∃ 正递减序列 A_n, C_n：**lim_{n→∞}(−1)^n A_n Ξ^{(2n)}(C_n z) = cos z**（紧集一致 ✓）✓
【⭐⭐⭐ 决定性论据】该吸引子结果**对以下对象同样成立**：
   · **扩展 Selberg 类**中的函数 —— **有函数方程但【不一定】有 Euler 积** ⟹ 含**大量不满足 RH 类比**的例子 ✓
   · **随机函数** —— 按构造满足 RH 类比，但零点服从 **Poisson 统计** ✓✓
   ⟹ **"Hermite/余弦的出现"不含任何 RH 信息** ✗✓✓（**与我们在 TP/PF 线发现的"实例化即坍缩"同型** ✓）
【结论】"微商【丢失】零点位置的信息" ⟹ "**在 RH 上，微商揭示极少**" ✓
【量化旁证】Conrey：Ξ^{(n)} 有 **(100 − O(1/n²))%** 的零点在实轴上 ✓
```
