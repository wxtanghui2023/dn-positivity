# 逐条论证

## N1 ⟶ A₁-fail [证明]
```
单尺度对称 H=X/H：约束 H·(X/H)=X 在每尺度独立成立，且直接给出 α=1/2
A₁ 要求：∀有界窗口 W，∃m₁,m₂: ρ_W(m₁)=ρ_W(m₂) 而 α(m₁)≠α(m₂)
但 N1 的每尺度状态已唯一确定 α=1/2 ⟹ 违反 A₁ ⟹ A₁-fail
```
**精确性**：H·(X/H)=X 是**恒等式**，每尺度独立钉住 α=1/2，不依赖任何跨尺度关系。此为**精确的逐尺度约束**，非渐近。

## N5 ⟶ A₁-fail [证明]
```
\|τ(χ)\|²=q：有限正交性在每个有限 q 上 exact 给出 \|τ\|=√q
A₁ 检查：在单尺度 q 上，该 constraint 唯一确定 α=1/2 ⟹ 违反 A₁ ⟹ A₁-fail
```
**精确性**：有限正交性是**定理级精确**（Parseval 型），per-scale exact。

## N7 ⟶ G₆-fail + C 不可提供 [证明]
```
G₆ 明确禁止：α 不是统计平均、数值拟合或已知谱量的重新编码
N7 的指数来自观测/统计 ⟹ 直接违反 G₆ ⟹ G₆-fail
同时：统计拟合不能提供 rigidity theorem ⟹ C 不可提供
```
**精确性**：G₆ 是 ISRG 的明定条件，N7 与其**字面冲突** ⟹ 证明级。

## N2 ⟶ C 不可提供 [结构性归约]
```
标签/类数据（character/Galois/余数类）的对称性：答案（若出现）预编码于标签结构中
C 要求：α=1/2 须从 primitive 公理导出，且不可被目标参数替换
N2 机制中，"1/2"若出现，来自标签结构的内禀性质（如 character 的阶），非 primitive 导出
⟹ 该类机制没有提供 C-rigidity theorem 的独立来源
```
**严格边界**：这是结构性归约，非"已证明 N2 不能有 C"。

## N3 ⟶ A₁-fail [结构性归约]
```
FE 对称点 s=1/2：每个 L-函数自身满足 FE，对称点 per-scale
A₁ 检查：FE 是单尺度性质（对每个 s，FE 给出 s↔1-s），不引入跨尺度耦合
⟹ 对称点 s=1/2 由单尺度 FE 结构决定，违反 A₁ ⟹ A₁-fail
```
**严格边界**：结构性归约；"FE 是单尺度性质"为结构判断，非定理。

## N4 ⟶ A-fail 或 C 不可提供 [结构性归约]
```
情形①：指数来自结构常数（如群阶、维度）⟹ 已存在于单尺度代数数据 ⟹ A₁-fail
情形②：指数来自迭代增长率 ⟹ 须证明非预装参数，但 N4 类机制本身不供应 C-rigidity 来源
⟹ 该类机制没有提供 C-rigidity theorem 的独立来源
```
**严格边界**：结构性归约；两种情形是穷尽性判断，非定理。

## N6 ⟶ C 不可提供 [结构性归约]
```
规范化/商空间选择是约定，非 primitive 导出
C 要求"1/2 不可被写入生成规则" ⟹ 规范化本身就是"写入"
⟹ 该类机制没有提供 C-rigidity theorem 的独立来源
```
**严格边界**：结构性归约。

# 总体命题与残余

## 总命题
$$\boxed{\forall i\in\{1,\ldots,7\},\quad N_i \overset{\mathcal R_i}{\longrightarrow} \neg(A+C)\ \text{或}\ \text{FROZEN GAP}}$$
**当前状态**：
- **[证明]** 级：N1（A₁-fail）、N5（A₁-fail）、N7（G₆-fail + C 不可提供）
- **[结构性归约]** 级：N2/N3/N4/N6
- **[FROZEN GAP]**：**无**（N1–N7 全部可归入某类）

## 第二个问题（M-NOGO 边界）
$$\boxed{\exists\ \mathfrak M\notin N1\cup\cdots\cup N7\ \text{s.t.}\ A(\mathfrak M)\land C(\mathfrak M)?}$$
**当前状态**：**仍未解决**（此即 ISRG 的实质数学问题：是否存在满足 A+C 的跨尺度 rigidity 定理）

## 关键区分（本轮反复强调）
```
"没有发现满足 A+C 的 N_i"  ⟹  可登记为 [结构性归约]
"证明 N_i 不可能满足 A+C"  ⟹  须为 [证明]（目前 N1/N5/N7 有此级别）
```
**C 的特殊逻辑**：
- C 不是"我们预先证明它没有 rigidity"
- C 是"该类机制没有提供 rigidity theorem 的独立来源"
- 这是**逻辑上不同的断言**（前者是 negative theorem，后者是 absent-source judgment）
