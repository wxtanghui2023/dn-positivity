## §2 ⭐⭐⭐⭐ **但真正需要的不是零密度 —— 而是三件更基本的事**
```
【结构】λ_n = Σ_在线[1 − cos(nθ_γ)]  +  Σ_离轴 (1 − w_ρ^n)
        · 在线部分：**逐项 ≥ 0** ✓（Re[1−e^{inθ}] = 1−cos ≥ 0 ✓；±γ 配对消虚部 ✓）
        · 离轴部分：仅 β < 1/2 者造负 ✓，且 **Re(1−w^n) ≥ 1 − |w|^n** ✓ 其中
          **|w|^n = e^{n|δ|/|ρ|²}** ⟹ 负贡献 ≥ **−(e^{n|δ|/γ²} − 1)** ✓
【关键】一切危险零点（γ > T ⟹ 由"验证到 T"）满足 **|δ| ≤ 1/2、γ > T** ⟹
        **e^{n|δ|/γ²} − 1 ≤ n|δ|/γ² ≤ n/(2γ²)** ✓✓（**对【所有】危险零点一致** ✓✓）
⟹ **离轴负贡献之和 ≥ −n·(1/2)Σ_{γ>T} 1/γ²** ✓✓ —— 而 **Σ_ρ 1/γ² 收敛** ✓✓（= 常数 C ≈ 0.046 家族 ✓）
⟹ **不需要零密度定理、不需要分散界、不需要均匀性** ✓✓✓（**全部撤回** ✓）
```
$$\boxed{\lambda_n\ \ge\ \underbrace{\sum_{\gamma\le T}\bigl[1-\cos(n\theta_\gamma)\bigr]}_{=:A_T(n)\ \ge 0,\ \textbf{可计算}}\ -\ \underbrace{n\cdot B_T}_{B_T:=\tfrac12\sum_{\gamma>T}\gamma^{-2},\ \textbf{有界}}}$$

## §3 ⭐⭐⭐ **为什么这给出 T²**（形状自然浮现 ✓）
```
· A_T(n)：对 n 的平均 ≈ **每个零点贡献 1** ⟹ **≈ N(T) ≈ (T/2π)log T** ✓（巨大 ✓）
· B_T = ½Σ_{γ>T}γ^{-2} ≈ ½∫_T^∞ (dN(t))/t² ≈ **O(log T / T)** ✓（小 ✓）
⟹ A_T(n) 与 n·B_T 的平衡：**n ≲ N(T)/B_T ≈ T²** ✓✓✓
```
$$\boxed{n\ \lesssim\ \frac{N(T)}{B_T}\ \approx\ T^2\qquad\text{（与本项目实测 }n^*\approx 6.6\gamma^2/|\delta|\text{ 及 Jensen }d\le T^2\ \text{一致 ✓✓）}}$$
```
⟹ **T² 不是被输入的，而是【从"逐项非负 + Σ1/γ² 收敛"里长出来的】** ✓✓✓
   —— 这也**给 taxonomy 一个统一解释**：T² 来自 **N(T)/B_T** 的比值结构 ✓
```
