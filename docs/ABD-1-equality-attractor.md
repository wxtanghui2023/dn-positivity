## 0. 规格登记（唐先生）

**先杀（不得作为成果）**：$ab$ 的离散梯度上升 $(a,b)\mapsto(a-1,b+1)$（因 $(a-1)(b+1)-ab=a-b-1>0$）
$$\boxed{\text{这只是把 AM-GM 的证明改写成离散梯度流} \Longrightarrow C_{\rm NI}\ \text{直接危险}}$$

**ABD-1 四条硬规矩**：
```
A  驱动【不得】读取 ab、|a-b|、(a-b)^2、ab/c^2
B  驱动【可以】读取 a+b=c、整除 d|a,b,c、gcd(a,b)、及其整数 refinement
C  必须存在【不可逆】的跨尺度演化（继承 DA-3 教训，不能是简单群作用）
D  E = {(a,b,c): a=b} 必须成为吸引/终端集合，但【不得出现在规则定义中】
```
**第一硬实验**：不是算 $\alpha_*$（ABD-0 已算），而是算 $R_n=\dfrac{\min(a_n,b_n)}{\max(a_n,b_n)}$，
问 $R_n\to1$ 是否是**算术 refinement 的必然结果**；并做三组对照（primitive / composite / adversarial，含 $(1,c-1)$）
**吸引盆判据**：须有非平凡 $\mathcal B(\mathcal E)\supsetneq\mathcal E$，且不得"因规则本身就是平衡操作"而平凡

## 2. ⭐ 实测三失败模式（verdict 与数据对齐后）

### (a) INERT（惰性）—— R1_gcd / R2_par
```
reach = 0.0169（≈0）；mean final R = 0.399（与初态平均相同）
adversarial (1,c-1)：mean final R = 0.079 —— 轨道【完全不动】
原因：primitive pairs（gcd=1）无可用移动，而其密度 = 0.622（≈6/π² = 0.608）
⟹ **无吸引盆** B(E) ⊋ E
```

### (b) DECORRELATED（去相关）—— R3_*（整除导出的方向，5 个复杂度变体）
```
⚠️ 它【不是】梯度：|a-b| 在 13.1%–21.8% 的轨道中【增加】
但它【到不了】平衡：reach 0.0249–0.0689 = ceiling 的 5%–14%
⟹ 第三种失败模式：**整除导出的序与"趋向平衡"的方向不对齐**，轨道停在原地而非收敛
```

### (c) NON-INJECTIVE（非单射 = 对称化）—— R4_sym
```
reach = 0.5085 = ceiling，约 1 步到达；但**非单射，fiber = c-1**：
c 的全部 c-1 个分解塌缩到唯一的平衡态 (c/2,c/2)
⟹ **加法信息被丢弃** ⟹ 这是【插入/对称化】，不是动力学
```

$$\boxed{\text{唯一能到达 ceiling 且【保留数据】的规则是 R0\_grad —— 而它读取 }|a-b|\text{（被 A 禁止）}}$$
$$\boxed{\text{⟹ 在实现的 admissible class 内，无规则产生非平凡等号吸引子}}$$

## 3. ⚠️ 勘误（本轮第二次自我修正，记录在案）
初稿 verdict 文字写"若 $|a-b|$ 从不增加 ⟹ 伪装梯度"；**实算显示 R3 的 $|a-b|$ 在 13–22% 轨道中增加** ⟹
R3 **不是**伪装梯度，而是**去相关失败**。已在写入归档前修正为与数据一致。
**教训（与 RCI-1 同族）**：**verdict 文字必须在数字出来之后写**；先写结论再补数据会产生与数据不符的记录。

## 4. 裁决与新靶点
$$\boxed{\text{ABD-1 第一轮：容许类内【未找到】等号吸引子（三失败模式已实测）}}$$
**楼梯状态**：ABD-0（极值刻画）→ **ABD-1（吸引子）✗ 未达成** ⟹ **ABD-2（幂律 $1-R_X\sim X^{-\delta}$）未到达**
**⭐ 三条失败模式共同指出的精确缺口**：
```
(a) 惰性     ：规则在 primitive 核心上无动作  ⟹ 缺【动作】
(b) 去相关   ：整除导出的方向与平衡方向不对齐 ⟹ 缺【对齐】
(c) 非单射   ：能对齐的规则靠丢弃加法数据实现 ⟹ 不允许（插入）
⟹ 真正缺的不是"可达性"，而是【对齐来源】：一个既不读 |a-b|/序、
   又不丢弃加法数据，却与平衡方向对齐的方向场
```
$$\boxed{\textbf{ABD-1}'：寻找一个【不读序、不丢数据】的 arithmetic 方向场，使其与平衡方向对齐}$$
（若此物不存在 ⟹ 应在"对齐"这一层收口，而不是再换对象）
