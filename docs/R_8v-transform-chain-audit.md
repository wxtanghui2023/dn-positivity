## §3 未对齐处理（本轮第一位）

### 3.1 两个公式不能同为 F-支持映射（结构性论证）
```
已知事实：
 (i)  Montgomery 无条件：F(α)=1 for α ≤ 1
 (ii) RH ⟹ F(α)=1 for α ≤ 2
 (iii) RH ⟹ V(X,H) ~ H log(X/H) for 1 ≤ H ≤ X^{1−ε}
 (iv) Hooley（无条件，AP 版）：H ≥ X^{7/12+ε}（**但平均坐标是 (q,a)**）
```
**一致性检验**：若字典 $\lambda=1/(1-\eta)$ 就是 F 的支持映射，则
```
(iv) 的 η=7/12+ε  ⟹ λ = 1/(5/12−ε) ≈ 2.4 > 1
   ⟹ 应给出【无条件 F 支持 > 1】——与 (i) 矛盾
```
**但该检验【不闭合】**：因为 (iv) 的平均坐标是 (q,a)（AOC\*），它**未必**给出 F-信息
⟹ **结论**：§3 的未对齐**未能通过一致性检验被判定**，因为关键环节（AP 平均是否转译为 F 信息）
正是 A1/AOC\* 本身。**这是一个"循环依赖"**：判定字典需要 A1，而 A1 的判定又需要字典。

### 3.2 但由此得到一个**可判定**的替代判据（本轮产出）
$$\boxed{\text{要判定字典，须用【非 AP-平均】的无条件短区间二阶结果（即未平均的 }V(X,H)\text{）}}\\
\text{若存在这样的无条件结果覆盖某个 }\eta>0\text{，则经由字典应给 λ>1 ⟹ 若与 (i) 冲突则字典被否证}$$
```
⟹ 必核项（两个）：
   ① LPZ / Montgomery–Soundararajan 中 α↔H 的确切约定（H=X^η ↦ α=?）
   ② 【未平均】V(X,H) 的无条件 η-范围（非 Hooley 的 AP 版）
   —— 两者到位后 §3 可判定；否则 A4 无从判定
```
