## 1. ⭐ arcsin 公式（p 由 ρ₁ 决定）

**p = 1/2 − arcsin(ρ₁)/π**（δ 近似二元高斯——相邻相关 ρ₁）

```
ζ：ρ₁ = −0.351335——实际 p = 0.618156——arcsin 预测 0.614272（差 0.004）
GUE：ρ₁ = −0.296637——p = 0.603494——arcsin 预测 0.595865
→ p 的核心 = ρ₁（相邻间距偏差相关）——问题转化！
```

## 2. ⭐ ζ 是"超 GUE"排斥

```
ρ₁：ζ −0.351 vs GUE −0.297——ζ 强 18%
p：ζ 0.618 vs GUE 0.604
→ ζ 的相邻排斥比 GUE 强——更强配对——更刚性——【超 GUE】
```

**意义**：ζ 不是 GUE（在 ρ₁/p 上）——**ζ 的排斥更强——可能来自素数的算术结构**（额外排斥——不是 Vandermonde）
