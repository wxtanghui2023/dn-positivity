## 0. ⭐ 中心判别器（本协议的核心装置）
$$\boxed{\text{候选结果的主项是否携带【连续尺度自由度】}H/X\ \text{（即 }1-\eta\text{），}\\
\text{还是只携带【离散参数】（AP modulus }q\text{ / Fourier cutoff / 另一坐标）？}}$$
```
· R8 的 carrier = 主项中**连续的 η-依赖**： C(X,H)/(HX log X) → 1−η
· AP 型结果的 cancellation 沿【modulus 平均】发生（离散频率）⟹ 与 R8 的连续尺度【不同坐标】
⟹ 本判别器即"对象对齐检验"的具体化（回应 N28）
```

## 1. 三个必答问题（V1–V3）
| # | 问题 | 判定要点 |

| **V1** | Lavrik / Hooley 型无条件结果，是否**真的包含** $H=X^\eta,\eta>0$ 的目标 short-interval **prime-pair** 二阶主项？ | 对象必须逐项对齐（变量空间／权函数／非对角展开） |

## 2. 三种合法结论（事先声明）
```
R8.3-C′   V1+V2 成立 ⟹ **η>0 的 S2-c 已知**
```
