## §1 【定理级】**基空间上的全局 Frobenius 提升必然是平凡的**（决定性）
```
Λ-环定义：ψ^p 满足 ψ^p(x) ≡ x^p (mod p)（"Frobenius 提升"）
事实 A：End(ℤ) = {id}（ℤ 的唯一环自同态是恒等）✓
事实 B：费马小定理 ⟹ id(x) = x ≡ x^p (mod p) ⟹ **id 确实是 Frobenius 提升** ✓
⟹ 两者合起来：**ℤ 上的 Frobenius 提升【只能是 id】** ⟹ 其特征值 = 1 ⟹ **不含任何模长信息** ✓✓
⟹ 故"到绝对几何去拿 Spec ℤ 上的 Frobenius"这条路，**在基空间层面被排除** ✓（不是"未找到"，是"必为平凡"）
```

## §2 非平凡的 Frobenius 结构**只存在于局部**（与 AOB3 一致，现从 Λ-环侧确认）
```
· p-进：Witt 向量 W(κ)（= 非分歧部分）上 Frobenius 提升**存在且 canonical**（Teichmüller 代表元 ✓）
· 同调侧：crystalline 上同调上的 Frobenius ✓（canonical，但 **p-进局部**）
· 全局：O_K 上一般**不存在** σ 使 σ(x)≡x^p mod p ⟹ 局部结构**无法黏合** ✓
⟹ 黏合失败处 = 本项目的 **β-墙 / 局部≠全局** ✓（两条独立路线汇聚同一处 ✓）
```

## §3 ⭐⭐⭐ **本轮核心（对 AOB3 的精确化）**：全局 canonical **含模长的扩张**【已经存在】且【可证不足】
```
【核验】theta 对合：θ(1/t) = √t · θ(t)，比值精确等于 √t（8 位吻合 ✓）
        t: 0.05→√t=0.2236｜0.5→0.7071｜1→1.0000｜2→1.41421｜5→2.23607｜20→4.47214 ✓
⟹ char 0 **存在**一个 canonical【全局】扩张，其乘子**非平凡**（= √t）✓✓
⟹ 而这个乘子 √t 正是**函数方程 s↔1−s 的来源**（Λ(s) = Λ(1−s) 由它"制造"）✓✓
⟹ 故"1/2"并非来自缺失的元素，而是来自这个已存在的 canonical 扩张 ✓
【引用·经典】但函数方程**可证不足**：Epstein 型（二元二次型）zeta 满足函数方程却有离线零点 ✗
```

$$\boxed{\text{char 0【不缺】canonical 元素与模长（theta 扩张 √t 就是）；缺的是【正性】}}$$
$$\boxed{\Longrightarrow\ \text{AOB3 的表述需精确化：缺口不是"元素化/模长"，而是【正性】}}$$
