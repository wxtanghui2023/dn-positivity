## §1 状态空间（`K_{2,2}`-free 情形）

```
$$X\in\{0,1\}^{m\times n},\qquad \forall i\ne i':\ |\operatorname{supp}(X_i)\cap\operatorname{supp}(X_{i'})|\le1$$ ✓
【等价形式】"行两两交 `\le1`" ⟺ **线性超图** ✓；**列侧同对称** ✓
【约束数】`\binom{m}{2}`（`m=n=22` ⟹ **`231`** 条行对约束）✓
**【关键恒等式（本档推导，用于剪枝估计）】** $$\sum_{j=1}^{n}\binom{c_j}{2}=\sum_{i<i'}|\operatorname{supp}(X_i)\cap\operatorname{supp}(X_{i'})|\ \le\ \binom{m}{2}$$ 其中 `c_j`＝列度 ✓ ⟹ **给出一条纯计数上界**（`Reiman` 型）✓

```
