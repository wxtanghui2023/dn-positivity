## 1. Robin 准则

RH ⟺ σ(n) < e^γ n log log n（n ≥ 5041）

## 2. 结果

### 全局最危险 n：**10080 = 2⁵·3²·5·7**

| n | 素因子 | 比值 σ/(e^γ n loglog n) |
|---|---|---|
| **10080** | 2⁵·3²·5·7 | **0.985819**（全局最大）|
| 55440 | 2⁴·3²·5·7·11 | 0.983254 |
| 27720 | 2³·3²·5·7·11 | 0.978364 |

**10080 在 n ≤ 10⁹ 的高度合数扫描中保持全局最危险**（0.9858 稳定）——文献已知（Robin 的著名极值，验证到 10^18 无违反）。

### 结构
- 最危险 n 都是高度合数（小素数高次幂，指数递减）✓ Ramanujan 理论
- 比值上确界 = 0.9858（10080），随 n 增大 loglog n 使比值减小
