## P26-A2 结果
### ① 截断数值（P 扫描）
- 最小奇异值随 P 快速下降（P=4: 2.2e-5 → P=12: 1.7e-15）——**高精度确认（mpmath 40 位——1.1e-7 → 1.3e-12）**
- 零空间方向与 log p 夹角 ≈ 0（≠ log p——新模式）
- **但——系数爆炸（P=10: 1, −15, 296, −1757, 25207, ...——不收敛）**

### ② ⚠️ 关键解读——截断数值是"插值假象"
- **g_p(s) = 1/(p^s−1) − 1/(p^{1−s}−1) = Σ_k (1+p^k)p^{−ks}（σ>1——Dirichlet 级数——|p^{1−s}|<1 收敛）**
- **g_p 线性无关（全 s）**——Σ b_p g_p(s) = 0（σ>1——Dirichlet 级数唯一性——n=p^k 处系数 b_p(1+p^k)——唯一——b_p = 0）
- **真实反射方向（全 s）只有 b = 0**（有限支撑——严格）
- **截断的最小奇异值→0 是"有限采样点的近似线性相关"（插值——大系数补偿）——不是全 s 的真实方向**

### ③ 有限支撑反射刚性——严格证明（新）
**g_p 线性无关（Dirichlet 唯一性）⟹ 有限支撑的反射方程唯一解 b = 0**
- 比 det 数值强（严格——不依赖数值）
- 与唐先生的精确奇点论证一致（s_k = 2πik/log p₀——无其他素数抵消）

### ④ 无限支撑——未证明
- M_b(1−s)（σ>1）是**解析延拓值**（不是 Σ b_p/(p^{1−s}−1)——无限项 σ<0 不收敛）
- g_p 论证只对有限支撑（无限支撑的延拓值复杂）
- **截断数值暗示"无合法无限方向"（系数爆炸——不收敛）——但——未严格证明**
- **反射 ⟹ FE（自动）**：γζM_b(s) = γ(1−s)ζ(1−s)M_b(1−s)——反射 + ξ 对称——恒等 ✓——所以——反射刚性 = P26-A 核心（若有非零反射方向——T_ζA={0} 假）

## ⭐ P26-A2 判定（诚实）
- **有限支撑：反射刚性严格证明（g_p 线性无关——Dirichlet 唯一性——新证明）**
- **无限支撑：未证明**（延拓值复杂——截断暗示无合法方向——但需严格）
