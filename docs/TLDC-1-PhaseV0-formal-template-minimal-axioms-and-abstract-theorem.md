## §2 任务 B：**abstract TLDC theorem**（证明，二层结构显式 ✓✓）

```
定理（TLDC-v1）。设 A1–A4 成立。则 **H = G**（即 F 在 G 上全域乘法）✓✓

证明。
 (i) **外层：对整数 q 的强归纳**（目标：ν(q) < T/2 ⟹ q ∈ H）✓
     基例：q ∈ S（实例：q = 1,2,3）✓
     归纳步：设 q ∉ H 且 ν(q) < T/2；由归纳假设，**∀ 1 ≤ j < q：j ∈ H** ✓
       定义失败谓词 **P(x) := [ F(qx) ≠ F(q)F(x) ]** ✓
       ① **P 非空**（q ∉ H 的定义直接给出）✓
       ② **P(−x) ↔ P(x)**：由 −1 ∈ H（A3，实例中 −1 在 S）⟹ F(−y) = −F(y) ✓；
          故 F(q(−x)) = −F(qx)、F(q)F(−x) = −F(q)F(x) ⟹ 等价保持 ✓✓
       ③ **P(jx) ↔ P(x)**（j < q）：由 j ∈ H 得 F(j·z) = F(j)F(z) ∀z ✓；
          取 z = qx 并用交换性 qjx = jqx ⟹ F(qjx) = F(j)F(qx)、F(q)F(jx) = F(q)F(j)F(x) ⟹ 等价保持 ✓✓
       ⟹ P 可容许 ⟹ 由 **A4** 得见证 n：**ν(n)·q < T** 且 n ∈ P ✓
       ⟹ 但由 **A2**（取 a = q、b = n，ab = qn < T ✓）：F(qn) = F(q)F(n) ⟹ **n ∉ P** ✗ **矛盾** ✓✓
       ⟹ q ∈ H ✓
 (ii) **收尾**：任意 x ∈ G，由 **A1** 写 x = ±n（ν(n) < T/2）⟹ n ∈ H（由 (i)）⟹
      F(xy) = F(x)F(y) ∀y（正则符号由 H ∋ −1 处理 ✓）⟹ **H = G** ∎

【⭐ 抽象化揭示的两点简化（本档新增）】
 ① **素数／合数二分并非必需**：实例中该二分只因**实例版压缩引理要求 q 为素数**（`short_representative_of_invariance`
    的假设 `hq : q.Prime`、`hqge : 5 ≤ q` ✓）；抽象版把该要求**吸收进 A4**，证明本身**无需**二分 ✓✓
 ② **n 的奇性与半化亦非公理**：它们只是**实例中建立 A4 的手段**（= A5 的一部分）✓✓
```
