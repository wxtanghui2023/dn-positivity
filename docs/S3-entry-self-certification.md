## S3-A｜原则本体（minimal primitive）

**语言（primitive）**：
```
atoms  : primes  (P)                       —— 原子由算术本身给出，非人造
operations : { +, x }                      —— 二元，构成半环语法
state  : a DERIVATION (finite ordered tree; internal nodes labelled +/x, leaves = primes)
         —— 状态是推导本身，【模 AC】（交换/结合；见 S3-C 的 G4 细化）
val    : derivation -> integer             —— 值（由状态导出，非状态本身）
```
**方向（direction）**：
$$\boxed{\text{方向} = \text{下一个构造步骤的【模式】}:\ \text{additive}\ \text{vs}\ \text{multiplicative}}$$
（即：从"当前对象"到"下一个被构造出的对象"这一步**属于哪一种构造**）

**目标量检查（逐项）**：表述中**无** $1/2$、**无** balance、**无** $|a-b|$、**无** $ab$、**无** $ab/c^2$ ✓

**两个 fork（模式由什么决定）**：
```
fork A：模式的判定来自【当前对象的算术类型】——prime -> additive；composite -> multiplicative
fork B：模式的判定来自【推导的交错历史】——与上一步的模式交替，并取"最小未用素数"作为新操作数
```

## S3-B｜G1 / G3（方向来自构造语法，而非从结果倒推）

**G1（原生产生）**：
```
语法定向（operands -> operation）是【定义性的】：构造子是自变量的函数，反方向无定义
⟹ 定向不咨询任何目标函数、不后悔求导、不引用输出值  ⟹ G1 成立
```
**⚠️ 但同时必须承认**：**语法定向本身近乎平凡**（任何语法都有它）。因此 S3 的**真正内容全在 continuation law**：
"下一个步骤的模式如何被决定"。**若 continuation law 是"枚举全部 continuation"，则一切回到组合计数（Catalan 型）⟹ 算术含量可疑**（见 §5 R1）。

**G3（目标盲，**方向性审计**）**：
```
驱动只读：(derivation 的形状, 叶素数, 操作标签, 当前值的算术类型)
不读：|a-b|、ab、(a-b)^2、ab/c^2、任何 balance observable
方向性审计（Gate V 教训）：须给出【方向不等于 |a-b|-梯度方向】的见证 ⟹ 见 S3-D 见证①的对照
```

**⭐ S3-B′（本轮新提出的子要求）：历史必须"**有作用**"（operative history）**
$$\boxed{\text{若两个 derivation 值相同、且在【未来】上不可区分}\ \Longrightarrow\ \text{历史是装饰性的}\ \Longrightarrow\ \text{不是 S3 的合法内容}}$$
**判定**：
```
fork A：模式只依赖【当前值】⟹ 两个值相同的 derivation 未来完全相同 ⟹ 历史装饰 ⟹ **S3-B′ 不通过**
fork B：模式依赖【交错历史】⟹ 值相同而历史不同的两个推导在未来上不同 ⟹ **S3-B′ 通过** ✓
```
$$\boxed{\text{故 S3-B 的结论：S3 必须在 fork B 上建立；fork A 已被 S3-B′ 淘汰}}$$

## S3-C｜G2 / G4（两个反例门）

### (i) G2：必须出现"同 $g$、不同方向"
（$g(t):=\gcd(\text{叶素数})$；定义见 S3-D 的 V-b 表）
| derivation | value | $g$ | 方向（fork A） |
|---|---|---|---|
| $3+5$ | 8 | $\gcd(3,5)=1$ | **mul**（8 合数） |
| $2+3$ | 5 | $\gcd(2,3)=1$ | **add**（5 素数） |
$$\boxed{\text{同一 }g=1\ \text{、方向不同} \Longrightarrow \text{反例存在} \Longrightarrow \text{方向【不是】}g\text{ 的函数（非 S2 退化）}}$$

### (ii) G4：必须出现"值相同、推导不同"
| value | 加法见证 | 乘法见证 | 值相同？ |
|---|---|---|---|
| 8 | $3+5$ | $2^3$ | ✓ |
| 12 | $5+7$ | $2^2\cdot3$ | ✓ |
| 30 | $7+23$ | $2\cdot3\cdot5$ | ✓ |
| 100 | $3+97$ | $2^2\cdot5^2$ | ✓ |
| 210 | $11+199$ | $2\cdot3\cdot5\cdot7$ | ✓ |
| 2310 | $13+2297$ | $2\cdot3\cdot5\cdot7\cdot11$ | ✓ |
$$\boxed{\text{值【不决定】推导} \Longrightarrow \text{若只保存值即为 G4 信息坍缩} \Longrightarrow \text{状态必须是推导本身}}$$

### ⚠️ (iii) G4 的一个必要细化（**需唐先生裁定**）
```
"不许任何商"会反而迫使状态携带【非算术】信息（结合/交换的顺序），那是【信息膨胀】而非守恒。
故建议：AC-取商【允许】（交换/结合是算术恒等式，取商不丢算术信息）；
        禁止的是"只留值"或任何把【算术上不同】的数据合并的商。
```

### (iv) 为何"构造"真的携带算术信息（不变量：加法 vs 乘法的分支不对称）
| $n$ | 加法分解数 $=n-1$ | 乘法分解数 $=d(n)$ | 比值 |
|---|---|---|---|
| $10$ | 9 | 4 | 2.2 |
| $100$ | 99 | 9 | 11.0 |
| $10^3$ | 999 | 16 | 62.4 |
| $10^4$ | 9999 | 25 | 400.0 |
| $10^5$ | 99999 | 36 | 2777.8 |
$$\boxed{\text{加法分支} \sim \text{线性};\ \text{乘法分支} \sim \text{次多项式}\ \Longrightarrow\ \text{值无法告知它是被哪条路线构造的}}$$
⟹ 生成历史携带**算术上可用的**信息 ✓（满足唐先生"construction itself carries irreversible mathematical information"）

## S3-D｜Gate V / V-b

### Gate V（空转检查）：判据必须**能**被违反——两个失败见证
```
见证① 规则"选使顶层 |a-b| 减小的 continuation"  ⟹ 【G3 失败】（读了 |a-b|）
见证② 规则"按 g 的取值选模式"                  ⟹ 【G2 失败】（方向是 g 的函数）
⟹ G2/G3 均可被具体状态违反 ⟹ 判据非空转 ✓
```

### V-b（定义—数值对账）
| 量 | 类别 | 本轮取值 |
|---|---|---|
| 叶-gcd $g(t)$ | **定义** | 叶素数的 gcd |
| value | **定义（导出）** | 叶的和/积 |
| 方向（模式） | **定义**（fork A 或 B） | add / mul |
| 加法分解数 | **计算（闭式）** | $n-1$ |
| 乘法分解数 | **计算（逐 $n$）** | $d(n)$，见 §3(iv) |
| witness $12=5+7=2^2\cdot3$ | **代表元（非极值）** | 最小的同时具两路构造的值 |
| witness 的 $g=1$ | **代表元** | 为对齐 $g$ 而选 |
**⚠️ 本轮 V-b 当场抓到两个计算错误（如实记录）**：
```

错误②：modeA 的"素数判定"写成 len(factorint)>1 ⟹ 8=2^3 只有 1 个键，被误判为 prime
⟹ 修正后重跑（现表已正确）；**这本身是 V-b 有效性的实证**，与 ERR-ABD1p-1 同族教训一致
```
