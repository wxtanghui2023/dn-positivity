# r(n) = O(1) 理论推导 — 框架与分解

> 日期: 2026-08-22 10:40

## 1. 核心分解（精确，数值验证）

### 1.1 r(n) = ∫f_n dS + O(1)

$$r(n) = \lambda_n - \tfrac12 n\log n - cn = \int_0^\infty f_n(t)\,dS(t) + O(1)$$

- $\lambda_n = 4\sum_\gamma \sin^2(n\theta_\gamma)$，$\theta(t) = \arctan(1/2t)$，$c = \tfrac12(\gamma_E-1-\log 2\pi) = -1.130331$
- $f_n(t) = 4\sin^2(n\theta(t))$
- S(t) = Riemann-von Mangoldt 的振荡项：N(T) = (T/2π)(log(T/2π)−1) + 7/8 + S(T)

**验证**：r_smooth（纯积分余项）≈ 0.000（解析主项精确捕获平滑积分），r_S = Σf − ∫fN'dt = r_total（差 < 0.03）。

### 1.2 等价形式

$$r_S(n) = \sum_\gamma f_n(\gamma) - \int f_n(t)N'(t)dt = 8n\int_0^\infty \frac{\sin(2n\theta(t))\,S(t)}{4t^2+1}dt$$

## 2. O(1) 机制：零点序列的低差异性

### 2.1 为什么 O(1) 成立（数值证据）

1. **corr(f_n(γ), S(γ)) ≈ 0.0002**（前 1 万零点）——f 与 S 完全无相关
2. **max|S| = 1.80**（2M 零点）——S 本身小
3. **贡献集中在 t ≲ 10n**（n=1000 验证：1.44 of 1.44）——大 t 衰减（f ≈ n²/t²）
4. **S(γ₁) = 0.5503** ✓（匹配文献）

### 2.2 理论框架

r(n) = O(1) ⟺ **零点序列的采样误差 O(1)**：

$$\sum_\gamma f(\gamma_k) - \int f(t)\,dN_{\text{主}}(t) = O(1) \quad \text{对光滑 } f$$

这等价于零点序列的**低差异性**（Koksma-Hlawka 型）：
- 零点均匀分布（N 主项精确）→ 离散和 ≈ 积分
- 需要 S(T) 的平均控制（S(T) 小 + 振荡抵消）

### 2.3 严格证明的障碍

| 障碍 | 说明 |
|:---|:---|
| 随机游走误差 | 若 f 与零点涨落无相关，采样误差 ~ 随机游走 √N？实测 O(1) |
| 低差异需要 S 控制 | 零点均匀性 ⟺ 对 S(T) 的深刻估计 |
| RH 条件性 | 低差异性质 ≈ RH 级困难（循环）|

## 3. 与之前 ε_m 瓶颈的联系

**同一个数学对象**！之前 ε_m = ∫f̃dS 的 Σ|ε_m| = O(1) 证明遇到的瓶颈，与现在 r(n) = ∫f dS 的 O(1) 完全一致：
- 都需要 S 函数的振荡抵消
- Cauchy-Schwarz + Selberg 二阶矩只给 O(n)
- 数值上 O(1) 成立，严格证明 RH 级困难

**结论**：λ_n 的余项结构（无论 ε_m 还是 r(n)）的 O(1) 性质，本质上都是**零点计数振荡 S(T) 的加权积分 O(1)**——这是 RH 的核心内容之一。

## 4. 主项常数来源（完整验证）

### 4.1 ½nlogn 来源

∫_0^∞ 4sin²(1/2x)dx = π（换元 x = t/n，测度 logn 部分）→ ½nlogn

### 4.2 cn 来源

c = B/(2π)，B = ∫_0^∞ 4sin²(1/2x)·log(x/2π)dx = −7.101978
c = −7.101978/(2π) = **−1.130315** ≈ 理论 −1.130331 ✓

## 5. 数值分解要点（含 bug 教训）

- N'(t) = (1/2π)·log(t/2π)（**不是** (log+1)/2π！之前 +1 错误造成 0.5n 假增长）
- 积分下限应从 0（含 t∈[0,γ₁] 的贡献）
- 尾部修正：λ_true = λ_2M + n²·coef（尾部恒正，应加）
