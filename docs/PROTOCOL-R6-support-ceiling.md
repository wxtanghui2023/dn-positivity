## 0. §0 前置与定位

```
① 分类：命中 S 级？——否（本对象是【信息类】问题，非机制候选）
② 语义三问：形式可证？局部可算？null 可复现？——均否
③ 档位：Proof 档；但产出物是【判定 + 天花板性质】，不是候选模型
```
**核心命题**：
$$\Lambda^*=\sup\{\lambda:\ \exists C\in\mathscr C_{\rm L1}\ \text{可无条件建立 support/position 约束至 }\lambda\}$$
**已知**：无条件侧 $\lambda\le1$；RH 强度需 $\lambda\ge2$。
$$\boxed{\text{R6 不预设 }\Lambda^*=1\text{；要判定的是：}\lambda=1\ \text{是【结构常数】还是【技术常数】}}$$

**R6 是什么 / 不是什么**
```
是  ：对【所有】canonical + non-equivalent + independent 的 L1 位置约束机制做 λ 比较审计
不是：寻找"更强的 1-level density 定理"（**硬禁令**，见 §7）
```

## 1. ⭐ 唐先生的第一关 + 我加的**λ-字典**（本协议的前线风险）

**危险**：把不同轴的参数当成同一个 λ。必须**先建字典**，否则 R6 会死于 R6-D。

| 机制 | 其参数 | 与"λ"的关系 | 是否同一可比量 |
|---|---|---|---|
| 1-level density | test function 的 Fourier support 半径 $\lambda$ | **= λ 的定义** | ✓（基准） |
| mollifier（Levinson 谱系） | 长度指数 $\theta$（$T^\theta$） | **不同轴**（R-A2 已证 $\theta$ 可 > 1/2） | **待判定，须显式映射** |
| pair correlation | 关联函数的 support | 与 λ 同族但非同一 | **待判定** |
| zero-free region | 区域形状（如 $\sigma>1-c/\log T$） | 不是 support 半径 | **不同轴** |
| zero proportion | 比例常数（5/12、2/3） | 输出量，非输入 support | **不同轴（下游）** |

$$\boxed{\text{Gate 1 产物 = 一张显式的 λ-字典 + 可比性判定；不可比即触发 R6-D}}$$

## 2. 先验锚点（须核实，标【文献级/待核实】，不得当既定事实）

```
① 单位（unitary）情形：无条件 1-level density 的 support 极限为 λ < 1
② 正交/辛（orthogonal/symplectic）族情形：族平均下可得 support < 2（LW/ILS 一类结果）
③ 机制线索：①②之差来自【移位矩展开中非对角项的存亡】——
      unitary 的非对角项消失/不可控 ⟹ λ<1；其他对称型非对角项存活 ⟹ λ<2
④ 支线乙自报：仅用 λ ≤ 1 矩信息的证明类，硬顶 0.68185（V2 审计已记录）
⟹ **②③ 直接关系到 Gate 2D（family averaging）与 Gate 5（λ ≥ 2）**：
      若 λ<2 只在非 unitary 族出现，则 ζ 不能借用（ζ 猜想为 unitary）
      —— 这正是 Gate 2 要判定的"真正来源"
```

## 3. 六关（严格化后的准入问题）

```
Gate 1  定义干净化：建立 λ-字典（§1），确认所有被审机制映射到同一可比量
        —— 不可比 ⟹ 直接输出 R6-D
Gate 2  λ ≤ 1 的真正来源（逐项排查，不得以"文献通常做到"代替）
        A 显式公式：是否因 prime sum 只能控制到某范围？（若只是"当前估计不够" ⟹ 非结构）
        B positivity：是否存在 Q(f) ≥ 0 型约束给出 support 界？
                     若存在 ⟹ 追问：它在整个 λ<2 区间是否存在，只是未证？
        C 算术独立性：λ>1 之后是否【需要新的独立算术输入】？（此最接近真结构障碍）
        D 族平均：λ=1 是否仅来自族平均？若改 family/weight/amplifier 可越过 ⟹ λ=1 非结构常数
Gate 3  必须主动构造 λ = 1+ε 的候选机制（失败亦可），并**明确失败节点**
        若所有 canonical L1 方法在同一数学节点失败（例如出现不可消除正项 B_λ ≥ c(λ) > 0）
        ⟹ 才开始具有"结构性天花板"的性质
Gate 4  **信息需求 vs 证明技术**（本关是 R6 的核心）
        若 λ>1 需要某个【原则上可独立确定】的二阶素数关联 ⟹ "目前不会算" ≠ "结构上不可能"
        若证得 λ>1 ⟹ 需要一个与目标 zero-position 【等价】的信息对象 ⟹ 真信息障碍
        产物必须写成：λ > 1 ⟹ 【哪一种新信息】？（禁止"现有方法做不到"式结论）
Gate 5  ★ 决定性一刀：canonical L1 机制能否跨过 λ ≥ 2？
        若存在满足 C1 / C2′ / C3 且不假设 RH、不编码零点的机制达 λ ≥ 2
        ⟹ FZ-3″ 核心判断被击穿 ⟹ L1 → pinning 首次成为现实路线
Gate 6  写死：比例 ⇏ 钉住（不可偷升级）
        若只得 N(σ,T) ≤ c·N(T)（c<1）⟹ 属【比例约束】，不是 RH
        必须有【独立步骤】 proportion → zero exclusion，否则只能记 L1 成果
```

## 4. 判定程序（⭐ 我加的：把"结构 vs 技术"操作化）

$$\boxed{\text{某天花板是【结构性】的，仅当存在形如下述的定理：}}$$
$$\boxed{\text{任何 }C\in\mathscr C_{\rm L1}\text{ 若 support}>\lambda_0\text{，则 }C\text{ 必含一个与零点【互相定义】的对象（或必为条件性）}}$$
```
· 结构性天花板 = 【在信息类内部证明】的界（不是观察到的界）
· 技术天花板   = 障碍可归约为一个【定义良好但尚未算出】的量（特定矩/关联）
⟹ Gate 4 的产出形式固定为："障碍是 ⟦未算但可定义的量⟧ 还是 ⟦与目标的等价性⟧？"
```
