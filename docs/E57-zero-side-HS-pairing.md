## 1. 对象与做法（✓）

```
【装置的核心输入 ✓】‖G‖²_HS ~ (a²L²)^{-1}·Σ_{γ,γ′}Φ(γ−γ′)²·(权重) ✓
   （Φ = 窗口平方的 Fourier 变换 ✓；前沿在**素数侧**用 Dirichlet 多项式二矩算它 ✓）
【本轮问题 ✓】能否改在**零点侧**、只用**三角不等式＋计数**（E55 的作法 ✓）算出来？✓
【取窗口 ✓】指标窗口 ψ₀（ψ = 1 on [−1/2,1/2] ✓）⟹ φ² = 1 on [−L/2,L/2] ✓ ⟹ 核 **Φ(x) = 2sin(xL/2)/x** ✓，Φ(0) = L ✓
【归一化配对 ✓】R_meas(N) := (1/N)Σ_{γ,γ′}(Φ(γ−γ′)/L)² ✓ = **1（对角 ✓）＋ 非对角/N** ✓
   前沿素数侧给出 **R(ψ₀) = 4/3 = 1.3333** ✓（这是比对的靶 ✓）
【核的衰减 ✓】|Φ/L| ≤ 2/(dL) ✓ ⟹ 平方按 d^{-2} 衰减 ✓ ⟹ 只需截断到 2000 个邻居 ＋ 解析尾部 ✓
```
