## §2 ⭐⭐⭐ **统一诊断：工具–目标错配**
```
**我们每次都要求工具交付【最强的目标】（RH / 排除 / 证明）；
  工具交不出 ⟹ 我们判定"该方向死" ✗
文献问的是："**这个工具最强能交付什么**"，然后**把它拿走** ✓✓**
```
$$\boxed{\text{错配} = \text{用"能否证明 RH"去评价每一个工具}\quad\Longrightarrow\quad\text{所有工具都被判死 ✗}}$$
```
⇒ 这条解释了此前所有诊断的**共同根源**：
   · "箭头方向反了"（用数值检验命题而非把数值当输入）✓ —— 是**使用方式**问题
   · "没有转换"（缺局部化配对）✓ —— 是**没问工具能交付什么**
   · "台账当档案而不当过滤器" ✓ —— 是**没把成果当工具登记**
```

## §3 **把"用法"分类（我们的 vs 文献的）**
```
【我们的三种用法】
 A 检验型：拿命题做数值测试 → 报一致性/偏差 ✗（零杠杆）
 B 攻击型：拿候选做对抗审查 → 破则弃 ✗（25 轮 NO-GO）
 C 封档型：拿等价（⟺ RH）→ 判"无杠杆"→ 关领域 ✗
【文献的三种用法（我们缺的）】
 D 放大器型：等价 + 数值事实 → **产出符号范围** ✓（d ≤ T²；N₁–N₂ ✓）
 E 记账型：不证明正性，**计数亏欠**（正指标/惯性/比例）✓✓
 F 输入型：把统计/算术估计当**无条件输入**喂机器 ✓
 G 优化型：对**族/窗**做优化，把常数推上去 ✓
 H 降级交付型：把目标从"排除 ✗"降到"**界数目/比例** ✓" —— **这是最大的一个** ✓✓
```

## §4 ⭐⭐ **由此得到的关键认识（也是"走更远"的真正入口）**
```
**可累积的中间目标**（比例、范围、度界、常数）——文献靠它们堆出成果（5/12→2/3→0.6725；d≤3→10²⁶）✓
**全有或全无的目标**（证明 / 排除零点）——我们只盯着这个 ✗ ⟹ 每个工具都"不合格" ✗
⟹ 我们不是缺工具，是**用"全有或全无"的尺子去量每一个可累积的工具** ✗✓
```

## §5 **制度修正：新增 P8（工具–交付审计）**
```
**P8**：任何成果/资产进入台账时，必须同时登记三项：
   (a) 它**最强能交付什么**（范围？比例？常数？判据？）
   (b) 与之匹配的**最弱但仍有意义的目标**（"可累积"优先 ✓）
   (c) 我们是否在**要求超出其能力的交付** ✗
并规定：**优先推进可累积目标**（比例/范围/界），而非全有或全无目标 ✓
```
