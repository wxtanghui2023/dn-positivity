## Zero-Prime Coupling（第一优先级——唐先生最看重）

### 核心想法
显式公式的横向约束：**zero configuration ↔ prime-power configuration**——离轴零点必须同时与固定的 Λ(n) 序列兼容——zero-side cancellation 必须匹配 prime-side positivity/structure——**换了约束的来源**（不是增加 R_k——是换轴）。

### 检查结果
1. **γ-only 的 f**（f_a(t) = 1/(a²+t²)）：离轴配置的零点侧**与在线相同**（轨道配对——虚部不变）——不区分在线/离轴
2. **含 β 的 f**（Re[1/(s₀−ρ)]）：**轨道配对一阶抵消**（ΣRe 在 δ=0/0.1/0.2 不变——0.0438）——函数方程对称性消灭一阶
3. **二阶残余**（δ²）：存在（a=0.5: 2.547→2.375）——但——**素数侧可吸收（显式公式自适应）**——无独立约束
4. **moment problem 版本**（一族 f 的截面）："合法素数测度"含 ζ 的 Λ（RH 假时——ζ 离轴 + 算术 Λ——兼容）——循环

### ⭐ 最终判定
**Zero-prime coupling 不提供 F_U 之外的独立约束（初步——数值+逻辑）**：
- **实际离轴（RH 假）满足任何真的约束**（ζ 是反例——它真的存在）
- **抽象离轴（修改 Hadamard）不满足**——但——唯一性——循环
- 含 β 的 f 一阶抵消——二阶残余素数侧可吸收（自适应）
- **moment problem**——ζ 自身（RH 假）是"合法实现"——任何真的 moment 约束——ζ 满足——循环

## 最终结论
**所有路线（P5 系列 + 盲区地图①-⑥ + zero-prime）确认同样的"唯一性/循环"墙**：
> **"实际离轴"（RH 假——ζ 自身）满足任何"真的"约束（ζ 是反例）——任何不依赖 RH 的"独立算术约束"必然被 ζ（无论在线/离轴）满足——因此不能排除离轴——循环。**

**Rigidity Gap 的定位**：
- **不是**"density ↛ coercivity"（P5 的——已稳）
- **而是**（更深的——初步确认）：**zero-only information 与 arithmetic realization 之间的结构性边界**——所有"零点统计"（密度/差谱/相位）和"零点-素数耦合"（显式公式/可实现性）——都撞同一堵墙
- **"Detection without Exclusion"框架——强**（不是"没找到证明"——是"结构性边界"）
