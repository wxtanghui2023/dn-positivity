# 延拓刚性第 ⑦ 关：size/product 基底审计

**日期**：2026-09-10 ｜ 承接 continuation-rigidity-gate-1 ｜ 结果：基底确实非同余 ⟹ 逃过 CRT 杀；但它落到已知同族难题，且结构性够不到 RH 强度

---

## 1. 基底的合法性：size/product 确实是【非同余】约束（逃过 ③）

同余基底被 CRT 杀死的原因是"局部配置总能拼成全局"。
by contrast，size/product 约束把**不同素数**通过**精确乘积**与**大小不等式**耦合起来：
$$n=ab\ \Longrightarrow\ \text{同时锁定 }a,b\ \text{的素数构成与大小},$$
这种耦合**不是同余型**，CRT 的局部–全局原理**不适用**。
$$\boxed{\text{⟹ size/product 基底是一个真正非同余的约束类（第 ⑦ 关的肯定面）}}$$

## 2. 但它的"交互内容"被恒等式吸收（pincer 第一腿再次出现）

size/product 基底的核心恒等式是**双曲恒等式**：
$$\sum_{n\le x}d(n)=2\sum_{d\le\sqrt x}\Big\lfloor\frac xd\Big\rfloor-\lfloor\sqrt x\rfloor^2 .$$
它**恒真**（对任意 $x$，不依赖素数配置）⟹ 与 Integrability–Null Pincer 第一腿同型：
$$\boxed{\text{恒等式 = 可积 = 不携带关于具体配置的刚性}}$$
⟹ 该基底的"刚性内容"必须先被抽掉这一层。

## 3. 抽掉恒等式后剩下的是它的【误差项】

$$\boxed{\Delta(x):=\sum_{n\le x}d(n)-x\log x-(2\gamma-1)x}$$
这就是 **Dirichlet 除数问题**（以及同族的 Gauss 圆问题）。

**结构位置（关键）**：
```
猜想指数   Δ(x) = O(x^{1/4+ε})
   ⟹ 1/4 = (1/2)·(1/2)：√ 结构的【自身误差】
   ⟹ 属 Lindelöf / 均值估计一族，与 RH 同族但【不同强度】
```

## 4. 结构性限制（本轮最重要的裁决）

$$\boxed{\text{size/product（双曲）基底天然只能触及 }1/4\text{ 族 (Lindelöf/除数问题族)，}\\
\text{而 RH 属 }1/2\text{ 族 —— 中间缺一个【族间转移机制】}}$$

诚实标注：$1/4$ 族与 $1/2$ 族之间的**精确蕴含网**（谁蕴含谁、是否等价）需逐条核对后才能引用；
本文只作"结构位置"判断，不作等价性断言。

⟹ 即使该基底被完全攻克，得到的也是**同族的已知难题**，
不能直接给出 RH —— 除非另有一个把族间刚性转移过来的机制，
**而那个机制正是 phase wall（ACA-1 §5）。**

## 5. 裁决

```
第 ⑦ 关（size/product 基底的局部–全局性）:
  肯定面：基底确实非同余，逃过 CRT 杀 ⟹ 作为约束类【合法】
  否定面：其刚性内容 = 已知同族难题（Dirichlet 除数问题 / Lindelöf 族）
          ⟹ 不是新桥；且结构上够不到 RH 强度
⟹ 结论类型：既非干净 NO-GO，也非活路 ——【换基底后落到已知同族难题】
```
