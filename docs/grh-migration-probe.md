# GRH 迁移试探性测试记录（2026-08-31 上午）

> 目标：验证 RH 判别判据框架能否迁移到 Dirichlet L 函数（GRH）——
> 这是通向强哥德巴赫的解析路径（GRH ⟹ 素数在 AP 分布 ⟹ 强哥德巴赫渐近）。

## 背景与战略

- 唐先生纠正：**RH（ζ）只对应弱哥德巴赫层面**——弱哥德巴赫已被 Helfgott
  无条件证明（2013）——RH 对哥德巴赫无新价值
- **强哥德巴赫**（偶数=2素数）需要 **GRH（L 函数）**——Hardy-Littlewood
  圆法——素数在算术级数的分布——L 函数零点控制
- 战略：**先做 GRH**（上游——一石二鸟）——第一步：迁移试探（单个 L 函数）

## 测试对象

**模 4 的 χ₄**（Dirichlet beta 函数 β(s)）：
- β(s) = 4^{−s}(ζ(s,¼) − ζ(s,¾))（Hurwitz 差——30 位验证一致）
- **关键修正**：χ₄ 是**奇字符**（χ₄(−1)=−1）——完成函数用 a=1：
  ξ(s) = (π/4)^{−(s+1)/2}Γ((s+1)/2)β(s)——函数方程 ξ(s) = −i·ξ(1−s)
  （相对差 2.8e-31——精确）——一开始当偶字符（a=0）是错的
- 零点寻找：粗扫凹陷 + 黄金分割极小化——168 个零点（γ<300）——
  **修正了凭记忆的"参考零点"错误**（我的零点 |β| 极小 1e-6——参考值
  |β|~0.3 根本不是零点）——零点实部 Re=0.500000（GRH 数值支持）

## 测试结果

### ① 相位锁定迁移（Σ_k e^{iγ_k log p}——N 增长）——中性
- p=2 早期"强锁定"（N<100 比值 0.05-0.16）——**N=168 时升到 0.62——
  局部抵消非渐近锁定**
- 其他 p 比值 1.3-3.1——与 ζ 同 N（1.75-2.8）同量级
- **结论**：χ 结构不破坏锁定（显式公式机制仍工作）——但无超强锁定——
  锁定是渐近现象（N~10⁴——ζ 也如此）——前 ~170 个零点只能看局部——
  继续堆零点在 mpmath 下太慢——不是好路径

### ② 成对正性机制（P_γ）迁移——决定性通过
- w_H/P_γ 闭式**直接适用**（纯代数——不依赖 L 函数——Hadamard+函数方程）
- 离轴测试：Q−Q'_RH = +P_γ(δ)——机器精度匹配（相对差 3.4e-24~2.7e-14）
- 多个 γ（6.02~287）+ 多个 δ（0.01~0.49）全过
- P_γ(δ) > 0（δ≠0）——=0 ⟺ δ=0——全部零点验证
- **等号刚性**：Q=Q'_RH ⟺ 全 δ=0——GRH 判据的"发动机"迁移成功
