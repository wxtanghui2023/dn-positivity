## §1 Selberg 机制的确切内容（为什么它是"唯一无条件成立的类"）
```
Z_X(s) = Π_{本原闭测地线 γ} Π_{k≥0} (1 − e^{−(s+k)ℓ(γ)})     （X = 双曲曲面 Γ\ℍ）
Selberg 迹公式：Σ_{谱} h(t_j) = 几何侧（闭测地线 + 常数项 + 连续谱）
⟹ Z_X 的零点 = 拉普拉斯算子的谱参数：λ_j = 1/4 + t_j²
⟹ **Δ 自伴 ⟹ λ_j 实 ⟹ t_j ∈ ℝ ⟹ Re(s) = 1/2**（当 λ_j ≥ 1/4 时）✓✓
【引用】例外：λ_j < 1/4 的"小特征值"给出**实**的例外零点（偏离临界线）✗
```
**成功的四要素**
| # | 要素 | Selberg 侧来源 |
|---|---|---|
| S1 | 自伴生成元 | **几何免费**（Riemann 流形上的 Laplacian 自动自伴且非负）✓ |
| S2 | 迹公式 | Selberg 迹公式 ✓ |
| S3 | 零点 = 谱参数 | 由迹公式给出 ✓ |
| S4 | 谱下界（λ ≥ 1/4） | ⚠️ **非自动**：一般曲面可有小特征值 ⟹ 需排除 |

## §3 ⭐⭐ 因此得到**被简化的目标**（收窄）
```
ζ 侧只需两件事：
 (T1) 一个**自伴/正性**的算术结构（= 缺口 ✗）

⟹ **谱实现路线所需的唯一缺失项 = 正性/自伴性** ✓✓
⟹ 而且：**不需要任何"谱隙/一致性(uniformity)"输入**！（自伴 ⟹ 谱实 ⟹ 零点在线 ✓）
```
$$\boxed{\text{目标简化：谱实现路线只需【正性】—— 谱隙/一致性【不是】必要条件}}$$
