## §1 **修复思路（与 NB2 失败原因对应 ✓）**
```
【NB2 失败 ✓】① 通用求积（maxdegree=6、区间 400 ✓）无法处理振荡被积函数（周期 2π/log(m/n) ≈ 9 ✓）
   ② 预计算 zeta 表未用 ✓ ⟹ 得到 **负的 d_N²** ✗（平方距离不可能为负 ✓）⟹ 实现错误 ✓
【✅ NB3 的正确做法】把 d_N² 化归为**单次傅里叶扫描** ✓✓：
   · 核 **K(m,n) = g(log(n/m))** ✓（**平移不变** ✓ —— 只依赖比值 ✓）
   · 线性型 **l_n = n^{−1/2}(1/π)∫_0^T Re[ζ(1/2+it)e^{−it log n}]dt/(1/4+t²)** ✓
   · 二者是**同一组网格值**的一次变换 ✓ ⟹ **不存在二维振荡求积** ✓✓
   · 求解 **K a = l** ⟹ **d_N² = 1 − lᵀa** ✓（精确最优 ✓）
【⚡ 速度】用 **Riemann–Siegel**：ζ(1/2+it) = Z(t)e^{iθ(t)} ✓（t ≥ 15 ✓；t < 15 用 mpmath ✓）
   ⟹ 8001 点网格 ~2 分钟 ✓，且**结果缓存** `data/nb3_grid_H0.050_T400.npz` ✓（重跑秒级 ✓）
```
