## 1. 定理

**定理（候选——无条件）**：
$$\sum_{k=1}^{N}\delta_k = O(1)$$

（8/22 证明 O(loglog T)——本证明改进到 O(1)）

## 2. 证明

### 恒等式（8/22——无条件）
$$\sum_{k=1}^{N}\delta_k = -\frac{S(\gamma_{N+1})}{N_0'(\gamma_{N+1})} - \int_{\gamma_1}^{\gamma_{N+1}} S(t)g(t)\,dt + O(1)$$

其中 g(t) = N₀''/N₀'² = 2π/(t log²(t/2π))（**绝对可积**——∫g < ∞——关键！）

### 端点项
|S| ≤ C·log t（Backlund）——S/N' ≤ 2πC = O(1) ✓

### 核心：∫S·g = O(1)

**分段展开（恒等式）**——S(t) = k − N₀(t) on [γ_k, γ_{k+1})：
$$\int_{\gamma_1}^{\gamma_{N+1}} S(t)g(t)\,dt = \sum_{k}\underbrace{S_k\,g(\gamma_k)\Delta\gamma_k}_{\text{项 A}} + \sum_k\underbrace{E_k}_{\text{项 B}}$$

**项 A**（Σ S_k·g·Δγ——用 mean(S)=½ 无条件定理）：
- w_k = g(γ_k)·Δγ_k（缓变正——Σw_k ≈ ∫g < ∞）
- Abel 求和：ΣS_k w_k = w_N·ΣS_k − ΣΔw_k·ΣS_j
- |Σ_{j≤k}S_j − k/2| = O(log²γ_k)（8/22——mean(S)=½）
- Σ|Δw_k|·log²γ_k < ∞（w 缓变 + log² 可积）
- **⟹ ΣS_k w_k = (1/2)Σw_k + O(1) = O(1)** ✓（数值：5.32 vs (1/2)ΣgΔγ=4.87——差 0.45）

**项 B**（ΣE_k——欧拉-麦克劳林误差）：
- E_k = ∫(k−N₀)g dt − S_k g(γ_k)Δγ_k
- **Σ|E_k| < ∞（绝对收敛）**——数值 46（到 γ~1.4e5 稳定）
- 尾部界：|E_k| ≤ C·(N₀'g + |S_k||g'|)·Δγ² ≤ C/(γ_k log³γ_k)（大 γ——收敛）
- 前端（有限个——γ 小）——E_k 大但有限（γ=14: E=−2.2）——O(1) 常数
- **⟹ ΣE_k = O(1)** ✓（数值 −4.88——绝对收敛）

### 结论
Σδ_k = O(1) + O(1) + O(1) = **O(1)** ∎

## 4. E_k 的严格界（完成）

**E_k = ∫_{γ_k}^{γ_{k+1}}(k−N₀)g dt − S_k·g(γ_k)·Δγ_k**

令 F(t) = (k−N₀(t))g(t)——欧拉-麦克劳林一阶：
$$|E_k| \le \frac12\max|F'|\cdot\Delta\gamma_k^2$$

**F' 的界**（无条件）：
$$|F'| \le N_0'g + |S|\cdot|g'| \le \frac{1}{t\log(t/2\pi)} + \frac{C\log t}{t^2\log^2(t/2\pi)}$$
（N₀'g = 1/(t log(t/2π))——精确；|g'| ≤ C/(t²log²)——Backlund |S| ≤ C log t）

**尾部**（γ_k 大——Δγ ~ 2π/log t）：
$$|E_k| \le \frac{C}{\gamma_k\log^3\gamma_k}$$
$$\sum_{\gamma_k>\gamma_0}|E_k| \le C\int_{\gamma_0}^\infty \frac{dt}{t\log^2 t} = \frac{C}{\log\gamma_0} \to 0$$
（用零点密度 Σf(γ_k) ≈ ∫f·(log t/2π)dt）

**前端**（γ_k ≤ γ₀——有限个）：|F'| 在 [γ₁, γ₀] 有界——每个 |E_k| ≤ C——**O(1) 常数** ✓

**⟹ Σ|E_k| = O(1)（绝对收敛——无条件）** ∎
