## §1 ⭐⭐⭐ **核心发现：同一个判据有【两条机制、两条律】** ✓✓
```
【登记表的疑问 ✓】"Li 似为线性 ✗ ⟹ 需解释 T² 来源" ✓
【答案】**平方不是判据的性质，而是【机制】的性质** ✓✓ —— **同一 Li 判据**同时允许两条路：
```

### **机制 A（窗口 / 逐项正性）⟹ 线性** ✓
```
【推导】（已在本文档外的 8-22 轮验证 ✓）对**在线**零点，第 n 项为 **1 − cos(nθ_γ)** ✓，
   θ_γ = arg(1 − 1/ρ) **≈ 1/γ** ✓（大 γ ✓）
⟹ 首次显著 ⟺ nθ_γ ~ 2π ⟹ **n*(γ) ≈ 2πγ** ✓ ⟹ **h(n) = n/(2π)（【线性】✓✓）**
【数值 ✓】γ=100：预测 **628.32** ✓ vs 2πγ = **628.3** ✓✓（γ=500: 3141.59 ✓；γ=1000: 6283.19 ✓）
【输入】**无条件** ✓（只用到 1 − cos ≥ 0 ✓）⟹ 这是**论文 A 的线性范围 2T** 的来源 ✓✓
```

### **机制 B（尾部预算）⟹ 平方** ✓
```
【推导】利用 **|1 − 1/ρ|² = 1 + (1−2β)/(β²+γ²)** ✓ —— 对 β = ½+δ 有 (1−2β) = −2δ ✓
   ⟹ q := |1−1/ρ| ≈ **1 − δ/(β²+γ²)** ✓（即**衰减** ✓）
   ⟹ 偏离度 1 − q^n 达到 1% 所需 **n* = log(0.99)/log(q) ≈ 0.01005·γ²/δ** ✓✓
【数值 ✓✓】**n*/γ² = 1.005**（γ=14.1/100/1000，δ=0.01 —— **常数！** ✓✓）
   ｜**n*/γ² = 0.1005**（δ=0.1）⟹ 精确的 **1/δ 标度** ✓✓
⟹ 反解：**h(n) ≈ 10·√(δn)**（**平方根** ✓）⟹ **"T² 律"** ✓
【输入】**条件性** ✗（需计数假设 + 未证的引理修复 ✓）
```

## §2 ⭐⭐⭐ **精化的突破点判据（两轴 ✓✓）**
```
【登记表 E30 的原判据】（单轴 ✓）"探针的 h(n) 若慢于 √n ⟹ 可达 T^{1/α} > T²" ✓
【⚠️ 问题】按单轴，机制 B（h ~ √n ✓）**优于**机制 A（h ~ n ✗）⟹ 会推荐**条件性**的路 ✗✓
【⭐⭐ 精化 ✓】**探针必须按两轴评分** ✓：
   ① **h(n)**（决定可达范围 ✓）  ② **输入的无条件性**（决定结论强度 ✓✓）
⟹ **突破 = 改善 h(n) 而【不】牺牲无条件性** ✓✓
   —— "为了更大的范围而放弃无条件性" **不是进步** ✗，只是**换了交易条件** ✓
【⟹ 具体目标（可检验 ✓）】**寻找"窗口型"机制且 h(n) 亚线性** ✓✓
   （现有窗口机制 h(n) = n/(2π) ✓ 线性 ✓；尾部机制 h(n) ~ √(δn) ✓ 但条件性 ✗）
```
