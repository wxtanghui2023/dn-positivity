# P26-A16：反向变分——离轴 ⟹ 矛盾（循环确认）

## P26-A16 结果

### ① 正向 vs 反向变分
- 正向（传统物理）：零点在势的极小（平衡——变分原理）——V(β) = V(1−β)——凸——极小 ½——但——变分原理缺失（A15）
- 反向（替代）：不假设"零点在极小"——证明"离轴零点 ⟹ 矛盾"

### ② 反向变分的候选盘点
- (a) D 判据反向：D ≥ 0（无条件）——离轴 ⟹ D > 0——但"D ≤ 0"未证（循环/自适应）
- (b) 物理能量：V 的极小在 0——但不 ⟹ δ = 0
- (c) β 矩：离轴 > 0——但无上界（发散）
- (d) 零密度（Ingham）：允许离轴
- (e) Weil 正性：⟺ RH——循环
- **全部撞墙（"无条件 ≥ 0 且离轴 ⟹ < 0"的量未找到）**

### ③④ ⭐ 反向变分的深层——循环确认
- 反向变分需要：Q ≥ 0（无条件）且离轴 ⟹ Q < 0
- **"Q ≥ 0（无条件——所有配置）"与"离轴 ⟹ Q < 0"直接矛盾**（除非离轴配置不存在——正是要证的）
- 正确形态：Q ≥ 0（合法配置）——但——"合法配置"包含离轴（如果 RH 假——ζ 是证据）
- **"离轴 ⟹ Q < 0"只在"在线"成立（RH——循环）**

### ⑤ 物理模板的替代——完整撞墙
- 正向变分（变分缺失）——反向变分（循环）——动力学（时间反演）——规范（非动力学）——γ 通道
- **物理方向完整图景**：变分缺失/循环/时间反演/γ 通道
