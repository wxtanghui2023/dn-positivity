| **(a) 提升【结构层级】**（秩 / 函子性 / 范畴 / 绝对几何 F₁） | ✓ **对齐**（直击元素化/极化/充分正性） | 见 §2、§3 |

## §2 ⭐⭐ **精确界限**（本轮新得出的关键区分）
```
同一个"升秩"输入，在两类域上产出【完全不同】：
  · char p：**Ramanujan ⟺ RH**（局部因子根模 = √q ⟺ 零点在 Re=1/2）⟹ 升秩直接给 RH ✓✓
  · ℚ    ：Ramanujan 型输入只给 **θ 的界**（7/64），**给不出** RH ✗
⟹ 差距 = **局部数据 → 全局零点**（Euler 积的"黏合"），
   而这正是本项目反复定位的 **β-墙 / 局部≠全局** ✓✓
⟹ 结论：升秩**买得到 β-界**，但买不到 β=1/2 —— 除非同时解决【黏合/极化】
```
