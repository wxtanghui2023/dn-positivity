# r(n) = O(1) 的 Abel 分解：常数部分（无条件）+ 振荡剩余（缺口）（2026-08-23 19:25）

> 来源：唐先生的 Δw_k 分析 → 我的数值验证
> 状态：✅ 分解清晰——常数部分无条件——振荡剩余 = 相位均匀性

## 1. Abel 分解（关键结构）

**r(n) 的 Abel 项** = Σ_k Δw_k·A_k（A_k = Σ_{j≤k}δ_j——O(1) 新定理）

**分解**：
$$\sum_k \Delta w_k A_k = \underbrace{A_\infty\sum_k\Delta w_k}_{\text{常数部分（无条件 O(1)）}} + \underbrace{\sum_k \Delta w_k(A_k - A_\infty)}_{\text{振荡剩余（缺口）}}$$

**常数部分**（望远镜——无条件）：
- ΣΔw_k = w_N − w_1——w_N → 0（θ_k → 0——w_k = 1−cos(nθ_k) → 0）
- = −w_1 = O(1) ✓
- A_∞ = Σδ_k = O(1)（新定理）
- **⟹ 常数部分 = O(1)——无条件！**

**振荡剩余**：ΣΔw_k(A_k − A_∞)——数值 O(1)（±3.5——n=10 到 2000 不增长）——**证明需要 A_k 的波动与 Δw 的振荡抵消——相位均匀性 = RH**

## 3. 意义

1. **r(n) = O(1) 的 Abel 项分解**——常数部分无条件——缺口精确定位到"振荡剩余"
2. **振荡剩余 = ΣΔw·(A_k−A_∞)**——需要 A_k 波动与 Δw 振荡的"正交性"——**相位均匀性**
3. **Δw_k ~ n·sin(nθ_k)·Δθ_k**——振荡（n 因子——但带符号抵消）
4. **新认知**：即使 Σ|Δw| = O(n)——带符号 ΣΔw·A = O(1)——**双重振荡抵消**
