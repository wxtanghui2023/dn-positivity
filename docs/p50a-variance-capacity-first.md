## 3. ⭐ 独立上界审计（核心——能否从 A_min 推出 c(T)·T ≤ C？）

### 3.1 逐点界不够
- PNT（无条件）：ψ(x)−x = O(x·e^{−c√log x})
- ⟹ c(T)·T ≤ T·(Te^{−c√logT})²·T^{−3}·T ~ **T·e^{−2c√logT} → ∞**（发散——逐点界太弱）

### 3.2 均方界需零点
- ψ−x 的 L² 对数均方渐近（Gallagher/Cramér 型）含零点实部 β₀——**依赖零点**
- β₀=½（RH）：∫₂^T(ψ−x)²x^{−2}dx ~ O(log²T)（对数——c(T)·T 有界 ✓）
- 无条件（零自由区域 β₀ ≤ 1−δ(T)）：均方 ~ T^{2(1−δ)−1}——δ~1/logT——**太大——无法判别任何固定 β₀>½**

### 3.3 结论：紧独立上界不可能从 A_min 推出
- "c(T)·T ≤ C（紧——够判别 13.6×）"需要零点级精度（Gallagher 型渐近含 ρ）——**循环**
- 这是"检测（β 体积——数值支持 β≈½）vs 约束（独立上界）"缺口的**精确形态**——同 P36.2（A≥P 需零点精度）——同 P49 墙
