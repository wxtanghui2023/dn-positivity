## §3 半径律与 1/d² 敏感度（核验）
```
【律】变体 1：rad·d²/|λ| = 2√(1−d²) ✓；变体 2：rad·d² = √(1−d²) ✓ ⟹ 两者 d²→0 时都是 **∝ 1/d²** ✓
【H=10³ 表（节选）】d²=0.9/0.1/0.01：rad₁ = 7.03e2 / 1.897e4 / 1.990e5；rad₂ = 0.351 / 9.487 / 99.50 ✓
【H 依赖】**变体 1 的半径 ∝ H**（固定 d²）；**变体 2 与 H 无关** ✓（中心虚部 = b = H）
【要求表】得半径 ≥ ρ：变体 1 需 d² ≲ |λ|/(aρ) = 2H/ρ ✓；变体 2 需 d² ≲ 1/ρ ✓（ρ=10³：v1 在 H=10³ 需 d²<0.8284，v2 需 d²<9.995e-4）
【阈值】两变体圆盘非空 ⟺ d² < 1/(2a) = **1**（r=1/2）；d²→1 时半径→0 ✓
```
