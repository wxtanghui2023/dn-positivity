## Lemma（Q_λ 缩放核）

> **陈述**：定义（λ = η/δ——离轴量比）
> $$Q_\lambda(y) = \frac{\frac12\log\frac{y^2+(1+\lambda)^2}{y^2+1} + \frac12\log\frac{y^2+(1-\lambda)^2}{y^2+1}}{\lambda^2} - \frac{y^2-1}{(y^2+1)^2}$$
> 则 $$\sup_{0<\lambda<1/2}\int_{\mathbb R} y^2|Q_\lambda(y)|\,dy \le C < \infty$$

## 证明（唐先生结构——三区覆盖）

**记号**：A_λ(y) = ½log(y²+(1+λ)²) + ½log(y²+(1−λ)²) − log(y²+1)（中心二阶差分——λ 偶函数）

**① 远场（|y| > R——最关键——抵消）**：
- 中心差分展开：A_λ(y)/λ² = 1/y² − λ²/(2y⁴) + O(λ⁴/y⁶)
- K₁(y) = (y²−1)/(y²+1)² = 1/y² − 3/y⁴ + O(y^{−6})
- **1/y² 项精确抵消**——Q_λ(y) = −λ²/(2y⁴) + O(y^{−6})
- y²|Q_λ(y)| ≲ λ²/y² + 1/y⁴——∫_{|y|>R} 可积——**λ 一致**（0<λ<½——λ²<¼）

**② 近场（|y| ≤ R——一致收敛）**：
- A_λ(y) 是 λ 的偶函数——Taylor：A_λ(y) = (λ²/2)∂_λ²A₀(y) + O(λ⁴)
- A_λ(y)/λ² → ½∂_λ²A₀(y)（λ→0）——**极限正好被 K₁(y) 抵消**（——½∂_λ²A₀ = (y²−1)/(y²+1)²——）
- **Q_λ(y) → 0——在 |y|≤R 一致**（λ→0）
- sup_{|y|≤R, 0<λ<½}|Q_λ(y)| < ∞

**③ 中间区（1 ≤ |y| ≤ R——紧致）**：
- (y,λ) ↦ Q_λ(y) 连续——紧区间 sup 有限

**闭合**：ℝ = {|y|≤R} ∪ {|y|>R}——紧区（Taylor+连续）+ 远区（y^{−4} 尾）——sup ≤ C ∎

## 推论（M₂ 的尺度——修正）

**尺度化**（x = δy——dx = δdy——E = δ^{−2}Q_{η/δ}(y)）：
$$M_2 = \int x^2 E(x)\,dx = \delta\int y^2 Q_{\eta/\delta}(y)\,dy$$

**由 Lemma**：$$|M_2| \le C\delta \quad \boxed{M_2 = O(\delta)}$$
**（修正：不是 O(η²δ²)——后者无证据支持——真实尺度是 δf(η/δ)）**

## 交换成立（墙 A 闭合）

配对展开（M₀ = 0——M₁ = 0——偶性）：
$$\langle E_{\eta,\rho}, H\rangle = \tfrac12 H''(\gamma_\rho) M_2 + \cdots$$
$$|\langle E,H\rangle| \le C\delta_\rho |H''(\gamma_\rho)|$$
求和（0 < δ_ρ < ½）：
$$\sum_\rho \delta_\rho |H''(\gamma_\rho)| \le \tfrac12 \sum_\rho |H''(\gamma_\rho)| < \infty$$
（H''(γ) ~ γ^{−2}——零点密度——Σγ_ρ^{−2} < ∞）

**⟹ 交换成立——墙 A 闭合 ∎**
