# RH 的谱测度唯一性命题（候选框架）

> 日期：2026-08-30 上午
> 状态：候选命题 + 证明路线 + 已知墙（未完成证明）
> 来源：混合导数 ∂_β∂_T log ξ 的 Fourier 编码——唐先生引导

## 1. 核心观测（M_ρ 方向）

定义（混合导数——方向探针）：
$$M_\rho(T) = \partial_\beta\partial_T \log\xi(\beta+iT)\big|_{\beta=1/2}$$

零点贡献（逐项）：
$$\partial_\beta\partial_T \log(s-\rho)\big|_{s=1/2+iT} \sim \Re\frac{i}{(T-\gamma)^2}$$

**在线逐项零化**：每个在线零点贡献 Re[i/(T−γ)²] = 0（——不是求和抵消——逐项恒等——真正的结构性零化）

**成对离轴不消**：检测 (β−½)(T−γ) 耦合——ρ↔1−ρ 不再简单杀死

## 2. Fourier 编码（谱测度）

对 T 做 Fourier（Poisson 核）：
$$\widehat M(\omega) = \int M(T)e^{-i\omega T}dT = -i\omega\pi \sum_\rho \epsilon_\rho e^{-|\omega||\epsilon_\rho|} e^{-i\omega\gamma_\rho}$$

其中 ε_ρ = β_ρ − ½。

定义离散测度：
$$d\mu(t) = \sum_\rho \epsilon_\rho\, \delta_{\gamma_\rho}(t)$$

则：
$$\widehat M(\omega) = -i\omega\pi \int e^{-i\omega t} e^{-|\omega||\epsilon(t)|} d\mu(t)$$

**RH ⟺ μ = 0**（目标——未证明）

## 3. 候选命题

> **命题候选**：若 M_ρ(T) = 0（∀T），则 β_ρ = ½（所有 ρ）。

**证明路线（唐先生 10:28）**：
1. Fourier 变换：M_ρ → M̂_ρ
2. M̂_ρ(ω) = −iωπ Σ_γ A_γ(ω)e^{−iωγ}，A_γ(ω) = Σ_{ρ:γ_ρ=γ}(β_ρ−½)e^{−|ω||ε_ρ|}
3. Fourier 唯一性：M̂_ρ ≡ 0 ⟹ A_γ(ω) = 0
4. ω 连续变化 ⟹ ε_ρ = 0

## 4. 已知墙

### 墙 1：同高度抵消（致命——已验证）
**物理离轴配对（+ε, −ε 同高度——函数方程 ρ 与 1−ρ̄）**：
$$A_\gamma(\omega) = \epsilon e^{-|\omega|\epsilon} - \epsilon e^{-|\omega|\epsilon} \equiv 0$$

- 数值确认：精确配对 A_γ(ω) ≡ 0（所有 ω）
- **M̂(ω) 一阶谱编码——对物理离轴配对——看不到！**
- 一般配对（+0.1, −0.05）：A_γ(ω) ≠ 0（可见）
- **出路：二阶谱编码**——ε² + (−ε)² = 2ε² ≠ 0——同高度不抵消
- 但 ε² = (β−½)² 非解析（非解析墙——回到偶化能量问题）

### 墙 2：M 的零点部分与显式项分离
- M = M_ρ + M_Γ + M_trivial——Fourier 后显式项是已知解析项
- 可定义 M̂_ρ = M̂ − M̂_Γ − M̂_trivial
- 问题：分离后的谱测度是否唯一

### 墙 3：无限谱唯一性
- 无限零点——不同高度 e^{−uγ_ρ} 的线性无关性
- 需分布 Fourier 唯一性（不依赖 γ 代数无关）
