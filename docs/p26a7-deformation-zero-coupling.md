## P26-A7 结果
### ① 修正反射（含极点的分布反射）
- 原反射（M_b(s)=M_b(1−s)）⟹ 留数反号（c_ρ̄ = −c_ρ）

- **修正反射：M_b^∂(t) = M_b^∂(−t) − J(−t)**

### ② ⭐ 关键发现：M_b 在 ρ 的留数 = −δ_ρ（零点移动）
- c_ρ = Ḟ(ρ)/ζ'(ρ)——F_t 的零点（一阶）δ_ρ = −Ḟ(ρ)/ζ'(ρ)——**c_ρ = −δ_ρ**
- **"合法变形（零点移动 δ_ρ）⟺ M_b 极点（留数 −δ_ρ）"**
- **δ 跳跃（transfer 障碍）与"零点移动"（变形本质）是一回事——无法消除（除非平凡变形——零点不动）**

### ③⑤ 修正反射的单频率测试——b ↔ δ_ρ
- 修正反射 ⟹ b_{p₀}p₀^{−k₀/2}φ̂(λ₀) = −2πi∫φ̂(μ)Z(μ)dμ——φ̂ 窄——**b_{p₀} ≈ −2πi·Z(λ₀)/(p₀^{−k₀/2})**
- Z(μ) = Σ c_ρ e^{−iμγ_ρ}（零点指数和——含留数 c_ρ = −δ_ρ）
- **b 由 Z（零点移动）决定——不是 b=0**——"修正反射刚性"失败（b ↔ δ_ρ——变形理论闭环）

- 合法变形（零点移动）含极点——不适用——"修正反射"（含跳跃）——b ↔ δ_ρ——不强制 0
