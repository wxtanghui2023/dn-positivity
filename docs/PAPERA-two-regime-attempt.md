# (b) 两区制论证 —— **第一次尝试：把常规估计算清，看它们在哪失效**

> 唐先生指令 ✓（20:38）："三项都要做，继续" —— 本文件 = (b) ✓
> 方法 ✓：**把每一个"常规"估计的定量结果算出来** ✓，与 allowance 对比 ✓ ⟹ **定位真正的障碍** ✓

---

## 一、目标与两区制划分 ✓

```
需证 ✓：|Osc(n)| < N(T₀) − n·B_{T₀}，对所有 n ≲ 2T₀² ✓
  其中 Osc(n) = Σ_{γ≤T₀}cos(nθ_γ) ✓，N = N(T₀) ≈ (T₀/2π)log T₀ ✓
【实测的两区制 ✓】
   区 I（共振区，n ≲ 10γ_max）：|Osc|/N ≤ **0.379** ✓（有尖峰 ✓）；allowance ≈ **N** ✓
   区 II（平均区，n > 30γ_max）：|Osc|/N ≤ **0.034** ✓（无尖峰 ✓）；allowance **变紧** ✓
```

## 二、区 I（小 n）：需要什么？✓ **很弱的条件** ✓✓

```
【转化 ✓】Osc(n) = N − Σ(1−cos(nθ_γ)) ✓ ⟹ 若 Osc ≥ 0 则 |Osc| ≤ N − Σ(1−cos) ✓
⟹ **只需**：Σ_{γ≤T₀}(1−cos(nθ_γ)) ≥ **ε·N**，某个**绝对常数 ε > 0** ✓✓
   （因为 allowance ≈ N ✓，取 ε 任意正即可 ✓；实测 ε ≈ 0.62 ✓ 余量极大 ✓）
⟹ ⭐ **区 I 只需要"正比例项未对齐"** ✓ —— 这比等分布**弱得多** ✓✓
   ⚠️ 但它**仍未证明** ✗ —— 需要一个"至少 ε 比例项的相位不落在 0 附近"的计数 ✓
   【候选 ✓】θ_γ 严格递减且跨 (0,π) ✓ + 零点密度（≈ log T/2π ✓）⟹ **相位不可能全挤在 0 附近** ✓
      这是一个**可攻击的计数问题** ✓（可能不难 ✓）
```

## 三、⭐⭐ 区 II（大 n）：**把常规估计一个个算清** ✓（本文件的硬内容 ✓）

```
【把内部振荡写成干净形式 ✓】
   内部项 = 8n∫_0^{T₀'} main(t)·sin(nθ(t))/(4t²+1) dt ✓（边界已由受控终止消掉 ✓）
   即 ∫ e^{iφ(t)} g(t) dt ✓，其中 **φ(t) = nθ(t) ✓，g(t) = 8n·main(t)/(4t²+1) ≈ n·log t/(π t)** ✓
   相位导数 ✓：**φ'(t) = −4n/(4t²+1) ≈ −n/t²** ✓；**φ''(t) = 32nt/(4t²+1)²** ✓

【估计 1：一阶导估计（van der Corput I）✓】
   |∫e^{iφ}g| ≤ (2 sup|g| + ∫|g'|)/ min|φ'| ✓
   · sup|g| ≈ n·max(log t/t)/π = n/(πe) ≈ **0.117n** ✓
   · min|φ'| = |φ'(T₀)| ≈ n/T₀² ✓
   · ∫|g'| ≈ (n/π)∫|1−log t|/t²dt = O(n) ✓
   ⟹ **|∫| ≲ 0.234·T₀²** ✗
   【与 allowance 对比 ✓】allowance ≈ N ≈ T₀log T₀/(2π) ✓
   ⟹ 比值 ≈ **T₀/(2.7 log T₀)** ✗✗ ⟹ **一阶估计完全不够** ✗✓

【估计 2：二阶导估计（van der Corput II）✓】
   |∫e^{iφ}g| ≤ C·|φ''|^{-1/2}·(...) ✓，|φ''|^{-1/2} = (4t²+1)/√(32nt) ≈ **t^{3/2}/(4√2·√n)** ✓
   · 强振荡区（|φ''|^{-1/2} ≪ 1）⟺ t^{3/2} ≪ √n ⟺ **t ≪ n^{1/3}** ✓
   · 取 n = T₀²：n^{1/3} = **T₀^{2/3}** ✗ ⟹ **区间 [T₀^{2/3}, T₀] 落在"弱振荡"侧** ✗✗
   ⟹ **二阶估计在最要紧的区间【不适用】** ✗✓
   （根因 ✓：φ' ≈ n/t² ✓，在 t = T₀ 处只有 n/T₀² = **2** ✓ ⟹ **相位不够快** ✗）

【估计 3：为什么"振荡"在这条路上帮不了忙 ✓】
   ⚠️ **根因定位 ✓**：相位 φ(t) = 2n·arctan(1/(2t)) ✓ 在 t ~ T₀ 处**变化极慢** ✓
   （φ' ≈ 2 ✓ ⟹ 一个周期要跨 Δt ≈ π ✓ ⟹ 与零点间距（≈ 2π/log T ✓）相比仍算快 ✓
    但**与权重 1/t 的尺度相比就慢了** ✗）
   ⟹ **仅靠相位振荡无法把 O(T₀²) 压到 O(T₀log T₀)** ✗✓
```

## 四、⭐ 因此区 II 需要什么（结论 ✓）

```
**区 II 需要的不是"振荡界"，而是【内部项的渐近主项 + 定量误差】** ✓✓：
   内部项 ≈ −(n/2)(log n − 1 + γ − log 2π) + O(?) ✓（配合 main 项凑出 λ_n 的闭式 ✓）
   ⟹ **必须【评估】它，而不是【界】它** ✓✓（Oesterlé 正是这么做的 ✓：换元 nθ = t ✓ ⟹ 闭式 ✓）
   ⟹ 缺口 = **那条鞍点评估的【误差项】** ✓（Voros 的 o(n) ✓ 要变成定量 ✓）
⟹ ⭐ **两区制论证的净产出 ✓**：
   ① 区 I 归结为一个**弱计数问题** ✓（"至少 ε 比例未对齐" ✓）—— 可能可攻 ✓
   ② 区 II **不能靠振荡估计** ✗（三个估计都算清了 ✓，都失败 ✓）
      —— 它归结为**鞍点渐近的定量误差** ✓，即**同一个已知缺口** ✓
```
