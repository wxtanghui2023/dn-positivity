$$\text{正性}\ \Longleftarrow\ \text{(a) 紧致性/几何}\quad\text{或}\quad\text{(b) 有限性}\quad\text{或}\quad\text{(c) 阈值型（平滑/极限）}$$
```

```
$$\boxed{\text{(c) 已死；(a) 在 char 0 无对象 ⟹ 唯一可能 = (b) 一个 char 0 的【有限性】}}$$
