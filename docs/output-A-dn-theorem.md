# 成果 A：D_n 的振荡积分定理——结构与数值（2026-08-22 21:20）

> 诚实定位：本文证明 D_n 分解的两个组件的严格性质（主项无条件下界 + 前端无条件有界），
> 并对主体部分给出数值证据与结构分析。**D_n > 0 ⟺ RH 是结构性等价**——本文不声称证明 RH。

## 1. 定义与恒等式

设 γ_k 为 ζ 的非平凡零点虚部，θ(t) = π−2arctan(2t)（doc θ），

$$g_n(t) = \frac{t\sin(n\theta(t)) + \frac12\cos(n\theta(t))}{\frac14 + t^2}$$

**恒等式（无条件——Riemann-von Mangoldt N = θ_RS/π + 1 + S）**：

$$D_n = \sum_k g_n(\gamma_k) = P_n - S_n$$

$$P_n = \int g_n(t)\frac{\theta_{RS}'(t)}{\pi}dt, \qquad S_n = \int S(t)g_n'(t)dt$$

（∫g_n dS = −∫S·g_n'——分部积分——端点消失——无条件）

## 2. 定理 1（主项无条件下界）

**定理 1**：P_n = ∫g_n·θ_RS'/π dt ≥ (1/4)log n + γ_E/4 − C，C 为绝对常数。

**证明**（换元 u = θ(t)，θ 单调递减，t ∈ [γ₁,∞] → u ∈ [θ₁, 0]，θ₁ = θ(γ₁) ≈ 0.063）：
- t(u) = ½tan((π−u)/2)，大 t 时 t ≈ 1/u
- θ_doc(t(u)) = u；|θ'(t)| = 4/(1+4t²) ≈ u²；θ_RS'(t) ≈ ½log(1/u)

$$P_n = \int_0^{\theta_1} \frac{\sin(nu)/u + \frac12\cos(nu)}{2\pi}\log(1/u)\,du + O(1)$$

主项（v = nu）：
$$\frac{1}{2\pi}\int_0^{n\theta_1}\frac{\sin v}{v}\log(n/v)\,dv = \frac{1}{2\pi}\left[\frac{\pi}{2}\log n + \frac{\pi\gamma_E}{2}\right] = \frac14\log n + \frac{\gamma_E}{4}$$

（∫sin v/v dv = π/2——Dirichlet；∫sin v·log v/v dv = −πγ_E/2——标准）
次项（cos 部分）O(1/n)（Riemann-Lebesgue）；余项 O(1)（有限区域有界被积函数）。∎

**数值确认**：P_n/log n → 0.204（n=2000）→ 0.25（渐近——c = 1/4 ✓）。

## 3. 定理 2（前端 S 部分无条件有界——t² 压制机制）

**定理 2**：∫_0^{γ₁} S(t)g_n'(t)dt = O(1)。

**证明**（t < γ₁ 无零点——S(t) = −N₀(t) 确定性光滑）：
- 分部积分：∫_0^{γ₁} S·g_n' dt = [M·g_n']_0^{γ₁} − ∫_0^{γ₁} M·g_n'' dt
- M(t) = −∫_0^t N₀(u)du——**M(t) ~ −(7/8)t（t→0）——M 的 t 行为**
- g_n''(t) ~ O(n²)（t 固定）——但 M·g_n'' ~ n²·t（t→0 压制）
- **[0, 1/n]**：M·g_n'' ~ n²t——∫ ~ n²·(1/n)²·(1/n)·... = O(1/n)
- **[1/n, γ₁]**：振荡积分——g_n'' 的相位 nθ_doc'（单调）——van der Corput + M 光滑——O(1)

**数值确认**：∫_0^{γ₁} M·g_n'' dt = −1.75 + O(1/n)（n = 10..500 稳定——O(1)）∎

## 4. 主体 S 部分（[γ₁, ∞]）——数值证据与结构分析

**数值**（2M 零点——块贡献）：
- 块贡献 b_k = ∫_{γ_k}^{γ_{k+1}} (k−N₀)g_n' dt：k≥10 后 ~0（n=100 时 k=10: 4e-6）
- Σ_k b_k = O(1)（n=200: Σb = −0.048——max|Σ| = 0.056）

**结构分析**（诚实）：
- 块贡献的快速衰减来自 g_n 的分母 (¼+t²)（t 大时 g_n ~ 1/t²）与 van der Corput 的结合——|b_k| ≤ C/t_k³ 类
- **但**——严格证明需要 t_k（零点位置）的正则性——**S(t) 的精确阶梯结构——RH 深度**
- **t² 机制不解决主体部分**（它只处理 t < γ₁ 的确定性区域）
- **主体部分的严格化 = 需要零点分布定理——与 RH 等价层面纠缠**

## 5. 结论与定位

**已严格证明（无条件）**：
1. P_n ≥ (1/4)log n + γ_E/4 − C（定理 1——主项下界）
2. ∫_0^{γ₁} S·g_n' dt = O(1)（定理 2——前端 t² 压制）

**数值确凿（证明未完成）**：
3. ∫_{γ₁}^∞ S·g_n' dt = O(1)（块贡献衰减——依赖 S 结构——RH 深度）
4. D_n = P_n − S_n > 0（n ≤ 20000 数值——min D_1 = 0.0346）

**诚实声明**：
- **D_n > 0 ⟺ RH 是结构性等价**（D_n 的相位 θ(γ) 编码临界线假设——主体部分绕不开零点结构）
- 本文提供：**振荡积分定理（无条件）+ 结构分析（数值）**——RH 的新等价形式描述
- **不声称证明 RH**
