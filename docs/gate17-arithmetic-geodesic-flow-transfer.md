**日期**：2026-09-10 ｜ 承接 `3f896ac` ｜ 结果：触发止损；且止损的**结构性原因**是新发现（GL(1)/Sym² 平凡化）

## 0. 先把 Selberg 1/4 拆到最小结构

```
(a) 自对偶参数化：Δ y^s = s(1−s) y^s  ⟹ λ = s(1−s)，自对偶点 s=1/2 ⟹ λ=1/4
(b) 正性：−Δ 在 L² 上自伴且非负 ⟹ λ ≥ 0（只给 λ≥0，不给 λ≥1/4）
(c) 谱定理：λ 参数化自动对称；唯一障碍是【例外/非 tempered 模式】(λ<1/4, s=1/2+iσ)
(d) 排除例外模式需要【算术输入】
```
$$\boxed{\text{真正的 }\tfrac14\text{ 不是来自几何正性 (b)，而是来自 (a)+(c)+算术输入 (d)}}$$

## 1. ⭐ 关键对应（精确且标准）
```
例外特征值 λ<1/4 (非 tempered)  ⟺  Siegel 零点（β 接近 1 的实零点）
Selberg 1/4 猜想                ⟺  "无 Siegel 零点 / tempered 性"
已知两侧结果同型：
   λ₁ ≥ 975/4096 (Kim–Sarnak 2003)   ⟺   β ≥ 1 − c/log q（经典无零点区）
⟹ 两侧都只到"λ≥0 型"（无零点区），"λ≥1/4 强度"= RH 强度
```

## 3. ⭐⭐ 止损的结构性原因（本轮新发现）

**自守侧的 F4 并不是"几何正性"，而是算术输入：**
```
Kim–Sarnak 975/4096 的引擎 = Kuznetsov 迹公式 + 【Sym² 函子性（Langlands）】
⟹ 排除非 tempered 模式靠的是【高阶对称幂提升】，不是几何
```

**而 ζ 是 GL(1) 的 L 函数（平凡特征的）**：
$$\boxed{\operatorname{Sym}^2(\text{GL}(1)\ \text{平凡特征})=\text{平凡}\ \Longrightarrow\ \text{引擎在 }\zeta\text{ 上【平凡化】}}$$
$$\boxed{\text{⟹ 自守侧"1/4 机制"的全部动力（Sym}^2\text{ 函子性）对 }\zeta\text{ 【自动消失】}}$$

这解释了为什么该机制从未自然触及 ζ ——**不是"还没搬过去"，而是它在 GL(1) 上根本无内容**。

## 4. 止损判定
```
① ζ 侧"流"的语言实现 = 显式公式（Connes 迹公式）      ⟹ 触发止损第一条 ✓
② 更深层：引擎（Sym² 函子性）在 GL(1) 平凡化           ⟹ 结构性止损 ✓
⟹ 第⑰关【关闭】（Transfer 不可实现）
```
