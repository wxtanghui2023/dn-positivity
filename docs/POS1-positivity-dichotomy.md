## §0 【核验】经典 PNT 正性恒等式（校准先过）
$$\boxed{3+4\cos t+\cos 2t=2(1+\cos t)^2\ \ge 0\qquad\text{等号}\iff \cos t=-1\iff t\equiv\pi}$$
```
数值核验：在 [-3π,3π] 上最小值 = 0.000e+00，取于 t = -3π（≡ π mod 2π）✓
作用：1 + 2cos t = Re(1 + 2e^{it})，乘正因子 (1+cos t) 得上式 ⟹ 控制 1/|ζ(s)| 在 σ≈1 的行为
     ⟹ 给出经典无零点区域（Vinogradov–Korobov）✓
```

## §1 ⭐⭐ 由该实例推出的**一般二分**（本轮核心）
设某正性方法的型 $P\ge0$ 定义在配置空间上，其**消失轨迹**决定它能排除什么：
| $P$ 的消失轨迹 | 后果 | 判定 |
|---|---|---|
| **消失太多**（含所有配置，$P\equiv0$） | 无信息（vacuous） | ✗ 不足 |
| **消失太少**（处处严格，$P>0$） | 只能给回避型区域，**不能排除个体** | ✗ 不足 |
| **恰好消失在【离临界配置】上** | 给出 RH | ⟹ **等价于 RH**，不是"方法" ✗ |
$$\boxed{\text{故：正性方法【不存在"更好的"】：sharp 且非空 ⟺ RH 等价}}$$
```
推论：任何"找一个更强的正性形式"的希望被【类级别地】排除 ✓（这是收窄，不是新死路）
```

## §2 经典实例正是该机制的展示（解释了为何余量非一致）
```
de la Vallée Poussin 正性在 t ≡ π 处【恰好为零】⟹ 其"可达距离"被消失轨迹限制
⟹ 所得无零点区域的余量 c/(log t)^{2/3}(log log t)^{1/3} 随 t 收缩但【永远不一致】✓
⟹ 这正是"无余量/临界"现象【在经典技术中的具体形态】✓
```
