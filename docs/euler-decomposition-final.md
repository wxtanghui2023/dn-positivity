## 1. 决定性验证：z_k（k≥1）唯一确定

**复值 log ζ 与 log|ζ| 的系数对比**（s=0 附近数值微分）：

| k | 复值实部 | 复值虚部 | log\|ζ\| |
|---|---|---|---|
| 0 | −0.691 | **iπ** | −0.691 |
| 1 | +1.8385 | 0 | +1.8385 |
| 2 | +0.3186 | 0 | +0.3186 |
| 3 | +0.3844 | 0 | +0.3844 |

**结论**：log ζ(s) = log|ζ(s)| + iπ（虚部常数）→ **k≥1 的导数虚部贡献为 0** → **z_k（k≥1）唯一确定**（= log|ζ| 系数，不依赖分支）！

## 2. 符号矛盾的解决

- λ^{logζ}(1) = −z₁ = −1.84（若 λ^{logζ} = ΣC(n,k)(−1)^k k z_k）
- 独立计算的 +1.84 用了**相反的符号约定**（λ^{logζ} = −Σ 或 Σ(−1)^{k+1}）
- **不是数学矛盾**，是**约定差异**

## 4. Euler 积路径最终结论

1. **围道法**：假象（平凡零点在圆内，log ζ 有奇点）——废弃
2. **符号结构**（λ^{logζ} 正/负）：约定依赖，非唯一事实——不成立为"结构发现"
3. **唯一可靠**：z_k 唯一 + 大数抵消
4. **无证明路径**：抵消是恒等式，不提供可证明不等式
5. **Knessl-Coffey 正确**（Sγ(n) 亚线性，非指数）

**Euler 积路径彻底关闭**（无可挖的新结构）。

## 5. 方法论教训（重要）

1. **围道积分对 log ζ 在 s=0 不可靠**（平凡零点 −2,−4 在圆内）
2. **数值微分（实轴，ζ 无极点处）可靠**
3. **复值 vs 实值 log 的系数**：k≥1 相同（虚部常数），k=0 不同（分支）
4. **符号约定必须明确**（λ^{logζ} 的 ±Σ 是人为的）
5. **验证锚点**：z₁ = ζ'(0)/ζ(0) = +1.84（解析）
6. **"结构发现"必须独立于约定**（大数抵消是唯一约定无关的）
