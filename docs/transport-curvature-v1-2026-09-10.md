# 算术运输曲率 v1 审计（2026-09-10）

## 模型
状态 S=(a,b,c), a+b=c
- A-运输：T_A(a,b,c) = (b, c, b+c)（Euclid/Fibonacci 加法移位，保关系）
- M-运输：T_M(S) = u(S)·S, u(S)=rad(c)（状态依赖标量，保关系）
- 曲率：Ω(S) = log[ W(T_M T_A S)·W(S) / ( W(T_A S)·W(T_M S) ) ]

## 结构定理（关键）
T_A 与 T_M 的两条路径端点：
  SAM = T_M∘T_A(S) = rad(b+c)·(b, c, b+c)
  SMA = T_A∘T_M(S) = rad(c)·(b, c, b+c)
⟹ **两者必在同一条射线上**（分量比完全相同）
⟹ 曲率【只能】是"标量因子失配"的读数，即 rad 比类数据

更一般地：若 T_M 保关系 a+b=c 且逐分量乘法作用，
则 f(a)+f(b)=f(c) 对一切 a+b=c 成立 ⟹ Cauchy ⟹ f(n)=un
⟹ 保关系空间的 M-运输【必然是状态依赖标量缩放】

## 自我修正
我原先预测"形状不变权 ⟹ Ω≡0"。**该预测错误**：W1=rad(abc)/(abc) 并非射线不变
（rad(λx)/(λx) ≠ rad(x)/x）。真正的射线不变权需取原始三元组 (a,b,c)/gcd。
BUT 该修正不改变结论：射线重合已由 SAM/SMA 的分量比证明。

## 构造性出路（v2 提案，尚未实施）
要绕开"射线重合"，M-运输必须【不是】标量 ⟹ 状态必须丰富到
乘法作用无法被标量化。自然候选：**赋值/进位态**
  - 状态 = 赋值向量 (v_p(a), v_p(b), v_p(c))_p
  - 关键：a+b=c 在赋值坐标下是【非线性】的（进位！）
  - 于是乘法运输（赋值平移）与加法进位动力学可以【非标量】地不交换
  ⟹ 这才是"加法×乘法同处一个状态转移"的真正非交换实现（Kummer/进位结构）
  ⟹ 同一套三判据可施：Ω≢0？可持续？不可约化？
