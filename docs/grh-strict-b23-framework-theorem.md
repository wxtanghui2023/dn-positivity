## b2：假设的形式化（"RH 成立"在框架内的含义——）

框架内——RH 的判据表述：D_ζ = 0——其中 D_ζ = Q_ζ − Q'_RH,ζ = ΣP_γ(δ_ρ)（ζ 的零点——）。
"假设 RH 成立"在框架内 = 假设 D_ζ = 0（ζ 的判据闭合——）。

【关键区分】两种"假设 RH"：
- (i) 假设 D_ζ = 0 作为【事实】（结果——）——不提供方法
- (ii) 假设存在【纯结构的判据闭合论证】证明 D_ζ = 0（方法——）

(i) 不给 GRH（b1.5——RH⊂GRH——事实不传递——）

## b3：框架定理（正式陈述——含条件——）

**定理 B（判据闭合的传递——条件形式——）**：
设 C 是"判据闭合的纯结构论证"（即——只使用 a1-a5 的机制——
FE 配对/Hadamard/计数/P_γ 代数——不使用 ζ 的算术特殊性——）——
且 C 证明 D_ζ = 0（RH——）。则 C 自动证明 D_χ = 0 对所有原字符 χ（GRH——）。

**证明**：C 的每一步（a1-a5——）对 ζ 和任意 χ 逐字成立——
（a1 轨道封闭性——一般字符已证——a2-a5 不依赖 ζ/χ——）
——C 的唯一输入是判据的通用结构——C 证明的 D=0 对任何满足
该结构的零点配置成立——χ 的配置满足（a1-a5——）——C 适用——∎

**推论 B'（框架统一——）**：
判据机制（P_γ——）把 RH 和 GRH 统一为【单一判据闭合问题】：
- RH = 该问题的 ζ 实例——GRH = 所有 χ 实例

  同时证明或同时不证明（——同一论证——）
