## §2 ⭐⭐⭐⭐ **我们的路线（3 步，全初等 ✓）**
```

      **x^{k/2} + x^{−k/2} − 2 = (x^{k/4} − x^{−k/4})² ≥ 0** ✓✓（**恒非负** ✓）
【步 2·单调性】F(x) := x^{k/2} + x^{−k/2} − 2 在 **x > 1** 上**严格递增** ✓
```
