# M(T) 机制完整图景（2026-09-09 构造+验证——）

## 核心定理候选（数值支持——）
M(T) = S₁(T) = ∫₀^T S(t)dt = ∫S̄ dt（区间平均版——）
S̄（零点区间平均 S——）= S 的"平滑部分"——几乎周期可展开：
  S̄(t) = −(1/π)Σ_p Σ_k c_{p,k}(t)·sin(k log p · t)（R² 0.997——）
展开的积分：
  M(T) ≈ −(1/π)Σ_{p,k} (1/(k p^{k/2}))·w_{p,k}(T)·(1−cos(kT log p))/(k log p)
——每项有界——Σ 收敛（1/(k p^{k/2} log p)——）——M(T) 有界——
