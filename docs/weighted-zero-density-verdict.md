# 加权 zero-density 深入判断：W^{(P)} 不比均匀 N(σ,T) 强（推论关系）

> 2026-09-02 20:18 · (a) 深入判断 · 诚实结论：加权是 N 的推论——非新机制

## 核心问题：W^{(P)}(σ,T) = Σ_{γ≤T,β>σ}P_γ(δ) 是否比 N(σ,T) 更有信息？

## 分析

### 1. 信息等价性（对象层）
- N(σ,T) 对**所有 σ** 的知识 = β 的完整累积分布（计数函数）
- W^{(P)} = ΣP_γ(δ) = ∫P(β−½) dN(β)（Stieltjes——对 β 分布加权）
- **从 N(σ,·)（σ 全知）可算 W^{(P)}**（分部积分）——W^{(P)} 不含 N 之外的信息
- ⟹ **加权 zero-density 作为"对象"不新**（同一 β 分布——不同加权）

### 2. 上界推论关系（定理层）
- zero-density 给 N(σ,T) ≤ C·T^{c(σ)}（每个 σ 的上界）
- W^{(P)} 的上界 = Σ_层 (σ−½)²·ΔN(σ,T)·(γ⁻⁴ 因子)（分层——从 N 推）
- **W^{(P)} 的界是 N 的界的推论——不会比 N 更好**（除非有独立方法——无）

### 3. ⚠️ 良定义性简化（重要修正）
- P_γ ~ δ²/γ⁴——γ⁻⁴ 权重极强——**高 γ 贡献自动小**
- D 的收敛只需 Σ_{β>½}1/γ⁴ < ∞——**RvM（N(T) ~ T logT——远小于 T⁴）就够**——不需要 Ingham zero-density！
- ⟹ 我之前"良定义性经 Ingham"是**过度设计**——RvM 即够（γ⁻⁴ 权重自压）
- **D 无条件收敛（良定义）——RvM 证明——更简单**

### 4. GM 技术迁移判断
- GM 改进 N(σ,T)（½≤σ≤¾——30/13）——迁移到 W^{(P)}——经分层——**改进传递但 W^{(P)} 的 γ⁻⁴ 权重使高 γ 已小——GM 的改进主要影响高 γ 区（大 T）——而 W^{(P)} 高 γ 权重 γ⁻⁴ 已压制——GM 对 W^{(P)} 的改进被权重"稀释"——收益小**
- **GM 技术迁移到加权版：低收益**（权重已压制 GM 改进的区域）

## 诚实结论
**加权 zero-density（W^{(P)}）不提供超越均匀 zero-density 的新信息/新机制**：
1. 对象层：同一 β 分布（不同加权——非新）
2. 定理层：N 的界 → W^{(P)} 的界（推论——不会更好）
3. 良定义性：RvM 即够（γ⁻⁴ 自压——不需 Ingham）
4. GM 迁移：低收益（权重稀释 GM 改进）
- **"文献未见"≠"有深度"**——是"新但浅"（标准定理的加权推论）
