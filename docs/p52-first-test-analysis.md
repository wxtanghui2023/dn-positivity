# P52 第一测试：Global Object 构造——概念分析

> 2026-09-02 19:30 · 逃逸在系数层 · global test 的精确/近似二分 · 三类机制诚实评估

## 1. Global object 的定义空间
"Global object" = 满足全部约束的完整零点配置 W：
- FE（ξ(s)=ξ(1−s)——允许离轴轨道对——P42/47：FE 不排除离轴四重奏——已证）
- 共轭（ρ̄ 也在——自动）
- Hadamard（任意配置给整函数——收敛条件——RvM 密度）
- Euler 积（Dirichlet 系数 a_{p^k} = log p——von Mangoldt——逐项精确）
- 显式公式（ψ_W 匹配 ψ_prime）

## 2. ⚠️ 系数层 vs ψ 层（逃逸是否也成功）
- **ψ 层（积分匹配）**：逃逸零点（γ_T 大）贡献 ~ x^{½+δ}/γ_T——处处小——匹配保持（P51-T4 已证）
- **系数层（von Mangoldt 逐项）**：a_n 是 ψ 的差分——逃逸零点对 a_n 的贡献同样 ~ n^{½+δ}/γ_T·振荡（对固定 n——γ_T→∞——偏离→0）——**低 n 系数 = Λ(n)（几乎）——高 n（n ~ e^{γ_T} 尺度？）偏离**
- **⚠️ 系数层逃逸同 ψ 层**（von Mangoldt = ψ 的差分——无新约束）——逃逸零点在"可观察系数"（任何有限 n）偏离 → 0

## 3. Global test 的精确/近似二分
- **精确版**（系数逐项 = Λ(n)——所有 n——含 n → ∞）：离轴 W 的 ξ_W 的 Dirichlet 系数**必在某 n 偏离**（Mellin 反演——零点决定系数——W≠W_RH ⟹ 系数偏离）——**但——检验"所有 n"需要无限信息——且"精确匹配 ⟹ W = W_RH"是 RH 本身（循环）**
- **近似版**（系数匹配到有限 n——逃逸）：可行（偏离 → 0）
- **⚠️ 中间带**：是否存在"精确匹配到所有有限 n 但零点离轴"的对象？——Mellin 反演的连续性——如果系数全 = Λ(n)（所有有限 n）——ψ 全匹配——显式公式唯一性 ⟹ W = W_RH？——**需要显式公式的唯一性定理（给定 ψ 全谱——零点唯一——Hadamard 乘积的唯一性——是标准的——但——ψ 全匹配 ⟹ W = W_RH 依赖"ψ 决定零点"——反演的唯一性——成立（Mellin 反演）——但——这是"ψ 精确匹配"的版本——离轴 W 的 ψ_W ≠ ψ_prime（精确——处处）——所以精确 global test 平凡排除离轴——循环**

## 4. 诚实评估：三类机制的先验障碍
| 机制 | 障碍 |

## 5. 核心判断
- **global test 的两端都被封**：精确版循环（ψ 全匹配 ⟹ W 唯一——平凡）——近似版逃逸（有限观察偏离 → 0）
- **"离轴在 global realization level 不存在"的证明** = 精确匹配的唯一性（标准——但只给"ψ 匹配的对象唯一"——不含"该唯一对象在线"——那是 RH）
- **三类机制（A/B/C）先验都有障碍**——A/B 已被 P47/P48 部分排除——C 无自然测度
- **⭐ 唯一未封的口**：唐先生的"母对象"（spectral defect ↔ prime correlation defect 同时产生者）——如果存在——P_γ 只是它的谱侧投影——prime correlation（C₂——孪生/哥德巴赫）是另一投影——**母对象的存在性本身是新的数学问题**（可能比 RH 更基本——但也可能只是重述）
