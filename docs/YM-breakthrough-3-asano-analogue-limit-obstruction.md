## §1 【推导】Asano 收缩的算术对应物已经存在：**截断 / 平衡项**
```

算术侧的对应物：

  "对齐项" = 平衡范围  n ≈ t/n  ⟺  n ≤ sqrt(t/2π)  ✓✓
  "混合项" = 超出平衡范围的尾部 ⟹ 在 Riemann–Siegel 公式里正是【修正项】✓
  ⟹ **算术 Asano 收缩 = Riemann–Siegel / Pólya 型截断**（保留平衡项、丢弃混合项）✓✓
```
$$\boxed{\text{算术 Asano 收缩} = \text{截断到"平衡项"（RS/Pólya 近似）}}$$
