# 框架判据良定义性：D 的无条件收敛（经 zero-density——文献锚定）

> 2026-09-02 20:08 · "继续"产出 · 加权 zero-density 探索第一轮

## 1. 加权 zero-density 的新颖性确认（文献检索）
- 标准 zero-density：N(σ,T)（均匀计数——Ingham/Halász/Huxley/Guth-Maynard 2024）
- **带权重（1/γ⁴ 或 P_γ(δ)——δ 依赖）的 zero-density：文献未见**——可能新
- Tao 框架：RH ⟺ sup(β 相关量) = 0——Density ⟺ sup ≤ 2——与我们的 D（加权和）同层但不同（sup vs 加权和）

## 2. ⭐ 判据良定义性定理（D 无条件收敛——文献锚定）

**命题**：对任何满足函数方程 + 收敛条件的零点配置 W（含离轴——δ_ρ = β_ρ − ½ ∈ (−½, ½)）：
**D(W) = Σ_ρ P_γ(δ_ρ) 无条件收敛**（有限——不需 RH）

**证明草图**（经 zero-density——Ingham）：
1. P_γ(δ) = δ²M₂/(2U²D₊D₋)——γ 大时 ~ C(δ)·δ²/γ⁴（P_γ ~ γ⁻⁴——P51-T4 数值确认）
2. 分层：Σ_ρ P_γ(δ_ρ) ≤ Σ_σ 层 (σ−½)²·(贡献 of β_ρ ∈ [σ, σ+dσ))
3. 零点在 β ≥ σ 的计数 N(σ,T)——**Ingham zero-density**：N(σ,T) = O(T^{3(1−σ)/(2−σ)+ε})（无条件——σ ≥ ¾）——或 Huxley/GM 改进
4. 对 σ > ½ + ε：N(σ,T) = O(T^{c(σ)})——c(σ) < 4（对 σ > ½——Ingham 指数 3(1−σ)/(2−σ) < 3 < 4 当 σ > ½）——**远小于 4**
5. Σ_{β>σ}1/γ⁴ 的尾部：Stieltjes ∫_T^∞ (1/u⁴)dN(σ,u) ~ N(σ,T)/T⁴ + ∫N(σ,u)/u⁵du——N(σ,u) = O(u^{c})——c<4——∫u^{c−5}du 收敛（c−5<−1）✓
6. 分层求和（σ 从 ½+ 到 1——δ 从 0 到 ½——P_γ ~ δ²/γ⁴——δ² ≤ ¼）⟹ D(W) ≤ C·Σ_层 < ∞
**∎ D 无条件良定义**（收敛——有限——对任何合法配置）

**推论**：
- D(W) 对离轴配置有定义（有限——非 ∞）——**判据不是"仅在线有定义"**——对 RH 假的情况也可评估
- **但——D 收敛（有限）不排除离轴**（稀疏高零点离轴——γ⁻⁴ 和有限——允许——与 P51-T4 逃逸一致）——**D < ∞ 无条件——D = 0 是 RH（强条件）**

## 3. 框架-文献锚定的意义
- **我们的 D（判据）不是孤立构造**——它的收敛性依赖标准的 zero-density 定理（Ingham——1940）——**框架的"良定义性"有文献基础**
- **反向**：我们的 P_γ 加权（δ²/γ⁴——δ 依赖）给 zero-density 一个"加权"推广（W^{(w)}(σ,T) = Σ_{β>σ,γ≤T}P_γ(β−½)）——**文献未见——可能是框架贡献给 GM 前沿的问题**
- D 的"集体界"（D_T = O(1)——无需 0）与 Density hypothesis（sup ≤ 2）同层——**框架的"可实现中间目标"**

## 4. 加权 zero-density 的候选问题（如果继续）
**定义**：W^{(P)}(σ,T) = Σ_{γ≤T, β_γ>σ} P_γ(β_γ − ½)——"P_γ 加权离轴计数"
**问题**：
- W^{(P)}(σ,T) 的无条件上界？（σ > ½——用 zero-density + P_γ ~ δ²/γ⁴——分层）
- W^{(P)}(½, T) = D_T（全离轴加权和——若 D_T = O(1)——"集体准在线"）
- **GM 的 Fourier 技术能否给 W^{(P)} 更好的界**（比均匀 zero-density 迁移的更优——因为权重压低高 γ）
