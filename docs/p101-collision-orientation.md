## P10 框架（唐先生）
**从静态约束转向零点产生/消灭的拓扑过程**：
- P5-P9：问"坏的零点配置能不能存在？"
- P10：问"**坏的零点配置能不能从已知全实零点区域连续地产生？**"
- de Bruijn-Newman flow：H_λ(z) = ∫Φ(u)e^{λu²}cos(zu)du——天然连续参数 + 已知全实区域（λ > ¼）+ double-zero 事件
- **非实零点产生必须经过 double-zero**：H = H_z = 0

## P10.1 推导（决定性）
### heat 方程结构
∂_λH_λ = −∂_z²H_λ（数学恒等——数值误差 2.03 是积分精度——非结构问题）

### Collision Orientation Lemma
在 double-zero（H = H_z = 0——H_zz ≠ 0）：
- H(λ₀+Δλ, x) ≈ H_λ·Δλ + ½H_xx·(x−x₀)² + ...
- **Q = H_λ·H_xx = −H_λ² ≤ 0（恒——heat 方程 H_xx = −H_λ）**
- 根分裂：(x−x₀)² = 2Δλ（主导——交叉项 0 时）
- **实根需要 Δλ > 0——λ 减小（Δλ < 0）⟹ 复根（complexification）**

### ⭐ 关键判定
**Collision Orientation（Q = −H_λ² < 0）——平凡成立（heat 恒）**——但——**给"分裂方向"（λ 减小 ⟹ 复）——不是"禁止碰撞"**——反而**精确描述 RH 假时的机制**（Λ > 0 处碰撞——λ 减小——复根——离轴零点出现）

## 循环检查（核心）
- **"RH ⟺ H_λ 在 λ ≥ 0 无 double-zero"——等价（de Bruijn-Newman——Λ ≤ 0——循环）**
- **"无碰撞"从 theta-kernel 独立可证？**——H_λ = H_λ' = 0 无解（λ ≥ 0）——积分方程无解性——**从 Φ 的结构？**
  - ⚠️ **Φ 变号（P9.2 确认）——"theta-kernel 正性"不适用——无正性可用**
  - **"无碰撞"是零点性质（含零点信息）——需要零点信息——循环**

## P10.1 判定（初步）
- **Q < 0（heat 恒）——新的结构发现**（complexification 的精确机制——一旦碰撞——λ 减小方向必然复化——描述 RH 假的过程——不是排除）
- **"无碰撞在 λ ≥ 0"——等价 RH（循环）**——且——**从 theta-kernel 独立可证希望渺茫**（Φ 变号——无正性——"无碰撞"需要零点信息——循环）
- **P10 与 P5-P9 相同的墙（初步）**——但——**"碰撞方向"（Q = −H_λ²）是新的**（记录）

## 有价值的新对象（记录）
**Q = H_λ·H_xx = −H_λ²（在 double-zero——heat 恒）**——**碰撞方向性**：de Bruijn-Newman 流中——double-zero 一旦发生——λ 减小方向必然产生复根（complexification）——这是"RH 假 ⟹ 离轴零点如何出现"的精确机制（不是排除——但精确）
