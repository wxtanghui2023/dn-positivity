# ρ₁ 解析路径 + 超 GUE 确认（2026-08-23 22:10）

## 1. ⭐ ρ₁ 的解析公式（精确——S 自协方差）

```
ρ₁ = (2γ(1)−γ(0)−γ(2))/(2γ(0)−2γ(1))
数值验证：公式 −0.3504 vs 直接 −0.3513（差 0.0009——精确 ✓）
S 自协方差：γ(0)=0.1074  γ(1)=0.0249  γ(2)=0.0002（γ(2)≈0——近 AR(1)）
φ = γ(1)/γ(0) = 0.2319（S 的 AR(1) 系数）
```

**意义**：ρ₁ 完全由 S 的自协方差决定——**S 的两点矩（Selberg/Tsang——无条件）是解析基础**

## 2. ⭐ 超 GUE 确认（ζ 排斥比 GUE 强）

```
ρ₁：ζ −0.351 vs GUE −0.297（强 18%）
γ(0)：ζ 0.107 vs Selberg 预测 0.133（近似）
→ ζ 的相邻排斥更强——素数来源（非 Vandermonde）
```

## 3. γ(1) 素数项推导（方向对——技术难）

```
S(t) ≈ −(1/π)Σ_p sin(t log p)/(√p log p)——Titchmarsh
γ(1) ≈ (1/π²)Σ_p cos(log p·Δγ)⟨sin²⟩/(p log²p)
预测 0.064 vs 实测 0.022（量级对——差 2.9 倍）
⟨cos(log p·Δγ)⟩：p=2 接近——p=11 符号反——需 Δγ 完整分布
→ 需要零点间距分布（本身是目标——循环）——或 Selberg 两点矩的精细渐近
```

## 5. 结论

1. **ρ₁ 公式精确**（S 自协方差——解析可表达——Selberg 矩是基础）
