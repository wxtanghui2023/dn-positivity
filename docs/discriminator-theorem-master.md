## Lemma A —— 核矩消去与交换（墙 A）🟢 核心闭合

**内容**：Q'_zeros = Σ_ρ w_H(γ_ρ, |δ_ρ|)——逐项配对与交换。

**核心结构**（Q_λ 缩放）：
$$M_2 = \delta\int y^2 Q_{\eta/\delta}(y)\,dy,\qquad |M_2| \le C\delta$$

- Q_λ(y) = 中心差(y,λ)/λ² − K₁(y)——sup_{λ<½}∫y²|Q_λ|dy < ∞（数值 0.12——解析骨架）
- 远场：Q_λ ~ −λ²/(2y⁴)——λ 一致可积——近场：Q_λ → 0（紧致一致——Taylor）——中间：连续覆盖
- 矩消去：M₀ = 0（∫E = 0——精确）——M₁ = 0（偶性）
- 交换：Σ_ρ δ_ρ|H''(γ_ρ)| ≤ ½Σ_ρ|H''(γ_ρ)| < ∞（H'' ~ γ^{−2}——Σγ^{−2} < ∞）
- 零频：Ŝ_zeros(ω) = O(ω)——Ĥ_0 ~ 1/|ω|——乘积 O(1)（结构性）

**剩余**：远场余项严格界——近场 Taylor 一致估计（sup_{λ<½}∫y²|Q_λ|dy < ∞ 的纯解析证明）

## Lemma B —— 统一 Weil 测试函数（墙 B）🟢 核心障碍解除

**内容**：H_0 统一（不依赖零点）——判别量 = 统一配对 Q' = ⟨S,H_0⟩。

**核心结构**：
$$H_0 = \mathcal F^{-1}\left[\frac{\widehat w_{\rm target}}{\widehat K_0}\right],\qquad \widehat K_0(\omega) = -\pi|\omega|$$

- **H_0 不依赖 ρ, γ, δ**——Q' = ⟨S,H_0⟩ = Σ_ρ⟨K_ρ,H_0⟩（统一——非 Σ⟨K_ρ,H_ρ⟩）
- 逐项权重：w_H(γ,δ) = ⟨K_δ(·−γ), H_0⟩——墙 A 控制
- 素数项：数值确认 + 条件满足方向（|Ĥ_0(ξ)| ≤ C_N(1+|ξ|)^{−N}——标准 Weil 条件）
- H_0 ∈ C^∞ ∩ S′——**待提升到明确 Weil 测试空间 W**

**剩余**：明确 Weil 测试空间（Schwartz 型/Barner-Weil/tempered 扩展）——写出适用显式公式

## Lemma C —— 正性与等号刚性（墙 C）🟢 核心机制

**内容**：Q'_zeros = Q'_RH 的等号条件——正性结构。

**核心结构**：
$$Q'_{\rm RH} - Q'_{\rm zeros} = \sum_\rho \delta_\rho^2\, w_H(\gamma_\rho, |\delta_\rho|)$$

- **w_H(γ,|δ|) > 0（恒正——L5——γ≥14——解析证明 N(x)——∂N/∂x > 0）**
- RH ⇒ 等号：δ=0——w_H(γ,0) = w_target——Q'_zeros = Q'_RH
- 等号 ⇒ RH：Σδ²w_H = 0——w_H > 0——正项和——每项 δ_ρ = 0——RH

**剩余**：墙 A/B 正式化完成后——等号方向完整落笔（逻辑结构已就绪）
