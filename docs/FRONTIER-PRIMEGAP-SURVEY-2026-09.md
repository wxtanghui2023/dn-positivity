## 0. 三句话结论

```
① 两条猜想都**未解决** ✓；已知最强工具都**朝同一方向**："**零点 ⟹ 素数**" ✓（显式公式 + 零密度 + 筛法 ✓）
   而我们要的是**反向**（素数 ⟹ 零点）✗ ⟹ **工具库里没有反向机器** ✓ ⟹ E47 的封口被**结构性确认** ✓✓
② ⭐ **突破口（2024→2026）**：Guth–Maynard 的**大值 Dirichlet 多项式**估计 ⟹ 零密度 **N(σ,T) ≪ T^{15(1−σ)/(3+5σ)+ε}**
   （σ ∈ [1/2,1] 一致 ✓）⟹ 短区间 PNT 的指数从 Huxley 的 **7/12** 推到 **17/30 ≈ 0.567** ✓（50 年首次 ✓）

## 1. 两条猜想：陈述与最优已知界（✓）

```
【Andrica ✓】√p_{n+1} − √p_n < 1 ✓ ⟺ **g_n < 2√p_n + 1** ✓（逐个 gap ✓，常数近 2 ✓）
   · 证明型最优 ✓：**g_n < p_n^{0.525}**（Baker–Harman–Pintz 2001 ✓，Harman 筛法 ✓）
     ⟹ 由 p_n^{0.525} < 2p_n^{0.5} + 1 ⟹ 猜想**已验证**至 p_n ≤ **1.099532599291×10¹²** ✓【多源 ✓】
     ⚠️ 另有**声称** θ = 0.52（Runbo Li 预印本 ✓）【单一来源·未核 ✗】
   · 计算型 ✓：经验验证至 1.3002×10¹⁶（Ghory ✓）→ 借最大间隙表延到 **2×10¹⁹ > 2⁶⁴** ✓【多源 ✓】
   · 高水位 ✓：A_n 最大值出现在 n = 1, 2, 4（A₄ = √11 − √7 ≈ **0.670873** ✓），前 10⁵ 素数内无更大 ✓
   · ⚠️ **关键事实 ✓**：**RH 不足以推出 Andrica** ✗（Visser ✓，见 §2-D ✓）
   · 推广 ✓：p_{n+1}^x − p_n^x = 1 的最小 x = **Smarandache 常数 0.567148** ✓（p_n = 113 ✓）
【Oppermann ✓】对每个 m：区间 (m²−m, m²) 与 (m², m²+m) **各含一个素数** ✓（⟹ 强于 Legendre ✓）
   · 无条件下 ✓：**未解决** ✗；已知最好的是**例外集型**结果 ✓（Bazzanella ✓，见 §2-C ✓）
   · 条件型 ✓：**RH + CMS + Sorenson–Webster** ⟹ 对**相邻幂**区间 [x^{2+δ}, (x+1)^{2+δ}] ✓
     **δ ≥ 1/4 时对所有 x ≥ 1 成立** ✓；δ < 1/4 时给出显式 x₀(δ) ✓（Chamberland–Straub ✓，Amer. Math. Monthly，2026 待刊 ✓）
     ⟹ ⚠️ 注意 ✓：这是**幂区间**（比平方区间**宽**得多 ✓）⟹ 与 Oppermann 仍有距离 ✗
```

## 2. 前沿攻击方向与技术手段（✓ 六层 ✓）

```
【A ✓ 短区间 PNT（渐近式型）—— 本轮最大动静 ✓】
   历史链 ✓：Ingham（1940 ✓）→ Huxley **θ > 7/12**（1972 ✓，**50 年未被推动** ✗）
     → ⭐ **Guth–Maynard 2024/2026 ⟹ θ > 17/30 ≈ 0.5667** ✓✓
   新工具 ✓：**大值 Dirichlet 多项式估计** ✓（长度 N 的多项式取到 ~N^{3/4} 级大值 —— 正是临界情形 ✓）
     手法 ✓：TT* 方法 ✓（估计 MM* 的首特征值 ✓，用 W 与 Φ 的 Fourier 系数 ✓）→ 由矩阵归一 ⟹ 零密度 ✓
   新零密度 ✓：**N(σ,T) ≪ T^{15(1−σ)/(3+5σ)+ε}**（**σ ∈ [1/2,1] 一致** ✓）
     ⟹ 合并 σ ≤ 7/10 的旧界 ⟹ **A(σ) < 30/13 ≈ 2.308** ✓（即 N(σ,T) ≪ T^{(30/13)(1−σ)+ε} ✓）
   ⚠️ 与 1/2 的距离 ✓：17/30 = 0.5667 vs 1/2 = 0.5 ✓ ⟹ **尚差 0.067** ✗（且 RH 本身只给 θ > 1/2 + ε ✓）
【B ✓ 下界型（"区间至少一个素数"）】筛法路线 ✓：Harman 筛 ⟹ **θ > 0.525** ✓（Baker–Harman–Pintz ✓）
   ⚠️ 与 A 的区别 ✓：A 给**渐近式** ✓（更贵 ✓）；B 只要**下界** ✓（更便宜 ⟹ 指数更好 ✓）
   ⚠️ MathOverflow 指出 ✓：**"显式化"是缺口** ✓（L-函数估计——如 Vinogradov–Korobov 零自由区——拖累了显式常数 ✓）
     ＋ 新方向 ✓：Matomäki–Merikoski–Teräväinen 显示**可不用 L-函数**检测短区间素数 ✓
【C ✓ 例外集 / 几乎处处】Bazzanella ✓：
   无条件 ✓：每个 [n², (n+1)²] ⊂ [1,N] 中，**除 O(N^{1/4+ε}) 个例外**外含期望多个素数 ✓
   RH 下 ✓：例外数降到 **O(f(N) log²N)** ✓（f 任意慢趋无穷 ✓）
   ⚠️ 条件性**证明猜想** ✓：需假设 **Selberg 短区间积分**的更强行为 ✓（Bazzanella 2000/2011 ✓）
     ＋ Lindelöf 型 / **Density Hypothesis** 版本 ✓（构造 |E_δ(N,h)| ≪ N^{1/2+ε} ✓）
【D ✓ RH 下的显式定量 + **RH 不足** ✓】
   Carneiro–Milinovich–Soundararajan ✓：**RH ⟹ g_n ≪ √p_n · log p_n** ✓（比 Andrica 目标 **2√p_n** 多一个 **log** ✓）
   Visser ✓（arXiv:1804.02500 ✓，Mathematics 6(12) 2018:289 ✓）：
     ⭐ **RH 不足以证 Andrica** ✗ ⟹ 只能给"带对数修正"的**变体** ✓；并讨论"可否用变体反推" ✓
【E ✓ 统计 / 多区间联合分布（条件型）】
   Leung ✓（QJM 76(1) 2025:251 ✓）：**RH + LI** ⟹ 多短区间素数呈**多元 Gaussian** + 弱负相关 ✓
   2026 续作 ✓（J. Funct. Anal. / ScienceDirect ✓）：更细的 Gaussian 与**相变**描述 ✓
   ⚠️ 结构 ✓：这些都是 **RH ⟹ 分布** ✓ —— **不是**分布 ⟹ RH ✗（与我们要的反向相反 ✓）
【F ✓ 权威综述（项目队列未读 ✓）】**arXiv:2607.04632** ✓
   "A decades-long breakthrough in zero-density estimates and primes in short intervals" ✓
   （2026 JMM Current Events Bulletin 配套综述 ✓，21 页 ✓，**BAMS 待刊** ✓）
   ⭐ 内含 ✓：(i) Theorem 4.3 = **Guth–Maynard 一致版** ✓；
     (ii) ⭐ **Theorem 4.4 型二分** ✓：**θ > 1 − 1/A₀ ⟹ 对【所有】x** ✓；**θ > 1 − 2/A₀ ⟹ 除密度零例外集外** ✓
     (iii) 零密度史表 + A(σ) 表 ✓（含 Ingham/Carlson/Bourgain/Huxley ✓）
   ＋ 相关显式文献 ✓：**arXiv:1401.4781** ✓、**arXiv:2101.12263**（"Explicit zero density"，JMAA 465 (2018) ✓）
   ＋ **arXiv:2603.17334**（2026 ✓：r-间隙的密度结果 ✓）
```

## 3. ⭐ 对我们 RH 攻击的启示（✓ 逐条 ✓）

```
【启示 1 ✓ 尺度被独立确认】两条猜想与我们的框架**共用同一临界尺度 h = √x** ✓：
   Andrica 常数 2√p ✓、Oppermann 区间长 m = √(m²) ✓、RH 的短区间阈值 θ = 1/2 ✓
   ⟹ 我们 E47 里 "gap 侧 vs 谱侧" 的比较**尺度选得对** ✓（不是巧合 ✓）
【启示 2 ⚠️ **方向相反**（最重要 ✓）】前沿**全部**是"零点 ⟹ 素数"：
   显式公式 → 零密度/大值估计 → 短区间素数 ✓；反向（素数 ⟹ 零点）**工具库中不存在** ✗
   ⟹ ⭐ **E47 的封口被结构性确认** ✓✓：不是我们没找到桥 ✓，而是**这一层工具的方向天然朝外** ✓
【启示 3 ⭐ **L∞ vs 平均 的分野在 SOTA 里是显式定理形态** ✓✓】
   综述 Theorem 4.4 ✓：`θ > 1−1/A₀ ⟹ 所有 x` ✓ vs `θ > 1−2/A₀ ⟹ 除密度零例外集` ✓
   Bazzanella 例外集 ✓：O(N^{1/4+ε}) 例外 ✓ ⟹ **"几乎处处"与"逐点"是两个不同价位** ✓
   ⟹ 这正是我们 E47 的结论（**平均控制不排除单个异常区间** ✓）的**前沿原话版本** ✓✓
   ⟹ 因此"gap 猜想 ⟹ RH"若要成立 ✓，必须付出**逐点**价位的代价 ✓ —— 而该价位在 SOTA 中**无人达到** ✗
     （θ 到 1/2 的 0.067 差距 = 就是我们算出的"缺一个档次" ✓）
【启示 4 ⭐ **一个真实、可操作的机会**（与项目风格对口 ✓）】
   ⚠️ 综述与 MathOverflow 均指出 ✓：**新零密度界尚未显式化** ✗
     —— 即"Guth–Maynard 的常数/显式版本"是**公开缺口** ✓✓（现存的显式零密度结果仍是旧的 ✓）
   ⭐ 这与项目两条既有线**完全对口** ✓：E20–E40 零密度线 ✓ + 显式常数风格（论文 A 的初等显式路线 ✓）
   若做成 ✓，可改进的对象 ✓：(i) 短区间类结果的**显式**阈值 ✓；(ii) 任何依赖 N(σ,T) 的显式结论 ✓
   ⚠️ **诚实边界 ✓（我已核对 ✗）**：**不**直接帮助我们的论文 A ✗ ——
     其离轴项用的是**逐点**界 c_ρ ≤ 1/(2γ²) ✓（由功能方程 ✓），**不用零密度** ✓
     ⟹ 想接上这条机会，需要**换一个用零密度的场景** ⚠️（如"离轴零计数"型论证 ✓，尚需设计 ✗）
【启示 5 ✓ 对 E46 的启示】E46 复现的素数侧二矩（Montgomery 型 ✓）**不用零密度** ✓
   ⟹ 新工具**不直接**改进 E46 ✗；但项目反复撞的墙正是"**大值估计 + 局部因子**" ✓
   ⟹ 值得跟踪其**显式化版本** ✓（与启示 4 同一件事 ✓）
【启示 6 ✓ 条件型统计路线的警示】Leung / 2026 续作都是 **RH + LI ⟹ 分布** ✓
   ⟹ 反向（分布 ⟹ RH）**必须先有 LI** ✗ ⟹ **循环** ✓（与 E47 §3 一致 ✓✓）
