## 1. 定义

- **ξ(s)** = ½s(s−1)π^{−s/2}Γ(s/2)ζ(s)——非平凡零点 ρ = ½+δ_ρ+iγ_ρ（|δ_ρ| < ½——临界带）
- **S** = ∂_t² log|ξ(½+it)|——零点偏移源（**分布定义——正式稿待补**）
- **单零点核**：K_δ(x) = (x²−δ²)/(x²+δ²)²——K̂_δ(ω) = −π|ω|e^{−|δ||ω|}
- **缩放核**（λ = η/δ）：Q_λ(y) = [中心差(y,λ)]/λ² − K₁(y)
- **统一测试函数**：H_0 = F⁻¹[ŵ_target/K̂_0]——K̂_0 = −π|ω|（**构造域与归一化——正式稿待补**）
- **目标权**：w_target(γ) = (1+γ²)^{−2}——ŵ_target = (π/2)(1+|ω|)e^{−|ω|}
- **逐项权重**：w_H(γ,δ) = ⟨K_δ(·−γ), H_0⟩——闭式 (1/2)[a²(a+1)+|δ|γ²]/(a²+γ²)²——a = 1+|δ|
- **Weil 判别量**：Q := ⟨S, H_0⟩——**Q'_RH** = Σ_ρ w_target(γ_ρ)（Weil 可算）

## 2. Lemma A —— 核矩消去与二阶矩控制（墙 A）🟢

**陈述**：单零点核 K_ρ 满足 M₀ = ∫K_ρ = 0——M₁ = ∫xK_ρ = 0（偶性）——且
$$|M_2| \le C|\delta_\rho|,\qquad M_2 = \delta_\rho\int y^2 Q_{\eta/\delta_\rho}(y)\,dy$$

**证明要点**：
- Q_λ lemma（附录 A.1）：sup_{0<λ<½}∫y²|Q_λ(y)|dy < ∞——远场（λ²/y⁴——λ 一致）+ 近场（Taylor——∂_λ²A₀ = 2K₁ 抵消——Q_λ = O(λ²)）+ 中间（连续）
- 交换：|⟨K_ρ,H_0⟩| ≤ C|δ_ρ||H_0''(γ_ρ)|——Σ_ρ|⟨K_ρ,H_0⟩| < ∞（H_0''(γ) = O(γ^{−2})——Σγ^{−2} < ∞）

## 3. Lemma B —— 统一 Weil 测试函数（墙 B）🟢

**陈述**：H_0 ∈ W（Weil 测试空间）——偶性 H_0(−t) = H_0(t)——实值——H_0 ∈ C^∞ ∩ S′——|Ĥ_0(u)| ≤ Ce^{−c|u|}（指数衰减）。

**证明要点**：
- 精确闭式：H_0(t) = −(1/2)[(1/2π)log(1+t²) + 1/(π(1+t²))]——Ĥ_0(ξ) = −(1/2)(1+|ξ|)e^{−|ξ|}/|ξ|
- 素数项绝对收敛（附录 A.2）：Σ(log p/p^{m/2})|Ĥ_0(m log p)| ≤ C·Σ log p·p^{−3m/2} < ∞
- Q = ⟨S,H_0⟩ 合法 Weil 分布配对（**扩展 Weil 公式版本——正式稿待补**）

## 4. Lemma C —— 正性与等号刚性（墙 C）🟢

**陈述**：w_H(γ,|δ|) > 0（γ ≥ 14——|δ| ∈ (0,½)）——且
$$Q - Q'_{\rm RH} = \sum_\rho \delta_\rho^2 w_H(\gamma_\rho, |\delta_\rho|) \ge 0$$

**证明要点**：
- w_H > 0（闭式——N(x) 分析——∂N/∂x ≥ γ⁶/2+γ⁴+γ²/2−6γ²−13.5 > 0——γ≥2）
- 正项和：Q = Q'_RH ⟹ Σδ²w_H = 0 ⟹ 每项 δ_ρ = 0（正项和唯一性——**完整落笔——正式稿待补**）

## 5. Weil 接口定理

**陈述**（扩展 Weil 公式）：设 H 满足（W1）对称实值（W2）C^∞ 缓增（W3）Fourier 衰减 |Ĥ(u)| ≤ C(1+|u|)^{−1−ε}——则
$$\langle S, H\rangle = \mathcal M(H) - \sum_{p,m}\frac{\log p}{p^{m/2}}\widehat H(m\log p) + \sum_\rho H(\gamma_\rho)$$

代入 H_0：三条件满足（Lemma B）——素数项收敛（A.2）——零点侧合法（Lemma A）——Q 严格定义。

## 6. RH 判别主定理

> **定理**：设 Q = ⟨S,H_0⟩（Weil 判别量）——则
> $$\boxed{Q = Q'_{\rm RH} \iff \text{RH（所有非平凡零点 } \rho = \tfrac12+i\gamma\text{）}}$$

**证明**：
1. Q − Q'_RH = Σ_ρ δ_ρ² w_H(γ_ρ,|δ_ρ|)（Lemma A 交换 + Lemma B 配对 + Weil 展开）
2. w_H > 0（Lemma C）——Q − Q'_RH ≥ 0
3. Q = Q'_RH ⟹ Σδ²w_H = 0 ⟹ 每项 δ_ρ = 0（正项和）⟹ RH ∎
（充分性：RH ⟹ δ_ρ = 0 ⟹ Q = Q'_RH——w_H(γ,0) = w_target）
