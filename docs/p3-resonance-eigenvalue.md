# P3：Resonance-to-Eigenvalue 审计

> 2026-09-01 · 唐先生指示 · modular/scattering 路线的结构性 no-go 判定

## 核心问题
连续散射共振 → 何时被迫成为独立离散谱的本征值？

## P3.1：一般定理
- 自伴算子：谱在实轴（λ ∈ ℝ）——无复共振
- 散射共振：S 矩阵极点（解析延拓）——复能量——非 L² 对象——"泄漏态"
- "resonance = eigenvalue"的特殊情形：闭合系统（无开放通道——束缚态）/ 特殊对称性
- **一般定理：无"共振必须成为本征值"的定理**——共振可自由复

## P3.2：模曲面——关键的结构分离（修正后更强）

### 精确设置
- 模曲面 PSL(2,Z)\H——Δ 自伴——L² 谱 = 离散（Maass cusp）+ 连续（Eisenstein）
- **Δ 的 L² 谱：s 在 Re s = ½**（λ = s(1−s) = ¼+t² 实——自伴）
- 散射矩阵：φ(s) = √πΓ(s−½)/Γ(s)·ζ(2s−1)/ζ(2s)——极点 = ζ(2s) 零点 = **s = ρ/2——Re s = β/2**

### 关键发现（比预期更强）
**在所采用的 s-参数化下——ζ 零点（φ 极点）位于 Re s = β/2——与自伴 Δ 的 L² 谱线（Re s = ½）完全分离**（注意：不同文献对 scattering parameter 的归一化不同——稳健表述如下）：

**稳健结论（参数化无关）**：
> ζ 零点对应 scattering determinant 的 resonance poles，而非 modular surface 的 L²-eigenvalues；自伴 Laplacian 的实离散谱约束因此不能直接作用于这些 poles。

- 即使在线（β=½）——φ 极点在 Re s = ¼ ≠ ½——ζ 零点从来不在 Δ 的谱线上（该参数化下）
- λ = s(1−s) 在 s = ρ/2——复（一般）——不是 Δ 本征值
- ζ 零点 = 连续谱散射共振——永远不是 L² 谱对象——与自伴性无关

### 结论：模曲面不满足"resonance=eigenvalue"——且更强
1. 系统开放（连续谱 Eisenstein——散射通道）
2. **ζ 零点（φ 极点）与 Δ 谱（Re s=½）几何分离**——即使在 β=½ 也不重合
3. 自伴 Δ 的 L² 谱固定（实）——散射极点在谱外且不可达
4. **无"提升机制"**——"散射共振 → 离散本征值"对 ζ 零点**连在线情形都不对应 Δ 谱**——提升无从谈起
5. 散射 unitarity/反射性/因果性：只给函数方程配对（旧墙）——被动性不成立（|φ|>1——已证）

## P3.3：循环检查
- 分析只用散射理论结构——不输入零点——**无循环**

## P3 判定：结构性 no-go（modular/scattering 路线）
**证明成立**：
> Riemann ζ 零点 = 模曲面连续谱散射矩阵 φ(s) 的极点——位于 Re s = β/2（解析延拓区域）——**与自伴 Δ 的 L² 谱（Re s = ½）完全分离**——"自伴 ⟹ 实谱"的约束**不触及** ζ 零点（它们不是 L² 谱对象——是散射共振）——散射理论（unitarity/因果性/被动性）**都不给 β=½**——"resonance = eigenvalue"提升机制**不存在**（ζ 零点连在线时都不在 Δ 谱线上）。

**这解释了为什么 Selberg 类比不能转移**：
- Selberg zeta 零点 = 离散 Laplace 谱（自伴——实谱——在线）✓
- Riemann ζ 零点 = 连续谱散射极点（共振——可复——不在谱上）✗
- **"离散谱"与"散射共振"是模曲面光谱的两个不同世界**——自伴魔法只作用于前者

## 物理路线因果图（最终压缩）
```
Selberg ⟶ L² eigenvalues ⟶ self-adjointness ⟶ critical line

ζ ⟶ scattering determinant ⟶ resonances ⟶̸ L² eigenvalues
```
- "ζ 复零点 = 物理共振能量"——成立到一定程度——但——
- "闭合系统没有复能量"拉回实轴——缺失关键一步：**共振不是闭合系统的普通本征值**
- 这解释了 P1 物理直觉好、P3 数学实现失败的原因
