## §1 【全文】**ζ 的无零点圆盘（精确形式）**
```
DFMR §7.1.1：设 r > max(0,σ₁)、r ≠ 1，取 λ ∈ ℂ、ℜ(λ) > 0。由 Thm 2.2 得：
   **ζ(s) 在圆盘  r + { μ ∈ ℂ : |(μ−λ)/(μ+λ̄)| < √( 1 − 2ℜ(λ)·d_r(λ)² ) }  上无零点** ✓✓
   其中 **d_r(λ) = dist( t^{λ̄}χ_{(0,1)} , K_r )**，**K_r = span(f_{A,r} : A 为 1-容许序列)** ✓
```
$$\boxed{\text{半径}\ =\ \sqrt{1-2\Re(\lambda)\,d_r(\lambda)^2}\qquad\Longrightarrow\qquad d_r\ \text{越小}\ \Rightarrow\ \text{圆盘越大}}$$
```
⭐⭐ **关键观察**：这里有 **λ 作为参数**，而**没有任何"验证高度 T"** ✗
   ⟹ **直接印证我上轮的更正**：门⑤的配对**不是"验证到 T"型** ✓✓
```

## §2 【全文】**更显式的形式与改进位置**
```
【Cor 2.3】半径 ~ √( 2(ℜ(λ)−σ₀) )·|d̃_{f_{A,r}}(λ)| / ‖f_{A,r}‖₂ ✓（即 半径 ∝ 距离/范数 ✓）
【Thm 4.3】d̃_{f_{A,r}}(λ) = L(λ+r−σ₀)·φ̂(λ+r−σ₀)·(Σ_j c_j α_j^{λ+r−σ₀}) ✓（**因子化穿过 L** ✓）
```
