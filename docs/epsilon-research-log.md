# ε_m 严格化：完整探索记录（2026-08-21 最终版）

## 目标
严格证明 Σ_m |ε_m| ≤ c·log n，c < 0.1934（即可闭合 D_n > 0 ⟹ RH 证明链）。
数值事实：Σ|ε_m| ≤ 0.74（n ≤ 2×10⁴），|Σε_m| ≤ 0.06，|Σε_m|/log n ≤ 0.018。

## 已排除的路线（7 条，避免重复）

| # | 路线 | 失败原因 |
|---|---|---|
| 1 | M(T) 桥接（M 有界 → 双重 IBP）| **M(T) 实际增长**（M(74921)≈−200），非 O(1) 非 O(log T) |
| 2 | Littlewood "M(T)=O(log T)" | 引用不成立（数值确认 M 增长）|
| 3 | Cauchy-Schwarz + Selberg 二阶矩 | ∫f'² ~ n²，∫S² ~ n log log n → O(n^1.5) |
| 4 | 逐块 van der Corput | 逐块和丢失跨块抵消，常数 0.7-1.4 > 0.1934 |
| 5 | 全局 van der Corput | λ_min ~ π²/n，g(γ₁) ~ O(n)，常数 ~ n² 爆炸 |
| 6 | 块内双重 IBP + M telescope | f'(t_{M'+1})M(t_{M'+1}) ~ O(n)，M 增长 |
| 7 | 符号同步（ε_m·(-1)^m ≥ 0）| 数值不成立（180/225 块违反）|

## 确认的事实（可用的正面结果）

1. **V(S) 饱和**：S 连续版本总变差 ≈ 1000（T ∈ [3×10³, 7.5×10⁴]），O(log T) 尺度——**S 是有界变差型**（对数尺度）
2. **ε_m = −∫_{B_m} f'S dt 精确**（块边界 f=0）
3. **A/B 分解**：f' = A cosφ + B sinφ
   - B 项（同号项）≈ 0（ΣepsB ≈ ±0.001）
   - A 项（振荡项）主导：ΣepsA 有界（+0.084/+0.115/−0.025 for n=1k/5k/10k）
   - Σ|epsA| ≤ 0.39
4. **|Σε_m|/log n ≤ 0.018**（比裕量 0.1934 低一个数量级）
5. **ε_m 跨块强抵消**：|Σε_m| ≪ Σ|ε_m|（0.06 vs 0.74）

## 唯一幸存路径（正确机制）

**A 项的振荡抵消**：εA_m = ∫ A·cosφ·S dt，φ=(n+½)θ 显式相位。

需要的技术（研究级）：
- **双相振荡积分**：cosφ 与 S 的零点跳跃相位之间的相关
- Selberg 精细 S 矩 + van der Corput 组合（跨块抵消，不是逐块）
- 或：S 的显式公式（S(T) = (1/π)arg ζ(½+iT)）在振荡积分中的应用
