## I. Kernel rigidity（墙 A）

### Lemma A1（单零点核结构）
K_ρ(t) = −K_{δ_ρ}(t−γ_ρ) 满足：
- **M₀** = ∫K_ρ = 0（——K_δ 变号——∫=0——精确）
- **M₁** = ∫xK_ρ = 0（——偶性——K_δ 偶——精确）
- **M₂** = δ_ρ∫y²Q_{η/δ_ρ}(y)dy——|M₂| ≤ C|δ_ρ|

### Lemma A2（Q_λ 一致矩界）
sup_{0<λ<½}∫y²|Q_λ(y)|dy < ∞——三区：
- **远场**：Q_λ = −(λ²/2)/(y²+1)² + O((y²+1)^{−3})——y²Q_λ ∈ L¹
- **近场**：Taylor——A_λ = λ²K₁ + O(λ⁴)——Q_λ = O(λ²)
- **中间**：紧致连续

**推论**：|⟨K_ρ,H_0⟩| ≤ C|δ_ρ||H_0''(γ_ρ)|——Σ_ρ|⟨K_ρ,H_0⟩| < ∞（H_0'' = O(γ^{−2})——Σγ^{−2} < ∞）——交换合法。

## III. Positivity rigidity（墙 C）

$$Q - Q'_{\rm RH} = \sum_\rho \delta_\rho^2\, w_H(\gamma_\rho, |\delta_\rho|)$$

- **w_H > 0**（L5——N(x)——∂N/∂x ≥ γ⁶/2+γ⁴+γ²/2−6γ²−13.5 > 0——γ≥2——w_H > w_target > 0）
- Q ≥ Q'_RH（非负）
- Q = Q'_RH ⟹ Σδ²w_H = 0 ⟹ 每项 δ²w_H = 0（正项和）⟹（w_H>0）每项 δ_ρ = 0 ⟹ Re ρ = ½

## IV. Main theorem

> **Theorem**：以下等价：
> 1. **RH 成立**（所有非平凡零点 Re ρ = ½）
> 2. **Q = Q'_RH**
> 3. **Q − Q'_RH = 0**
>
> **RH ⟹ equality**：全 δ_ρ = 0——Q − Q'_RH = Σ0·w_H = 0（——w_H(γ,0) = w_target——Q = Q'_RH——）∎
> **equality ⟹ RH**：由正性刚性（III）——Σδ²w_H = 0——w_H>0——每项 δ_ρ = 0——所有零点 Re ρ = ½——RH ∎
