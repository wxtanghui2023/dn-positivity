## 2. 精确分解：r(n) = ∫f_n dS + O(1)

$$r(n) = \sum_\gamma f_n(\gamma) - \int f_n(t)N'(t)dt = \int_0^\infty f_n(t)\,dS(t) + O(1)$$

- $f_n(t) = 4\sin^2(n\theta(t))$，$\theta(t) = \arctan(1/2t)$
- S(t) = 零点计数振荡（N = M + 7/8 + S）
- 验证：r_smooth ≈ 0.000（主项精确捕获），r_S = r_total（差 < 0.03）

**主项来源**（完整验证）：
- ½nlogn：∫4sin²(1/2x)dx = π
- cn：c = B/(2π) = −1.130315 ≈ −1.130331 ✓

## 3. 机制：GUE 能级排斥（d_k 负相关）

### 3.1 逐区间分解

$d_k = f_n(\gamma_k) - \int_{\gamma_k}^{\gamma_{k+1}} f_n N' dt$，$\sum d_k = r(n)$（恒等式）

### 3.2 关键观察

- **d_k 相邻负相关 lag-1 ≈ −0.38~−0.43**（GUE 能级排斥特征）
- Σρ(1..30) ≈ −0.46~−0.49，1+2Σρ ≈ 0.02~0.08
- 涨落压缩 5-6 倍（max|S_c| 2.6-11 vs 独立 15-37）

### 3.3 ⚠️ 方法论教训

**d_k 分解是"同义反复"**：Σd_k = r(n) 恒等，负相关只是 O(1) 的重新表述，**不提供独立证明**。不能从 d_k 统计推出 O(1)（那是循环）。

## 5. Arias de Reyna 指数判别（新认识）

### 5.1 无条件表达式

$$\lambda_n = \sum_\rho \left[1 - r_\rho^n\cos(n\varphi_\rho)\right]$$

- $r_\rho = \sqrt{((\beta-1)^2+\gamma^2)/(\beta^2+\gamma^2)}$
- **β=½ ⟹ r=1**（sin² 公式，RH 条件性）
- **β<½ ⟹ r>1**（离轴零点 → r^n 指数增长）

### 5.2 判别

> RH 假 ⟹ ∃r>1：|λ_n| ≥ r^n 无穷多次（指数爆炸）
> RH 真 ⟹ λ_n ~ ½nlogn（对数增长）

### 5.3 我们数据的意义

**数值验证 λ_n = O(n·logn) 到 n=3000** → 排除离轴零点的指数贡献（对应高度内）→ **RH 的数值确认**（Arias de Reyna 判别），非证明但有意义。
