## §2 **纯核**（显式陈述；**仅含 X, P, μ, ℕ** ✓✓）

```
theorem no_failure {X : Type} (P : X → Prop) (μ : X → ℕ)
    (step : ∀ x, P x → ∃ y, P y ∧ μ y < μ x) :
    ¬ ∃ x, P x
【证明（纯 ℕ-良基，一步）】 设 ∃x, P x；取集合 {x : P x} 中 μ 最小者 x₀（ℕ 良序 ⟹ 存在 ✓）；
   step x₀ 给出 y 使 P y 且 μ y < μ x₀ ⟹ 与 x₀ 的最小性矛盾 ∎ ✓✓
【内容审计 ✓】 不出现：群／素数／Euclid／Brahmagupta／Liouville／Fermat／强归纳实现 ✗✓
   ⚠️ 说明：**"最小反例"出现在核的【证明】里**（由 ℕ 良基性**导出**），
      但**不进入任何定义／接口** —— 满足唐先生"不得把最小反例法写进定义" ✓✓
```

## §3 接口层：**四槽**精确签名（提案；待 乙-3 检验 ✓）

```
structure DescentData (X : Type) (P : X → Prop) (μ : X → ℕ) (Target : Prop) (h : ¬ Target) where
  -- ── C：独立压缩（含定量界 B；"落在受控尺度"的抽象）──
  B          : ℕ
  compress   : ∃ x, P x ∧ μ x ≤ B
  -- ── R：失败保持（在【原始下降输出】层）──
  Y          : Type
  Q          : Y → Prop
  raw        : ∀ x, P x → Y                         -- 原始下降步（D 的原料）
  raw_Q      : ∀ x (hx : P x), Q (raw x hx)         -- 原始输出仍"失败"
  -- ── K：送回 X（闭包／再入；保证 P 仍可表达）──
  reenter    : ∀ x (hx : P x) (y : Y), Q y → X
  reenter_P  : ∀ x hx y hy, P (reenter x hx y hy)
  -- ── D：严格下降 ──
  reenter_lt : ∀ x hx y hy, μ (reenter x hx y hy) < μ x
```
```
【⭐ 本刀新发现（由 A2 逼出）】 接口必须 **"反证相对"（reductio-relative）**：
   各槽**允许依赖** `h : ¬ Target` ✓✓
   原因：**A2 的 P-保持只在 ¬Target 下成立** —— 下降若给出 m′ = 1，则 m′p = A²+B² ⟹ **Target 已成立**，
   与 h 矛盾 ⟹ 故在 h 下必有 **m′ > 1** ⟹ `P(m′)` 成立 ✓✓（Liouville 侧不需要 h，可忽略 ✓）
【⛔ 污染判据】 若把 `Y := Unit`、`Q := True`、或把 `reenter_P` 当作**假设**而非**待证命题** ⟹
   **抽象污染** ⟹ 判 **FAIL** ✓✗（详见 §6）
```

## §4 由四槽**组装**出下降义务（Layer-2 的推导 ✓✓）

```
step : ∀ x, P x → ∃ y, P y ∧ μ y < μ x
step x hx := ⟨ reenter x hx (raw x hx) (raw_Q x hx) ,
               reenter_P x hx (raw x hx) (raw_Q x hx) ,
               reenter_lt x hx (raw x hx) (raw_Q x hx) ⟩      ✓✓
⟹ 组合： `target_of_descent (h : ¬Target) (I : DescentData …) : Target`
   = no_failure (step from I) 给出 ¬∃x P x；而 I.compress 给出 ∃x P x ⟹ 矛盾 ⟹ ¬¬Target ⟹（经典）Target ✓
【要点】 **C 与 (R,D,K) 是两组独立假设** ⟹ 二者都在接口上**可见**，未被压成单一前提 ✓✓
```

## §5 ⭐ 两实例实例化字典（同一接口 ✓✓）

```
【Liouville（Prototype-0）】
  Target := "F 在 F_p^× 上乘法" ✓
  X := { (q,y) : 1 ≤ q, 0 < y }（候选乘子对）✓
  P((q,y)) := [ F(q·y) ≠ F(q)·F(y) ]（失败对）✓
  μ((q,y)) := y ✓（**内层**尺度；外层强归纳在 §6 归入 K 的证明 ✓）
  C: compress 由 ¬Target 取失败对，再用**短代表元引理** ⟹ ∃(q,y): P ∧ y ≤ p/2 ⟹ **B := p/2** ✓✓
  R: raw((q,y)) := **下降证书**的输出 (j,r)（`extension_descent_certificate_symmetric`）✓
     Q((j,r)) := [ j < q ∧ r < y ∧ (相关同余式成立) ] ✓（**原始层失败谓词** ✓）
  K: reenter := 恒等（(j,r) 已在 X 中）✓；reenter_P 证明**实质使用**：证书 ＋ **j<q ⟹ j ∈ H**（外层强归纳）✓✓
  D: reenter_lt := **r < y** ✓✓
【A2（Fermat 两平方）】
  Target := "1 ∈ M"（即 p = a²+b²）✓
  X := { (a,b,m) : m ≥ 1, a² + b² = m·p } ✓
  P((a,b,m)) := [ m > 1 ] ✓；μ := m ✓
  C: compress := **鸽笼**（配 x² ≡ −1 (mod p)）⟹ 得 m ≤ 2；在 h : ¬Target 下 m ≠ 1 ⟹ m = 2 ⟹ P 成立 ⟹ **B := 2** ✓✓
  R: raw((a,b,m)) := 模 m 归约后的 (a′, b′)（|a′|,|b′| ≤ m/2）✓
     Q((a′,b′)) := [ m | a′² + b′² ∧ (a′,b′) ≠ (0,0) ] ✓
  K: reenter := **Brahmagupta 组合** ⟹ (A, B, m′)，m′ := (a′²+b′²)/m ✓
     reenter_P: m′ > 1 —— ⭐ **须用 h : ¬Target**：若 m′ = 1 则 p = A²+B² ⟹ Target ⟹ 与 h 矛盾 ✓✓
  D: reenter_lt := **m′ ≤ m/2 < m** ✓✓
【结论】 两实例**确实实例化同一接口**（含"反证相对"条款）✓✓
```
