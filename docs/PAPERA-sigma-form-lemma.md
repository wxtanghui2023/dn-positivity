# PAPERA-SIGMA-FORM-LEMMA — Σ-form 引理核验（区域 B 唯一把守者）【判死】(2026-09-12)

**对象**：候选 Σ-form van der Corput 引理
```
对实序列 φ_k (k ≤ M):   |Σ_{k≤M} e^{iφ_k}| ≤ √(M·L) + √(M/L),
其中 L := Σ_k |Δ²φ_k|,  Δ²φ_k = φ_{k+2} − 2φ_{k+1} + φ_k（二阶差分【总质量】替代 sup）。
```
项目 `docs/PAPERA-uniformity-attack.md` §4.2 用它得区域 B 界 **3.622e5 = 0.553× 额度**，且标注「引理未核验」。本文件给出**明确判定：引理为假**（含两类反例），给出标准定理的正确形式与正确常数，并重算区域 B。

## 1. 反例一：阶跃函数（一般实序列，判死核心）

取 `φ_k = 2π·m_k`，`m_k = 0 (k≤K)`、`m_k = 1 (k>K)`（一个 2π 跳变）。则
`e^{iφ_k} = 1` 对所有 k ⟹ **`|Σ e^{iφ_k}| = M`**（完全相干）。
二阶差分仅在跳变处有两个尖峰：`Δ²φ = +2π`（k=K−1）与 `−2π`（k=K），故
**`L = Σ|Δ²φ_k| = 4π ≈ 12.566`**，与 M **无关**。
Σ-form 要求 `M ≤ √(4πM) + √(M/(4π))`。实测（`PAPERA_sigma_verify.txt` V2）：

| M | \|Σ\| | L | √(ML)+√(M/L) | 比（lhs/rhs） |
|---|---|---|---|---|
| 100 | 100 | 12.566 | 38.27 | 2.6 |
| 1000 | 1000 | 12.566 | 121.0 | 8.3 |
| 1e6 | 1e6 | 12.566 | 3827 | 261 |
| **2e6** | **2e6** | **12.566** | **5412** | **369.5** |

**判定 [推导]：Σ-form 为假。** 一个 2π 拐点只贡献 `L=4π` 的二阶质量，却让整段求和相干到 `M`——总质量 `L` 完全不感知"跳变发生在哪里、相干长度多长"。这正是 L-form 想处理的"坏点"场景，而它在此场景下**判死**。（注：这是「相位几乎线性 + 一个跳变」的任务提示反例；此处跳变取 2π 使相干最坏。）

## 2. 反例二：凸抛物线（连"定号"情形也失败）

任务提示"少数点有巨大 Δ²φ"之外，还需排除"**凸（定号二阶差分）情形下 Σ-form 是否成立**"。取**纯抛物线**（无浮点抵消）：
```
φ_k = ε·(k − M/2)²,   则  Δ²φ_k = 2ε（常数）,  L = 2εM.
```
`|Σ e^{iφ_k}|` 当 `ε ≪ 1/M²` 时 ≈ M（相位几乎为 0，全相干）。Σ-form 右端 = `√(M·2εM) + √(M/(2εM)) = M√(2ε) + 1/√(2ε)`。取 `ε = c/M²`：

| c = ε·M² | \|Σ\|/M | Σ-form/M | 比 |
|---|---|---|---|
| 0.10 | 1.0000 | 0.447 | 0.45（界不紧但成立） |
| 0.50 | 0.9993 | 0.999 | ~1.0 |
| **1.00** | **0.9972** | **0.7071** | **1.41 假** |
| 2.00 | 0.9890 | 0.500 | 1.98 假 |
| 4.00 | 0.9563 | 0.354 | 2.70 假 |
| 10.00 | 0.7493 | 0.224 | 3.34 假 |

（`PAPERA_sigma_sharp.txt` S1，M=1e4 与 M=2e6 结果一致，比例与 M 无关。）

**判定 [推导]：即便二阶差分定号（凸），Σ-form 也为假**（c=1 时 `|Σ|=0.997M > 0.707M`）。根因：`L = Σ|Δ²φ|` 是"曲率总量"，而"几乎线性整数斜率 + 极小凸曲率"的相位曲率总量极小（`L = 2c/M`），却能保持全程相干。要控制它，需要的是**最小曲率 `min|Δ²φ|` 的下界**（标准定理的形式），而非总质量。

## 3. 标准定理的正确形式（查文献 + 常数）

**标准离散/连续二阶导检验**（van der Corput；Graham–Kolesnik《van der Corput's Method of Exponential Sums》LMS LNM 126；Titchmarsh Ch.5；Iwaniec–Kowalski Ch.8）：

> **[引]**（Elkies, Math 259 notes, "van der Corput inequalities"）若存在常数 `0 < c < C` 使 **`c·λ₂ < f″ < C·λ₂`** 对 `x ∈ [1,N]` 成立（即 **f″ 定号且上下有界、典型值 ~λ₂**），则
> `S = Σ e(f(n)) ≪_{c,C} N·λ₂^{1/2} + λ₂^{-1/2}`。
>
> **[引]**（Joni's Math Notes，转述 Graham–Kolesnik/Titchmarsh）设 F 二次连续可微，**`λ ≤ |F″(x)| ≤ αλ`**，则 `Σ_{n∈I} e(F(n)) ≪ α|I|·λ^{1/2} + λ^{-1/2}`（绝对常数；首项系数 ~α = 上下界比）。
>
> **[引]**（Kusmin–Landau；Baier, Lectures on exponential sums, Lemma 10）f 连续可微、**f′ 单调**且 `‖f′(x)‖ ≥ δ > 0`，则 `Σ e(f(n)) ≪ δ^{-1}`。
>
> **[引]**（Kuzmin 原版；Arias de Reyna, "On Kuzmin–Landau Lemma"）`δ_k = a_{k+1}−a_k` **递增**且 `θ ≤ δ_k ≤ 1−θ`，则 `|Σ e^{2πia_k}| ≤ 2/sin(πθ) ≤ 1/θ`。

**三条共同要点 [引]**：
1. **用 `min`（下界 λ），不是 `max`，更不是总质量 `Σ|Δ²φ|`。** 标准定理的输入是"曲率的典型值（下有界）"，保证相位**处处**有足够的弯曲去相干。
2. **要求 f″（或增量）定号**（凸/凹，或增量单调）——这是 Kusmin–Landau 的单调性前提。
3. **首项系数是 α（max/min 比），不是 1**；末项系数为绝对常数（≥1，实测锐界 ≈ 1.4–3.4 量级，见 §4）。

**Σ-form 与标准定理不等价 [推导]**：Σ-form 把 `min|Δ²φ|` 换成 `(1/M)Σ|Δ²φ|`（平均），把 `f″` 定号要求整个丢掉，还把 `α` 与末项常数都压成 1。这**不是**标准定理的任何版本，且如 §1–§2 所示直接为假。文献中**不存在**"用二阶差分总质量替代 sup"的 van der Corput 引理。

## 4. 项目 sup-form `M√Λ + Λ^{-1/2}` 也非法（Λ = max，C = 1）

项目 §4.1 的 sup-form 亦非标准定理：**用 max 而非 min**（标准定理要 min 且定号），且末项系数取 1。

- **反例 [推导]**：同 §2 的凸抛物线 `ε = 1/M²`，`Λ = max|Δ²φ| = 2/M²`。sup-form(C=1) = `M√(2/M²) + 1/√(2/M²) = √2 + M/√2 = 0.707M < 0.997M = |Σ|`。**假。**
- **锐常数 [未核验为定理，数值]**：对凸抛物线 / 随机符号混合 / 阶跃三族做对抗扫描，`|Σ| ≤ M√Λ + C/√Λ`（max 版）要成立需 **`C ≳ 3.36`**（`PAPERA_sigma_sharp.txt` S2，最坏来自凸抛物线 `c≈4`）。故 C=1 非法；即便 max 版是某条真定理（本文件**不主张**），run-split 的 1/√Λ 每段付费也须从 0.890 涨到 ~3.4 倍。
- **标准定理不适用于实际相位 [推导/数值]**：`φ_k = nθ(γ_k)` 的二阶差分 `nΔ²θ_k` 实测**符号 50.0% / 50.0% 混合**（正 999942 / 负 1001108，`PAPERA_sigma_sharp.txt` S3），因为 `Δ²θ ≈ θ′(γ)·(gap jump) + θ″(γ)·g²`，区域 B 内 `θ′·gapjump ~ 1e-12·0.35` 比 `θ″·g² ~ 4e-19` **大 6 个数量级**，被符号随机的 gap jump 主导。⟹ **`f″` 定号前提不成立**，标准二阶导检验、sup-form、run-split **全部是 van der Corput 的误用**。

## 6. 收尾

### 6.1 引理判定

**判死。** `|Σ e^{iφ_k}| ≤ √(M·L) + √(M/L)`（`L = Σ|Δ²φ|`）**为假**，且**不在文献中**。正确替代是标准二阶导检验 `|Σ e^{if(n)}| ≤ C·(N·λ^{1/2} + λ^{-1/2})`，其中 `λ = min|f″|`（定号、下有界），系数含 max/min 比 α——但它对 `nθ(γ_k)` **不适用**（二阶差分 50/50 符号混合）。

### 6.2 修正后的区域 B 界与 ×额度

**区域 B 严格界 = 平凡界 `M_B = 5.81e5` = 0.888× 额度**（闭合，但平凡）。Σ-form 的 3.622e5（0.553×）作废；sup-form 9.81e5、run-split 6.702e5 作废。

### 6.3 剩余缺口

**只剩区域 A**（与 `PAPERA-uniformity-attack.md` §5 / `PAPERA-expsum.md` §5 定位一致）：区域 A（`γ < γ_res`）平凡界 `M_A = 1.42e6`（D_n 分解下 `2N_A = 2.84e6`）恒 > 额度，而实测 `|S_n^A| = 259`——真实相消比任何现有工具强，但**无一定理证明**。`nθ′ ≈ n/γ²` 在 `γ₁ = 14` 发散是致命伤（§4.3 八度分箱：sup-form = 平凡界 1.42e6，Σ-form `L_A = 4.72e10 ⟹ 2.587e8`）。

### 6.4 要闭合区域 B 必须新证的一句话命题

区域 B **无需新命题**（平凡界 0.888× 已闭合）。若仍要一条**非平凡**的 B 界（把 0.888× 往下压、为区域 A 腾额度），须新证：
> 「对 `γ ∈ [γ_res, T0]`、二阶差分符号混合的实序列 `φ_k = nθ(γ_k)`（不满足 `f″` 定号、增量不单调），存在 `|Σ_{k∈B} e^{iφ_k}| ≤ c·M_B`（c < 0.888），且其证明不得调用标准二阶导检验（该检验的定号前提此处不成立）。」

（而真正的缺口命题，仍如父文档所定位：**对 `n ≤ T0²` 一致**的频域 Selberg 型定量定理，强度 `|D_n| = o(N)`。）
