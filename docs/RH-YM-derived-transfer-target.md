## §1 先把"保结构极限"形式化（推导的三条件）
一个变形族 $\{X_\lambda\}$（每个 $X_\lambda$ 是完整算术对象）若能承担 YM 大 N 极限所承担的角色，须满足：
$$\text{(T1) 可证点：存在 }\lambda_*\text{ 使目标性质在 }X_{\lambda_*}\text{ 上【已被证明】}$$
$$\text{(T2) 回程：}\lambda_0\text{ 使 }X_{\lambda_0}=\zeta\ \text{（或与 }\zeta\text{ 的结论等价）}$$
$$\text{(T3) 转移定理：由 }X_{\lambda_*}\text{ 的性质可推出 }X_{\lambda_0}\text{ 的性质（保个体信息，非平均）}$$
**筛掉已知失败的轴**（本项目已注册）：函数域（T2 失败：无回程）✗｜大 conductor/统计（T3 失败：β-盲）✗｜切换过程 ζ_X（T3 循环：极限即 RH）✗｜两变量 w-形变（T1 失败：三种正性互不相交）✗

## §2 ⭐⭐ 推导结果：**de Bruijn–Newman 流是唯一已知满足 (T1)+(T2) 的族**
```
定义：H_t(x) = ∫ e^{t u²} Φ(u) e^{i u x} du（Ξ 的前向热流，t ≥ 0）
【引用·经典】
 · Λ := inf{ t : H_t 的零点全为实数 }；RH ⟺ Λ ≤ 0
 · Rodgers–Tao (2018)：Λ ≥ 0  ⟹  **RH ⟺ Λ = 0**
 · de Bruijn–Newman / Ki–Kim–Lee：Λ ≤ 0.2（有限上界）⟹ **t ≥ 0.2 时零点【全为实数】是定理** ✓
```
$$\boxed{\text{(T1) 可证点：}t\ge 0.2\ \text{处零点全实【已证】}\quad\text{(T2) 回程：}t=0\ \text{即 Ξ 本身（}\Lambda=0\iff\mathrm{RH}\text{）}}$$
$$\boxed{\text{(T3) 转移定理：把 }t=0.2\text{ 的结论降到 }t=0\ ——\ \textbf{这就是 RH 本身}}$$
**⟹ 与 YM 的对应极其精确**：
| | YM | RH |
|---|---|---|
| 可证侧 | 格点（大批量/强耦合）✓ | $t\ge 0.2$（零点全实）✓ |
| 待证侧 | 连续极限（$a\to0$）✗ | $t\to0$（$\Lambda=0$）✗ |
| 开放的核心 | **跨越极限的转移**（需与 $a$ 无关的一致界） | **沿流的转移**（需与 $t$ 无关/可控的量） |
