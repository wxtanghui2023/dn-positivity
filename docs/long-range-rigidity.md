## 3. 诚实评估：方法移植可行性

**Bourgade 刚性证明方法**（不移植）：
- 依赖**随机矩阵系综**（Wigner 矩阵——概率测度——局部半圆律）
- 对数势的凸性/平衡测度——唯一性
- **ζ 零点没有系综**（确定序列）——不能直接移植

**ζ 的"刚性"是弱的**：
- 随机矩阵：波动 O(√(log N)/N)——趋于 0（强刚性）
- ζ 零点：S(γ_k) ~ √(log log T)（Selberg——无界但慢）——相对间距趋于 0（弱刚性）
- **不同型**——Bourgade 的强刚性方法不适用
