# 第一部分：P1d 登记（唐先生）

## 0. 结论
$$\boxed{\text{G7″ 仍不足}}$$
**但漏洞可压成更精确的问题**：
$$\boxed{\text{"全局确定"}\neq\text{"只有无限多个局部副本联合起来才确定"}}$$
后者仍可能只是 PIM-V 的无限复制版

## 1. 三攻击面
| 攻击 | 机制 | 本质 |
|---|---|---|
| **PIM-VI** | 前缀/cofinal 复制：每个前缀 $W_N=\{X_1,\dots,X_N\}$ 都不确定 $\alpha$，但 $\alpha_N\to\tfrac12$ | **局部独立事实 + 无限取极限 ⟹ $\alpha$** |
| **（超滤版）** | $\alpha=\lim_{\mathcal U}\frac{\log L_X}{\log X}$（非主超滤） | 超滤只是**极限选择器**：$\boxed{\text{global functional}\neq\text{global arithmetic constraint}}$ ⟹ 归入 PIM-VI |
| **PIM-VII** | 窗口嵌套自相似复制：$\mathcal R_{n+1}=\operatorname{Scale}(\mathcal R_n)$ | **目前最危险**：可满足 $\Sigma\subsetneq\Sigma_{\rm dec}$、$\alpha_\Sigma=\tfrac12$ 而 $\alpha_{\Sigma_{\rm dec}}$ 不唯一、且任意有界窗口不确定 $\alpha$ ⟹ **甚至通过解集版 decoupling test** |

## 2. 但不得因此禁止一切极限（过排除警戒）
若真机制为 $s_{X_{n+1}}=T(s_{X_n})$、$\alpha=\lim_n A(s_{X_n})$ —— 它当然也经极限得到 $\alpha$
$$\boxed{\text{须问的是：极限本身是否携带新的约束？而非：有没有极限？}}$$

## 3. G7‴ 提案（Non-Replicable Cross-Scale Generation）
```
(a) 解集收缩：Σ_∞ ⊊ Σ_dec
(b) 指数生成：α=1/2 在 Σ_∞ 上唯一、在 Σ_dec 上不唯一
(c) 非有限窗口生成：任意有限窗口 W 不足以唯一确定 α
(d) 非 cofinal replication：不存在独立于目标指数的有限/局部机制 K，经其复制/缩放/嵌套/极限即得 α=1/2
(e) 非单尺度继承：删除全部跨尺度关系后 α 失去唯一性
(f) 内生性：仍由 G4/POC 保证（不得人为规定 s_{2X}=√2 s_X 等）
```
**审计表**：G7″ 实际只杀到 **PIM-IV/V**；PIM-VI、PIM-VII **能通过 G7″**；G7‴ 则杀到全部 —— 但见 §5。

## 4. ⚠️ G7‴ 的过排除危险（本轮关键）
```
任何真正的 renormalization：s_{n+1}=T(s_n) 都可以被描述为"模板 T 被不断复制"
⟹ 若把"不可复制"理解为【形式上不可由规则生成】⟹ **所有 scale dynamics 都被 PIM-VII 杀死**
```
**正确定位**：
```
排除者：**有限模板本身已包含 α=1/2**，然后重复到无限尺度
允许者：**有限模板给出的是变换规则**，α=1/2 是其【无限迭代的涌现不变量】
```
## 5. 最干净的分界（唐先生）
$$\textbf{PIM}:\quad K\Rightarrow\alpha=\tfrac12,\qquad K^\infty\ \text{只是复制}\ K$$
$$\textbf{真 ISRG}:\quad K\not\Rightarrow\tfrac12,\qquad K^\infty\Rightarrow\tfrac12$$
$$\boxed{\text{这比"窗口是否有限"强得多}}$$
**P1d 冻结的必要分解**：
$$\boxed{\text{ISRG}=\text{Cross-Scale Coupling}+\text{Non-Replication}+\text{Emergent Exponent}}$$
**三轴判定**：
```
A：不是继承 —— decoupling 后指数消失
B：不是复制 —— 有限机制本身不含指数
C：不是规定 —— G4/POC
```
**P1d 结论**：前缀/超滤、极限包装、嵌套窗口复制**统一落入"infinite replication of finite law"**这一更深的 PIM 类
**但**："非复制"仍须在 P1e 中解决"真正迭代规则"与"复制规则"的语义区分，否则冻结定义会**过排除**
⟹ **M-NOGO-1 仍不能启动**

## 6. 发现一：**PIM-VI 其实已被【语义版】decoupling test 杀死**（G7″ 的窗口版反而做不到）
```

⟹ **语义版严格强于窗口版**：G7″ 的"窗口"限定应【删除】，代之以语义版
```

## 7. 发现二：⭐ 局部读出测试（新增，用于封死 PIM-I/II/III/VI 的统一来源）
```
定义 α_X^loc := 由 scale-X 的【单尺度状态数据】单独可提取的指数（若有）
⟹ PIM-I/II/III/VI 全部满足：α_X^loc 有定义，且 α_X^loc → α   ⟹ **局部数据"已经知道"指数**
⟹ 真递归 s_{n+1}=T(s_n)：仅凭 s_n【无】指数可言 ⟹ α_X^loc 未定义 ✓
```
$$\boxed{\textbf{G8（无单尺度局部读出）}:\ \text{对每个尺度 }X\text{，仅凭该尺度状态数据【不能】读出任何指数}}$$
**分工**：若指数写在【规则】里（如 $L_{X'}=L_X(X'/X)^{1/2}$）⟹ 属**规定** ⟹ 由 **G4/POC** 处理 ✓
**结论**：**G7″ 应替换为**：(语义 decoupling Σ ⊊ Σ_dec) + **G8** ⟹ 覆盖 PIM-I…VI

## 8. 发现三：⭐⭐ **PIM-VII 不是漏洞，而是【目标形状本身】**
```
PIM-VII：嵌套自相似，且 α 由【自相似/自洽方程】确定

```
**唯一差别**：
$$\boxed{\text{自洽方程是【算术原生（由 primitives 导出）】还是【构造出来】}}$$
**⟹ 于是"非复制"（B 轴）不独立**：
$$\boxed{\text{B 轴塌缩进 C 轴（G4/POC）——"非复制"是"内生性"在自相似情形下的投影}}$$
**三轴 → 两轴**：
```

（B 轴并入 C 轴）
```
**⭐ 重要的正面读法**：若有人用**算术 primitives** 构造出一个嵌套自相似、其自洽方程唯一给出 $\alpha=\tfrac12$ ——
那**不是** PIM，而是**我们一直在找的机制本身** ✓
$$\boxed{\text{攻击面 PIM-VII ⟺ 目标形状：唯一问题只是"自洽方程是否算术原生"（G4/POC）}}$$
