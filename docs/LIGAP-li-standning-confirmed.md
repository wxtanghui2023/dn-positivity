## §3 ⭐⭐⭐⭐ **判决（Q6）**
```
【① **Li 通过反例间隙检验**】✓✓
   低高度失败（γ=14）**必然被已验证的范围捕获**（n* ~ 10³–10⁴ ≪ 10²⁴ ✓，间隙比 10²⁰ ⟹ **无弥散空间** ✓）
   排除力达 **γ ≈ 1.4–4.6×10¹¹**，与验证高度 T=3.0×10¹² **同量级**（差 7–20× ✓）
【② **Li 不受 Farmer 的"通用性"缺陷影响**】✓✓✓
   Farmer 的杀伤力来自：**J_{d,n}（n≥1）的双曲性对【大量不满足 RH 类比的对象】也成立** ⟹ 不含 RH 信息 ✗
   而 **Li 是【等价】：λ_n ≥ 0 ∀n ⟺ RH** ✓ —— **不存在"大量反例对象也满足"的情形** ⟹ **无通用性缺陷** ✓✓
【③ 结论】**Li 作为【唯一可用强准则】的地位得到确认** ✓✓（用杀死 Jensen 的同一把尺子量过 ✓）
【④ 但保留其代价】**其形状为二次 ⟹ 纯数值验证不可行**（需 n ~ 10²⁴ ✗）⟹ **必须靠【转换】**（CONV3 + Palojärvi ✓）
```

