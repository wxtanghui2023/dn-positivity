## A 链：L 函数判别判据（每个 χ——我们的新工作）

### A1. 完成函数与 S_χ 的 Hadamard 展开
- L(s,χ) 完成函数 ξ_χ(s)（奇/偶字符 a=0/1——Gamma 因子）
- S_χ(t) = ∂²log|ξ_χ(½+it)| = Σ_ρ m_ρ K^nat_ρ(t) + S_reg,χ(t)
- K^nat_ρ(t) = (δ_ρ²−(t−γ_ρ)²)/(δ_ρ²+(t−γ_ρ)²)²（通用）
- **状态**：✅ 模 3/4 验证（Hadamard 零点项）——⚠️ S_reg,χ 是否=0 未单独验证
  （但判据 Q 只用零点项——S_reg 不进入 Q——不影响判据）

### A2. 测试对象 H_0（通用构造）
- H_0(t) = −(1/4π)log(1+t²) + 1/(2π(1+t²))——F⁻¹[ŵ_target/K̂₀]
- **不依赖 L 函数**（纯 Fourier——从 w_target 与核 K_0 构造）
- **状态**：✅（与 ζ 版相同——通用）

### A3. 配对权重 w_H 与成对正性 P_γ（闭式）
- w_H(γ,δ) = [a²(a+1)+δγ²]/(2(a²+γ²)²)——a = 1+δ
- P_γ(δ) = 2w_H(γ,0) − w_H(γ,δ) − w_H(γ,−δ) = δ²M₂/(2U²D₊D₋)
- **纯代数**（只依赖 K^nat 形式 + H_0 Fourier）——不依赖 L 函数/模/字符
- **状态**：✅ 模 4 验证（机器精度 3.4e-24）——✅ 模 3 验证（1.9e-20）——
  闭式推导（ζ 版 C2/C4）不依赖具体零点——通用

### A4. 等号刚性（Q_χ = Q'_{RH,χ} ⟺ χ 零点全在线）
- Q_χ = −Σ_ρ m_ρ w_H(γ_ρ,δ_ρ)——Q'_{RH,χ} = −Σ_ρ m_ρ w_H(γ_ρ,0)（投影）
- Q_χ − Q'_{RH,χ} = Σ_{轨道} m_ρ P_{γ_ρ}(δ_ρ)——P_γ > 0（δ≠0）——=0 ⟺ δ=0
- **P_γ > 0 的代数条件**：γ > 1/√5 ≈ 0.45（5γ²−1>0——5U²−16U+16 恒正——
  判别式 < 0——U≥1 恒正）——**L 函数零点 γ ≥ γ₁,χ ≥ 6.02 > 0.45**——自动满足
- **状态**：✅（模 3/4 装配验证——等号刚性依赖 P_γ>0——通用）

### A5. Weil 显式公式接口（L 函数版本）
- L 函数的 Weil 显式公式：Σ_ρ h(γ_ρ) = M(h) + P_χ(h) + 常数项
- **素数项含 χ(p)**：P_χ(h) = −Σ_p (χ(p)log p/√p)·ĥ(log p/2π) 类
- 核对：H_0 的 Weil 兼容性（H_0''∈L¹——素数项绝对收敛——含 χ(p) 调制）
- **状态**：🔴 未核对（ζ 版有——L 函数版本需重做——素数项 χ(p) 的影响——
  绝对值 ≤ log p/√p（|χ(p)|≤1）——绝对收敛应该仍成立——但需正式核对）

### A6. 族一致性（对任意模 q 任意 χ）
- 框架的每个对象（H_0/w_H/P_γ/Q 定义）**不依赖 q/χ**（纯代数——A2/A3）
- 判据对每个 χ 独立成立（A1-A4）——GRH = 对所有 χ 成立
- **统一论证**：只需概念证明"框架对任意 L(s,χ) 成立"——不需逐 χ 计算
- **状态**：⚠️ 需正式陈述（A1 的 Hadamard 展开对任意 χ——A5 的 Weil 接口
  对任意 χ——A4 的 P_γ>0 对任意 γ≥γ₁,χ）——数值已验模 3/4——概念论证待写

## C 链：AP 分布 ⟹ 强哥德巴赫渐近（标准——引用）

### C1. 圆法分解
- r(n) = ∫₀¹ S(α)²e^{−2πinα}dα——major arcs（a/q 附近）+ minor arcs
- **状态**：✅ 标准（Hardy-Littlewood 框架）

### C2. Major arcs 主项
- 主项 = 奇异级数 S(n)·n/log²n——S(n) = 2C₂·Π_{p|n,p>2}(p−1)/(p−2)
- **状态**：✅ 标准

### C3. Major arcs 误差（素数 AP 分布——GRH 控制）
- 需要 ψ(x;q,a) 的强分布（B2）——GRH ⟹ 误差可控
- **状态**：✅ 标准（——GRH 版圆法——Hardy-Littlewood 1923——）

### C4. Minor arcs 估计
- |S(α)| 的上界——Vinogradov 型（无条件）或 GRH 强化
- 强哥德巴赫需要 |S(α)| ≤ N/(log N)^A 在 minor arcs——GRH 下成立
- **状态**：✅ 标准（——GRH 版本——）

### C5. 强哥德巴赫渐近
- GRH ⟹ r(n) = S(n)n/log²n·(1+o(1))——充分大偶数
- **状态**：✅ 标准（Hardy-Littlewood 1923——GRH 假设下）

### C6. 数值衔接
- 充分大 → 所有：已验证到 4×10¹⁸（——如果渐近的"充分大"阈值 ≤ 4×10¹⁸——）
- **状态**：⚠️ 阈值核对（——渐近的显式阈值通常很大——需要确认可衔接——）
  （注：很多 GRH 版哥德巴赫的阈值是天文数字——数值衔接可能不现实——
  这是"渐近"与"全猜想"的差距——诚实标注）
