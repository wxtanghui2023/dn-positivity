## §2 不足性论证（形式化）

原 `(2,2,1)` 约束具有**三个节点**的信息。此前约化从

```
2T_q(a) + 2T_q(b) + T_q(c) ≤ 1/2
```

利用 `T_q(c) ≥ −1` 得到

```
T_q(a) + T_q(b) ≤ 3/4
```

再令 `σ = (θ_a + θ_b)/2`、`δ = (θ_a − θ_b)/2`，得到

```
cos(qσ)cos(qδ) ≤ 3/8
```

因此有逻辑链

```
原系统 ⟹ 二参数约化系统        （这条蕴含是**正确**的 ✓）
```

但若二参数系统存在可行点，则**不能**反推

```
二参数系统可行 ⟹ 原系统可行        ✗
更不能反推 原系统不可行            ✗
```

本档显式证书恰好说明 `二参数系统 ≠ 空集`。所以该约化**不足以**完成原问题的不可行性证明。

这也精确解释了此前 P/N 对撞机制的局限：

```
P = { q : A_q > 3/8 }   提供 δ 上界
N = { q : A_q < −3/8 }  提供 δ 下界
```

但在剩余 σ 区域，这些上下界**并不必然发生对撞**；显式 `(σ, δ)` 证书已经给出一个完整的反例 ✓。

因此继续细分 σ，只是在寻找一个**已经被证明存在可行点的约化系统**的空区间，**不能完成全域封口** ✗✓
