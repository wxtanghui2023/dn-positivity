## §0 硬闸（✓ 不可绕过 ✗）

$$\boxed{\text{任何外部定理／论文结果，进入推导前必须填满下表四项 }(\mathcal O,\mathcal D,\mathcal H,\mathcal C)\ ✓}$$
$$\boxed{\text{若 }(\mathcal O,\mathcal D,\mathcal H)\ \textbf{不能从原文【逐字】确认 ✗}\ \Longrightarrow\ \textbf{该结果【不得进入推导 ✗】}}$$
$$\textbf{禁止的推理 ✗}：\ \boxed{\text{"形式相似"}\ \Rightarrow\ \text{"对象相同"}}\ \ \text{（本项目 }8+\ \text{次死于此 ✗）}$$

## §1 强制表（✓ 复制到每个使用处 ✓）

```
【引用来源】文件/arXiv/书 + 版本 + 页码/定理号：
【取用日期】：
────────────────────────────────────────────────────────
𝒪  【对象的精确定义】（符号 + 原文定义句，逐字）：
    ⧉ 原文逐字：
𝒟  【定义域 / 参数范围】（变量范围、取值域、是否有限维）：
    ⧉ 原文逐字：
ℋ  【全部假设】（正则性、支撑、界、单调性、可测性…）：
    ⧉ 原文逐字：
𝒞  【允许调用的结论】（该定理【直接给出】的是什么，不是什么是）：
    ⧉ 原文逐字：
────────────────────────────────────────────────────────
【接口核对】本项目的哪个量 = 上式中的 𝒪？【等式/不等式，写出来】
【边界核对】本项目该量所在范围 ⊂ 𝒟 吗？若不 ⊂ ⟹ 停止 ✗
【假设核对】ℋ 本项目满足吗？逐条打勾，缺一 ⟹ 停止 ✗
【可否升级】若假设不满足：| 可减弱？ | 需换定理？ | 需自证？
【一票否决】以上任一栏为空 ⟹ 本结果【不得进入推导 ✗】
```

## §2 三条使用规则（✓）

$$\textbf{规则 1（逐字 ✓）}：\text{引用必须【抄原文句】✗，}\textbf{不得凭摘要／记忆／二手综述 ✓}$$
$$\qquad\text{（}\text{本项目实例 ✓}：E88\ \text{的"骨架"来自 arXiv:2006.08503 ✓ —— 后证实是 }\textbf{RH 情形的 }S_n\ \text{高阶矩 ✓，非所需的无条件 Thm 6/7 ✗}）}$$
$$\textbf{规则 2（接口先行 ✓）}：\text{先写【接口等式 ✓】，再谈"能用"✓}；\textbf{接口写不出的 ⟹ 不可用 ✗}$$
$$\qquad\text{（}\text{实例 ✓}：E93\ \text{把 Karatsuba Thm 4 用于 }S\ \text{的余项 ✓，}\textbf{实为 }S_1=\int_0^tS\ \text{级 ✗}）$$
$$\textbf{规则 3（对象优先于精度 ✓）}：\text{宁可【对象对、精度粗 ✓】，不可【对象错、精度细 ✗】}$$
$$\qquad\text{（}\text{实例 ✓}：E63/E64\ \text{围绕 }\Phi\ \text{vs }\Phi^2\ \text{来回三次 ✗ —— 对象定死后一行解决 ✓}）$$
