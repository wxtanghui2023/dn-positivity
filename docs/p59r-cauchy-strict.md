# P5.9-R：Cauchy 配置定理的严格化——四步审计结果

> 核心：positive ⇏ coercive 的严格化——Rigidity Gap 从观察变成可验证命题

## 配置定义（P5.9-R 第 1 步）
**规则排列配置**：ρ_j = β + iγ_j（β > 1/2），γ_j = γ₀ + jδ（j = 0,...,J−1），δ = c/log γ₀
- **最小间距**：γ_{j+1} − γ_j = δ ≥ c/log γ_j（对所有 j——因为 γ_j ≥ γ₀）
- **局部密度**：J 个零点在 [γ₀, γ₀+Jδ]——密度 ~ 1/δ ~ log γ₀（规定的）

**Gram 核**：K_T(j,k) = ∫_{logT}^∞ e^{(ρ_j+ρ̄_k−2)u}du = T^{2β−2}e^{i(γ_j−γ_k)logT}/(2−2β−i(γ_j−γ_k))

## P5.9-R 第 2 步：正定性 ✅
K_T 是 Gram 矩阵（内积 <e^{ρ_j u}, e^{ρ_k u}>_{L²([logT,∞), e^{−2u}du}）——**Hermitian 正定——无条件**（任何配置）。
归一化相关矩阵 K̃（对角=1）：K̃(j,k) = e^{i(j−k)θ}(2−2β)/(2−2β−i(j−k)δ)，θ = δlogT。

## P5.9-R 第 3 步：Cauchy 行列式 ✅（闭式——但渐近修正）
**K̃ = D₁CD₂（对角缩放 × Cauchy 矩阵）**——C(j,k) = 1/(x_j−y_k)，x_j = 2−2β−iγ_j，y_k = −iγ_k：
- **Cauchy 闭式验证**：直接 det vs 闭式——比值 1.0000（J=2..6——完全一致）✅
- **|det K̃| = (2−2β)^J·|det C|**——T 完全抵消（det 与 T 无关——数值确认 λ_min 不随 T）
- **det 退化**：log|det K̃|/J²logJ → 0（J=100: −0.16 → J=1600: −0.008）——**主导项（J²logJ）完全抵消——真实退化更低阶**
- **精确渐近**：分子（Vandermonde）~ J²logJ − (3/2)J² + J²logδ——分母 ~ 同阶——**差 ~ O(J log J) 阶（次主导）**——log|det K̃| ~ −c·J·logJ（c ~ 13-15——数值 log/(JlogJ) ~ −15 波动）——**⚠️ 需要 Euler-Maclaurin 高阶项精确确定（不是 e^{−cJ²}——之前"超指数"错误已修正）**

## P5.9-R 第 4 步：λ_min 上界 ⚠️（关键——det → λ_min 的步骤）
**唐先生的框架**：
- det = Πλ_j——det 退化只给**几何平均**（det^{1/J} ~ e^{−c logJ} = J^{−c}——多项式）
- 要 λ_min 的"紧"上界——需要 λ_max 控制：**λ_min ≤ det/λ_max^{J−1}**（若 λ_max ≤ M）
- λ_max(K̃) ≤ tr(K̃) = J（对角=1——相关矩阵）——**λ_max = O(J)**
- **但——λ_max ≥ 1（相关矩阵）——det/λ_max^{J−1} 是"下界"方向（λ_min ≥ det/λ_max^{J−1}）——上界需要 Π_{j≠min}λ_j 的控制——不直接**

**数值（直接测量）**：
- **λ_min 超快退化**：J ≥ 20 时 < 1e-300（机器精度下溢）——**谱 gap 缺失确凿**（相对真实零点 λ_min ~ 0.13-0.22——比值 1e299）
- **⚠️ 但**——λ_min 小 ≠ 固定方向小（见下）

## P5.9-R 补充检查：固定方向（B 反例的直接判定）⚠️
**B 反例需要 ⟨a, K_T a⟩ = O(T^{−1+ε})（a = 1/ρ——固定系数）**——λ_min 小只给"最坏方向"——不直接给固定方向：

| 配置 | ⟨a,K̃a⟩/||a||²（J=40） | （J=240） | 趋势 |
|------|:--:|:--:|------|
| **规则排列** | 0.086 | 0.0098 | **~1/J 线性退化（→0）** |
| **真实零点** | 0.956 | 0.895 | **稳定 ~0.9（有下界）** |

**如果 ⟨a,K̃a⟩/||a||² ~ 1/J 严格**：
- V(T) = T^{2β−2}/(2−2β)·⟨a,K̃a⟩ ~ c·T^{2β−2}/J——J ~ N(T) ~ T log T
- **V(T) ~ c·T^{2β−3}/log T——β=0.6——T^{−1.8}/log T = O(T^{−1+ε})——B 反例成立！**
- **⚠️ 但——需要严格证明退化速率（数值 1/J 趋势——未严格建立）**

## ⭐ P5.9-R 最终判定（诚实）

### 可确认（数值强 + 闭式支持）
1. ✅ K̃ 正定（Gram——无条件）
2. ✅ Cauchy 闭式正确（比值 1.0）——det 退化（JlogJ 阶——主导抵消）
3. ✅ **谱 gap 缺失**：规则排列 λ_min 超快退化（< 1e-300 @ J=20）——**G_geom ⇏ G_coercive——Rigidity Gap Proposition 成立（数值层面）**
4. ⚠️ **固定方向退化**：⟨a,K̃a⟩/||a||² ~ 1/J（数值）——**B 反例方向——但严格证明未完成**

### 需要补（从数值到定理的差距——唐先生踩刹车的原因）
1. **λ_min 退化的严格证明**：det（JlogJ 阶）+ λ_max 控制（λ_max = O(J)）——**但——det/λ_max^{J−1} 给下界——上界需要 Π_{j≠min}λ_j 控制——需要"谱分布"论证（如——除 λ_min 外所有 λ_j ≥ c > 0？——需验证）**
2. **固定方向 ⟨a,K̃a⟩ ~ 1/J 的严格证明**：a = 1/ρ 的结构（同相位）+ K̃ 的傅里叶型——**需要完整推导（E 部分的理论框架——Σ_m e^{imθ}/(2−2β−imδ) 的估计）**
3. **退化速率的精确阶**：log|det| ~ −cJlogJ（c 的精确值——Euler-Maclaurin）——λ_min 真实退化（比 det^{1/J} 快——需谱论证）

### 定理表述（最终——唐先生的框架）
**Rigidity Gap Proposition（严格版——目标）**：
存在满足最小间距约束 + 规定密度的频率配置 {γ_j}（规则排列）——其 Gram 核正定（无条件）——但：
- (a) 最小特征值无统一正下界（λ_min → 0——谱 gap 缺失）；

**即：G_geom ⇏ G_coercive——几何约束（间距/密度/正定）不提供谱 gap——也不提供固定方向的 exclusion。**
