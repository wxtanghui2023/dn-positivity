$$\textbf{(a) }\Theta:\mathfrak K\to\mathfrak S_{\rm density}\ \text{被当作}\ \textbf{函数} \text{使用} \Longrightarrow \text{预设了"每个强度点}\ q\ \text{唯一决定一个 density exponent"}$$
