# GPS 源考古：什么结构能产生【内生方向】？（S1–S8 分类）

**日期**：2026-09-10 18:20+ ｜ 依据：唐先生「ABD 代结束 → GPS 成为新阶段入口 → 寻找 generating principle 的来源；先不提出具体模型」
**本轮任务（原话）**：
> **什么数学结构能够产生一个"方向场"，同时这个方向不是从目标几何量读取出来的？**
**要求形态**：$\text{primitive law}\to\text{intrinsic direction}\to\text{cross-scale constraint}\to\text{rigid critical exponent}$
**禁止形态**：$\text{arithmetic statistic}\to\tfrac12$

## §1 内生动方向的来源分类（S1–S8）
> 表中 **GPS profile** = 预先判断该源在五门下的典型风险（**判断，非定理**）；**已知实例** 引本项目既有登记。

### S1 不可逆动力学生成元（semigroup generator）
* 方向 = 单参数半群 $e^{tA}$ 的生成元切场 $A\cdot x$
* 为何内生：方向来自**不可逆性**本身，与任何目标泛函无关 ✓
* ⚠️ **G4 结构性风险**：耗散型生成元**丢信息**（热量方程型）⟹ 多数不可逆流**死在 G4**
* ⭐ 唯一 G4-相容的不可逆性是 **单射非满射**（如 $n\mapsto 2n$：不可逆但保信息）
* 已知实例：D2/solenoid（**群**流 ⟹ 无箭头 ⟹ 无方向场）⟹ 已 CLOSED

### S2 序 / 偏序方向（order, positivity）
* 方向 = 严格序：**整除 ↑**（算术中最标准的箭头）、$\le$ 于 $\mathbb N$
* 为何内生：序是原始结构的一部分 ✓；保信息 ✓（序即数据）
* ⚠️ **G2 结构性风险**：序方向通常**随规模/合数性单调** ⟹ 极易退化为 $g$-支配或规模支配
* 已知实例：O4（有向关系审计）｜进位层（CLOSED）｜**ABD-1′ 的 $g$-支配本质上是 S2 型方向** ⟹ **S2 在 G2 上结构性脆弱**

### S3 ⭐⭐ 构造 / 项方向（vertical：operand → operation）
* 方向 = **算术"构造"本身的箭头**：由操作数指向操作（$(a,b)\to a+b$ 是"下游"）
* 为何内生：方向来自**半环语法/项结构**，与任何目标量无关 ✓✓；**算术原生** ✓
* G4：状态 = 推导/项本身 ⟹ 保信息 ✓（**陷阱**：若**按 AC 规范化**（交换/结合律取商）即**立刻违 G4**）
* G2：与 $g$ **无天然关系** ⟹ 不 $g$-支配 ✓（待构造验证）
* 已知实例：**本项目未被触碰** —— ABD 全部动力学都是**保关系**的（$a'+b'=c'$），即"沿关系图的水平方向"，
  从未使用"由操作数**产生**和"的垂直方向 ⭐

### S4 非交换 / 交换子方向（commutator, non-commutativity）
* 方向 = 两个原始运算交换次序时的**缺陷**（holonomy / commutator）
* 为何内生：缺陷由结构决定，不读目标 ✓
* G4 ⚠️：缺陷量常为不可逆/多对一
* 已知实例：运输曲率、$K_2$ 矩阵曲率、分配律/结合律 holonomy、进位层 —— **全部已 CLOSED**
  （死因：coboundary / hardcoded history / CRT 独立）⟹ **已知封闭类**

### S5 自对偶不动点方向（flow toward the fixed locus）
* 方向 = 朝某个对合的不动点流动
* ⚠️ **G3 结构性风险**：不动点常**就是**目标几何量 ⟹ 读目标
* 已知实例：N1（$H=X/H$）、N5（$|\tau|^2=q$）、FE 中心（$s=1/2$）——**全部 CLOSED**；
  且自对偶"减半"**按构造**给出 $1/2$ ⟹ **反调参测试必淘汰** ⟹ **已知封闭类**

### S6 模空间上的形变场（deformation field）
* 方向 = 算术对象模空间上的规范向量场
* G1 ✓（若不引用目标）；G3 ✓
* ⚠️ **G4 结构性风险**：模空间**本身是商**（$\cong$ 类）⟹ 违 G4（除非用带标记/有结构的版本）

### S7 谱 / 本征方向（spectral）
* 方向 = 由谱分量（本征向量/指数）给出
* ⚠️ **G1 + N3 双重风险**：内容住在既有谱理论里；HP 型包已被排除
* 已知实例：Hilbert–Pólya 族、D1/D3 谱路线 —— 已 CLOSED

### S8 迭代 / 自映射方向（iteration, self-map）
* 方向 = 任一自映射 $f$ 的迭代（"时间"由 $f$ 自己的迭代给出）——**最弱也最一般的源**
* G1 ✓（不需目标）；G3 ✓；G4 ✓（当且仅当 $f$ 单射）
* ⚠️ **G2 风险**：迭代量的增长若对某规模/$g$ 单调 ⟹ 退化
* 已知实例：ABD-1 的 R1/R2（gcd/2-adic 缩：**保比** ⟹ 无有效方向）｜ABD 的 ℤ² 保关系流（$g$-支配）

## §3 ⭐⭐ 关键结构观察：水平 vs 垂直
```
ABD 全部动力学（ABD-1 的 L1/L2、ABD-1′ 的 ℤ² 流）都是【保关系】的：
      (a,b,c) → (a+p, b+q, c+p+q)，即"沿关系 a+b=c 的图移动"（水平）
      其合法性由整除给出（增量 ∈ gℤ）⟹ **方向被 g 支配**（= S2 型）
      故 ABD-1′ 的反对齐不是偶然：**水平 + 整除合法性 ⟹ 必然 g 支配 ⟹ G2 必败**

从未被触碰的是【垂直方向】：由操作数【构造】出和的方向（S3）
      —— 它不沿关系的图移动，而是"生成关系本身"
      —— 与 g 无天然关系 ⟹ 不落入 ABD-1′ 的失败机制
```
$$\boxed{\text{ABD 代的失败可重述为：它一直在【水平方向】里工作，而水平+整除合法性 ⟹ }g\text{-支配}}$$
$$\boxed{\text{因此"生成原则的来源"问题，最有信息量的第一站是 S3（垂直/构造方向）}}$$
