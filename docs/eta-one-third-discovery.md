# ⭐ 重大发现：η_j ~ C·(−1/3)^j 渐近——λ~_n = O(1) 的结构钥匙（2026-09-08）

> dn-project ｜ 从"相位均匀性突破 → 我们的突破点"逐条验证中发现

## 发现（数值——高精度 mpmath——）

**Maślanka 递推的 η_j 比率精确收敛到 −1/3**：
```
η_j/η_{j-1}：j=5: −0.320——j=10: −0.3325——j=15: −0.3333——j=25: −0.333333
→ η_j ~ C·(−1/3)^j 渐近（几何——精确 1/3——）
```

**λ~_n = −Σ C(n,j)·η_{j-1} 的 O(1) 由此解释**：
```
若 η_j ~ C(−1/3)^j：λ~_n = −C·Σ C(n,j)(−1/3)^{j-1}
  = −C·3[1−(2/3)^n] → −3C（常数——）——O(1) 且指数收敛
```

## 鲁棒性（关键——）

**η 的 −1/3 对 γ_m 细节鲁棒**：
- γ_m 大 m 扰动 +1% → η 比率不变（−0.333328 = −0.333328）
- γ_m 截断（m>15 置零）→ η 的 j≤25 渐近不变（−0.333328）
- 但 γ_m 替换为几何 q^m → η 比率不同（非 −1/3）——−1/3 依赖真实 γ_m 低阶

**⟹ −1/3 来自真实 Stieltjes 常数（无条件可算——）的低阶结构**

## 高零点离线不可检测（低阶——）
```
单零点对 γ_m 贡献 ~ 1/γ₀^(m+1)
高零点（γ₀>10⁶）离线 → 影响 γ_m ~ 1/γ₀^16——1e-35 相对——不可检测
低零点离线 → 影响大——可检测
⟹ 高离线影响只在"巨大 n"（η_n 高阶——）显现（与逃逸一致——）
```

## 意义

1. **λ~_n = O(1) 的结构原因清楚了**：η 几何衰减 → 二项式变换收敛
2. **−1/3 的来源待解释**：可能来自 ξ 的显式结构（无条件——）——若可证——λ~_n=O(1)→λ_n≥0→RH
3. **循环风险定位**：高离线破坏 η 的高阶渐近（n~2γ²/δ——）——需要"η 全阶渐近的无条件证明"
4. **关键问题**：γ_m（Stieltjes——）的渐近无条件可证吗？（文献多假设 RH——）
