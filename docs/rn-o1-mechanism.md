## 1. 决定性检验结果（rn_random.py）

### 逐区间差分解

$$d_k = f_n(\gamma_k) - \int_{\gamma_k}^{\gamma_{k+1}} f_n(t)N'(t)dt$$

部分和 $S_K = \sum_{k\le K} d_k \to r_S$（精确分解的离散形式）

### 部分和收敛（非随机游走！）

| n | S_K/√K (K=10%→100%) | 结论 |
|---|---|---|
| 500 | −0.004 → −0.000 | 相消 ✓ |
| 1000 | 0.091 → 0.030 | 相消 ✓ |
| 2000 | 0.248 → 0.078 | 相消 ✓ |

**若 d_k 独立 → S_K ~ √K 随机游走 → 排除！**

## 4. 完整机制链条

```
r(n) = Σf_n(γ) − ∫f_n N'dt         精确分解（误差<0.03）
     = Σ_k d_k                      逐区间差
     ↓
零点间距偏差 δ_k = Δγ_k − 1/N'
δ_k 相邻负相关（lag-1 ≈ −0.39）     ← GUE 能级排斥！
     ↓
d_k ≈ f·N'·δ 继承负相关 → 成对相消
     ↓
Var(Σd) ≈ Kσ²(1+2Σρ_lag) 压缩 2-5×
     ↓
S_K/√K → 0，Σd = O(1) 有界振荡
```

## 5. 理论意义（⚠️ 修正后）

### d_k 负相关与能级排斥的联系（启发式）

- **数值事实**：d_k 相邻负相关（lag-1 ≈ −0.39）导致方差压缩，Σd = O(1)
- **物理解释**：与 GUE 能级排斥（大间距后倾向小间距）的间距反关联一致
- **⚠️ 不严格等价**：ζ 零点的 GUE 统计是**猜想**（Montgomery-Odlyzko）；d_k 负相关是数值观察，不能推出 GUE 统计，反之亦然

### 关键未决问题（诚实）

1. d_k 负相关能否从**无条件已知结果**推出？
   - Montgomery (1973) 对关联 R₂(x) 对支撑 |α|<1 无条件，但 d_k 负相关需更强局部信息
   - 目前：**否**（搜索确认，文献都是二阶/粗粒度）
2. GUE 型对关联 → O(1) 推导路径：**未闭合**（且 GUE 本身是猜想）
3. 能级排斥统计**不排除有限个离轴零点**（统计对异常值不敏感）——与 β 依赖分析一致：有限数据无法排除高 γ 离轴零点

## 6. 数值局限（诚实）

- 梯形近似（区间积分）有系统偏差（Σd vs r_total 差 ~2-6）
- 截断到 20n（f 衰减后，误差应小）
- 2M 零点有限（n≤3000）
- 需要更精确的区间积分验证（辛普森/高斯）
