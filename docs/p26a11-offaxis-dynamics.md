# P26-A11：离轴 β 动力学——轨道模式——关键认识

> 2026-09-01 · 继续 Level III · 离轴 β 动力学探索

## P26-A11 结果

### ① 轨道结构（离轴零点的 δ 模式）
- 离轴零点 ρ = β+iγ（β≠½）——四元素轨道 {ρ, ρ̄, 1−ρ, 1−ρ̄}
- FE（反射对）：δ_{1−ρ} = −δ_ρ——δ_{1−ρ̄} = −δ_ρ̄
- 共轭（实 b_p）：δ_ρ̄ = conj(δ_ρ)
- 轨道 δ 模式：δ_ρ, conj(δ_ρ), −δ_ρ, −conj(δ_ρ)——Re δ：+, +, −, −
- **Σ Re δ（轨道）= 0（零和守恒）**——但——个体 Re δ_ρ ≠ 0 可能

### ② 在线 vs 离轴（约束合并的关键差异）
- 在线（β=½）：1−ρ = ρ̄——FE 和共轭同一位置——conj(δ_ρ) = −δ_ρ——Re δ_ρ = 0——β 不变 ✓
- 离轴（β≠½）：1−ρ ≠ ρ̄——不同位置——不冲突——Re δ_ρ ≠ 0 可能——β 可移动
- A10 修正确认（β 不变 = 在线——离轴可动）

### ③ 数值（轨道模式）
- 离轴 ρ = 0.4+14.13i——δ_ρ = 1+0.5i（Re = +1——β 移动）
- 轨道：+1+0.5i（ρ）, +1−0.5i（ρ̄）, −1−0.5i（1−ρ）, −1+0.5i（1−ρ̄）——Σ Re = 0 ✓

### ④ 离轴 β 移动的约束
- FE + 共轭：不排除（不同位置——轨道 ±——零和）
- 增长（ζ 型）：零点密度不约束 β 位置——零点计数（N_t(T)）：γ 通道——不含 β
- **"离轴 β 移动"（Re δ_ρ ≠ 0）——FE/共轭/增长/计数——都不排除**
- 但——"完整合法变形"（Euler 结构）——离轴 β 移动——未构造——"局部允许 vs 全局存在"未闭合

### ⑤⑥ ⭐ 关键认识——变形不改变 ζ 本身
- **F_t 的零点（ρ + tδ_ρ——移动）——但——ζ = F_0 的零点（ρ——t=0）**
- **"变形动力学"（t 演变——零点移动）不改变"t=0 的配置"**
- **"RH"（ζ = F_0 的零点在线）是"初始配置"**——变形下 β 移动描述"演变"——不说明"初始"
- **"离轴 β 动力学"——对 RH——原则上无直接信息**——除非"t=0 是特殊点"（吸引子——de Bruijn-Newman 类——但那是 H_t——不是我们的 Euler 变形）

## ⭐ P26-A11 判定
- 轨道模式（±——零和守恒）——离轴 β 可移动（FE/共轭/增长不排除）
- **变形动力学不改变 ζ 本身（t=0）——对 RH 无直接结论**
- "在线不变 + 离轴可动"——结构认识——但——变形的 β 动力学不 ⟹ RH
