## 1. ① 展开：$|S_n|^4$ 的精确分解（✓）

```
|S_n|⁴ = Σ_{γ₁γ₂γ₃γ₄} e^{in(θ₁−θ₂+θ₃−θ₄)} ✓
【对角（多重集相等）✓】**三种配对**：{γ₁=γ₂, γ₃=γ₄} ✓｜{γ₁=γ₃, γ₂=γ₄} ✓｜{γ₁=γ₄, γ₂=γ₃} ✓
   各贡献 N² ✓ ⟹ **对角 = 3N²** ✓✓ —— **这正是高斯预测值** ✓
【非对角 ✓】其余配置 ✓ ⟹ 由**两队的差配对**（即对相关测度的二阶矩 ✓）控制 ✓
⟹ **M₄ = 3N² ＋ 非对角** ✓（精确 ✓）
```

## 2. ② 控制：非对角由**无条件**对相关给出（✓ 定性 ✓）

```
【结构 ✓】|S_n|² = A_n := Σ_u N_u e^{inu} ✓（N_u = 差为 u 的配对计数 ✓）⟹ **|S_n|⁴ = A_n²** ✓
   ⟹ 即 **对相关测度的【二阶矩】** ✓ —— 而 **对相关无条件** ✓（Montgomery ✓；[BGSTB24] Thm 1 ✓；我方 E57 已数值验证零点侧形态 ✓）
【⚠️ 诚实 ✓】这一步目前是**控制关系** ✓；要用它**算出带常数的界**，仍需**一致性（in n ✓）** ✗
```

## 3. ③ 判据换算成常数（✓ 关键一步 ✓）

```
【Markov 零例外 ✓】#例外 ≤ |I|·M_{2k}/(0.8N)^{2k} < 1 ✓ ← 取阈值 0.8N（因需 c ≥ 0.2 ✓）

   ⟹ 需 M₄ < 1.02e13 ⟺ **C < 1.02e13/N² = 2.55** ✓✓（M₄ = C·N² 归一 ✓）
【对照 ✓】高斯 C = 3 ✗（**恰好差一点** ✓ —— 与 E65 的"真实尺度 c₂ = 0.832 > 0.8" ✓ 同一事实 ✓）

```
