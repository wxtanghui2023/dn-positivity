## 1. 装置（✓ 逐条复述，全部为定义/初等事实 ✓）

```
【窗口 ✓】ψ ∈ C²([−1/2,1/2])，偶、正 ✓；本文用两例：ψ₀ = 1_{[−1/2,1/2]} ✓、
   ψ_MT(s) = cos(√2 s)·1_{[−1/2,1/2]}(s) ✓
【截断 ✓】χ ∈ C^∞(ℝ) 非降 ✓、χ|_{(−∞,0]} = 0 ✓、χ|_{[1,∞)} = 1 ✓
【长度 ✓】L := log(T/2π) ✓，X := e^L = T/2π ✓
【测试函数 ✓】φ(u) := χ(L/2+u)·χ(L/2−u)·ψ(u/L)^{1/2} ✓
   ⟹ φ ∈ C²_c(ℝ) ✓、偶 ✓、0 ≤ φ ≤ 1 ✓、supp φ = [−L/2, L/2] ✓、φ² = ψ(u/L) 在两条过渡带外 ✓
【关键衰减 ✓】φ̂(z) ≪_χ e^{(L/2)|Im z|}·min(L, |z|^{-1}, |z|^{-2}) ✓（Paley–Wiener + 分部积分 ✓，
   由 ‖φ‖₁ ≤ L ✓、‖φ′‖₁ ≪ 1 ✓、‖φ″‖₁ ≪ 1 ✓）
【采样 ✓】**临界密度** h := 2π/L ✓；α_k := T + hk ✓；d := ⌊LT/2π⌋ ⟹ α_0..α_{d−1} ∈ [T,2T) ✓、d = N(T,2T)+O(L) ✓
【向量与矩阵 ✓】v_ρ := (φ̂(γ_ρ − α_k))_{0≤k<d} ✓；a := ‖φ‖²₂/L = ∫ψ + O(L^{-1}) ✓
   G̃ := (aL²)^{-1} Σ_{Re γ_ρ ∈ I′} m_ρ v_ρ v_ρᵀ ✓（P ✓、Q := G̃ − P ✓、Ẽ ✓ 同 §2.3 ✓）
【为何 h = 2π/L ✓】这是**临界**密度：Poisson 对偶格步长 = 2π/h = L，恰等于 φ 的支撑长度 ✓
   ⟹ 相邻平移的支撑**刚好不重叠** ✓ ⟹ 无混叠 ✓（这正是 §2 的核心 ✓）
```

## 2. ⭐ **独立证明：Poisson–Gabor 恒等式**（✓ 我方证明 ✓）

```
【断言 ✓】对所有 z, z′ ∈ ℂ： Σ_{k∈ℤ} φ̂(z−α_k)·φ̂(z′−α_k) = L·(φ²)^(z−z′) ✓
   （记号 ✓：(φ²)^(ξ) := ∫_ℝ φ(u)² e^{−iξu} du ✓，即 φ² 的 Fourier 变换 ✓）

【证明 ✓】
(1) 记 Υ(s) := φ̂(z−s)·φ̂(z′−s) ✓。由 φ ∈ C²_c 与 φ̂ 的衰减 ✓ ⟹ Υ 光滑且 Υ(s) = O(|s|^{-4}) ✓
    ⟹ Poisson 求和合法 ✓：Σ_{k∈ℤ} Υ(T+hk) = (1/h) Σ_{m∈ℤ} Υ̂(2πm/h)·e^{2πimT/h} ✓
(2) 计算 Υ̂ ✓。由 φ̂(w) = ∫φ(u)e^{−iwu}du ✓：
    Υ(s) = ∬ φ(u)φ(v) e^{−izu} e^{−iz′v} e^{is(u+v)} du dv ✓
    ⟹ Υ̂(ξ) = ∫Υ(s)e^{−iξs}ds = 2π∬ φ(u)φ(v) e^{−izu−iz′v} δ(u+v−ξ) du dv
             = 2π∫_ℝ φ(u) φ(ξ−u) e^{−izu−iz′(ξ−u)} du ✓
    特别 ξ = 0（**唯一存活的对偶项** ✓）：
       Υ̂(0) = 2π∫φ(u)φ(−u)e^{−izu+iz′u}du = 2π∫φ(u)² e^{−i(z−z′)u}du = **2π (φ²)^(z−z′)** ✓（φ 偶 ✓）
(3) **非零对偶项全为零** ✓。对 m ≠ 0，ξ = 2πm/h = mL ✓，被积函数含 φ(u)·φ(mL−u) ✓；
    两项支撑分别为 [−L/2, L/2] 与 [mL−L/2, mL+L/2] ✓，对 m ≠ 0 **不相交** ✓ ⟹ Υ̂(mL) = 0 ✓
(4) 合并 ✓：Σ_k Υ(T+hk) = (1/h)·Υ̂(0) = (L/2π)·2π(φ²)^(z−z′) = **L(φ²)^(z−z′)** ✓ ∎

【⭐ 推论（前沿未强调 ✓，但对我方有用 ✓）】**恒等式与格偏移 T 无关** ✓ ——
   T 只出现在 (1) 的相位因子 e^{2πimT/h} 中 ✓，而它们乘在 (3) 中**恒为零**的项上 ✓
   ⟹ 抵消 ✓ ⟹ 可取 **T = 0** ✓（数值验证据此才可行 ✓，见 §4–§5 ✓）
   ⚠️ 对照 ✓：前沿的证明确实带着该相位 ✓（从文本可见 ✓），但**未指出**它无关 ✓
```

## 3. 迹推论（✓ 前沿 Prop 4.2 所用的分解 ✓）

```
取 z = z′ = γ ∈ ℝ（零点的实纵坐标 ✓），由 §2 的恒等式 ✓：
   Σ_{k∈ℤ} φ̂(γ−α_k)² = L·(φ²)^(0) = L·∫φ² = **aL²** ✓（因 a = ‖φ‖²/L ✓）
切到 [0,d) 与其余 ✓ ⟹ **tr(v_ρ v_ρᵀ) = Σ_{0≤k<d} φ̂(γ−α_k)² = aL² − Σ_{k∉[0,d)} φ̂(γ−α_k)²** ✓
   ⭐ 这正是前沿 Prop 4.2 计算 tr G̃ 的起点 ✓；而其尾部估计（Prop 4.3 ✓）用 φ̂ 的
      |z|^{-2} 衰减 ✓ + α_k ∉ [T,2T) ⟹ |Re γ_ρ − α_k| ≥ dist(Re γ_ρ, {T,2T}) ✓
```
✅ 说明 ✓：**该分解的合法性完全依赖 §2 的恒等式** ✓ ⟹ 我方独立证明后，这一步即可**独立使用** ✓。
