## 3. 定理 A/B 的完整链条（✓ 我方版本 ✓）

```
【装置 ✓】φ(u) = χ(L/2+u)χ(L/2−u)√ψ(u/L) ✓（C² 紧支撑 ✓）；临界 Gabor 密度 h = 2π/L ✓
   ⟹ 双格步长 = 支撑长度 ⟹ 相邻平移不重叠 ⟹ 无混叠 ✓
【恒等式 ✓（WP2 ✓，我方证明 ✓）】Σ_{k∈ℤ}φ̂(z−α_k)φ̂(z′−α_k) = L·(φ²)^(z−z′) ✓（Poisson 求和四步 ✓）
   ⭐ 且**与格偏移 T 无关** ✓（T 只出现在恒为零的对偶相位中 ✓）
【归约 ✓（WP3.1 ✓）】‖G̃+Ẽ‖²_HS = (a²L²)^{-1}∬Φ(τ−τ′)²ν_X(τ)ν_X(τ′)dτdτ′ + O(N log L/L²) ✓
   主项**就是**恒等式 ✓；误差 = 尾部 ℰ₁ + 区外 ℰ₂ ✓
【素数侧 ✓（WP3.2 ✓）】M[μ,μ]+M[P_X,P_X] = (TL³/2π)R(ψ)(∫ψ)² + O(TL²) ✓
   其中 **非对角 O₁ 全部依赖加权 Hilbert 不等式** ✓（**非猜想** ✓）⟹ **无条件** ✓
   ⟹ **‖G̃‖²_HS = (R(ψ) + O(L⁻¹))·N(T,2T)** ✓
【装配 ✓（WP4 ✓）】rank P₁ ≥ 4tr G̃ − 2N − ‖G̃‖²_HS ✓
   ⟹ ⭐ **N₀ˢ ≥ (2 − R(ψ) − o(1))N** ✓（R(ψ₀) = 4/3 ⟹ **2/3** ✓）
   ⟹ ⭐ **N_d ≥ ½(3 − R(ψ) − o(1))N** ✓（⟹ **5/6** ✓）
【我方独立验证 ✓】同一结论由**多重度 LP** 重推 ✓：核心标量事实 Σ_ρ m_ρ² ≤ R·N ✓
   （由 WP2 恒等式：对角项恰为 Σm² ✓、交叉项 ≥ 0 ✓）⟹ LP 最优值恰为 2 − R 与 (3 − R)/2 ✓✓
```
