# P49-G2.7.3-P1：Odd-Sector Exclusion——第一轮结果（粗界 FAIL + ground 分析）

> 2026-09-02 14:20 · 粗范数界失败 · odd ground 结构 · uniform 性待证

## 粗范数界 FAIL（预期——太粗）
- Σ_{n≤λ²}Λ(n)·B_n（B_n = ‖T(n)|odd‖ 谱范数）= 3.18 > −Q_prime(V₀) = 2.14——**FAIL**
- ⚠️ B_n 谱范数太粗——odd 块 T(n) 特征值混合符号——Q_prime = −ΣΛT 的组合有内部结构——范数和 overestimate

## Odd ground 分析（λ=3, N=8）
- odd 块 Q_prime 最小 = **−1.052**（N=4: −0.54——N=8: −1.05——**随 N 变化——在降**）
- **odd ground 系数集中高 k**（o_6 = −0.707, o_7 = 0.473, o_8 = 0.524——k=1-5 小）
- **⟨T(n)f,f⟩ 分布**：主要负贡献来自 n=2,3,4（小素数——Λ 大——⟨Tf,f⟩ = +0.59/+0.32/+0.33 正——−Λ⟨T⟩ 负）——n ≥ 7 贡献小——**正贡献几乎为零**（+0.002）
- Q_prime(odd ground) = −1.052——V₀ = −2.141——**差 = 1.09**

## 机制澄清（修正"odd 弱耦合"说法）
- **odd ground 不是"弱耦合"**（n=2,3,4 耦合强——⟨Tf,f⟩ ~ 0.3-0.6）——是"**每个模式的耦合被 Fourier 振荡限制**"——高 k 模式（o_6-8）与小素数 n 的卷积重叠——但总耦合有上限
- **V₀（常数——所有 n 同相）给 −2.14——odd（振荡——无常数模式）总耦合受限（−1.05）**
- 正贡献几乎零（不是"大量抵消"——是"odd ground 主要与小素数耦合——高 k 主导"）

## ⚠️ Uniform 性问题（P1 核心难点）
- **odd 最小随 N 变化**（N=4: −0.54——N=8: −1.05——在降）——⚠️ 若继续降——可能接近 V₀（−2.14）？
- V₀ 值固定（−2.14——只依赖 λ）——odd 最小能否到 −2.14？——需检查多 N
- **P1 定理形状**：证明对任意 odd f（‖f‖=1）：Q_prime(f) ≥ −2 + ε（uniform 下界——不随 N 恶化到 V₀）——机制：odd f 的 (f**f)(n) 受振荡限制（无常数模式——不能所有 n 同相）
- **需监控 odd 最小的 N 趋势**（若收敛到 > −2 的极限——uniform 性有希望——若趋近 −2.14——P1 失败）

## 判定
- **粗界 FAIL（工具错误——非 P1 失败）**
- **ground 分析揭示机制**（odd 高 k 模式 + 小素数耦合——总耦合受限——vs V₀ 常数全相）
- **P1 真正难点 = odd 最小的 uniform 下界**（不随 N 崩到 V₀）——需多 N 数值监控 + 解析振荡界
