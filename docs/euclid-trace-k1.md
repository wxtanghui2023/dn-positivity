# Euclidean Cocycle Tr(P_s^k) 测试：k=1 扭曲塌缩（2026-09-03 11:30）

## 对象
P_s f(x) = Σ_n Λ(n)(n+x)^{-2s} f(1/(n+x))
Tr(P_s^k) = Σ_{周期k连分数} Π_j Λ(n_j)(n_j+x_j)^{-2s}/|1-(T^k)'(x)|

## k=1 数值（N=200000）
Tr(P_s) = Σ_{n素幂} Λ(n)(n+x_n)^{-2σ}/(1+x_n²), x_n=(√(n²+4)-n)/2 (周期1固定点)

|---|---|---|---|
| 0.8 | 1.0296 | 1.1850 | 0.869 |

| 3.0 | 0.0040 | 0.0126 | 0.315 |

## 结构分析
- Tr(P_s) ≠ -ζ'/ζ(2s)（比值偏离大）——但**不是新谱——是"代数扭曲"**：
  (n+x_n)^{-2s} = ((n+√(n²+4))/2)^{-2s}——基底从整数 n 变二次无理数 (n+√(n²+4))/2
- 小 n 的 x_n 显著（x₂=0.414——(2.414)^{-6} vs 2^{-6} 差 3.4 倍）——系统偏差
- **扭曲塌缩**：Tr(P_s) = "代数扭曲的 -ζ'/ζ"（仍 Λ(n) 素数结构——n 标签——非整数幂基底）——无新零点谱证据

## 判断
- k=1 迹**塌缩（变体）**：不是纯 -ζ'/ζ(2s)——是它的代数扭曲（二次无理基底）
- 扭曲使"Euler 积"结构不显然（非整数幂——）——但**无新谱证据**（素数结构——n 标签——）
- k≥2（周期轨道——部分商耦合——）未测——完整判死需 k≥2（周期连分数枚举）
