# 凹势探索：ζ 零点不是任何势的平衡（2026-08-23 20:10）

> 唐先生想法：GUE 凸势 → 推导 ζ 的凹势对应物用于证明
> 结论：❌ 不成立——ζ 零点不是变分对象（凸或凹势平衡都不满足）

## 1. 探索内容

**GUE**：凸势 V(x)（高斯）——平衡测度（半圆律——凸优化唯一）——刚性

**ζ 假设**：完整势 φ(t) = Σ_{γ≠t}log|t−γ| + θ(t)（Γ 主项——Riemann-Siegel）
- 平衡条件：φ'(t) = 0——Σ1/(t−γ) = −θ'(t)

**验证**（数值）：
```
k=500:  Σ1/(γ_k−γ_j) = −2.40 vs −θ' = −2.43（比值 0.988——几乎精确）
k=10000: Σ1/(γ_k−γ_j) = −2.12 vs −θ' = −3.68（比值 0.58——偏离）
→ 大 k 偏离——ζ 零点不是完整势的平衡
```

## 2. Σ1/(γ_k−γ_j) 不是常数

```
窗口 ±10:   −0.94
窗口 ±5000: −1.23
窗口 ±20000: −2.85（增长——1/x 对数发散——远处累积）
随 k 振荡：γ_1000: −0.20, γ_5000: −1.14, γ_50000: +0.62（非普适常数）
```

**之前看到的"−2.5 常数"是假象**（特定窗口 + 特定 k）

## 3. 结论

1. **ζ 零点不是任何势的平衡**（凸或凹）——Σ1/(γ_k−γ_j) ≠ −θ'（大 k）
2. **"局部排斥普适常数"不存在**——Σ1/ 随窗口增长 + 位置振荡
3. **凹势类比（GUE 移植）彻底关闭**——ζ 零点**不是变分对象**（不由势最小化/最大化决定）
4. **深层含义**：零点分布由**解析结构（显式公式——素数）**决定——**不是变分原理**——这解释了为什么所有"势方法"（GUE 凸优化、凹势）不适用

## 4. 意义

- **负面结果有价值**：确认 ζ 零点是"非变分"对象——排除整个变分方法家族（GUE 移植、凹势、平衡测度）
- **正面启示**：零点分布 = 显式公式（素数）的直接结构——**唯一正确的框架是显式公式**（Guinand/van der Corput——我们的统一机制）
- **与我们的发现一致**：统一机制（素数相位结构 ⟹ 刚性）是唯一成功的路径——因为它是"显式公式框架"不是"变分框架"
