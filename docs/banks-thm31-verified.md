## 定理 3.1 验证（完美——）
Σ₁(T) + Σ₂(T/2πξ) = O(T^{½}log²T)：
- Σ₁（ζ 零点 ξ 扭曲）= −(μ/φ)·T/(2πξ) + 涨落（主项确认——模 q 算术——）
- Σ₂（Λ 的 ξ 扭曲）= (μ/φ)·T/(2πξ) + 涨落（Ramanujan 主项——）
- |Σ₁ + Σ₂| ~ 3-27（T=2000-20000——比值 ~0.001——远小于 T^{½}log²T 界）
- 对所有 q（含平方——q=4,8,9——μ(q)=0 情形主项为 0——同样成立）
