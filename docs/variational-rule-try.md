# 变分规则尝试：ζ = 最小化离轴能量 D？

> 2026-09-01 · 唐先生指示"先试试变分规则" · 诚实评估

## 变分规则的构造
- 能量：D[配置] = Σ_ρ P_γ_ρ(δ_ρ)（离轴能量——逐轨道正性——闭式）
- 规则：合法配置 = argmin D
- 若 ζ 最小化 D——D = 0——全轨道退化——RH

## 验证结果
### ✓ 在线是 D 的局部极小（平凡）
- ∂²P/∂δ²(0) > 0（γ=14.13: 4.18e-6——正定）——P_γ 偶函数——每个轨道独立
- 在线（全 δ=0）是 D 的局部极小——**但这是平凡的**（P_γ 偶——每个轨道单独最小化）

### ✓ D ≥ 0——全局最小值 0（在线）——逐轨道（平凡）
- 假想离轴（前 50 轨道 δ=0.1）：D = 2.43e-8（>0——代价）
- **但——"代价"不是"禁止"**——离轴配置 D>0 但"允许"

### ✗ 核心缺失："ζ 必须选最小值"不强制
- "ζ = 最小化 D"两种理解：
  1. **作为假设（原理）**：ζ 最小化 D ⟹ RH——但——这是"假设 RH"（循环）
  2. **作为定理**：证明 ζ 最小化 D——= 反向（D≤0）——我们的墙（D4）
- **变分规则没有绕过墙——只是换语言**

### ✗ "ζ 作为变分问题的解"——独立原理缺失
- 物理：最小作用量原理（原理——假设）
- 数学：ζ 是"给定的"（素数数据确定）——不是"变分选择的"
- "ζ 最小化某个能量"需要独立证明——未找到

## 诚实结论
**变分规则（ζ = 最小化 D）**：
- ✓ 在线是局部极小（平凡——P_γ 偶）
- ✗ "ζ 必须选最小值"不强制（离轴可实现——D>0 允许）
- ✗ "ζ 最小化 D"的独立证明未找到（= 反向——循环）
- **没有绕过墙——但——确认了"变分稳定性"是正确的问题**

## 变分规则的正确形式（如果可行）
需要：
1. **能量泛函 E[配置]**——独立构造（不依赖零点——Level 2）
2. **ζ = E 的唯一全局最小化器**——独立证明
3. **最小化强制轨道退化**（δ=0）——E 的结构保证

**D 不是正确的能量**（局部极小平凡——不强制全局）——需要**新的能量泛函**——其全局最小化**唯一**且**强制退化**——未找到

## 与"变分稳定性"（唐先生排序的高优先级）的关系
- 变分规则尝试确认：需要"ζ = 某个能量泛函的唯一全局最小化器"（且最小化强制退化）
- 这是"变分稳定性"方向的核心——但——能量泛函未找到
- D（离轴能量）不是——需要新的（含 γ 通道 + β 通道 + 全局结构——且最小化唯一）的泛函
