## P16 框架（唐先生）
**把"离轴"理解为"复谱的非正规性"（non-normality）**——不是位置 β——而是成对非自伴谱结构（ρ 和 1−ρ）：
- **更弱目标（比 HP 弱）**：Tψ_ρ = γψ_ρ + δ·φ_ρ——||(T−γ)ψ_ρ|| ≍ |δ|——**RH 表现为"某个算术算子的非正规性必须为零"**
- 非正规算子有额外信息 [T,T*]——N(T) = ||[T,T*]||——或——局部 defect N_ρ = ||(T*−λ̄_ρ)ψ_ρ||
- **算术共轭**：A（乘法算术）B（函数方程）——A* = U⁻¹AU——或——[A,B] = R_arith——R_arith 独立正性/零性 ⟹ 零点实部进入 defect
- **两步分开**：几何 lemma（||[T,T*]|| ≥ C·Σw_jδ_j²）+ 算术 normality lemma（arithmetic ⟹ [T,T*] = 0）——两个独立定理

## P16 第一道门检查
### ② 固定算子的非正规性
- 平移 T_a：酉（正规——[T,T*]=0）——反射 R：自伴（正规）
- 组合 D = T_a·R：非正规（[D,D*] ≠ 0）——**但——[D,D*] 固定（不含零点——不感知 β）**

### ③ β 如何进入（两难确认——与 P12/P13 相同）
- ⟨ψ_ρ, [T,T*]ψ_ρ⟩——ψ_ρ 需含 β：
  - 求值泛函（显式公式——自适应——循环）
  - T 特征向量（算术——不含零点——不感知）
  - T_Λ（含配置——感知——但——含零点——循环/非自适应桥）

### ④ 伪谱（唐先生的更弱版本——近似 HP）
- "γ 是 T 的近似谱（残差 δ）"——**T（算术——平移/反射）谱连续（单位圆/±1）——不含离散零点虚部**——除非构造含零点（循环）
