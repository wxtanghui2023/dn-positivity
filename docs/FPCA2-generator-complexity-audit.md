# FPCA 修正 + FPCA-2：Generator Complexity Audit（纸面，无程序）

**日期**：2026-09-10 ｜ 唐先生拦截两处错误，助手接受并撤回 ｜ 判决：复杂度门槛不成立 → 改为"类型门槛"

## 0. 撤回（两处，必须留档）

### 撤回 1：输出信息量级错误
原写：未来配置携带 $\sim x/\log x$ 比特。**错。**
区间长 $L$、素数密度 $p\sim1/\log x$，稀疏二元串的 Shannon 熵为
$$L\,H_2(p)\sim\frac{x}{\log x}\log_2\log x\ \text{比特}$$
（或组合形式 $\log_2\binom{M}{k}$，$k\sim x/\log x$，$M\sim x/\log x$。）
$$\boxed{\Longrightarrow\ I_{\rm out}(x)\gtrsim \frac{x}{\log x}\log\log x\quad(\text{修正后})}$$
方向性结论仍成立（$x\log\log x/\log x\ \gg\ \log\log x$），但**原量级错误**。

### 撤回 2：由"输出信息量大"推"内部状态必须同样大"——无效
$$\boxed{\text{程序描述长度}\ \neq\ \text{程序输出的信息量}}$$
短程序（试除）可生成极高复杂度输出。这是 AIT 与 Shannon 熵的基本区别。
**故原文断言"排除一切有限状态 + 有限规则机制"作废。**

## 1. 采纳：P-Info 升级版（三量分离）

$$\boxed{I_{\rm state}(x),\quad I_{\rm rule}(x),\quad I_{\rm out}(x)\ \text{三者分离}}$$
候选**允许** $I_{\rm state}+I_{\rm rule}\ll I_{\rm out}$；否则任何压缩生成器在定义上被排除。
附加条件（**No primality oracle**）：$F$ 不得调用 $p_N,p_{N+1},\dots$ 或任何素性预言机。

## 2. FPCA-2：G1–G3

### G1：是否存在不调用 oracle 的短生成律，能确定具体位置？
$$\boxed{\text{是。试除：描述长度 }O(1)\text{，无 oracle，逐点确定每一个位置}}$$

### G2：最低不可避免的计算复杂度？
```
· 试除：单点 O(√n)；全部 n≤x：O(x^{3/2})
· Eratosthenes 筛：全部位置 O(x log log x) 时间，O(√x) 空间（分段）
· AKS（2002）：单点 O(log^{6} n) —— 【素性判定 ∈ P】
  ⟹ 全部 n≤x：~x·polylog(x)（拟线性）
```
$$\boxed{\textbf{结论：素性判定是多项式时间的 ⟹【计算复杂度不是这堵墙】}}$$
⟹ 唐先生所设想的 P-Comp 门槛**无法起判别作用**：任何候选都会平凡满足"低复杂度 + 无 oracle +
逐点确定位置"（试除与 AKS 就是现成反例）。

### G3：是否存在低复杂度但非局部、约束强度超越 sieve 的生成律？
```
存在（AKS 本质上是环 ℤ/n 上的全局代数条件，非局部）
但它【不产生任何解析刚性】：
  单点正确性证明 ⟹ 只说 "G(n)=1_{n prime}" ⟹ 与任何分布相容
```
$$\boxed{\text{点式（逐 n）判定}\ \not\Longrightarrow\ \text{聚合刚性（误差项/计数律）}}$$

## 3. 真正的门槛：类型错配（Type Wall）

$$\boxed{\text{点式生成器（n ↦ 素性，O(polylog)）确定【集合】，但不承载【聚合命题的证明】}}$$

- 素数分布是**聚合层**命题（$\pi(x)$、误差项、零点）；
- 任何"逐 n 判定"装置，其正确性证明是点式的；
- 点式定义**与任意分布相容** ⟹ 不能由它推出聚合界。

**诚实标注**：此断言的严格形式应是"可定义性/独立性"定理；目前它是**方法学边界**，
不是已证定理。但它与经典现象一致：素性的点式刻画是初等的，聚合行为必须用解析结构。

⟹ 修正后的机制墙不是"信息墙"，也不是"复杂度墙"，而是**类型墙**：
$$\boxed{\text{点式装置}\ \not\Rightarrow\ \text{聚合刚性}}$$
