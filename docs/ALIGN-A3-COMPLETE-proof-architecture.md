## §1 ⭐⭐⭐⭐ **前沿的证明架构（原文级 ✓✓）**
```
【核心两式（原文 ✓✓）】
   (1.1)  **rank P₁ ≥ 2 tr P₁ + 4 tr Q′ − 4b − ‖P₁ + Q′‖²_HS** ✓
   (1.2)  **N₀^s + o(N) ≥ rank P₁ ≥ 4 tr G̃ − 2N − ‖G̃‖²_HS = (2 − R(ψ) − o(1))N** ✓
   其中 P₁ := P 的**简单在线**部分，Q′ := G̃ − P₁ ✓；R(ψ) 由测试窗 ψ 决定 ✓
【零侧 (Z)（原文 §4 ✓✓）】ρ ∈ on ⟹ v_ρ ∈ ℝ^d、**m_ρ v_ρ v_ρ^T ⪰ 0 且 rank ≤ 1**
   ⟹ 求和得 **P ⪰ 0，rank P ≤ #on = N₀*(I′)** ✓
   又（其 Lemma 2.1 + 被加项非负）**‖v_ρ‖² = Σ_{0≤k<d} φ̂(γ_ρ−α_k)² ≤ L‖φ‖²₂** ✓
   ⟹ **tr P ≤ Σ_{ρ∈on} m_ρ = N₀(I′)** ✓✓
   另有 **(Z) 的计数不等式**：**tr P₁ + 2n₊(Q′) ≤ N** ✓
【(1.1) 的来源（原文 §B.3 ✓✓）】写 **Q = Q₊ − Q₋**（Q± ⪰ 0、Q₊Q₋ = 0、**rank Q₊ ≤ b** ✓），
   则 ‖P+Q‖²_HS = ‖P‖²+‖Q₊‖²+‖Q₋‖² + 2tr(PQ₊) − 2tr(PQ₋) − 2tr(Q₊Q₋) ✓
   用 **tr(PQ₊) ≥ 0**、**tr(Q₊Q₋) = 0**，及 **von Neumann 迹不等式 tr(PQ₋) ≤ Σ p_i n_i** ✓
   ⟹ 得 (1.1) ✓ —— **即：用【正指标 + 秩 + 二阶矩】把【零侧不可知量】夹住** ✓✓
【⭐ 分析输入（原文明确 ✓✓）】"the arithmetic inputs are **Weil's explicit formula**, the
   **Riemann–von Mangoldt formula** and **N(t,t+1) ≪ log t**, **Stirling for Γ′/Γ**,
   **Chebyshev–Mertens estimates for Σ_{n≤X}Λ(n)² and Σ_{n≤X}Λ(n)²/n**, and the
   **Montgomery–Vaughan inequality** for the frequencies {log n : n ≤ X}, X ≤ T.
   ⭐⭐ **No mollifier, zero-density estimate, or zero-free region is used.**" ✓✓✓
【第二结果】3s₁+4(s₂+p) ≥ (4−R(ψ))N 减去 s₁+2s₂+2p ≤ N ⟹ **N_d ≥ ½(3−R(ψ)−o(1))N** ✓（= 0.83625 ✓）
【推广】Theorem B：**对 L(s,χ)（固定原特征）逐字成立** ✓
```
