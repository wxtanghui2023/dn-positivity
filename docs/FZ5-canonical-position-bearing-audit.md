## 1. 对 FZ-3 的修正：canonical 位置承载对象**存在**

**反例（canonical 且携带位置）**：
$$W_0:=\ x\longmapsto \psi(x)-x=\sum_{n\le x}\Lambda(n)-x$$
```
· canonical ✓：Λ 由素数（乘法结构）定义，完全在 (+、×、|、≤) 之内
· 位置承载 ✓：其振荡由零点支配（ψ(x)−x ~ −Σ_ρ x^ρ/ρ）
⟹ **"canonical ⟹ 给不出位置信息"是错的**
```
**因此 FZ-3 的二分必须改写。** 真正的障碍不是"位置信息不可及"，而是：

$$\boxed{\text{canonical 对象的位置内容与 ζ 零点【互相定义】}}\\
\text{⟹ 从 }W_0\text{ 读出位置，必然经过显式公式 ⟹ 读的是零点本身，无独立杠杆}$$
即：**位置承载不是问题，"位置的独立来源"才是问题。**

## 2. 对唐先生 W(x)=0 反例的回答（双向修正）

你的反例正确：**低信息熵 ⇏ 低位置区分力**（若某定理证 $W=0\iff\Re\rho=\tfrac12$，一个 bit 也够）。
但**对偶的失效模式同样存在**：**位置内容"相同"⇏ 可用**——因为若 $W$ 的位置内容与目标**等价**，则任何"由 W 读出的刚性"都是在读零点（FZ-3 的 M1/N1 循环）。
$$\boxed{\text{真正的判据既不是 entropy 也不是 discrimination，而是【独立性】：}\\
\text{载体的位置内容必须【严格弱于】目标，且仍足以约束}}$$
⟹ **C2 必须从"non-encoding"强化为"non-equivalent"（C2′：不与显式公式互相定义）**
