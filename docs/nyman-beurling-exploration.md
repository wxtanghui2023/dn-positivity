## 1. 框架

**Nyman (1950) / Báez-Duarte (1990)**：RH ⟺ 特征函数 χ_(0,1) 属于 span{r_k} 的 L²(0,1) 闭包，其中 r_k(x) = {1/(kx)}（分数部分函数）。

**Möbius 恒等式**：Σ_{k=1}^∞ μ(k){1/(kx)} = 1（0<x≤1，精确）——Báez-Duarte：RH ⟺ Möbius 系数截断误差 → 0。

## 2. 关键实现细节（含修正）

### b_j 的修正（重要！）

$$b_j = \int_0^1 \left\{\frac{1}{jx}\right\}dx = \frac{\log j + 1 - \gamma}{j}$$

**不是** (1−γ)/j！（换元 u = 1/(jx)，下限是 1/j 不是 1）——文献中 (1−γ)/j 对 j≥2 是错的。

**验证**：b_2 = (log2 + 1 − γ)/2 = 0.5578 ✓（数值匹配）

### Gram 矩阵（分段解析）

G_{jk} = ∫₀¹ r_j r_k dx，用 u = 1/x 坐标 + 锯齿分段：
- 每段 u ∈ (a,b) 上 {u/j} = u/j − m，{u/k} = u/k − n
- 积分 = (b−a)/(jk) − (n/j + m/k)log(b/a) − mn(1/b − 1/a)

**验证**：G[0,0] = ∫r₁² = 0.2605 ✓（解析 0.2606）

### 最小二乘

χ ≈ Σ_{k≤M} c_k r_k，c = G⁻¹b，d_M² = 1 − bᵀG⁻¹b（||χ||² = 1）
