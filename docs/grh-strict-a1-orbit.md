# a1：复字符轨道封闭性——完整严格证明

> 目标：证明对任意原字符 χ（模 q——含复字符——），L(s,χ) 的非平凡零点集
> Z_χ 对映射 ρ ↦ 1−ρ̄ 封闭（同高度——重数保持）——判据轨道装配的基础

## 定理 a1.1（轨道封闭性——一般字符——）
设 χ 是模 q 的原字符（实或复——），L(s,χ) 的完成函数 ξ_χ(s) 满足
函数方程：
$$\xi_\chi(s) = \varepsilon_\chi\, \xi_{\bar\chi}(1-s),\qquad |\varepsilon_\chi|=1.$$
则 L(s,χ) 的非平凡零点集 Z_χ（计重数——）对映射 ρ ↦ 1−ρ̄ 封闭：
$$\rho \in Z_\chi \implies 1-\bar\rho \in Z_\chi,\qquad m_\rho = m_{1-\bar\rho}.$$

## 证明

### 第 1 步：共轭对称性（——χ 与 χ̄ 的零点关系——）
L(s,χ) 的 Dirichlet 级数（σ > 1——）：L(s,χ) = Σ_{n≥1}χ(n)n^{−s}。
取复共轭——注意 χ(n) 一般复值（χ 复字符——）：
$$\overline{L(s,\chi)} = \sum_n \overline{\chi(n)}\, \overline{n^{-s}}
= \sum_n \bar\chi(n)\, n^{-\bar s} = L(\bar s, \bar\chi).$$
即 L(s̄,χ) = conj(L(s,χ̄))（解析延拓下同样成立——恒等式在 σ>1 成立——
延拓保持——）。⟹ 零点关系：
$$\rho \in Z_\chi \iff L(\rho,\chi)=0 \iff \overline{L(\rho,\chi)}=0
\iff L(\bar\rho,\bar\chi)=0 \iff \bar\rho \in Z_{\bar\chi}.$$
（重数保持：共轭是反全纯映射——零点的阶不变——m_ρ = m_{ρ̄}（在 Z_χ̄ 中计——））

### 第 2 步：函数方程（——χ̄ 的零点映回 χ——）
完成函数方程：ξ_χ(s) = ε_χ ξ_χ̄(1−s)。ξ_χ 与 L(s,χ) 的非平凡零点
相同（Gamma 因子无零点——仅在 s=0 极点——不在临界带——）。
由 ρ̄ ∈ Z_χ̄——用 FE（对 χ̄——）：ξ_χ̄(ρ̄) = 0——FE 给
ξ_χ(1−ρ̄) = ε_χ ξ_χ̄(ρ̄)·？——注意 FE 的变量：ξ_χ(s) = ε_χ ξ_χ̄(1−s)。
令 s = 1−ρ̄：ξ_χ(1−ρ̄) = ε_χ ξ_χ̄(ρ̄) = 0——⟹ 1−ρ̄ ∈ Z_χ。✓
（重数：FE 是全纯的等价——ξ_χ(1−s) 与 ξ_χ̄(s) 同阶——m_{1−ρ̄} = m_{ρ̄}（在 Z_χ̄——）——
组合第 1 步（m_ρ = m_{ρ̄}——）和本步（m_{ρ̄} = m_{1−ρ̄}——）⟹ m_ρ = m_{1−ρ̄}——）

### 第 3 步：同高度（——判据轨道需要——）
ρ = β + iγ——则 1−ρ̄ = 1−(β−iγ) = (1−β) + iγ——虚部相同（+iγ——）——
实部 1−β = ½ ∓ δ（当 β = ½ ± δ——）。⟹ 轨道 {ρ, 1−ρ̄} 在同一高度 γ——
实部关于 ½ 对称（β 和 1−β——）。✓

### 第 4 步：实字符的退化（自配对——）
若 χ = χ̄（实字符——）——共轭对称退化为 Z_χ 的自共轭——
第 1-2 步合并为：ρ ∈ Z_χ ⟹ ρ̄ ∈ Z_χ（自共轭——）⟹ FE（自配对——
ξ_χ(s) = ε ξ_χ(1−s)——）⟹ 1−ρ̄ ∈ Z_χ——轨道结构同（在线 δ=0 自配对——
离轴 2 点——）。✓

## 推论 a1.2（判据轨道装配合法——）
对任意原字符 χ（实或复——）：
- Z_χ 对 ρ ↦ 1−ρ̄ 封闭（同高度——重数保持——）——轨道良定义
- 轨道分类：离轴轨道 2 零点 {½+δ+iγ, ½−δ+iγ}——在线轨道 1 零点（δ=0——）
- Q_χ − Q'_RH,χ = Σ_{轨道}m_ρP_γ(δ_ρ)——（正项和——装配合法——）
- 绝对收敛：|P_γ(δ)| ≤ Cγ^{−6}——Σm_ργ^{−6} < ∞（N_χ(T)=O(TlogT)——）
