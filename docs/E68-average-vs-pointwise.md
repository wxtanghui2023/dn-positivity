## 2. 真正障碍：**输入类型不匹配**（⭐ 核心）

| 我方全部无条件输入 | 形态 |
|:--|:--|
| Montgomery 对相关 ✓ | **对高度平均** |
| 大筛法 ✓ | **对频率平均** |
| 零密度（GM ✓） | **计数型（平均）** |
| E55 块二阶矩 ✓ | **对 n 平均** |

而 T1 需要：**对所有 $n$ 同时成立**（$\max_n$ 型 ✓）
$$\underbrace{\text{rms}\lvert S_n\rvert\sim\sqrt N}_{\text{能证 ✓}}\;\xrightarrow{\ \mathrm{L}^2\to\mathrm{L}^\infty\ }\;\underbrace{\lvert S_n\rvert\le 0.8N}_{\text{要证 ✗}}\quad\Longrightarrow\quad\textbf{代价}=\sqrt N\approx1414\ \text{倍}$$
⭐ 该 $\sqrt N$ **恰好就是缺口** ✓（非巧合 ✓）：L²→L∞ 的唯一标准工具 = **更高阶矩** ✓，
   而四阶矩需要**逐点的对相关** ✗（非平均 ✓）⟹ 循环 ✓

## 3. ⚠️ 压缩效应使"平均"更无效（✓ 本轮新看清 ✓）

```
【在 n ≈ T₀² 处 ✓】n(θ_γ − θ_γ′) ≈ −nΔγ/γ² ≈ **−Δγ**（γ ≈ T₀ ✓）
   ⟹ **相位差 ≈ 纵坐标差本身** ⟹ 对 n **几乎不变** ✗
   ⟹ E_n[e^{inδ}] 的 sinc 因子 ≈ sinc(0.35Δγ) ~ **O(1)** ✗ **不衰减** ⟹ **非对角不被平均掉** ✗
⟹ 对象 = **一个固定尺度上的加权四重相关** ✓ —— **本质上是逐点型量** ✗ ✓
```
