## 1. ⭐ 本轮的桥（起草时发现，是 V2 的核心问题）

**把 V2 接到宪法修正案 2 的 N29 双通道上**：
```
修正案 2 结论：测试函数正性有两条通道 ——
   ① 比例/密度通道：**无条件有效**（已知前沿）
   ② 钉住通道（pinning）：位置盲，关闭
⟹ Levinson–Conrey 正是【比例通道的引擎】；而 √T 屏障是该通道的【定量上限】
⟹ 于是"缺口"从模糊的"比例 → 全部"精确化为一个可判定问题：
```
$$\boxed{\text{θ}=\tfrac12\ \text{（mollifier 长度 }T^{\theta}\text{）是【结构墙】还是【方法墙】？}}$$
```
· 若【结构墙】（可证 θ<1/2 为内禀限制）⟹ 比例通道被严格封顶于 <1
  ⟹ **产出新的 NO-GO（N47 候选）：比例通道无法达到"全部"** —— 且必须配 R
· 若【方法墙】（可绕过）⟹ **第一个真正的新入口出现**（R3 的构造起点）
⟹ 两种结果都是进展；且都不赌在 RH 上
```
