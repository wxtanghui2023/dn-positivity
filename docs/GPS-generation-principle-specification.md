# GPS — Generation Principle Specification（第四类机制验收规范）

**日期**：2026-09-10 18:15+ ｜ 依据：唐先生 (甲) 升级版｜ 定位：**判定器**，先于任何新模型
**适用边界**：ABD 保持冻结、不回挖；本规范用于**新生成原则**的准入判定

## §0 目的与定位
$$\boxed{\text{目标不是"限制清单"，而是能区分【真正第四类机制】与【换皮 ABD】的【判定器】}}$$
**要求的方向（必须满足）**：
$$\boxed{\text{生成原则}\to\text{内部约束}\to\text{唯一临界行为}\to\alpha=\tfrac12}$$
**禁止的方向（自动淘汰）**：
$$\boxed{\text{先有 }\tfrac12\to\text{设计一个规则让它出现}}$$
**规范先行**：本规范**先于**任何候选提交；任何候选必须**逐门**通过，且**通过顺序固定**（§7 决策树）。

## §1 五个硬门（唐先生指定）

### G1 — Primitive generation（原生产生）
**定义**：原则本身必须产生方向/状态演化，**不能从目标函数反推方向**。
**可执行检验**：
```
把原则的表述中【所有出现在目标侧的量】删掉（ab、a-b、ab/c^2、以及任何以平衡为目标的可观测量），
若原则仍能定义出方向/演化 ⟹ 通过；若原则退化为无方向或必须引用目标 ⟹ 淘汰
```
**淘汰条件**：方向只在对目标函数求梯度/极值时才存在。

### G2 — Non-monotone（非单调支配）
**定义**：不能由单一 $g=\gcd(a,b)$ **或其单调函数**支配。
**可执行检验**：
```
① 计算机制的方向/临界量对状态的全部依赖；
② 若存在单调 f 使（方向或判别量）=(f∘g) 的函 数，则淘汰；
③ 数值判据：对固定 c 的切片，检查该量是否随 g 单调（若严格单调 ⟹ 淘汰）
```
**已校准反例**：ABD-1′（$\mathcal C=(2\lfloor B/g\rfloor+1)^2$ 对 $g$ 单调不增）⟹ **G2 淘汰**。

### G3 — Target-blind（目标盲）
**定义**：规则**不得读取** $a-b$、$ab$、$(a-b)^2$、$ab/c^2$ 或**等价的 balance observable**。
**可执行检验**：
```
对原则的每个输入量做"是否在 σ(|a-b|, ab, c) 的平衡侧"审计；
注意 Gate V（空转检查）：审计判据必须【能】被某个状态违反，否则判据无效
```
**⚠️ 已知陷阱（须避免重犯）**：$(|a-b|,c)$ 决定无序状态 $\{a,b\}$ ⟹ **"不属于 σ(...)" 这种表述本身可能空转**；
正确形式是**方向性审计**：由该量诱导的方向是否 = $|a-b|$-梯度方向。
**已校准反例**：R0_grad（读 $|a-b|$）⟹ **G3 淘汰**。

### G4 — Information-preserving（信息保持）
**定义**：不能靠**非单射**、**商空间**、**canonicalization** 丢掉原始算术信息。
**可执行检验**：
```
① 检查映射在相关纤维上的单射性；若 fiber 尺寸 > 1 且增长（如 c-1）⟹ 淘汰；
② 检查是否对状态做了投影/取商（把不同态映到同一态）；
③ 检查是否依赖"规范化代表元"的选择
```
**已校准反例**：R4_sym（投影到 $(c/2,c/2)$，fiber $=c-1$）⟹ **G4 淘汰**；ER-1 的 $k{=}2$ 达点（两 child 皆平衡态）同因 ⟹ **G4 淘汰**。

### G5 — Cross-scale rigidity（跨尺度刚性）
**定义**：必须产生**真正的跨尺度约束**，并通过 $C_{\rm NI}$ 与 Gate V／V-b；
特别是**不能把 $1/2$ 写进权重、尺度律或边界条件**。
**可执行检验（三项全过）**：
```
G5-a 【A1】局部不可辨识：∀ 有界窗口 W，机制的限制到 W 的约束【不】确定 α
G5-b 【A2】耦合非平凡：删去跨尺度耦合后，α 的确定消失（Σ ⊊ Σ_dec）
G5-c 【C_NI / 不可插入】α=1/2 不可由自由目标参数、权重、归一化、边界条件替换得到
```

## §2 ⭐ 反调参测试（One-Knob Test；本规范的核心判别力）
$$\boxed{\text{若只改变一个自由参数，就能【连续把 }\alpha_*\text{ 调到 }1/2\text{】}\ \Longrightarrow\ \text{立即淘汰}}$$
**形式化（可计算）**：设机制族 $M_\theta$（$\theta\in\Theta\subseteq\mathbb R^k$ 为结构自由参数，**不含指数本身**），得 $\alpha_*(\theta)$。
```
淘汰：∃θ* , 方向 v，使 α_*(θ*)=1/2 且 ∂α_*/∂v |_{θ*} ≠ 0
      （即 1/2 是【参数范围内的可移动内点】）
通过（三者之一）：
  (a) Θ = ∅（无自由参数）
  (b) α_* ≡ 1/2 于整个 Θ（被强制，与参数无关）
  (c) α_*=1/2 仅出现在【刚性 locus】：唯一被约束固定的 θ，或 1/2 作为【极值】只在结构强制达到的边界处
```
**⚠️ 与之配套的禁令（表述层）**：定义（权重/尺度律/边界条件）中不得出现 $1/2$ 或**任何可证等于它**的表达式（$C_{\rm NI}$ 的证明论形式）。
**已校准反例**：ER-1 的均匀 $k$-child 族——$\alpha_*=\log k/\log(1/m)$，取 $m=1/k^2$ 即得 $1/2$，
即"**旋一个旋钮就能调到 1/2**" ⟹ **反调参测试淘汰**（这是教科书式反例，正是它推动了本规范）。

## §3 蕴含方向要求（不得反向设计）
**必须展示一条【单向推导链】**：
$$\boxed{\text{原则（不含 }1/2\text{）}\ \longrightarrow\ \text{内部约束}\ \longrightarrow\ \text{临界行为唯一}\ \longrightarrow\ \alpha_*=1/2}$$
**证书要求（提交时必须附）**：
```
① 原则的表述（逐字检查：无 1/2、无平衡量、无目标函数）
② 由原则产生的内部约束（可独立陈述，不需要知道答案）
③ 由约束推出临界行为的唯一性（不是"存在一个解"，而是"唯一解/唯一极值"）
④ 1/2 出现的【那一步】明确标注，且证明此前各步均不含 1/2
⑤ 若 1/2 出现在 ②③ 之间任何位置作为【输入】 ⟹ 自动淘汰
```

## §4 方法与卫生门（沿用既有登记）
```
Gate V   （空转检查）：任何判据运行前，必须先给出一个【能使其失败】的状态
Gate V-b （定义—数值对账）：引用的数值必须说明是【该类极值】还是【代表态值】
数值卫生：数值不是定理；"未找到" ≠ "不存在"；证据分级 [证明]/[结构性归约]/[实测]/[FROZEN]
勘误纪律：不得静默重写；修正以勘误形式记录（RCI-1；ERR-ABD1p-1 为示例）
```

## §6 什么算"通过"（证书形态）
```
一个候选通过 ⟺ 同时满足：
 (i)   G1 原生产生（方向不由目标反推）
 (ii)  G2 非单调（不以 g 或其单调函数支配）
 (iii) G3 目标盲（方向性审计通过，且审计判据非空转）
 (iv)  G4 信息保持（单射/无投影/无规范化依赖）
 (v)   G5-a/b/c 全过（局部不可辨识 + 耦合非平凡 + 不可插入）
 (vi)  反调参测试通过（Θ=∅ 或 α_*≡1/2 或 1/2 仅在刚性 locus）
 (vii) §3 的单向推导链完整，且 1/2 出现的那一步被明确标注
 ⟹ 【此时才允许】声称"生成了 1/2"
```
