## §0 结论（先说结论，R7 数字驱动）

```
【① 单/少项上界 → d_r(λ)² 在 r=1/2 处随高度 H 退化为平凡值 1】[核验]
   H = 0     （λ = 1/2 实）：单项 d² ≤ 0.2574、三项 d² ≤ 0.15665（目标 1 可被逼近 ⟹ 泛函"活着"）
   H = 10³  ：单项 d² ≤ 0.999993309、三项 d² ≤ 0.999990354（≈ 1）
   H = 10⁵  ：单项 d² ≤ 0.999999997、三项 d² ≤ 0.999999996（= 1 到 9 位）
   ⟹ d² = 1 − O(1/H²)，即 |A| = |⟨t^{−iH}, f⟩| ∝ 1/H（Riemann–Lebesgue）。
【② 无零点圆盘】[核验/推导]
   正确公式（DFMR I Thm 2.2 原文）：半径 rad = √(1−d²)/d²、圆心 (1/d², H)（a = r = 1/2）
   ⟹ 实际圆盘半径 rad ≈ O(1/H)：H=10³ ⟹ rad = 2.587×10⁻³；H=10⁵ ⟹ rad = 5.694×10⁻⁵。
   ⟹ **圆盘几乎为空（半径 ~ 1/H 随高度收缩），而非 E27 所预期的大圆盘**。
【③ E27 §2 公式有代数错】[核验/新发现]
   E27 写 rad = |λ|√(1−2a d²)/(a d²) ⟹ 比正确值多一个因子 |λ|/a = 2|λ| ≈ 2H（H=10³ 时 2000、H=10⁵ 时 2×10⁵）。
   根因：|z−λ|² < R²|z+λ̄|² 展开时，交叉项 (zλ̄+z̄λ)=2(ax+by) 的 y 系数应是 (1−R²) 而非 (1+R²)；
   正确圆心是 (a(1+R²)/(1−R²), b)（虚部 b=H 不变），不是 cλ=(ca, cb)。
【④ 非空 / 冲突】[核验]
   非空 ⟺ d² < 1；当前输入 d² ≈ 1 ⟹ 空。即使假设 d² 很小，圆盘左缘 Re = 1/(1+√(1−d²)) > 1/2，
   永不越过临界线 ⟹ 与 Platt–Trudgian 已验证零点（Re=1/2）**零冲突，也零信息**（Burnol"令人失望的事实"）。
【⑤ rad ≫ 1 所需 d²（正确公式）】[推导]
   rad ≥ 1 ⟺ d² ≤ 0.618；rad ≥ 10 ⟺ d² ≤ 0.0951；rad ≥ 10³ ⟺ d² ≤ 9.995×10⁻⁴；rad ≥ 10⁶ ⟺ d² ≤ 10⁻⁶。
【⟹ 诚实判语】在当前**未修好归一化**（M1）下，这些数字只对"DFMR ζ-case 泛函自身"成立，
   与项目的 d_N² **不是同一个量**（见 §5 G1/G2）。但有一个**与归一化无关的结构性结论**：
   点态距离在 r=1/2、高 H 处被相位 t^{−iH} 钉死在平凡值 1，故点态圆盘半径 ~1/H 收缩——
   **E27 的点态机制在 r=1/2 处不产生 rad ≫ 1 的圆盘，与 d_N² 修得再准无关**。

## §2 任务 1：单/少项上界估计 d_r(λ)²

**泛函精确形式（推导，据 §1 原文）**：
```
d_r(λ)² = dist( t^{λ̄} χ_{(0,1)} , K_r )²  于 L²((0,1), dt/t)，K_r = span(t^r({α/t}−α{1/t}))。
r = 1/2、λ = 1/2 + iH 时，因子 t^{1/2} 抵消：
   d_{1/2}(λ)² = min_{c,α} ∫₀¹ | t^{−iH} − Σ_j c_j ( {α_j/t} − α_j{1/t} ) |² dt        (Lebesgue dt)
⟹ 目标 = t^{−iH}（单位模、相位振荡），‖t^{−iH}‖² = ∫₀¹ 1 dt = 1。
```

**单/少项上界 = 最小二乘投影残差（推导）**：取一组基 f_j(t) = {α_j/t} − α_j{1/t}，
```
   d² ≤ 1 − vᴴ G⁻¹ v ， G_{jk} = ∫₀¹ f_j f_k dt ， v_j = ∫₀¹ f_j(t) t^{−iH} dt 。
单一项：d² ≤ 1 − |A|²/B ，A = ∫₀¹ f_α(t) t^{−iH} dt ，B = ∫₀¹ f_α(t)² dt。
```

**数值（核验，`scripts/A4C_pointwise_disk.txt`，EPS=1e-6 截断，尾差 O(EPS)）**：
```
  交叉验证 ✓：H=0 时 A = ∫₀¹ f_α dt = −α·ln α 解析成立，逐位吻合（0.259930 vs 0.259930 …）✓✓
  基线性无关 ✓：{f_0.25, f_0.5, f_0.75} 的 Gram 阵特征值 = (0.0489, 0.1414, 0.3799) 全正 ✓

  H = 0    ：单项 d² ≤ 0.257440（α=0.25）｜三项 {0.25,0.5,0.75} d² ≤ 0.156649
  H = 10³  ：单项 d² ≤ 0.999993309（α=0.875）｜三项 d² ≤ 0.999990354
  H = 10⁵  ：单项 d² ≤ 0.999999997（α=0.75）｜三项 d² ≤ 0.999999996
  ⟹ d² = 1 − |A|²/B，|A|² ∝ H⁻²（Riemann–Lebesgue）：H 增 100 倍，|A|² 降 ~10⁴ 倍 ✓
```

**诚实读法**：H=0 处目标 1 被分数部分函数明显逼近（d²≈0.16–0.26，且随项数增加而下降 ⟹ 方向正确）；
H=10³、10⁵ 处相位 t^{−iH} 在 t→0⁺ 无限次振荡，分段常数型测试函数**无法追踪** ⟹ d² → 1。

## §3 任务 2+3：圆盘半径、非空、冲突、1/d² 敏感度

**正确公式（引用，DFMR I Thm 2.2 原文自述的圆心/半径）**：
```
   集合 { μ : |(μ−λ)/(μ+λ̄−2σ₀)| < R } 是欧氏圆盘：圆心 ((a+R²(a−2σ₀))/(1−R²), b)，半径 2R(a−σ₀)/(1−R²)。
   σ₀=0、R²=1−2a d²、a=r=1/2：
     无零点区域 = r + 圆盘 = 圆心 (1/d², H)、半径 rad = 2aR/(1−R²) = √(1−d²)/d²。
   非空 ⟺ R²>0 ⟺ d² < 1/(2a) = 1。d²=1 ⟹ R=0 ⟹ 半径 0（空）。
```

**E27 §2 代数错（核验/推导）**：
```
   |z−λ|² < R²|z+λ̄|²  ⟺  (1−R²)|z|² − 2ax(1+R²) − 2by(1−R²) + (1−R²)|λ|² < 0
   ⟹ 圆心 (a(1+R²)/(1−R²), b)、半径 2aR/(1−R²) = R/d²。
   E27 把交叉项 (zλ̄+z̄λ) = 2(ax+by) 整体乘了 (1+R²)，但 y 系数实为 (1−R²) ⟹
   E27 得圆心 cλ=(ca,cb)（虚部错被放大 c 倍）、半径 |λ|R/(a d²)（多因子 |λ|/a = 2|λ|）。
```

**1/d² 敏感度表（核验）**——rad(正确) = √(1−d²)/d²，rad(E27) = 2|λ|√(1−d²)/d²：
```
   d²        rad(正确)        rad(E27, H=10³)    rad(E27, H=10⁵)
   1.0       空(半径 0)       空                  空
   0.1       9.4868           1.8974×10⁴          1.8974×10⁶
   0.01      99.499           1.9900×10⁵          1.9900×10⁷
   0.001     999.5            1.9990×10⁶          1.9990×10⁸
   10⁻⁶      1.0000×10⁶       1.999999×10⁹        2.0×10¹¹
   ⟹ 两者都是纯 1/d² 律；E27 版整体多一个与 H 成正比的因子 2|λ| ≈ 2H（虚假放大）。
```

**非空性 / 冲突（核验，data/zeros_odlyzko_2M.npy，2,001,052 个零点，γ ∈ [14.135, 1,132,491]）**：
```
   实际单/少项输入 ⟹ d² ≈ 1 ⟹ 圆盘半径：H=10³: 2.587×10⁻³（圆心 (1.000007, 1000)）；
                                     H=10⁵: 5.694×10⁻⁵（圆心 (1.0, 100000)）。
   ⟹ rad·H ≈ 2.6（H=10³）、5.7（H=10⁵）⟹ **rad ≈ O(1/H) 随高度收缩** [推导]。
   圆盘左缘 Re = (1−√(1−d²))/d² = 1/(1+√(1−d²)) > 1/2 对一切 d²∈(0,1) 成立 ⟹
   圆盘**永不越过临界线** ⟹ 与 Platt–Trudgian（|t|≤3×10¹² 已验证 RH）**零冲突**；
   且盘中 0 个已知零点（所有已知零点 Re=1/2）⟹ 同时**零信息**（不触及临界线）。
```

## §4 任务 4：可信度（依赖 M1）与 rad ≫ 1 所需 d²

   rad = 100 ⟺ d² ≤ 9.950×10⁻³
   rad = 10³ ⟺ d² ≤ 9.995×10⁻⁴
   rad = 10⁶ ⟺ d² ≤ 9.999×10⁻⁷   （≈ 1/rad）
```

**可信度标注（诚实）**：
```
【与 M1 的关系】本档案算的 d_r(λ)² 是 **DFMR ζ-case 泛函自身**（§7.1.1），
   不经过项目的 d_N²，故**不依赖 M1（归一化因子 k_N）** ✓。但反过来，它**也不等于** d_N²：
   · 项目 d_N²（N=160 修正后 = 0.0489，Báez-Duarte 形式）是**高度积分**量
     (1/2π)∫|1−ζ(½+it)A_N(½+it)|² dt/(1/4+t²)，长度截断 N；
   · DFMR d_r(λ)² 是**点态**量（一个 λ 处的距离），长度无界（所有 α∈(0,1]）。
   两者由 Mellin/Plancherel 对偶相连，但**不是同一对象**（见 §5 G2）。
【结构性结论（与 M1 无关）】d_r(λ)² → 1 − O(1/H²) 是**相位退相干**：目标 t^{λ̄} 的相位在
   t→0⁺ 无限次振荡，分段常数测试空间 K_r 无法追踪。这个结论对任何归一化都成立 ⟹
   **修好 M1 后，点态圆盘在高 H 处仍然空（rad ~ 1/H）**。
【⟹ E27 是否有实操价值】按本档案：**r=1/2 的点态圆盘没有**——除非能造出 d² ≪ 1 的 λ，
   而 r=1/2 下 d² 被钉在 1。DFMR 原文自己的改进（大 ℑλ 圆盘更大）来自换 φ=(1−t)^{−σ₁}χ_{(0,1)}
   （σ₁>0），**不是** ζ-case 的 φ=χ_{(0,1)}——这是另一个对象，未在本项内（标注未核验）。
【诚实判语】E27 的"d<ε ⟹ 圆盘"机制**形式正确**（§3 已核验公式），但把它接到本项目 d_N²
   需要跨过 (G1)(G2) 两道门（§5）；而即便跨过，点态量在高度的退相干也使其圆盘 ~1/H 收缩。
```
