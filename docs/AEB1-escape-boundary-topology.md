# AEB1-附：**强化**（无限但离散的阶段也逃不出拓扑障碍）

**动机**：§1 的结论"逃逸必须要求无限阶段"可能被误读为"无限阶段就能产生连续边界" ✗。此处收紧。

## §9 【推导】连续 1D 边界要求**非离散阶段**
```
命题：设每一阶段 S_n 都是【离散空间】（有限或可数/任意基数，均取离散拓扑）。
      则 ∏_n S_n 是【零维】空间：
        · 有限坐标柱集 = 有限多个坐标上的单点集的积 ⟹ 【开】✓
        · 其补集是其余柱集之并 ⟹ 也是【开】✓ ⟹ 柱集【既开又闭】✓
        · 柱集构成基 ⟹ 空间【零维】✓
      ⟹ 极限（作为闭子空间）亦零维 ⟹ 【全不连通】✓✓
```
$$\boxed{\text{离散阶段（有限【或无限】）}\ \Longrightarrow\ \text{逆极限全不连通}\ \Longrightarrow\ \text{不含任何非退化连通子集}}$$
$$\boxed{\Longrightarrow\ \text{connected 1D boundary 【不可能】是极限本身 —— 与阶段是否有限【无关】}}$$

## §10 因此逃逸路线的**真正必要条件是"非离散阶段"**
$$\boxed{\text{要得到 connected 1D，某阶段必须携带真正的连续统（}\mathbb R/S^1/\mathbb C/\ldots\text{）}}$$
```
⟹ 该连续统必须是【算术 canonical】的
⟹ 而算术中 canonical 的连续结构，恰好就是此前已排除的那些：
    archimedean（ℝ）｜adelic｜period/周期坐标｜spectral
⟹ 于是 AEB 路线的拓扑障碍【不因引入无限阶段而消失】，反而被收紧为一句：
```
$$\boxed{\text{AEB 要活，必须先有一个【算术 canonical 的连续阶段】—— 而这正是已排除的类}}$$
