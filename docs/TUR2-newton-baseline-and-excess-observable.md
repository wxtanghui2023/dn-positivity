## §3 ⭐⭐ **本轮的关键一步：Newton 基线**
```

且 x_k > 0 ⟹ **Newton 不等式**（对 N 个正数，N→∞）给出：
```
$$\boxed{r_n\ \ge\ \frac{n+1}{n}\ =\ 1+\frac1n\qquad(\text{RH 下必然})}$$
```
⟹ 故"r_n > 1"太弱；**真正的可观测量 = 超出 Newton 基准的【超额】e_n := r_n − (n+1)/n** ✓✓
