## ③ 逐类【局部 normal form】＋ 判定程序 ＋ 边界

> **纪律 ✓**：`E105` §5 **未给**形式化 normal form ✗（只给类名＋归类靶 ✓）⟹ 下列**标准形模板**均标 **〔本方拟定义 NF〕** ✓；
> 其**归类靶**沿用 `E105` §5 逐字（标＝档案级 ✓）；**不发明新类／新结论** ✗。

〔本方拟定义 NF〕称类 $c\in\mathfrak M_5$ 的一个**局部 normal form** 为三元组 $(S_c,\ \mathrm{Dec}_c,\ \partial_c)$：
```
· S_c  标准形模板（含参数）✓ —— 该类任意机制可写成 S_c 的一个元素 ✓（"局部"＝单机/单点版 ✗，不含全域统一性 ✗）
· Dec_c 判定程序 ✓ —— 输入＝机制的【有限呈现】（该机制的定义操作 ＋ 其算术数据 D ✓），有限步内判 "该呈现 ∈ S_c？" ✓
· ∂_c  边界 ✓ —— 【是】单点隔离但【不可】写成 S_c 的情形（反例／边界 ✓）
```

### ① 方程型
```
S₁ ✓标准形：M = ZeroSet(F) —— 由 D（整数/素数/理想/Galois/adelic/global ✓）canonical 构造的某函数 F，
   输出 L(ρ) ＝ {x : F(x)=0 且 x 为单零点} ✓；参数 ＝ 构造数据（呈现中给出 ✓）。
Dec₁ ✓输入＝(呈现 π, 数据 D)；步骤：① 解析 π 是否为"某 F 的零集回拉"✓；② 查 F 是否由 D 构造（过 E102 §C1 否式 A≠A({ρ}) ✓）；
   ③ 查零点是否【单点隔离】（收缩块 ∩D_N={ρ} ✓，E106 §2 等价形 ✓）。有限步 ⟹ 是/否 ✓。
∂₁ ✓边界：F=0 有【非孤立】零点（连续统 ⟹ 非单点 ✗）；重零点；且【③ 归约到此】⟹ ① 非极小类 ⚠️（见 §④ ✓）。
```
### ② 极值／不等式型
```
S₂ ✓标准形：M = argmax_{x∈Ω} Φ(x)（或 argmin ✓）—— Φ ＝ 由 D canonical 构造的泛函；参数 ＝ (Φ, Ω, 唯一性前提 ✓)。
Dec₂ ✓输入＝(呈现 π)；步骤：① 解析 π 是否为"某泛函的极值点提取"✓；② 查极大点是否【唯一】（否则非单点 ✗）。有限步 ⟹ 是/否 ✓。
∂₂ ✓边界：**并列极大**（tie ⟹ 非单点 ✗）；Φ 非严格凹 ⟹ 极值集非孤立 ✗；"箱 5"归类仅说明它【不看见零点】✗（E105 §5 逐字 ✓）。
```
### ③ 对称／不动点型
```
S₃ ✓标准形：M = Fix(g) = {x : g·x=x}，g 为 canonical 作用（等变 ✓）；参数 ＝ (作用 g, 基空间 ✓)。
⭐ 归约 ✓（逐字 ✓）：`E105` §5"对称／不动点（g·x=x）⟹ **仍是方程**"✓ ⟹ S₃ ⊂ S₁，取 F(x):=g·x−x ✓（〔本方推论〕）。
Dec₃ ✓输入＝(呈现 π)；步骤：① 解析 π 是否为"某作用的不动点集"✓；② 依 Dec₁ 判单点隔离 ✓。有限步 ⟹ 是/否 ✓。
∂₃ ✓边界：非孤立不动点集（如等变轨道 ⟹ 连续统 ✗）；S₃ 无独立判定力 ⟹ **并入 ①** ⚠️（归类靶逐字"仍是方程"✓）。
```
### ④ 可定义性型
```
S₄ ✓标准形：M = "最小满足 P 的点" —— (P, 逻辑 L, 良序) ⟹ 输出 ＝ 可定义元素 ✓；参数 ＝ 有限公式 P ✓（**有限句法对象** ✓）。
Dec₄ ✓输入＝(公式 P, 逻辑 L)；步骤：① 查 L 的判定性（如 Presburger 可判定 ✓）；② 逐字 ✓：Presburger ⟹ **最终周期** ⟹ **回 congruence** ✓（故归【类 VI】✗）。有限步 ⟹ 是/否 ✓。
∂₄ ✓边界：**弱逻辑**（如 Presburger）只能给"最终周期／congruence"结构 ⟹ **够不到**（超越）零点 ρ ✗；
   若逻辑强到能命名 ρ ⟹ 必【用 {ρ}】⟹ 违 `E102` §C1 否式 ⟹ 循环 ✗（〔本方推论〕）。
```
### ⑤ 动力／发生构造型
```
S₅ ✓标准形：M = lim_{n} T^n x₀（迭代极限 ✓）；或 = ZeroSet(ζ_dyn)（动力/转移 zeta ✓，E105 §5 逐字 ✓）；参数 ＝ (映射 T, 初值 x₀, 收敛模 ✓)。
Dec₅ ✓输入＝(呈现 π)；步骤：① 解析 π 是否为"某映射的迭代极限"或"动力 zeta 的零"✓；② 查收敛且极限为单点 ✓。有限步 ⟹ 是/否 ✓。
∂₅ ✓边界：极限=不动点 ⟹ 归 ③ ⟹ 归 ① ⚠️；动力 zeta 的零＝zeta 的零 ⟹ 若 zeta 由 D 解析构造则回 ①；归类靶逐字"箱 5"✗（E105 §5 ✓）。
```

```
【本轮 §③ 结论 ✓】五类**各有** (S_c, Dec_c, ∂_c) ✓ —— **局部 normal form 建成** ✓（在"给定有限呈现"意义下 ✓）；
```
