## 函数域权重定理的"最小结构"（Deligne/Weil——）
曲线 X/F_q——ζ(X,s) = P_1(T)/((1−T)(1−qT))——T = q^{−s}
RH（曲线——）⟺ P_1 的根 α 满足 |α| = q^{1/2}

**证明依赖的三件套**：
1. **Frobenius F**：X 上的几何自同态（x → x^q——）——作用 H¹
2. **函数方程/自对偶**（极化——）：ξ_X(s) = ξ_X(1−s)——来自相交配对
3. **模关系**：F 在极化下满足 F·F* = q——⟹ F/q^{1/2} 幺正——⟹ |α|² = q

**关键**：RH 不是来自"有 Frobenius"——是来自 **"Frobenius 在极化下的模 = q^{1/2}"**（权重——）——F 的"模"被几何钉住。

## char-0（ℚ——）缺什么？
1. **无代数 Frobenius**（x→x^q 不保持加法——）——已知
2. **FE 有**（ξ(s)=ξ(1−s)——极化影子——）——但只给对称（β↔1−β——）
3. **缺"Frobenius 的模"**：无自同态——无法定义"算子/权重标度"的幺正性

## 核心障碍的精确表述（推导结论——）
**函数域：几何（Frobenius——）提供"模"——权重 = 几何的产物**
**char 0：无几何自同态——"模"无来源——FE 只是极化的影子（无 F 的模——）**

**β 墙的"权重语言"**：RH 需要"权重律 |α|=1"——但 char 0 中产生权重律的机制（Frobenius 模——）不存在——所有替代（解析——谱——正性——）都给不出"模 = 权重"的约束。

## 推导第二轮（20:50——逐零点 vs 成对权重——）
### Archimedean 权重的精确状态
- |χ(½+it)| = 1（FE 因子模在临界线 = 1——）——Archimedean 侧"权重 1"存在
- **但只给 FE 对称**（ρ ↔ 1−ρ 成对——）——不给 RH（零点在反射固定点——）
- χ 的模不"钉"零点在 ½（离轴可成对——FE 仍成立——）

### 核心困难的精确化
**函数域**：Frobenius 的模给"逐特征值"权重（每个 α——|α|=q^{1/2}——）
**char 0**：χ/Γ 的权重是"成对"的（FE 反射——）——无"逐零点"权重
⟹ RH 需要"逐零点权重 1"——每个 ρ 单独 |e^{ρ−1/2}|=1——不是成对

### 为什么逐零点权重难
- 零点无限且连续分布（γ_n~n/logn——）

- char 0：无自然"逐零点对象"——需要**连续族实现**（模空间/形变——）
- 或者：零点是"某个大对象的谱参数"（回到 HP——死——）——或"连续族的参数"（模空间——未试——）
