# 排斥势探索：ζ 的势是凹的——GUE 凸性方法不适用（2026-08-23 19:55）

> 唐先生线索：Bourgade 刚性 → 探索"排斥势"移植
> 结论：❌ 凸性失败——ζ 势凹 vs GUE 凸——GUE 工具移植最后路径关闭

## 1. 探索：ζ 的 Hadamard 对数势

**势**：log|ζ(½+it)| 的零点贡献 = Σ_γ log|1−(½+it)/(½+iγ)| = Σ_γ log|γ−t| − ½Σlog(¼+γ²)

**数值（200k 零点）**：
```
φ'(t) ≈ −8（常数——零点之间——不为 0——零点不是势的平衡位置）
φ''(t) < 0（凹：−1.01, −1.31, −4.60 在 t=51, 200, 1000）
```

## 2. 为什么凸性失败

**GUE 对数气体**：能量 E = −Σlog|x_i−x_j| + ΣV(x_i)——**V 凸** ⟹ 平衡测度唯一（凸优化）⟹ 刚性

**ζ 零点**：
- 零点部分势：Σlog|γ−t|——**凹**（φ'' = −Σ1/(t−γ)² < 0）
- 主项（Γ 部分——θ(t)）：θ'' ~ 1/t²——**t 大时 → 0**——不能抵消凹性
- **完整势是凹的**——平衡不唯一（凸性缺失）——**GUE 刚性方法不适用**

## 3. 深层含义

**"看起来像 GUE 但证明不了"的数学原因找到了**：
- 数值上：长程相关、方差压缩、谱刚性——都像 GUE ✓
- 结构上：**势的凸性缺失**——ζ 零点不是"凸对数气体"
- **这就是为什么 GUE 工具（DPP/凸性/平衡测度）全部不移植**——不是方法不够——是**结构不同**（凹势）

## 4. 结论

1. **排斥势类比（GUE 移植）关闭**——凸性失败
2. **ζ 的结构特殊性确认**：凹势——不是 GUE 型——需要完全不同的工具
3. **数值相似性（长程刚性）是"表观"的**——深层结构（凸性）不同——**这解释了"像 GUE 但无证明"**
4. **一阶刚性（Σδ=O(1)）已经是最远能到的**（不需要凸性——用 mean(S)=½）
5. **二阶（方差压缩）需要处理凹势**——无现成工具——RH 深度（最终确认）
