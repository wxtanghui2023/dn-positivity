## 一、原文关键引理（逐字 ✓）

```
**Lemma 3.2 (Rank–trace inequality)**
  Let P, Q be Hermitian d×d matrices with P ⪰ 0, rank P ≤ r, and n₊(Q) ≤ b. Then
      (3.1)   r ≥ 2 tr P + 4 tr Q − 4b − ‖P + Q‖²_HS
  Equality holds if P = Π₁, Q = 2Π₂ for orthogonal projections Π₁ ⟂ Π₂ of ranks r, b.
```
```
**摘要（逐字 ✓）**
  "the Riemann hypothesis, classically needed to read the zero side as a positive sum over
   real ordinates, **is replaced by a rank–trace inequality** applied to a finite compression
   of Weil's Hermitian form, **with Sylvester's law of inertia handling off-line pairs**"
```
```
**证明（逐字片段 ✓）**
  "Write Q = Q₊ − Q₋ with Q± ⪰ 0, Q₊Q₋ = 0, rank Q₊ ≤ b. Then
   ‖P+Q‖²_HS = ‖P‖²_HS + ‖Q₊‖²_HS + ‖Q₋‖²_HS + 2tr(PQ₊) − 2tr(PQ₋) − 2tr(Q₊Q₋)
   and tr(PQ₊) ≥ 0, tr(Q₊Q₋) = 0. Let p₁ ≥ … ≥ p_d ≥ 0 and n₁ ≥ … ≥ n_d ≥ 0 be the
   eigenvalues of P and Q₋. By **von Neumann's trace inequality** tr(PQ₋) ≤ Σᵢpᵢnᵢ, so …"
```

## 二、5-C 的两个答案（都由原文直接给出 ✓）

### 答案 ①：**关掉惯性项 ⟹ 必须假设 RH** ✓ ⟹ 0.6725 **不成立** ✓

```
原文摘要明确 ✓：RH 在经典论证里"被需要来把零点侧读成**对实纵标的正和**" ✓；
本文**用秩–迹不等式 + Sylvester 惯性律替代它** ✓
⟹ **惯性项（−4b，b = n₊(Q)）正是"无条件化"的关键部件** ✓✓
⟹ 关掉它 ⟹ 回到 RH 条件 ⟹ 0.6725 只在 **RH 下**成立 ✓
```
✅ **所以 5-C 的答案是：不成立** ✓ —— 且**不需要新计算** ✓（原文自陈 ✓）

```
【我的疑问 ✗】为什么不用更强的 **Cauchy–Schwarz 形式** `rank ≥ (tr)²/‖·‖²` ✓？
```
