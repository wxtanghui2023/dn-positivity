## §2 TLDC 的精确 schema（五公理；在您的 A–E 上做**精化** ✓✓）

```
【设定】 有限交换群 𝒢（本实例 𝒢 = F_p^×，循环），给定满同态 π: ℤ → 𝒢（核 = (p)），
        并有一个"尺寸" |n|（本实例：中心代表 0 < n < p/2）。
        F : 𝒢 → {±1}，F(1) = 1。

【A · 良基尺寸】 存在 μ: 候选状态 → ℕ，使严格下降链有限 ✓
     实例：两个 ℕ-值量 —— **q**（强归纳）与 **n**（最小失败代表）✓✓
【B · 局部精确闭包】 存在生成集 S ⊆ 𝒢（含 −1）与"精确乘子子群"
     H := { c : F(cx) = F(c)F(x) ∀x } ⊇ S ✓
【C · 代表压缩】 对任意非空 **S-不变** 子集（特别：失败集／余商），存在代表 n 使
     **|n| · q < 阈值**（实例：2qn < p）✓✓
【D · 下降证书】 若代表仍失败，则可构造**更小**失败代表：
     存在 (j, r) 使 j < q、r < n，且 a ∈ {2j, 3j}、b ∈ {1,2}、a·n = p + b·r 或 p = a·n + b·r ✓✓
     （源码：`extension_descent_certificate_symmetric` 逐字给出该四元组 ✓）
【E · 小代表上的局部律】 在 |n|·q < 阈值 时局部乘法律可用（实例：F(qn) = F(q)F(n)）⟹ 与"C 给出的失败代表"直接冲突 ✓✓
```

**抽象定理（TLDC）**：满足 A–E ⟹ `H = 𝒢`（即 F 全域乘法）✓
**证明骨架（源码级）**：强归纳于 q（`2q<p`）→ ① 合数：`q=ab`（a,b<q）⟹ 归纳假设 ＋ `isGood_mul` ✓
② 素数：取失败集 `P(y) = [F(qy) ≠ F(q)F(y)]`，证 P 满足 C2 的不变性 → 用 C 得短代表 n →
用 E 得 `F(qn) = F(q)F(n)` ⟹ `¬P(n)` ⟹ 与最小性冲突 ✓✓；末尾由中心代表把任意 x 归到 ±n ✓

## §3 essentiality 分析（**本档新增核心** ✓✓）

```
【2 不可替代】 双重作用：① 最小性 ⟹ n 必为**奇**（否则 n/2 更小，由 2 ∈ H 保持失败）✓
   ② 下降中余数**为偶**（p,n,a 皆奇 ⟹ |p−an| 偶）⟹ 可**除以 2** 得严格更小代表 ✓
   ⟹ 去掉 2 ⟹ n 的奇性与半化同时失效 ⟹ **下降断裂** ✗✓
【3 不可替代】 作用 = **鸽笼覆盖**：q ≥ 5 素 ⟹ 3 ∤ q ⟹ q ≡ 1 或 2 (mod 3)
   ⟹ **2q−1 与 2q+1 中恰有一个 ≡ 0 (mod 3)** ⟹ 可写成 a = 3j 且 j < q ✓✓
   ⟹ 覆盖窄带 (2q−1)n < p < 2qn 这一**唯一残留区间** ✓（宽区由 2 的倍数处理，源码 `t = p/n` 分支 ✓）
【{2,5} 会失败】 5 ∤ q 无保证（q mod 5 ∈ {1,2,3,4}）⟹ 2q±1 不保证被 5 整除 ⟹ 鸽笼不成立 ✗✓
   ⟹ **3 的特殊性 = "最小的、且 ≥5 素 q 必与之互素的奇素数"** ✓✓
【奇偶性不可或缺】 半化要求 p 奇（⟹ p>2 素 ⟹ 本实例自动）＋ n 奇（由 2）＋ a 奇（a ∈ {2q±1} 或 a=2j 时另走分支）✓
【欧几里得逼近不可或缺】 宽区用 **p = t·n + s（0<s<n）**（`t = p/n`, `s = p mod n`），
   据 t 奇偶取 t 或 t+1 = 2j（j<q ✓）⟹ 这是**除法余项**给的下降 ✓✓
【双良基结构】 q-层（强归纳）与 n-层（最小反例）**互相配合**：素数情形用 n-层；合数情形用 q-层 ✓✓
   ⚠️ 注意：矛盾最终只需 r<n；**j<q 的作用是"使局部律可用"**（j<q ⟹ j ∈ H）✓✓
   + ⟹ 二者**角色分工**：`j<q` 供"可用局部规则"；`r<n` 供"良基矛盾" ✓✓
```
