# **`EXP-A-1`：一阶 β 信号在"仅由零点构型驱动"的载体上**恒为零**

## §0 我上一刀的两处技术错误（本档更正）

```
**(i) 高度方向发散** `F(z)=(z/r)e^{-z^2/r^2}` 沿 `|z|\sim 2\gamma_0` 给 `e^{+4\gamma_0^2/r^2}` **增长** ⟹ **零点侧和发散** ⟹ 不可容许 ✗（须改为对**谱变量** `\gamma` 的 Gauss 衰减）
**(ii) 配对求和** 对奇载体，配对 `\{\gamma_0-i\delta,\gamma_0+i\delta\}` 的**两项恒等相反** ⟹ 和为 `0` ✗
```

## §1 ⭐⭐ 判死定理（本档核心）

```
【事实 1】 离轴零点是**伙伴对**：`\rho_+= \frac12+\delta+i\gamma_0` 与 `\rho_-=\frac12-\delta+i\gamma_0`（＝`1-\bar\rho_+`）✓
【事实 2】 **伙伴交换** `\rho_+\leftrightarrow\rho_-` 等价于 `\delta\to-\delta`，而**多重集不变** ✓✓
【⟹ 定理】 设 `S` 是**只依赖零点多重集**的泛函。若 `S` 在**伙伴交换下为奇**，则 $$S\equiv0$$ —— 因为交换前后**输入相同**，而奇性要求值反号 ✓✓✓
【⟹ 推论】 $$\boxed{\text{任何"伙伴奇"载体（＝试图恢复一阶 }\delta\text{）在仅由零点构型驱动时恒为零}}$$ ✓✓
【⟹ 现状给定】 要么取**伙伴偶**载体 ⟹ 响应 `O(\delta^2)`（回到 `T1`）✗；要么**换输入**（见 §3）✓
```

## §2 **与既有结果的关系**

```
**`T1`**（σ-对称固定核一阶响应 `=0`）＝本定理的**特例** ✓；**`T3`**（逃逸需 σ-反对称）在**仅零点构型**口径下**不可实现** ✓（更正：`T3` 只对"泛函"成立，对"仅构型的泛函"无效）✓✓
```

## §3 ⭐ **逃逸条件（本档给出）**

```
【唯一出路】 载体输入必须**含一个在 `\delta\to-\delta` 下不不变的参数**，即：$$\boxed{\text{用\textbf{一参数形变族}，使伙伴对称被打破}}$$ ✓✓
【例子（我们已有的）】 `\Lambda`-型 heat flow（`t` 参数）；把某个常数/权重连续变形 ⟹ 在形变过程中 `\pm\delta` 伙伴**不再同时出现** ⟹ 一阶可用 ✓
【⟹ 与 `C` 的关系】 `A\to B` 的顺序在这点被**理论判死**：**`B`（静态移动载体）不可能恢复一阶；只有"形变/流动"路线（＝`C`）能** ✓✓
