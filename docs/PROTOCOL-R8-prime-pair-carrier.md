# 0. ⚠️ 勘误（先行，以撤回形式留档，不静默改写）

**被撤回的陈述**（`a38bf6f` / R-A6 第二轮 §2）：
> $\lambda_\zeta>1$ 的 carrier 是【素数侧独立对象】（依 Goldston–Montgomery 无条件处理 $\alpha\in[1,2]$）

**撤回理由**（唐先生核实）：
```
· GM87 的核心等价是在【RH 下】成立的
· 1987 把 Montgomery 的 x ≤ T^{1−ε} 推进到 x ≤ T，同样在【RH 框架下】
· Languasco–Perelli–Zaccagnini 明确把 GM 定理描述为"在 RH 下"建立
  短区间均方与 ζ pair correlation 的定量关系
· Bui–Keating–Smith（Selberg class 推广）明确指出其方法【从零点统计出发】，
  因为一般不存在可用的 Hardy–Littlewood 型算术自相关结果
```
**失误性质**：**未核实即用作判读依据**——正是本协议预注册所要防止的失效模式（"看起来独立，实际已偷偷用了 RH"）。
**拦截过程**：预注册的可证伪判据 + 外部核实 ⟹ 成功拦截 ✓（这正是 §6 纪律的价值）
$$\boxed{\text{勘误：R-A6 §2 "素数侧独立对象"判读【撤回】；}\lambda_\zeta>1\ \text{的 carrier 性质} = \textbf{未定}}$$

## 1. R8 命题
$$\boxed{R8:\ \text{短区间素数方差 / 素数对相关，能否作为 }\lambda_\zeta>1\ \text{的【独立、非等价、无条件】算术输入？}}$$
**三问（保持不变）**：
```
Q1 独立性  ：能否【完全不使用 RH / 零点统计】定义并无条件获得所需素数侧量？
Q2 跨越性  ：该量能否真正支持 λ_ζ>1，尤其 λ_ζ ≥ 2？
Q3 非等价性：它是否【不是】pair correlation / RH 的另一种表达？
```

## 2. ⭐ Gate 0（**本协议首位，强制**）：RH Contamination Audit
```
逐项追踪 GM87 及后续定理中
    素数方差 ⟷ 零点 pair correlation
的【方向】究竟在哪一步用了 RH；每一步必须打六个标记：
   ① unconditional / conditional
   ② 是否用了 RH
   ③ 是否用了 zero statistics
   ④ 是否用了 Hardy–Littlewood（或等价猜想）
   ⑤ 是否只是【等价转换】（无新信息）
   ⑥ 是否真的提供了新的 β-sensitive information
```
$$\boxed{\text{核心理念："素数侧对象可以定义"}\ \neq\ \text{"素数侧对象可以独立无条件算出"}}$$
**V1 要求的是后者**——Gate 0 就是查这一条是否被违反。
**已知方向性结构（本轮航标）**：
```
无条件可行的方向 = 【零点侧 → 素数侧】（即显式公式方向）= N1 编码方向
而"素数侧 → 约束"所需的方向，正是【非无条件】的那一侧（BKS 明确从零点统计出发）
⟹ 预先倾向：R8-C（Gate-4 型杀灭）——但**必须核实，不得先判**
```

## 3. 具体靶点（唐先生指定）
$$V(X,H)=\frac1X\int_X^{2X}\big(\psi(x+H)-\psi(x)-H\big)^2dx
=\ \sum_{h\le H}(H-h)\sum_{n\sim X}\Lambda(n)\Lambda(n+h)\ (\text{展开})$$
**逐箭审计表**：
| 箭 | 内容 | 须标记 |
|---|---|---|
| 箭 1 | prime-pair correlation → $V(X,H)$ | ①②③④⑤⑥ |
| 箭 2 | $V(X,H)$ → $\lambda_\zeta>1$ | ①②③④⑤⑥ |
| 箭 3 | $\lambda_\zeta>1$ → $\lambda_\zeta\ge2$ | ①②③④⑤⑥ |

## 4. ⭐ Gate 1（继承 R6 的字典问题）：H-范围 ↔ λ-范围 的映射
```
R6-D' 已确立：λ 不是跨机制统一坐标 ⟹ 本协议必须先给出
      V(X,H) 的 H-范围  ↔  λ support 范围  ↔  1-level density support
的显式映射，否则"support>1"无法被转译为"λ>1"
```
**结构性要点（待核实）**：
```
· 无条件结果通常覆盖【较大 H】（H 接近 X）而猜想覆盖【较小 H】（H ≤ X^{1−ε}）
· ⟹ 必须查清：无条件 H-范围 是否足以支撑 λ>1（而不仅是 λ<1）
```

## 5. Gate 2–4（三问的形式化）
```
Gate 2 独立性：所需精度下的素数侧量，是否无条件可得？（对照无条件 H-范围 vs 猜想范围）
Gate 3 跨越性：可达 λ ≥ 2 ？（决定性问题）
Gate 4 非等价性：是否只是 pair correlation / RH 的重述？
```
