## §1 G1 计算（显式；直线路径 ✓）

```
【设定】 主支：`ε_i = ε_j`（同号）、`R_r(x) ≠ 0`（故 `g(x) = √x·R_r(x) ≠ 0`）；
　路径（G1 用直线）：`x_i = x + δ`、`x_j = x`、其余 `x_ℓ` 固定 ✓
【numerator】 `N := F_{2r+1} = ε_i g(x_i) + ε_j g(x_j) + S`，`S := Σ_{ℓ≠i,j} ε_ℓ g(x_ℓ)`（对 δ 为常数 ✓）
【denominator】 `D := g(x_i)`（依 `C380-L3-1D` 候选 ✓）
【在 `δ = 0`】 `N_0 = 2ε_i g(x) + S`；`D_0 = g(x)`（**≠ 0** ✓）
【一阶系数】 `N_1 = ε_i g′(x)`；`D_1 = g′(x)` ✓
【⭐ 显式检查（依令②）】
　$$A_1 = \frac{N_1 D_0 - N_0 D_1}{D_0^{2}}
　= \frac{\epsilon_i g'(x)\,g(x) - (2\epsilon_i g(x) + S)\,g'(x)}{g(x)^{2}}
　= \boxed{-\,\frac{g'(x)\,[\,\epsilon_i g(x) + S\,]}{g(x)^{2}}}$$ ✓✓
```

```
