# P27-G5-C：Negative-Witness–Frequency-Isolation Uncertainty（obstruction 确认）

> 2026-09-01 · 唐先生 G5-C 指令 · 二叉判定实验 · uncertainty obstruction

## G5-C0：Channel-Isolation Lemma ✓
- f_{τ,ε}：dμ 集中 τ——u=τ+x——v=τ+y——**u−v = x−y——τ 完全消失（相位变量）**——cos(γ(u−v)) = cos(γ(x−y))
- u+v = 2τ+x+y——cosh(δ(2τ+x+y))−1——**τ 控制 β 信号大小**
- **⭐ τ 是 β 通道参数（信号强度）——不是 γ 隔离参数**——translation in u localizes the β channel, not the γ channel

## G5-C1：R(γ) 解析表达式
**R(γ) = α²A + 2αβB·cos(γε) + β²C**（点核近似）
- A = cosh(2δτ)−1（γ 无关）——B = cosh(δ(2τ+ε))−1（交叉项——γ 依赖）——C = cosh(2δ(τ+ε))−1（γ 无关）
- **γ 依赖 ONLY 在交叉项（cos(γε)）**——R(γ)<0 ⟺ cos(γε) > 阈值 = (α²A+β²C)/(−2αβB)
- 负区间周期性——宽度 ~ arccos(阈值)/ε

## G5-C2：负带宽
**Δγ₋ = arccos(阈值)/ε = 5.66**（δ=0.5——τ=0.1——ε=0.05——阈值 0.960）——**~O(1/ε)**——周期 2π/ε = 125.7

## G5-C3：零点间距比较
**Δγ₋ = 5.66 vs Δγ_zero ≈ 2.37（γ₀=14.13——2π/log γ₀）——比值 2.4——负带宽 ≫ 零点间距——单零点隔离不可能**
- 相位条件 ε ≲ 1/γ₀ ⟹ Δγ₋ ≳ arccos(阈值)·γ₀——O(γ₀)——高零点更严重

## G5-C4：dichotomy——uncertainty obstruction 确认
- **"negative bandwidth < zero spacing"（单零点隔离）——不可能**（Δγ₋ ~ O(1/ε) ≳ γ₀ vs Δγ_zero ~ 2π/log γ₀）
- **uncertainty obstruction**：局部负方向的产生机制（对角集中——ε 小——u−v≈0——宽频响应）与频率隔离机制（u−v 宽尺度）**不可兼得**——"负带宽 ~ 1/ε"与"相位条件 ε ≲ 1/γ₀"⟹ 负带宽 ≥ γ₀

## ⭐⭐ 关键简化——在线零点零贡献
- **在线零点（δ=0）：cosh(0)−1 = 0——D_ρ = 0**——Σ_{ρ≠ρ₀}D_ρ 只含"其他离轴零点"
- **"G5-C 不是控制所有零点——只是其他离轴零点"（唐先生 ✓）**
- 如果离轴零点稀疏（RH 否定假设）——L = Σ_{离轴≠ρ₀}|D_ρ|——有限项——可算

## ⭐ 核心判定
- **"单零点隔离"的障碍 ≠ "全局非抵消"的障碍**：
  - 单零点隔离不可能（uncertainty obstruction——Δγ₋ ≫ Δγ_zero）
  - 但全局 witness 只依赖离轴零点集合（在线零贡献）
  - **有限离轴假设（反证）**——有限项求和——同号/异号——周期负区间——**全局 witness 可能——未判定**
