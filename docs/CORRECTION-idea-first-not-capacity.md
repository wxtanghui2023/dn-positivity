## §1 ⚠️ **承认框定错误（本档第一件事）**

## §3 **正确的诊断轴（本档修正）**

```
【错】 $$\text{归约后空间}\ \le\ 10^4\times\text{日容量}\quad(\text{暴力路线判据})$$ ⟹ **降级为：只在"纯暴力候选"上才用** ✓
【对】 $$\boxed{\text{结构诊断：是否存在一个重述，把问题变成一个\textbf{一页内可写、机器可复核的小证书}？}}$$ ✓✓✓
【判据细化】 "小证书"的具体形状：**有限覆盖 ＋ 每块严格界 ＋ 见证 ＋ 独立校验器**（＝`k=4` 的形状）✓；或**一个不变量的有限代数判定**✓；或**一个单变量/小维问题的显式求解**✓

```
