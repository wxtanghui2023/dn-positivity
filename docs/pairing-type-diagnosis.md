# 配对类型分析：为什么函数方程不给 RH——Poincaré 对偶给 Weil

> 2026-09-01 · 搭接相探索 (c) 的深挖 · 最精确的机制诊断

## 三种配对的类型
| 配对 | 形式 | 模的约束 |
|------|------|---------|
| 共轭配对 | ρ ↔ ρ̄ | \|λ\| 相同——不固定模 |
| 函数方程配对 | ρ ↔ 1−ρ̄ | λ ↔ e^{−1}λ̄——乘积 e^{−1}——**不固定 \|λ\|** |
| **Poincaré 对偶（F_q）** | α ↔ q^w/α | 纯倒数——+ 共轭 ⟹ **\|α\|² = q^w——固定！** |

## 为什么纯倒数配对固定模——而共轭-缩放不固定
**Poincaré（F_q）**：
```
α 和 q^w/α 都是特征值（纯倒数——模互补）
+ α 和 ᾱ 都是特征值（实系数）
⟹ q^w/α = ᾱ ⟹ |α|² = q^w ⟹ |α| = q^{w/2} —— 模固定 —— β = w/2
```
**函数方程（Spec Z）**：
```
ρ 和 1−ρ̄ 都是零点（共轭-缩放——λ ↔ e^{−1}λ̄）
——乘积 |λ|·|λ'| = e^{−1}（固定）——但——|λ| 自由（β 自由）
——"纯倒数配对"（ρ ↔ 1−ρ——λ ↔ e^{−1}/λ）——不存在！
——不固定 |λ| —— 不固定 β
```

## 数值确认
- 函数方程：δ=0→0.3——乘积恒 e^{−1}——但 |λ| 从 0.61 变到 0.45——**不固定**
- Poincaré：|α| = √q 恒固定（不管相位）——**β = w/2 固定**

## ⭐ 最精确诊断
**Spec Z（Riemann ζ）缺"纯倒数配对"（Poincaré 类——α ↔ q^w/α）**：
- 函数方程只给"共轭-缩放配对"（ρ ↔ 1−ρ̄）——不固定模
- F_q 有"纯倒数配对"（Fr 的 Poincaré 对偶）——固定模——Weil 证明
- **"缺纯倒数配对"——是断裂双重的最精确机制**——RH 与 Weil 难度差异的配对类型解释

## pseudo-Hermitian/酉的关联（类型不匹配）
- **pseudo-Hermitian**（η 正定 ⟹ 谱实）：给"谱实"（虚部）——不是"模固定"（实部）——**类型不匹配**
- **酉算子**（|λ|=1）：给"模固定"——但——需要"模配对"（Spec Z 无）
- **"模固定"需要"纯倒数配对"**——Spec Z 的算子理论（TP/权）没有此结构

## 战略意义
- 这个分析把"断裂"推进到**配对类型**层面：
  - 共轭配对（ρ↔ρ̄）——不固定
  - 函数方程配对（ρ↔1−ρ̄）——共轭-缩放——不固定
  - **纯倒数配对（Poincaré——α↔q^w/α）——固定——F_q 有——Spec Z 缺**
- 这是"为什么函数方程（已知 150 年）不给 RH——而 Poincaré 对偶给 Weil"的机制解释
- **要找的"搭接相"**：本质上是找"纯倒数配对"（模互补——Poincaré 类）——Spec Z 没有已知来源
