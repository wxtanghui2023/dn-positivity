## §2 ⭐⭐⭐⭐ **审计：五处问题（按严重度）**

### ★★★★ **问题 1（决定性）：收尾论证【无效】** —— 循环/非逻辑
```
【原文（结论段 ✓）】"Hardy's result and **the computation of the nontrivial zeros** … **fixes already the
   real part of R**. If our critical line is located at σ = 1/2, it will be consistent with the Hardy's
   proof and the computation … else it will be contradictory with them. **This excludes the possibility
   that the critical line is off σ = 1/2.**" ✓
【为什么无效 ✗✓】
   · **Hardy 定理（1914）**：证明【无穷多个】零点在临界线上 ✓ —— **不是"全部"** ✗
   · **数值计算**：验证前 ~10¹³ 个零点 ✓ —— **不排除在其他高度存在离轴零点** ✗
   · ⟹ **"与 Hardy + 数值不相矛盾"【不能排除】临界线（由其模型定出者）偏离 σ=1/2** ✗✓
   ⟹ ⭐ **该步【以待证结论为前提】** ✓✓ —— 即：它用"已知有零点在线上"去论证"全部零点在线上" ✗
```

### ★★★ **问题 2：单位圆结论所依赖的正性【未给出】**

【事实】Lee–Yang/Fisher 的**单位圆结论**依赖于**铁磁性/正性（Markov 性）** ✓（Lee–Yang 1952 ✓）
【该文模型】另一晶向为**随机竞争性（含反铁磁）** ⟹ **Lee–Yang 前提不成立** ✗✓
   ⟹ **"全部零点在单位圆上"是【需证明】的强主张**，不能引用 Lee–Yang 定理 ✓
【我方相关资产 ✓✓】**我们的 TP₅ 失败**（7 个负子式，120 位稳定 ✓ + Gaussian 对照 ✓）——
   **证明该类核在亚正性层面失败** ⟹ **正是审计此类主张所需的工具** ✓✓
