# 重数强制搜索：Spec Z 无轨道退化的自然机制

## 核心问题
RH ⟺ 轨道退化（{ρ,1−ρ,ρ̄,1−ρ̄} → {ρ,ρ̄}）——退化需要"重数强制"——Spec Z 有候选吗？

## 候选盘点（全部审计）
| 候选 | 结果 |
|------|------|
| 有限维特征多项式（F_q 的 det(1−tFr)） | Spec Z 无（0 维——无 H¹——无有限维宿主） |

## 数值确认
- 特殊值变化 ~ δ²（连续）——不判别轨道退化（离散——δ=0 vs δ≠0）
- 退化度 Σδ²——= D 相关——无独立上界（D4 已审计）

## ⭐ 核心确认
**Spec Z 无自然的重数强制**：
- RH ⟺ 轨道退化（4→2 元素）
- 退化需要"重数强制"（F_q 的特征值多项式——有限维——Poincaré 对偶 + 共轭——重数固定——配对重合）
- **Spec Z：无限零点 + 0 维（无 H¹）——双重缺失——无特征值多项式——无重数强制——轨道退化无机制**
