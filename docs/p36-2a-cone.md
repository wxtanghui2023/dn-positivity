# P36.2-A：Arithmetic-forced Cone Positivity——第一轮（约定 + 关键认识）

## 尝试
用 Mellin-Weil（h_a(u) = u·e^{−au}——H_a(ρ) = 1/(a−ρ)²——Σ_ρ H_a(ρ) = A_a − P_a）验证约定 + 快速失败测试。

## 结果
**① Weil 验证差大**（±γ 对称修复后——a=2.5: 3.48——a=4: 0.12——a=6: 0.013——不 →0——约定不完美——可能 P_a 截断/尾部外推/平凡零点项）

**② 快速失败测试**：a>2 有效区——A/P 全 < 1（0.08 到 −32.8）——W = A−P 全负
**③ 分解**：A = 主项 1/(a−1)²（正）+ 修正（负——log(1−e^{−2u}) 项）——a 大时修正主导——A < 0——P（正——小 n 主导——收敛）

## ⭐⭐ 关键认识（重要——数值实验的局限）
**1. h_a = ue^{−au} 不在 Weil 正性锥**——它的"Fourier 变换"（Mellin 型 H_a(γ) = 1/(a−iγ)²）是复数——不是 ≥ 0——**h_a ∉ {ĥ ≥ 0}**——所以——W(h_a) < 0 不矛盾（RH 不需要 A ≥ P 对 h_a）

**2. 锥内"快速失败"不可能数值触发**——若 f ∈ Weil 锥（f̂ ≥ 0——Fourier 正）——则 A(f) − P(f) = Σ_γ f(γ)（实际在线零点——Weil）——**在线时 Σ_γ f(γ) ≥ 0（Weil 正性——RH 下——数值到 2M 零点）**——所以——**锥内 A/P ≥ 1 必然（数值）**——快速失败测试（inf A/P < 1）**在锥内不会触发**——只能对"锥外"的 f（不判 RH）

**3. "算术强制"（A ≥ P 独立证明——不用零点）是解析问题——数值不能做**——数值只能显示"实际符号"（= 检测——用零点算 Σ）——**检测 ≠ 证明**——"A ≥ P 的独立证明"需要 Γ 项 vs prime 项的解析不等式——数值无法验证

## ⭐ 结论
- **P36.2 的"快速失败"（情形 C）数值上不可能触发**（锥内 W ≥ 0 是实际事实）
- **"算术强制正性"是解析问题**——数值实验的价值有限（验证约定 + 检测离轴）
- **"金区"（算术强制 ∩ 离轴检测）**——数值只能显示"离轴检测"（P27-G 已有——D_δ 缺陷）——"算术强制"需解析（未找到）
- **正确方向**：解析尝试——A(f) ≥ P(f) 对锥内 f 的"独立证明"（Γ 项与 prime 项的结构比较）——或——接受"数值不可判"
