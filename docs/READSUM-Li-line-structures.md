## §2 ⭐⭐⭐ **结构一：λ_n 是【范数平方】**（2301.05779 Thm 1.1 ✓）
```
**RH ⟺ λ_n = (1/2π)·‖G_n‖²_{L²(ℝ)}  对一切 n** ✓✓
   · G_n(z) := H_n(1/2 − iz)，H_n 为**显式初等函数**（由 ξ、ξ′/ξ、η_k、ζ(k+1) 组成 ✓）
   · 且 **RH 下 G_n ∈ 模型空间 K(Θ)**，Θ(z)=overline{E(z̄)}/E(z)，**E(z)=ξ(1/2−iz)+ξ′(1/2−iz)** ✓
   · **K(Θ) ≅ de Branges 空间 H(E)**（Lagarias 引入 ✓），且
     **"乘法算子的某个自伴扩张以 ξ(1/2−iz) 的零点为特征值"** ✓✓✓ ← **Hilbert–Pólya 型结构在此**
   · 原文注：G_n 的**谱意义尚不清楚** ⚠️
【机制】**临界线 ℜ(s)=1/2 经 s ↦ 1−1/s 映到【单位圆】** ✓（故 |1−1/ρ| = 1 ✓）
```

## §3 ⭐⭐⭐ **结构二：λ_n 有【显式无条件算术公式】**（B–L Thm 2 ✓）
```
**λ_n = −Σ_{j=1}^n C(n,j)η_{j−1} + 1 − (γ₀ + log 4π)·(n/2) − Σ_{j=2}^n C(n,j)(−1)^{j−1}(1−2^{−j})ζ(j)** ✓✓
   其中 **η_k 有显式算术公式**：η_k = ((−1)^k/k!)·lim_{ε→0+}[ Σ_{1≤m≤1/ε} (Λ(m)/m)(log m)^k − (log(1/ε))^{k+1}/(k+1) ] ✓✓
   （即 −ζ′/ζ(s+1) 的 Laurent 系数 ✓，Stieltjes 常数家族 ✓）
【另一条 B–L 恒等式】**2λ_n = W( g_n(x) ∗ x^{−1}overline{g_n(x^{−1})} )**，W 为 **Weil 分布** ✓
   其中 g_n(x) = Σ_{j=1}^n C(n,j)(log x)^{j−1}/(j−1)!（0<x<1）✓ —— **完全显式** ✓
   原文注："该恒等式**无条件**成立，但**右侧非负性极为非平凡**" ✓
```
