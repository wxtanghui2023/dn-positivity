# Rédei R1——三体不可约性测试（四点混合差分）

> 2026-09-07 · v4 实现验证后进入 R1

## 测试设计
若 R(a,b,c) = f(a,b)+g(b,c)+h(c,a)（F₂ pairwise 可分解——）
则四点混合差分 Δ = R(a,b,c)+R(a',b,c)+R(a,b,c')+R(a',b,c') ≡ 0 恒
Δ ≠ 0 → 真三体（不可 pairwise 分解——）

## 结果
```
构造性采样（固定 b——a 池——c 池——）：
80 个四点测试——Δ≠0: 31——Δ=0: 49
Δ≠0 比例: 0.39
```

## 解读
- 若 R 纯 pairwise——Δ 应恒 0——**39% 非零 = 真三体不可约成分存在** ✓
- 39% 非 100%：R 含 pairwise 成分（部分被二体解释——）但非零混合差分证明**存在不可约三体部分**
- 符合 Rédei 符号的数学性质（真三线性——非循环积——"边正常但三角形有 obstruction"——）
