## 1. 无条件表达式

$$\lambda_n = \sum_\rho \left[1-\left(1-\frac{1}{\rho}\right)^n\right] = \sum_\rho \left[1-r_\rho^n e^{in\varphi_\rho}\right]$$

- $r_\rho = |1-1/\rho| = \sqrt{((\beta-1)^2+\gamma^2)/(\beta^2+\gamma^2)}$
- $\varphi_\rho = \arg(1-1/\rho)$

## 2. 三类零点贡献（验证）

| 零点 | r | 贡献形态 | 大 n 行为 |
|---|---|---|---|
| β=½ | r=1 | 1−e^{inφ} | 2sin²(nφ/2)·(上下对) ≥ 0 有界 |
| β>½ | r<1 | 1−r^n e^{inφ} | → 1（正，有界）|
| β<½ | r>1 | 1−r^n e^{inφ} | → −∞（指数负）|

**验证**：sin² 公式（单 γ）= 2×直接算 1−((ρ−1)/ρ)^n 实部（上下共轭对）✓

## 3. 敏感性：log|r| 展开

$$|r|^2 = 1 + \frac{1-2\beta}{\beta^2+\gamma^2}, \quad \log|r| \approx \frac{1-2\beta}{2(\beta^2+\gamma^2)}$$

- β<½（1−2β>0）: log|r|>0 → 增长
- β>½: log|r|<0 → 衰减
- **γ 大时 log|r| ~ 1/γ²**（极弱）——"慢燃"

## 4. 破坏时间表（数值，γ=100 单零点）

| β | r | 破坏 λ_n>0 的 n |
|---|---|---|
| 0.49 | 1.000001 | >10⁷ |
| 0.45 | 1.000005 | ~10⁷ |
| 0.40 | 1.000010 | ~3×10⁶ |
| 0.30 | 1.000020 | ~10⁶ |

**公式**：破坏条件 r^n > ½nlogn，n_break ~ γ²·log(½nlogn)/|1−2β|

## 5. 核心结论

1. **λ_n ≥ 0 对所有 n ⟺ 无 β<½ 零点**（Li 准则原始形式）
   - β<½ 贡献 ~ −r^n·cos(nφ)，必然在某个 n 超过正项（½nlogn）
2. **破坏是"慢燃"**：γ 大时 r−1 ~ 1/γ²，n 需 ~γ² 量级
3. **Voros 阈值确认**：γ~10¹² 的离轴零点需 n~10²⁵ 才显现
4. **我们的数值（n≤3000）**：排除 γ≤10⁶ 的显著离轴零点（β<½ 且 γ 小）
   - 但不排除 γ 大的慢燃离轴零点（数值不可达）
