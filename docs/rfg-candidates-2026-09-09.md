## 候选 R₁：加法质闭包关联（Tang 的例子）
```
R₁(n,m) = Σ_{p|n, q|m} 1{P^+(p+q) | n+m}
——p（n 的素因子——）、q（m 的——）通过 p+q 的最大素因子
  P^+(p+q) 关联到 n+m——
——不是独立问 p|n+m、q|n+m（CRT 可拆——）——
  是 (p,q) 联合 → P^+(p+q)（跨 p,q 的加法产物——）→ n+m
```
