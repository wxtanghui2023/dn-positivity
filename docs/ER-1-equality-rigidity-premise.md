## 0. 要检验的前提
ABD-0 留下的说法：**"$\alpha_*=1/2$ 恰在 AM-GM 平衡点 $a=b$ 处达到"** ⟹ 若能据此建立"动力学被迫取等"的**等号刚性**，(甲) 就通了。
其来源是均匀 $k$-child refinement：$k\,m^{\alpha}=1$，$m=r(1-r)$，$r=a/c$。取 $\alpha_*=1/2$：
$$\frac{1}{r(1-r)}=k^2\iff r(1-r)=\frac{1}{k^2}\iff r=\frac{1\pm\sqrt{1-4/k^2}}{2}$$

## 1. 精确求解（实算）
| $k$ | $r_-$ | $r_+$ | $\min\lvert r-1/2\rvert$ | $k\cdot m^{1/2}$（校验） |
|---|---|---|---|---|
| **2** | **0.500000000** | **0.500000000** | **0.000000e+00** | 1.000000000000 |
| 3 | 0.127322004 | 0.872677996 | 3.726780e-01 | 1.000000000000 |
| 4 | 0.066987298 | 0.933012702 | 4.330127e-01 | 1.000000000000 |
| 10 | 0.010102051 | 0.989897949 | 4.898979e-01 | 1.000000000000 |

$$\boxed{\alpha_*=1/2\ \text{对【一切】}k\ \text{都可由 }m=1/k^2\ \text{精确达到（校验列全为 }1.000000)}\quad\text{但 }k\ge3\ \text{的解【严重偏离平衡】}}$$
且随 $k$ 增大偏离趋于 $1/2$（$k{=}10$ 时 $0.490$）——**$\alpha_*=1/2$ 在 $k$ 大时由【极端不平衡】的 refinement 达到**。

## 2. 裁决：前提失败
```
k = 2：r(1−r) = 1/4 的根【唯一】为 r = 1/2 ⟹ 精确平衡 ✓
       但"两个 child 都取 r = 1/2"意味着两个 child 都是平衡态 (c/2,c/2) 本身
       ⟹ refinement 把父态塌缩成它自己平衡点的两份拷贝
       ⟹ 这正是 ABD-1 已判定的 (c) NON-INJECTIVE（fiber = c−1）= 【插入/对称化】，不是动力学
k ≥ 3：r(1−r) = 1/k² 有两个根，【都严格偏离平衡】（k=3: 0.127/0.873，距 1/2 约 0.373）
       而仍然精确给出 α_*=1/2（因 α_*=log k/log(1/m)，m=1/k² ⟹ log k/(2 log k) = 1/2）
```
$$\boxed{\alpha_*=1/2\ \textbf{并不}表征平衡的 child ratio}$$
$$\boxed{\text{"}\alpha_*=1/2\text{ 恰在 AM-GM 平衡处达到"【仅对】均匀 2-child 成立，而那一点正是【已排除的对称化】}}$$
$$\boxed{\textbf{(甲) 等号刚性不可得：取 1/2 的 refinement 要么退化/对称化 }(k{=}2)\text{，要么不平衡 }(k\ge3)}$$

## 3. 与冻结条目的一致性
这与 §12（ALIGNMENT SOURCE, FROZEN）**同向**：又一次出现"**sharp equality 不可由这些机制到达**"。
且 $k$ 越大越不平衡这一趋势，与 ABD-1′ 的"分支最大化偏好 primitive/不平衡态"同向。

## 4. 对 ABD-0 陈述的限定（限定，非改写）
ABD-0 的**已验证事实**仍然成立：
```
✓ m = ab/c^2 ≤ 1/4，等号 ⟺ a=b（c≤1500 穷举；AM-GM 精确）
✓ 特定非对称 2-child refinement（拆较大者）α_* < 1/2 严格，a/b→1 时 →1/2（实测）
✓ 均匀 k-child：α_* = log k / log(1/m)；α_*=1/2 ⟺ m = 1/k²
```
**需要限定的是【解读】**：
```
原解读："1/2 = 可达指数的上确界，被 AM-GM 从上方钉住"
限定为：上述"上确界/唯一达点"性质【仅对 2-child 均匀 refinement】，且该点退化；
        对 k≥3，α_*=1/2 由【不平衡】child ratio 达到 ⟹ 1/2 不是平衡的专属值
```
