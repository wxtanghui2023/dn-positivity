## 2. ⭐ 难度的**精确定位**（✓ 本轮最有价值 ✓）

```
S_n = Σ_{γ≤T} e^{inθ_γ} ✓，相位速度 |φ′(γ)| = nθ′(γ) = 4n/(4γ²+1) ✓
【快相位区 ✓】γ ≪ √n：|φ′| ≫ 1 ✓ ⟹ 驻相/vdC **有效** ✓（有抵消 ✓）
【慢相位区 ✗】γ ≳ √n：|φ′| ≲ 1 ✓ ⟹ **无抵消可用** ✗✗ ⟹ **困难唯一所在地** ✓
【临界点 ✓】γ ≈ √n 处 |φ′| ≈ 1 ✓ ⟹ 相位差 ≈ 纵坐标差 ⟹ **相位与纵坐标"同尺度"** ✓
   ⟹ 该区求和 ≈ **Σ_{γ∈slow} e^{iγ}** ✓ —— 一个**经典的单位频率零点侧指数和** ✓
⭐ **结构意义 ✓**：临界性 γ ~ √n ⟺ **临界密度** ✓ —— 与 Gabor 临界密度（h = 2π/L ✓）**同型** ✓
   ⟹ 即：**困难恰好落在"临界"这一点上** ✓（NS 里也是临界空间最难 ✓）—— 这是最干净的定位 ✓
```
