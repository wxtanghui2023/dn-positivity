# (乙) 端点攻击：**周期块法** —— 一个我认为【能消解端点障碍】的新论证

> 唐先生指令 ✓（21:01）："先选乙"（攻相位路线上的端点）
> 性质 ✓：**我的想法** ✓（不是文献里的 ✓）；**解析推导** ✓；**数值验证待做** ✗（见 §四 ✓）

---

## 一、想法 ✓：不用分部积分，用**相位周期分块**

```
【内部积分 ✓】I(n) = ∫_0^{T₀} cos(nθ(t))·main'(t) dt ✓
【分部积分路 ✗（(b) 已证失败 ✓）】留下 O(main(T₀)) 的【边界项】✗
【块法 ✓】改为在**相位 φ = nθ(t) 前进 2π 的块**上分块 ✓，换元 u = φ(t) ✓：
        **I(n) = ∫ cos(u)·G(u) du** ✓，G(u) := main'(t(u)) / |φ'(t(u))| ✓
```

## 二、⭐⭐ **关键恒等式（这就是端点被消解的原因 ✓）**

```
在一个**完整周期**上 ✓：
        ∫_0^{2π} cos u du = **0** ✓                      （常数项 → 0 ✓）
        ∫_0^{2π} u·cos u du = [u·sin u + cos u]_0^{2π} = (0+1) − (0+1) = **0** ✓✓
        （**线性项也 → 0** ✓✓ —— 这是与 sin 的关键区别 ✓）
⟹ ⭐ **每个完整块只留下【曲率项】G''·O(1)** ✓✓
⟹ 这与分部积分路形成鲜明对照 ✓：后者留下一个 O(main(T₀)) 的边界 ✗
```

## 三、⭐ **定量结果：内部积分小到可忽略** ✓✓

```
【G 的显式形状 ✓】G = main'(t)/|φ'(t)| ✓，φ ≈ n/t ✓ ⟹ |φ'| ≈ n/t² ✓ ⟹ **t ≈ n/u** ✓
        ⟹ G ≈ (n/u)²·log(n/u)/(2πn) = **n·log(n/u)/(2πu²)** ✓
【曲率 ✓】G'' ≈ c·**n/u⁴** ✓
【块数 ✓】φ 总前进量 ≈ nπ ✓ ⟹ **块数 ≈ n/2** ✓
【求和 ✓】Σ_blocks |G''|·O(1) ≈ ∫_{u_min}^{nπ}(n/u⁴)(du/2π) ✓
        = n/(6π·u_min³) ✓，而 **u_min = nθ(T₀) ≈ n/T₀** ✓
        ⟹ **|I(n)| ≈ T₀³/(6π·n²)** ✓✓
【在二次端点 n = T₀² ✓】**|I| ≈ 1/(6π·T₀)** ✓ —— 而信号 2N ≈ (T₀/π)log T₀ ✓
        ⟹ ⭐ **比信号小约 T₀²/(6π²log T₀) 倍** ✓✓✓ —— **完全可忽略** ✓
```

## 四、⚠️ 三条必须说清的保留 ✓

```
① **末块（不完整周期）** ✗ —— 需把截断选在 **sin(φ) = 0** 处 ✓（可控 ✓，与 ② 的受控终止相容 ✓）
② **δN 部分【不能】用块法** ✗ —— δN 是**测度** ✗（不是光滑函数 ✓）；
   且对 **sin** 线性项**【不】消失** ✗：∫_0^{2π}u·sin u du = [−u cos u + sin u]_0^{2π} = **−2π ≠ 0** ✗
```
