## 目标形式

$$X_k\ \text{给定}\ \Longrightarrow\ p_k\in I_k(X_k),\qquad I_k\ \text{真缩小}$$

要求：$X_k$ 自生成、不含素数表、不是 sieve 重包装、跨尺度收缩、
且临界尺度**自然**给出 $1/2$（不得人为放入）。

## Q1–Q2：最小状态变量 & 自生成

从 $(\mathbb Z,+,\times)$ 自身只能生成两类数据：

```
(a) 因子/整除数据（n 的分解）——【局部可检验】
(b) 序/大小数据（n 在 ℕ 中的位置）——【全局，但只是阿基米德序】
```

**唯一的全局"资源/饱和"结构**是：$(ℕ,\times)$ 是由素数生成的**自由交换幺半群**，
素数 = 生成元。但这个刻画只用乘法：

$$\boxed{\text{只用乘法 ⟹ Sym}(\mathbb P)\text{-协变 ⟹ 不能固定素数标签}}$$

（本项目早期已证：纯整除性结构对素数置换不变。）
⟹ **Q2 的第一结论：单靠"唯一分解的资源饱和"不可能确定位置**，
位置信息的唯一来源是乘法与**加法/大小**的交互（加法是唯一打破 $\mathrm{Sym}(\mathbb P)$ 的要素）。

## ⚠️ 循环性死亡分析（必须先摆上）

任何"足以约束位置"的 $X_k$，若包含每个 $n\le N$ 的因子数据，
则它**已经包含**哪些 $n$ 是素数
$$\Longrightarrow\ X_k\ \text{包含它要预测的东西}\ \Longrightarrow\ \text{违反 P1′（读 vs 约束）}$$

$$\boxed{\text{唯一出路：}X_k\ \text{必须是【压缩态】——复杂度有界，却能决定位置}}$$

即：**有界复杂度的、决定素数位置的压缩对象**。这是本方向真正的技术核心，而不是"饱和条件"。

## Q3：如何排除未来位置？

两条路径都被堵：
```
(i)  纯局部排除 ⟹ 就是 divisibility/CRT/sieve（第一天死）
(ii) 用素数分布的定理（PNT/Bertrand/误差估计）排除 ⟹ 用待证目标当输入（循环）
```
⟹ Q3 只有在"压缩态"存在时才可能有非循环答案。

## Q4：为什么不是 sieve/CRT 重包装？

因为要求 (i) 压缩（复杂度有界）+ (ii) 位置决定。sieve/CRT 是**局部且非压缩**的
（它需要记住 $[2,N]$ 上的全部倍数标记 ⟹ 复杂度 $\sim N$）。

$$\boxed{\text{判据：状态的描述长度必须 } \ll\ N\ \text{（例如 }O(\log N)\text{ 或 }O(\sqrt N))}$$

## Q5：$1/2$ 能否自然出现？

**能，而且很容易**——任何**自对偶配对**都给 $1/2$：
$$n\leftrightarrow x/n,\qquad \sigma\leftrightarrow1-\sigma,\qquad s\leftrightarrow1-s$$
自对偶尺度 = 平方根尺度 $\sqrt x$。

所以 Q5 的困难不在"产生 $1/2$"，而在**迫使误差/零点落在自对偶尺度上**。
必须区分本项目早已澄清的**三个 $1/2$**：
```
① 代数权重中点 / ② 函数方程对称中心（需阿基米德 Γ） / ③ RH 刚性
```
Q5 要求的必须是 **③**，不能是 ①②——否则就是"把 1/2 人为放进去"。

## 关键发现：压缩态的原型正是零点集，而它在你的排除清单上

$$\boxed{\{ γ: ζ(1/2+iγ)=0\}\ \text{是压缩的（离散、密度已知）且决定素数位置（显式公式）}}$$

这就是 $\mathcal P_X$ 类提案无法逃逸的结构原因：**"压缩 + 位置决定"的自然原型
= 零点集 = 显式公式**，而你已明确排除"显式公式换皮"。

⟹ 因此下一候选必须回答一个更尖锐的问题：

$$\boxed{\textbf{是否存在一个压缩、位置决定、但【不与零点集等价】的状态？}}$$

**等价性判据（可操作）**：
```
若 X 的不变量（谱/特征值/相位）能通过一个显式公式型的计算映射到 {γ}，
则 X 是换皮 —— 死。
若映射不存在，或映射本身要证明 RH —— 才是新桥。
```
