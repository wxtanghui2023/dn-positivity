## §3 ⭐⭐⭐ **结构发现（缺口精确化）**
```
【发现】**A(n)/n 在 n ≤ 20000 上【递增】** ⟹ **最小值出现在【最小的 n】**（n=1 ✓）
   —— 而在小 n 区，**A(n) ≈ n²·S2/2**（抛物线 ✓，S2=Σθ²≈0.0219 ✓）⟹ **A(n)/n ∝ n ⟹ 递增** ✓✓
   ⟹ ⭐ **小 n 区【可证】** ✓✓（由相位展开 1−cos x ≥ 2x²/π² 或直接展开 ✓）
【大 n 区】A(n) **饱和 ≈ N**（A(n)/N = 0.94–1.01 ✓）⟹ **A(n)/n ≈ N/n【递减】** ✗
   ⟹ 正性在 **n > 2N/B_T ≈ 3.8×10¹²** 处终止 ✓（与 Track A 估计一致 ✓）
   ⟹ ⭐ **剩下的缺口【精确化】为一条陈述**：

      **{n·θ_γ mod 2π} 在零点集上【足够均匀】** ✓✓（**Montgomery 型/等分布型** ✓）
```
⭐ **并且**：因 **θ_γ ≈ 1/γ**（γ 大 ✓），该和近似为**积分** ✓：
