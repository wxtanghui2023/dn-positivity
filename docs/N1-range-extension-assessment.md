## §1 **A 的范围是怎么来的（原文 ✓✓）**
```
【A 的定理】设 0 < γ ≤ T 的零点全在线上，且
   **#{γ ∈ [n/2, min(2n,T)]} ≥ n·B_T^exp/C₁(n)**（判据 ✓）⟹ **λ_n ≥ 0** ✓
【范围】**N_max(T) = 2T − O(1)** ✓（T = 3.000175×10¹² ⟹ n ≤ 6.00035×10¹² ✓）
【⭐ 原文给出的【机制】（关键 ✓✓）】
   "…the count in (criterion) is **N(T) − N(n/2)** … **the deficit is a constant because near
   n = 2T the count equals the number of zeros in [n/2, T], of order (T − n/2)·logT/(2π), and the
   required bound is ≈140 …, giving **T − n/2 = O(1)**." ✓✓✓
⟹ ⭐⭐⭐ **范围上限由【窗口被 T 截断】决定** ✓✓ —— **不是由离轴项决定** ✗✓
```

## §2 ⭐⭐⭐⭐ **为什么 B 帮不上（三条，逐条 ✓）**
```
【理由 1·瓶颈错位】A 的约束是**窗口上端 ≤ T** ✓（n ≤ 2T ✓）：
   窗口 [n/2, min(2n,T)] 必须落在**已验证区（0,T]** 内 ✓；
   n > 2T 时窗口退化为 [n/2, T] ✓ —— 而 n/2 > T 时**窗口为空** ✗ ⟹ **n ≤ 2T 是方法的硬边界** ✓✓
【理由 2·B 与 A 的求和对象不同】
   A 的离轴项 = Σ_{γ>T}[|w_ρ|^n − 1] ✓（**对 γ > T 求和** ✓，即**远处** ✓）
   B 的不等式 = Σ_{|γ|>H}[(1+1/γ²)^{k/2} + (1+1/γ²)^{−k/2} − 2] ✓（**对 H 求和** ✓）
   ⟹ 对 γ > T ≫ 1：(1+1/γ²)^{n/2} − 1 ≈ n/(2γ²) ✓ —— **与 A 的界【同阶】** ✗
   ⟹ **B 的"尖锐"只在 γ 接近 H 处有价值** ✓ —— 而 A 的求和区在**远场** ✗ ⟹ **无增益** ✓
【理由 3·两侧量级相当】A 的窗口计数 ≈ (1.5n/2π)log n ✓（**线性于 n** ✓）
   A 的离轴代价 = n·B_T ✓（**线性于 n** ✓）⟹ **判据与 n 无关**（只差 log n ✓）
   ⟹ **离轴项从来不是瓶颈** ✗✓ —— 故**任何**对它的改进都不改变范围 ✓✓
⟹ ⭐⭐⭐ **结论**：**B 的尖锐界【不能】扩 A 的范围** ✗✓ —— **"先扩范围"这条路不成立** ✓（诚实判定 ✓）
```

## §3 ⭐⭐ **更深一层：A 的范围是【在 T 上最优】的**
```
【推论】既然瓶颈是"窗口必须在已验证区" ✓，而窗口宽度 ~1.5n ✓、需要的最小零点数 ≈140 ✓
   ⟹ **只要用这个方法，n ≤ 2T 就是极限** ✓✓（**提高 T 才能提高范围** ✓）
```
