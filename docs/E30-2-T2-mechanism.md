## 二、⭐⭐ **机制：平方来自【模长】，不是来自 λ_n 的量级** ✓✓

```
【关键对象 ✓】共享恒等式（论文 A 与 B 的核心 ✓）：
      **|1 − 1/ρ|² = 1 + (1 − 2β)/(β² + γ²)** ✓✓
【离轴零点的模长 ✓】对 β > 1/2：|1 − 1/ρ| = 1 + (2β−1)/(2γ²) + O(γ^{-4}) ✓
   即 **log|1 − 1/ρ| ≈ (2β−1)/(2γ²)** ✓✓ —— **注意 γ 出现在【分母的平方】** ✓✓
【于是该项的 n 次幂 ✓】(1−1/ρ)^n 的模 = exp(n·log|1−1/ρ|) ≈ exp( n(2β−1)/(2γ²) ) ✓
【检测阈值 ✓】要让这一项【大到能盖过主项】✓，需要
      n(2β−1)/(2γ²) ≳ log n ⟹ **n ≳ 2γ²log n/(2β−1)** ✓
   ⟹ 即 **γ ≲ √( n(2β−1)/(2log n) )** ✓✓
   ⟹ ⭐ **h(n) ≈ √(nδ/(2log n))** ✓ —— **α = ½** ✓✓
```
