# 高度定位展开：β 检测器（z₀ = iγ₀ + ε）

> 日期: 2026-08-25 06:05
> 状态: 数值验证通过（尖峰 4014 倍 + 理论主导匹配 1.000）——严格化骨架完整——数据外可用（逐点）
> 目标: 非集体检测——按高度定位——读零点实部 β——不靠 k 矩的巨大 k

---

## 1. 定义

在 z₀ = iγ₀ + ε（ε 为小正实数）处展开 log ξ(½+z)：

$$\log\xi(\tfrac12+z_0+w) = \log\xi(\tfrac12+z_0) + \sum_{k\ge1} A_k w^k$$

$$A_k(\gamma_0,\varepsilon) = -\frac1k \sum_\rho \frac{1}{(\rho-\tfrac12 - i\gamma_0 - \varepsilon)^k}$$

- 若 γ₀ = 某零点 ρ₀=β₀+iγ₀ 的虚部：目标零点分母 = (β₀−½) − ε（**实数**）
- 其他零点分母 = (β_j−½) + i(γ_j−γ₀) − ε——模 ≥ |γ_j−γ₀| − ε（间距量级）

- **扫描 γ₀ → 尖峰位置 = 零点虚部**（数据外可用——用 ξ 数值——不循环）

## 3. β 检测（A₁ 符号翻转）

目标零点主导时：

$$A_1 \approx -\frac{1}{\beta_0-\tfrac12-\varepsilon}$$

- β₀ = ½：分母 = −ε——A₁ ≈ **+1/ε（正）**
- β₀ > ½ + ε：分母 > 0——A₁ ≈ **−1/δ（负）**
- **A₁ 符号翻转点 = β₀ − ½**——扫描 ε——从大到小——A₁ 从负变正（ε 穿过 β₀−½）

数据内验证（β₀=½——γ≈1000）：A₂ 全负（偶次——不区分）——A₁ 应全正（ε>0 无翻转）——待补 A₁ 数值（逻辑已清）

---

## 4. 严格化骨架

**引理 1（目标主导）**: 若 γ₀ 为零点虚部且 |β₀−½−ε| < min_j≠0 |ρ_j−½−iγ₀−ε|——则 A_k 由目标零点主导。
- 条件: |β₀−½| < 间距/2 − ε（零点间距 ~1/log γ——高处更小——ε 需相应小）
- 其他零点贡献 = O((间距)^{−k})——目标 = O(|β₀−½−ε|^{−k})——指数分离

**引理 2（A₁ 符号）**: A₁ 的符号 = −sign(β₀−½−ε)·(1+o(1))——翻转点在 ε = β₀−½。

**引理 3（ε 可扫描）**: 收敛半径 = |β₀−½−ε|——Vandermonde 圆半径 < 0.4·|β₀−½−ε|——ε 可扫描到 |β₀−½| 附近（数值——ε_min 由精度定——A₁~1/ε——dps=40 支持 ε~1e-10）

**核心推论**: 对任何**指定高度** γ₀（若该处有零点）——扫描 ε——A₁ 翻转点 = β₀−½。若翻转点 ≈ 0——β₀ = ½。

---

## 5. 数据外用法与诚实局限

**用法**（数据外——γ > 1.13e6）:
1. 扫描 γ₀（网格——步长 < 间距/2 ~ 0.03）——A₁/A₂ 尖峰 → 零点位置（ξ 数值——高处慢但可行——分钟级/展开）
2. 尖峰处——ε 扫描——A₁ 翻转点 → β₀

**局限（诚实）**:
- 逐点检测——每次一个高度——数据外零点无限——扫描网格有限——**不能自动覆盖全部**
- 覆盖全部需要"全平面论证"（所有 γ₀ 的 A₁ 无翻转）——= RH（循环）
- ε_min 限制：β₀−½ < ε_min 的慢燃离轴——检测不到（ε_min ~ 1e-10——dps 决定）
- 高处计算慢：mpmath zeta 高处 ~分钟/次——全扫描不现实——抽样/针对性检测可行

---

## 6. 与搭桥的关系

- **验证端**: 检测器（对任何指定高度——数值读 β）——数据内/中等高度验证通过
- **证明端**: 严格化（引理 1-3）给出"单点 β=½"的证明骨架——但——逐点——不自动覆盖无限
- **缺口**: 从"任意指定高度可检测"到"所有高度无离轴"——需要全平面论证——或——递推（检测到 γ_m → 下一个）——但——递推也需要知道下一个零点位置（扫描）——本质同墙
