## 精确有限维问题（已建立）
- **K**（加权 Gram）：G(j,k) = 1/(c_w − i(γ_j−γ_k))——Cauchy 型
- **A_M**（算术子空间）：span{a⁽⁰⁾,...,a⁽ᴹ⁾}——a_j⁽ᵐ⁾ = (log γ_j)^m/ρ_j（或 1/ρ_j^m——显式公式微分的权重）
- **N_ε(K)**（近零空间）：λ_min(K) 的坏方向
- **Restricted coercivity**：inf_{a∈A_M, ||a||=1} a*Ka > c_M > 0？
- **核心猜想**：A_arithmetic ∩ N_ε(K) = ∅——坏谱方向不属于 ζ 允许的算术子空间

## ⭐ 关键发现
1. **M=0（a=1/ρ——显式公式规范方向）restricted > 0——避开坏方向**——**确认 P5.9-S 的"a=1/ρ 不坏掉"**（单方向——不是子空间）
2. **M≥1 不避开**——span{1/ρ, (log γ)/ρ, ...} 太宽——**包含坏方向**——restricted → 0
3. **"算术子空间"需要更精确的定义**——不是"任意 span 生成"——而是"**显式公式兼容**"（A_arithmetic——满足 Z(Λ) = P——零点侧 = 素数侧）
