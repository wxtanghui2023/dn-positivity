## §2 ⭐⭐⭐ **两律的统一解释（假说 + 待核）**
```
【共同来源】**显式公式的傅里叶对偶**：素数侧在第 n 个素数/频率 log n 处贡献；零侧在高度 γ 处贡献 ✓
【T² 律的假说】第 n 个系数型探针（λ_n / γ(n)）的**敏感高度 ~ √n** ⟹ 用高度 T 的验证只能支撑 n ~ T² ✓
   ⚠️ **待核**：Li 的 (1−1/ρ)^n ≈ e^{−n/ρ} 表面上给出 n ↔ γ 的**线性**关系 ✗ ——
      故 T² 的**确切机制需查证**（可能来自【测试函数宽度 vs 尾部预算】的二次比较 ✓）
【log 律的假说】矩/阶/相位型探针的**有效阶数由数据的分辨率决定** ⟹ 阶数 ~ log(尺度) ✓✓
【共同含义】**两律都是"输入 ↔ 输出"的转换率**，而**不是**关于零点位置的陈述 ✓
   —— 即：**它们描述了【判据的信息容量】，而非【RH 的真值】** ✓✓
```

## §3 ⭐⭐⭐⭐⭐ **突破点的【可操作判据】（本框架最实用的产出）**
```
【推理】若某判据的探针满足"索引 n ↔ 高度 h(n)"，则：
   · h(n) ~ √n  ⟹ **可达 = （已验证高度）²**（律 I ✓ —— 现状 ✓）
   · h(n) ~ n    ⟹ **可达 = （已验证高度）¹（线性！）** ⟹ **比现状强【T 倍】** ✓✓✓
   · h(n) ~ n^α  ⟹ **可达 = （已验证高度）^{1/α}**（α < 1/2 才突破 ✓）
⟹ ⭐⭐⭐⭐⭐ **突破点 = 找到一个"索引→高度"优于 √n 的探针** ✓✓✓
   **具体后果**：**h(n) ~ n 的探针 ⟹ 可达高度 = 已验证高度本身** ✓✓ ——
   而**目前验证到 3.0×10¹²** ⟹ **若能线性推进，可达范围将从 9×10²⁴ 退回到 3×10¹² 的【点数】…**
   —— ⚠️ **注意方向**：此处"更强"指**同样的验证高度支撑更大的索引范围**（反之亦然：**用小索引覆盖更大高度** ✓）
   **最理想：h(n) ~ n ⟹ 索引 n 只需验证到高度 ~n ⟹ 可用 n ≤ T（而非 T²）** ✓✓
【推论】⭐ **律 I 与律 II 的界是【当前所有已知判据的族边界】** ✓ ——
   **任何突破必须先打破其中一条** ✓✓ —— 而**打破的方式只有两种**：
   ① **换探针**（寻找 h(n) 更优的判据 ✓）② **换输入**（用更强的算术输入，如二阶矩/零密度 ✓）
```
