# R3 考古 v3 结果——数值边界确认 + 非法扰动发现

> 2026-09-07 16:00 · D(a) 全-a 结构的数值考古

## 数值发现 1：单零点虚部扰动 → D < 0（非法配置——）
移动 γ₁ 的虚部（+0.1 到 +1.0——）使 S_proj **减小**（D < 0——）：
```
γ₁ +0.1:  D max = −3.3e-09（小 a 区 −7e-07——）
γ₁ +0.5:  D max = −1.6e-08（小 a 区 −3.3e-06——）
γ₁ +1.0:  D max = −3.3e-08（小 a 区 −6e-06——）
```
**这违反变分定理（D ≥ 0——）⟹ 单零点扰动不是合法配置**——与 8/31 发现一致（假想离轴违反 Weil——非法——）。

## 数值发现 2：合法配置空间受强约束
- 单独移动零点虚部 = 非法（破坏"来自某个 ξ'"——FE/Weil——）
- 合法的离轴配置 = 另一个 ξ'（满足 FE——）的零点——虚部整体"更分散"（D > 0——）
- **数值上无法构造合法离轴**（需要完整 ξ'——不可行——）——数值考古的边界

## 分析：变分定理证明不含跨 a 耦合
8/31 证明链（G = W(a)/2——逐项 Re[f_a] ≤ R ≤ S_proj——）**对每个 a 独立**：
- 每个 a 用同一论证（Re[f_a(t_ρ)] ≤ 1/(a²+γ²+δ²)² ≤ 1/(a²+γ²)²——）
- **没有跨 a 的耦合步骤**——变分定理本身不含"全 a 额外约束"

## 完全单调性检验（理论——）
- 1/(a²+γ²)² 对 a 的导数：f'' = (8a²−4γ²)/(a²+γ²)⁴——a < γ/√2 时负
- **单核不是 a 的完全单调函数**——S_proj 不是完全单调——Bernstein 检验结构上失败
- （核是"有界频率"型——非 Laplace 型——）

## 判断（初步——）
数值考古边界确认：
1. 无法构造合法离轴配置做数值测试（单点扰动非法——）
2. 变分定理证明逐点独立（无跨 a 耦合——）
3. S_proj 无完全单调性（核结构——）
