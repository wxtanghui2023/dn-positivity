## 一、错在哪 ✓

```
【我上一轮写的 ✗（`PAPERA-delta-N-attack.md`）】
   误差项 = 4∫_0^{T₀} sin(nθ(T))·δN(T)/(4T²+1)·dT ✓
   ⟹ |误差| ≤ 4C∫log T/(4T²+1)dT = **O(1)** ✓ ⟹ **O(log T₀)** ✓ ⟹ "免费" ✓

【错因 ✗】我把 δN **当成了有光滑密度的函数** ✗ —— 用了 `δN(T)·dT` ✓
   但 δN 是**计数函数的涨落** ✓，它**没有密度** ✗ —— 正确的写法必须是 **Stieltjes 形式** ✓：
        ⟨f, δN⟩ = ∫ f d(δN) ✓✗
   ⟹ 分部积分（对**测度** ✓，不是对函数 ✗）：
        ∫_0^{T₀} f d(δN) = [f·δN]_0^{T₀} − ∫_0^{T₀} δN·f' dt ✓
   其中 f = 1−cos(nθ) ✓ ⟹ **|f'| = n·|sin(nθ)|·|θ'| ≤ n·4/(4t²+1)** ✓
   ⟹ |内点项| ≤ sup|δN|·n·∫_0^{T₀}4/(4t²+1)dt = C log T₀ · n · **π** ✓
   ⟹ ⚠️ **= O(n·log T₀)** ✗✗ —— **不是 O(log T₀)** ✗
```

## 二、更正后的后果 ✓

```
【与信号对比 ✓】信号 2N(T₀) ≈ (T₀/π)log T₀ ✓
   比值 = O(n log T₀)/(T₀ log T₀) = **O(n/T₀)** ✓
   ⟹ 要这个比值 ≪ 1 ⟺ **n ≪ T₀** ✗✓ —— **只给线性范围** ✗

⟹ ⚠️ **撤回**："① δN 项 = O(log T₀) 免费" ✗ 是**错的** ✓
⟹ ✅ **更正**：**δN 项本身就给不出二次范围** ✗ —— 它只给线性 ✓
   （也就是说：**它不是"免费"的 ✓，而是和线性范围同一量级 ✓**）
```
