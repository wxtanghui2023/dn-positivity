# 第一轮（唐先生执行，签署归档）

## 状态：**R6-D'**（比 R6-D 更强：不只是"参数不可比"，而是发现两类不同问题）

## Gate 1 — λ-字典的正确性判定
```
1-level density : supp φ̂ ⊂ (−λ,λ)                    ⟹ **λ 的基准定义** ✓
mollifier       : θ 是 Dirichlet 多项式长度指数        ⟹ **θ ≢ λ**（R-A2 已证 θ 可 > 1/2）✓
pair correlation: support 作用在【零点差变量】上，无条件区间 [−1,1]
                  ⟹ 与 1-level density 同族但**非同一参数**，不可直接比较数值 ✓
zero-free region: 区域形状，**根本不是 support 半径** ⟹ λ_ZFR ∉ ℝ_λ ✓
zero proportion : **下游输出量**（如 κ>0.4），不能反向定义 λ ✓
```
**首条正式 R**：
$$\boxed{R_1:\ \lambda\ \text{只能在同一统计机制、同归一化下比较}}$$
**注意**：1-level density 内部可比、pair correlation 内部可比 ⟹ **R6-D' 是全局坐标层风险，不是数学结论**。

## Gate 2 — λ ≤ 1 的来源（逐项）
```
A 显式公式 : 确是重要来源（support 增大 ⟹ 更长素数和），但**显式公式本身不证明 λ ≤ 1**
             （其他族在同一框架下可突破 1）
B positivity: **非普适** —— 已有无条件 orth/symplectic 族突破 1
             （ILS 型可达 support < 2；λ = 1.5；1.866…；15/8 = 1.875；渐近逼近 2）
             ⟹ **positivity ⇏ λ ≤ 1**，"1 是 positivity 的普适常数"被否定
C 算术独立性: 真正障碍确实在【非对角项】（最接近真结构障碍）⚠️
D 族平均   : **决定性反例** —— 固定权重、素数 level 的 holomorphic newforms 已有
             无条件 λ = 1.5，后续 1.866…，Maass 族 15/8
             ⟹ **λ = 1 不是 one-level density 的数学结构上限**
```

## Gate 3 — 主动攻击 λ = 1+ε
```
D_λ = D_diag + B_λ
· 但没有得到"B_λ ≥ c(λ) > 0 的结构定理"
· 实际得到的是：**B_λ = 一个可定义的非对角算术相关量**
· 且在 orth 族中，同类非对角贡献经 trace formula / Kloosterman / zero-density 可被控制甚至精确算出
⟹ 失败节点不是"λ=1 后数学禁止继续"，而是
   **"λ=1 后必须计算此前被 diagonal approximation 隐藏的非对角算术结构"**
```

## Gate 4 — 信息 vs 技术（判定）
```
类型 I（未算但可定义）：B_λ 型非对角算术相关
   · 可定义、不需知道零点位置、在他族可通过额外结构计算、困难主要是估计/cancellation/trace formula
   ⟹ **technology barrier**
类型 II（必须知道目标零点）：本轮**未发现**这种必然性
⟹ **λ=1 的现有障碍不能被升级成"信息论天花板"** ⟹ 倾向**技术型**
```

## Gate 5 — 能否到 λ ≥ 2（两层）
```
层 A（一般 canonical L-function family）：**可以**（1<λ<2，2025 工作 1.866…，Maass 15/8）
层 B（ζ 本身）：**未突破** —— ζ 没有可自由选择 symmetry type 的 family average
⟹ **不能把 λ_family = 1.866 搬成 λ_ζ = 1.866**；这是**族结构不匹配**，非简单"技术未移植"
```

## 第一轮裁决
$$\boxed{\textbf{R6-A 被否定}}\ \text{（已存在 canonical/independent/non-equivalent L1 机制使 support 跨 1）}$$
$$\boxed{\textbf{R6-B 不可宣布}}\ \text{（λ>1 是在【其他 L 函数族】实现，不是 ζ 的 RH engine）}$$
$$\boxed{\textbf{R6-D'}:\ \lambda\ \text{作为跨机制统一坐标不可用；}\lambda_\zeta\ \text{须单独定义}}$$
**留下来的真活口**：
$$\boxed{\text{为什么 orth/symplectic family 能跨过 1，而 ζ 的 unitary 对象没有相同的独立结构？}}$$

# 第二轮（小灵执行）：λ_ζ > 1 的 non-diagonal carrier 审计

## 1. 结构性差异：族有"第二条描述"，ζ 没有
```
族（Petersson/Kuznetsov）：
   迹公式提供【几何侧】= Kloosterman 和 + Bessel 核
   ⟹ 非对角项由【有限算术数据】给出，**独立于该 L 函数的零点** ✓✓
ζ：
   没有 family average；其"迹公式"就是【显式公式】
   而显式公式的几何侧**就是素数侧本身**
   ⟹ 问题归结为：**素数侧的非对角和非条件可算吗？**
```

## 2. ⭐ 关键文献线索（**待核实**，但方向明确）
```
· Montgomery：**无条件**范围 λ < 1（对角主导区）
· **Goldston–Montgomery (1987)**：**无条件**处理 α ∈ [1,2] 区间，
   其中 F(α) 的评估与【素数间隙的方差 / 素数对相关】相联系
   ⟹ **λ > 1 的 carrier 是【素数侧对象】，不是零点侧对象** ✓✓
```
**⟹ 我的初步判读（与协议里预注册的先验锚点相反）**：
$$\boxed{\lambda_\zeta>1\ \text{的 carrier 是【独立的算术对象】（素数对/间隙相关）}}\\
\boxed{\text{⟹ 在 }1\ \text{处的天花板倾向【技术型】，不是结构型}}$$
即：**缺失的输入 = 素数对相关数据**（经典独立问题），而**不是**与零点等价的信息。

## 3. 预注册的可证伪判据（防止事后调整）
$$\boxed{\text{判读失败（⟹ 转 R6-A 结构性）当且仅当可证：}}\\
\text{任何对 }\lambda>1\ \text{素数侧和的 canonical 求值，其正则化必须引入超越素数间隙统计的零点侧输入}$$
```
若该判据被证实 ⟹ R6-A（λ_ζ 结构性天花板）
若未被证实（当前状态）⟹ **技术型天花板**，缺失输入 = 素数对相关
```

## 4. ⭐⭐ 与 V1 规格的汇合（本轮最重要的正面发现）
```
V1 活对象规格要求：β-敏感 ∩ 位置作用 ∩ √X 对角 ∩ char-0 供给
                    ∩ 非 coboundary ∩ 非局部 ∩ 非零编码
而本轮得到的"缺失输入"= 【素数对（间隙）相关数据】恰好满足：
   ✓ char-0 供给（素数侧，纯算术）
   ✓ 非零编码（不含零点位置）
   ✓ 非局部（跨素数关联）
   ✓ β-敏感（其分布直接约束零点统计）
⟹ **R6 第二轮可能正好交出了宪法一直要求的"新的独立算术输入"类别**
⟹ 且它与本项目早期的素数间隙线（H₁ ≤ 240/186 等）直接相接
```

## 5. 因此：**不做坐标系跃迁；沿 λ_ζ 继续**
```
不做跃迁的理由：第一轮已否定 R6-A ⟹ 坐标系未失效
下一个真实动作：审计【素数对相关数据能否作为 λ_ζ > 1 的独立输入】
   —— 具体三问：
   ① 它是否独立于零点数据？（当前证据：是）
   ② 它是否足以跨过 λ = 2？（未判定——这是 λ_ζ 的决定性问题）
   ③ 它是否非等价？（即不与显式公式互相定义——当前证据：是）
```

## 6. Gate 6（写死，不变）
$$\boxed{\text{support enlargement}\ \not\Rightarrow\ \text{critical-line pinning}}$$
即使 λ ≥ 2，仍须额外过 C2′（non-equivalence）与 C3（independent），否则只是更强的 L1，不是 L3。
