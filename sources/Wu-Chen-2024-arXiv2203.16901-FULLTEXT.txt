 Abstract 
 A dominating set on an n n -dimensional hypercube is equivalent to a binary covering code of length n n and covering radius 1. It is still an open problem to determine the domination number γ ⁡ ( Q n ) ​  for  ​ n ≥ 9 ​  and  ​ n ≠ 2 k , 2 k − 1 \gamma(Q_{n})\text{ for }n\geq 9\text{ and }n\neq 2^{k},2^{k}-1 ( k ∈ ℕ k\in\mathbb{N} ). When n n is a multiple of 6, the best known lower bound is γ ⁡ ( Q n ) ≥ 2 n n \gamma(Q_{n})\geq\frac{2^{n}}{n} , given by Van Wee [ 4 ] . In this article, we present a new method using congruence properties due to Laurent Habsieger [ 1 ] and obtained an improved lower bound γ ⁡ ( Q n ) ≥ ( n − 2 ) ​ 2 n n 2 − 2 ​ n − 2 \gamma(Q_{n})\geq\frac{(n-2)2^{n}}{n^{2}-2n-2} .
